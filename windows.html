Windows 安装指引

适用于 Windows 10 及以上（64 位）

下载后第一次运行，Windows 很可能弹一个蓝色窗口：「Windows 已保护你的电脑」， 发布者写着「未知发布者」。这不是报毒，也不代表文件有问题——它只是说这个安装包 还没买代码签名证书。下面三步就能继续，整页看完不到两分钟。

一、出现「Windows 已保护你的电脑」怎么办

  1. 在那个蓝色窗口里点左下角的 更多信息（默认是折叠的，不点看不到下一步）。
  2. 展开后右下角会多出 仍要运行，点它。
  3. 之后就是正常的安装流程，一路下一步即可。装完只有这一次会问，以后打开不再提示。

二、如果没看到「更多信息」

有些系统设置下那个按钮不出现。改用这个办法：在下载好的 LawPulse-0.10.0-x64.exe 上点右键 → 属性， 在「常规」标签页的最下面，如果有一行「安全：此文件来自其他计算机…」， 勾选它右边的 解除锁定，点 确定，再双击安装。

三、杀毒软件拦下来了

没有签名的新安装包被安全软件拦截是常见情况。在拦截提示里选择「允许」或 「添加信任」即可；若它已经把文件移进隔离区，需要先从隔离区恢复，再重新运行。 法脉装好后不联网也能用，你也可以装完先断网试一遍。

四、为什么会有这个提示

因为这个 Windows 包还没有做代码签名。签名证书是按年付费的，我们想先确认 真的有 Windows 用户在用，再决定这笔年费——所以现在把 Windows 版标为「预览版」。 「预览」指的只是这件事：功能与法律库和 macOS 版完全一致， 不是功能阉割版，也不是测试版数据。

如果你因为这个提示犹豫要不要装，欢迎直接告诉我们一声（ 反馈入口）。 有人反馈，这件事才排得上号。

五、装完之后

  • 首次启动会把内置法律库铺开，需要等几秒，之后打开就很快了。
  • 安装包内自带 120 部常用法律法规，其余 400 多部在设置页一键补全，补全后同样存在本机。
  • 全文检索、笔记、案例库断网可用；只有 AI 功能需要联网，且用你自己的模型密钥直连。
  • 安装位置默认在 %LOCALAPPDATA%\Programs\lawpulse，卸载走系统「应用和功能」。
