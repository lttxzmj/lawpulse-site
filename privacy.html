法脉隐私政策

最后更新：2026-11-06

法脉是一款单机桌面软件。我们没有账号系统，也没有一台可以接收你内容的服务器—— 这不是承诺，是架构决定的结果。本页把「有哪些数据、存在哪里、什么时候会联网」写清楚。

一、我们不收集什么

  • 不需要注册，没有账号体系，不需要手机号、身份信息或执业信息。
  • 不收集你的材料内容：合同、笔记、文书、问题与搜索词都不会被发回， 连存放它们的字段都不存在。0.11 起有一项只记功能与时间的使用统计 （默认开启、可关闭、不含内容），口径见第四节最后一条。

二、唯一与你有关的个人信息：购买邮箱

  • 购买专业版时你提供的邮箱，用于签发激活码、标识授权归属，以及退款、续费、更换授权邮箱等必要联系。
  • 该邮箱与激活码记录保存在开发者本机的授权台账中，不进入任何第三方营销或分析平台。
  • 激活码采用 Ed25519 离线签名，验证全程在你的电脑本地完成，不联网、不回传，也不绑定机器指纹。

三、你的内容存在哪里

  • 法律库、笔记、高亮、法条关联、案件夹、导入的合同与文书、AI 生成的报告与问答记录， 全部存放在你自己设备的本地数据库：
    ~/Library/Application Support/法脉/。
  • 应用每天启动时在本机做一次数据库快照，滚动保留最近 7 份，同样只在本机。
  • 这些内容不会被上传。我们没有能接收它们的服务器，因此也无从备份、无从恢复、无从查看。 请自行做好本机备份。
  • 删除应用与数据目录后，这些内容即不复存在。

四、应用会发起的网络请求（穷举）

除下面几类之外，法脉不会主动联网（第 4 类自订阅功能上线之日起生效）：

  1. 检查软件更新：应用启动与打开设置页时，向对象存储请求一个静态文件 release.json 比对版本号；可在设置的「更新」中关闭自动检查， 关闭后只剩手动触发的操作会联网。请求不携带任何本机信息；对方（腾讯云 COS） 与所有 HTTP 服务一样能看到你的 IP 与访问时间。 若发现新版并由你点击下载，下载地址会带一个固定的 ?from=app-update 标记—— 它对所有人是同一个字符串，不含版本、机器或任何本机信息，用途只是让我们在服务器日志里 把「老用户升级」与「新用户第一次下载」分开计数，无法凭它区分或追踪某一位用户。
  2. 更新法规数据（专业版）：由你在设置页手动触发，从同一对象存储下载法规 JSON 文件。 同上，只暴露 IP 与时间，不发送你的任何内容。
  3. AI 功能（当前公测版）：请求从你的电脑直连你在设置中接入的模型服务 （默认通义千问，也可接入其他服务或本地模型）。我们没有中转服务器， 因此看不到请求内容。发送出去的是你提交的材料（合同条款、问题、附件与截图中的文本）与提示词， 该过程受该服务提供方的服务条款与隐私政策约束。 默认开启「发送前脱敏」，对全部 AI 功能一视同仁（合同审查、法库问答、 文书解读、文书起草、案件夹归纳、法条对照、案例检索）：身份证号、手机号、固定电话、 银行卡号、统一社会信用代码、邮箱、车牌会先在本机替换为占位符，当事人姓名与企业名 按裁判文书网风格化名（李某、甲公司）后再发出，模型返回后在本机还原，对照表不落盘。 金额、日期、案号、法条条号与法院、检察院等机关名称不替换——它们是分析本身要用的信息。 图片是例外：截图识字必须把原图整张发出，图片里的姓名、印章、签名 过不了文字脱敏这道闸，因此它会单独请你确认一次。 每家云端服务首次发送材料前，应用也会弹窗请你确认； 你也可以在设置中开启「仅本地模型」，由主进程拦截全部云端 AI 请求， 只放行跑在你自己电脑上的模型服务。 本机复核认为有当事人没被替换时，法脉会在材料发出之前暂停（默认开启）， 你可以当场把漏掉的词加入名单并重新脱敏，本次即生效； 「查看发出的全文」中还可搜索核对某个姓名是否确已被替换。 材料涉及病情、宗教信仰、未成年人、违法犯罪记录等《个人信息保护法》第二十八条 列明的敏感类别时，法脉会在隐私面板中告知但不替换——这类内容一旦 遮盖，模型就无法理解案情，是否发送由你判断。 图片是另一回事：文字脱敏对图片不起作用，整张原图会到达模型服务商。 因此发图前法脉会把图摆给你，可在图上拖框涂黑，涂掉的部分不随图发出； 这道确认不设开关、每次都有（本机模型除外），因为图片背后没有任何兜底。 笔记与案件夹可导出化名版（Word / PDF）：当事人化名、证件号等占位， 法条原文、案号与法院名保留，用于交付、培训或请教所外同行； 化名与 AI 链路共用同一套名册，同一主体在两处一致。 你可以随时查看实际发出的全文（顶栏盾牌 →「查看发出的全文」）， 也可以在设置的「隐私」里开启发送前预览：材料出网前暂停， 把脱敏后的全文摆给你过目，可当场取消（默认关闭；同一功能每次运行只问一次）。 脱敏完成后，法脉会在实际要发出的那份文本上再复核一遍， 把「看着像当事人却没被替换」的词挑出来提示你，可一键加入强制化名名单。 判别用的是你本机的法规全文（出现在官方法条里的词不会是当事人姓名）， 整个过程在本机完成；这些复核片段只存在于内存，不写入出网台账、 不落盘，关闭应用即消失。 你还可以在案件夹里建立当事人名册，并在设置的「隐私」里维护 强制化名与永不发送两张词表：名册与强制化名的词 换出去、换回来，永不发送的词替换为「【已隐去】」且不还原， 模型与你看到的结果里都不会出现。这些设定只存在本机，化名对照表不落盘。 每次请求的时间、功能、端点、模型、发出字节数与本机脱敏计数会记进本机的 出网台账（设置 → 隐私），滚动保留最近 500 条、可导出 CSV； 台账只记这些元数据，不记录材料内容，也不会上传。
  4. AI 订阅额度（自订阅功能上线之日起生效）：订阅用户的云端 AI 请求 经法脉额度网关转发到模型厂商，用于验证订阅资格与记点数，你无需接入任何服务。 网关的规则写死如下：化名替换仍在你的电脑上、出网之前完成，网关收到的已是化名版本； 请求与回答只在网关内存中经过，不落盘、不留副本、不用于训练； 日志只记激活码指纹（单向哈希）、时间、模型名、token 计数、点数与请求状态； 计量账本只记激活码哈希、月份与已用点数。 模型不分国内外，由你自己选（见下一条），启用清单会在本页列明； 本地模型与自定义接入不经网关，口径同上一条。
  5. 深度档与境外模型服务（0.11 起随订阅功能生效）： 订阅版的 AI 功能有三个档位——快答、深度、长文，在每个功能的发起处选， 默认快答。只有深度档会用到境外的模型服务，快答与长文只走境内厂商。 选深度档时，应用内的档位说明也会写明「经由境外模型服务，材料脱敏后出境」。
    接收方类别：①法脉签约的模型服务代理商（中转调用，境内或境外主体）； ②该代理商对接的境外模型厂商。两类的具体主体名称、所在地区与域名， 会在通道启用的同一个版本里在本页列明——没列明就是还没启用。 出境的是什么：你提交的材料与提示词，且已在你的电脑上完成化名替换 （口径与上一条的脱敏完全相同，境外通道不享受任何例外）；化名对照表留在本机、不出网。 做什么用：仅为生成你这一次请求的回答。按网关规则， 请求与回答只在内存中经过，不落盘、不留副本、不用于训练。 你怎么关掉：设置 →「AI 与订阅」→ 打开「深度档不走境外通道」， 开启后深度档由应用主进程直接拦住，材料不会出境（同一处还能把默认档位设为快答或长文）； 开着「仅本地模型」时，深度档同样被拦。 通道还没启用时会怎样：代理商通道尚未接通或整体不可用时， 深度档会自动改走境内模型，此时材料不出境， 并按快答档计点（不按深度档的三倍收），应用据此提示你这次实际走的档位。
  6. 使用统计（0.11 起，默认开启，可在设置的「隐私与安全」里关闭）： 法脉会把功能使用的元数据发回自家服务器，用来判断哪些功能真的有人用。 收集什么：用了哪个功能（如「打开法条」「新建笔记」「合同审查完成」）、 发生时间（精确到秒）、是否成功与耗时、应用版本、操作系统与安装渠道， 以及一个本机随机生成的标识（与激活码、购买邮箱、设备指纹都不关联， 可在设置页随时重置，重置后新旧数据无法关联）， 和每条记录自带的一个随机编号（只用来防止网络重发被计成两次， 每条各自随机，关联不出任何东西）。 不收集什么：合同、笔记、问题、文书、法条内容与搜索词—— 任何材料内容都不在其中，连字段都没有；也不收集 IP 之外的网络信息 （与所有 HTTP 服务一样，服务器能看到 IP 与访问时间）。 做什么用：统计哪些功能被使用、新装用户是否用起来了、 改动有没有让使用变多（A/B 对照）。不用于广告，不出售； 除下述看板服务外不共享给第三方。 存在哪里：法脉自己的服务器（与额度网关同一台，但分库存放， 不与激活码记录放在一起）。 看板服务（尚未启用）：拟由法脉服务器把上述元数据转给 PostHog， 不安装自动采集或录屏组件，不发送你的 IP、材料或身份信息。 PostHog Cloud 可选美国或欧盟区域，均在中国境外；实际主体、选定区域与启用版本 将在启用前于本页和更新日志列明。关闭统计会停止新采集并删除本机待发记录， 已上传的历史记录可能继续处理。 每次发送都会记进本机的出网台账（功能名「使用统计」），你可以自己核对； 关闭开关后立即停止，本机尚未发出的记录会一并删除。

给执业律师的提醒：使用云端模型意味着材料会离开你的电脑，发往该模型厂商。 请自行评估是否符合你的保密义务与客户约定；对保密要求极高的材料，请勿使用云端 AI 功能。 若你的委托协议或单位内控要求材料不出境，请在设置里打开「深度档不走境外通道」—— 这个开关由应用主进程把关，不依赖你记得别选那个档位。 不使用 AI 功能时，法脉的检索、笔记、案件夹与导出全程不联网。

五、模型服务的访问凭据

  • 当前公测版：模型服务由你在设置中接入，访问凭据经操作系统级加密 （macOS 钥匙串支撑的 Electron safeStorage）后仅存储于本机， 不会上传，也不会出现在导出文件中；使用该服务产生的费用由该服务方收取， 我们无从知晓你的用量。
  • 订阅上线后：AI 额度内置在订阅里，你无需接入任何服务；调用模型厂商所用的凭据 由法脉持有在网关侧，不进入你的设备。你已接入的服务不受影响， 可在「高级」中继续使用。

六、本网站

  • 本站是托管在 GitHub Pages 上的纯静态页面：没有账号、没有表单， 也没有广告脚本与第三方追踪像素。你在本站上用到的演示都在浏览器里跑完， 输进演示框的字不会被发到任何地方。
  • 本站不加载第三方统计脚本，不写 Cookie 或访客标识，也不记录你的输入内容。 应用内的匿名使用统计独立于本站，规则见第四节。
  • 与任何网站一样，托管方 GitHub 可以看到访问者的 IP 与访问时间。

七、涉及的第三方

  • 腾讯云 COS：分发安装包与法规数据。可见 IP、时间与所请求的文件。
  • GitHub Pages：托管本网站。可见 IP、时间与所访问的页面。
  • 你接入或订阅池启用的模型厂商：仅在你使用 AI 功能时，接收你提交的材料（已化名版本）。
  • 模型服务代理商与境外模型厂商：仅在你选择深度档且该通道已启用时， 接收你提交的材料（已化名版本）与提示词，用于生成这一次的回答。 具体主体、所在地区与域名将于通道启用的同一个版本在本页列明； 你可在设置里打开「深度档不走境外通道」彻底关掉这条链路。规则见第四节第 5 条。
  • 额度网关的云服务商（订阅上线后）：承载法脉的计量网关；内容不落盘， 规则见第四节第 4 条，具体域名与主体将于上线时在本页列明。
  • 使用统计的承载方：当前由法脉自己的服务器接收（与额度网关同机、分库）， 规则见第四节最后一条。
  • PostHog（看板服务，尚未启用）：拟接收第四节列明的匿名功能元数据， 不接收材料内容、姓名、手机号、邮箱、激活码或用户 IP。Cloud 的数据区域可选美国 或欧盟；签约主体、实际区域与启用版本将在启用前列明。

法脉不出售用户信息；对外传递仅限本政策列明的服务目的与字段。

八、你的权利

  • 你的内容始终在你自己的设备上，增删改由你直接完成，不需要向我们申请。
  • 与购买邮箱有关的查询、更正、删除请求，可到反馈区（github.com/lttxzmj/lawpulse-feedback）提出；涉及邮箱等敏感信息的，说明后我们会约替代方式。 删除授权记录会使对应激活码无法继续获得支持与续费。

九、未成年人

本软件面向执业律师与法律从业者，不面向未成年人，也不会有意收集未成年人的信息。

十、政策变更

本政策如有更新，将在本页面公布，并在软件内提示。与授权、退款相关的条款见 用户协议与免责声明。
