法脉隐私政策

最后更新：2026-08-06

法脉是一款单机桌面软件。我们没有账号系统，也没有一台可以接收你内容的服务器—— 这不是承诺，是架构决定的结果。本页把「有哪些数据、存在哪里、什么时候会联网」写清楚。

一、我们不收集什么

  • 不需要注册，没有账号体系，不需要手机号、身份信息或执业信息。
  • 不采集使用数据：产品内没有埋点、没有统计 SDK、没有崩溃上报、没有任何形式的遥测。
  • 我们不知道你安装了没有、打开过几次、查过哪些法条、审过什么合同。

二、唯一与你有关的个人信息：购买邮箱

  • 购买专业版时你提供的邮箱，用于签发激活码、标识授权归属，以及退款、续费、更换授权邮箱等必要联系。
  • 该邮箱与激活码记录保存在开发者本机的授权台账中，不进入任何第三方营销或分析平台。
  • 激活码采用 Ed25519 离线签名，验证全程在你的电脑本地完成，不联网、不回传，也不绑定机器指纹。

三、你的内容存在哪里

  • 法律库、笔记、高亮、法条关联、案件夹、导入的合同与文书、AI 生成的报告与问答记录， 全部存放在你自己设备的本地数据库：
    ~/Library/Application Support/法脉/。
  • 应用每天启动时在本机做一次数据库快照，滚动保留最近 7 份，同样只在本机。
  • 这些内容不会被上传。我们没有能接收它们的服务器，因此也无从备份、无从恢复、无从查看。 请自行做好本机备份。
  • 删除应用与数据目录后，这些内容即不复存在。

四、应用会发起的网络请求（穷举）

除下面三类之外，法脉不会主动联网：

  1. 检查软件更新：打开设置页时，向对象存储请求一个静态文件 release.json 比对版本号。请求不携带任何本机信息；对方（腾讯云 COS） 与所有 HTTP 服务一样能看到你的 IP 与访问时间。
  2. 更新法规数据（专业版）：由你在设置页手动触发，从同一对象存储下载法规 JSON 文件。 同上，只暴露 IP 与时间，不发送你的任何内容。
  3. AI 功能：请求从你的电脑直连你自己选定的模型厂商 （如 DeepSeek、阿里云百炼，或你填入的自定义端点）。我们没有中转服务器， 因此看不到请求内容。发送出去的是你提交的材料（合同条款、问题、附件与截图中的文本）与提示词， 该过程受该厂商的服务条款与隐私政策约束。

给执业律师的提醒：使用云端模型意味着材料会离开你的电脑，发往该模型厂商。 请自行评估是否符合你的保密义务与客户约定；对保密要求极高的材料，请勿使用云端 AI 功能。 不使用 AI 功能时，法脉的检索、笔记、案件夹与导出全程不联网。

五、模型密钥

  • AI 功能采用「自带密钥」（BYOK）：密钥由你在设置中填入，用于你的电脑直连模型厂商。
  • 密钥经操作系统级加密（macOS 钥匙串支撑的 Electron safeStorage）后仅存储于本机， 不会上传，也不会出现在导出文件中。
  • 模型费用由你直接支付给该厂商，我们不代收、不赚差价，也无从知晓你的用量。

六、本网站

  • 本站是托管在 GitHub Pages 上的纯静态页面：没有 Cookie， 没有统计脚本、没有广告脚本、没有第三方追踪像素。
  • 浏览器 localStorage 中只保存一项主题偏好（跟随系统 / 浅色 / 深色）， 仅供页面显示使用，不用于识别你。
  • 与任何网站一样，托管方 GitHub 可以看到访问者的 IP 与访问时间。

七、涉及的第三方

  • 腾讯云 COS：分发安装包与法规数据。可见 IP、时间与所请求的文件。
  • GitHub Pages：托管本网站。可见 IP、时间与所访问的页面。
  • 你选定的模型厂商：仅在你使用 AI 功能时，接收你提交的材料。

我们不向任何第三方出售、共享或交换用户信息——除购买邮箱外，我们手里也没有可共享的东西。

八、你的权利

  • 你的内容始终在你自己的设备上，增删改由你直接完成，不需要向我们申请。
  • 与购买邮箱有关的查询、更正、删除请求，可通过购买页面提供的联系方式提出。 删除授权记录会使对应激活码无法继续获得支持与续费。

九、未成年人

本软件面向执业律师与法律从业者，不面向未成年人，也不会有意收集未成年人的信息。

十、政策变更

本政策如有更新，将在本页面公布，并在软件内提示。与授权、退款相关的条款见 用户协议与免责声明。
