# 中华人民共和国特种设备安全法第二十八条

- 法规：中华人民共和国特种设备安全法（现行有效，施行日期 2014-01-01）
- 章节：第二章生产、经营、使用 · 第三节经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-1ccece62eb/28.html

特种设备出租单位不得出租未取得许可生产的特种设备或者国家明令淘汰和已经报废的特种设备，以及未按照安全技术规范的要求进行维护保养和未经检验或者检验不合格的特种设备。
