# 中华人民共和国技术进出口管理条例第十八条

- 法规：中华人民共和国技术进出口管理条例（现行有效，施行日期 2020-11-29）
- 章节：第二章技术进口管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-381315c19a/18.html

进口属于自由进口的技术，应当向国务院外经贸主管部门办理登记，并提交下列文件：
(一)技术进口合同登记申请书；
(二)技术进口合同副本；
(三)签约双方法律地位的证明文件。
