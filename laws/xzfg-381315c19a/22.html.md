# 中华人民共和国技术进出口管理条例第二十二条

- 法规：中华人民共和国技术进出口管理条例（现行有效，施行日期 2020-11-29）
- 章节：第二章技术进口管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-381315c19a/22.html

国务院外经贸主管部门和有关部门及其工作人员在履行技术进口管理职责中，对所知悉的商业秘密负有保密义务。
