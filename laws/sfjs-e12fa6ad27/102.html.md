# 人民检察院民事诉讼监督规则第一百零二条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第六章对审判程序中审判人员违法行为的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/102.html

人民检察院依照本章规定提出检察建议的，应当制作《检察建议书》，在决定提出检察建议之日起十五日内将《检察建议书》连同案件卷宗移送同级人民法院，并制作决定提出检察建议的《通知书》，发送申请人。
