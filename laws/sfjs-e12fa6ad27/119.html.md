# 人民检察院民事诉讼监督规则第一百一十九条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/119.html

人民检察院发现人民法院审查和处理当事人申请执行、撤销仲裁裁决或者申请执行公证债权文书存在违法、错误情形的，参照本规则第六章、第七章有关规定执行。
