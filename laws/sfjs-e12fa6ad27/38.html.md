# 人民检察院民事诉讼监督规则第三十八条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第三章受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/38.html

下级人民检察院提请抗诉、提请其他监督等案件，由上一级人民检察院负责案件管理的部门受理。
依职权启动监督程序的民事诉讼监督案件，负责民事检察的部门应当到负责案件管理的部门登记受理。
