# 人民检察院民事诉讼监督规则第一百二十五条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/125.html

地方各级人民检察院对适用法律确属疑难、复杂，本院难以决断的重大民事诉讼监督案件，可以向上一级人民检察院请示。
请示案件依照最高人民检察院关于办理下级人民检察院请示件、下级人民检察院向最高人民检察院报送公文的相关规定办理。
