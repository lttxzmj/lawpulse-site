# 人民检察院民事诉讼监督规则第八十八条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第五章对生效判决、裁定、调解书的监督 · 第二节再审检察建议和提请抗诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/88.html

人民检察院提请抗诉，应当制作《提请抗诉报告书》，在决定提请抗诉之日起十五日内将《提请抗诉报告书》连同案件卷宗报送上一级人民检察院，并制作决定提请抗诉的《通知书》，发送当事人。
