# 人民检察院民事诉讼监督规则第九十四条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第五章对生效判决、裁定、调解书的监督 · 第四节出庭
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/94.html

人民检察院提出抗诉的案件，人民法院再审时，人民检察院应当派员出席法庭。
必要时，人民检察院可以协调人民法院安排人民监督员旁听。
