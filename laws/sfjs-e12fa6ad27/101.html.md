# 人民检察院民事诉讼监督规则第一百零一条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第六章对审判程序中审判人员违法行为的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/101.html

人民检察院发现同级人民法院民事审判程序中审判人员有《中华人民共和国法官法》第四十六条等规定的违法行为且可能影响案件公正审判、执行的，应当向同级人民法院提出检察建议。
