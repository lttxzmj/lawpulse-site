# 人民检察院民事诉讼监督规则第三十三条

- 法规：人民检察院民事诉讼监督规则（现行有效，施行日期 2021-08-01）
- 章节：第三章受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12fa6ad27/33.html

负责控告申诉检察的部门应当在决定受理之日起三日内制作《受理通知书》，发送申请人，并告知其权利义务；同时将《受理通知书》和监督申请书副本发送其他当事人，并告知其权利义务。其他当事人可以在收到监督申请书副本之日起十五日内提出书面意见，不提出意见的不影响人民检察院对案件的审查。
