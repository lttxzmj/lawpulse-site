# 中华人民共和国资产评估法第二十八条

- 法规：中华人民共和国资产评估法（现行有效，施行日期 2016-12-01）
- 章节：第四章评估程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-19e7ce90b8/28.html

评估机构开展法定评估业务，应当指定至少两名相应专业类别的评估师承办，评估报告应当由至少两名承办该项业务的评估师签名并加盖评估机构印章。
