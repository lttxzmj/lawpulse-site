# 退役军人安置条例第九十二条

- 法规：退役军人安置条例（现行有效，施行日期 2024-09-01）
- 章节：第十一章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ced8a6365/92.html

军官离职休养和少将以上军官退休后，按照国务院和中央军事委员会的有关规定安置管理。
军队院校学员依法退出现役的，按照国家有关规定执行。
已经按照自主择业方式安置的退役军人的待遇保障，按照国务院和中央军事委员会的有关规定执行。
