# 退役军人安置条例第八十一条

- 法规：退役军人安置条例（现行有效，施行日期 2024-09-01）
- 章节：第九章社会保险
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ced8a6365/81.html

军人退出现役时，军队按照规定转移军人保险关系和相应资金，安置地社会保险经办机构应当及时办理相应的转移接续手续。
退役军人依法参加养老、医疗、工伤、失业、生育等社会保险，缴纳社会保险费，享受社会保险待遇。
退役军人服现役年限与入伍前、退役后参加社会保险的缴费年限依法合并计算。
