# 退役军人安置条例第八十二条

- 法规：退役军人安置条例（现行有效，施行日期 2024-09-01）
- 章节：第九章社会保险
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ced8a6365/82.html

安排工作的退役军士和义务兵在国家规定的待安排工作期间，按照规定参加安置地职工基本养老保险并享受相应待遇，所需费用由安置地人民政府同级财政资金安排。
