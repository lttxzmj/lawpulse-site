# 退役军人安置条例第三条

- 法规：退役军人安置条例（现行有效，施行日期 2024-09-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ced8a6365/3.html

退役军人为国防和军队建设做出了重要贡献，是社会主义现代化建设的重要力量。
国家关心、优待退役军人，保障退役军人依法享有相应的权益。
全社会应当尊重、优待退役军人，支持退役军人安置工作。
