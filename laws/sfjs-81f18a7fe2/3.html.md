# 最高人民法院关于审理危害军事通信刑事案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理危害军事通信刑事案件具体应用法律若干问题的解释（现行有效，施行日期 2007-06-29）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-81f18a7fe2/3.html

过失损坏军事通信，造成重要军事通信中断或者严重障碍的，属于刑法第三百六十九条第二款规定的“造成严重后果”，以过失损坏军事通信罪定罪，处三年以下有期徒刑或者拘役。
