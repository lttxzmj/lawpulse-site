# 最高人民法院关于审理旅游纠纷案件适用法律若干问题的规定第三条

- 法规：最高人民法院关于审理旅游纠纷案件适用法律若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d92526ec4f/3.html

因旅游经营者方面的同一原因造成旅游者人身损害、财产损失，旅游者选择请求旅游经营者承担违约责任或者侵权责任的，人民法院应当根据当事人选择的案由进行审理。
