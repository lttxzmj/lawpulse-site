# 中华人民共和国船舶登记条例第二十八条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第五章光船租赁登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/28.html

以光船条件从境外租进船舶，承租人应当比照本条例第九条规定确定船籍港，并在船舶起租前持下列文件，到船舶登记机关申请办理光船租赁登记：
(一)光船租赁合同正本、副本；
(二)法定的船舶检验机构签发的有效船舶技术证书；
(三)原船籍港船舶登记机关出具的中止或者注销船舶国籍证明书，或者将于重新登记时立即中止或者注销船舶国籍的证明书。
对经审查符合本条例规定的，船舶登记机关应当发给光船租赁登记证明书，并应当依照本条例第十七条的规定发给临时船舶国籍证书，在船舶登记簿上载明原登记国。
