# 中华人民共和国船舶登记条例第三十四条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第六章船舶标志和公司旗
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/34.html

船籍港船舶登记机关对经核准予以登记的船舶烟囱标志、公司旗应当予以公告。
业经登记的船舶烟囱标志、公司旗属登记申请人专用，其他船舶或者公司不得使用。
