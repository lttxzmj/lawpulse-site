# 中华人民共和国船舶登记条例第五十一条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/51.html

违反本条例规定，有下列情形之一的，船籍港船舶登记机关可以视情节给予警告、根据船舶吨位处以本条例第五十条规定的罚款数额的50%直至没收船舶登记证书：
(一)在办理登记手续时隐瞒真实情况、弄虚作假的；
(二)隐瞒登记事实，造成重复登记的；
(三)伪造、涂改船舶登记证书的。
