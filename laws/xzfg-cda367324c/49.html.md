# 中华人民共和国船舶登记条例第四十九条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/49.html

假冒中华人民共和国国籍，悬挂中华人民共和国国旗航行的，由船舶登记机关依法没收该船舶。
中国籍船舶假冒外国国籍，悬挂外国国旗航行的，适用前款规定。
