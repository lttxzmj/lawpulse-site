# 中华人民共和国船舶登记条例第三十三条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第六章船舶标志和公司旗
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/33.html

同一公司的船舶只准使用一个船舶烟囱标志、公司旗。
船舶烟囱标志、公司旗由船籍港船舶登记机关审核。
船舶烟囱标志、公司旗不得与登记在先的船舶烟囱标志、公司旗相同或者相似。
