# 中华人民共和国船舶登记条例第四十五条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第八章船舶所有权登记证书、船舶国籍证书的换发和补发
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/45.html

船舶国籍证书有效期届满前1年内，船舶所有人应当持船舶国籍证书和有效船舶技术证书，到船籍港船舶登记机关办理证书换发手续。
