# 中华人民共和国船舶登记条例第三十八条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第七章变更登记和注销登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/38.html

船舶抵押合同变更时，抵押权人和抵押人应当持船舶所有权登记证书、船舶抵押权登记证书和船舶抵押合同变更的证明文件，到船籍港船舶登记机关办理变更登记。
对经审查符合本条例规定的，船籍港船舶登记机关应当在船舶所有权登记证书和船舶抵押权登记证书以及船舶登记簿上注明船舶抵押合同的变更事项。
