# 中华人民共和国船舶登记条例第五十七条

- 法规：中华人民共和国船舶登记条例（现行有效）
- 章节：第十章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cda367324c/57.html

除公务船舶外，船舶登记机关按照规定收取船舶登记费。船舶登记费的收费标准和管理办法，由国务院财政部门、物价行政主管部门会同国务院交通行政主管部门制定。
