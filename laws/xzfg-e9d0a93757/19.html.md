# 博物馆条例第十九条

- 法规：博物馆条例（现行有效）
- 章节：第三章博物馆管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e9d0a93757/19.html

博物馆依法管理和使用的资产，任何组织或者个人不得侵占。
博物馆不得从事文物等藏品的商业经营活动。博物馆从事其他商业经营活动，不得违反办馆宗旨，不得损害观众利益。博物馆从事其他商业经营活动的具体办法由国家文物主管部门制定。
