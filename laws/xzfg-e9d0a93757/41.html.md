# 博物馆条例第四十一条

- 法规：博物馆条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e9d0a93757/41.html

博物馆自取得登记证书之日起6个月内未向公众开放，或者未依照本条例的规定实行免费或者其他优惠的，由省、自治区、直辖市人民政府文物主管部门责令改正；拒不改正的，由登记管理机关撤销登记。
