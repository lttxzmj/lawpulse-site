# 太湖流域管理条例第二十七条

- 法规：太湖流域管理条例（现行有效）
- 章节：第四章水污染防治
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-72fb420df1/27.html

国务院环境保护主管部门可以根据太湖流域水污染防治和优化产业结构、调整产业布局的需要，制定水污染物特别排放限值，并商两省一市人民政府确定和公布在太湖流域执行水污染物特别排放限值的具体地域范围和时限。
