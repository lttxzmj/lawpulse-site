# 住房公积金管理条例第二十八条

- 法规：住房公积金管理条例（现行有效，施行日期 2026-09-20）
- 章节：第四章提取和使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3e48f7006/28.html

住房公积金管理中心在保证住房公积金提取和贷款的前提下，经住房公积金管理委员会批准，可以将住房公积金用于购买国债和政策性金融债。
住房公积金管理中心不得向他人提供担保。
