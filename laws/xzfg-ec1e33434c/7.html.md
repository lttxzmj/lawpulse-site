# 国务院关于股份有限公司境内上市外资股的规定第七条

- 法规：国务院关于股份有限公司境内上市外资股的规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ec1e33434c/7.html

国务院证券委员会及其监督管理执行机构中国证券监督管理委员会(以下简称中国证监会)，依照法律、行政法规的规定，对境内上市外资股的发行、交易及相关活动实施管理和监督。
