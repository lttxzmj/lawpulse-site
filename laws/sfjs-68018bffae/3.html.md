# 最高人民法院关于人民法院委托评估、拍卖工作的若干规定第三条

- 法规：最高人民法院关于人民法院委托评估、拍卖工作的若干规定（现行有效，施行日期 2012-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-68018bffae/3.html

人民法院采用随机方式确定评估、拍卖机构。高级人民法院或者中级人民法院可以根据本地实际情况统一实施对外委托。
