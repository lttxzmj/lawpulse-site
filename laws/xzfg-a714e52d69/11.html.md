# 畜禽规模养殖污染防治条例第十一条

- 法规：畜禽规模养殖污染防治条例（现行有效）
- 章节：第二章预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a714e52d69/11.html

禁止在下列区域内建设畜禽养殖场、养殖小区：
(一)饮用水水源保护区，风景名胜区；
(二)自然保护区的核心区和缓冲区；
(三)城镇居民区、文化教育科学研究区等人口集中区域；
(四)法律、法规规定的其他禁止养殖区域。
