# 畜禽规模养殖污染防治条例第四十二条

- 法规：畜禽规模养殖污染防治条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a714e52d69/42.html

未按照规定对染疫畜禽和病害畜禽养殖废弃物进行无害化处理的，由动物卫生监督机构责令无害化处理，所需处理费用由违法行为人承担，可以处3000元以下的罚款。
