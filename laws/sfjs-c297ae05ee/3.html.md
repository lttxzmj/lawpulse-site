# 最高人民法院关于审理海上保险纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理海上保险纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c297ae05ee/3.html

审理保险人因发生船舶触碰港口设施或者码头等保险事故，行使代位请求赔偿权利向造成保险事故的第三人追偿的案件，适用海商法的规定。
