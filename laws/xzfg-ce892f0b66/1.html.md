# 国务院关于出境入境管理的规定第一条

- 法规：国务院关于出境入境管理的规定（现行有效，施行日期 2026-09-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ce892f0b66/1.html

为了规范出境入境管理，保障出境入境人员的合法权益，维护国家主权、安全、发展利益，根据《中华人民共和国出境入境管理法》等法律，制定本规定。
