# 中华人民共和国标准化法实施条例第二十一条

- 法规：中华人民共和国标准化法实施条例（现行有效，施行日期 2026-03-20）
- 章节：第三章标准的制定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c574600125/21.html

国家标准、行业标准和地方标准的代号、编号办法，由国务院标准化行政主管部门统一规定。
企业标准的代号、编号办法，由国务院标准化行政主管部门会同国务院有关行政主管部门规定。
