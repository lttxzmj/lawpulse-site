# 中华人民共和国标准化法实施条例第二十五条

- 法规：中华人民共和国标准化法实施条例（现行有效，施行日期 2026-03-20）
- 章节：第四章标准的实施与监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c574600125/25.html

出口产品的技术要求由合同双方约定。
出口产品在国内销售时，属于我国强制性标准管理范围的，必须符合强制性标准的要求。
