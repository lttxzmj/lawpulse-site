# 中华人民共和国标准化法实施条例第十七条

- 法规：中华人民共和国标准化法实施条例（现行有效，施行日期 2026-03-20）
- 章节：第三章标准的制定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c574600125/17.html

企业生产的产品没有国家标准、行业标准和地方标准的，应当制定相应的企业标准，作为组织生产的依据。企业标准由企业组织制定（农业企业标准制定办法另定），并按省、自治区、直辖市人民政府的规定备案。
对已有国家标准、行业标准或者地方标准的，鼓励企业制定严于国家标准、行业标准或者地方标准要求的企业标准，在企业内部适用。
