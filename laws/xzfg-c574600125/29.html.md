# 中华人民共和国标准化法实施条例第二十九条

- 法规：中华人民共和国标准化法实施条例（现行有效，施行日期 2026-03-20）
- 章节：第四章标准的实施与监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c574600125/29.html

国家检验机构由国务院标准化行政主管部门会同国务院有关行政主管部门规划、审查。地方检验机构由省、自治区、直辖市人民政府标准化行政主管部门会同省级有关行政主管部门规划、审查。
处理有关产品是否符合标准的争议，以本条规定的检验机构的检验数据为准。
