# 中华人民共和国标准化法实施条例第十四条

- 法规：中华人民共和国标准化法实施条例（现行有效，施行日期 2026-03-20）
- 章节：第三章标准的制定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c574600125/14.html

行业标准由国务院有关行政主管部门编制计划，组织草拟，统一审批、编号、发布，并报国务院标准化行政主管部门备案。
行业标准在相应的国家标准实施后，自行废止。
