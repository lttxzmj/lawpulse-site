# 中华人民共和国民法典第一百三十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第六章民事法律行为 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/136.html

民事法律行为自成立时生效，但是法律另有规定或者当事人另有约定的除外。
行为人非依法律规定或者未经对方同意，不得擅自变更或者解除民事法律行为。
