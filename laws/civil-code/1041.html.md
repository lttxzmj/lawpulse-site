# 中华人民共和国民法典第一千零四十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1041.html

婚姻家庭受国家保护。
实行婚姻自由、一夫一妻、男女平等的婚姻制度。
保护妇女、未成年人、老年人、残疾人的合法权益。
