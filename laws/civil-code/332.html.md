# 中华人民共和国民法典第三百三十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十一章土地承包经营权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/332.html

耕地的承包期为三十年。草地的承包期为三十年至五十年。林地的承包期为三十年至七十年。
前款规定的承包期限届满，由土地承包经营权人依照农村土地承包的法律规定继续承包。
