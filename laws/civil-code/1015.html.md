# 中华人民共和国民法典第一千零一十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第三章姓名权和名称权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1015.html

自然人应当随父姓或者母姓，但是有下列情形之一的，可以在父姓和母姓之外选取姓氏：
（一）选取其他直系长辈血亲的姓氏；
（二）因由法定扶养人以外的人扶养而选取扶养人姓氏；
（三）有不违背公序良俗的其他正当理由。
少数民族自然人的姓氏可以遵从本民族的文化传统和风俗习惯。
