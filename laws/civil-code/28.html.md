# 中华人民共和国民法典第二十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第二章自然人 · 第二节监护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/28.html

无民事行为能力或者限制民事行为能力的成年人，由下列有监护能力的人按顺序担任监护人：
（一）配偶；
（二）父母、子女；
（三）其他近亲属；
（四）其他愿意担任监护人的个人或者组织，但是须经被监护人住所地的居民委员会、村民委员会或者民政部门同意。
