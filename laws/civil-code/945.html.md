# 中华人民共和国民法典第九百四十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十四章物业服务合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/945.html

业主装饰装修房屋的，应当事先告知物业服务人，遵守物业服务人提示的合理注意事项，并配合其进行必要的现场检查。
业主转让、出租物业专有部分、设立居住权或者依法改变共有部分用途的，应当及时将相关情况告知物业服务人。
