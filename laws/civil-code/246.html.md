# 中华人民共和国民法典第二百四十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第五章国家所有权和集体所有权、私人所有权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/246.html

法律规定属于国家所有的财产，属于国家所有即全民所有。
国有财产由国务院代表国家行使所有权。法律另有规定的，依照其规定。
