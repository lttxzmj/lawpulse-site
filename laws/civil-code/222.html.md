# 中华人民共和国民法典第二百二十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第一分编通则 · 第二章物权的设立、变更、转让和消灭 · 第一节不动产登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/222.html

当事人提供虚假材料申请登记，造成他人损害的，应当承担赔偿责任。
因登记错误，造成他人损害的，登记机构应当承担赔偿责任。登记机构赔偿后，可以向造成登记错误的人追偿。
