# 中华人民共和国民法典第九十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第三节非营利法人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/93.html

设立捐助法人应当依法制定法人章程。
捐助法人应当设理事会、民主管理组织等决策机构，并设执行机构。理事长等负责人按照法人章程的规定担任法定代表人。
捐助法人应当设监事会等监督机构。
