# 中华人民共和国民法典第一千一百八十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第二章损害赔偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1183.html

侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。
因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的，被侵权人有权请求精神损害赔偿。
