# 中华人民共和国民法典第一千零六十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第一节夫妻关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1062.html

夫妻在婚姻关系存续期间所得的下列财产，为夫妻的共同财产，归夫妻共同所有：
（一）工资、奖金、劳务报酬；
（二）生产、经营、投资的收益；
（三）知识产权的收益；
（四）继承或者受赠的财产，但是本法第一千零六十三条第三项规定的除外；
（五）其他应当归共同所有的财产。
夫妻对共同财产，有平等的处理权。
