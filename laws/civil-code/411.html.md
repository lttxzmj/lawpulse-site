# 中华人民共和国民法典第四百一十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十七章抵押权 · 第一节一般抵押权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/411.html

依据本法第三百九十六条规定设定抵押的，抵押财产自下列情形之一发生时确定：
（一）债务履行期限届满，债权未实现；
（二）抵押人被宣告破产或者解散；
（三）当事人约定的实现抵押权的情形；
（四）严重影响债权实现的其他情形。
