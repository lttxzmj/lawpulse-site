# 中华人民共和国民法典第一百九十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第九章诉讼时效
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/196.html

下列请求权不适用诉讼时效的规定：
（一）请求停止侵害、排除妨碍、消除危险；
（二）不动产物权和登记的动产物权的权利人请求返还财产；
（三）请求支付抚养费、赡养费或者扶养费；
（四）依法不适用诉讼时效的其他请求权。
