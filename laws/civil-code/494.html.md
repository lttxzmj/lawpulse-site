# 中华人民共和国民法典第四百九十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/494.html

国家根据抢险救灾、疫情防控或者其他需要下达国家订货任务、指令性任务的，有关民事主体之间应当依照有关法律、行政法规规定的权利和义务订立合同。
依照法律、行政法规的规定负有发出要约义务的当事人，应当及时发出合理的要约。
依照法律、行政法规的规定负有作出承诺义务的当事人，不得拒绝对方合理的订立合同要求。
