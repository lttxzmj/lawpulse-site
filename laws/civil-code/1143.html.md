# 中华人民共和国民法典第一千一百四十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第三章遗嘱继承和遗赠
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1143.html

无民事行为能力人或者限制民事行为能力人所立的遗嘱无效。
遗嘱必须表示遗嘱人的真实意思，受欺诈、胁迫所立的遗嘱无效。
伪造的遗嘱无效。
遗嘱被篡改的，篡改的内容无效。
