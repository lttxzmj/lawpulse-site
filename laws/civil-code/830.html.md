# 中华人民共和国民法典第八百三十条

- 章节：第三编合同 · 第二分编典型合同 · 第十九章运输合同 · 第三节货运合同
- 数据核对至：2026-10-22

货物运输到达后，承运人知道收货人的，应当及时通知收货人，收货人应当及时提货。收货人逾期提货的，应当向承运人支付保管费等费用。
