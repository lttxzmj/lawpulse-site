# 中华人民共和国民法典第九百三十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十三章委托合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/936.html

因受托人死亡、丧失民事行为能力或者被宣告破产、解散，致使委托合同终止的，受托人的继承人、遗产管理人、法定代理人或者清算人应当及时通知委托人。因委托合同终止将损害委托人利益的，在委托人作出善后处理之前，受托人的继承人、遗产管理人、法定代理人或者清算人应当采取必要措施。
