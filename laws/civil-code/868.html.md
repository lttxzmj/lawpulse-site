# 中华人民共和国民法典第八百六十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十章技术合同 · 第三节技术转让合同和技术许可合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/868.html

技术秘密转让合同的让与人和技术秘密使用许可合同的许可人应当按照约定提供技术资料，进行技术指导，保证技术的实用性、可靠性，承担保密义务。
前款规定的保密义务，不限制许可人申请专利，但是当事人另有约定的除外。
