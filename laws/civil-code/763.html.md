# 中华人民共和国民法典第七百六十三条

- 章节：第三编合同 · 第二分编典型合同 · 第十六章保理合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/763.html

应收账款债权人与债务人虚构应收账款作为转让标的，与保理人订立保理合同的，应收账款债务人不得以应收账款不存在为由对抗保理人，但是保理人明知虚构的除外。
