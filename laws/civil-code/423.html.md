# 中华人民共和国民法典第四百二十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十七章抵押权 · 第二节最高额抵押权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/423.html

有下列情形之一的，抵押权人的债权确定：
（一）约定的债权确定期间届满；
（二）没有约定债权确定期间或者约定不明确，抵押权人或者抵押人自最高额抵押权设立之日起满二年后请求确定债权；
（三）新的债权不可能发生；
（四）抵押权人知道或者应当知道抵押财产被查封、扣押；
（五）债务人、抵押人被宣告破产或者解散；
（六）法律规定债权确定的其他情形。
