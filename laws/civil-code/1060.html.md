# 中华人民共和国民法典第一千零六十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第一节夫妻关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1060.html

夫妻一方因家庭日常生活需要而实施的民事法律行为，对夫妻双方发生效力，但是夫妻一方与相对人另有约定的除外。
夫妻之间对一方可以实施的民事法律行为范围的限制，不得对抗善意相对人。
