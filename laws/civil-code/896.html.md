# 中华人民共和国民法典第八百九十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十一章保管合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/896.html

第三人对保管物主张权利的，除依法对保管物采取保全或者执行措施外，保管人应当履行向寄存人返还保管物的义务。
第三人对保管人提起诉讼或者对保管物申请扣押的，保管人应当及时通知寄存人。
