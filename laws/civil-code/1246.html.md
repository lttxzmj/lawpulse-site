# 中华人民共和国民法典第一千二百四十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第九章饲养动物损害责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1246.html

违反管理规定，未对动物采取安全措施造成他人损害的，动物饲养人或者管理人应当承担侵权责任；但是，能够证明损害是因被侵权人故意造成的，可以减轻责任。
