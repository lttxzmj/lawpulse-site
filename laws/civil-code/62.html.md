# 中华人民共和国民法典第六十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/62.html

法定代表人因执行职务造成他人损害的，由法人承担民事责任。
法人承担民事责任后，依照法律或者法人章程的规定，可以向有过错的法定代表人追偿。
