# 中华人民共和国民法典第六百八十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十三章保证合同 · 第一节一般规定
- 数据核对至：2026-10-22

机关法人不得为保证人，但是经国务院批准为使用外国政府或者国际经济组织贷款进行转贷的除外。
以公益为目的的非营利法人、非法人组织不得为保证人。
