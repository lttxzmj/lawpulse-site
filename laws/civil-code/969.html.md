# 中华人民共和国民法典第九百六十九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十七章合伙合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/969.html

合伙人的出资、因合伙事务依法取得的收益和其他财产，属于合伙财产。
合伙合同终止前，合伙人不得请求分割合伙财产。
