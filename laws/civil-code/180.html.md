# 中华人民共和国民法典第一百八十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第八章民事责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/180.html

因不可抗力不能履行民事义务的，不承担民事责任。法律另有规定的，依照其规定。
不可抗力是不能预见、不能避免且不能克服的客观情况。
