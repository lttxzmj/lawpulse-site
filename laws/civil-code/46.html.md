# 中华人民共和国民法典第四十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第二章自然人 · 第三节宣告失踪和宣告死亡
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/46.html

自然人有下列情形之一的，利害关系人可以向人民法院申请宣告该自然人死亡：
（一）下落不明满四年；
（二）因意外事件，下落不明满二年。
因意外事件下落不明，经有关机关证明该自然人不可能生存的，申请宣告死亡不受二年时间的限制。
