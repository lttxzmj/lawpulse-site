# 中华人民共和国民法典第三百九十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十六章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/393.html

有下列情形之一的，担保物权消灭：
（一）主债权消灭；
（二）担保物权实现；
（三）债权人放弃担保物权；
（四）法律规定担保物权消灭的其他情形。
