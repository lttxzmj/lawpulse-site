# 中华人民共和国民法典第一千一百四十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1147.html

遗产管理人应当履行下列职责：
（一）清理遗产并制作遗产清单；
（二）向继承人报告遗产情况；
（三）采取必要措施防止遗产毁损、灭失；
（四）处理被继承人的债权债务；
（五）按照遗嘱或者依照法律规定分割遗产；
（六）实施与管理遗产有关的其他必要行为。
