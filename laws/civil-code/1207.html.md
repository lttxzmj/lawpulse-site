# 中华人民共和国民法典第一千二百零七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第四章产品责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1207.html

明知产品存在缺陷仍然生产、销售，或者没有依据前条规定采取有效补救措施，造成他人死亡或者健康严重损害的，被侵权人有权请求相应的惩罚性赔偿。
