# 中华人民共和国民法典第八百二十九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十九章运输合同 · 第三节货运合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/829.html

在承运人将货物交付收货人之前，托运人可以要求承运人中止运输、返还货物、变更到达地或者将货物交给其他收货人，但是应当赔偿承运人因此受到的损失。
