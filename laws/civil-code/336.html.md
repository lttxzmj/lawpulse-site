# 中华人民共和国民法典第三百三十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十一章土地承包经营权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/336.html

承包期内发包人不得调整承包地。
因自然灾害严重毁损承包地等特殊情形，需要适当调整承包的耕地和草地的，应当依照农村土地承包的法律规定办理。
