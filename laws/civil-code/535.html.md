# 中华人民共和国民法典第五百三十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第五章合同的保全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/535.html

因债务人怠于行使其债权或者与该债权有关的从权利，影响债权人的到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使债务人对相对人的权利，但是该权利专属于债务人自身的除外。
代位权的行使范围以债权人的到期债权为限。债权人行使代位权的必要费用，由债务人负担。
相对人对债务人的抗辩，可以向债权人主张。
