# 中华人民共和国民法典第四百九十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/495.html

当事人约定在将来一定期限内订立合同的认购书、订购书、预订书等，构成预约合同。
当事人一方不履行预约合同约定的订立合同义务的，对方可以请求其承担预约合同的违约责任。
