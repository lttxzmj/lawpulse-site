# 中华人民共和国民法典第一千零九十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第五章收养 · 第一节收养关系的成立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1098.html

收养人应当同时具备下列条件：
（一）无子女或者只有一名子女；
（二）有抚养、教育和保护被收养人的能力；
（三）未患有在医学上认为不应当收养子女的疾病；
（四）无不利于被收养人健康成长的违法犯罪记录；
（五）年满三十周岁。
