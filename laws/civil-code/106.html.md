# 中华人民共和国民法典第一百零六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第四章非法人组织
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/106.html

有下列情形之一的，非法人组织解散：
（一）章程规定的存续期间届满或者章程规定的其他解散事由出现；
（二）出资人或者设立人决定解散；
（三）法律规定的其他情形。
