# 中华人民共和国民法典第七百三十九条

- 数据核对至：2026-10-22

出租人根据承租人对出卖人、租赁物的选择订立的买卖合同，出卖人应当按照约定向承租人交付标的物，承租人享有与受领标的物有关的买受人的权利。
