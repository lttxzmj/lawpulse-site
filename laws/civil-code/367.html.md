# 中华人民共和国民法典第三百六十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十四章居住权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/367.html

设立居住权，当事人应当采用书面形式订立居住权合同。
居住权合同一般包括下列条款：
（一）当事人的姓名或者名称和住所；
（二）住宅的位置；
（三）居住的条件和要求；
（四）居住权期限；
（五）解决争议的方法。
