# 中华人民共和国民法典第八十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第二节营利法人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/80.html

营利法人应当设权力机构。
权力机构行使修改法人章程，选举或者更换执行机构、监督机构成员，以及法人章程规定的其他职权。
