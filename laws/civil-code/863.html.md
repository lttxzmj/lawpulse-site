# 中华人民共和国民法典第八百六十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十章技术合同 · 第三节技术转让合同和技术许可合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/863.html

技术转让合同包括专利权转让、专利申请权转让、技术秘密转让等合同。
技术许可合同包括专利实施许可、技术秘密使用许可等合同。
技术转让合同和技术许可合同应当采用书面形式。
