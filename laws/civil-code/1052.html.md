# 中华人民共和国民法典第一千零五十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第二章结婚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1052.html

因胁迫结婚的，受胁迫的一方可以向人民法院请求撤销婚姻。
请求撤销婚姻的，应当自胁迫行为终止之日起一年内提出。
被非法限制人身自由的当事人请求撤销婚姻的，应当自恢复人身自由之日起一年内提出。
