# 中华人民共和国民法典第一百七十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第七章代理 · 第三节代理终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/175.html

有下列情形之一的，法定代理终止：
（一）被代理人取得或者恢复完全民事行为能力；
（二）代理人丧失民事行为能力；
（三）代理人或者被代理人死亡；
（四）法律规定的其他情形。
