# 中华人民共和国民法典第九百零九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十二章仓储合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/909.html

保管人应当在仓单上签名或者盖章。仓单包括下列事项：
（一）存货人的姓名或者名称和住所；
（二）仓储物的品种、数量、质量、包装及其件数和标记；
（三）仓储物的损耗标准；
（四）储存场所；
（五）储存期限；
（六）仓储费；
（七）仓储物已经办理保险的，其保险金额、期间以及保险人的名称；
（八）填发人、填发地和填发日期。
