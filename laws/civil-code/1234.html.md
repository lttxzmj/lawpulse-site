# 中华人民共和国民法典第一千二百三十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第七章环境污染和生态破坏责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1234.html

违反国家规定造成生态环境损害，生态环境能够修复的，国家规定的机关或者法律规定的组织有权请求侵权人在合理期限内承担修复责任。侵权人在期限内未修复的，国家规定的机关或者法律规定的组织可以自行或者委托他人进行修复，所需费用由侵权人负担。
