# 中华人民共和国民法典第五百八十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第八章违约责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/588.html

当事人既约定违约金，又约定定金的，一方违约时，对方可以选择适用违约金或者定金条款。
定金不足以弥补一方违约造成的损失的，对方可以请求赔偿超过定金数额的损失。
