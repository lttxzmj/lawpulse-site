# 中华人民共和国民法典第二百七十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第六章业主的建筑物区分所有权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/277.html

业主可以设立业主大会，选举业主委员会。业主大会、业主委员会成立的具体条件和程序，依照法律、法规的规定。
地方人民政府有关部门、居民委员会应当对设立业主大会和选举业主委员会给予指导和协助。
