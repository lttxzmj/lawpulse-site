# 中华人民共和国民法典第七百五十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十五章融资租赁合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/757.html

出租人和承租人可以约定租赁期限届满租赁物的归属；对租赁物的归属没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，租赁物的所有权归出租人。
