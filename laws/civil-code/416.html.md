# 中华人民共和国民法典第四百一十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十七章抵押权 · 第一节一般抵押权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/416.html

动产抵押担保的主债权是抵押物的价款，标的物交付后十日内办理抵押登记的，该抵押权人优先于抵押物买受人的其他担保物权人受偿，但是留置权人除外。
