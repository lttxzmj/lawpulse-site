# 中华人民共和国民法典第一千一百三十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第三章遗嘱继承和遗赠
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1138.html

遗嘱人在危急情况下，可以立口头遗嘱。口头遗嘱应当有两个以上见证人在场见证。危急情况消除后，遗嘱人能够以书面或者录音录像形式立遗嘱的，所立的口头遗嘱无效。
