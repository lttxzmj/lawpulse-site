# 中华人民共和国民法典第四百一十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十七章抵押权 · 第一节一般抵押权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/414.html

同一财产向两个以上债权人抵押的，拍卖、变卖抵押财产所得的价款依照下列规定清偿：
（一）抵押权已经登记的，按照登记的时间先后确定清偿顺序；
（二）抵押权已经登记的先于未登记的受偿；
（三）抵押权未登记的，按照债权比例清偿。
其他可以登记的担保物权，清偿顺序参照适用前款规定。
