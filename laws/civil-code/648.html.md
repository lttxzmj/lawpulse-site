# 中华人民共和国民法典第六百四十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十章供用电、水、气、热力合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/648.html

供用电合同是供电人向用电人供电，用电人支付电费的合同。
向社会公众供电的供电人，不得拒绝用电人合理的订立合同要求。
