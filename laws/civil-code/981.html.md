# 中华人民共和国民法典第九百八十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第三分编准合同 · 第二十八章无因管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/981.html

管理人管理他人事务，应当采取有利于受益人的方法。中断管理对受益人不利的，无正当理由不得中断。
