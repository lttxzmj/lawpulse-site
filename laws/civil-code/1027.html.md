# 中华人民共和国民法典第一千零二十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第五章名誉权和荣誉权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1027.html

行为人发表的文学、艺术作品以真人真事或者特定人为描述对象，含有侮辱、诽谤内容，侵害他人名誉权的，受害人有权依法请求该行为人承担民事责任。
行为人发表的文学、艺术作品不以特定人为描述对象，仅其中的情节与该特定人的情况相似的，不承担民事责任。
