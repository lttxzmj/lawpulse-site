# 中华人民共和国民法典第七百五十三条

- 章节：第三编合同 · 第二分编典型合同 · 第十五章融资租赁合同
- 数据核对至：2026-10-22

承租人未经出租人同意，将租赁物转让、抵押、质押、投资入股或者以其他方式处分的，出租人可以解除融资租赁合同。
