# 中华人民共和国民法典第五百六十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第七章合同的权利义务终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/562.html

当事人协商一致，可以解除合同。
当事人可以约定一方解除合同的事由。解除合同的事由发生时，解除权人可以解除合同。
