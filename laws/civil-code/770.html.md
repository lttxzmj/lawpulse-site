# 中华人民共和国民法典第七百七十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十七章承揽合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/770.html

承揽合同是承揽人按照定作人的要求完成工作，交付工作成果，定作人支付报酬的合同。
承揽包括加工、定作、修理、复制、测试、检验等工作。
