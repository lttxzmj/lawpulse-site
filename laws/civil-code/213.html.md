# 中华人民共和国民法典第二百一十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第一分编通则 · 第二章物权的设立、变更、转让和消灭 · 第一节不动产登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/213.html

登记机构不得有下列行为：
（一）要求对不动产进行评估；
（二）以年检等名义进行重复登记；
（三）超出登记职责范围的其他行为。
