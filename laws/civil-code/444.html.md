# 中华人民共和国民法典第四百四十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十八章质权 · 第二节权利质权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/444.html

以注册商标专用权、专利权、著作权等知识产权中的财产权出质的，质权自办理出质登记时设立。
知识产权中的财产权出质后，出质人不得转让或者许可他人使用，但是出质人与质权人协商同意的除外。出质人转让或者许可他人使用出质的知识产权中的财产权所得的价款，应当向质权人提前清偿债务或者提存。
