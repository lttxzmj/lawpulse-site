# 中华人民共和国民法典第七百八十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十八章建设工程合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/788.html

建设工程合同是承包人进行工程建设，发包人支付价款的合同。
建设工程合同包括工程勘察、设计、施工合同。
