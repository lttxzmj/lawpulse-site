# 中华人民共和国民法典第五百五十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第七章合同的权利义务终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/557.html

有下列情形之一的，债权债务终止：
（一）债务已经履行；
（二）债务相互抵销；
（三）债务人依法将标的物提存；
（四）债权人免除债务；
（五）债权债务同归于一人；
（六）法律规定或者当事人约定终止的其他情形。
合同解除的，该合同的权利义务关系终止。
