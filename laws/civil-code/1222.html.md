# 中华人民共和国民法典第一千二百二十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第六章医疗损害责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1222.html

患者在诊疗活动中受到损害，有下列情形之一的，推定医疗机构有过错：
（一）违反法律、行政法规、规章以及其他有关诊疗规范的规定；
（二）隐匿或者拒绝提供与纠纷有关的病历资料；
（三）遗失、伪造、篡改或者违法销毁病历资料。
