# 中华人民共和国民法典第四百七十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/470.html

合同的内容由当事人约定，一般包括下列条款：
（一）当事人的姓名或者名称和住所；
（二）标的；
（三）数量；
（四）质量；
（五）价款或者报酬；
（六）履行期限、地点和方式；
（七）违约责任；
（八）解决争议的方法。
当事人可以参照各类合同的示范文本订立合同。
