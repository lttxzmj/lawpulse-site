# 中华人民共和国民法典第一千一百五十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1156.html

遗产分割应当有利于生产和生活需要，不损害遗产的效用。
不宜分割的遗产，可以采取折价、适当补偿或者共有等方法处理。
