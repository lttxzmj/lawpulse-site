# 中华人民共和国民法典第八百二十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十九章运输合同 · 第三节货运合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/827.html

托运人应当按照约定的方式包装货物。对包装方式没有约定或者约定不明确的，适用本法第六百一十九条的规定。
托运人违反前款规定的，承运人可以拒绝运输。
