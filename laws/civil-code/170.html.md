# 中华人民共和国民法典第一百七十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第七章代理 · 第二节委托代理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/170.html

执行法人或者非法人组织工作任务的人员，就其职权范围内的事项，以法人或者非法人组织的名义实施的民事法律行为，对法人或者非法人组织发生效力。
法人或者非法人组织对执行其工作任务的人员职权范围的限制，不得对抗善意相对人。
