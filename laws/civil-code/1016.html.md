# 中华人民共和国民法典第一千零一十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第三章姓名权和名称权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1016.html

自然人决定、变更姓名，或者法人、非法人组织决定、变更、转让名称的，应当依法向有关机关办理登记手续，但是法律另有规定的除外。
民事主体变更姓名、名称的，变更前实施的民事法律行为对其具有法律约束力。
