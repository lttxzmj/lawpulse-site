# 中华人民共和国民法典第七百二十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十四章租赁合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/724.html

有下列情形之一，非因承租人原因致使租赁物无法使用的，承租人可以解除合同：
（一）租赁物被司法机关或者行政机关依法查封、扣押；
（二）租赁物权属有争议；
（三）租赁物具有违反法律、行政法规关于使用条件的强制性规定情形。
