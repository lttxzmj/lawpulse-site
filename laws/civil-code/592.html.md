# 中华人民共和国民法典第五百九十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第八章违约责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/592.html

当事人都违反合同的，应当各自承担相应的责任。
当事人一方违约造成对方损失，对方对损失的发生有过错的，可以减少相应的损失赔偿额。
