# 中华人民共和国民法典第一千二百五十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第十章建筑物和物件损害责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1258.html

在公共场所或者道路上挖掘、修缮安装地下设施等造成他人损害，施工人不能证明已经设置明显标志和采取安全措施的，应当承担侵权责任。
窨井等地下设施造成他人损害，管理人不能证明尽到管理职责的，应当承担侵权责任。
