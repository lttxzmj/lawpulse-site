# 中华人民共和国民法典第一千零二十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第五章名誉权和荣誉权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1024.html

民事主体享有名誉权。任何组织或者个人不得以侮辱、诽谤等方式侵害他人的名誉权。
名誉是对民事主体的品德、声望、才能、信用等的社会评价。
