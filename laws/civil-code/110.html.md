# 中华人民共和国民法典第一百一十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第五章民事权利
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/110.html

自然人享有生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权、婚姻自主权等权利。
法人、非法人组织享有名称权、名誉权和荣誉权。
