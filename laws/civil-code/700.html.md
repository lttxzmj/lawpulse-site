# 中华人民共和国民法典第七百条

- 章节：第三编合同 · 第二分编典型合同 · 第十三章保证合同 · 第二节保证责任

- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/700.html

保证人承担保证责任后，除当事人另有约定外，有权在其承担保证责任的范围内向债务人追偿，享有债权人对债务人的权利，但是不得损害债权人的利益。
