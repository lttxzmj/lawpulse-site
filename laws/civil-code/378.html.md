# 中华人民共和国民法典第三百七十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十五章地役权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/378.html

土地所有权人享有地役权或者负担地役权的，设立土地承包经营权、宅基地使用权等用益物权时，该用益物权人继续享有或者负担已经设立的地役权。
