# 中华人民共和国民法典第一百八十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第八章民事责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/181.html

因正当防卫造成损害的，不承担民事责任。
正当防卫超过必要的限度，造成不应有的损害的，正当防卫人应当承担适当的民事责任。
