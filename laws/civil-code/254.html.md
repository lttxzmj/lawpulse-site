# 中华人民共和国民法典第二百五十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第五章国家所有权和集体所有权、私人所有权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/254.html

国防资产属于国家所有。
铁路、公路、电力设施、电信设施和油气管道等基础设施，依照法律规定为国家所有的，属于国家所有。
