# 中华人民共和国民法典第一千零四十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1044.html

收养应当遵循最有利于被收养人的原则，保障被收养人和收养人的合法权益。
禁止借收养名义买卖未成年人。
