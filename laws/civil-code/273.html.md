# 中华人民共和国民法典第二百七十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第六章业主的建筑物区分所有权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/273.html

业主对建筑物专有部分以外的共有部分，享有权利，承担义务；不得以放弃权利为由不履行义务。
业主转让建筑物内的住宅、经营性用房，其对共有部分享有的共有和共同管理的权利一并转让。
