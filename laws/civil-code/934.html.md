# 中华人民共和国民法典第九百三十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十三章委托合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/934.html

委托人死亡、终止或者受托人死亡、丧失民事行为能力、终止的，委托合同终止；但是，当事人另有约定或者根据委托事务的性质不宜终止的除外。
