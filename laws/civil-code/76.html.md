# 中华人民共和国民法典第七十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第二节营利法人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/76.html

以取得利润并分配给股东等出资人为目的成立的法人，为营利法人。
营利法人包括有限责任公司、股份有限公司和其他企业法人等。
