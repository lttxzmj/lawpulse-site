# 中华人民共和国民法典第一百七十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第七章代理 · 第三节代理终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/173.html

有下列情形之一的，委托代理终止：
（一）代理期限届满或者代理事务完成；
（二）被代理人取消委托或者代理人辞去委托；
（三）代理人丧失民事行为能力；
（四）代理人或者被代理人死亡；
（五）作为代理人或者被代理人的法人、非法人组织终止。
