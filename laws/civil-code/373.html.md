# 中华人民共和国民法典第三百七十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十五章地役权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/373.html

设立地役权，当事人应当采用书面形式订立地役权合同。
地役权合同一般包括下列条款：
（一）当事人的姓名或者名称和住所；
（二）供役地和需役地的位置；
（三）利用目的和方法；
（四）地役权期限；
（五）费用及其支付方式；
（六）解决争议的方法。
