# 中华人民共和国民法典第九百七十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十七章合伙合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/976.html

合伙人对合伙期限没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，视为不定期合伙。
合伙期限届满，合伙人继续执行合伙事务，其他合伙人没有提出异议的，原合伙合同继续有效，但是合伙期限为不定期。
合伙人可以随时解除不定期合伙合同，但是应当在合理期限之前通知其他合伙人。
