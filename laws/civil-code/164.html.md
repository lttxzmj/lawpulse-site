# 中华人民共和国民法典第一百六十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第七章代理 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/164.html

代理人不履行或者不完全履行职责，造成被代理人损害的，应当承担民事责任。
代理人和相对人恶意串通，损害被代理人合法权益的，代理人和相对人应当承担连带责任。
