# 中华人民共和国民法典第一千零二十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第五章名誉权和荣誉权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1025.html

行为人为公共利益实施新闻报道、舆论监督等行为，影响他人名誉的，不承担民事责任，但是有下列情形之一的除外：
（一）捏造、歪曲事实；
（二）对他人提供的严重失实内容未尽到合理核实义务；
（三）使用侮辱性言辞等贬损他人名誉。
