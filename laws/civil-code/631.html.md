# 中华人民共和国民法典第六百三十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第九章买卖合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/631.html

因标的物的主物不符合约定而解除合同的，解除合同的效力及于从物。因标的物的从物不符合约定被解除的，解除的效力不及于主物。
