# 中华人民共和国民法典第一千一百四十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第三章遗嘱继承和遗赠
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1142.html

遗嘱人可以撤回、变更自己所立的遗嘱。
立遗嘱后，遗嘱人实施与遗嘱内容相反的民事法律行为的，视为对遗嘱相关内容的撤回。
立有数份遗嘱，内容相抵触的，以最后的遗嘱为准。
