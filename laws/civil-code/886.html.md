# 中华人民共和国民法典第八百八十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十章技术合同 · 第四节技术咨询合同和技术服务合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/886.html

技术咨询合同和技术服务合同对受托人正常开展工作所需费用的负担没有约定或者约定不明确的，由受托人负担。
