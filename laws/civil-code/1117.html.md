# 中华人民共和国民法典第一千一百一十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第五章收养 · 第三节收养关系的解除
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1117.html

收养关系解除后，养子女与养父母以及其他近亲属间的权利义务关系即行消除，与生父母以及其他近亲属间的权利义务关系自行恢复。但是，成年养子女与生父母以及其他近亲属间的权利义务关系是否恢复，可以协商确定。
