# 中华人民共和国民法典第三百七十九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十五章地役权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/379.html

土地上已经设立土地承包经营权、建设用地使用权、宅基地使用权等用益物权的，未经用益物权人同意，土地所有权人不得设立地役权。
