# 中华人民共和国民法典第三十九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第二章自然人 · 第二节监护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/39.html

有下列情形之一的，监护关系终止：
（一）被监护人取得或者恢复完全民事行为能力；
（二）监护人丧失监护能力；
（三）被监护人或者监护人死亡；
（四）人民法院认定监护关系终止的其他情形。
监护关系终止后，被监护人仍然需要监护的，应当依法另行确定监护人。
