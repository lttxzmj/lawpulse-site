# 中华人民共和国民法典第九百八十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第三分编准合同 · 第二十八章无因管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/983.html

管理结束后，管理人应当向受益人报告管理事务的情况。管理人管理事务取得的财产，应当及时转交给受益人。
