# 中华人民共和国民法典第六百一十七条

- 章节：第三编合同 · 第二分编典型合同 · 第九章买卖合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/617.html
