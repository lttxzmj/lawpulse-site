# 中华人民共和国民法典第八十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第二节营利法人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/83.html

营利法人的出资人不得滥用出资人权利损害法人或者其他出资人的利益；滥用出资人权利造成法人或者其他出资人损失的，应当依法承担民事责任。
营利法人的出资人不得滥用法人独立地位和出资人有限责任损害法人债权人的利益；滥用法人独立地位和出资人有限责任，逃避债务，严重损害法人债权人的利益的，应当对法人债务承担连带责任。
