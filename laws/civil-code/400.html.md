# 中华人民共和国民法典第四百条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十七章抵押权 · 第一节一般抵押权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/400.html

设立抵押权，当事人应当采用书面形式订立抵押合同。
抵押合同一般包括下列条款：
（一）被担保债权的种类和数额；
（二）债务人履行债务的期限；
（三）抵押财产的名称、数量等情况；
（四）担保的范围。
