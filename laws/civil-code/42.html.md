# 中华人民共和国民法典第四十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第二章自然人 · 第三节宣告失踪和宣告死亡
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/42.html

失踪人的财产由其配偶、成年子女、父母或者其他愿意担任财产代管人的人代管。
代管有争议，没有前款规定的人，或者前款规定的人无代管能力的，由人民法院指定的人代管。
