# 中华人民共和国民法典第三百四十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第三分编用益物权 · 第十二章建设用地使用权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/344.html

建设用地使用权人依法对国家所有的土地享有占有、使用和收益的权利，有权利用该土地建造建筑物、构筑物及其附属设施。
