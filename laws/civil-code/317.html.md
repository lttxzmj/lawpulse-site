# 中华人民共和国民法典第三百一十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第九章所有权取得的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/317.html

权利人领取遗失物时，应当向拾得人或者有关部门支付保管遗失物等支出的必要费用。
权利人悬赏寻找遗失物的，领取遗失物时应当按照承诺履行义务。
拾得人侵占遗失物的，无权请求保管遗失物等支出的费用，也无权请求权利人按照承诺履行义务。
