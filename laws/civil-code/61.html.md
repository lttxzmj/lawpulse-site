# 中华人民共和国民法典第六十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/61.html

依照法律或者法人章程的规定，代表法人从事民事活动的负责人，为法人的法定代表人。
法定代表人以法人名义从事的民事活动，其法律后果由法人承受。
法人章程或者法人权力机构对法定代表人代表权的限制，不得对抗善意相对人。
