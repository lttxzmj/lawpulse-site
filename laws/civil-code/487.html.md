# 中华人民共和国民法典第四百八十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/487.html

受要约人在承诺期限内发出承诺，按照通常情形能够及时到达要约人，但是因其他原因致使承诺到达要约人时超过承诺期限的，除要约人及时通知受要约人因承诺超过期限不接受该承诺外，该承诺有效。
