# 中华人民共和国民法典第九百三十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十三章委托合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/935.html

因委托人死亡或者被宣告破产、解散，致使委托合同终止将损害委托人利益的，在委托人的继承人、遗产管理人或者清算人承受委托事务之前，受托人应当继续处理委托事务。
