# 中华人民共和国民法典第六百六十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十二章借款合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/668.html

借款合同应当采用书面形式，但是自然人之间借款另有约定的除外。
借款合同的内容一般包括借款种类、币种、用途、数额、利率、期限和还款方式等条款。
