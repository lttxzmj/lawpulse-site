# 中华人民共和国民法典第一千一百四十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1148.html

遗产管理人应当依法履行职责，因故意或者重大过失造成继承人、受遗赠人、债权人损害的，应当承担民事责任。
