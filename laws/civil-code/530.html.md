# 中华人民共和国民法典第五百三十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第四章合同的履行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/530.html

债权人可以拒绝债务人提前履行债务，但是提前履行不损害债权人利益的除外。
债务人提前履行债务给债权人增加的费用，由债务人负担。
