# 中华人民共和国民法典第一千一百一十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第五章收养 · 第三节收养关系的解除
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1118.html

收养关系解除后，经养父母抚养的成年养子女，对缺乏劳动能力又缺乏生活来源的养父母，应当给付生活费。因养子女成年后虐待、遗弃养父母而解除收养关系的，养父母可以要求养子女补偿收养期间支出的抚养费。
生父母要求解除收养关系的，养父母可以要求生父母适当补偿收养期间支出的抚养费；但是，因养父母虐待、遗弃养子女而解除收养关系的除外。
