# 中华人民共和国民法典第一千一百七十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1176.html

自愿参加具有一定风险的文体活动，因其他参加者的行为受到损害的，受害人不得请求其他参加者承担侵权责任；但是，其他参加者对损害的发生有故意或者重大过失的除外。
活动组织者的责任适用本法第一千一百九十八条至第一千二百零一条的规定。
