# 中华人民共和国民法典第一百七十九条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第八章民事责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/179.html

承担民事责任的方式主要有：
（一）停止侵害；
（二）排除妨碍；
（三）消除危险；
（四）返还财产；
（五）恢复原状；
（六）修理、重作、更换；
（七）继续履行；
（八）赔偿损失；
（九）支付违约金；
（十）消除影响、恢复名誉；
（十一）赔礼道歉。
法律规定惩罚性赔偿的，依照其规定。
本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。
