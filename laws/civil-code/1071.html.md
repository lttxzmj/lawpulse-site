# 中华人民共和国民法典第一千零七十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第二节父母子女关系和其他近亲属关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1071.html

非婚生子女享有与婚生子女同等的权利，任何组织或者个人不得加以危害和歧视。
不直接抚养非婚生子女的生父或者生母，应当负担未成年子女或者不能独立生活的成年子女的抚养费。
