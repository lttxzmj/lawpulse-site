# 中华人民共和国民法典第一百八十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第八章民事责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/182.html

因紧急避险造成损害的，由引起险情发生的人承担民事责任。
危险由自然原因引起的，紧急避险人不承担民事责任，可以给予适当补偿。
紧急避险采取措施不当或者超过必要的限度，造成不应有的损害的，紧急避险人应当承担适当的民事责任。
