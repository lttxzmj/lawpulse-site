# 中华人民共和国民法典第六百二十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第九章买卖合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/627.html

买受人应当按照约定的地点支付价款。对支付地点没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，买受人应当在出卖人的营业地支付；但是，约定支付价款以交付标的物或者交付提取标的物单证为条件的，在交付标的物或者交付提取标的物单证的所在地支付。
