# 中华人民共和国民法典第五百条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/500.html

当事人在订立合同过程中有下列情形之一，造成对方损失的，应当承担赔偿责任：
（一）假借订立合同，恶意进行磋商；
（二）故意隐瞒与订立合同有关的重要事实或者提供虚假情况；
（三）有其他违背诚信原则的行为。
