# 中华人民共和国民法典第九百九十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/990.html

人格权是民事主体享有的生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等权利。
除前款规定的人格权外，自然人享有基于人身自由、人格尊严产生的其他人格权益。
