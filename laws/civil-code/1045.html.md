# 中华人民共和国民法典第一千零四十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1045.html

亲属包括配偶、血亲和姻亲。
配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女为近亲属。
配偶、父母、子女和其他共同生活的近亲属为家庭成员。
