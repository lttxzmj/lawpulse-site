# 中华人民共和国民法典第三百二十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第九章所有权取得的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/321.html

天然孳息，由所有权人取得；既有所有权人又有用益物权人的，由用益物权人取得。当事人另有约定的，按照其约定。
法定孳息，当事人有约定的，按照约定取得；没有约定或者约定不明确的，按照交易习惯取得。
