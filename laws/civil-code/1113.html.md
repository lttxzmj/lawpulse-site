# 中华人民共和国民法典第一千一百一十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第五章收养 · 第二节收养的效力
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1113.html

有本法第一编关于民事法律行为无效规定情形或者违反本编规定的收养行为无效。
无效的收养行为自始没有法律约束力。
