# 中华人民共和国民法典第一千零七十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第二节父母子女关系和其他近亲属关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1075.html

有负担能力的兄、姐，对于父母已经死亡或者父母无力抚养的未成年弟、妹，有扶养的义务。
由兄、姐扶养长大的有负担能力的弟、妹，对于缺乏劳动能力又缺乏生活来源的兄、姐，有扶养的义务。
