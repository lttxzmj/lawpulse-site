# 中华人民共和国民法典第六十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/68.html

有下列原因之一并依法完成清算、注销登记的，法人终止：
（一）法人解散；
（二）法人被宣告破产；
（三）法律规定的其他原因。
法人终止，法律、行政法规规定须经有关机关批准的，依照其规定。
