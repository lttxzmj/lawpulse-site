# 中华人民共和国民法典第一千零九十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第五章收养 · 第一节收养关系的成立
- 数据核对至：2026-10-22

下列个人、组织可以作送养人：
（一）孤儿的监护人；
（二）儿童福利机构；
（三）有特殊困难无力抚养子女的生父母。
