# 中华人民共和国民法典第四百七十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/478.html

有下列情形之一的，要约失效：
（一）要约被拒绝；
（二）要约被依法撤销；
（三）承诺期限届满，受要约人未作出承诺；
（四）受要约人对要约的内容作出实质性变更。
