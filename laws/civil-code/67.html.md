# 中华人民共和国民法典第六十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第三章法人 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/67.html

法人合并的，其权利和义务由合并后的法人享有和承担。
法人分立的，其权利和义务由分立后的法人享有连带债权，承担连带债务，但是债权人和债务人另有约定的除外。
