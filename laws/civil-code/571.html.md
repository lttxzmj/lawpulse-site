# 中华人民共和国民法典第五百七十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第七章合同的权利义务终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/571.html

债务人将标的物或者将标的物依法拍卖、变卖所得价款交付提存部门时，提存成立。
提存成立的，视为债务人在其提存范围内已经交付标的物。
