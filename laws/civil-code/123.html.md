# 中华人民共和国民法典第一百二十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第五章民事权利
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/123.html

民事主体依法享有知识产权。
知识产权是权利人依法就下列客体享有的专有的权利：
（一）作品；
（二）发明、实用新型、外观设计；
（三）商标；
（四）地理标志；
（五）商业秘密；
（六）集成电路布图设计；
（七）植物新品种；
（八）法律规定的其他客体。
