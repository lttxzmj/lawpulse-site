# 中华人民共和国民法典第一百七十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第八章民事责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/178.html

二人以上依法承担连带责任的，权利人有权请求部分或者全部连带责任人承担责任。
连带责任人的责任份额根据各自责任大小确定；难以确定责任大小的，平均承担责任。实际承担责任超过自己责任份额的连带责任人，有权向其他连带责任人追偿。
连带责任，由法律规定或者当事人约定。
