# 中华人民共和国民法典第九百九十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第四编人格权 · 第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/996.html

因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。
