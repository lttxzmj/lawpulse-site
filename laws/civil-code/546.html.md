# 中华人民共和国民法典第五百四十六条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第六章合同的变更和转让
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/546.html

债权人转让债权，未通知债务人的，该转让对债务人不发生效力。
债权转让的通知不得撤销，但是经受让人同意的除外。
