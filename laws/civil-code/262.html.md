# 中华人民共和国民法典第二百六十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第二分编所有权 · 第五章国家所有权和集体所有权、私人所有权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/262.html

对于集体所有的土地和森林、山岭、草原、荒地、滩涂等，依照下列规定行使所有权：
（一）属于村农民集体所有的，由村集体经济组织或者村民委员会依法代表集体行使所有权；
（二）分别属于村内两个以上农民集体所有的，由村内各该集体经济组织或者村民小组依法代表集体行使所有权；
（三）属于乡镇农民集体所有的，由乡镇集体经济组织代表集体行使所有权。
