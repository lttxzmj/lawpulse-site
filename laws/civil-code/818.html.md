# 中华人民共和国民法典第八百一十八条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十九章运输合同 · 第二节客运合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/818.html

旅客不得随身携带或者在行李中夹带易燃、易爆、有毒、有腐蚀性、有放射性以及可能危及运输工具上人身和财产安全的危险物品或者违禁物品。
旅客违反前款规定的，承运人可以将危险物品或者违禁物品卸下、销毁或者送交有关部门。旅客坚持携带或者夹带危险物品或者违禁物品的，承运人应当拒绝运输。
