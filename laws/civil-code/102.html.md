# 中华人民共和国民法典第一百零二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第四章非法人组织
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/102.html

非法人组织是不具有法人资格，但是能够依法以自己的名义从事民事活动的组织。
非法人组织包括个人独资企业、合伙企业、不具有法人资格的专业服务机构等。
