# 中华人民共和国民法典第四百八十一条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/481.html

承诺应当在要约确定的期限内到达要约人。
要约没有确定承诺期限的，承诺应当依照下列规定到达：
（一）要约以对话方式作出的，应当即时作出承诺；
（二）要约以非对话方式作出的，承诺应当在合理期限内到达。
