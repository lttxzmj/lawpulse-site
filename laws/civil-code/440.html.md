# 中华人民共和国民法典第四百四十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第二编物权 · 第四分编担保物权 · 第十八章质权 · 第二节权利质权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/440.html

债务人或者第三人有权处分的下列权利可以出质：
（一）汇票、本票、支票；
（二）债券、存款单；
（三）仓单、提单；
（四）可以转让的基金份额、股权；
（五）可以转让的注册商标专用权、专利权、著作权等知识产权中的财产权；
（六）现有的以及将有的应收账款；
（七）法律、行政法规规定可以出质的其他财产权利。
