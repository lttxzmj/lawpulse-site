# 中华人民共和国民法典第六百八十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第十三章保证合同 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/682.html

保证合同是主债权债务合同的从合同。主债权债务合同无效的，保证合同无效，但是法律另有规定的除外。
保证合同被确认无效后，债务人、保证人、债权人有过错的，应当根据其过错各自承担相应的民事责任。
