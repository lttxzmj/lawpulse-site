# 中华人民共和国民法典第一百三十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第六章民事法律行为 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/134.html

民事法律行为可以基于双方或者多方的意思表示一致成立，也可以基于单方的意思表示成立。
法人、非法人组织依照法律或者章程规定的议事方式和表决程序作出决议的，该决议行为成立。
