# 中华人民共和国民法典第一百七十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第一编总则 · 第七章代理 · 第三节代理终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/174.html

被代理人死亡后，有下列情形之一的，委托代理人实施的代理行为有效：
（一）代理人不知道且不应当知道被代理人死亡；
（二）被代理人的继承人予以承认；
（三）授权中明确代理权在代理事务完成时终止；
（四）被代理人死亡前已经实施，为了被代理人的继承人的利益继续代理。
作为被代理人的法人、非法人组织终止的，参照适用前款规定。
