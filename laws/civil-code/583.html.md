# 中华人民共和国民法典第五百八十三条

- 章节：第三编合同 · 第一分编通则 · 第八章违约责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/583.html

当事人一方不履行合同义务或者履行合同义务不符合约定的，在履行义务或者采取补救措施后，对方还有其他损失的，应当赔偿损失。
