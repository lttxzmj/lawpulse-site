# 中华人民共和国民法典第九百八十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第三分编准合同 · 第二十八章无因管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/982.html

管理人管理他人事务，能够通知受益人的，应当及时通知受益人。管理的事务不需要紧急处理的，应当等待受益人的指示。
