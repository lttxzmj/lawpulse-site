# 中华人民共和国民法典第五百四十七条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第六章合同的变更和转让
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/547.html

债权人转让债权的，受让人取得与债权有关的从权利，但是该从权利专属于债权人自身的除外。
受让人取得从权利不因该从权利未办理转移登记手续或者未转移占有而受到影响。
