# 中华人民共和国民法典第一千一百五十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1153.html

夫妻共同所有的财产，除有约定的外，遗产分割时，应当先将共同所有的财产的一半分出为配偶所有，其余的为被继承人的遗产。
遗产在家庭共有财产之中的，遗产分割时，应当先分出他人的财产。
