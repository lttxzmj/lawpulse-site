# 中华人民共和国民法典第一千零六十三条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第一节夫妻关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1063.html

下列财产为夫妻一方的个人财产：
（一）一方的婚前财产；
（二）一方因受到人身损害获得的赔偿或者补偿；
（三）遗嘱或者赠与合同中确定只归一方的财产；
（四）一方专用的生活用品；
（五）其他应当归一方的财产。
