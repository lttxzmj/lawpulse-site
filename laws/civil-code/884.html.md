# 中华人民共和国民法典第八百八十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第二分编典型合同 · 第二十章技术合同 · 第四节技术咨询合同和技术服务合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/884.html

技术服务合同的委托人不履行合同义务或者履行合同义务不符合约定，影响工作进度和质量，不接受或者逾期接受工作成果的，支付的报酬不得追回，未支付的报酬应当支付。
技术服务合同的受托人未按照约定完成服务工作的，应当承担免收报酬等违约责任。
