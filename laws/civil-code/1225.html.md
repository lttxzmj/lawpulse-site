# 中华人民共和国民法典第一千二百二十五条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第七编侵权责任 · 第六章医疗损害责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1225.html

医疗机构及其医务人员应当按照规定填写并妥善保管住院志、医嘱单、检验报告、手术及麻醉记录、病理资料、护理记录等病历资料。
患者要求查阅、复制前款规定的病历资料的，医疗机构应当及时提供。
