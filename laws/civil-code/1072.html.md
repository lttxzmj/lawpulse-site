# 中华人民共和国民法典第一千零七十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第五编婚姻家庭 · 第三章家庭关系 · 第二节父母子女关系和其他近亲属关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1072.html

继父母与继子女间，不得虐待或者歧视。
继父或者继母和受其抚养教育的继子女间的权利义务关系，适用本法关于父母子女关系的规定。
