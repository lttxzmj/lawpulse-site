# 中华人民共和国民法典第四百七十二条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第三编合同 · 第一分编通则 · 第二章合同的订立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/472.html

要约是希望与他人订立合同的意思表示，该意思表示应当符合下列条件：
（一）内容具体确定；
（二）表明经受要约人承诺，要约人即受该意思表示约束。
