# 中华人民共和国民法典第一千一百五十条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1150.html

继承开始后，知道被继承人死亡的继承人应当及时通知其他继承人和遗嘱执行人。继承人中无人知道被继承人死亡或者知道被继承人死亡而不能通知的，由被继承人生前所在单位或者住所地的居民委员会、村民委员会负责通知。
