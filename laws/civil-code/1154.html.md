# 中华人民共和国民法典第一千一百五十四条

- 法规：中华人民共和国民法典（现行有效，施行日期 2021-01-01）
- 章节：第六编继承 · 第四章遗产的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/civil-code/1154.html

有下列情形之一的，遗产中的有关部分按照法定继承办理：
（一）遗嘱继承人放弃继承或者受遗赠人放弃受遗赠；
（二）遗嘱继承人丧失继承权或者受遗赠人丧失受遗赠权；
（三）遗嘱继承人、受遗赠人先于遗嘱人死亡或者终止；
（四）遗嘱无效部分所涉及的遗产；
（五）遗嘱未处分的遗产。
