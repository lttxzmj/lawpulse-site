# 保障农民工工资支付条例第二十三条

- 法规：保障农民工工资支付条例（现行有效，施行日期 2020-05-01）
- 章节：第四章工程建设领域特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f764e4b761/23.html

建设单位应当有满足施工所需要的资金安排。没有满足施工所需要的资金安排的，工程建设项目不得开工建设；依法需要办理施工许可证的，相关行业工程建设主管部门不予颁发施工许可证。
政府投资项目所需资金，应当按照国家有关规定落实到位，不得由施工单位垫资建设。
