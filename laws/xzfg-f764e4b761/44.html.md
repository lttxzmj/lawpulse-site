# 保障农民工工资支付条例第四十四条

- 法规：保障农民工工资支付条例（现行有效，施行日期 2020-05-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f764e4b761/44.html

财政部门、审计机关和相关行业工程建设主管部门按照职责，依法对政府投资项目建设单位按照工程施工合同约定向农民工工资专用账户拨付资金情况进行监督。
