# 军服管理条例第七条

- 法规：军服管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b712f1e701/7.html

承运军服、军服专用材料的企业，应当具备货物运输资质。军队军需主管部门或者其授权的机构应当与其签订运输合同。承运企业应当严格履行运输合同，承运企业工作人员不得泄露运输的军服、军服专用材料的数量、接收单位等涉及国家秘密的信息。
