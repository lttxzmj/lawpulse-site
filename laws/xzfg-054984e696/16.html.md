# 融资担保公司监督管理条例第十六条

- 法规：融资担保公司监督管理条例（现行有效）
- 章节：第三章经营规则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054984e696/16.html

融资担保公司对同一被担保人的担保责任余额与融资担保公司净资产的比例不得超过10%，对同一被担保人及其关联方的担保责任余额与融资担保公司净资产的比例不得超过15%。
