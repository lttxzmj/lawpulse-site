# 法律援助条例第三条

- 法规：法律援助条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-66284338a8/3.html

法律援助是政府的责任，县级以上人民政府应当采取积极措施推动法律援助工作，为法律援助提供财政支持，保障法律援助事业与经济、社会协调发展。
法律援助经费应当专款专用，接受财政、审计部门的监督。
