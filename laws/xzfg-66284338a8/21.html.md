# 法律援助条例第二十一条

- 法规：法律援助条例（现行有效）
- 章节：第四章法律援助实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-66284338a8/21.html

法律援助机构可以指派律师事务所安排律师或者安排本机构的工作人员办理法律援助案件；也可以根据其他社会组织的要求，安排其所属人员办理法律援助案件。对人民法院指定辩护的案件，法律援助机构应当在开庭3日前将确定的承办人员名单回复作出指定的人民法院。
