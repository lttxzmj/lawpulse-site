# 最高人民法院关于人民法院特邀调解的规定第五条

- 法规：最高人民法院关于人民法院特邀调解的规定（现行有效，施行日期 2016-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7a7d462340/5.html

人民法院开展特邀调解工作应当建立特邀调解组织和特邀调解员名册。建立名册的法院应当为入册的特邀调解组织或者特邀调解员颁发证书，并对名册进行管理。上级法院建立的名册，下级法院可以使用。
