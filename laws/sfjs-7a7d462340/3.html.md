# 最高人民法院关于人民法院特邀调解的规定第三条

- 法规：最高人民法院关于人民法院特邀调解的规定（现行有效，施行日期 2016-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7a7d462340/3.html

人民法院在特邀调解工作中，承担以下职责：
（一）对适宜调解的纠纷，指导当事人选择名册中的调解组织或者调解员先行调解；
（二）指导特邀调解组织和特邀调解员开展工作；
（三）管理特邀调解案件流程并统计相关数据；
（四）提供必要场所、办公设施等相关服务；
（五）组织特邀调解员进行业务培训；
（六）组织开展特邀调解业绩评估工作；
（七）承担其他与特邀调解有关的工作。
