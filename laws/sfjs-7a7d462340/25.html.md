# 最高人民法院关于人民法院特邀调解的规定第二十五条

- 法规：最高人民法院关于人民法院特邀调解的规定（现行有效，施行日期 2016-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7a7d462340/25.html

委派调解达成调解协议后，当事人就调解协议的履行或者调解协议的内容发生争议的，可以向人民法院提起诉讼，人民法院应当受理。一方当事人以原纠纷向人民法院起诉，对方当事人以调解协议提出抗辩的，应当提供调解协议书。
经司法确认的调解协议，一方当事人拒绝履行或者未全部履行的，对方当事人可以向人民法院申请执行。
