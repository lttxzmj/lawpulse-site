# 最高人民法院关于人民法院特邀调解的规定第二十八条

- 法规：最高人民法院关于人民法院特邀调解的规定（现行有效，施行日期 2016-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7a7d462340/28.html

特邀调解员不得有下列行为：
（一）强迫调解；
（二）违法调解；
（三）接受当事人请托或收受财物；
（四）泄露调解过程或调解协议内容；
（五）其他违反调解员职业道德的行为。
当事人发现存在上述情形的，可以向人民法院投诉。经审查属实的，人民法院应当予以纠正并作出警告、通报、除名等相应处理。
