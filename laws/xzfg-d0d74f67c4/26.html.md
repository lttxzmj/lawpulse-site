# 全民健身条例第二十六条

- 法规：全民健身条例（现行有效）
- 章节：第四章全民健身保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d0d74f67c4/26.html

县级以上人民政府应当将全民健身工作所需经费列入本级财政预算，并随着国民经济的发展逐步增加对全民健身的投入。
按照国家有关彩票公益金的分配政策由体育主管部门分配使用的彩票公益金，应当根据国家有关规定用于全民健身事业。
