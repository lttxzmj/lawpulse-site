# 中华人民共和国看守所条例第二十二条

- 法规：中华人民共和国看守所条例（现行有效）
- 章节：第五章生活、卫生
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7ed750009b/22.html

监室应当通风、采光，能够防潮、防暑、防寒。看守所对监房应当经常检查，及时维修，防止火灾和其他自然灾害。
被羁押人犯的居住面积，应当不影响其日常生活。
