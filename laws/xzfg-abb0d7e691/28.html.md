# 中华人民共和国外资保险公司管理条例第二十八条

- 法规：中华人民共和国外资保险公司管理条例（现行有效，施行日期 2019-09-30）
- 章节：第五章终止与清算
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-abb0d7e691/28.html

外资保险公司因解散、依法被撤销而清算的，应当自清算组成立之日起60日内在报纸上至少公告3次。公告内容应当经国务院保险监督管理机构核准。
