# 最高人民法院关于认可和执行台湾地区仲裁裁决的规定第十八条

- 法规：最高人民法院关于认可和执行台湾地区仲裁裁决的规定（现行有效，施行日期 2015-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c60b2e76da/18.html

对人民法院裁定不予认可的台湾地区仲裁裁决，申请人再次提出申请的，人民法院不予受理。但当事人可以根据双方重新达成的仲裁协议申请仲裁，也可以就同一争议向人民法院起诉。
