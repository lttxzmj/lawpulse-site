# 最高人民法院关于认可和执行台湾地区仲裁裁决的规定第三条

- 法规：最高人民法院关于认可和执行台湾地区仲裁裁决的规定（现行有效，施行日期 2015-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c60b2e76da/3.html

申请人同时提出认可和执行台湾地区仲裁裁决申请的，人民法院先按照认可程序进行审查，裁定认可后，由人民法院执行机构执行。
申请人直接申请执行的，人民法院应当告知其一并提交认可申请；坚持不申请认可的，裁定驳回其申请。
