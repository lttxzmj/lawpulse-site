# 最高人民法院关于认可和执行台湾地区仲裁裁决的规定第二条

- 法规：最高人民法院关于认可和执行台湾地区仲裁裁决的规定（现行有效，施行日期 2015-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c60b2e76da/2.html

本规定所称台湾地区仲裁裁决是指，有关常设仲裁机构及临时仲裁庭在台湾地区按照台湾地区仲裁规定就有关民商事争议作出的仲裁裁决，包括仲裁判断、仲裁和解和仲裁调解。
