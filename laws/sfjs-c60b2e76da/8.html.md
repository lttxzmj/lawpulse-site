# 最高人民法院关于认可和执行台湾地区仲裁裁决的规定第八条

- 法规：最高人民法院关于认可和执行台湾地区仲裁裁决的规定（现行有效，施行日期 2015-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c60b2e76da/8.html

对于符合本规定第四条和第七条规定条件的申请，人民法院应当在收到申请后七日内立案，并通知申请人和被申请人，同时将申请书送达被申请人；不符合本规定第四条和第七条规定条件的，应当在七日内裁定不予受理，同时说明不予受理的理由；申请人对裁定不服的，可以提起上诉。
