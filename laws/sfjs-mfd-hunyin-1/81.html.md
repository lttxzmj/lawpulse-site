# 最高人民法院关于适用《中华人民共和国民法典》婚姻家庭编的解释（一）第八十一条

- 法规：最高人民法院关于适用《中华人民共和国民法典》婚姻家庭编的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-hunyin-1/81.html

婚姻关系存续期间，夫妻一方作为继承人依法可以继承的遗产，在继承人之间尚未实际分割，起诉离婚时另一方请求分割的，人民法院应当告知当事人在继承人之间实际分割遗产后另行起诉。
