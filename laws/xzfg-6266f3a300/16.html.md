# 奥林匹克标志保护条例第十六条

- 法规：奥林匹克标志保护条例（现行有效，施行日期 2018-07-31）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6266f3a300/16.html

奥林匹克标志除依照本条例受到保护外，还可以依照《中华人民共和国著作权法》、《中华人民共和国商标法》、《中华人民共和国专利法》、《特殊标志管理条例》等法律、行政法规的规定获得保护。
