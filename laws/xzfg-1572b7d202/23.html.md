# 中华人民共和国海关对出口加工区监管的暂行办法第二十三条

- 法规：中华人民共和国海关对出口加工区监管的暂行办法（现行有效）
- 章节：第三章对加工区与区外之间进出货物的监管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1572b7d202/23.html

区内企业经主管海关批准，可在区外进行产品的测试、检验和展示活动。测试、检验和展示的产品，应比照海关对暂时进口货物的管理规定办理出区手续。
