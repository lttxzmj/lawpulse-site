# 中华人民共和国海关对出口加工区监管的暂行办法第十六条

- 法规：中华人民共和国海关对出口加工区监管的暂行办法（现行有效）
- 章节：第二章对加工区与境外之间进出货物的监管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1572b7d202/16.html

加工区与境外之间进、出的货物，除实行出口被动配额管理的外，不实行进出口配额、许可证件管理。
