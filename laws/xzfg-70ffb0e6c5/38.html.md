# 网络数据安全管理条例第三十八条

- 法规：网络数据安全管理条例（现行有效，施行日期 2025-01-01）
- 章节：第五章网络数据跨境安全管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70ffb0e6c5/38.html

通过数据出境安全评估后，网络数据处理者向境外提供个人信息和重要数据的，不得超出评估时明确的数据出境目的、方式、范围和种类、规模等。
