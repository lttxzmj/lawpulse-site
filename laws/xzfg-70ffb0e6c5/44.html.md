# 网络数据安全管理条例第四十四条

- 法规：网络数据安全管理条例（现行有效，施行日期 2025-01-01）
- 章节：第六章网络平台服务提供者义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70ffb0e6c5/44.html

大型网络平台服务提供者应当每年度发布个人信息保护社会责任报告，报告内容包括但不限于个人信息保护措施和成效、个人行使权利的申请受理情况、主要由外部成员组成的个人信息保护监督机构履行职责情况等。
