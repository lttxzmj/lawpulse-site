# 长江河道采砂管理条例第二十三条

- 法规：长江河道采砂管理条例（现行有效，施行日期 2023-07-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9bcba5eed2/23.html

在长江航道内非法采砂影响通航安全的，由长江航务管理局、长江海事机构依照《中华人民共和国内河交通安全管理条例》和《中华人民共和国航道管理条例》等规定给予处罚。
