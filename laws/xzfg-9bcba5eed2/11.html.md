# 长江河道采砂管理条例第十一条

- 法规：长江河道采砂管理条例（现行有效，施行日期 2023-07-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9bcba5eed2/11.html

河道采砂许可证应当载明船主姓名（名称）、船名、船号和开采的性质、种类、地点、时限以及作业方式、弃料处理方式、许可证的有效期限等有关事项和内容。
