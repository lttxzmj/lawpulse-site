# 长江河道采砂管理条例第十六条

- 法规：长江河道采砂管理条例（现行有效，施行日期 2023-07-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9bcba5eed2/16.html

除按照河道采砂许可证规定的期限在可采区作业外，采砂船舶应当集中停放在沿江县级人民政府指定的地点，并由采砂船舶所有者或者使用者负责管护。无正当理由，不得擅自离开指定的地点。
