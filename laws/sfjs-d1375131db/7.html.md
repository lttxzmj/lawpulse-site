# 最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释第七条

- 法规：最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释（已被修改，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d1375131db/7.html

经最高人民法院批准，高级人民法院可以根据本辖区环境和生态保护的实际情况，在辖区内确定部分中级人民法院受理第一审环境民事公益诉讼案件。
中级人民法院管辖环境民事公益诉讼案件的区域由高级人民法院确定。
