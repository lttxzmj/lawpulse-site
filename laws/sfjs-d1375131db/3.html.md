# 最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理环境民事公益诉讼案件适用法律若干问题的解释（已被修改，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d1375131db/3.html

设区的市，自治州、盟、地区，不设区的地级市，直辖市的区以上人民政府民政部门，可以认定为环境保护法第五十八条规定的“设区的市级以上人民政府民政部门”。
