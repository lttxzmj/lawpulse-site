# 重大动物疫情应急条例第二十三条

- 法规：重大动物疫情应急条例（现行有效，施行日期 2017-10-07）
- 章节：第三章监测、报告和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-304ba38ed9/23.html

发生重大动物疫情可能感染人群时，卫生主管部门应当对疫区内易受感染的人群进行监测，并采取相应的预防、控制措施。卫生主管部门和兽医主管部门应当及时相互通报情况。
