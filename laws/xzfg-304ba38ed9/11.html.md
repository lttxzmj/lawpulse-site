# 重大动物疫情应急条例第十一条

- 法规：重大动物疫情应急条例（现行有效，施行日期 2017-10-07）
- 章节：第二章应急准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-304ba38ed9/11.html

国务院有关部门和县级以上地方人民政府及其有关部门，应当根据重大动物疫情应急预案的要求，确保应急处理所需的疫苗、药品、设施设备和防护用品等物资的储备。
