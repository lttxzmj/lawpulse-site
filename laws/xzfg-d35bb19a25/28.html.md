# 防范和处置非法集资条例第二十八条

- 法规：防范和处置非法集资条例（现行有效，施行日期 2021-05-01）
- 章节：第三章处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d35bb19a25/28.html

国务院金融管理部门及其分支机构、派出机构，地方人民政府有关部门以及其他有关单位和个人，对处置非法集资工作应当给予支持、配合。
任何单位和个人不得阻挠、妨碍处置非法集资工作。
