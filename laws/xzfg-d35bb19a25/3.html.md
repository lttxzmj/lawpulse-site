# 防范和处置非法集资条例第三条

- 法规：防范和处置非法集资条例（现行有效，施行日期 2021-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d35bb19a25/3.html

本条例所称非法集资人，是指发起、主导或者组织实施非法集资的单位和个人；所称非法集资协助人，是指明知是非法集资而为其提供帮助并获取经济利益的单位和个人。
