# 农业保险条例第七条

- 法规：农业保险条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7d56ff3b5a/7.html

农民或者农业生产经营组织投保的农业保险标的属于财政给予保险费补贴范围的，由财政部门按照规定给予保险费补贴，具体办法由国务院财政部门商国务院农业、林业主管部门和保险监督管理机构制定。
国家鼓励地方人民政府采取由地方财政给予保险费补贴等措施，支持发展农业保险。
