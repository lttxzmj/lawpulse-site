# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百二十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十五章犯罪嫌疑人、被告人逃匿、死亡案件违法所得的没收程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/622.html

对没收违法所得或者驳回申请的裁定，犯罪嫌疑人、被告人的近亲属和其他利害关系人或者人民检察院可以在五日以内提出上诉、抗诉。
