# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百三十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十七章死刑复核程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/431.html

高级人民法院依照复核程序审理后报请最高人民法院核准死刑，最高人民法院裁定不予核准，发回高级人民法院重新审判的，高级人民法院可以依照第二审程序提审或者发回重新审判。
