# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百五十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十九章审判监督程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/455.html

对死刑案件的申诉，可以由原核准的人民法院直接审查处理，也可以交由原审人民法院审查。原审人民法院应当制作审查报告，提出处理意见，层报原核准的人民法院审查处理。
