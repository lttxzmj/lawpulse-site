# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百四十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十八章涉案财物处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/448.html

对冻结的存款、汇款、债券、股票、基金份额等财产判决没收的，第一审人民法院应当在判决生效后，将判决书、裁定书送达相关金融机构和财政部门，通知相关金融机构依法上缴国库并在接到执行通知书后十五日以内，将上缴国库的凭证、执行回单送回。
