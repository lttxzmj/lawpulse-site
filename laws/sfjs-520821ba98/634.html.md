# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百三十四条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十六章依法不负刑事责任的精神病人的强制医疗程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/634.html

审理强制医疗案件，应当通知被申请人或者被告人的法定代理人到场；被申请人或者被告人的法定代理人经通知未到场的，可以通知被申请人或者被告人的其他近亲属到场。
被申请人或者被告人没有委托诉讼代理人的，应当自受理强制医疗申请或者发现被告人符合强制医疗条件之日起三日以内，通知法律援助机构指派律师担任其诉讼代理人，为其提供法律帮助。
