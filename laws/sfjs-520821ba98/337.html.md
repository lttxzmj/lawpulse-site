# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百三十七条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十一章单位犯罪案件的审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/337.html

开庭审理单位犯罪案件，应当通知被告单位的诉讼代表人出庭；诉讼代表人不符合前条规定的，应当要求人民检察院另行确定。
被告单位的诉讼代表人不出庭的，应当按照下列情形分别处理：
（一）诉讼代表人系被告单位的法定代表人、实际控制人或者主要负责人，无正当理由拒不出庭的，可以拘传其到庭；因客观原因无法出庭，或者下落不明的，应当要求人民检察院另行确定诉讼代表人；
（二）诉讼代表人系其他人员的，应当要求人民检察院另行确定诉讼代表人。
