# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二百五十三条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第九章公诉案件第一审普通程序 · 第三节宣布开庭与法庭调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/253.html

证人具有下列情形之一，无法出庭作证的，人民法院可以准许其不出庭：
（一）庭审期间身患严重疾病或者行动极为不便的；
（二）居所远离开庭地点且交通极为不便的；
（三）身处国外短期无法回国的；
（四）有其他客观原因，确实无法出庭的。
具有前款规定情形的，可以通过视频等方式作证。
