# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百四十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十六章依法不负刑事责任的精神病人的强制医疗程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/641.html

人民法院决定强制医疗的，应当在作出决定后五日以内，向公安机关送达强制医疗决定书和强制医疗执行通知书，由公安机关将被决定强制医疗的人送交强制医疗。
