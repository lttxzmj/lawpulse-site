# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百一十六条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十五章犯罪嫌疑人、被告人逃匿、死亡案件违法所得的没收程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/616.html

刑事诉讼法第二百九十九条第二款、第三百条第二款规定的“其他利害关系人”，是指除犯罪嫌疑人、被告人的近亲属以外的，对申请没收的财产主张权利的自然人和单位。
