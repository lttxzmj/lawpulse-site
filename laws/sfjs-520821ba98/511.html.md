# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百一十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十一章执行程序 · 第二节死刑缓期执行、无期徒刑、有期徒刑、拘役的交付执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/511.html

被判处死刑缓期执行、无期徒刑、有期徒刑、拘役的罪犯，第一审人民法院应当在判决、裁定生效后十日以内，将判决书、裁定书、起诉书副本、自诉状复印件、执行通知书、结案登记表送达公安机关、监狱或者其他执行机关。
