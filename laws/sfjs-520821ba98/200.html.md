# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二百条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第六章附带民事诉讼
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/200.html

被害人或者其法定代理人、近亲属在刑事诉讼过程中未提起附带民事诉讼，另行提起民事诉讼的，人民法院可以进行调解，或者根据本解释第一百九十二条第二款、第三款的规定作出判决。
