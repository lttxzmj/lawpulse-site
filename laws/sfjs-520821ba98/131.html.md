# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百三十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第九节非法证据排除
- 数据核对至：2026-10-22

在庭前会议中，人民检察院可以撤回有关证据。撤回的证据，没有新的理由，不得在庭审中出示。
当事人及其辩护人、诉讼代理人可以撤回排除非法证据的申请。撤回申请后，没有新的线索或者材料，不得再次对有关证据提出排除申请。
