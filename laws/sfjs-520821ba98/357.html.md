# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百五十七条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十二章认罪认罚案件的审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/357.html

对被告人在第一审程序中未认罪认罚，在第二审程序中认罪认罚的案件，应当根据其认罪认罚的具体情况决定是否从宽，并依法作出裁判。确定从宽幅度时应当与第一审程序认罪认罚有所区别。
