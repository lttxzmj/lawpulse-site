# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第八十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第二节物证、书证的审查与认定
- 数据核对至：2026-10-22

对与案件事实可能有关联的血迹、体液、毛发、人体组织、指纹、足迹、字迹等生物样本、痕迹和物品，应当提取而没有提取，应当鉴定而没有鉴定，应当移送鉴定意见而没有移送，导致案件事实存疑的，人民法院应当通知人民检察院依法补充收集、调取、移送证据。
