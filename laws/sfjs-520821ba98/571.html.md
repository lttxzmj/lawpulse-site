# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百七十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第三节审判
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/571.html

人民法院应当在辩护台靠近旁听区一侧为未成年被告人的法定代理人或者合适成年人设置席位。
审理可能判处五年有期徒刑以下刑罚或者过失犯罪的未成年人刑事案件，可以采取适合未成年人特点的方式设置法庭席位。
