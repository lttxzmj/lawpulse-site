# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百七十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/172.html

被采取强制措施的被告人，被判处管制、缓刑的，在社区矫正开始后，强制措施自动解除；被单处附加刑的，在判决、裁定发生法律效力后，强制措施自动解除；被判处监禁刑的，在刑罚开始执行后，强制措施自动解除。
