# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百五十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/558.html

开庭审理涉及未成年人的刑事案件，未成年被害人、证人一般不出庭作证；必须出庭的，应当采取保护其隐私的技术手段和心理干预等保护措施。
