# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百八十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第四节执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/580.html

将未成年罪犯送监执行刑罚或者送交社区矫正时，人民法院应当将有关未成年罪犯的调查报告及其在案件审理中的表现材料，连同有关法律文书，一并送达执行机关。
