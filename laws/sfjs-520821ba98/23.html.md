# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二十三条

第二审人民法院发回重新审判的案件，人民检察院撤回起诉后，又向原第一审人民法院的下级人民法院重新提起公诉的，下级人民法院应当将有关情况层报原第二审人民法院。原第二审人民法院根据具体情况，可以决定将案件移送原第一审人民法院或者其他人民法院审判。
