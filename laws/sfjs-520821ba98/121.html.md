# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百二十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第八节技术调查、侦查证据的审查与认定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/121.html

采用技术调查、侦查证据作为定案根据的，人民法院在裁判文书中可以表述相关证据的名称、证据种类和证明对象，但不得表述有关人员身份和技术调查、侦查措施使用的技术设备、技术方法等。
