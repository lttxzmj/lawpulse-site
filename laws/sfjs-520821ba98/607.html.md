# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百零七条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十四章缺席审判程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/607.html

人民法院按照审判监督程序重新审判的案件，被告人死亡的，可以缺席审理。有证据证明被告人无罪，经缺席审理确认被告人无罪的，应当判决宣告被告人无罪；虽然构成犯罪，但原判量刑畸重的，应当依法作出判决。
