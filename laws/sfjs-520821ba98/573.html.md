# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百七十三条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第三节审判
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/573.html

法庭审理过程中，审判人员应当根据未成年被告人的智力发育程度和心理状态，使用适合未成年人的语言表达方式。
发现有对未成年被告人威胁、训斥、诱供或者讽刺等情形的，审判长应当制止。
