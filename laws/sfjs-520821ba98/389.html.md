# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百八十九条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十五章第二审程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/389.html

共同犯罪案件，只有部分被告人提出上诉，或者自诉人只对部分被告人的判决提出上诉，或者人民检察院只对部分被告人的判决提出抗诉的，第二审人民法院应当对全案进行审查，一并处理。
