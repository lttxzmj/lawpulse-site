# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百六十四条

- 章节：第二十二章未成年人刑事案件诉讼程序 · 第二节开庭准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/564.html

审判时不满十八周岁的未成年被告人没有委托辩护人的，人民法院应当通知法律援助机构指派熟悉未成年人身心特点的律师为其提供辩护。
