# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第九十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第三节证人证言、被害人陈述的审查与认定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/90.html

证人证言的收集程序、方式有下列瑕疵，经补正或者作出合理解释的，可以采用；不能补正或者作出合理解释的，不得作为定案的根据：
（一）询问笔录没有填写询问人、记录人、法定代理人姓名以及询问的起止时间、地点的；
（二）询问地点不符合规定的；
（三）询问笔录没有记录告知证人有关权利义务和法律责任的；
（四）询问笔录反映出在同一时段，同一询问人员询问不同证人的；
（五）询问未成年人，其法定代理人或者合适成年人不在场的。
