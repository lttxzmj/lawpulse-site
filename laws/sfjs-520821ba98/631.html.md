# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百三十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十六章依法不负刑事责任的精神病人的强制医疗程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/631.html

人民检察院申请对依法不负刑事责任的精神病人强制医疗的案件，由被申请人实施暴力行为所在地的基层人民法院管辖；由被申请人居住地的人民法院审判更为适宜的，可以由被申请人居住地的基层人民法院管辖。
