# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二百零八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第七章期间、送达、审理期限
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/208.html

诉讼文书的收件人是军人的，可以通过其所在部队团级以上单位的政治部门转交。
收件人正在服刑的，可以通过执行机关转交。
收件人正在接受专门矫治教育等的，可以通过相关机构转交。
由有关部门、单位代为转交诉讼文书的，应当请有关部门、单位收到后立即交收件人签收，并将送达回证及时寄送人民法院。
