# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百四十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第十节证据的综合审查与运用
- 数据核对至：2026-10-22

没有直接证据，但间接证据同时符合下列条件的，可以认定被告人有罪：
（一）证据已经查证属实；
（二）证据之间相互印证，不存在无法排除的矛盾和无法解释的疑问；
（三）全案证据形成完整的证据链；
（四）根据证据认定案件事实足以排除合理怀疑，结论具有唯一性；
（五）运用证据进行的推理符合逻辑和经验。
