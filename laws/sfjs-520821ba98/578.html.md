# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百七十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第三节审判
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/578.html

对未成年人刑事案件，宣告判决应当公开进行。
对依法应当封存犯罪记录的案件，宣判时，不得组织人员旁听；有旁听人员的，应当告知其不得传播案件信息。
