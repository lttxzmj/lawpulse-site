# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百六十七条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/167.html

人民法院作出逮捕决定后，应当将逮捕决定书等相关材料送交公安机关执行，并将逮捕决定书抄送人民检察院。逮捕被告人后，人民法院应当将逮捕的原因和羁押的处所，在二十四小时以内通知其家属；确实无法通知的，应当记录在案。
