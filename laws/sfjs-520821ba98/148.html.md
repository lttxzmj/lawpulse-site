# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百四十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/148.html

对经依法传唤拒不到庭的被告人，或者根据案件情况有必要拘传的被告人，可以拘传。
拘传被告人，应当由院长签发拘传票，由司法警察执行，执行人员不得少于二人。
拘传被告人，应当出示拘传票。对抗拒拘传的被告人，可以使用戒具。
