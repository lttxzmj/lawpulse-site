# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百三十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第九节非法证据排除
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/130.html

开庭审理前，人民法院可以召开庭前会议，就非法证据排除等问题了解情况，听取意见。
在庭前会议中，人民检察院可以通过出示有关证据材料等方式，对证据收集的合法性加以说明。必要时，可以通知调查人员、侦查人员或者其他人员参加庭前会议，说明情况。
