# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百四十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十六章依法不负刑事责任的精神病人的强制医疗程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/645.html

被强制医疗的人及其近亲属申请解除强制医疗的，应当向决定强制医疗的人民法院提出。
被强制医疗的人及其近亲属提出的解除强制医疗申请被人民法院驳回，六个月后再次提出申请的，人民法院应当受理。
