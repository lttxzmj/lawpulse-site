# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百四十四条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十一章执行程序 · 第六节缓刑、假释的撤销
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/544.html

被提请撤销缓刑、假释的罪犯可能逃跑或者可能发生社会危险，社区矫正机构在提出撤销缓刑、假释建议的同时，提请人民法院决定对其予以逮捕的，人民法院应当在四十八小时以内作出是否逮捕的决定。决定逮捕的，由公安机关执行。逮捕后的羁押期限不得超过三十日。
