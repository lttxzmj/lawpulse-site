# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百三十六条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第九节非法证据排除
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/136.html

控辩双方申请法庭通知调查人员、侦查人员或者其他人员出庭说明情况，法庭认为有必要的，应当通知有关人员出庭。
根据案件情况，法庭可以依职权通知调查人员、侦查人员或者其他人员出庭说明情况。
调查人员、侦查人员或者其他人员出庭的，应当向法庭说明证据收集过程，并就相关情况接受控辩双方和法庭的询问。
