# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百四十六条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十八章涉案财物处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/446.html

第二审期间，发现第一审判决未对随案移送的涉案财物及其孳息作出处理的，可以裁定撤销原判，发回原审人民法院重新审判，由原审人民法院依法对涉案财物及其孳息一并作出处理。
判决生效后，发现原判未对随案移送的涉案财物及其孳息作出处理的，由原审人民法院依法对涉案财物及其孳息另行作出处理。
