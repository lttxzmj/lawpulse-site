# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百二十九条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十章自诉案件第一审程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/329.html

判决宣告前，自诉案件的当事人可以自行和解，自诉人可以撤回自诉。
人民法院经审查，认为和解、撤回自诉确属自愿的，应当裁定准许；认为系被强迫、威吓等，并非自愿的，不予准许。
