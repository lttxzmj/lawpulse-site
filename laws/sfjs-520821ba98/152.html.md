# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百五十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/152.html

人民法院应当审查保证人是否符合法定条件。符合条件的，应当告知其必须履行的保证义务，以及不履行义务的法律后果，并由其出具保证书。
