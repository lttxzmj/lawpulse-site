# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二百八十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第九章公诉案件第一审普通程序 · 第四节法庭辩论与最后陈述
- 数据核对至：2026-10-22

法庭辩论应当在审判长的主持下，按照下列顺序进行：
（一）公诉人发言；
（二）被害人及其诉讼代理人发言；
（三）被告人自行辩护；
（四）辩护人辩护；
（五）控辩双方进行辩论。
