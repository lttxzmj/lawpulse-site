# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百三十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十七章死刑复核程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/432.html

最高人民法院裁定不予核准死刑，发回重新审判的案件，原审人民法院应当另行组成合议庭审理，但本解释第四百二十九条第四项、第五项规定的案件除外。
