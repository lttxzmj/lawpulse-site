# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百四十三条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第十节证据的综合审查与运用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/143.html

下列证据应当慎重使用，有其他证据印证的，可以采信：
（一）生理上、精神上有缺陷，对案件事实的认知和表达存在一定困难，但尚未丧失正确认知、表达能力的被害人、证人和被告人所作的陈述、证言和供述；
（二）与被告人有亲属关系或者其他密切关系的证人所作的有利于被告人的证言，或者与被告人有利害冲突的证人所作的不利于被告人的证言。
