# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百一十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第七节视听资料、电子数据的审查与认定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/110.html

对电子数据是否真实，应当着重审查以下内容：
（一）是否移送原始存储介质；在原始存储介质无法封存、不便移动时，有无说明原因，并注明收集、提取过程及原始存储介质的存放地点或者电子数据的来源等情况；
（二）是否具有数字签名、数字证书等特殊标识；
（三）收集、提取的过程是否可以重现；
（四）如有增加、删除、修改等情形的，是否附有说明；
（五）完整性是否可以保证。
