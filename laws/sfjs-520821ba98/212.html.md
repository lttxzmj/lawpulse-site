# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第二百一十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第八章审判组织
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/212.html

合议庭由审判员担任审判长。院长或者庭长参加审理案件时，由其本人担任审判长。
审判员依法独任审判时，行使与审判长相同的职权。
