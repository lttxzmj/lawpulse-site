# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百三十九条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十八章涉案财物处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/439.html

审判期间，对不宜长期保存、易贬值或者市场价格波动大的财产，或者有效期即将届满的票据等，经权利人申请或者同意，并经院长批准，可以依法先行处置，所得款项由人民法院保管。
涉案财物先行处置应当依法、公开、公平。
