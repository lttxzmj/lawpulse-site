# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百一十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十五章犯罪嫌疑人、被告人逃匿、死亡案件违法所得的没收程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/618.html

犯罪嫌疑人、被告人逃匿境外，委托诉讼代理人申请参加诉讼，且违法所得或者其他涉案财产所在国、地区主管机关明确提出意见予以支持的，人民法院可以准许。
人民法院准许参加诉讼的，犯罪嫌疑人、被告人的诉讼代理人依照本解释关于利害关系人的诉讼代理人的规定行使诉讼权利。
