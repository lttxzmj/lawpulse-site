# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百二十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十章自诉案件第一审程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/325.html

自诉案件当事人因客观原因不能取得的证据，申请人民法院调取的，应当说明理由，并提供相关线索或者材料。人民法院认为有必要的，应当及时调取。
对通过信息网络实施的侮辱、诽谤行为，被害人向人民法院告诉，但提供证据确有困难的，人民法院可以要求公安机关提供协助。
