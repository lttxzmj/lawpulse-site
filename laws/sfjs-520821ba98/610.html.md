# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第六百一十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十五章犯罪嫌疑人、被告人逃匿、死亡案件违法所得的没收程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/610.html

在省、自治区、直辖市或者全国范围内具有较大影响的犯罪案件，或者犯罪嫌疑人、被告人逃匿境外的犯罪案件，应当认定为刑事诉讼法第二百九十八条第一款规定的“重大犯罪案件”。
