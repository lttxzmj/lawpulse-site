# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百六十七条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十二章未成年人刑事案件诉讼程序 · 第二节开庭准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/567.html

被告人实施被指控的犯罪时不满十八周岁，开庭时已满十八周岁、不满二十周岁的，人民法院开庭时，一般应当通知其近亲属到庭。经法庭同意，近亲属可以发表意见。近亲属无法通知、不能到场或者是共犯的，应当记录在案。
