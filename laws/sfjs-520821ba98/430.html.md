# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第四百三十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十七章死刑复核程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/430.html

最高人民法院裁定不予核准死刑的，根据案件情况，可以发回第二审人民法院或者第一审人民法院重新审判。
对最高人民法院发回第二审人民法院重新审判的案件，第二审人民法院一般不得发回第一审人民法院重新审判。
第一审人民法院重新审判的，应当开庭审理。第二审人民法院重新审判的，可以直接改判；必须通过开庭查清事实、核实证据或者纠正原审程序违法的，应当开庭审理。
