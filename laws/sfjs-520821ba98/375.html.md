# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百七十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十四章速裁程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/375.html

适用速裁程序审理案件，在法庭审理过程中，具有下列情形之一的，应当转为普通程序或者简易程序审理：
（一）被告人的行为可能不构成犯罪或者不应当追究刑事责任的；
（二）被告人违背意愿认罪认罚的；
（三）被告人否认指控的犯罪事实的；
（四）案件疑难、复杂或者对适用法律有重大争议的；
（五）其他不宜适用速裁程序的情形。
