# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百五十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/151.html

对下列被告人决定取保候审的，可以责令其提出一至二名保证人：
（一）无力交纳保证金的；
（二）未成年或者已满七十五周岁的；
（三）不宜收取保证金的其他被告人。
