# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百八十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十三章当事人和解的公诉案件诉讼程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/588.html

符合刑事诉讼法第二百八十八条规定的公诉案件，被害人死亡的，其近亲属可以与被告人和解。近亲属有多人的，达成和解协议，应当经处于最先继承顺序的所有近亲属同意。
被害人系无行为能力或者限制行为能力人的，其法定代理人、近亲属可以代为和解。
