# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百二十四条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十一章执行程序 · 第四节刑事裁判涉财产部分和附带民事裁判的执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/524.html

因遭遇不能抗拒的灾祸等原因缴纳罚金确有困难，被执行人申请延期缴纳、酌情减少或者免除罚金的，应当提交相关证明材料。人民法院应当在收到申请后一个月以内作出裁定。符合法定条件的，应当准许；不符合条件的，驳回申请。
