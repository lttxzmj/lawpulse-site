# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百六十二条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第五章强制措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/162.html

人民检察院、公安机关已经对犯罪嫌疑人取保候审、监视居住，案件起诉至人民法院后，需要继续取保候审、监视居住或者变更强制措施的，人民法院应当在七日以内作出决定，并通知人民检察院、公安机关。
决定继续取保候审、监视居住的，应当重新办理手续，期限重新计算；继续使用保证金保证的，不再收取保证金。
