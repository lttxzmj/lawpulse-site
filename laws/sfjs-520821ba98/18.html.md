# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第十八条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）

- 数据核对至：2026-10-22

有管辖权的人民法院因案件涉及本院院长需要回避或者其他原因，不宜行使管辖权的，可以请求移送上一级人民法院管辖。上一级人民法院可以管辖，也可以指定与提出请求的人民法院同级的其他人民法院管辖。
