# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百三十三条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十一章执行程序 · 第五节减刑、假释案件的审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/533.html

被判处死刑缓期执行的罪犯，在死刑缓期执行期间，没有故意犯罪的，死刑缓期执行期满后，应当裁定减刑；死刑缓期执行期满后，尚未裁定减刑前又犯罪的，应当在依法减刑后，对其所犯新罪另行审判。
