# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百五十三条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十二章认罪认罚案件的审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/353.html

对认罪认罚案件，人民法院经审理认为量刑建议明显不当，或者被告人、辩护人对量刑建议提出异议的，人民检察院可以调整量刑建议。人民检察院不调整或者调整后仍然明显不当的，人民法院应当依法作出判决。
适用速裁程序审理认罪认罚案件，需要调整量刑建议的，应当在庭前或者当庭作出调整；调整量刑建议后，仍然符合速裁程序适用条件的，继续适用速裁程序审理。
