# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第一百四十六条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第四章证据 · 第十节证据的综合审查与运用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/146.html

审查被告人实施被指控的犯罪时或者审判时是否达到相应法定责任年龄，应当根据户籍证明、出生证明文件、学籍卡、人口普查登记、无利害关系人的证言等证据综合判断。
证明被告人已满十二周岁、十四周岁、十六周岁、十八周岁或者不满七十五周岁的证据不足的，应当作出有利于被告人的认定。
