# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第五百四十五条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第二十一章执行程序 · 第六节缓刑、假释的撤销
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/545.html

人民法院应当在收到社区矫正机构的撤销缓刑、假释建议书后三十日以内作出裁定。撤销缓刑、假释的裁定一经作出，立即生效。
人民法院应当将撤销缓刑、假释裁定书送达社区矫正机构和公安机关，并抄送人民检察院，由公安机关将罪犯送交执行。执行以前被逮捕的，羁押一日折抵刑期一日。
