# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百五十条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十二章认罪认罚案件的审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/350.html

人民法院应当将被告人认罪认罚作为其是否具有社会危险性的重要考虑因素。被告人罪行较轻，采用非羁押性强制措施足以防止发生社会危险性的，应当依法适用非羁押性强制措施。
