# 最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释第三百二十一条

- 法规：最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释（现行有效，施行日期 2021-03-01）
- 章节：第十章自诉案件第一审程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-520821ba98/321.html

对已经立案，经审查缺乏罪证的自诉案件，自诉人提不出补充证据的，人民法院应当说服其撤回起诉或者裁定驳回起诉；自诉人撤回起诉或者被驳回起诉后，又提出了新的足以证明被告人有罪的证据，再次提起自诉的，人民法院应当受理。
