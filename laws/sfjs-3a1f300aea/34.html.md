# 最高人民法院关于办理减刑、假释案件具体应用法律的规定第三十四条

- 法规：最高人民法院关于办理减刑、假释案件具体应用法律的规定（现行有效，施行日期 2017-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3a1f300aea/34.html

罪犯被裁定减刑后，刑罚执行期间因发现漏罪而数罪并罚的，原减刑裁定自动失效。如漏罪系罪犯主动交代的，对其原减去的刑期，由执行机关报请有管辖权的人民法院重新作出减刑裁定，予以确认；如漏罪系有关机关发现或者他人检举揭发的，由执行机关报请有管辖权的人民法院，在原减刑裁定减去的刑期总和之内，酌情重新裁定。
