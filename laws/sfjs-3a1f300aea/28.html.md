# 最高人民法院关于办理减刑、假释案件具体应用法律的规定第二十八条

- 法规：最高人民法院关于办理减刑、假释案件具体应用法律的规定（现行有效，施行日期 2017-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3a1f300aea/28.html

罪犯减刑后又假释的，间隔时间不得少于一年；对一次减去一年以上有期徒刑后，决定假释的，间隔时间不得少于一年六个月。
罪犯减刑后余刑不足二年，决定假释的，可以适当缩短间隔时间。
