# 最高人民法院关于办理减刑、假释案件具体应用法律的规定第三十三条

- 法规：最高人民法院关于办理减刑、假释案件具体应用法律的规定（现行有效，施行日期 2017-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3a1f300aea/33.html

罪犯被裁定减刑后，刑罚执行期间因故意犯罪而数罪并罚时，经减刑裁定减去的刑期不计入已经执行的刑期。原判死刑缓期执行减为无期徒刑、有期徒刑，或者无期徒刑减为有期徒刑的裁定继续有效。
