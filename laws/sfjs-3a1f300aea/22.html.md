# 最高人民法院关于办理减刑、假释案件具体应用法律的规定第二十二条

- 法规：最高人民法院关于办理减刑、假释案件具体应用法律的规定（现行有效，施行日期 2017-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3a1f300aea/22.html

办理假释案件，认定“没有再犯罪的危险”，除符合刑法第八十一条规定的情形外，还应当根据犯罪的具体情节、原判刑罚情况，在刑罚执行中的一贯表现，罪犯的年龄、身体状况、性格特征，假释后生活来源以及监管条件等因素综合考虑。
