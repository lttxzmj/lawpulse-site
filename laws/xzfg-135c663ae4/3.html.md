# 互联网平台企业涉税信息报送规定第三条

- 法规：互联网平台企业涉税信息报送规定（现行有效，施行日期 2025-06-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-135c663ae4/3.html

互联网平台企业应当自本规定施行之日起30日内或者自从事互联网经营业务之日起30日内向其主管税务机关报送平台域名、业务类型、相关运营主体的统一社会信用代码以及名称等信息。
