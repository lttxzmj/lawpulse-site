# 人工影响天气管理条例第三条

- 法规：人工影响天气管理条例（现行有效，施行日期 2020-03-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-63d4a171e6/3.html

本条例所称人工影响天气，是指为避免或者减轻气象灾害，合理利用气候资源，在适当条件下通过科技手段对局部大气的物理、化学过程进行人工影响，实现增雨雪、防雹、消雨、消雾、防霜等目的的活动。
