# 人工影响天气管理条例第八条

- 法规：人工影响天气管理条例（现行有效，施行日期 2020-03-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-63d4a171e6/8.html

人工影响天气的作业地点，由省、自治区、直辖市气象主管机构根据当地气候特点、地理条件，依照《中华人民共和国民用航空法》、《中华人民共和国飞行基本规则》的有关规定，会同有关飞行管制部门确定。
