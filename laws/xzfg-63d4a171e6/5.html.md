# 人工影响天气管理条例第五条

- 法规：人工影响天气管理条例（现行有效，施行日期 2020-03-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-63d4a171e6/5.html

开展人工影响天气工作，应当制定人工影响天气工作计划。人工影响天气工作计划由有关地方气象主管机构商同级有关部门编制，报本级人民政府批准后实施。
按照有关人民政府批准的人工影响天气工作计划开展的人工影响天气工作属于公益性事业，所需经费列入该级人民政府的财政预算。
