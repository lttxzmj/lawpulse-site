# 食盐加碘消除碘缺乏危害管理条例第二十三条

- 法规：食盐加碘消除碘缺乏危害管理条例（现行有效）
- 章节：第四章监督和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bb12247d8b/23.html

卫生监督人员在实施卫生监督、监测时，应当主动出示卫生行政部门制发的监督证件；盐政人员在执行职务时，应当主动出示盐业主管机构制发的证件。
