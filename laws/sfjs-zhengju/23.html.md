# 最高人民法院关于民事诉讼证据的若干规定第二十三条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/23.html

人民法院调查收集视听资料、电子数据，应当要求被调查人提供原始载体。
提供原始载体确有困难的，可以提供复制件。提供复制件的，人民法院应当在调查笔录中说明其来源和制作经过。
人民法院对视听资料、电子数据采取证据保全措施的，适用前款规定。
