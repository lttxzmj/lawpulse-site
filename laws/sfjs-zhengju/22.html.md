# 最高人民法院关于民事诉讼证据的若干规定第二十二条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/22.html

人民法院调查收集的物证应当是原物。被调查人提供原物确有困难的，可以提供复制品或者影像资料。提供复制品或者影像资料的，应当在调查笔录中说明取证情况。
