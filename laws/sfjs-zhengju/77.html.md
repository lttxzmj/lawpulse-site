# 最高人民法院关于民事诉讼证据的若干规定第七十七条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/77.html

证人经人民法院准许，以书面证言方式作证的，应当签署保证书；以视听传输技术或者视听资料方式作证的，应当签署保证书并宣读保证书的内容。
