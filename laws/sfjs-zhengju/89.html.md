# 最高人民法院关于民事诉讼证据的若干规定第八十九条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/89.html

当事人在诉讼过程中认可的证据，人民法院应当予以确认。但法律、司法解释另有规定的除外。
当事人对认可的证据反悔的，参照《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第二百二十九条的规定处理。
