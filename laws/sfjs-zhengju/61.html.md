# 最高人民法院关于民事诉讼证据的若干规定第六十一条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/61.html

对书证、物证、视听资料进行质证时，当事人应当出示证据的原件或者原物。但有下列情形之一的除外：
（一）出示原件或者原物确有困难并经人民法院准许出示复制件或者复制品的；
（二）原件或者原物已不存在，但有证据证明复制件、复制品与原件或者原物一致的。
