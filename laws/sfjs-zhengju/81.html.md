# 最高人民法院关于民事诉讼证据的若干规定第八十一条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/81.html

鉴定人拒不出庭作证的，鉴定意见不得作为认定案件事实的根据。人民法院应当建议有关主管部门或者组织对拒不出庭作证的鉴定人予以处罚。
当事人要求退还鉴定费用的，人民法院应当在三日内作出裁定，责令鉴定人退还；拒不退还的，由人民法院依法执行。
当事人因鉴定人拒不出庭作证申请重新鉴定的，人民法院应当准许。
