# 最高人民法院关于民事诉讼证据的若干规定第六十四条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/64.html

人民法院认为有必要的，可以要求当事人本人到场，就案件的有关事实接受询问。
人民法院要求当事人到场接受询问的，应当通知当事人询问的时间、地点、拒不到场的后果等内容。
