# 最高人民法院关于民事诉讼证据的若干规定第六十六条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/66.html

当事人无正当理由拒不到场、拒不签署或宣读保证书或者拒不接受询问的，人民法院应当综合案件情况，判断待证事实的真伪。待证事实无其他证据证明的，人民法院应当作出不利于该当事人的认定。
