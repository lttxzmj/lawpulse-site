# 最高人民法院关于民事诉讼证据的若干规定第七十五条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/75.html

证人出庭作证后，可以向人民法院申请支付证人出庭作证费用。证人有困难需要预先支取出庭作证费用的，人民法院可以根据证人的申请在出庭作证前支付。
