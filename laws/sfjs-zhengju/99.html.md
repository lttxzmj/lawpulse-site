# 最高人民法院关于民事诉讼证据的若干规定第九十九条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/99.html

本规定对证据保全没有规定的，参照适用法律、司法解释关于财产保全的规定。
除法律、司法解释另有规定外，对当事人、鉴定人、有专门知识的人的询问参照适用本规定中关于询问证人的规定；关于书证的规定适用于视听资料、电子数据；存储在电子计算机等电子介质中的视听资料，适用电子数据的规定。
