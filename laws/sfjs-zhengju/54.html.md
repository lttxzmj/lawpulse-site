# 最高人民法院关于民事诉讼证据的若干规定第五十四条

- 法规：最高人民法院关于民事诉讼证据的若干规定（现行有效，施行日期 2020-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-zhengju/54.html

当事人申请延长举证期限的，应当在举证期限届满前向人民法院提出书面申请。
申请理由成立的，人民法院应当准许，适当延长举证期限，并通知其他当事人。延长的举证期限适用于其他当事人。
申请理由不成立的，人民法院不予准许，并通知申请人。
