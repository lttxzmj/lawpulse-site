# 中华人民共和国环境保护税法实施条例第十九条

- 法规：中华人民共和国环境保护税法实施条例（现行有效）
- 章节：第四章征收管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f1f714a8c4/19.html

税务机关应当依据环境保护主管部门交送的排污单位信息进行纳税人识别。
在环境保护主管部门交送的排污单位信息中没有对应信息的纳税人，由税务机关在纳税人首次办理环境保护税纳税申报时进行纳税人识别，并将相关信息交送环境保护主管部门。
