# 中华人民共和国环境保护税法实施条例第八条

- 法规：中华人民共和国环境保护税法实施条例（现行有效）
- 章节：第二章计税依据
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f1f714a8c4/8.html

从两个以上排放口排放应税污染物的，对每一排放口排放的应税污染物分别计算征收环境保护税；纳税人持有排污许可证的，其污染物排放口按照排污许可证载明的污染物排放口确定。
