# 中华人民共和国环境保护税法实施条例第十八条

- 法规：中华人民共和国环境保护税法实施条例（现行有效）
- 章节：第四章征收管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f1f714a8c4/18.html

纳税人跨区域排放应税污染物，税务机关对税收征收管辖有争议的，由争议各方按照有利于征收管理的原则协商解决；不能协商一致的，报请共同的上级税务机关决定。
