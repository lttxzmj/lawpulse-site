# 征兵工作条例第三十三条

- 法规：征兵工作条例（现行有效，施行日期 2023-05-01）
- 章节：第五章审定新兵
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6cb6b55884/33.html

已被普通高等学校录取或者正在普通高等学校就学的学生，被批准服现役的，服现役期间保留入学资格或者学籍，退出现役后两年内允许入学或者复学。
