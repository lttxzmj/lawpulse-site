# 征兵工作条例第五十四条

- 法规：征兵工作条例（现行有效，施行日期 2023-05-01）
- 章节：第七章检疫、复查和退回
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6cb6b55884/54.html

对退回的人员，原征集地的县、自治县、不设区的市、市辖区人民政府征兵办公室应当注销其应征公民入伍批准书，通知其户籍所在地的户口登记机关。
