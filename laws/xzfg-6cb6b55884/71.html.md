# 征兵工作条例第七十一条

- 法规：征兵工作条例（现行有效，施行日期 2023-05-01）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6cb6b55884/71.html

本条例第六十七条、第六十八条规定的处罚，由县级以上地方人民政府兵役机关会同有关部门查明事实，经同级地方人民政府作出处罚决定后，由县级以上地方人民政府兵役机关、发展改革、公安、卫生健康、教育、人力资源社会保障等部门按照职责分工具体执行。
