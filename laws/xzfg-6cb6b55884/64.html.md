# 征兵工作条例第六十四条

- 法规：征兵工作条例（现行有效，施行日期 2023-05-01）
- 章节：第九章战时征集
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6cb6b55884/64.html

战时根据需要，国务院和中央军事委员会可以在法律规定的范围内调整征集公民服现役的条件和办法。
战时根据需要，可以重点征集退役军人，补充到原服现役单位或者同类型岗位。
