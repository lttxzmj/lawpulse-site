# 征兵工作条例第三十四条

- 法规：征兵工作条例（现行有效，施行日期 2023-05-01）
- 章节：第五章审定新兵
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6cb6b55884/34.html

在征集期间，应征公民被征集服现役，同时被机关、团体、企业事业组织招录或者聘用的，应当优先履行服兵役义务；有关机关、团体、企业事业组织应当支持其应征入伍，有条件的应当允许其延后入职。
被批准服现役的应征公民，是机关、团体、企业事业组织工作人员的，由原单位发给离职当月的全部工资、奖金及各种补贴。
