# 最高人民法院关于适用《中华人民共和国民法典》有关担保制度的解释第四十九条

- 法规：最高人民法院关于适用《中华人民共和国民法典》有关担保制度的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-danbao/49.html

以违法的建筑物抵押的，抵押合同无效，但是一审法庭辩论终结前已经办理合法手续的除外。抵押合同无效的法律后果，依照本解释第十七条的有关规定处理。
当事人以建设用地使用权依法设立抵押，抵押人以土地上存在违法的建筑物为由主张抵押合同无效的，人民法院不予支持。
