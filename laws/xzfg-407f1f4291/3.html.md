# 中华人民共和国境内外国人宗教活动管理规定第三条

- 法规：中华人民共和国境内外国人宗教活动管理规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-407f1f4291/3.html

外国人可以在中国境内的寺院、宫观、清真寺、教堂等宗教活动场所参加宗教活动。经省、自治区、直辖市以上宗教团体的邀请，外国人可以在中国宗教活动场所讲经、讲道。
