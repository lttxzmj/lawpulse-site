# 导游人员管理条例第三条

- 法规：导游人员管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-033789fdf7/3.html

国家实行全国统一的导游人员资格考试制度。
具有高级中学、中等专业学校或者以上学历，身体健康，具有适应导游需要的基本知识和语言表达能力的中华人民共和国公民，可以参加导游人员资格考试；经考试合格的，由国务院旅游行政部门或者国务院旅游行政部门委托省、自治区、直辖市人民政府旅游行政部门颁发导游人员资格证书。
