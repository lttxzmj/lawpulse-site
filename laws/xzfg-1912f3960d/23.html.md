# 中华人民共和国个人所得税法实施条例第二十三条

- 法规：中华人民共和国个人所得税法实施条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1912f3960d/23.html

个人所得税法第八条第二款规定的利息，应当按照税款所属纳税申报期最后一日中国人民银行公布的与补税期间同期的人民币贷款基准利率计算，自税款纳税申报期满次日起至补缴税款期限届满之日止按日加收。纳税人在补缴税款期限届满前补缴税款的，利息加收至补缴税款之日。
