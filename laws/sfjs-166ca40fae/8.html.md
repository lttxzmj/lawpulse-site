# 最高人民法院关于审理民事级别管辖异议案件若干问题的规定第八条

- 法规：最高人民法院关于审理民事级别管辖异议案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-166ca40fae/8.html

对于将案件移送上级人民法院管辖的裁定，当事人未提出上诉，但受移送的上级人民法院认为确有错误的，可以依职权裁定撤销。
