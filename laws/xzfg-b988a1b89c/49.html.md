# 中华人民共和国矿产资源法实施条例第四十九条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第四章矿区生态修复
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/49.html

国家完善政策措施，鼓励社会资本依法参与矿区生态修复，维护参与矿区生态修复的社会资本的合法权益。
国家充分发挥市场机制在矿区生态修复中的作用，推进矿区生态修复市场化发展。
