# 中华人民共和国矿产资源法实施条例第三十六条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第三章矿产资源勘查、开采
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/36.html

矿业权人可以依法通过划拨、出让、租赁、作价出资等方式使用国有土地，也可以依法通过出让、出租等方式取得集体经营性建设用地使用权。
开采矿产资源使用国有土地和集体经营性建设用地，可以通过协议方式出让。
