# 中华人民共和国矿产资源法实施条例第六十六条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/66.html

国家自然资源督察机构根据国务院的授权，对省、自治区、直辖市人民政府矿产资源开发利用和监督管理情况进行督察。
国家自然资源督察机构进行督察时，有权向与督察事项有关的单位和个人了解督察事项有关情况，有关单位和个人应当支持、协助督察机构工作。
