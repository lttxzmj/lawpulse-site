# 中华人民共和国矿产资源法实施条例第三十三条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第三章矿产资源勘查、开采
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/33.html

矿业权人进行矿产资源勘查、开采作业前，应当依法办理建设项目核准（备案）、用地用海、生态环境、安全生产等方面相关手续；涉及军用土地的，还应当经军队团级以上单位按照中央军事委员会的相关规定报经批准。
采矿权人编制矿山开发项目可行性研究报告、矿山初步设计（油气田开发方案）等，应当与开采方案相衔接。
