# 中华人民共和国矿产资源法实施条例第六十四条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/64.html

国务院自然资源主管部门根据从事矿产资源勘查单位的规模、技术能力、人才装备、信用状况等，对其实行备案和分级分类监管，引导矿产资源勘查市场规模化发展，提升专业化水平。
