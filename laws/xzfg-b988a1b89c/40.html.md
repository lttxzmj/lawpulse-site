# 中华人民共和国矿产资源法实施条例第四十条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第三章矿产资源勘查、开采
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/40.html

国务院自然资源主管部门会同国务院有关部门组织制定矿产资源开采回采率、选矿回收率、综合利用率有关国家标准。
采矿权人应当从技术、设备、管理等方面采取有效措施，确保矿产资源开采回采率、选矿回收率、综合利用率达到有关国家标准的要求。
国家制定和完善相关激励性政策措施，促进提高矿产资源开采回采率、选矿回收率、综合利用率。
