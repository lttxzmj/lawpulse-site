# 中华人民共和国矿产资源法实施条例第七十条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/70.html

矿业权人未按照规定缴纳矿业权占用费的，征收机关可以责令限期缴纳，逾期不缴纳的，可以处应缴矿业权占用费3倍以下的罚款。
