# 中华人民共和国矿产资源法实施条例第四十二条

- 法规：中华人民共和国矿产资源法实施条例（现行有效，施行日期 2026-06-15）
- 章节：第三章矿产资源勘查、开采
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b988a1b89c/42.html

国家建立矿产资源储量管理制度，加强对矿产资源储量及其变动情况的调查、核实、统计、评估等，为编制矿产资源相关规划、促进矿产资源合理开发利用、加强矿产资源保护等提供依据。
国家定期组织开展矿产资源潜力评价和开发利用现状调查，加强对矿产资源储量和矿业权价值及相关权益的评估管理。
