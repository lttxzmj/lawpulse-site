# 中华人民共和国外汇管理条例第二十八条

- 法规：中华人民共和国外汇管理条例（现行有效）
- 章节：第五章人民币汇率和外汇市场管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a6b2705ead/28.html

经营结汇、售汇业务的金融机构和符合国务院外汇管理部门规定条件的其他机构，可以按照国务院外汇管理部门的规定在银行间外汇市场进行外汇交易。
