# 中华人民共和国外汇管理条例第三十四条

- 法规：中华人民共和国外汇管理条例（现行有效）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a6b2705ead/34.html

外汇管理机关依法进行监督检查或者调查，监督检查或者调查的人员不得少于2人，并应当出示证件。监督检查、调查的人员少于2人或者未出示证件的，被监督检查、调查的单位和个人有权拒绝。
