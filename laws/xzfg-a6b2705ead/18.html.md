# 中华人民共和国外汇管理条例第十八条

- 法规：中华人民共和国外汇管理条例（现行有效）
- 章节：第三章资本项目外汇管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a6b2705ead/18.html

国家对外债实行规模管理。借用外债应当按照国家有关规定办理，并到外汇管理机关办理外债登记。
国务院外汇管理部门负责全国的外债统计与监测，并定期公布外债情况。
