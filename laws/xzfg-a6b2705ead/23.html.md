# 中华人民共和国外汇管理条例第二十三条

- 法规：中华人民共和国外汇管理条例（现行有效）
- 章节：第三章资本项目外汇管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a6b2705ead/23.html

资本项目外汇及结汇资金，应当按照有关主管部门及外汇管理机关批准的用途使用。外汇管理机关有权对资本项目外汇及结汇资金使用和账户变动情况进行监督检查。
