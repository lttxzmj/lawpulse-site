# 最高人民法院关于适用财产刑若干问题的规定第三条

- 法规：最高人民法院关于适用财产刑若干问题的规定（现行有效，施行日期 2000-12-19）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0afa4fd07c/3.html

依法对犯罪分子所犯数罪分别判处罚金的，应当实行并罚，将所判处的罚金数额相加，执行总和数额。
一人犯数罪依法同时并处罚金和没收财产的，应当合并执行；但并处没收全部财产的，只执行没收财产刑。
