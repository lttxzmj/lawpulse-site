# 最高人民法院关于适用财产刑若干问题的规定第二条

- 法规：最高人民法院关于适用财产刑若干问题的规定（现行有效，施行日期 2000-12-19）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0afa4fd07c/2.html

人民法院应当根据犯罪情节，如违法所得数额、造成损失的大小等，并综合考虑犯罪分子缴纳罚金的能力，依法判处罚金。刑法没有明确规定罚金数额标准的，罚金的最低数额不能少于一千元。
对未成年人犯罪应当从轻或者减轻判处罚金，但罚金的最低数额不能少于五百元。
