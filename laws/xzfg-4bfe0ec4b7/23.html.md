# 中华人民共和国陆生野生动物保护实施条例第二十三条

- 法规：中华人民共和国陆生野生动物保护实施条例（现行有效）
- 章节：第四章野生动物驯养繁殖管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4bfe0ec4b7/23.html

从国外引进的珍贵、濒危野生动物，经国务院林业行政主管部门核准，可以视为国家重点保护野生动物；从国外引进的其他野生动物，经省、自治区、直辖市人民政府林业行政主管部门核准，可以视为地方重点保护野生动物。
