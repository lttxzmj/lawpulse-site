# 中华人民共和国陆生野生动物保护实施条例第二十八条

- 法规：中华人民共和国陆生野生动物保护实施条例（现行有效）
- 章节：第五章野生动物经营利用管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4bfe0ec4b7/28.html

运输、携带国家重点保护野生动物或者其产品出县境的，应当凭特许猎捕证、驯养繁殖许可证，向县级人民政府野生动物行政主管部门提出申请，报省、自治区、直辖市人民政府林业行政主管部门或者其授权的单位批准。动物园之间因繁殖动物，需要运输国家重点保护野生动物的，可以由省、自治区、直辖市人民政府林业行政主管部门授权同级建设行政主管部门审批。
