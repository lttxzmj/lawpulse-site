# 中华人民共和国陆生野生动物保护实施条例第三条

- 法规：中华人民共和国陆生野生动物保护实施条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4bfe0ec4b7/3.html

国务院林业行政主管部门主管全国陆生野生动物管理工作。
省、自治区、直辖市人民政府林业行政主管部门主管本行政区域内陆生野生动物管理工作。自治州、县和市人民政府陆生野生动物管理工作的行政主管部门，由省、自治区、直辖市人民政府确定。
