# 生态保护补偿条例第三条

- 法规：生态保护补偿条例（现行有效，施行日期 2024-06-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-08789e6993/3.html

生态保护补偿工作坚持中国共产党的领导，坚持政府主导、社会参与、市场调节相结合，坚持激励与约束并重，坚持统筹协同推进，坚持生态效益与经济效益、社会效益相统一。
