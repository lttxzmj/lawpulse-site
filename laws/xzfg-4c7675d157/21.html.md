# 互联网上网服务营业场所管理条例第二十一条

- 法规：互联网上网服务营业场所管理条例（现行有效，施行日期 2025-01-20）
- 章节：第三章经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c7675d157/21.html

互联网上网服务营业场所经营单位不得接纳未成年人进入营业场所。
互联网上网服务营业场所经营单位应当在营业场所入口处的显著位置悬挂未成年人禁入标志。
