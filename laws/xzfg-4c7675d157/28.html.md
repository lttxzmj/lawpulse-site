# 互联网上网服务营业场所管理条例第二十八条

- 法规：互联网上网服务营业场所管理条例（现行有效，施行日期 2025-01-20）
- 章节：第四章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c7675d157/28.html

文化行政部门应当建立互联网上网服务营业场所经营单位的经营活动信用监管制度，建立健全信用约束机制，并及时公布行政处罚信息。
