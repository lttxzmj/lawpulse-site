# 最高人民法院关于审理专利纠纷案件适用法律问题的若干规定第十八条

- 法规：最高人民法院关于审理专利纠纷案件适用法律问题的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c7902e049e/18.html

专利法第十一条、第六十九条所称的许诺销售，是指以做广告、在商店橱窗中陈列或者在展销会上展出等方式作出销售商品的意思表示。
