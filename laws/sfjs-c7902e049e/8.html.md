# 最高人民法院关于审理专利纠纷案件适用法律问题的若干规定第八条

- 法规：最高人民法院关于审理专利纠纷案件适用法律问题的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c7902e049e/8.html

人民法院决定中止诉讼，专利权人或者利害关系人请求责令被告停止有关行为或者采取其他制止侵权损害继续扩大的措施，并提供了担保，人民法院经审查符合有关法律规定的，可以在裁定中止诉讼的同时一并作出有关裁定。
