# 最高人民法院关于审理民事、行政诉讼中司法赔偿案件适用法律若干问题的解释第八条

- 法规：最高人民法院关于审理民事、行政诉讼中司法赔偿案件适用法律若干问题的解释（现行有效，施行日期 2016-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3429d85ae6/8.html

因多种原因造成公民、法人和其他组织合法权益损害的，应当根据人民法院及其工作人员行使职权的行为对损害结果的发生或者扩大所起的作用等因素，合理确定赔偿金额。
