# 志愿服务条例第二十三条

- 法规：志愿服务条例（现行有效）
- 章节：第三章志愿服务活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f408efe3cc/23.html

国家鼓励和支持国家机关、企业事业单位、人民团体、社会组织等成立志愿服务队伍开展专业志愿服务活动，鼓励和支持具备专业知识、技能的志愿者提供专业志愿服务。
国家鼓励和支持公共服务机构招募志愿者提供志愿服务。
