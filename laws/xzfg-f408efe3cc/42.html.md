# 志愿服务条例第四十二条

- 法规：志愿服务条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f408efe3cc/42.html

志愿服务组织以外的其他组织可以开展力所能及的志愿服务活动。
城乡社区、单位内部经基层群众性自治组织或者本单位同意成立的团体，可以在本社区、本单位内部开展志愿服务活动。
