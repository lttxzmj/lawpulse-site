# 农业化学物质产品行政保护条例第三条

- 法规：农业化学物质产品行政保护条例（现行有效，施行日期 2020-11-29）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3ff19f017a/3.html

凡与中华人民共和国缔结有关农业化学物质产品行政保护双边条约或者协定的国家、地区的企业和其他组织以及个人，都可以依照本条例申请农业化学物质产品行政保护。
