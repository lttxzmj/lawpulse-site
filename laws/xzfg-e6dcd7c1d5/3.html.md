# 中华人民共和国计量法实施细则第三条

- 法规：中华人民共和国计量法实施细则（现行有效，施行日期 2022-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6dcd7c1d5/3.html

国家有计划地发展计量事业，用现代计量技术装备各级计量检定机构，为社会主义现代化建设服务，为工农业生产、国防建设、科学实验、国内外贸易以及人民的健康、安全提供计量保证，维护国家和人民的利益。
