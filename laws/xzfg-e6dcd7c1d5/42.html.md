# 中华人民共和国计量法实施细则第四十二条

- 法规：中华人民共和国计量法实施细则（现行有效，施行日期 2022-05-01）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6dcd7c1d5/42.html

部门和企业、事业单位的各项最高计量标准，未经有关人民政府计量行政部门考核合格而开展计量检定的，责令其停止使用，可并处1000元以下的罚款。
