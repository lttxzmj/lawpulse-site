# 中华人民共和国计量法实施细则第二十条

- 法规：中华人民共和国计量法实施细则（现行有效，施行日期 2022-05-01）
- 章节：第五章计量器具的销售和使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6dcd7c1d5/20.html

县级以上地方人民政府计量行政部门对当地销售的计量器具实施监督检查。凡没有产品合格印、证标志的计量器具不得销售。
