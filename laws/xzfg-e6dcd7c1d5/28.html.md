# 中华人民共和国计量法实施细则第二十八条

- 法规：中华人民共和国计量法实施细则（现行有效，施行日期 2022-05-01）
- 章节：第六章计量监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6dcd7c1d5/28.html

根据本细则第二十七条规定被授权的单位，应当遵守下列规定：
（一）被授权单位执行检定、测试任务的人员，必须经考核合格；
（二）被授权单位的相应计量标准，必须接受计量基准或者社会公用计量标准的检定；
（三）被授权单位承担授权的检定、测试工作，须接受授权单位的监督；
（四）被授权单位成为计量纠纷中当事人一方时，在双方协商不能自行解决的情况下，由县级以上有关人民政府计量行政部门进行调解和仲裁检定。
