# 普通高等学校设置暂行条例第十六条

- 法规：普通高等学校设置暂行条例（现行有效）
- 章节：第四章审批验收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-257320b0d5/16.html

国家教育委员会每年第三季度办理设置普通高等学校的审批手续。设置普通高等学校的主管部门，应当在每年第三季度以前提出申请，逾期则延至下一年度审批时间办理。
