# 普通高等学校设置暂行条例第三条

- 法规：普通高等学校设置暂行条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-257320b0d5/3.html

国家教育委员会应当根据经济建设和社会发展的需要、人才需求的科学预测和办学条件的实际可能，编制全国普通高等教育事业发展规划，调整普通高等教育的结构，妥善地处理发展普通高等教育同发展成人高等教育、中等专业教育和基础教育的关系，合理地确定科类和层次。
