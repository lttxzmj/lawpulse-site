# 最高人民法院关于审理期货纠纷案件若干问题的规定第四十五条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/45.html

在期货合约交割期内，买方或者卖方客户违约的，期货交易所应当代期货公司、期货公司应当代客户向对方承担违约责任。
