# 最高人民法院关于审理期货纠纷案件若干问题的规定第五十三条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/53.html

期货公司私下对冲、与客户对赌等不将客户指令入市交易的行为，应当认定为无效，期货公司应当赔偿由此给客户造成的经济损失；期货公司与客户均有过错的，应当根据过错大小，分别承担相应的赔偿责任。
