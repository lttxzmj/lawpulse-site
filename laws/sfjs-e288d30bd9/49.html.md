# 最高人民法院关于审理期货纠纷案件若干问题的规定第四十九条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/49.html

期货交易所未代期货公司履行期货合约，期货公司应当根据客户请求向期货交易所主张权利。
期货公司拒绝代客户向期货交易所主张权利的，客户可直接起诉期货交易所，期货公司可作为第三人参加诉讼。
