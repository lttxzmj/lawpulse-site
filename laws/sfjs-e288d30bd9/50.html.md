# 最高人民法院关于审理期货纠纷案件若干问题的规定第五十条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/50.html

因期货交易所的过错导致信息发布、交易指令处理错误，造成期货公司或者客户直接经济损失的，期货交易所应当承担赔偿责任，但其能够证明系不可抗力的除外。
