# 最高人民法院关于审理期货纠纷案件若干问题的规定第五十二条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/52.html

期货交易所、期货公司故意提供虚假信息误导客户下单的，由此造成客户的经济损失由期货交易所、期货公司承担。
