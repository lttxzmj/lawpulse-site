# 最高人民法院关于审理期货纠纷案件若干问题的规定第六十条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/60.html

期货公司为债务人的，人民法院不得冻结、划拨专用结算账户中未被期货合约占用的用于担保期货合约履行的最低限额的结算准备金；期货公司已经结清所有持仓并清偿客户资金的，人民法院可以对结算准备金依法予以冻结、划拨。
期货公司有其他财产的，人民法院应当依法先行冻结、查封、执行期货公司的其他财产。
