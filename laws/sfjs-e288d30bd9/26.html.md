# 最高人民法院关于审理期货纠纷案件若干问题的规定第二十六条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/26.html

期货公司与客户对交易结算结果的通知方式未作约定或者约定不明确，期货公司未能提供证据证明已经发出上述通知的，对客户因继续持仓而造成扩大的损失，应当承担主要赔偿责任，赔偿额不超过损失的百分之八十。
