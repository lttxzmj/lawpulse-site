# 最高人民法院关于审理期货纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/3.html

人民法院审理期货侵权纠纷和无效的期货交易合同纠纷案件，应当根据各方当事人是否有过错，以及过错的性质、大小，过错和损失之间的因果关系，确定过错方承担的民事责任。
