# 最高人民法院关于审理期货纠纷案件若干问题的规定第十八条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/18.html

期货公司与客户签订的期货经纪合同对下达交易指令的方式未作约定或者约定不明确的，期货公司不能证明其所进行的交易是依据客户交易指令进行的，对该交易造成客户的损失，期货公司应当承担赔偿责任，客户予以追认的除外。
