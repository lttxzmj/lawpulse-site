# 最高人民法院关于审理期货纠纷案件若干问题的规定第四十三条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/43.html

期货公司没有代客户履行申请交割义务的，应当承担违约责任；造成客户损失的，应当承担赔偿责任。
