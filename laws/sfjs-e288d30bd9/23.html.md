# 最高人民法院关于审理期货纠纷案件若干问题的规定第二十三条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/23.html

期货公司不当延误执行客户交易指令给客户造成损失的，应当承担赔偿责任，但由于市场原因致客户交易指令未能全部或者部分成交的，期货公司不承担责任。
