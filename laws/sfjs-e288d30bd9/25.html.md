# 最高人民法院关于审理期货纠纷案件若干问题的规定第二十五条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e288d30bd9/25.html

期货交易所未按交易规则规定的期限、方式，将交易或者持仓头寸的结算结果通知期货公司，造成期货公司损失的，由期货交易所承担赔偿责任。
期货公司未按期货经纪合同约定的期限、方式，将交易或者持仓头寸的结算结果通知客户，造成客户损失的，由期货公司承担赔偿责任。
