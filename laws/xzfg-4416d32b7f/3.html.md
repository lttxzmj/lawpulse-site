# 残疾预防和残疾人康复条例第三条

- 法规：残疾预防和残疾人康复条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4416d32b7f/3.html

残疾预防和残疾人康复工作应当坚持以人为本，从实际出发，实行预防为主、预防与康复相结合的方针。
国家采取措施为残疾人提供基本康复服务，支持和帮助其融入社会。禁止基于残疾的歧视。
