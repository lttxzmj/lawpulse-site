# 残疾预防和残疾人康复条例第二十七条

- 法规：残疾预防和残疾人康复条例（现行有效）
- 章节：第四章保障措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4416d32b7f/27.html

各级人民政府应当根据残疾预防和残疾人康复工作需要，将残疾预防和残疾人康复工作经费列入本级政府预算。
从事残疾预防和残疾人康复服务的机构依法享受有关税收优惠政策。县级以上人民政府有关部门对相关机构给予资金、设施设备、土地使用等方面的支持。
