# 最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释第七条

- 法规：最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0e50d0dc4a/7.html

对涉及不同侵权行为实施地的多个被告提起的共同诉讼，原告可以选择其中一个被告的侵权行为实施地人民法院管辖；仅对其中某一被告提起的诉讼，该被告侵权行为实施地的人民法院有管辖权。
