# 最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释第五条

- 法规：最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0e50d0dc4a/5.html

商标注册人或者利害关系人在注册商标续展宽展期内提出续展申请，未获核准前，以他人侵犯其注册商标专用权提起诉讼的，人民法院应当受理。
