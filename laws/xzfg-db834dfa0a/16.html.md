# 中华人民共和国内河交通安全管理条例第十六条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第三章航行、停泊和作业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/16.html

船舶在内河航行时，上行船舶应当沿缓流或者航路一侧航行，下行船舶应当沿主流或者航路中间航行；在潮流河段、湖泊、水库、平流区域，应当尽可能沿本船右舷一侧航路航行。
