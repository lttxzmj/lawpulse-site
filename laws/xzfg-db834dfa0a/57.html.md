# 中华人民共和国内河交通安全管理条例第五十七条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/57.html

在旅游、交通运输繁忙的湖泊、水库，在气候恶劣的季节，在法定或者传统节日、重大集会、集市、农忙、学生放学放假等交通高峰期间，县级以上地方各级人民政府应当加强对维护内河交通安全的组织、协调工作。
