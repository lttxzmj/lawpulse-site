# 中华人民共和国内河交通安全管理条例第四十九条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第七章救助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/49.html

船舶、浮动设施遇险时，有关部门和人员必须积极协助海事管理机构做好救助工作。
遇险现场和附近的船舶、人员，必须服从海事管理机构的统一调度和指挥。
