# 中华人民共和国内河交通安全管理条例第二十三条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第三章航行、停泊和作业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/23.html

遇有下列情形之一时，海事管理机构可以根据情况采取限时航行、单航、封航等临时性限制、疏导交通的措施，并予公告：
(一)恶劣天气；
(二)大范围水上施工作业；
(三)影响航行的水上交通事故；
(四)水上大型群众性活动或者体育比赛；
(五)对航行安全影响较大的其他情形。
