# 中华人民共和国内河交通安全管理条例第六十一条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/61.html

海事管理机构依照本条例实施监督检查时，可以根据情况对违反本条例有关规定的船舶，采取责令临时停航、驶向指定地点，禁止进港、离港，强制卸载、拆除动力装置、暂扣船舶等保障通航安全的措施。
