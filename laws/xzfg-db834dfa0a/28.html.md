# 中华人民共和国内河交通安全管理条例第二十八条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第三章航行、停泊和作业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/28.html

在内河通航水域进行下列可能影响通航安全的作业，应当在进行作业前向海事管理机构备案：
(一)气象观测、测量、地质调查；
(二)航道日常养护；
(三)大面积清除水面垃圾；
(四)可能影响内河通航水域交通安全的其他行为。
