# 中华人民共和国内河交通安全管理条例第六十条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/60.html

对内河交通密集区域、多发事故水域以及货物装卸、乘客上下比较集中的港口，对客渡船、滚装客船、高速客轮、旅游船和载运危险货物的船舶，海事管理机构必须加强安全巡查。
