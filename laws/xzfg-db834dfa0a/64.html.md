# 中华人民共和国内河交通安全管理条例第六十四条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/64.html

违反本条例的规定，船舶、浮动设施未持有合格的检验证书、登记证书或者船舶未持有必要的航行资料，擅自航行或者作业的，由海事管理机构责令停止航行或者作业；拒不停止的，暂扣船舶、浮动设施；情节严重的，予以没收。
