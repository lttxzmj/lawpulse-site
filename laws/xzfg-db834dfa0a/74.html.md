# 中华人民共和国内河交通安全管理条例第七十四条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/74.html

违反本条例的规定，在内河通航水域的航道内养殖、种植植物、水生物或者设置永久性固定设施的，由海事管理机构责令限期改正；逾期不改正的，予以强制清除，因清除发生的费用由其所有人或者经营人承担。
