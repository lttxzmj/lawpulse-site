# 中华人民共和国内河交通安全管理条例第九十二条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第十一章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/92.html

军事船舶在内河通航水域航行，应当遵守内河航行、避让和信号显示规则。军事船舶的检验、登记和船员的考试、发证等管理办法，按照国家有关规定执行。
