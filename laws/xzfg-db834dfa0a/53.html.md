# 中华人民共和国内河交通安全管理条例第五十三条

- 法规：中华人民共和国内河交通安全管理条例（现行有效）
- 章节：第八章事故调查处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-db834dfa0a/53.html

海事管理机构应当在内河交通事故调查、取证结束后30日内，依据调查事实和证据作出调查结论，并书面告知内河交通事故当事人。
