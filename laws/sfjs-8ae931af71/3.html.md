# 最高人民法院、最高人民检察院关于办理非法占用耕地案件适用法律若干问题的规定第三条

- 法规：最高人民法院、最高人民检察院关于办理非法占用耕地案件适用法律若干问题的规定（现行有效，施行日期 2026-05-18）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8ae931af71/3.html

非法占用耕地的行为，在耕地恢复至未被占用的状态之前，应当视为具有行政处罚法第三十六条第二款规定的“继续状态”，行政处罚的追责期限应当从违法行为终了之日起计算。
