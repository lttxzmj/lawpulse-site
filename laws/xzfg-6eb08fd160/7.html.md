# 中华人民共和国国际货物运输代理业管理规定第七条

- 法规：中华人民共和国国际货物运输代理业管理规定（现行有效）
- 章节：第二章设立条件
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6eb08fd160/7.html

设立国际货物运输代理企业，根据其行业特点，应当具备下列条件：
(一)有与其从事的国际货物运输代理业务相适应的专业人员；
(二)有固定的营业场所和必要的营业设施；
(三)有稳定的进出口货源市场。
