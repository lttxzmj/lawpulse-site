# 中华人民共和国国际货物运输代理业管理规定第二十三条

- 法规：中华人民共和国国际货物运输代理业管理规定（现行有效）
- 章节：第五章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6eb08fd160/23.html

国际货物运输代理企业违反本规定第十九条、第二十一条规定的，由国务院对外贸易经济合作主管部门予以警告并责令限期改正；未在限期内改正的，可以撤销其批准证书。
