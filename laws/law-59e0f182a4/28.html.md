# 中华人民共和国水污染防治法第二十八条

- 法规：中华人民共和国水污染防治法（已废止，施行日期 2018-01-01）
- 章节：第三章水污染防治的监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-59e0f182a4/28.html

国务院环境保护主管部门应当会同国务院水行政等部门和有关省、自治区、直辖市人民政府，建立重要江河、湖泊的流域水环境保护联合协调机制，实行统一规划、统一标准、统一监测、统一的防治措施。
