# 中华人民共和国水污染防治法第二十三条

- 法规：中华人民共和国水污染防治法（已废止，施行日期 2018-01-01）
- 章节：第三章水污染防治的监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-59e0f182a4/23.html

实行排污许可管理的企业事业单位和其他生产经营者应当按照国家有关规定和监测规范，对所排放的水污染物自行监测，并保存原始监测记录。重点排污单位还应当安装水污染物排放自动监测设备，与环境保护主管部门的监控设备联网，并保证监测设备正常运行。具体办法由国务院环境保护主管部门规定。
应当安装水污染物排放自动监测设备的重点排污单位名录，由设区的市级以上地方人民政府环境保护主管部门根据本行政区域的环境容量、重点水污染物排放总量控制指标的要求以及排污单位排放水污染物的种类、数量和浓度等因素，商同级有关部门确定。
