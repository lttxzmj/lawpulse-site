# 计算机信息网络国际联网安全保护管理办法第八条

- 法规：计算机信息网络国际联网安全保护管理办法（现行有效）
- 章节：第二章安全保护责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-13f8fbc50e/8.html

从事国际联网业务的单位和个人应当接受公安机关的安全监督、检查和指导，如实向公安机关提供有关安全保护的信息、资料及数据文件，协助公安机关查处通过国际联网的计算机信息网络的违法犯罪行为。
