# 计算机信息网络国际联网安全保护管理办法第十六条

- 法规：计算机信息网络国际联网安全保护管理办法（现行有效）
- 章节：第三章安全监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-13f8fbc50e/16.html

公安机关计算机管理监察机构应当掌握互联单位、接入单位和用户的备案情况，建立备案档案，进行备案统计，并按照国家有关规定逐级上报。
