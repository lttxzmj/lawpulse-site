# 南水北调工程供用水管理条例第二十八条

- 法规：南水北调工程供用水管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章水质保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bdf90c13bd/28.html

建设穿越、跨越、邻接南水北调工程输水河道的桥梁、公路、石油天然气管道、雨污水管道等工程设施的，其建设、管理单位应当设置警示标志，并采取有效措施，防范工程建设或者交通事故、管道泄漏等带来的安全风险。
