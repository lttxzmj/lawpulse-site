# 南水北调工程供用水管理条例第四十五条

- 法规：南水北调工程供用水管理条例（现行有效，施行日期 2026-08-15）
- 章节：第五章工程设施管理和保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bdf90c13bd/45.html

在汛期，南水北调工程管理单位应当加强巡查，发现险情立即采取抢修等措施，并及时向有关防汛抗旱指挥机构报告。
