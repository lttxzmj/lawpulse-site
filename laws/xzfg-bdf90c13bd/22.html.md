# 南水北调工程供用水管理条例第二十二条

- 法规：南水北调工程供用水管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章水质保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bdf90c13bd/22.html

南水北调东线工程调水沿线区域和中线工程水源地的水污染物排放单位，应当配套建设与其排放量相适应的治理设施；实行排污许可重点管理的单位应当按照有关规定安装自动监测设备。
南水北调东线工程干线、中线工程总干渠禁止设置排污口。
