# 南水北调工程供用水管理条例第二十三条

- 法规：南水北调工程供用水管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章水质保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bdf90c13bd/23.html

南水北调东线工程调水沿线区域和中线工程水源地县级以上地方人民政府所在城镇排放的污水，应当经过集中处理，实现达标排放。
南水北调东线工程调水沿线区域和中线工程水源地县级以上地方人民政府应当合理规划、建设污水集中处理设施和配套管网，并组织收集、无害化处理城乡生活垃圾，避免污染水环境。
南水北调东线工程调水沿线区域和中线工程水源地的畜禽养殖场、养殖小区，应当按照国家有关规定对畜禽粪便、废水等进行无害化处理和资源化利用。
