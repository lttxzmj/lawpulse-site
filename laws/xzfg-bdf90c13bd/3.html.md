# 南水北调工程供用水管理条例第三条

- 法规：南水北调工程供用水管理条例（现行有效，施行日期 2026-08-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bdf90c13bd/3.html

南水北调工程的供用水管理遵循先节水后调水、先治污后通水、先环保后用水的原则，坚持全程管理、统筹兼顾、权责明晰、严格保护，确保调度合理、水质合格、用水节约、设施安全。
