# 机关事务管理条例第十八条

- 法规：机关事务管理条例（现行有效）
- 章节：第三章资产管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/18.html

县级以上人民政府应当根据有关机关资产管理的规定、经济社会发展水平、节能环保要求和机关运行的基本需求，结合机关事务管理实际，分类制定机关资产配置标准，确定资产数量、价格、性能和最低使用年限。政府各部门应当根据机关资产配置标准编制本部门的资产配置计划。
