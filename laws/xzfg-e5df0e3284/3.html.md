# 机关事务管理条例第三条

- 法规：机关事务管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/3.html

县级以上人民政府应当推进本级政府机关事务的统一管理，建立健全管理制度和标准，统筹配置资源。
政府各部门应当对本部门的机关事务实行集中管理，执行机关事务管理制度和标准。
