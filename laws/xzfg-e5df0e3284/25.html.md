# 机关事务管理条例第二十五条

- 法规：机关事务管理条例（现行有效）
- 章节：第三章资产管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/25.html

政府各部门应当严格执行公务用车编制和配备标准，建立健全公务用车配备更新管理制度，不得超编制、超标准配备公务用车或者超标准租用车辆，不得为公务用车增加高档配置或者豪华内饰，不得借用、占用下级单位和其他单位的车辆，不得接受企业事业单位和个人捐赠的车辆。
