# 机关事务管理条例第二十二条

- 法规：机关事务管理条例（现行有效）
- 章节：第三章资产管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/22.html

政府各部门超过核定面积的办公用房，因办公用房新建、调整和机构撤销腾退的办公用房，应当由本级政府及时收回，统一调剂使用。
各级人民政府及其部门的工作人员退休或者调离的，其办公用房应当由原单位及时收回，调剂使用。
