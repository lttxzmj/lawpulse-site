# 机关事务管理条例第二十八条

- 法规：机关事务管理条例（现行有效）
- 章节：第四章服务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/28.html

各级人民政府应当按照简化礼仪、务实节俭的原则管理和规范公务接待工作。
国务院机关事务主管部门负责拟订政府机关公务接待的相关制度和中央国家机关公务接待标准。县级以上地方人民政府应当结合本地实际，确定公务接待的范围和标准。政府各部门和公务接待管理机构应当严格执行公务接待制度和标准。
县级以上地方人民政府公务接待管理机构负责管理本级政府公务接待工作，指导下级政府公务接待工作。
