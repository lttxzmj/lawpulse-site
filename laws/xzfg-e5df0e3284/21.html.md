# 机关事务管理条例第二十一条

- 法规：机关事务管理条例（现行有效）
- 章节：第三章资产管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e5df0e3284/21.html

县级以上人民政府应当建立健全机关办公用房管理制度，对本级政府机关办公用房实行统一调配、统一权属登记；具备条件的，可以对本级政府机关办公用房实行统一建设。
政府各部门办公用房的建设和维修应当严格执行政府机关办公用房建设、维修标准，符合简朴实用、节能环保、安全保密等要求；办公用房的使用和维护应当严格执行政府机关办公用房物业服务标准。
