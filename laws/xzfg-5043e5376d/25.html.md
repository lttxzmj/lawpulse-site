# 中华人民共和国畜禽遗传资源进出境和对外合作研究利用审批办法第二十五条

- 法规：中华人民共和国畜禽遗传资源进出境和对外合作研究利用审批办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5043e5376d/25.html

未经审核批准，从境外引进畜禽遗传资源，或者在境内与境外机构、个人合作研究利用列入畜禽遗传资源保护名录的畜禽遗传资源，或者在境内与境外机构、个人合作研究利用未经国家畜禽遗传资源委员会鉴定的新发现的畜禽遗传资源的，依照《中华人民共和国畜牧法》的有关规定追究法律责任。
