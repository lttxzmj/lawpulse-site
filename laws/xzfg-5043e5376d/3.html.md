# 中华人民共和国畜禽遗传资源进出境和对外合作研究利用审批办法第三条

- 法规：中华人民共和国畜禽遗传资源进出境和对外合作研究利用审批办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5043e5376d/3.html

本办法所称畜禽，是指列入依照《中华人民共和国畜牧法》第十一条规定公布的畜禽遗传资源目录的畜禽。
本办法所称畜禽遗传资源，是指畜禽及其卵子(蛋)、胚胎、精液、基因物质等遗传材料。
