# 娱乐场所管理条例第四十九条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/49.html

娱乐场所违反本条例规定，有下列情形之一的，由县级人民政府文化主管部门责令改正，给予警告；情节严重的，责令停业整顿1个月至3个月：
(一)变更有关事项，未按照本条例规定申请重新核发娱乐经营许可证的；
(二)在本条例规定的禁止营业时间内营业的；
(三)从业人员在营业期间未统一着装并佩带工作标志的。
