# 娱乐场所管理条例第三十三条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/33.html

文化主管部门、公安部门和其他有关部门应当记录监督检查的情况和处理结果。监督检查记录由监督检查人员签字归档。公众有权查阅监督检查记录。
