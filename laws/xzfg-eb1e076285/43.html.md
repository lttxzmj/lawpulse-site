# 娱乐场所管理条例第四十三条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/43.html

娱乐场所实施本条例第十四条禁止行为的，由县级公安部门没收违法所得和非法财物，责令停业整顿3个月至6个月；情节严重的，由原发证机关吊销娱乐经营许可证，对直接负责的主管人员和其他直接责任人员处1万元以上2万元以下的罚款。
