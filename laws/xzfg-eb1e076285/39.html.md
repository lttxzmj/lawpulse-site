# 娱乐场所管理条例第三十九条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/39.html

文化主管部门、公安部门和其他有关部门及其工作人员违反本条例规定的，任何单位或者个人可以向依法有权处理的本级或者上一级机关举报。接到举报的机关应当依法及时调查、处理。
