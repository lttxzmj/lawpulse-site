# 娱乐场所管理条例第四十一条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/41.html

违反本条例规定，擅自从事娱乐场所经营活动的，由文化主管部门依法予以取缔；公安部门在查处治安、刑事案件时，发现擅自从事娱乐场所经营活动的，应当依法予以取缔。
