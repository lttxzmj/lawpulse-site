# 娱乐场所管理条例第七条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第二章设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/7.html

娱乐场所不得设在下列地点：
(一)居民楼、博物馆、图书馆和被核定为文物保护单位的建筑物内；
(二)居民住宅区和学校、医院、机关周围；
(三)车站、机场等人群密集的场所；
(四)建筑物地下一层以下；
(五)与危险化学品仓库毗连的区域。
娱乐场所的边界噪声，应当符合国家规定的环境噪声标准。
