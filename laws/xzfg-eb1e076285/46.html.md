# 娱乐场所管理条例第四十六条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/46.html

娱乐场所指使、纵容从业人员侵害消费者人身权利的，应当依法承担民事责任，并由县级公安部门责令停业整顿1个月至3个月；造成严重后果的，由原发证机关吊销娱乐经营许可证。
