# 娱乐场所管理条例第三十七条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/37.html

任何单位或者个人发现娱乐场所内有违反本条例行为的，有权向文化主管部门、公安部门等有关部门举报。
文化主管部门、公安部门等有关部门接到举报，应当记录，并及时依法调查、处理；对不属于本部门职责范围的，应当及时移送有关部门。
