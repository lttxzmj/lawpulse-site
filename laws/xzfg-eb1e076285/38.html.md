# 娱乐场所管理条例第三十八条

- 法规：娱乐场所管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eb1e076285/38.html

上级人民政府文化主管部门、公安部门在必要时，可以依照本条例的规定调查、处理由下级人民政府文化主管部门、公安部门调查、处理的案件。
下级人民政府文化主管部门、公安部门认为案件重大、复杂的，可以请求移送上级人民政府文化主管部门、公安部门调查、处理。
