# 广播电视设施保护条例第三条

- 法规：广播电视设施保护条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf9e813afb/3.html

县级以上人民政府应当将广播电视设施的规划和保护纳入城乡建设总体规划，并加强广播电视设施保护的宣传教育工作。
县级以上人民政府负责广播电视行政管理工作的部门或者机构(以下统称广播电视行政管理部门)负责所管辖的广播电视设施的保护工作，并采取措施，确保广播电视设施的安全。
