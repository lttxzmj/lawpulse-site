# 广播电视设施保护条例第二十五条

- 法规：广播电视设施保护条例（现行有效）
- 章节：第三章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf9e813afb/25.html

广播电视行政管理部门、城市规划主管部门、公安机关的工作人员违反本条例规定，滥用职权、玩忽职守、徇私舞弊，造成广播电视设施严重损害或者严重影响其使用效能，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予行政处分。
