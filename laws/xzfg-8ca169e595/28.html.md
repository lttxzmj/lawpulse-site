# 计算机软件保护条例第二十八条

- 法规：计算机软件保护条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8ca169e595/28.html

软件复制品的出版者、制作者不能证明其出版、制作有合法授权的，或者软件复制品的发行者、出租者不能证明其发行、出租的复制品有合法来源的，应当承担法律责任。
