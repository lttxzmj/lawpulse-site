# 计算机软件保护条例第二十七条

- 法规：计算机软件保护条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8ca169e595/27.html

为了制止侵权行为，在证据可能灭失或者以后难以取得的情况下，软件著作权人可以依照《中华人民共和国著作权法》第五十一条的规定，在提起诉讼前向人民法院申请保全证据。
