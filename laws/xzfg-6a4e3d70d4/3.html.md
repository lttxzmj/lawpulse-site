# 失业保险条例第三条

- 法规：失业保险条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a4e3d70d4/3.html

国务院劳动保障行政部门主管全国的失业保险工作。县级以上地方各级人民政府劳动保障行政部门主管本行政区域内的失业保险工作。劳动保障行政部门按照国务院规定设立的经办失业保险业务的社会保险经办机构依照本条例的规定，具体承办失业保险工作。
