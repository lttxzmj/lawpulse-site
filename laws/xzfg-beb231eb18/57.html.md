# 生物医学新技术临床研究和临床转化应用管理条例第五十七条

- 法规：生物医学新技术临床研究和临床转化应用管理条例（现行有效，施行日期 2026-05-01）
- 章节：第七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-beb231eb18/57.html

本条例施行前已经开展的生物医学新技术临床研究，临床研究机构可以按照临床研究方案继续实施，并应当自本条例施行之日起1个月内依照本条例规定进行备案。
