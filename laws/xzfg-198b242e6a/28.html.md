# 中华人民共和国消费者权益保护法实施条例第二十八条

- 法规：中华人民共和国消费者权益保护法实施条例（现行有效，施行日期 2024-07-01）
- 章节：第三章国家对消费者合法权益的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-198b242e6a/28.html

市场监督管理部门和其他有关行政部门应当加强消费者权益保护工作的协同配合和信息共享，依照法律、法规的规定，在各自的职责范围内，对经营者提供的商品和服务实施抽查检验等监管措施，及时查处侵害消费者合法权益的行为。
