# 中华人民共和国消费者权益保护法实施条例第三十六条

- 法规：中华人民共和国消费者权益保护法实施条例（现行有效，施行日期 2024-07-01）
- 章节：第四章消费者组织
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-198b242e6a/36.html

有关行政部门应当认真听取消费者协会的意见和建议。对于消费者协会向有关行政部门反映的侵害消费者合法权益的问题，有关行政部门应当及时调查处理并予以回复；对于立案查处的案件，有关行政部门应当将处理结果告知消费者协会。
