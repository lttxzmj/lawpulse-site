# 中华人民共和国消费者权益保护法实施条例第十六条

- 法规：中华人民共和国消费者权益保护法实施条例（现行有效，施行日期 2024-07-01）
- 章节：第二章消费者的权利和经营者的义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-198b242e6a/16.html

经营者提供网络游戏服务的，应当符合国家关于网络游戏服务相关时段、时长、功能和内容等方面的规定和标准，针对未成年人设置相应的时间管理、权限管理、消费管理等功能，在注册、登录等环节严格进行用户核验，依法保护未成年人身心健康。
