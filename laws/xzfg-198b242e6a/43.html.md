# 中华人民共和国消费者权益保护法实施条例第四十三条

- 法规：中华人民共和国消费者权益保护法实施条例（现行有效，施行日期 2024-07-01）
- 章节：第五章争议的解决
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-198b242e6a/43.html

各级人民政府市场监督管理部门和其他有关行政部门应当推动、健全消费争议多元化解决机制，引导消费者依法通过协商、调解、投诉、仲裁、诉讼等方式维护自身合法权益。
