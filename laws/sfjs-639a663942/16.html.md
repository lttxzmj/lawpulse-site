# 最高人民法院关于执行和解若干问题的规定第十六条

- 法规：最高人民法院关于执行和解若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-639a663942/16.html

当事人、利害关系人认为执行和解协议无效或者应予撤销的，可以向执行法院提起诉讼。执行和解协议被确认无效或者撤销后，申请执行人可以据此申请恢复执行。
被执行人以执行和解协议无效或者应予撤销为由提起诉讼的，不影响申请执行人申请恢复执行。
