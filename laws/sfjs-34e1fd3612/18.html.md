# 最高人民法院、最高人民检察院关于办理危害药品安全刑事案件适用法律若干问题的解释第十八条

- 法规：最高人民法院、最高人民检察院关于办理危害药品安全刑事案件适用法律若干问题的解释（现行有效，施行日期 2022-03-06）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-34e1fd3612/18.html

根据民间传统配方私自加工药品或者销售上述药品，数量不大，且未造成他人伤害后果或者延误诊治的，或者不以营利为目的实施带有自救、互助性质的生产、进口、销售药品的行为，不应当认定为犯罪。
对于是否属于民间传统配方难以确定的，根据地市级以上药品监督管理部门或者有关部门出具的认定意见，结合其他证据作出认定。
