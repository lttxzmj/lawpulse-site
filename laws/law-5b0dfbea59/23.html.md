# 中华人民共和国检察官法第二十三条

- 法规：中华人民共和国检察官法（现行有效，施行日期 2019-10-01）
- 章节：第四章检察官的任免
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-5b0dfbea59/23.html

检察官不得兼任人民代表大会常务委员会的组成人员，不得兼任行政机关、监察机关、审判机关的职务，不得兼任企业或者其他营利性组织、事业单位的职务，不得兼任律师、仲裁员和公证员。
