# 最高人民法院关于审理未成年人刑事案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理未成年人刑事案件具体应用法律若干问题的解释（现行有效，施行日期 2006-01-23）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-be273b5275/3.html

审理未成年人刑事案件，应当查明被告人实施被指控的犯罪时的年龄。裁判文书中应当写明被告人出生的年、月、日。
