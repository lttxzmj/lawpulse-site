# 中华人民共和国归侨侨眷权益保护法实施办法第三条

- 法规：中华人民共和国归侨侨眷权益保护法实施办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aa144476a2/3.html

华侨、归侨去世后或者华侨身份改变后，其国内眷属原依法认定的侨眷身份不变。
依法与华侨、归侨及其子女解除婚姻关系，或者与华侨、归侨解除扶养关系的，其原依法认定的侨眷身份丧失。
