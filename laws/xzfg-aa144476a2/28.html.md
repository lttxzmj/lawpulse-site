# 中华人民共和国归侨侨眷权益保护法实施办法第二十八条

- 法规：中华人民共和国归侨侨眷权益保护法实施办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aa144476a2/28.html

经办侨务专项经费的机构、人员，违反本办法规定，挪用、截留、私分侨务专项经费的，对直接负责的主管人员和其他直接责任人员依法给予行政处分或者纪律处分；构成犯罪的，依法追究刑事责任。被挪用、截留、私分的侨务专项经费，由其主管部门责令追回。
