# 最高人民检察院关于以检察专递方式邮寄送达有关检察法律文书的若干规定第三条

- 法规：最高人民检察院关于以检察专递方式邮寄送达有关检察法律文书的若干规定（现行有效，施行日期 2015-02-13）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-2789105814/3.html

当事人向人民检察院申请监督、提出申诉或者提交答辩意见时，应当向人民检察院提供或者确认自己准确的送达地址及联系方式，并填写当事人联系方式确认书。
