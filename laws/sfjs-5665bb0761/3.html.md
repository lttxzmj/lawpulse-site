# 最高人民法院关于互联网法院审理案件若干问题的规定第三条

- 法规：最高人民法院关于互联网法院审理案件若干问题的规定（现行有效，施行日期 2018-09-07）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5665bb0761/3.html

当事人可以在本规定第二条确定的合同及其他财产权益纠纷范围内，依法协议约定与争议有实际联系地点的互联网法院管辖。
电子商务经营者、网络服务提供商等采取格式条款形式与用户订立管辖协议的，应当符合法律及司法解释关于格式条款的规定。
