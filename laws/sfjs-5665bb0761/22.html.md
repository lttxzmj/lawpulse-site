# 最高人民法院关于互联网法院审理案件若干问题的规定第二十二条

- 法规：最高人民法院关于互联网法院审理案件若干问题的规定（现行有效，施行日期 2018-09-07）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5665bb0761/22.html

当事人对互联网法院审理的案件提起上诉的，第二审法院原则上采取在线方式审理。第二审法院在线审理规则参照适用本规定。
