# 中国人民解放军现役士兵服役条例第四十一条

- 法规：中国人民解放军现役士兵服役条例（现行有效）
- 章节：第五章士兵的待遇
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d28b02bd1b/41.html

执行作战任务的部队的士官停止探亲和休假。国家发布动员令或者部队紧急战备需要召回时，正在探亲、休假的士官应当立即结束探亲、休假，返回本部。
