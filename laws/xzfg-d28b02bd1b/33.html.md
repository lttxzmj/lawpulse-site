# 中国人民解放军现役士兵服役条例第三十三条

- 法规：中国人民解放军现役士兵服役条例（现行有效）
- 章节：第五章士兵的待遇
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d28b02bd1b/33.html

担任副班长、班长或者相当于班长职务和担任分队行政或者专业技术领导、管理职务的士兵，按照规定发给职务津贴。
士兵代理军官职务期间，按照规定发给与其代理职务相应的岗位津贴。
