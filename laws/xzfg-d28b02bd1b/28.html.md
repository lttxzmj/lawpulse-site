# 中国人民解放军现役士兵服役条例第二十八条

- 法规：中国人民解放军现役士兵服役条例（现行有效）
- 章节：第四章士兵的奖惩
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d28b02bd1b/28.html

对在作战、训练、执勤和工作中表现突出，取得显著成绩，以及为国家和人民做出其他较大贡献的士兵，应当给予奖励。奖励的项目、条件、批准权限和实施程序按照中央军事委员会的规定执行。
