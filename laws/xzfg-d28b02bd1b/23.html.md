# 中国人民解放军现役士兵服役条例第二十三条

- 法规：中国人民解放军现役士兵服役条例（现行有效）
- 章节：第三章士兵的军衔
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d28b02bd1b/23.html

士兵在院校和训练机构学习期间军衔的晋升，由本人隶属单位办理。
士兵住院治疗期间军衔的晋升，由原单位办理。士兵因病和非因公致伤致残住院或者病休时间，连续计算超过半年的，军衔暂缓晋升，暂缓期限不得少于半年；医疗终结后符合条件继续服现役的，应当按期晋升。
