# 中华人民共和国劳动合同法实施条例第二十五条

- 法规：中华人民共和国劳动合同法实施条例（现行有效）
- 章节：第三章劳动合同的解除和终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ec5eb2c922/25.html

用人单位违反劳动合同法的规定解除或者终止劳动合同，依照劳动合同法第八十七条的规定支付了赔偿金的，不再支付经济补偿。赔偿金的计算年限自用工之日起计算。
