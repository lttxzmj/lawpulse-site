# 中华人民共和国劳动合同法实施条例第二十八条

- 法规：中华人民共和国劳动合同法实施条例（现行有效）
- 章节：第四章劳务派遣特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ec5eb2c922/28.html

用人单位或者其所属单位出资或者合伙设立的劳务派遣单位，向本单位或者所属单位派遣劳动者的，属于劳动合同法第六十七条规定的不得设立的劳务派遣单位。
