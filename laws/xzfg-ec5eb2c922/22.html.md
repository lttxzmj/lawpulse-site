# 中华人民共和国劳动合同法实施条例第二十二条

- 法规：中华人民共和国劳动合同法实施条例（现行有效）
- 章节：第三章劳动合同的解除和终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ec5eb2c922/22.html

以完成一定工作任务为期限的劳动合同因任务完成而终止的，用人单位应当依照劳动合同法第四十七条的规定向劳动者支付经济补偿。
