# 中华人民共和国劳动合同法实施条例第二十三条

- 法规：中华人民共和国劳动合同法实施条例（现行有效）
- 章节：第三章劳动合同的解除和终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ec5eb2c922/23.html

用人单位依法终止工伤职工的劳动合同的，除依照劳动合同法第四十七条的规定支付经济补偿外，还应当依照国家有关工伤保险的规定支付一次性工伤医疗补助金和伤残就业补助金。
