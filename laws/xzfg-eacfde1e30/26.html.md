# 生产安全事故应急条例第二十六条

- 法规：生产安全事故应急条例（现行有效，施行日期 2019-04-01）
- 章节：第三章应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eacfde1e30/26.html

有关人民政府及其部门根据生产安全事故应急救援需要依法调用和征用的财产，在使用完毕或者应急救援结束后，应当及时归还。财产被调用、征用或者调用、征用后毁损、灭失的，有关人民政府及其部门应当按照国家有关规定给予补偿。
