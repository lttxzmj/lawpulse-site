# 生产安全事故应急条例第二十三条

- 法规：生产安全事故应急条例（现行有效，施行日期 2019-04-01）
- 章节：第三章应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eacfde1e30/23.html

生产安全事故发生地人民政府应当为应急救援人员提供必需的后勤保障，并组织通信、交通运输、医疗卫生、气象、水文、地质、电力、供水等单位协助应急救援。
