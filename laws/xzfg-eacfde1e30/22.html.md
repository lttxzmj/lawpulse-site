# 生产安全事故应急条例第二十二条

- 法规：生产安全事故应急条例（现行有效，施行日期 2019-04-01）
- 章节：第三章应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eacfde1e30/22.html

在生产安全事故应急救援过程中，发现可能直接危及应急救援人员生命安全的紧急情况时，现场指挥部或者统一指挥应急救援的人民政府应当立即采取相应措施消除隐患，降低或者化解风险，必要时可以暂时撤离应急救援人员。
