# 生产安全事故应急条例第二十八条

- 法规：生产安全事故应急条例（现行有效，施行日期 2019-04-01）
- 章节：第三章应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eacfde1e30/28.html

县级以上地方人民政府应当按照国家有关规定，对在生产安全事故应急救援中伤亡的人员及时给予救治和抚恤；符合烈士评定条件的，按照国家有关规定评定为烈士。
