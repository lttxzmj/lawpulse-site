# 生产安全事故应急条例第二十五条

- 法规：生产安全事故应急条例（现行有效，施行日期 2019-04-01）
- 章节：第三章应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-eacfde1e30/25.html

生产安全事故的威胁和危害得到控制或者消除后，有关人民政府应当决定停止执行依照本条例和有关法律、法规采取的全部或者部分应急救援措施。
