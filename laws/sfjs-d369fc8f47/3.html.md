# 最高人民法院关于审理拐卖妇女儿童犯罪案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理拐卖妇女儿童犯罪案件具体应用法律若干问题的解释（现行有效，施行日期 2017-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d369fc8f47/3.html

以介绍婚姻为名，采取非法扣押身份证件、限制人身自由等方式，或者利用妇女人地生疏、语言不通、孤立无援等境况，违背妇女意志，将其出卖给他人的，应当以拐卖妇女罪追究刑事责任。
以介绍婚姻为名，与被介绍妇女串通骗取他人钱财，数额较大的，应当以诈骗罪追究刑事责任。
