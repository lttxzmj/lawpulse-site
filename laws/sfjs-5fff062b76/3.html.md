# 最高人民法院关于人民法院办理财产保全案件若干问题的规定第三条

- 法规：最高人民法院关于人民法院办理财产保全案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5fff062b76/3.html

仲裁过程中，当事人申请财产保全的，应当通过仲裁机构向人民法院提交申请书及仲裁案件受理通知书等相关材料。人民法院裁定采取保全措施或者裁定驳回申请的，应当将裁定书送达当事人，并通知仲裁机构。
