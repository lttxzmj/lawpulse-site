# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第四十三条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第七章划拨土地使用权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/43.html

划拨土地使用权是指土地使用者通过各种方式依法无偿取得的土地使用权。
前款土地使用者应当依照《中华人民共和国城镇土地使用税暂行条例》的规定缴纳土地使用税。
