# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第二十八条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第四章土地使用权出租
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/28.html

土地使用权出租是指土地使用者作为出租人将土地使用权随同地上建筑物、其他附着物租赁给承租人使用，由承租人向出租人支付租金的行为。
未按土地使用权出让合同规定的期限和条件投资开发、利用土地的，土地使用权不得出租。
