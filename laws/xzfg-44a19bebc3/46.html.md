# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第四十六条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第七章划拨土地使用权
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/46.html

对未经批准擅自转让、出租、抵押划拨土地使用权的单位和个人，市、县人民政府土地管理部门应当没收其非法收入，并根据情节处以罚款。
