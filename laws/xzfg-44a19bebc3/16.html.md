# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第十六条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第二章土地使用权出让
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/16.html

土地使用者在支付全部土地使用权出让金后，应当依照规定办理登记，领取土地使用证，取得土地使用权。
