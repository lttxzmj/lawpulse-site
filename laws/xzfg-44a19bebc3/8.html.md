# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第八条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第二章土地使用权出让
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/8.html

土地使用权出让是指国家以土地所有者的身份将土地使用权在一定年限内让与土地使用者，并由土地使用者向国家支付土地使用权出让金的行为。
土地使用权出让应当签订出让合同。
