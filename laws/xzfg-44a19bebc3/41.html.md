# 中华人民共和国城镇国有土地使用权出让和转让暂行条例第四十一条

- 法规：中华人民共和国城镇国有土地使用权出让和转让暂行条例（现行有效，施行日期 2020-11-29）
- 章节：第六章土地使用权终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-44a19bebc3/41.html

土地使用权期满，土地使用者可以申请续期。需要续期的，应当依照本条例第二章的规定重新签订合同，支付土地使用权出让金，并办理登记。
