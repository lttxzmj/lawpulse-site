# 最高人民法院关于内地与香港特别行政区法院相互认可和执行民商事案件判决的安排第二十二条

- 法规：最高人民法院关于内地与香港特别行政区法院相互认可和执行民商事案件判决的安排（现行有效，施行日期 2024-01-29）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b94862e2b6/22.html

在审理民商事案件期间，当事人申请认可和执行另一地法院就同一争议作出的判决的，应当受理。受理后，有关诉讼应当中止，待就认可和执行的申请作出裁定或者命令后，再视情终止或者恢复诉讼。
