# 最高人民法院关于内地与香港特别行政区法院相互认可和执行民商事案件判决的安排第二十八条

- 法规：最高人民法院关于内地与香港特别行政区法院相互认可和执行民商事案件判决的安排（现行有效，施行日期 2024-01-29）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b94862e2b6/28.html

本安排签署后，最高人民法院和香港特别行政区政府经协商，可以就第三条所列案件判决的认可和执行以及第四条所涉保全、临时济助的协助问题签署补充文件。
本安排在执行过程中遇有问题或者需要修改的，由最高人民法院和香港特别行政区政府协商解决。
