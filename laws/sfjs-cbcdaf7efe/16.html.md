# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（二）第十六条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-cbcdaf7efe/16.html

人民法院组织清算的，清算组应当自成立之日起六个月内清算完毕。
因特殊情况无法在六个月内完成清算的，清算组应当向人民法院申请延长。
