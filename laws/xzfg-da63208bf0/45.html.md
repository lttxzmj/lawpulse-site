# 行政法规制定程序条例第四十五条

- 法规：行政法规制定程序条例（现行有效，施行日期 2026-07-01）
- 章节：第七章其他规定
- 数据核对至：2026-10-22

行政法规的修改、废止程序适用本条例的有关规定。
行政法规修改的，应当公布新的行政法规文本。
行政法规废止的，除由法律、其他行政法规规定废止该行政法规的以外，由总理签署国务院令予以公布。
