# 行政法规制定程序条例第三条

- 法规：行政法规制定程序条例（现行有效，施行日期 2026-07-01）

制定行政法规，应当坚持中国共产党的领导，贯彻落实党的路线方针政策和决策部署。
制定行政法规，应当符合宪法和法律的规定，遵循立法法确定的指导思想和原则。
