# 行政法规制定程序条例第三十二条

- 法规：行政法规制定程序条例（现行有效，施行日期 2026-07-01）
- 章节：第五章决定与公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da63208bf0/32.html

国务院法治部门应当根据国务院对行政法规草案的审议意见，对行政法规草案进行修改，形成草案修改稿，报请总理签署国务院令公布施行。
签署公布行政法规的国务院令载明该行政法规的施行日期。
