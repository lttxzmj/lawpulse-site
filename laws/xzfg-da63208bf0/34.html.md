# 行政法规制定程序条例第三十四条

- 法规：行政法规制定程序条例（现行有效，施行日期 2026-07-01）
- 章节：第五章决定与公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da63208bf0/34.html

行政法规应当自公布之日起30日后施行；但是，涉及国家安全、外汇汇率、货币政策的确定以及公布后不立即施行将有碍行政法规施行的，可以自公布之日起施行。
