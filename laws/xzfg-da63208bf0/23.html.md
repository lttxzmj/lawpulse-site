# 行政法规制定程序条例第二十三条

- 法规：行政法规制定程序条例（现行有效，施行日期 2026-07-01）
- 章节：第四章审查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da63208bf0/23.html

报送国务院的送审稿，由国务院法治部门负责审查。国务院法治部门应当完善政府立法审查制度，提高审查质效。
国务院法治部门主要从以下方面对送审稿进行审查：
（一）是否严格贯彻落实党的路线方针政策和决策部署，是否符合宪法和法律的规定，是否遵循立法法确定的指导思想和原则；
（二）是否符合本条例第十七条的要求；
（三）是否与有关行政法规协调、衔接；
（四）是否正确处理有关机关、组织和公民对送审稿主要问题的意见；
（五）其他需要审查的内容。
