# 实施《中华人民共和国反外国制裁法》的规定第十六条

- 法规：实施《中华人民共和国反外国制裁法》的规定（现行有效，施行日期 2025-03-23）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96f411a7e8/16.html

采取反制措施的决定公布后，有关组织、个人在特殊情况下确需与被采取反制措施的组织、个人进行被禁止或者限制的相关活动的，应当向作出采取反制措施决定的国务院有关部门提供相应的事实和理由，经同意可以与被采取反制措施的组织、个人进行相关活动。
