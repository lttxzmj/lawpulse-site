# 实施《中华人民共和国反外国制裁法》的规定第十八条

- 法规：实施《中华人民共和国反外国制裁法》的规定（现行有效，施行日期 2025-03-23）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96f411a7e8/18.html

任何组织和个人执行或者协助执行外国国家对我国公民、组织采取的歧视性限制措施，侵害我国公民、组织合法权益的，我国公民、组织有权依法向人民法院提起诉讼，要求停止侵害、赔偿损失。
