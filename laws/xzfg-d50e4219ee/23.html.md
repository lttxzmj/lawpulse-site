# 电网调度管理条例第二十三条

- 法规：电网调度管理条例（现行有效）
- 章节：第五章调度指令
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d50e4219ee/23.html

电网管理部门的负责人，调度机构的负责人以及发电厂、变电站的负责人，对上级调度机构的值班人员发布的调度指令有不同意见时，可以向上级电网电力行政主管部门或者上级调度机构提出，但是在其未作出答复前，调度系统的值班人员必须按照上级调度机构的值班人员发布的调度指令执行。
