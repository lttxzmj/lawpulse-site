# 电网调度管理条例第二十八条

- 法规：电网调度管理条例（现行有效）
- 章节：第七章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d50e4219ee/28.html

调度机构对于超计划用电的用户应当予以警告；经警告，仍未按照计划用电的，调度机构可以发布限电指令，并可以强行扣还电力、电量；当超计划用电威胁电网安全运行时，调度机构可以部分或者全部暂时停止供电。
