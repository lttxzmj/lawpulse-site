# 外商投资电信企业管理规定第七条

- 法规：外商投资电信企业管理规定（现行有效，施行日期 2022-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-88ee378fb8/7.html

外商投资电信企业经营电信业务，除应当符合本规定第四条、第五条、第六条规定的条件外，还应当符合电信条例规定的经营基础电信业务或者经营增值电信业务应当具备的条件。
