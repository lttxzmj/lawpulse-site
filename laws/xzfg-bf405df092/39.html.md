# 易制毒化学品管理条例第三十九条

- 法规：易制毒化学品管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf405df092/39.html

违反本条例规定，走私易制毒化学品的，由海关没收走私的易制毒化学品；有违法所得的，没收违法所得，并依照海关法律、行政法规给予行政处罚；构成犯罪的，依法追究刑事责任。
