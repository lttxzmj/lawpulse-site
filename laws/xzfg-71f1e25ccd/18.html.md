# 国务院关于鼓励华侨和香港澳门同胞投资的规定第十八条

- 法规：国务院关于鼓励华侨和香港澳门同胞投资的规定（现行有效，施行日期 1990-08-18）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-71f1e25ccd/18.html

在华侨、港澳同胞投资企业集中的地区，华侨、港澳投资者可以向当地人民政府申请成立华侨、港澳投资者协会。
