# 中华人民共和国领事特权与豁免条例第二十三条

- 法规：中华人民共和国领事特权与豁免条例（现行有效，施行日期 1990-10-30）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-945dc6f5af/23.html

下列人员在中国过境或者逗留期间享有所必需的豁免和不受侵犯：
（一）途经中国的外国驻第三国的领事官员和与其共同生活的配偶及未成年子女；
（二）持有中国外交签证或者持有与中国互免签证国家外交护照的外国领事官员。
