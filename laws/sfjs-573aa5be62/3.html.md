# 最高人民法院关于内地与香港特别行政区法院就民商事案件相互委托提取证据的安排第三条

- 法规：最高人民法院关于内地与香港特别行政区法院就民商事案件相互委托提取证据的安排（现行有效，施行日期 2017-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-573aa5be62/3.html

受委托方的联络机关收到对方的委托书后，应当及时将委托书及所附相关材料转送相关法院或者其他机关办理，或者自行办理。
如果受委托方认为委托材料不符合本辖区相关法律规定，影响其完成受托事项，应当及时通知委托方修改、补充。委托方应当按照受委托方的要求予以修改、补充，或者重新出具委托书。
如果受委托方认为受托事项不属于本安排规定的委托事项范围，可以予以退回并说明原因。
