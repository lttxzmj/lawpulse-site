# 政府督查工作条例第二十三条

- 法规：政府督查工作条例（现行有效，施行日期 2021-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c3b69a4200/23.html

督查工作中发现公职人员涉嫌贪污贿赂、失职渎职等职务违法或者职务犯罪的问题线索，政府督查机构应当移送监察机关，由监察机关依法调查处置；发现涉嫌其他犯罪的问题线索，移送司法机关依法处理。
