# 最高人民法院关于审理商标案件有关管辖和法律适用范围问题的解释第三条

- 法规：最高人民法院关于审理商标案件有关管辖和法律适用范围问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f8155f5a8d/3.html

商标注册人或者利害关系人向国家知识产权局就侵犯商标权行为请求处理，又向人民法院提起侵害商标权诉讼请求损害赔偿的，人民法院应当受理。
