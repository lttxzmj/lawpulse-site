# 中华人民共和国外资银行管理条例第五十二条

- 法规：中华人民共和国外资银行管理条例（现行有效，施行日期 2019-09-30）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-43e88938df/52.html

外资银行营业性机构应当按照规定向银行业监督管理机构报送财务会计报告、报表和有关资料。
外国银行代表处应当按照规定向银行业监督管理机构报送资料。
