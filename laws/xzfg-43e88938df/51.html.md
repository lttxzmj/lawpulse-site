# 中华人民共和国外资银行管理条例第五十一条

- 法规：中华人民共和国外资银行管理条例（现行有效，施行日期 2019-09-30）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-43e88938df/51.html

外资银行营业性机构应当聘请在中华人民共和国境内依法设立的会计师事务所对其财务会计报告进行审计，并应当向其所在地的银行业监督管理机构报告。解聘会计师事务所的，应当说明理由。
