# 中华人民共和国外资银行管理条例第二十八条

- 法规：中华人民共和国外资银行管理条例（现行有效，施行日期 2019-09-30）
- 章节：第二章设立与登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-43e88938df/28.html

外商独资银行、中外合资银行变更股东的，变更后的股东应当符合本条例第九条、第十条或者第十一条关于股东的条件。
