# 中华人民共和国外资银行管理条例第三条

- 法规：中华人民共和国外资银行管理条例（现行有效，施行日期 2019-09-30）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-43e88938df/3.html

本条例所称外国金融机构，是指在中华人民共和国境外注册并经所在国家或者地区金融监管当局批准或者许可的金融机构。
本条例所称外国银行，是指在中华人民共和国境外注册并经所在国家或者地区金融监管当局批准或者许可的商业银行。
