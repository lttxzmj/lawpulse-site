# 烈士褒扬条例第四十九条

- 法规：烈士褒扬条例（现行有效，施行日期 2025-01-01）
- 章节：第五章烈士遗骸和遗物的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1be7882d74/49.html

县级以上人民政府退役军人工作主管部门应当妥善保护烈士遗骸，按照规定安葬或者安放；对烈士遗物登记造册，妥善保管，有效运用；按照规定管理烈士遗骸的鉴定数据信息。
