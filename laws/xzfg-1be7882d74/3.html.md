# 烈士褒扬条例第三条

- 法规：烈士褒扬条例（现行有效，施行日期 2025-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1be7882d74/3.html

烈士褒扬工作坚持中国共产党的领导。
国家褒扬、纪念和保护烈士，维护烈士尊严荣誉，保障烈士遗属合法权益，宣传烈士事迹和精神，弘扬社会主义核心价值观，在全社会营造崇尚烈士、缅怀烈士、学习烈士、捍卫烈士、关爱烈士遗属的氛围。
