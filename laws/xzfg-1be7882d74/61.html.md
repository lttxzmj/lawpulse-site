# 烈士褒扬条例第六十一条

- 法规：烈士褒扬条例（现行有效，施行日期 2025-01-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1be7882d74/61.html

冒领烈士褒扬金、抚恤金、补助，出具虚假证明或者伪造证件、印章骗取烈士褒扬金或者抚恤金、补助的，由县级以上地方人民政府退役军人工作主管部门取消相关待遇、追缴违法所得，并由其所在单位或者有关部门依法给予处分。
