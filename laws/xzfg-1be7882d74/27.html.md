# 烈士褒扬条例第二十七条

- 法规：烈士褒扬条例（现行有效，施行日期 2025-01-01）
- 章节：第三章烈士褒扬金和烈士遗属的抚恤优待
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1be7882d74/27.html

烈士的子女、兄弟姐妹本人自愿应征并且符合征兵条件的，优先批准其服现役；报考军队文职人员的，按照规定享受优待。烈士子女符合公务员考录条件的，在同等条件下优先录用为公务员。
烈士遗属符合就业条件的，由当地人民政府优先提供政策支持和就业服务，促进其实现稳定就业。烈士遗属已经就业，用人单位经济性裁员时，应当优先留用。烈士遗属从事经营活动的，享受国家和当地人民政府规定的优惠政策。
