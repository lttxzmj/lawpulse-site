# 关键信息基础设施安全保护条例第五十条

- 法规：关键信息基础设施安全保护条例（现行有效，施行日期 2021-09-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-33e47672bc/50.html

存储、处理涉及国家秘密信息的关键信息基础设施的安全保护，还应当遵守保密法律、行政法规的规定。
关键信息基础设施中的密码使用和管理，还应当遵守相关法律、行政法规的规定。
