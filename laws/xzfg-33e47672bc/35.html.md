# 关键信息基础设施安全保护条例第三十五条

- 法规：关键信息基础设施安全保护条例（现行有效，施行日期 2021-09-01）
- 章节：第四章保障和促进
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-33e47672bc/35.html

国家采取措施，鼓励网络安全专门人才从事关键信息基础设施安全保护工作；将运营者安全管理人员、安全技术人员培训纳入国家继续教育体系。
