# 关键信息基础设施安全保护条例第十一条

- 法规：关键信息基础设施安全保护条例（现行有效，施行日期 2021-09-01）
- 章节：第二章关键信息基础设施认定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-33e47672bc/11.html

关键信息基础设施发生较大变化，可能影响其认定结果的，运营者应当及时将相关情况报告保护工作部门。保护工作部门自收到报告之日起3个月内完成重新认定，将认定结果通知运营者，并通报国务院公安部门。
