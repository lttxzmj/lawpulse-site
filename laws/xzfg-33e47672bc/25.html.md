# 关键信息基础设施安全保护条例第二十五条

- 法规：关键信息基础设施安全保护条例（现行有效，施行日期 2021-09-01）
- 章节：第四章保障和促进
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-33e47672bc/25.html

保护工作部门应当按照国家网络安全事件应急预案的要求，建立健全本行业、本领域的网络安全事件应急预案，定期组织应急演练；指导运营者做好网络安全事件应对处置，并根据需要组织提供技术支持与协助。
