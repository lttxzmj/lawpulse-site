# 关键信息基础设施安全保护条例第三十二条

- 法规：关键信息基础设施安全保护条例（现行有效，施行日期 2021-09-01）
- 章节：第四章保障和促进
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-33e47672bc/32.html

国家采取措施，优先保障能源、电信等关键信息基础设施安全运行。
能源、电信行业应当采取措施，为其他行业和领域的关键信息基础设施安全运行提供重点保障。
