# 中华人民共和国期货和衍生品法第八十一条

- 法规：中华人民共和国期货和衍生品法（现行有效，施行日期 2022-08-01）
- 章节：第六章期货交易场所
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-c025646800/81.html

期货交易所应当在其名称中标明“商品交易所”或者“期货交易所”等字样。其他任何单位或者个人不得使用期货交易所或者其他可能产生混淆或者误导的名称。
