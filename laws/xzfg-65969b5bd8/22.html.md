# 中华人民共和国航标条例第二十二条

- 法规：中华人民共和国航标条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-65969b5bd8/22.html

违反本条例第十五条、第十六条、第十七条的规定，危害航标及其辅助设施或者影响航标工作效能的，由航标管理机关责令其限期改正，给予警告，可以并处2000元以下的罚款；造成损失的，应当依法赔偿。
