# 中华人民共和国航标条例第十六条

- 法规：中华人民共和国航标条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-65969b5bd8/16.html

禁止破坏航标辅助设施的行为。
前款所称航标辅助设施，是指为航标及其管理人员提供能源、水和其他所需物资而设置的各类设施，包括航标场地、直升机平台、登陆点、码头、趸船、水塔、储水池、水井、油(水)泵房、电力设施、业务用房以及专用道路、仓库等。
