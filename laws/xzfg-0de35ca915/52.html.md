# 期货交易管理条例第五十二条

- 法规：期货交易管理条例（现行有效）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0de35ca915/52.html

期货保证金安全存管监控机构依照有关规定对保证金安全实施监控，进行每日稽核，发现问题应当立即报告国务院期货监督管理机构。国务院期货监督管理机构应当根据不同情况，依照本条例有关规定及时处理。
