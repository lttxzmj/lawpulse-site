# 期货交易管理条例第二十三条

- 法规：期货交易管理条例（现行有效）
- 章节：第四章期货交易基本规则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0de35ca915/23.html

在期货交易所进行期货交易的，应当是期货交易所会员。
符合规定条件的境外机构，可以在期货交易所从事特定品种的期货交易。具体办法由国务院期货监督管理机构制定。
