# 最高人民法院关于审理非法出版物刑事案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理非法出版物刑事案件具体应用法律若干问题的解释（现行有效，施行日期 1998-12-23）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-fd623cbd8b/3.html

刑法第二百一十七条第（一）项中规定的“复制发行”，是指行为人以营利为目的，未经著作权人许可而实施的复制、发行或者既复制又发行其文字作品、音乐、电影、电视、录像作品、计算机软件及其他作品的行为。
