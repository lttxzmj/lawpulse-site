# 优化营商环境条例第二十二条

- 法规：优化营商环境条例（现行有效，施行日期 2020-01-01）
- 章节：第三章市场环境
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0504890178/22.html

国家建立健全统一开放、竞争有序的人力资源市场体系，打破城乡、地区、行业分割和身份、性别等歧视，促进人力资源有序社会性流动和合理配置。
