# 优化营商环境条例第二十三条

- 法规：优化营商环境条例（现行有效，施行日期 2020-01-01）
- 章节：第三章市场环境
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0504890178/23.html

政府及其有关部门应当完善政策措施、强化创新服务，鼓励和支持市场主体拓展创新空间，持续推进产品、技术、商业模式、管理等创新，充分发挥市场主体在推动科技成果转化中的作用。
