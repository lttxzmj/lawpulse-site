# 优化营商环境条例第五十八条

- 法规：优化营商环境条例（现行有效，施行日期 2020-01-01）
- 章节：第五章监管执法
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0504890178/58.html

行政执法机关应当按照国家有关规定，全面落实行政执法公示、行政执法全过程记录和重大行政执法决定法制审核制度，实现行政执法信息及时准确公示、行政执法全过程留痕和可回溯管理、重大行政执法决定法制审核全覆盖。
