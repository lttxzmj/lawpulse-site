# 优化营商环境条例第三十三条

- 法规：优化营商环境条例（现行有效，施行日期 2020-01-01）
- 章节：第三章市场环境
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0504890178/33.html

政府有关部门应当优化市场主体注销办理流程，精简申请材料、压缩办理时间、降低注销成本。对设立后未开展生产经营活动或者无债权债务的市场主体，可以按照简易程序办理注销。对有债权债务的市场主体，在债权债务依法解决后及时办理注销。
县级以上地方人民政府应当根据需要建立企业破产工作协调机制，协调解决企业破产过程中涉及的有关问题。
