# 优化营商环境条例第五十条

- 法规：优化营商环境条例（现行有效，施行日期 2020-01-01）
- 章节：第四章政务服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0504890178/50.html

新闻媒体应当及时、准确宣传优化营商环境的措施和成效，为优化营商环境创造良好舆论氛围。
国家鼓励对营商环境进行舆论监督，但禁止捏造虚假信息或者歪曲事实进行不实报道。
