# 中华人民共和国城镇集体所有制企业条例第五十六条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/56.html

集体企业有下列行为之一的，由工商行政管理机关依照国家有关法律、法规的规定给予行政处罚：
(一)登记时弄虚作假或者不按规定申请变更登记的；
(二)违反核准登记事项或者超越核准登记的经营范围从事经营活动的；
(三)利用分立、合并、终止和清算等行为抽逃资金、隐匿和私分财产的；
(四)其他违法行为。
