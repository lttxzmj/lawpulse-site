# 中华人民共和国城镇集体所有制企业条例第四十九条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第六章财产管理和收益分配
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/49.html

集体企业必须依照国家规定提取职工养老、待业等保险基金。职工养老、待业等保险基金按国家规定在征收所得税前提取，专项储存，专款专用。
