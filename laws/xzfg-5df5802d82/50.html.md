# 中华人民共和国城镇集体所有制企业条例第五十条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第七章集体企业和政府的关系
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/50.html

各级人民政府应当把发展城镇集体经济纳入各级政府的国民经济和社会发展计划，从各方面给予扶持和指导，保障城镇集体经济的健康发展。
