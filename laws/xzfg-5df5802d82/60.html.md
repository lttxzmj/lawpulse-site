# 中华人民共和国城镇集体所有制企业条例第六十条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/60.html

集体企业的领导人员或者政府有关部门的工作人员，因工作过失给企业造成损失的，由企业的上级管理机构或者政府有关部门按照干部的管理权限给予行政处分。
集体企业的领导人员和政府有关部门的工作人员玩忽职守，致使集体企业财产、利益遭受重大损失，构成犯罪的，依法追究刑事责任。
