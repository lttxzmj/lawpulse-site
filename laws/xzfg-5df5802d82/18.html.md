# 中华人民共和国城镇集体所有制企业条例第十八条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第二章集体企业的设立、变更和终止
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/18.html

集体企业终止，应当依照国家有关规定清算企业财产。企业财产按下列顺序清偿各种债务和费用：
(一)清算工作所需各项费用；
(二)所欠职工工资和劳动保险费用；
(三)所欠税款；
(四)所欠银行和信用合作社贷款以及其他债务。
不足清偿同一顺序的清偿要求的，按照比例分配。
