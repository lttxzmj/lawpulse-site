# 中华人民共和国城镇集体所有制企业条例第五十七条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/57.html

集体企业因生产、销售伪劣商品，给用户和消费者造成财产损失和人身伤害的，应当承担赔偿责任；构成犯罪的，对负有直接责任的集体企业领导人员和其他直接责任人员依法追究刑事责任。
