# 中华人民共和国城镇集体所有制企业条例第五十九条

- 法规：中华人民共和国城镇集体所有制企业条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5df5802d82/59.html

集体企业领导人员滥用职权，侵犯职工合法权益，情节严重的，由上级管理机构按照干部管理权限给予行政处分；滥用职权，假公济私，对职工进行报复陷害的，依法追究刑事责任。
