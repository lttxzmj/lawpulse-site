# 中华人民共和国城镇集体所有制企业条例第六十六条

- 数据核对至：2026-10-22

劳动就业服务性集体企业应当遵循本条例规定的原则，具体管理办法按国务院发布的《劳动就业服务企业管理规定》执行。
集中安置残疾人员的福利性集体企业的管理办法，根据本条例的原则另行制定。
