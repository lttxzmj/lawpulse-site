# 中华人民共和国河道管理条例第四十一条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第五章经费
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/41.html

任何单位和个人，凡对堤防、护岸和其他水工程设施造成损坏或者造成河道淤积的，由责任者负责修复、清淤或者承担维修费用。
