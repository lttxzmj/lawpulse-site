# 中华人民共和国河道管理条例第四十二条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第五章经费
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/42.html

河道主管机关收取的各项费用，用于河道堤防工程的建设、管理、维修和设施的更新改造。结余资金可以连年结转使用，任何部门不得截取或者挪用。
