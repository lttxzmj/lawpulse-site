# 中华人民共和国河道管理条例第二十条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/20.html

有堤防的河道，其管理范围为两岸堤防之间的水域、沙洲、滩地（包括可耕地）、行洪区，两岸堤防及护堤地。
无堤防的河道，其管理范围根据历史最高洪水位或者设计洪水位确定。
河道的具体管理范围，由县级以上地方人民政府负责划定。
