# 中华人民共和国河道管理条例第三十三条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/33.html

在河道中流放竹木，不得影响行洪、航运和水工程安全，并服从当地河道主管机关的安全管理。
在汛期，河道主管机关有权对河道上的竹木和其他漂流物进行紧急处置。
