# 中华人民共和国河道管理条例第二十七条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/27.html

禁止围湖造田。已经围垦的，应当按照国家规定的防洪标准进行治理，逐步退田还湖。湖泊的开发利用规划必须经河道主管机关审查同意。
禁止围垦河流，确需围垦的，必须经过科学论证，并经省级以上人民政府批准。
