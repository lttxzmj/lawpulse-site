# 中华人民共和国河道管理条例第三条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/3.html

开发利用江河湖泊水资源和防治水害，应当全面规划、统筹兼顾、综合利用、讲求效益，服从防洪的总体安排，促进各项事业的发展。
