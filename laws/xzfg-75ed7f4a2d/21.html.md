# 中华人民共和国河道管理条例第二十一条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/21.html

在河道管理范围内，水域和土地的利用应当符合江河行洪、输水和航运的要求；滩地的利用，应当由河道主管机关会同土地管理等有关部门制定规划，报县级以上地方人民政府批准后实施。
