# 中华人民共和国河道管理条例第二十五条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/25.html

在河道管理范围内进行下列活动，必须报经河道主管机关批准；涉及其他部门的，由河道主管机关会同有关部门批准：
（一）采砂、取土、淘金、弃置砂石或者淤泥；
（二）爆破、钻探、挖筑鱼塘；
（三）在河道滩地存放物料、修建厂房或者其他建筑设施；
（四）在河道滩地开采地下资源及进行考古发掘。
