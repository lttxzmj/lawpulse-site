# 中华人民共和国河道管理条例第十九条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第二章河道整治与建设
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/19.html

省、自治区、直辖市以河道为边界的，在河道两岸外侧各10公里之内，以及跨省、自治区、直辖市的河道，未经有关各方达成协议或者国务院水利行政主管部门批准，禁止单方面修建排水、阻水、引水、蓄水工程以及河道整治工程。
