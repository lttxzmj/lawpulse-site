# 中华人民共和国河道管理条例第二十二条

- 法规：中华人民共和国河道管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章河道保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-75ed7f4a2d/22.html

禁止损毁堤防、护岸、闸坝等水工程建筑物和防汛设施、水文监测和测量设施、河岸地质监测设施以及通信照明等设施。
在防汛抢险期间，无关人员和车辆不得上堤。
因降雨雪等造成堤顶泥泞期间，禁止车辆通行，但防汛抢险车辆除外。
