# 最高人民法院关于适用《中华人民共和国民法典》合同编通则若干问题的解释第六十四条

- 法规：最高人民法院关于适用《中华人民共和国民法典》合同编通则若干问题的解释（现行有效，施行日期 2023-12-05）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-hetong/64.html

当事人一方通过反诉或者抗辩的方式，请求调整违约金的，人民法院依法予以支持。
违约方主张约定的违约金过分高于违约造成的损失，请求予以适当减少的，应当承担举证责任。非违约方主张约定的违约金合理的，也应当提供相应的证据。
当事人仅以合同约定不得对违约金进行调整为由主张不予调整违约金的，人民法院不予支持。
