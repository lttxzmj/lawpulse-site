# 征信业管理条例第二十八条

- 法规：征信业管理条例（现行有效）
- 章节：第五章金融信用信息基础数据库
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02efae68de/28.html

金融信用信息基础数据库接收从事信贷业务的机构按照规定提供的信贷信息。
金融信用信息基础数据库为信息主体和取得信息主体本人书面同意的信息使用者提供查询服务。国家机关可以依法查询金融信用信息基础数据库的信息。
