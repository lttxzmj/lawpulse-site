# 对外劳务合作管理条例第八条

- 法规：对外劳务合作管理条例（现行有效）
- 章节：第二章从事对外劳务合作的企业与劳务人员
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be1e7a35fd/8.html

对外劳务合作企业不得允许其他单位或者个人以本企业的名义组织劳务人员赴国外工作。
任何单位和个人不得以商务、旅游、留学等名义组织劳务人员赴国外工作。
