# 对外劳务合作管理条例第三条

国家鼓励和支持依法开展对外劳务合作，提高对外劳务合作水平，维护劳务人员的合法权益。
国务院有关部门制定和完善促进对外劳务合作发展的政策措施，建立健全对外劳务合作服务体系以及风险防范和处置机制。
