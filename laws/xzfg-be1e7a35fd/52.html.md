# 对外劳务合作管理条例第五十二条

- 法规：对外劳务合作管理条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be1e7a35fd/52.html

本条例施行前按照国家有关规定经批准从事对外劳务合作的企业，不具备本条例规定条件的，应当在国务院商务主管部门规定的期限内达到本条例规定的条件；逾期达不到本条例规定条件的，不得继续从事对外劳务合作。
