# 对外劳务合作管理条例第五十一条

- 法规：对外劳务合作管理条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be1e7a35fd/51.html

对外劳务合作企业组织劳务人员赴国务院商务主管部门会同国务院外交等有关部门确定的特定国家或者地区工作的，应当经国务院商务主管部门会同国务院有关部门批准。
