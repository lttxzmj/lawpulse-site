# 对外劳务合作管理条例第三十九条

- 法规：对外劳务合作管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be1e7a35fd/39.html

未依法取得对外劳务合作经营资格，从事对外劳务合作的，由商务主管部门提请工商行政管理部门依照《无照经营查处取缔办法》的规定查处取缔；构成犯罪的，依法追究刑事责任。
