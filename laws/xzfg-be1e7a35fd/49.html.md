# 对外劳务合作管理条例第四十九条

- 法规：对外劳务合作管理条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be1e7a35fd/49.html

对外承包工程项下外派人员赴国外工作的管理，依照《对外承包工程管理条例》以及国务院商务主管部门、国务院住房城乡建设主管部门的规定执行。
外派海员类(不含渔业船员)对外劳务合作的管理办法，由国务院交通运输主管部门根据《中华人民共和国船员条例》以及本条例的有关规定另行制定。
