# 劳动就业服务企业管理规定第十七条

- 法规：劳动就业服务企业管理规定（现行有效）
- 章节：第四章劳动就业服务企业的内部管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca36f929fb/17.html

劳动就业服务企业应当按照灵活方便、合同管理、骨干稳定、合理流动的原则，自主选择用工形式。
从业人员在劳动就业服务企业工作期间应当计算工龄。
