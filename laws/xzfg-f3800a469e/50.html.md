# 军人抚恤优待条例第五十条

- 法规：军人抚恤优待条例（现行有效，施行日期 2024-10-01）
- 章节：第四章优待
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3800a469e/50.html

退出现役后，在机关、群团组织、企业事业单位和社会组织工作的残疾军人，享受与所在单位工伤人员同等的生活福利和医疗待遇。所在单位不得因其残疾将其辞退、解除聘用合同或者劳动合同。
