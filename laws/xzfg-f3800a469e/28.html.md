# 军人抚恤优待条例第二十八条

- 法规：军人抚恤优待条例（现行有效，施行日期 2024-10-01）
- 章节：第三章军人残疾抚恤
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3800a469e/28.html

因战、因公、因病致残性质的认定和残疾等级的评定权限是：
（一）义务兵和初级军士的残疾，由军队军级以上单位卫生部门会同相关部门认定和评定；
（二）军官、中级以上军士的残疾，由军队战区级以上单位卫生部门会同相关部门认定和评定；
（三）退出现役的军人和移交政府安置的军队离休退休干部、退休军士需要认定残疾性质和评定残疾等级的，由省级人民政府退役军人工作主管部门认定和评定。
评定残疾等级，应当依据医疗卫生专家小组出具的残疾等级医学鉴定意见。
残疾军人由认定残疾性质和评定残疾等级的机关发给《中华人民共和国残疾军人证》。
