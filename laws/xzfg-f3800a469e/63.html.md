# 军人抚恤优待条例第六十三条

- 法规：军人抚恤优待条例（现行有效，施行日期 2024-10-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3800a469e/63.html

深化国防和军队改革期间现役军人转改的文职人员，按照本条例有关军人抚恤优待的规定执行。
其他文职人员因在作战和有作战背景的军事行动中承担支援保障任务、参加非战争军事行动以及军级以上单位批准且列入军事训练计划的军事训练伤亡的抚恤优待，参照本条例的有关规定办理。
