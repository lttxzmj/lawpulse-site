# 军人抚恤优待条例第三十七条

- 法规：军人抚恤优待条例（现行有效，施行日期 2024-10-01）
- 章节：第四章优待
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3800a469e/37.html

国家完善抚恤优待对象表彰、奖励办法，构建精神与物质并重的荣誉激励制度体系，建立抚恤优待对象荣誉激励机制，健全邀请参加重大庆典活动、开展典型宣传、悬挂光荣牌、制发优待证、送喜报、载入地方志、组织短期疗养等政策制度。
