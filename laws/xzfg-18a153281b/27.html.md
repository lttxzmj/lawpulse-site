# 中华人民共和国濒危野生动植物进出口管理条例第二十七条

- 法规：中华人民共和国濒危野生动植物进出口管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-18a153281b/27.html

伪造、倒卖或者转让进出口批准文件或者允许进出口证明书的，由野生动植物主管部门或者市场监督管理部门按照职责分工依法予以处罚；情节严重，构成犯罪的，依法追究刑事责任。
