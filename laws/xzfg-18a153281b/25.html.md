# 中华人民共和国濒危野生动植物进出口管理条例第二十五条

- 法规：中华人民共和国濒危野生动植物进出口管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-18a153281b/25.html

国家濒危物种进出口科学机构的工作人员，利用职务上的便利收取他人财物或者谋取其他利益，出具虚假意见，情节严重，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予处分。
