# 中华人民共和国濒危野生动植物进出口管理条例第八条

- 法规：中华人民共和国濒危野生动植物进出口管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-18a153281b/8.html

进口濒危野生动植物及其产品的，必须具备下列条件：
(一)对濒危野生动植物及其产品的使用符合国家有关规定；
(二)具有有效控制措施并符合生态安全要求；
(三)申请人提供的材料真实有效；
(四)国务院野生动植物主管部门公示的其他条件。
