# 中华人民共和国濒危野生动植物进出口管理条例第二十二条

- 法规：中华人民共和国濒危野生动植物进出口管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-18a153281b/22.html

国家濒危物种进出口管理机构应当将核发允许进出口证明书的有关资料和濒危野生动植物及其产品年度进出口情况，及时抄送国务院野生动植物主管部门及其他有关主管部门。
