# 城镇燃气管理条例第二十八条

- 法规：城镇燃气管理条例（现行有效）
- 章节：第四章燃气使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4ea6b420e9/28.html

燃气用户及相关单位和个人不得有下列行为：
(一)擅自操作公用燃气阀门；
(二)将燃气管道作为负重支架或者接地引线；
(三)安装、使用不符合气源要求的燃气燃烧器具；
(四)擅自安装、改装、拆除户内燃气设施和燃气计量装置；
(五)在不具备安全条件的场所使用、储存燃气；
(六)盗用燃气；
(七)改变燃气用途或者转供燃气。
