# 城镇燃气管理条例第三十二条

- 法规：城镇燃气管理条例（现行有效）
- 章节：第四章燃气使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4ea6b420e9/32.html

燃气燃烧器具生产单位、销售单位应当设立或者委托设立售后服务站点，配备经考核合格的燃气燃烧器具安装、维修人员，负责售后的安装、维修服务。
燃气燃烧器具的安装、维修，应当符合国家有关标准。
