# 城镇燃气管理条例第三十四条

- 法规：城镇燃气管理条例（现行有效）
- 章节：第五章燃气设施保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4ea6b420e9/34.html

在燃气设施保护范围内，有关单位从事敷设管道、打桩、顶进、挖掘、钻探等可能影响燃气设施安全活动的，应当与燃气经营者共同制定燃气设施保护方案，并采取相应的安全保护措施。
