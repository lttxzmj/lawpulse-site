# 私募投资基金监督管理条例第五十条

- 法规：私募投资基金监督管理条例（现行有效，施行日期 2023-09-01）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-11532af5e7/50.html

违反本条例第二十二条第一款规定，私募基金管理人未对募集完毕的私募基金办理备案的，处10万元以上30万元以下的罚款。对直接负责的主管人员和其他直接责任人员给予警告，并处3万元以上10万元以下的罚款。
