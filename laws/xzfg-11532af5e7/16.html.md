# 私募投资基金监督管理条例第十六条

- 法规：私募投资基金监督管理条例（现行有效，施行日期 2023-09-01）
- 章节：第二章私募基金管理人和私募基金托管人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-11532af5e7/16.html

私募基金财产进行托管的，私募基金托管人应当依法履行职责。
私募基金托管人应当依法建立托管业务和其他业务的隔离机制，保证私募基金财产的独立和安全。
