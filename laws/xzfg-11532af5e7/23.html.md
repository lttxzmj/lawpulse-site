# 私募投资基金监督管理条例第二十三条

- 法规：私募投资基金监督管理条例（现行有效，施行日期 2023-09-01）
- 章节：第三章资金募集和投资运作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-11532af5e7/23.html

国务院证券监督管理机构应当建立健全私募基金监测机制，对私募基金及其投资者份额持有情况等进行集中监测，具体办法由国务院证券监督管理机构规定。
