# 中华人民共和国房产税暂行条例第三条

- 法规：中华人民共和国房产税暂行条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2da8931ae1/3.html

房产税依照房产原值一次减除10%至30%后的余值计算缴纳。具体减除幅度，由省、自治区、直辖市人民政府规定。
没有房产原值作为依据的，由房产所在地税务机关参考同类房产核定。
房产出租的，以房产租金收入为房产税的计税依据。
