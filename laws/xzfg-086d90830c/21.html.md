# 乡村医生从业管理条例第二十一条

- 法规：乡村医生从业管理条例（现行有效）
- 章节：第二章执业注册
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-086d90830c/21.html

村民和乡村医生发现违法办理乡村医生执业注册、再注册、注销注册的，可以向有关人民政府卫生行政主管部门反映；有关人民政府卫生行政主管部门对反映的情况应当及时核实，调查处理，并将调查处理结果予以公布。
