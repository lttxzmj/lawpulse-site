# 最高人民法院关于具有专门知识的人民陪审员参加环境资源案件审理的若干规定第三条

- 法规：最高人民法院关于具有专门知识的人民陪审员参加环境资源案件审理的若干规定（现行有效，施行日期 2023-08-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-68aaed622d/3.html

人民法院参与人民陪审员选任，可以根据环境资源审判活动需要，结合案件类型、数量等特点，协商司法行政机关确定一定数量具有专门知识的人民陪审员候选人。
