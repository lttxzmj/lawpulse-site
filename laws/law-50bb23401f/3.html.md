# 中华人民共和国能源法第三条

- 法规：中华人民共和国能源法（现行有效，施行日期 2025-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-50bb23401f/3.html

能源工作应当坚持中国共产党的领导，贯彻新发展理念和总体国家安全观，统筹发展和安全，实施推动能源消费革命、能源供给革命、能源技术革命、能源体制革命和全方位加强国际合作的能源安全新战略，坚持立足国内、多元保障、节约优先、绿色发展，加快构建清洁低碳、安全高效的新型能源体系。
