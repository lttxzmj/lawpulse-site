# 节约用水条例第二十六条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第三章节水措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/26.html

国家加快推进农村生活节水。
县级以上地方人民政府及其有关部门应当加强农村生活供水设施以及配套管网建设和改造，推广使用生活节水器具。
