# 节约用水条例第三十九条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第四章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/39.html

国家鼓励金融机构提供多种形式的节水金融服务，引导金融机构加大对节水项目的融资支持力度。
国家鼓励和引导社会资本按照市场化原则依法参与节水项目建设和运营，保护其合法权益。
