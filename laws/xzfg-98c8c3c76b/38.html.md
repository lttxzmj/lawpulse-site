# 节约用水条例第三十八条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第四章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/38.html

县级以上地方人民政府应当健全与节水成效、农业水价水平、财力状况相匹配的农业用水精准补贴机制和节水奖励机制。
对符合条件的节水项目，按照国家有关规定给予补助。
