# 节约用水条例第二十三条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第三章节水措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/23.html

县级以上人民政府及其有关部门应当根据经济社会发展水平和水资源状况，引导农业生产经营主体合理调整种植养殖结构和农业用水结构，积极发展节水型农业，因地制宜发展旱作农业。
国家对水资源短缺地区发展节水型农业给予重点扶持。
