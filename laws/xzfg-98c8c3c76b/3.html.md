# 节约用水条例第三条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/3.html

节水工作应当坚持中国共产党的领导，贯彻总体国家安全观，统筹发展和安全，遵循统筹规划、综合施策、因地制宜、分类指导的原则，坚持总量控制、科学配置、高效利用，坚持约束和激励相结合，建立政府主导、各方协同、市场调节、公众参与的节水机制。
