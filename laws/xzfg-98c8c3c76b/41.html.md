# 节约用水条例第四十一条

- 法规：节约用水条例（现行有效，施行日期 2024-05-01）
- 章节：第四章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-98c8c3c76b/41.html

国家培育和规范水权市场，支持开展多种形式的水权交易，健全水权交易系统，引导开展集中交易，完善水权交易规则，并逐步将水权交易纳入公共资源交易平台体系。
