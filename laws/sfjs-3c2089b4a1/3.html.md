# 最高人民法院关于行政机关负责人出庭应诉若干问题的规定第三条

- 法规：最高人民法院关于行政机关负责人出庭应诉若干问题的规定（现行有效，施行日期 2020-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3c2089b4a1/3.html

有共同被告的行政案件，可以由共同被告协商确定行政机关负责人出庭应诉；也可以由人民法院确定。
