# 最高人民法院关于证券纠纷代表人诉讼若干问题的规定第三十七条

- 法规：最高人民法院关于证券纠纷代表人诉讼若干问题的规定（现行有效，施行日期 2020-07-31）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-40b8c51584/37.html

针对同一代表人诉讼，原则上应当由一个投资者保护机构作为代表人参加诉讼。两个以上的投资者保护机构分别受五十名以上投资者委托，且均决定作为代表人参加诉讼的，应当协商处理；协商不成的，由人民法院指定其中一个作为代表人参加诉讼。
