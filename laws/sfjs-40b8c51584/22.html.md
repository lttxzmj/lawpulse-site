# 最高人民法院关于证券纠纷代表人诉讼若干问题的规定第二十二条

- 法规：最高人民法院关于证券纠纷代表人诉讼若干问题的规定（现行有效，施行日期 2020-07-31）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-40b8c51584/22.html

代表人变更或者放弃诉讼请求、承认对方当事人诉讼请求、决定撤诉的，应当向人民法院提交书面申请，并通知全体原告。人民法院收到申请后，应当根据原告所提异议情况，依法裁定是否准许。
对于代表人依据前款规定提交的书面申请，原告自收到通知之日起十日内未提出异议的，人民法院可以裁定准许。
