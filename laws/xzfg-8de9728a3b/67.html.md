# 社会救助暂行办法第六十七条

- 法规：社会救助暂行办法（现行有效）
- 章节：第十二章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8de9728a3b/67.html

违反本办法规定，截留、挤占、挪用、私分社会救助资金、物资的，由有关部门责令追回；有违法所得的，没收违法所得；对直接负责的主管人员和其他直接责任人员依法给予处分。
