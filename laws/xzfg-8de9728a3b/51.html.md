# 社会救助暂行办法第五十一条

- 法规：社会救助暂行办法（现行有效）
- 章节：第九章临时救助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8de9728a3b/51.html

公安机关和其他有关行政机关的工作人员在执行公务时发现流浪、乞讨人员的，应当告知其向救助管理机构求助。对其中的残疾人、未成年人、老年人和行动不便的其他人员，应当引导、护送到救助管理机构；对突发急病人员，应当立即通知急救机构进行救治。
