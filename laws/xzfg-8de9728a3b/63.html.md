# 社会救助暂行办法第六十三条

- 法规：社会救助暂行办法（现行有效）
- 章节：第十一章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8de9728a3b/63.html

履行社会救助职责的工作人员行使职权，应当接受社会监督。
任何单位、个人有权对履行社会救助职责的工作人员在社会救助工作中的违法行为进行举报、投诉。受理举报、投诉的机关应当及时核实、处理。
