# 社会救助暂行办法第二十二条

- 法规：社会救助暂行办法（现行有效）
- 章节：第四章受灾人员救助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8de9728a3b/22.html

自然灾害发生后，县级以上人民政府或者人民政府的自然灾害救助应急综合协调机构应当根据情况紧急疏散、转移、安置受灾人员，及时为受灾人员提供必要的食品、饮用水、衣被、取暖、临时住所、医疗防疫等应急救助。
