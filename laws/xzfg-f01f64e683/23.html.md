# 重大行政决策程序暂行条例第二十三条

- 法规：重大行政决策程序暂行条例（现行有效）
- 章节：第二章决策草案的形成 · 第四节风险评估
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f01f64e683/23.html

开展风险评估，可以通过舆情跟踪、重点走访、会商分析等方式，运用定性分析与定量分析等方法，对决策实施的风险进行科学预测、综合研判。
开展风险评估，应当听取有关部门的意见，形成风险评估报告，明确风险点，提出风险防范措施和处置预案。
开展风险评估，可以委托专业机构、社会组织等第三方进行。
