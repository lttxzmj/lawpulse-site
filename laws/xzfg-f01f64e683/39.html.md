# 重大行政决策程序暂行条例第三十九条

- 法规：重大行政决策程序暂行条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f01f64e683/39.html

决策承办单位或者承担决策有关工作的单位未按照本条例规定履行决策程序或者履行决策程序时失职渎职、弄虚作假的，由决策机关责令改正，对负有责任的领导人员和直接责任人员依法追究责任。
