# 中华人民共和国水生野生动物保护实施条例第七条

- 法规：中华人民共和国水生野生动物保护实施条例（现行有效）
- 章节：第二章水生野生动物保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf2f79cbe4/7.html

渔业行政主管部门应当组织社会各方面力量，采取有效措施，维护和改善水生野生动物的生存环境，保护和增殖水生野生动物资源。
禁止任何单位和个人破坏国家重点保护的和地方重点保护的水生野生动物生息繁衍的水域、场所和生存条件。
