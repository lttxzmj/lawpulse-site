# 中华人民共和国水生野生动物保护实施条例第二十八条

- 法规：中华人民共和国水生野生动物保护实施条例（现行有效）
- 章节：第四章奖励和惩罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf2f79cbe4/28.html

违反野生动物保护法律、法规，出售、收购、运输、携带国家重点保护的或者地方重点保护的水生野生动物或者其产品的，由工商行政管理部门或者其授权的渔业行政主管部门没收实物和违法所得，可以并处相当于实物价值10倍以下的罚款。
