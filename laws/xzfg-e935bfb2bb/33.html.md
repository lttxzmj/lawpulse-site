# 票据管理实施办法第三十三条

- 法规：票据管理实施办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e935bfb2bb/33.html

票据的付款人对见票即付或者到期的票据，故意压票、拖延支付的，由中国人民银行处以压票、拖延支付期间内每日票据金额0.7‰的罚款；对直接负责的主管人员和其他直接责任人员给予警告、记过、撤职或者开除的处分。
