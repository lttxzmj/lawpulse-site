# 票据管理实施办法第二十八条

- 法规：票据管理实施办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e935bfb2bb/28.html

票据法第六十三条规定的“其他有关证明”是指：
(一)医院或者有关单位出具的承兑人、付款人死亡的证明；
(二)司法机关出具的承兑人、付款人逃匿的证明；
(三)公证机关出具的具有拒绝证明效力的文书。
