# 国务院关于加强食品等产品安全监督管理的特别规定第十六条

- 法规：国务院关于加强食品等产品安全监督管理的特别规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-89f829d370/16.html

农业、卫生、质检、商务、工商、药品等监督管理部门应当建立生产经营者违法行为记录制度，对违法行为的情况予以记录并公布；对有多次违法行为记录的生产经营者，吊销许可证照。
