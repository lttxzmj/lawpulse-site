# 农药管理条例第六十四条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/64.html

生产、经营的农药造成农药使用者人身、财产损害的，农药使用者可以向农药生产企业要求赔偿，也可以向农药经营者要求赔偿。属于农药生产企业责任的，农药经营者赔偿后有权向农药生产企业追偿；属于农药经营者责任的，农药生产企业赔偿后有权向农药经营者追偿。
