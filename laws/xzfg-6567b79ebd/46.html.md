# 农药管理条例第四十六条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/46.html

假农药、劣质农药和回收的农药废弃物等应当交由具有危险废物经营资质的单位集中处置，处置费用由相应的农药生产企业、农药经营者承担；农药生产企业、农药经营者不明确的，处置费用由所在地县级人民政府财政列支。
