# 农药管理条例第二十三条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第三章农药生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/23.html

农药生产企业不得擅自改变经核准的农药的标签内容，不得在农药的标签中标注虚假、误导使用者的内容。
农药包装过小，标签不能标注全部内容的，应当同时附具说明书，说明书的内容应当与经核准的标签内容一致。
