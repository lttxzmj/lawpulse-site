# 农药管理条例第四十四条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/44.html

有下列情形之一的，认定为假农药：
（一）以非农药冒充农药；
（二）以此种农药冒充他种农药；
（三）农药所含有效成分种类与农药的标签、说明书标注的有效成分不符。
禁用的农药，未依法取得农药登记证而生产、进口的农药，以及未附具标签的农药，按照假农药处理。
