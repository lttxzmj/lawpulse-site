# 农药管理条例第三十九条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章农药使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/39.html

因防治突发重大病虫害等紧急需要，国务院农业主管部门可以决定临时生产、使用规定数量的未取得登记或者禁用、限制使用的农药，必要时应当会同国务院对外贸易主管部门决定临时限制出口或者临时进口规定数量、品种的农药。
前款规定的农药，应当在使用地县级人民政府农业主管部门的监督和指导下使用。
