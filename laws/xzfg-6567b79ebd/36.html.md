# 农药管理条例第三十六条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章农药使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/36.html

农产品生产企业、食品和食用农产品仓储企业、专业化病虫害防治服务组织和从事农产品生产的农民专业合作社等应当建立农药使用记录，如实记录使用农药的时间、地点、对象以及农药名称、用量、生产企业等。农药使用记录应当保存2年以上。
国家鼓励其他农药使用者建立农药使用记录。
