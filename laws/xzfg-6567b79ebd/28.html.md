# 农药管理条例第二十八条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第四章农药经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/28.html

农药经营者不得加工、分装农药，不得在农药中添加任何物质，不得采购、销售包装和标签不符合规定，未附具产品质量检验合格证，未取得有关许可证明文件的农药。
经营卫生用农药的，应当将卫生用农药与其他商品分柜销售；经营其他农药的，不得在农药经营场所内经营食品、食用农产品、饲料等。
