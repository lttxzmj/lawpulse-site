# 农药管理条例第三十七条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章农药使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/37.html

国家鼓励农药使用者妥善收集农药包装物等废弃物；农药生产企业、农药经营者应当回收农药废弃物，防止农药污染环境和农药中毒事故的发生。具体办法由国务院环境保护主管部门会同国务院农业主管部门、国务院财政部门等部门制定。
