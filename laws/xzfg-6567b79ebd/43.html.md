# 农药管理条例第四十三条

- 法规：农药管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6567b79ebd/43.html

国务院农业主管部门和省、自治区、直辖市人民政府农业主管部门应当组织负责农药检定工作的机构、植物保护机构对已登记农药的安全性和有效性进行监测。
发现已登记农药对农业、林业、人畜安全、农产品质量安全、生态环境等有严重危害或者较大风险的，国务院农业主管部门应当组织农药登记评审委员会进行评审，根据评审结果撤销、变更相应的农药登记证，必要时应当决定禁用或者限制使用并予以公告。
