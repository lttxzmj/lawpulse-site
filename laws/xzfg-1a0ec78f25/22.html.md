# 建设工程抗震管理条例第二十二条

- 法规：建设工程抗震管理条例（现行有效，施行日期 2021-09-01）
- 章节：第三章鉴定、加固和维护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1a0ec78f25/22.html

抗震加固应当依照《建设工程质量管理条例》等规定执行，并符合抗震设防强制性标准。
竣工验收合格后，应当通过信息化手段或者在建设工程显著部位设置永久性标牌等方式，公示抗震加固时间、后续使用年限等信息。
