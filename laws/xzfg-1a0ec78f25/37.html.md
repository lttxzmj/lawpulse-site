# 建设工程抗震管理条例第三十七条

- 法规：建设工程抗震管理条例（现行有效，施行日期 2021-09-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1a0ec78f25/37.html

县级以上人民政府住房和城乡建设主管部门或者其他有关监督管理部门应当建立建设工程抗震责任企业及从业人员信用记录制度，将相关信用记录纳入全国信用信息共享平台。
