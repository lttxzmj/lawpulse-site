# 建设工程抗震管理条例第十一条

- 法规：建设工程抗震管理条例（现行有效，施行日期 2021-09-01）
- 章节：第二章勘察、设计和施工
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1a0ec78f25/11.html

建设工程勘察文件中应当说明抗震场地类别，对场地地震效应进行分析，并提出工程选址、不良地质处置等建议。
建设工程设计文件中应当说明抗震设防烈度、抗震设防类别以及拟采用的抗震设防措施。采用隔震减震技术的建设工程，设计文件中应当对隔震减震装置技术性能、检验检测、施工安装和使用维护等提出明确要求。
