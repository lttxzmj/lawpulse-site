# 建设工程抗震管理条例第四十二条

- 法规：建设工程抗震管理条例（现行有效，施行日期 2021-09-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1a0ec78f25/42.html

违反本条例规定，施工单位在施工中未按照抗震设防强制性标准进行施工的，责令改正，处工程合同价款2%以上4%以下的罚款；造成建设工程不符合抗震设防强制性标准的，负责返工、加固，并赔偿因此造成的损失；情节严重的，责令停业整顿，降低资质等级或者吊销资质证书。
