# 建设工程抗震管理条例第三十四条

- 法规：建设工程抗震管理条例（现行有效，施行日期 2021-09-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1a0ec78f25/34.html

县级以上人民政府住房和城乡建设主管部门和其他有关监督管理部门应当按照职责分工，加强对建设工程抗震设防强制性标准执行情况的监督检查。
县级以上人民政府住房和城乡建设主管部门应当会同有关部门建立完善建设工程抗震设防数据信息库，并与应急管理、地震等部门实时共享数据。
