# 建设工程勘察设计管理条例第十六条

- 法规：建设工程勘察设计管理条例（现行有效）
- 章节：第三章建设工程勘察设计发包与承包
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b4fe59ac9d/16.html

下列建设工程的勘察、设计，经有关主管部门批准，可以直接发包：
(一)采用特定的专利或者专有技术的；
(二)建筑艺术造型有特殊要求的；
(三)国务院规定的其他建设工程的勘察、设计。
