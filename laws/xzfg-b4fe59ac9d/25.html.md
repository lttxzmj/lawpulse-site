# 建设工程勘察设计管理条例第二十五条

- 法规：建设工程勘察设计管理条例（现行有效）
- 章节：第四章建设工程勘察设计文件的编制与实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b4fe59ac9d/25.html

编制建设工程勘察、设计文件，应当以下列规定为依据：
(一)项目批准文件；
(二)城乡规划；
(三)工程建设强制性标准；
(四)国家规定的建设工程勘察、设计深度要求。
铁路、交通、水利等专业建设工程，还应当以专业规划的要求为依据。
