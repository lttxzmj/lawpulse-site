# 建设工程勘察设计管理条例第十九条

- 法规：建设工程勘察设计管理条例（现行有效）
- 章节：第三章建设工程勘察设计发包与承包
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b4fe59ac9d/19.html

除建设工程主体部分的勘察、设计外，经发包方书面同意，承包方可以将建设工程其他部分的勘察、设计再分包给其他具有相应资质等级的建设工程勘察、设计单位。
