# 建设工程勘察设计管理条例第四十三条

- 法规：建设工程勘察设计管理条例（现行有效）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b4fe59ac9d/43.html

国家机关工作人员在建设工程勘察、设计活动的监督管理工作中玩忽职守、滥用职权、徇私舞弊，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予行政处分。
