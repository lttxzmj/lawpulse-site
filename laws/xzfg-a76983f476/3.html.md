# 征收教育费附加的暂行规定第三条

- 法规：征收教育费附加的暂行规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a76983f476/3.html

教育费附加，以各单位和个人实际缴纳的增值税、营业税、消费税的税额为计征依据，教育费附加率为3%，分别与增值税、营业税、消费税同时缴纳。
除国务院另有规定者外，任何地区、部门不得擅自提高或者降低教育费附加率。
