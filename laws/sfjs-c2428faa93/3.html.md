# 最高人民法院关于审理房屋登记案件若干问题的规定第三条

- 法规：最高人民法院关于审理房屋登记案件若干问题的规定（现行有效，施行日期 2010-11-18）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c2428faa93/3.html

公民、法人或者其他组织对房屋登记行为不服提起行政诉讼的，不受下列情形的影响：
（一）房屋灭失；
（二）房屋登记行为已被登记机构改变；
（三）生效法律文书将房屋权属证书、房屋登记簿或者房屋登记证明作为定案证据采用。
