# 长江三峡工程建设移民条例第四十一条

- 法规：长江三峡工程建设移民条例（现行有效）
- 章节：第四章移民资金使用的管理和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25a11e26ca/41.html

国家对移民资金的管理、拨付和安排使用实行稽察制度，对管理、拨付和安排使用移民资金的有关地方人民政府及其有关部门、机构的负责人实行任期经济责任审计制度。
