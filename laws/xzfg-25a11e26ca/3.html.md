# 长江三峡工程建设移民条例第三条

- 法规：长江三峡工程建设移民条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25a11e26ca/3.html

三峡工程建设，实行开发性移民方针，统筹使用移民资金，合理开发资源，保护生态环境，妥善安置移民，使移民的生产、生活达到或者超过原有水平，为三峡库区经济和社会发展创造条件。
