# 长江三峡工程建设移民条例第六十条

- 法规：长江三峡工程建设移民条例（现行有效）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25a11e26ca/60.html

违反本条例规定，在国务院三峡工程建设委员会移民管理机构或者省、自治区、直辖市人民政府移民管理机构指定的银行之外的金融机构存储移民资金的，由县级以上人民政府移民管理机构按照职责分工，责令限期改正，给予警告；对直接负责的主管人员和其他直接责任人员，依法给予行政处分；有违法所得的，没收违法所得，并处违法所得1倍以上3倍以下的罚款。
