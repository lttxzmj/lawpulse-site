# 全国中小学勤工俭学暂行工作条例第二十三条

- 法规：全国中小学勤工俭学暂行工作条例（现行有效）
- 章节：第六章组织领导
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d9b837472/23.html

各级教育行政部门可根据本地区的实际情况，建立健全勤工俭学的管理机构。根据需要还可设立专业公司。
农村中心校应有专人负责勤工俭学的管理工作。
