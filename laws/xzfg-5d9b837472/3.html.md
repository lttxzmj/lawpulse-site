# 全国中小学勤工俭学暂行工作条例第三条

- 法规：全国中小学勤工俭学暂行工作条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d9b837472/3.html

要从实际出发，因地制宜地积极开展多种形式的勤工俭学活动，要坚持社会主义方向和自力更生、艰苦创业的精神，根据当地的自然条件和学校的可能，宜工则工、宜农则农(含林、牧、副、渔)，为教学和科研服务，为生产服务，为人民生活服务，有条件的也要为外贸出口服务。
