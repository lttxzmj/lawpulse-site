# 全国中小学勤工俭学暂行工作条例第二十一条

- 法规：全国中小学勤工俭学暂行工作条例（现行有效）
- 章节：第五章劳动工资
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d9b837472/21.html

学校派到校办工厂、农场的教职工，仍属学校事业编制。长期从事校办厂(场)工作，具有一定技术专长的教职工，可按技术人员评定职称标准，按规定经过考核，授予技术职称。
