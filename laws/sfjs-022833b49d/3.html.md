# 最高人民法院关于办理人身安全保护令案件适用法律若干问题的规定第三条

- 法规：最高人民法院关于办理人身安全保护令案件适用法律若干问题的规定（现行有效，施行日期 2022-08-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-022833b49d/3.html

家庭成员之间以冻饿或者经常性侮辱、诽谤、威胁、跟踪、骚扰等方式实施的身体或者精神侵害行为,应当认定为反家庭暴力法第二条规定的“家庭暴力”。
