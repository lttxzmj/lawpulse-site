# 快递暂行条例第二十六条

- 法规：快递暂行条例（现行有效，施行日期 2026-08-15）
- 章节：第四章快递服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da0af852ff/26.html

经营快递业务的企业应当将快件投递到约定的收件地址、收件人或者收件人指定的代收人，并告知收件人或者代收人当面验收。收件人或者代收人有权当面验收。
