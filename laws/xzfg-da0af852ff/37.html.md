# 快递暂行条例第三十七条

- 法规：快递暂行条例（现行有效，施行日期 2026-08-15）
- 章节：第六章快递包装
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da0af852ff/37.html

快递包装应当符合寄递生产作业的要求，节约使用资源，避免过度包装，防止污染环境。
国务院标准化行政主管部门和国务院邮政管理等部门按照职责分工组织制定快递包装的国家标准、行业标准。快递包装应当符合强制性国家标准。
