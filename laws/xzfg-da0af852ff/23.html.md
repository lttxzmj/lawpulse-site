# 快递暂行条例第二十三条

- 法规：快递暂行条例（现行有效，施行日期 2026-08-15）
- 章节：第四章快递服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-da0af852ff/23.html

寄件人交寄快件，应当如实提供以下事项：
（一）寄件人姓名、地址、联系电话；
（二）收件人姓名（名称）、地址、联系电话；
（三）寄递物品的名称、性质、数量。
除信件和已签订安全协议用户交寄的快件外，经营快递业务的企业收寄快件，应当对寄件人身份进行查验，并登记身份信息，但不得在快递运单上记录除姓名（名称）、地址、联系电话以外的用户身份信息。寄件人拒绝提供身份信息或者提供身份信息不实的，经营快递业务的企业不得收寄。
