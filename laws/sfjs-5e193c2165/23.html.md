# 最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释第二十三条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》执行程序若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5e193c2165/23.html

依照民事诉讼法第二百五十五条规定对被执行人限制出境的，应当由申请执行人向执行法院提出书面申请；必要时，执行法院可以依职权决定。
