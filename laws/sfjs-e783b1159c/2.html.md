# 最高人民法院关于严格规范民商事案件延长审限和延期开庭问题的规定第二条

- 法规：最高人民法院关于严格规范民商事案件延长审限和延期开庭问题的规定（现行有效，施行日期 2019-03-28）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e783b1159c/2.html

民事诉讼法第一百四十六条第四项规定的“其他应当延期的情形”，是指因不可抗力或者意外事件导致庭审无法正常进行的情形。
