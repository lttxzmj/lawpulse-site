# 最高人民法院关于严格规范民商事案件延长审限和延期开庭问题的规定第三条

- 法规：最高人民法院关于严格规范民商事案件延长审限和延期开庭问题的规定（现行有效，施行日期 2019-03-28）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e783b1159c/3.html

人民法院应当严格限制延期开庭审理次数。适用普通程序审理民商事案件，延期开庭审理次数不超过两次；适用简易程序以及小额速裁程序审理民商事案件，延期开庭审理次数不超过一次。
