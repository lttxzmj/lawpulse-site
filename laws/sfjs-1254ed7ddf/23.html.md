# 最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释第二十三条

- 法规：最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释（现行有效，施行日期 2014-09-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1254ed7ddf/23.html

实施走私犯罪，具有下列情形之一的，应当认定为犯罪既遂：
（一）在海关监管现场被查获的；
（二）以虚假申报方式走私，申报行为实施完毕的；
（三）以保税货物或者特定减税、免税进口的货物、物品为对象走私，在境内销售的，或者申请核销行为实施完毕的。
