# 最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释第三条

- 法规：最高人民法院、最高人民检察院关于办理走私刑事案件适用法律若干问题的解释（现行有效，施行日期 2014-09-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1254ed7ddf/3.html

走私枪支散件，构成犯罪的，依照刑法第一百五十一条第一款的规定，以走私武器罪定罪处罚。成套枪支散件以相应数量的枪支计，非成套枪支散件以每三十件为一套枪支散件计。
