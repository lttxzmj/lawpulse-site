# 烟花爆竹安全管理条例第三十二条

- 法规：烟花爆竹安全管理条例（现行有效）
- 章节：第五章燃放安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-462f04cbc1/32.html

举办焰火晚会以及其他大型焰火燃放活动，应当按照举办的时间、地点、环境、活动性质、规模以及燃放烟花爆竹的种类、规格和数量，确定危险等级，实行分级管理。分级管理的具体办法，由国务院公安部门规定。
