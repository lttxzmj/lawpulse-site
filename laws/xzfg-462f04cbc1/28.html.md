# 烟花爆竹安全管理条例第二十八条

- 法规：烟花爆竹安全管理条例（现行有效）
- 章节：第五章燃放安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-462f04cbc1/28.html

燃放烟花爆竹，应当遵守有关法律、法规和规章的规定。县级以上地方人民政府可以根据本行政区域的实际情况，确定限制或者禁止燃放烟花爆竹的时间、地点和种类。
