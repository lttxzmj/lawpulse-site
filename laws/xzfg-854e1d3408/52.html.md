# 医疗废物管理条例第五十二条

- 法规：医疗废物管理条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-854e1d3408/52.html

未取得经营许可证从事医疗废物的收集、运送、贮存、处置等活动的，由县级以上地方人民政府环境保护行政主管部门责令立即停止违法行为，没收违法所得，可以并处违法所得1倍以下的罚款。
