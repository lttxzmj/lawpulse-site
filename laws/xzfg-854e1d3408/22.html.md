# 医疗废物管理条例第二十二条

- 法规：医疗废物管理条例（现行有效）
- 章节：第四章医疗废物的集中处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-854e1d3408/22.html

从事医疗废物集中处置活动的单位，应当向县级以上人民政府环境保护行政主管部门申请领取经营许可证；未取得经营许可证的单位，不得从事有关医疗废物集中处置的活动。
