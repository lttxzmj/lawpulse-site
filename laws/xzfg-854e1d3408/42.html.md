# 医疗废物管理条例第四十二条

- 法规：医疗废物管理条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-854e1d3408/42.html

县级以上地方人民政府未依照本条例的规定，组织建设医疗废物集中处置设施或者组织制定医疗废物过渡性处置方案的，由上级人民政府通报批评，责令限期建成医疗废物集中处置设施或者组织制定医疗废物过渡性处置方案；并可以对政府主要领导人、负有责任的主管人员，依法给予行政处分。
