# 退耕还林条例第三十九条

- 法规：退耕还林条例（现行有效）
- 章节：第四章资金和粮食补助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c12e387c9/39.html

省、自治区、直辖市人民政府应当根据当地口粮消费习惯和农作物种植习惯以及当地粮食库存实际情况合理确定补助粮食的品种。
补助粮食必须达到国家规定的质量标准。不符合国家质量标准的，不得供应给退耕还林者。
