# 退耕还林条例第三十四条

- 法规：退耕还林条例（现行有效）
- 章节：第三章造林、管护与检查验收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c12e387c9/34.html

省、自治区、直辖市人民政府应当对县级退耕还林检查验收结果进行复查，并根据复查结果对县级人民政府和有关责任人员进行奖惩。
国务院林业行政主管部门应当对省级复查结果进行核查，并将核查结果上报国务院。
