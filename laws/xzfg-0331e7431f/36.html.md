# 医疗保障基金使用监督管理条例第三十六条

- 法规：医疗保障基金使用监督管理条例（现行有效，施行日期 2021-05-01）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0331e7431f/36.html

医疗保障经办机构有下列情形之一的，由医疗保障行政部门责令改正，对直接负责的主管人员和其他直接责任人员依法给予处分：
（一）未建立健全业务、财务、安全和风险管理制度；
（二）未履行服务协议管理、费用监控、基金拨付、待遇审核及支付等职责；
（三）未定期向社会公开医疗保障基金的收入、支出、结余等情况。
