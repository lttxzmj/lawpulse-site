# 医疗保障基金使用监督管理条例第二十三条

- 法规：医疗保障基金使用监督管理条例（现行有效，施行日期 2021-05-01）
- 章节：第三章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0331e7431f/23.html

国务院医疗保障行政部门负责制定服务协议管理办法，规范、简化、优化医药机构定点申请、专业评估、协商谈判程序，制作并定期修订服务协议范本。
国务院医疗保障行政部门制定服务协议管理办法，应当听取有关部门、医药机构、行业协会、社会公众、专家等方面意见。
