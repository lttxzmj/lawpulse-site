# 医疗保障基金使用监督管理条例第四十七条

- 法规：医疗保障基金使用监督管理条例（现行有效，施行日期 2021-05-01）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0331e7431f/47.html

医疗保障等行政部门工作人员在医疗保障基金使用监督管理工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分。
