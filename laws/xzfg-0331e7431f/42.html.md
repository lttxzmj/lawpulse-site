# 医疗保障基金使用监督管理条例第四十二条

- 法规：医疗保障基金使用监督管理条例（现行有效，施行日期 2021-05-01）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0331e7431f/42.html

医疗保障等行政部门、医疗保障经办机构、定点医药机构及其工作人员收受贿赂或者取得其他非法收入的，没收违法所得，对有关责任人员依法给予处分；违反其他法律、行政法规的，由有关主管部门依法处理。
