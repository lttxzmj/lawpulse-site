# 人民检察院刑事诉讼规则第四百七十一条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十二章特别程序 · 第一节未成年人刑事案件诉讼程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/471.html

人民检察院作出附条件不起诉的决定后，应当制作附条件不起诉决定书，并在三日以内送达公安机关、被害人或者其近亲属及其诉讼代理人、未成年犯罪嫌疑人及其法定代理人、辩护人。
人民检察院应当当面向未成年犯罪嫌疑人及其法定代理人宣布附条件不起诉决定，告知考验期限、在考验期内应当遵守的规定以及违反规定应负的法律责任，并制作笔录附卷。
