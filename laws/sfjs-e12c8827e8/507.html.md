# 人民检察院刑事诉讼规则第五百零七条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十二章特别程序 · 第三节缺席审判程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/507.html

最高人民检察院收到下级人民检察院报请核准提起公诉的案卷材料后，应当及时指派检察官对案卷材料进行审查，提出核准或者不予核准的意见，报检察长决定。
