# 人民检察院刑事诉讼规则第一百八十九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第九章侦查 · 第二节讯问犯罪嫌疑人
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/189.html

犯罪嫌疑人请求自行书写供述的，检察人员应当准许。必要时，检察人员也可以要求犯罪嫌疑人亲笔书写供述。犯罪嫌疑人应当在亲笔供述的末页签名或者盖章，并捺指印，注明书写日期。检察人员收到后，应当在首页右上方写明“于某年某月某日收到”，并签名。
