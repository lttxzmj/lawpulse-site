# 人民检察院刑事诉讼规则第三百三十五条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第七节审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/335.html

人民检察院审查案件时，对监察机关或者公安机关的勘验、检查，认为需要复验、复查的，应当要求其复验、复查，人民检察院可以派员参加；也可以自行复验、复查，商请监察机关或者公安机关派员参加，必要时也可以指派检察技术人员或者聘请其他有专门知识的人参加。
