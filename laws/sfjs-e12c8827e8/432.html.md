# 人民检察院刑事诉讼规则第四百三十二条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十一章出席法庭 · 第二节简易程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/432.html

基层人民检察院审查案件，认为案件事实清楚、证据充分的，应当在讯问犯罪嫌疑人时，了解其是否承认自己所犯罪行，对指控的犯罪事实有无异议，告知其适用简易程序的法律规定，确认其是否同意适用简易程序。
