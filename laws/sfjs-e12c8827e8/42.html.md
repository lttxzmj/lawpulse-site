# 人民检察院刑事诉讼规则第四十二条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第四章辩护与代理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/42.html

人民检察院办理直接受理侦查案件和审查起诉案件，发现犯罪嫌疑人是盲、聋、哑人或者是尚未完全丧失辨认或者控制自己行为能力的精神病人，或者可能被判处无期徒刑、死刑，没有委托辩护人的，应当自发现之日起三日以内书面通知法律援助机构指派律师为其提供辩护。
