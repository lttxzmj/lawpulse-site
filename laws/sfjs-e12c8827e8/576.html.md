# 人民检察院刑事诉讼规则第五百七十六条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十三章刑事诉讼法律监督 · 第五节羁押必要性审查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/576.html

办案机关对应的同级人民检察院负责控告申诉检察的部门或者负责案件管理的部门收到羁押必要性审查申请后，应当在当日移送本院负责捕诉的部门。
其他人民检察院收到羁押必要性审查申请的，应当告知申请人向办案机关对应的同级人民检察院提出申请，或者在二日以内将申请材料移送办案机关对应的同级人民检察院，并告知申请人。
