# 人民检察院刑事诉讼规则第三百六十九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第九节不起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/369.html

人民检察院根据刑事诉讼法第一百七十五条第四款规定决定不起诉的，在发现新的证据，符合起诉条件时，可以提起公诉。
