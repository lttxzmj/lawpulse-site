# 人民检察院刑事诉讼规则第三百七十六条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第九节不起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/376.html

不起诉的决定，由人民检察院公开宣布。公开宣布不起诉决定的活动应当记录在案。
不起诉决定书自公开宣布之日起生效。
被不起诉人在押的，应当立即释放；被采取其他强制措施的，应当通知执行机关解除。
