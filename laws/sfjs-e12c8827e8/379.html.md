# 人民检察院刑事诉讼规则第三百七十九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第九节不起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/379.html

监察机关认为不起诉的决定有错误，向上一级人民检察院提请复议的，上一级人民检察院应当在收到提请复议意见书后三十日以内，经检察长批准，作出复议决定，通知监察机关。
公安机关认为不起诉决定有错误要求复议的，人民检察院负责捕诉的部门应当另行指派检察官或者检察官办案组进行审查，并在收到要求复议意见书后三十日以内，经检察长批准，作出复议决定，通知公安机关。
