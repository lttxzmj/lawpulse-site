# 人民检察院刑事诉讼规则第八十七条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第六章强制措施 · 第二节取保候审
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/87.html

人民检察院对于严重危害社会治安的犯罪嫌疑人，以及其他犯罪性质恶劣、情节严重的犯罪嫌疑人不得取保候审。
