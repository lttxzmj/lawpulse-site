# 人民检察院刑事诉讼规则第五百二十一条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十二章特别程序 · 第四节犯罪嫌疑人、被告人逃匿、死亡案件违法所得的没收程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/521.html

监察机关或者公安机关向人民检察院移送没收违法所得意见书，应当由有管辖权的人民检察院的同级监察机关或者公安机关移送。
