# 人民检察院刑事诉讼规则第三百零九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第五节延长侦查羁押期限和重新计算侦查羁押期限
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/309.html

公安机关需要延长侦查羁押期限的，人民检察院应当要求其在侦查羁押期限届满七日前提请批准延长侦查羁押期限。
人民检察院办理直接受理侦查的案件，负责侦查的部门认为需要延长侦查羁押期限的，应当按照前款规定向本院负责捕诉的部门移送延长侦查羁押期限意见书及有关材料。
对于超过法定羁押期限提请延长侦查羁押期限的，不予受理。
