# 人民检察院刑事诉讼规则第六百八十条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/680.html

人民检察院办理国家安全机关、海警机关、监狱移送的刑事案件以及对国家安全机关、海警机关、监狱立案、侦查活动的监督，适用本规则关于公安机关的规定。
