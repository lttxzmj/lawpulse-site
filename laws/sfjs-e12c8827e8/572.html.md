# 人民检察院刑事诉讼规则第五百七十二条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十三章刑事诉讼法律监督 · 第四节审判活动监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/572.html

人民检察院在审判活动监督中，发现人民法院或者审判人员审理案件违反法律规定的诉讼程序，应当向人民法院提出纠正意见。
人民检察院对违反程序的庭审活动提出纠正意见，应当由人民检察院在庭审后提出。出席法庭的检察人员发现法庭审判违反法律规定的诉讼程序，应当在休庭后及时向检察长报告。
