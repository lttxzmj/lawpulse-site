# 人民检察院刑事诉讼规则第一百三十九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第六章强制措施 · 第五节逮捕
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/139.html

对具有下列情形之一的犯罪嫌疑人，人民检察院应当作出不批准逮捕或者不予逮捕的决定：
（一）不符合本规则规定的逮捕条件的；
（二）具有HYPERLINK "javascript:SLC(13912,0)"刑事诉讼法第HYPERLINK "javascript:SLC(13912,15)"十六条规定的情形之一的。
