# 人民检察院刑事诉讼规则第六百五十六条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十四章刑罚执行和监管执法监督 · 第八节监管执法监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/656.html

看守所对收押的犯罪嫌疑人进行身体检查时，人民检察院驻看守所检察人员可以在场。发现收押的犯罪嫌疑人有伤或者身体异常的，应当要求看守所进行拍照或者录像，由送押人员、犯罪嫌疑人说明原因，在体检记录中写明，并由送押人员、收押人员和犯罪嫌疑人签字确认。必要时，驻看守所检察人员可以自行拍照或者录像，并将相关情况记录在案。
