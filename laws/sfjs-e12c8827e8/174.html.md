# 人民检察院刑事诉讼规则第一百七十四条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第八章立案 · 第二节立案决定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/174.html

错告对被控告人、被举报人造成不良影响的，人民检察院应当自作出不立案决定之日起一个月以内向其所在单位或者有关部门通报调查核实的结论，澄清事实。
属于诬告陷害的，应当移送有关机关处理。
