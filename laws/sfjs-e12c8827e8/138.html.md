# 人民检察院刑事诉讼规则第一百三十八条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第六章强制措施 · 第五节逮捕
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/138.html

对实施多个犯罪行为或者共同犯罪案件的犯罪嫌疑人，符合本规则第一百二十八条的规定，具有下列情形之一的，应当批准或者决定逮捕：
（一）有证据证明犯有数罪中的一罪的；
（二）有证据证明实施多次犯罪中的一次犯罪的；
（三）共同犯罪中，已有证据证明有犯罪事实的犯罪嫌疑人。
