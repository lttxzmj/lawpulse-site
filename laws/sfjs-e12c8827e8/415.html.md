# 人民检察院刑事诉讼规则第四百一十五条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十一章出席法庭 · 第一节出席第一审法庭
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/415.html

在法庭审理过程中，合议庭对证据有疑问并在休庭后进行勘验、检查、查封、扣押、鉴定和查询、冻结的，人民检察院应当依法进行监督，发现上述活动有违法情况的，应当提出纠正意见。
