# 人民检察院刑事诉讼规则第六百八十二条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十七章附则
- 数据核对至：2026-10-22

本规则所称检察官，包括检察长、副检察长、检察委员会委员、检察员。
本规则所称检察人员，包括检察官和检察官助理。
