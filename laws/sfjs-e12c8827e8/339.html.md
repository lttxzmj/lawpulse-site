# 人民检察院刑事诉讼规则第三百三十九条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第七节审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/339.html

人民检察院对案件进行审查后，应当依法作出起诉或者不起诉以及是否提起附带民事诉讼、附带民事公益诉讼的决定。
