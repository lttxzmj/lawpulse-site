# 人民检察院刑事诉讼规则第三百二十七条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第六节核准追诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/327.html

最高人民检察院决定核准追诉的案件，最初受理案件的人民检察院应当监督公安机关的侦查工作。
最高人民检察院决定不予核准追诉，公安机关未及时撤销案件的，同级人民检察院应当提出纠正意见。犯罪嫌疑人在押的，应当立即释放。
