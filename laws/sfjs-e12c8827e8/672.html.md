# 人民检察院刑事诉讼规则第六百七十二条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十六章刑事司法协助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/672.html

人民检察院刑事司法协助的范围包括刑事诉讼文书送达，调查取证，安排证人作证或者协助调查，查封、扣押、冻结涉案财物，返还违法所得及其他涉案财物，移管被判刑人以及其他协助。
