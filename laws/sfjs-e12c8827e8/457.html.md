# 人民检察院刑事诉讼规则第四百五十七条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十二章特别程序 · 第一节未成年人刑事案件诉讼程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/457.html

人民检察院办理未成年人刑事案件，应当贯彻“教育、感化、挽救”方针和“教育为主、惩罚为辅”的原则，坚持优先保护、特殊保护、双向保护，以帮助教育和预防重新犯罪为目的。
人民检察院可以借助社会力量开展帮助教育未成年人的工作。
