# 人民检察院刑事诉讼规则第三条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第一章通则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/3.html

人民检察院办理刑事案件，应当严格遵守《中华人民共和国刑事诉讼法》以及其他法律的有关规定，秉持客观公正的立场，尊重和保障人权，既要追诉犯罪，也要保障无罪的人不受刑事追究。
