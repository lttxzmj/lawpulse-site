# 人民检察院刑事诉讼规则第二百七十七条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第二节认罪认罚从宽案件办理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/277.html

犯罪嫌疑人认罪认罚，人民检察院拟提出适用缓刑或者判处管制的量刑建议，可以委托犯罪嫌疑人居住地的社区矫正机构进行调查评估，也可以自行调查评估。
