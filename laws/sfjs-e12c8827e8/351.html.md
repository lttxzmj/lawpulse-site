# 人民检察院刑事诉讼规则第三百五十一条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第七节审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/351.html

人民检察院对于移送起诉的案件，应当在一个月以内作出决定；重大、复杂的案件，一个月以内不能作出决定的，可以延长十五日。
人民检察院审查起诉的案件，改变管辖的，从改变后的人民检察院收到案件之日起计算审查起诉期限。
