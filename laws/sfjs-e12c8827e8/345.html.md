# 人民检察院刑事诉讼规则第三百四十五条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第七节审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/345.html

人民检察院负责捕诉的部门对本院负责侦查的部门移送起诉的案件进行审查后，认为犯罪事实不清、证据不足或者存在遗漏罪行、遗漏同案犯罪嫌疑人等情形需要补充侦查的，应当制作补充侦查提纲，连同案卷材料一并退回负责侦查的部门补充侦查。必要时，也可以自行侦查，可以要求负责侦查的部门予以协助。
