# 人民检察院刑事诉讼规则第六百四十条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十四章刑罚执行和监管执法监督 · 第三节减刑、假释、暂予监外执行监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/640.html

对人民法院减刑、假释裁定的纠正意见，由作出减刑、假释裁定的人民法院的同级人民检察院书面提出。
下级人民检察院发现人民法院减刑、假释裁定不当的，应当向作出减刑、假释裁定的人民法院的同级人民检察院报告。
