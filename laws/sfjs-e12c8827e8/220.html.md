# 人民检察院刑事诉讼规则第二百二十条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第九章侦查 · 第七节鉴定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/220.html

对于鉴定意见，检察人员应当进行审查，必要时可以进行补充鉴定或者重新鉴定。重新鉴定的，应当另行指派或者聘请鉴定人。
