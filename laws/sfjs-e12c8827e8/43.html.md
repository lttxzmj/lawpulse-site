# 人民检察院刑事诉讼规则第四十三条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第四章辩护与代理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/43.html

人民检察院收到在押或者被指定居所监视居住的犯罪嫌疑人提出的法律援助申请，应当在二十四小时以内将申请材料转交法律援助机构，并通知犯罪嫌疑人的监护人、近亲属或者其委托的其他人员协助提供有关证件、证明等材料。
