# 人民检察院刑事诉讼规则第三百八十三条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十章审查逮捕和审查起诉 · 第九节不起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/383.html

人民检察院应当将复查决定书送达被害人、被不起诉人和作出不起诉决定的人民检察院。
上级人民检察院经复查作出起诉决定的，应当撤销下级人民检察院的不起诉决定，交由下级人民检察院提起公诉，并将复查决定抄送移送起诉的监察机关或者公安机关。
