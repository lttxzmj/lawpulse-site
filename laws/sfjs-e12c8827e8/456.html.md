# 人民检察院刑事诉讼规则第四百五十六条

- 法规：人民检察院刑事诉讼规则（现行有效，施行日期 2019-12-30）
- 章节：第十一章出席法庭 · 第五节出席再审法庭
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e12c8827e8/456.html

人民检察院派员出席再审法庭，如果再审案件按照第一审程序审理，参照本章第一节有关规定执行；如果再审案件按照第二审程序审理，参照本章第四节有关规定执行。
