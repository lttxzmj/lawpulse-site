# 中华人民共和国药品管理法实施条例第六十四条

- 法规：中华人民共和国药品管理法实施条例（现行有效，施行日期 2026-05-15）
- 章节：第七章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-490d7fca4c/64.html

国务院药品监督管理部门应当制定统一的药品追溯标准和规范。药品上市许可持有人、药品生产企业应当按照规定在药品包装上赋予追溯标识。药品上市许可持有人、药品生产企业、药品经营企业和医疗机构应当按照规定提供追溯信息，保证药品可追溯。
