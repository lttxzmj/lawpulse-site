# 中华人民共和国药品管理法实施条例第八十四条

- 法规：中华人民共和国药品管理法实施条例（现行有效，施行日期 2026-05-15）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-490d7fca4c/84.html

药品网络交易第三方平台提供者未按照规定建立健全药品网络销售质量管理体系的，由省级人民政府药品监督管理部门责令限期改正，给予警告；逾期不改正的，处10万元以上50万元以下的罚款；情节严重的，处50万元以上200万元以下的罚款。
药品网络交易第三方平台提供者、药品上市许可持有人、药品经营企业为其他药品网络交易第三方平台提供者、药品上市许可持有人、药品经营企业通过网络销售药品提供信息展示、链接跳转等服务，违反国务院药品监督管理部门规定的，由省级人民政府药品监督管理部门责令限期改正，给予警告；逾期不改正的，没收违法所得，并处10万元以上50万元以下的罚款；情节严重的，没收违法所得，并处50万元以上200万元以下的罚款。
