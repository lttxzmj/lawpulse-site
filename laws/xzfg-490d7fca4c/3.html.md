# 中华人民共和国药品管理法实施条例第三条

- 法规：中华人民共和国药品管理法实施条例（现行有效，施行日期 2026-05-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-490d7fca4c/3.html

国家完善药品创新体系，支持以临床价值为导向的药品研制和创新，鼓励研究和创制新药，支持新药临床推广和使用；促进中药传承创新，充分发挥中药在预防、医疗和保健中的作用；促进仿制药研发创新，提升仿制药质量和疗效。
