# 重新组建仲裁机构方案第二十三条

- 法规：重新组建仲裁机构方案（现行有效）
- 章节：第四章仲裁员
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-68a0bd904d/23.html

仲裁员有下列情形之一的，仲裁委员会应当予以解聘：
(一)隐瞒应当回避的情形，对案件审理产生不良影响的；
(二)无正当理由不到庭审理案件的；
(三)有不宜继续担任仲裁员的其他情形的。
