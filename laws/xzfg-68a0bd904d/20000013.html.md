# 重新组建仲裁机构方案第十三条

- 法规：重新组建仲裁机构方案（现行有效）
- 章节：第二章申请和受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-68a0bd904d/20000013.html

一方当事人因另一方当事人的行为或者其他原因，可能使裁决不能执行或者难以执行的，可以申请财产保全。
当事人申请财产保全的，本仲裁委员会应当将当事人的申请依照民事诉讼法的有关规定提交人民法院。
申请有错误的，申请人应当赔偿被申请人因财产保全遭受的损失。
