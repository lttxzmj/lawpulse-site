# 重新组建仲裁机构方案第五十条

- 法规：重新组建仲裁机构方案（现行有效）
- 章节：第五章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-68a0bd904d/50.html

期间以时、日、月、年计算。期间开始的时和日，不计算在期间内。
期间届满的最后一日是节假日的，以节假日后的第一日为期间届满的日期。
期间不包括在途时间，仲裁文书、材料、通知在期满前交邮、交发的，不算过期。
