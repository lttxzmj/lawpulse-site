# 中华人民共和国对外国籍船舶管理规则第四十二条

- 法规：中华人民共和国对外国籍船舶管理规则（现行有效）
- 章节：第七章消防和救助
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0d4c9eabb5/42.html

船舶在港内进行烧焊等工程，应事先清理周围环境，采取严密防范措施，配备消防设备，并且在施工前后进行检查。对油舱及其邻近部位还必须卸完全部油料，清除残油，彻底通风，排除其内部易燃气体，并取得合格证明之后，才可以烧焊。
