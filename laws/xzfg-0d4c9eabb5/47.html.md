# 中华人民共和国对外国籍船舶管理规则第四十七条

- 法规：中华人民共和国对外国籍船舶管理规则（现行有效）
- 章节：第八章海损事故
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0d4c9eabb5/47.html

船舶在中华人民共和国港口和沿海水域造成人命、财产损害事故时，应积极救助受害的船舶和人员，及时向港务监督报告，并接受调查和处理。如果肇事者见危不救，隐匿逃遁，将从严处理。
