# 中华人民共和国对外国籍船舶管理规则第二十三条

- 法规：中华人民共和国对外国籍船舶管理规则（现行有效）
- 章节：第三章信号和通讯
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0d4c9eabb5/23.html

船舶在中华人民共和国港口和沿海水域航行、停泊，白天应悬挂船籍国的国旗，进出港口和移泊应加挂船名呼号旗和港口规定的有关信号。
