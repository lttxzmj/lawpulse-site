# 中华人民共和国对外国籍船舶管理规则第四十六条

- 法规：中华人民共和国对外国籍船舶管理规则（现行有效）
- 章节：第八章海损事故
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0d4c9eabb5/46.html

船舶发生海损事故，应尽速用电报或无线电话向港务监督报出扼要报告。在港区以外发出的海损事故，船长应在船舶进入第一港口四十八小时内，向港务监督递交海损事故报告书；在港区内发生的海损事故，船长应在二十四小时内向港务监督递交海损事故报告书。
