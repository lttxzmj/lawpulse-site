# 国务院关于对外投资的规定第三条

- 法规：国务院关于对外投资的规定（现行有效，施行日期 2026-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9dd77de65c/3.html

对外投资工作坚持对外开放的基本国策，贯彻总体国家安全观，统筹发展和安全，统筹国内国际，健全对外投资管理服务体系，提升对外投资质量与水平，促进开放合作、互利共赢。
