# 中华人民共和国渔业船舶检验条例第二十三条

- 法规：中华人民共和国渔业船舶检验条例（现行有效）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55eb65098d/23.html

有下列情形之一的渔业船舶，渔业船舶检验机构不得受理检验：
(一)设计图纸、技术文件未经渔业船舶检验机构审查批准或者确认的；
(二)违反本条例第八条第二款和第九条第二款规定制造、改造的；
(三)违反本条例第十六条、第十七条规定维修的；
(四)按照国家有关规定应当报废的。
