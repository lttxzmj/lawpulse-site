# 中华人民共和国渔业船舶检验条例第二十一条

- 法规：中华人民共和国渔业船舶检验条例（现行有效）
- 章节：第四章临时检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55eb65098d/21.html

渔业船舶检验机构应当自申报临时检验的渔业船舶到达受检地之日起2个工作日内实施检验。经检验合格的，应当自检验完毕之日起3个工作日内在渔业船舶检验证书上签署意见或者签发渔业船舶检验证书；经检验不合格的，应当书面通知当事人，并说明理由。
