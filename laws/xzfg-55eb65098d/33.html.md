# 中华人民共和国渔业船舶检验条例第三十三条

- 法规：中华人民共和国渔业船舶检验条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55eb65098d/33.html

违反本条例规定，渔业船舶应当申报营运检验或者临时检验而不申报的，责令立即停止作业，限期申报检验；逾期仍不申报检验的，处1000元以上1万元以下的罚款，并可以暂扣渔业船舶检验证书。
