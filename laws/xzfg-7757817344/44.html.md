# 中华人民共和国进出境动植物检疫法实施条例第四十四条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第六章携带、邮寄物检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/44.html

邮寄进境的动植物、动植物产品和其他检疫物，由口岸动植物检疫机关在国际邮件互换局(含国际邮件快递公司及其他经营国际邮件的单位，以下简称邮局)实施检疫。邮局应当提供必要的工作条件。
经现场检疫合格的，由口岸动植物检疫机关加盖检疫放行章，交邮局运递。需要作实验室检疫或者隔离检疫的，口岸动植物检疫机关应当向邮局办理交接手续；检疫合格的，加盖检疫放行章，交邮局运递。
