# 中华人民共和国进出境动植物检疫法实施条例第六十六条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第十章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/66.html

口岸动植物检疫机关依法实施检疫，需要采取样品时，应当出具采样凭单；验余的样品，货主、物主或者其代理人应当在规定的期限内领回；逾期不领回的，由口岸动植物检疫机关按照规定处理。
