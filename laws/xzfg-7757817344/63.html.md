# 中华人民共和国进出境动植物检疫法实施条例第六十三条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/63.html

从事进出境动植物检疫熏蒸、消毒处理业务的单位和人员，不按照规定进行熏蒸和消毒处理的，口岸动植物检疫机关可以视情节取消其熏蒸、消毒资格。
