# 中华人民共和国进出境动植物检疫法实施条例第四十二条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第六章携带、邮寄物检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/42.html

口岸动植物检疫机关可以在港口、机场、车站的旅客通道、行李提取处等现场进行检查，对可能携带动植物、动植物产品和其他检疫物而未申报的，可以进行查询并抽检其物品，必要时可以开包(箱)检查。
旅客进出境检查现场应当设立动植物检疫台位和标志。
