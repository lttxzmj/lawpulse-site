# 中华人民共和国进出境动植物检疫法实施条例第二十八条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第三章进境检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/28.html

输入动植物、动植物产品和其他检疫物，经检疫不合格的，由口岸动植物检疫机关签发《检疫处理通知单》，通知货主或者其代理人在口岸动植物检疫机关的监督和技术指导下，作除害处理；需要对外索赔的，由口岸动植物检疫机关出具检疫证书。
