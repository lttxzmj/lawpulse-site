# 中华人民共和国进出境动植物检疫法实施条例第五十七条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第八章检疫监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/57.html

口岸动植物检疫机关根据需要，可以对运载进出境动植物、动植物产品和其他检疫物的运输工具、装载容器加施动植物检疫封识或者标志；未经口岸动植物检疫机关许可，不得开拆或者损毁检疫封识、标志。
动植物检疫封识和标志由国家动植物检疫局统一制发。
