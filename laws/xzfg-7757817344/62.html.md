# 中华人民共和国进出境动植物检疫法实施条例第六十二条

- 法规：中华人民共和国进出境动植物检疫法实施条例（现行有效）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7757817344/62.html

有下列违法行为之一的，依法追究刑事责任；尚不构成犯罪或者犯罪情节显著轻微依法不需要判处刑罚的，由口岸动植物检疫机关处2万元以上5万元以下的罚款：
(一)引起重大动植物疫情的；
(二)伪造、变造动植物检疫单证、印章、标志、封识的。
