# 专利代理条例第二十三条

- 法规：专利代理条例（现行有效）
- 章节：第三章专利代理执业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-733094fe41/23.html

国务院专利行政部门和省、自治区、直辖市人民政府管理专利工作的部门应当加强专利代理公共信息发布，为公众了解专利代理机构经营情况、专利代理师执业情况提供查询服务。
