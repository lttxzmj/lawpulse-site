# 病原微生物实验室生物安全管理条例第五十七条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/57.html

卫生主管部门或者兽医主管部门违反本条例的规定，准予不符合本条例规定条件的实验室从事高致病性病原微生物相关实验活动的，由作出批准决定的卫生主管部门或者兽医主管部门撤销原批准决定，责令有关实验室立即停止有关活动，并监督其将用于实验活动的病原微生物销毁或者送交保藏机构，对直接负责的主管人员和其他直接责任人员依法给予行政处分；构成犯罪的，依法追究刑事责任。
因违法作出批准决定给当事人的合法权益造成损害的，作出批准决定的卫生主管部门或者兽医主管部门应当依法承担赔偿责任。
