# 病原微生物实验室生物安全管理条例第十八条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章实验室的设立与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/18.html

国家根据实验室对病原微生物的生物安全防护水平，并依照实验室生物安全国家标准的规定，将实验室分为一级、二级、三级、四级。
