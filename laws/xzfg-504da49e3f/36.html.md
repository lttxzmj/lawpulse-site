# 病原微生物实验室生物安全管理条例第三十六条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章实验室的设立与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/36.html

在同一个实验室的同一个独立安全区域内，只能同时从事一种高致病性病原微生物的相关实验活动。
