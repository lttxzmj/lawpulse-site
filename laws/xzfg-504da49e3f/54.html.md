# 病原微生物实验室生物安全管理条例第五十四条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/54.html

卫生主管部门、兽医主管部门、环境保护主管部门及其执法人员执行职务，应当自觉接受社会和公民的监督。公民、法人和其他组织有权向上级人民政府及其卫生主管部门、兽医主管部门、环境保护主管部门举报地方人民政府及其有关主管部门不依照规定履行职责的情况。接到举报的有关人民政府或者其卫生主管部门、兽医主管部门、环境保护主管部门，应当及时调查处理。
