# 病原微生物实验室生物安全管理条例第二十八条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章实验室的设立与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/28.html

对我国尚未发现或者已经宣布消灭的病原微生物，任何单位和个人未经批准不得从事相关实验活动。
为了预防、控制传染病，需要从事前款所指病原微生物相关实验活动的，应当经国务院卫生主管部门或者兽医主管部门批准，并在批准部门指定的专业实验室中进行。
