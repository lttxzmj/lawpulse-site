# 病原微生物实验室生物安全管理条例第四十二条

- 法规：病原微生物实验室生物安全管理条例（现行有效，施行日期 2026-08-15）
- 章节：第四章实验室感染控制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-504da49e3f/42.html

实验室的设立单位应当指定专门的机构或者人员承担实验室感染控制工作，定期检查实验室的生物安全防护、病原微生物菌（毒）种和样本保存与使用、安全操作、实验室排放的废水和废气以及其他废物处置等规章制度的实施情况。
负责实验室感染控制工作的机构或者人员应当具有与该实验室中的病原微生物有关的传染病防治知识，并定期调查、了解实验室工作人员的健康状况。
