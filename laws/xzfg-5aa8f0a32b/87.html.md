# 中华人民共和国预算法实施条例第八十七条

- 法规：中华人民共和国预算法实施条例（现行有效，施行日期 2020-10-01）
- 章节：第五章决算
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5aa8f0a32b/87.html

年度预算执行终了，对于上下级财政之间按照规定需要清算的事项，应当在决算时办理结算。
县级以上各级政府财政部门编制的决算草案应当及时报送本级政府审计部门审计。
