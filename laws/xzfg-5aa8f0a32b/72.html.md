# 中华人民共和国预算法实施条例第七十二条

- 法规：中华人民共和国预算法实施条例（现行有效，施行日期 2020-10-01）
- 章节：第四章预算执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5aa8f0a32b/72.html

各级政府应当加强对预算执行工作的领导，定期听取财政部门有关预算执行情况的汇报，研究解决预算执行中出现的问题。
