# 中华人民共和国预算法实施条例第三条

- 法规：中华人民共和国预算法实施条例（现行有效，施行日期 2020-10-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5aa8f0a32b/3.html

社会保险基金预算应当在精算平衡的基础上实现可持续运行，一般公共预算可以根据需要和财力适当安排资金补充社会保险基金预算。
