# 中华人民共和国预算法实施条例第八十九条

- 法规：中华人民共和国预算法实施条例（现行有效，施行日期 2020-10-01）
- 章节：第六章监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5aa8f0a32b/89.html

县级以上各级政府应当接受本级和上级人民代表大会及其常务委员会对预算执行情况和决算的监督，乡、民族乡、镇政府应当接受本级人民代表大会和上级人民代表大会及其常务委员会对预算执行情况和决算的监督；按照本级人民代表大会或者其常务委员会的要求，报告预算执行情况；认真研究处理本级人民代表大会代表或者其常务委员会组成人员有关改进预算管理的建议、批评和意见，并及时答复。
