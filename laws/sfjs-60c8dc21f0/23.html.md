# 最高人民检察院关于指派、聘请有专门知识的人参与办案若干问题的规定（试行）第二十三条

- 法规：最高人民检察院关于指派、聘请有专门知识的人参与办案若干问题的规定（试行）（现行有效，施行日期 2018-03-21）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-60c8dc21f0/23.html

各省、自治区、直辖市人民检察院可以依照本规定，结合本地实际，制定具体实施办法，并报最高人民检察院备案。
