# 非银行支付机构监督管理条例第四十四条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/44.html

非银行支付机构发生风险事件影响其正常运营、损害用户合法权益的，中国人民银行可以区分情形，对非银行支付机构采取下列措施：
（一）责令主要股东履行补充资本的监管承诺；
（二）限制重大资产交易；
（三）责令调整董事、监事、高级管理人员或者限制其权利。
