# 非银行支付机构监督管理条例第四十六条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/46.html

中国人民银行应当依照法律、行政法规和国家有关规定，完善非银行支付机构行业风险防范化解措施，化解非银行支付机构风险。
