# 非银行支付机构监督管理条例第四十二条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/42.html

非银行支付机构不得实施垄断或者不正当竞争行为，妨害市场公平竞争秩序。
中国人民银行在履行职责中发现非银行支付机构涉嫌垄断或者不正当竞争行为的，应当将相关线索移送有关执法部门，并配合其进行查处。
