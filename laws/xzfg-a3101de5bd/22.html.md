# 非银行支付机构监督管理条例第二十二条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第三章支付业务规则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/22.html

非银行支付机构应当自行完成特约商户尽职调查、支付服务协议签订、持续风险监测等业务活动。非银行支付机构不得为未经依法设立或者从事非法经营活动的商户提供服务。
