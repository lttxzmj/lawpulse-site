# 非银行支付机构监督管理条例第二十七条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第三章支付业务规则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/27.html

非银行支付机构应当根据用户发起的支付指令划转备付金，用户备付金被依法冻结、扣划的除外。
本条例所称备付金，是指非银行支付机构为用户办理支付业务而实际收到的预收待付货币资金。
非银行支付机构不得以任何形式挪用、占用、借用备付金，不得以备付金为自己或者他人提供担保。
