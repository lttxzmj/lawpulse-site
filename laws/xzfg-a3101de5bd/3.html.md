# 非银行支付机构监督管理条例第三条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/3.html

非银行支付机构开展业务，应当遵守法律、行政法规的规定，遵循安全、高效、诚信和公平竞争的原则，以提供小额、便民支付服务为宗旨，维护国家金融安全，不得损害国家利益、社会公共利益和他人合法权益。
