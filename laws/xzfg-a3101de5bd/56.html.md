# 非银行支付机构监督管理条例第五十六条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/56.html

中国人民银行工作人员有下列情形之一的，依法给予处分：
（一）违反规定审查批准非银行支付机构的设立、变更、终止申请等事项；
（二）泄露履行职责过程中知悉的国家秘密、商业秘密或者个人信息；
（三）滥用职权、玩忽职守的其他行为。
