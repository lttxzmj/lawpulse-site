# 非银行支付机构监督管理条例第五十三条

- 法规：非银行支付机构监督管理条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a3101de5bd/53.html

非银行支付机构未按照规定建立用户尽职调查制度，履行相关义务，或者存在外汇、价格违法行为的，以及任何单位和个人非法买卖、出租、出借支付账户的，由有关主管部门依照有关法律、行政法规进行处罚。
非银行支付机构未经批准从事依法需经批准的其他业务的，依照有关法律、行政法规进行处罚。
