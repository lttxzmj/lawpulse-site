# 最高人民法院关于公布失信被执行人名单信息的若干规定第三条

- 法规：最高人民法院关于公布失信被执行人名单信息的若干规定（现行有效，施行日期 2017-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-886bccaa66/3.html

具有下列情形之一的，人民法院不得依据本规定第一条第一项的规定将被执行人纳入失信被执行人名单：
（一）提供了充分有效担保的；
（二）已被采取查封、扣押、冻结等措施的财产足以清偿生效法律文书确定债务的；
（三）被执行人履行顺序在后，对其依法不应强制执行的；
（四）其他不属于有履行能力而拒不履行生效法律文书确定义务的情形。
