# 农村公路条例第二十三条

- 法规：农村公路条例（现行有效，施行日期 2025-09-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6787f52f1/23.html

县级人民政府应当加强农村公路应急保障和防灾抗灾能力建设，组织落实农村公路突发事件应急预案制定、应急物资储备、灾害监测预警等方面的责任。
因自然灾害或者其他突发事件造成农村公路中断的，县级人民政府应当组织交通运输等有关部门及时进行抢通；难以及时抢通的，应当设立警示标志并发布绕行路线。
