# 农村公路条例第十八条

- 法规：农村公路条例（现行有效，施行日期 2025-09-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e6787f52f1/18.html

农村公路养护按作业性质分为日常养护和养护工程。
县道的养护由县级人民政府交通运输主管部门组织实施。
乡道、村道的日常养护由乡镇人民政府组织实施。乡道、村道的养护工程由县级人民政府交通运输主管部门组织实施，或者交由具备条件的乡镇人民政府组织实施。
