# 麻醉药品和精神药品管理条例第八十八条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第九章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/88.html

军队医疗机构麻醉药品和精神药品的供应、使用，由国务院药品监督管理部门会同中央军事委员会后勤保障部依据本条例制定具体管理办法。
