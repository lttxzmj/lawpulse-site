# 麻醉药品和精神药品管理条例第七十七条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/77.html

药物临床试验机构以健康人为麻醉药品和第一类精神药品临床试验的受试对象的，由药品监督管理部门责令停止违法行为，给予警告；情节严重的，取消其药物临床试验机构的资格；构成犯罪的，依法追究刑事责任。对受试对象造成损害的，药物临床试验机构依法承担治疗和赔偿责任。
