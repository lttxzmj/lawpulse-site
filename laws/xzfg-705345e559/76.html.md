# 麻醉药品和精神药品管理条例第七十六条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/76.html

药品研究单位在普通药品的实验研究和研制过程中，产生本条例规定管制的麻醉药品和精神药品，未依照本条例的规定报告的，由药品监督管理部门责令改正，给予警告，没收违法药品；拒不改正的，责令停止实验研究和研制活动。
