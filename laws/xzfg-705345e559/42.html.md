# 麻醉药品和精神药品管理条例第四十二条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第四章使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/42.html

医疗机构抢救病人急需麻醉药品和第一类精神药品而本医疗机构无法提供时，可以从其他医疗机构或者定点批发企业紧急借用；抢救工作结束后，应当及时将借用情况报所在地设区的市级药品监督管理部门和卫生主管部门备案。
