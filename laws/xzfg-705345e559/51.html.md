# 麻醉药品和精神药品管理条例第五十一条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第六章运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/51.html

通过铁路运输麻醉药品和第一类精神药品的，应当使用集装箱或者铁路行李车运输，具体办法由国务院药品监督管理部门会同国务院铁路主管部门制定。
没有铁路需要通过公路或者水路运输麻醉药品和第一类精神药品的，应当由专人负责押运。
