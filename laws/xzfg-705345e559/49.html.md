# 麻醉药品和精神药品管理条例第四十九条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第五章储存
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/49.html

第二类精神药品经营企业应当在药品库房中设立独立的专库或者专柜储存第二类精神药品，并建立专用账册，实行专人管理。专用账册的保存期限应当自药品有效期期满之日起不少于5年。
