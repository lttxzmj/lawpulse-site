# 麻醉药品和精神药品管理条例第八十七条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第九章附则
- 数据核对至：2026-10-22

非药用类麻醉药品和精神药品管理的具体办法，由国务院公安部门会同国务院药品监督管理部门、国务院卫生主管部门依据本条例制定。
