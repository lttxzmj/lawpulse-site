# 麻醉药品和精神药品管理条例第七十一条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/71.html

本条例第三十四条、第三十五条规定的单位违反本条例的规定，购买麻醉药品和精神药品的，由药品监督管理部门没收违法购买的麻醉药品和精神药品，责令限期改正，给予警告；逾期不改正的，责令停产或者停止相关活动，并处2万元以上5万元以下的罚款。
