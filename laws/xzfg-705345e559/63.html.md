# 麻醉药品和精神药品管理条例第六十三条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第七章审批程序和监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/63.html

药品监督管理部门、卫生主管部门和公安机关应当互相通报麻醉药品和精神药品生产、经营企业和使用单位的名单以及其他管理信息。
各级药品监督管理部门应当将在麻醉药品药用原植物的种植以及麻醉药品和精神药品的实验研究、生产、经营、使用、储存、运输等各环节的管理中的审批、撤销等事项通报同级公安机关。
麻醉药品和精神药品的经营企业、使用单位报送各级药品监督管理部门的备案事项，应当同时报送同级公安机关。
