# 麻醉药品和精神药品管理条例第八条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第二章种植、实验研究和生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/8.html

麻醉药品药用原植物种植企业应当根据年度种植计划，种植麻醉药品药用原植物。
麻醉药品药用原植物种植企业应当向国务院药品监督管理部门和国务院农业主管部门定期报告种植情况。
