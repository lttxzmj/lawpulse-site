# 麻醉药品和精神药品管理条例第十九条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第二章种植、实验研究和生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/19.html

定点生产企业应当严格按照麻醉药品和精神药品年度生产计划安排生产，并依照规定向所在地省、自治区、直辖市人民政府药品监督管理部门报告生产情况。
