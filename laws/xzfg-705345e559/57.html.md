# 麻醉药品和精神药品管理条例第五十七条

- 法规：麻醉药品和精神药品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第七章审批程序和监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-705345e559/57.html

药品监督管理部门应当根据规定的职责权限，对麻醉药品药用原植物的种植以及麻醉药品和精神药品的实验研究、生产、经营、使用、储存、运输活动进行监督检查。
