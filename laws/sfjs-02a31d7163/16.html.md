# 最高人民法院关于审理生态环境侵权责任纠纷案件适用法律若干问题的解释第十六条

- 法规：最高人民法院关于审理生态环境侵权责任纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-02a31d7163/16.html
