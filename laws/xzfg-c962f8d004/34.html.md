# 医疗事故处理条例第三十四条

- 法规：医疗事故处理条例（现行有效）
- 章节：第三章医疗事故的技术鉴定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c962f8d004/34.html

医疗事故技术鉴定，可以收取鉴定费用。经鉴定，属于医疗事故的，鉴定费用由医疗机构支付；不属于医疗事故的，鉴定费用由提出医疗事故处理申请的一方支付。鉴定费用标准由省、自治区、直辖市人民政府价格主管部门会同同级财政部门、卫生行政部门规定。
