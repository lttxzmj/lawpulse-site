# 风景名胜区条例第四十二条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/42.html

违反本条例的规定，在国家级风景名胜区内修建缆车、索道等重大建设工程，项目的选址方案未经省、自治区、直辖市人民政府林业草原主管部门核准，县级以上地方人民政府有关部门核发选址意见书的，对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。
