# 风景名胜区条例第十七条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第三章规划
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/17.html

编制风景名胜区规划，应当采用招标等公平竞争的方式选择具有相应资质等级的单位承担。
风景名胜区规划应当按照经审定的风景名胜区范围、性质和保护目标，依照国家有关法律、法规和技术规范编制。
