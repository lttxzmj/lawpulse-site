# 风景名胜区条例第二十三条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第三章规划
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/23.html

风景名胜区总体规划的规划期届满前2年，规划的组织编制机关应当组织专家对规划进行评估，作出是否重新编制规划的决定。在新规划批准前，原规划继续有效。
