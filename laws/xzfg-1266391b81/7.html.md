# 风景名胜区条例第七条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第二章设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/7.html

设立风景名胜区，应当有利于保护和合理利用风景名胜资源。
新设立的风景名胜区与自然保护区不得重合或者交叉；已设立的风景名胜区与自然保护区重合或者交叉的，风景名胜区规划与自然保护区规划应当相协调。
