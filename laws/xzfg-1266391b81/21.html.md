# 风景名胜区条例第二十一条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第三章规划
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/21.html

风景名胜区规划经批准后，应当向社会公布，任何组织和个人有权查阅。
风景名胜区内的单位和个人应当遵守经批准的风景名胜区规划，服从规划管理。
风景名胜区规划未经批准的，不得在风景名胜区内进行各类建设活动。
