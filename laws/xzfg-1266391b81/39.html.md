# 风景名胜区条例第三十九条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第五章利用和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/39.html

风景名胜区管理机构不得从事以营利为目的的经营活动，不得将规划、管理和监督等行政管理职能委托给企业或者个人行使。
风景名胜区管理机构的工作人员，不得在风景名胜区内的企业兼职。
