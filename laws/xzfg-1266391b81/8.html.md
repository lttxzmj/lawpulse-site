# 风景名胜区条例第八条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第二章设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/8.html

风景名胜区划分为国家级风景名胜区和省级风景名胜区。
自然景观和人文景观能够反映重要自然变化过程和重大历史文化发展过程，基本处于自然状态或者保持历史原貌，具有国家代表性的，可以申请设立国家级风景名胜区；具有区域代表性的，可以申请设立省级风景名胜区。
