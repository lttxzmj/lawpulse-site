# 风景名胜区条例第十八条

- 法规：风景名胜区条例（现行有效，施行日期 2026-03-20）
- 章节：第三章规划
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1266391b81/18.html

编制风景名胜区规划，应当广泛征求有关部门、公众和专家的意见；必要时，应当进行听证。
风景名胜区规划报送审批的材料应当包括社会各界的意见以及意见采纳的情况和未予采纳的理由。
