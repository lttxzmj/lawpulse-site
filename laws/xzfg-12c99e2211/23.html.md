# 中华人民共和国野生植物保护条例第二十三条

- 法规：中华人民共和国野生植物保护条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-12c99e2211/23.html

未取得采集证或者未按照采集证的规定采集国家重点保护野生植物的，由野生植物行政主管部门没收所采集的野生植物和违法所得，可以并处违法所得10倍以下的罚款；有采集证的，并可以吊销采集证。
