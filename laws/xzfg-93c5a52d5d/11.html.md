# 音像制品管理条例第十一条

- 法规：音像制品管理条例（现行有效，施行日期 2025-01-20）
- 章节：第二章出版
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-93c5a52d5d/11.html

音像出版单位的年度出版计划和涉及国家安全、社会安定等方面的重大选题，应当经所在地省、自治区、直辖市人民政府出版行政主管部门审核后报国务院出版行政主管部门备案；重大选题音像制品未在出版前报备案的，不得出版。
