# 全国经济普查条例第二十八条

- 法规：全国经济普查条例（现行有效）
- 章节：第五章数据处理和质量控制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e69a005068/28.html

地方各级经济普查机构应当根据国务院经济普查领导小组办公室的统一规定，建立经济普查数据质量控制岗位责任制，并对经济普查实施中的每个环节实行质量控制和检查验收。
