# 全国经济普查条例第二十二条

- 法规：全国经济普查条例（现行有效）
- 章节：第四章经济普查的组织实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e69a005068/22.html

普查指导员和普查员有权查阅法人单位、产业活动单位和个体经营户与经济普查有关的财务会计、统计和业务核算等相关原始资料及有关经营证件，有权要求经济普查对象改正其经济普查表中不确实的内容。
