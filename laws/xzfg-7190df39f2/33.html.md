# 中华人民共和国道路交通安全法实施条例第三十三条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第三章道路通行条件
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/33.html

城市人民政府有关部门可以在不影响行人、车辆通行的情况下，在城市道路上施划停车泊位，并规定停车泊位的使用时间。
