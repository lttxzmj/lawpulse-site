# 中华人民共和国道路交通安全法实施条例第一百零一条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第六章执法监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/101.html

公安机关交通管理部门应当建立执法质量考核评议、执法责任制和执法过错追究制度，防止和纠正道路交通安全执法中的错误或者不当行为。
