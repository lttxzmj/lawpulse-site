# 中华人民共和国道路交通安全法实施条例第一百一十条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/110.html

当事人对公安机关交通管理部门及其交通警察的处罚有权进行陈述和申辩，交通警察应当充分听取当事人的陈述和申辩，不得因当事人陈述、申辩而加重其处罚。
