# 中华人民共和国道路交通安全法实施条例第六十九条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第四章道路通行规定 · 第三节非机动车通行规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/69.html

非机动车通过没有交通信号灯控制也没有交通警察指挥的交叉路口，除应当遵守第六十八条第(一)项、第(二)项和第(三)项的规定外，还应当遵守下列规定：
(一)有交通标志、标线控制的，让优先通行的一方先行；
(二)没有交通标志、标线控制的，在路口外慢行或者停车瞭望，让右方道路的来车先行；
(三)相对方向行驶的右转弯的非机动车让左转弯的车辆先行。
