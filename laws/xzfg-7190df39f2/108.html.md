# 中华人民共和国道路交通安全法实施条例第一百零八条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/108.html

交通警察按照简易程序当场作出行政处罚的，应当告知当事人道路交通安全违法行为的事实、处罚的理由和依据，并将行政处罚决定书当场交付被处罚人。
