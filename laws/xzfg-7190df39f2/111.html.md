# 中华人民共和国道路交通安全法实施条例第一百一十一条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第八章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/111.html

本条例所称上道路行驶的拖拉机，是指手扶拖拉机等最高设计行驶速度不超过每小时20公里的轮式拖拉机和最高设计行驶速度不超过每小时40公里、牵引挂车方可从事道路运输的轮式拖拉机。
