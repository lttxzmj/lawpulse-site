# 中华人民共和国道路交通安全法实施条例第六十四条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第四章道路通行规定 · 第二节机动车通行规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/64.html
