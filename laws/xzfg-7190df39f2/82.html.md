# 中华人民共和国道路交通安全法实施条例第八十二条

- 法规：中华人民共和国道路交通安全法实施条例（现行有效，施行日期 2017-10-07）
- 章节：第四章道路通行规定 · 第五节高速公路的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7190df39f2/82.html

机动车在高速公路上行驶，不得有下列行为：
(一)倒车、逆行、穿越中央分隔带掉头或者在车道内停车；
(二)在匝道、加速车道或者减速车道上超车；
(三)骑、轧车行道分界线或者在路肩上行驶；
(四)非紧急情况时在应急车道行驶或者停车；
(五)试车或者学习驾驶机动车。
