# 突发公共卫生事件应急条例第四十四条

- 法规：突发公共卫生事件应急条例（现行有效）
- 章节：第四章应急处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b658b32c37/44.html

在突发事件中需要接受隔离治疗、医学观察措施的病人、疑似病人和传染病病人密切接触者在卫生行政主管部门或者有关机构采取医学措施时应当予以配合；拒绝配合的，由公安机关依法协助强制执行。
