# 突发公共卫生事件应急条例第三十二条

- 法规：突发公共卫生事件应急条例（现行有效）
- 章节：第四章应急处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b658b32c37/32.html

突发事件发生后，国务院有关部门和县级以上地方人民政府及其有关部门，应当保证突发事件应急处理所需的医疗救护设备、救治药品、医疗器械等物资的生产、供应；铁路、交通、民用航空行政主管部门应当保证及时运送。
