# 突发公共卫生事件应急条例第三条

- 法规：突发公共卫生事件应急条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b658b32c37/3.html

突发事件发生后，国务院设立全国突发事件应急处理指挥部，由国务院有关部门和军队有关部门组成，国务院主管领导人担任总指挥，负责对全国突发事件应急处理的统一领导、统一指挥。
国务院卫生行政主管部门和其他有关部门，在各自的职责范围内做好突发事件应急处理的有关工作。
