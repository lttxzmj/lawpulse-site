# 突发公共卫生事件应急条例第四十三条

- 法规：突发公共卫生事件应急条例（现行有效）
- 章节：第四章应急处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b658b32c37/43.html

县级以上各级人民政府应当提供必要资金，保障因突发事件致病、致残的人员得到及时、有效的救治。具体办法由国务院财政部门、卫生行政主管部门和劳动保障行政主管部门制定。
