# 集成电路布图设计保护条例第四十一条

- 法规：集成电路布图设计保护条例（现行有效，施行日期 2026-10-15）
- 章节：第四章布图设计专有权的行使
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c1477c251f/41.html

取得使用布图设计非自愿许可的自然人、法人或者非法人组织不享有独占的使用权，并且无权允许他人使用。
