# 保安服务管理条例第二十五条

- 法规：保安服务管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章保安服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cbda2a3079/25.html

保安服务中使用的技术防范产品，应当符合有关的产品质量要求。保安服务中安装监控设备应当遵守国家有关技术规范，使用监控设备不得侵犯他人合法权益或者个人隐私。
保安服务中形成的监控影像资料、报警记录，应当至少留存30日备查，保安从业单位和客户单位不得删改或者扩散。
