# 保安服务管理条例第四十四条

- 法规：保安服务管理条例（现行有效，施行日期 2022-05-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cbda2a3079/44.html

保安从业单位因保安员不执行违法指令而解除与保安员的劳动合同，降低其劳动报酬和其他待遇，或者停缴、少缴依法应当为其缴纳的社会保险费的，对保安从业单位的处罚和对保安员的赔偿依照有关劳动合同和社会保险的法律、行政法规的规定执行。
