# 保安服务管理条例第四十六条

- 法规：保安服务管理条例（现行有效，施行日期 2022-05-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cbda2a3079/46.html

保安员在保安服务中造成他人人身伤亡、财产损失的，由保安从业单位赔付；保安员有故意或者重大过失的，保安从业单位可以依法向保安员追偿。
