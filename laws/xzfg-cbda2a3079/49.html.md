# 保安服务管理条例第四十九条

- 法规：保安服务管理条例（现行有效，施行日期 2022-05-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cbda2a3079/49.html

公安机关的人民警察在保安服务活动监督管理工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分；构成犯罪的，依法追究刑事责任。
