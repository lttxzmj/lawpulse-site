# 保安服务管理条例第三十九条

- 法规：保安服务管理条例（现行有效，施行日期 2022-05-01）
- 章节：第七章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cbda2a3079/39.html

县级以上人民政府公安机关应当公布投诉方式，受理社会公众对保安从业单位、保安培训单位和保安员的投诉。接到投诉的公安机关应当及时调查处理，并反馈查处结果。
