# 中华人民共和国旅游法第二十三条

- 法规：中华人民共和国旅游法（现行有效，施行日期 2018-10-26）
- 章节：第三章旅游规划和促进
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-100415b86b/23.html

国务院和县级以上地方人民政府应当制定并组织实施有利于旅游业持续健康发展的产业政策，推进旅游休闲体系建设，采取措施推动区域旅游合作，鼓励跨区域旅游线路和产品开发，促进旅游与工业、农业、商业、文化、卫生、体育、科教等领域的融合，扶持少数民族地区、革命老区、边远地区和贫困地区旅游业发展。
