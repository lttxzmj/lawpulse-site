# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第四十三条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/43.html

海事强制令由海事法院执行。被申请人、其他相关单位或者个人不履行海事强制令的，海事法院应当依据民事诉讼法的有关规定强制执行。
