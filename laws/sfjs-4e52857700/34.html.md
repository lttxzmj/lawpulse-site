# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第三十四条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/34.html
