# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第二十一条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/21.html

诉讼或者仲裁前申请海事请求保全适用海事诉讼特别程序法第十四条的规定。外国法院已受理相关海事案件或者有关纠纷已经提交仲裁，但涉案财产在中华人民共和国领域内，当事人向财产所在地的海事法院提出海事请求保全申请的，海事法院应当受理。
