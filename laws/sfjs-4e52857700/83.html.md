# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第八十三条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/83.html

利害关系人依据海事诉讼特别程序法第一百零六条的规定对申请人设立海事赔偿责任限制基金提出异议的，海事法院应当对设立基金申请人的主体资格、事故所涉及的债权性质和申请设立基金的数额进行审查。
