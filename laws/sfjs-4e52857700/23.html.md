# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第二十三条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/23.html

被请求人或者利害关系人依据海事诉讼特别程序法第二十条的规定要求海事请求人赔偿损失，向采取海事请求保全措施的海事法院提起诉讼的，海事法院应当受理。
