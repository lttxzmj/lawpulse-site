# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第八十四条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/84.html

准予申请人设立海事赔偿责任限制基金的裁定生效后，申请人应当在三日内在海事法院设立海事赔偿责任限制基金。申请人逾期未设立基金的，按自动撤回申请处理。
