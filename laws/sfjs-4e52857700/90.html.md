# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第九十条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/90.html

债权人依据海事诉讼特别程序法第一百一十六条规定向受理债权登记的海事法院提起确权诉讼的，应当在办理债权登记后七日内提起。
