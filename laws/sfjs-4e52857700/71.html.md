# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第七十一条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/71.html

申请人依据海事诉讼特别程序法第一百条的规定向海事法院申请公示催告的，应当递交申请书。申请书应当载明：提单等提货凭证的种类、编号、货物品名、数量、承运人、托运人、收货人、承运船舶名称、航次以及背书情况和申请的理由、事实等。有副本的应当附有单证的副本。
