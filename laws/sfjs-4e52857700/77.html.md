# 最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释第七十七条

- 法规：最高人民法院关于适用《中华人民共和国海事诉讼特别程序法》若干问题的解释（现行有效，施行日期 2003-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4e52857700/77.html

公示催告期间无人申报的，海事法院应当根据申请人的申请作出判决，宣告提单或者有关提货凭证无效。判决内容应当公告，并通知承运人、承运人的代理人或者货物保管人。自判决公告之日起，申请人有权请求承运人、承运人的代理人或者货物保管人交付货物。
