# 最高人民法院关于审理商标授权确权行政案件若干问题的规定第二十二条

- 法规：最高人民法院关于审理商标授权确权行政案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a6af4a0ad4/22.html

当事人主张诉争商标损害角色形象著作权的，人民法院按照本规定第十九条进行审查。
对于著作权保护期限内的作品，如果作品名称、作品中的角色名称等具有较高知名度，将其作为商标使用在相关商品上容易导致相关公众误认为其经过权利人的许可或者与权利人存在特定联系，当事人以此主张构成在先权益的，人民法院予以支持。
