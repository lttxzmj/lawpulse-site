# 最高人民法院关于审理商标授权确权行政案件若干问题的规定第二十八条

- 法规：最高人民法院关于审理商标授权确权行政案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a6af4a0ad4/28.html

人民法院审理商标授权确权行政案件的过程中，国家知识产权局对诉争商标予以驳回、不予核准注册或者予以无效宣告的事由不复存在的，人民法院可以依据新的事实撤销国家知识产权局相关裁决，并判令其根据变更后的事实重新作出裁决。
