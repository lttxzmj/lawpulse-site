# 最高人民法院关于审理商标授权确权行政案件若干问题的规定第二十五条

- 法规：最高人民法院关于审理商标授权确权行政案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a6af4a0ad4/25.html

人民法院判断诉争商标申请人是否“恶意注册”他人驰名商标，应综合考虑引证商标的知名度、诉争商标申请人申请诉争商标的理由以及使用诉争商标的具体情形来判断其主观意图。引证商标知名度高、诉争商标申请人没有正当理由的，人民法院可以推定其注册构成商标法第四十五条第一款所指的“恶意注册”。
