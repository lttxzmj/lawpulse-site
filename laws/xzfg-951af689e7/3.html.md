# 印刷业管理条例第三条

- 法规：印刷业管理条例（现行有效，施行日期 2025-01-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-951af689e7/3.html

印刷业经营者必须遵守有关法律、法规和规章，讲求社会效益。
禁止印刷含有反动、淫秽、迷信内容和国家明令禁止印刷的其他内容的出版物、包装装潢印刷品和其他印刷品。
