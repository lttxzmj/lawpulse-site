# 印刷业管理条例第十一条

- 法规：印刷业管理条例（现行有效，施行日期 2025-01-20）
- 章节：第二章印刷企业的设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-951af689e7/11.html

出版行政部门应当自收到依据本条例第十条提出的申请之日起60日内作出批准或者不批准的决定。批准申请的，应当发给印刷经营许可证；不批准申请的，应当通知申请人并说明理由。
印刷经营许可证应当注明印刷企业所从事的印刷经营活动的种类。
印刷经营许可证不得出售、出租、出借或者以其他形式转让。
