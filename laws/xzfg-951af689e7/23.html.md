# 印刷业管理条例第二十三条

- 法规：印刷业管理条例（现行有效，施行日期 2025-01-20）
- 章节：第三章出版物的印刷
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-951af689e7/23.html

印刷企业不得盗印出版物，不得销售、擅自加印或者接受第三人委托加印受委托印刷的出版物，不得将接受委托印刷的出版物纸型及印刷底片等出售、出租、出借或者以其他形式转让给其他单位或者个人。
