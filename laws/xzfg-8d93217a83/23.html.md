# 中华人民共和国两用物项出口管制条例第二十三条

- 法规：中华人民共和国两用物项出口管制条例（现行有效，施行日期 2024-12-01）
- 章节：第三章管制措施 · 第二节最终用户和最终用途管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8d93217a83/23.html

国务院商务主管部门建立两用物项最终用户和最终用途风险管理制度，对两用物项的最终用户和最终用途进行评估、核查，加强最终用户和最终用途管理。
