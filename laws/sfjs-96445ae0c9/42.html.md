# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）第四十二条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-96445ae0c9/42.html

管理人收到债权人提出的主张债务抵销的通知后，经审查无异议的，抵销自管理人收到通知之日起生效。
管理人对抵销主张有异议的，应当在约定的异议期限内或者自收到主张债务抵销的通知之日起三个月内向人民法院提起诉讼。无正当理由逾期提起的，人民法院不予支持。
人民法院判决驳回管理人提起的抵销无效诉讼请求的，该抵销自管理人收到主张债务抵销的通知之日起生效。
