# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）第二十八条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-96445ae0c9/28.html

权利人行使取回权时未依法向管理人支付相关的加工费、保管费、托运费、委托费、代销费等费用，管理人拒绝其取回相关财产的，人民法院应予支持。
