# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）第二十六条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-96445ae0c9/26.html

权利人依据企业破产法第三十八条的规定行使取回权，应当在破产财产变价方案或者和解协议、重整计划草案提交债权人会议表决前向管理人提出。权利人在上述期限后主张取回相关财产的，应当承担延迟行使取回权增加的相关费用。
