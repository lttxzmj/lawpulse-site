# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）第四十一条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-96445ae0c9/41.html

债权人依据企业破产法第四十条的规定行使抵销权，应当向管理人提出抵销主张。
管理人不得主动抵销债务人与债权人的互负债务，但抵销使债务人财产受益的除外。
