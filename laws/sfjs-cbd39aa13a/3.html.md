# 最高人民法院关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的规定第三条

- 法规：最高人民法院关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-cbd39aa13a/3.html

原告起诉网络服务提供者，网络服务提供者以涉嫌侵权的信息系网络用户发布为由抗辩的，人民法院可以根据原告的请求及案件的具体情况，责令网络服务提供者向人民法院提供能够确定涉嫌侵权的网络用户的姓名（名称）、联系方式、网络地址等信息。
网络服务提供者无正当理由拒不提供的，人民法院可以依据民事诉讼法第一百一十四条的规定对网络服务提供者采取处罚等措施。
原告根据网络服务提供者提供的信息请求追加网络用户为被告的，人民法院应予准许。
