# 国务院行政机构设置和编制管理条例第十四条

- 法规：国务院行政机构设置和编制管理条例（现行有效）
- 章节：第二章机构设置管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be8c32ff08/14.html

国务院行政机构的司级内设机构的增设、撤销或者合并，经国务院机构编制管理机关审核方案，报国务院批准。
国务院行政机构的处级内设机构的设立、撤销或者合并，由国务院行政机构根据国家有关规定决定，按年度报国务院机构编制管理机关备案。
