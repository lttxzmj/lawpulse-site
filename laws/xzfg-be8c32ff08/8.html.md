# 国务院行政机构设置和编制管理条例第八条

- 法规：国务院行政机构设置和编制管理条例（现行有效）
- 章节：第二章机构设置管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be8c32ff08/8.html

国务院直属机构、国务院办事机构和国务院组成部门管理的国家行政机构的设立、撤销或者合并由国务院机构编制管理机关提出方案，报国务院决定。
