# 国务院行政机构设置和编制管理条例第十六条

- 法规：国务院行政机构设置和编制管理条例（现行有效）
- 章节：第二章机构设置管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be8c32ff08/16.html

国务院行政机构及其司级内设机构的名称应当规范、明确，并与该机构的类型和职能相称。
国务院行政机构及其司级内设机构不得擅自变更名称。
