# 国务院行政机构设置和编制管理条例第二十三条

- 法规：国务院行政机构设置和编制管理条例（现行有效）
- 章节：第四章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be8c32ff08/23.html

国务院行政机构违反本条例规定，有下列行为之一的，由国务院机构编制管理机关责令限期纠正；逾期不纠正的，由国务院机构编制管理机关建议国务院或者国务院有关部门对负有直接责任的主管人员和其他直接责任人员依法给予行政处分：
(一)擅自设立司级内设机构的；
(二)擅自扩大职能的；
(三)擅自变更机构名称的；
(四)擅自超过核定的编制使用工作人员的；
(五)有违反机构设置和编制管理法律、行政法规的其他行为的。
