# 国务院行政机构设置和编制管理条例第三条

- 法规：国务院行政机构设置和编制管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be8c32ff08/3.html

国务院根据宪法和国务院组织法的规定，行使国务院行政机构设置和编制管理职权。
国务院机构编制管理机关在国务院领导下，负责国务院行政机构设置和编制管理的具体工作。
