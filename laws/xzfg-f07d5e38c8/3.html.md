# 废旧金属收购业治安管理办法第三条

- 法规：废旧金属收购业治安管理办法（现行有效，施行日期 2023-07-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f07d5e38c8/3.html

生产性废旧金属，按照国务院有关规定由有权经营生产性废旧金属收购业的企业收购。收购废旧金属的其他企业和个体工商户只能收购非生产性废旧金属，不得收购生产性废旧金属。
