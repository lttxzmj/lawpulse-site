# 最高人民法院关于审理票据纠纷案件若干问题的规定第四十三条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/43.html

因更改银行汇票的实际结算金额引起纠纷而提起诉讼，当事人请求认定汇票效力的，人民法院应当认定该银行汇票无效。
