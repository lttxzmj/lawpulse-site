# 最高人民法院关于审理票据纠纷案件若干问题的规定第六十九条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/69.html

付款人及其代理付款人有下列情形之一的，应当自行承担责任：
（一）未依照票据法第五十七条的规定对提示付款人的合法身份证明或者有效证件以及汇票背书的连续性履行审查义务而错误付款的；
（二）公示催告期间对公示催告的票据付款的；
（三）收到人民法院的止付通知后付款的；
（四）其他以恶意或者重大过失付款的。
