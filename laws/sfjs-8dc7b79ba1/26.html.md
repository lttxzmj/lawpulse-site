# 最高人民法院关于审理票据纠纷案件若干问题的规定第二十六条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/26.html

出票人已经签章但未记载代理付款人的银行汇票丧失后，失票人依法向付款人即出票银行所在地人民法院申请公示催告的，人民法院应当依法受理。
