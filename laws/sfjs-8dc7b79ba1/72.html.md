# 最高人民法院关于审理票据纠纷案件若干问题的规定第七十二条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/72.html

因出票人签发空头支票、与其预留本名的签名式样或者印鉴不符的支票给他人造成损失的，支票的出票人和背书人应当依法承担民事责任。
