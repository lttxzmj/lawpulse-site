# 最高人民法院关于审理票据纠纷案件若干问题的规定第四十七条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/47.html

依照票据法第二十七条的规定，票据的出票人在票据上记载“不得转让”字样，票据持有人背书转让的，背书行为无效。背书转让后的受让人不得享有票据权利，票据的出票人、承兑人对受让人不承担票据责任。
