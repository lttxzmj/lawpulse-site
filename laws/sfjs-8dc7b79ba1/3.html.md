# 最高人民法院关于审理票据纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/3.html

依照票据法第三十六条的规定，票据被拒绝承兑、被拒绝付款或者汇票、支票超过提示付款期限后，票据持有人背书转让的，被背书人以背书人为被告行使追索权而提起诉讼的，人民法院应当依法受理。
