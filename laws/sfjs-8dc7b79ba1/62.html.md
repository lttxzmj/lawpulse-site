# 最高人民法院关于审理票据纠纷案件若干问题的规定第六十二条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/62.html

人民法院审理票据纠纷案件，适用票据法的规定；票据法没有规定的，适用《中华人民共和国民法典》等法律以及国务院制定的行政法规。
中国人民银行制定并公布施行的有关行政规章与法律、行政法规不抵触的，可以参照适用。
