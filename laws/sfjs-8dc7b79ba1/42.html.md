# 最高人民法院关于审理票据纠纷案件若干问题的规定第四十二条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/42.html

依照票据法第九条以及《票据管理实施办法》的规定，票据金额的中文大写与数码不一致，或者票据载明的金额、出票日期或者签发日期、收款人名称更改，或者违反规定加盖银行部门印章代替专用章，付款人或者代理付款人对此类票据付款的，应当承担责任。
