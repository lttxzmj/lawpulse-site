# 最高人民法院关于审理票据纠纷案件若干问题的规定第五十三条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/53.html

依照票据法第三十四条和第三十五条的规定，背书人在票据上记载“不得转让”字样，其后手以此票据进行贴现、质押的，原背书人对后手的被背书人不承担票据责任。
