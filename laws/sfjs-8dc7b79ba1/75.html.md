# 最高人民法院关于审理票据纠纷案件若干问题的规定第七十五条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/75.html

依照票据法第一百零六条的规定，由于出票人制作票据，或者其他票据债务人未按照法定条件在票据上签章，给他人造成损失的，除应当按照所记载事项承担票据责任外，还应当承担相应的民事责任。
持票人明知或者应当知道前款情形而接受的，可以适当减轻出票人或者票据债务人的责任。
