# 最高人民法院关于审理票据纠纷案件若干问题的规定第四十九条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/49.html

依照票据法第三十一条的规定，连续背书的第一背书人应当是在票据上记载的收款人，最后的票据持有人应当是最后一次背书的被背书人。
