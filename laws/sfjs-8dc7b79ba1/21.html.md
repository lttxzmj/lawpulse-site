# 最高人民法院关于审理票据纠纷案件若干问题的规定第二十一条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/21.html

票据法第七十条、第七十一条所称中国人民银行规定的利率，是指中国人民银行规定的企业同期流动资金贷款利率。
