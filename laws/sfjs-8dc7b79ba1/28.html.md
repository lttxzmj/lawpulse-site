# 最高人民法院关于审理票据纠纷案件若干问题的规定第二十八条

- 法规：最高人民法院关于审理票据纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8dc7b79ba1/28.html

失票人通知票据付款人挂失止付后三日内向人民法院申请公示催告的，公示催告申请书应当载明下列内容：
（一）票面金额；
（二）出票人、持票人、背书人；
（三）申请的理由、事实；
（四）通知票据付款人或者代理付款人挂失止付的时间；
（五）付款人或者代理付款人的名称、通信地址、电话号码等。
