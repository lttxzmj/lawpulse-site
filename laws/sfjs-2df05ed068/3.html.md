# 最高人民法院关于审理食品药品纠纷案件适用法律若干问题的规定第三条

- 法规：最高人民法院关于审理食品药品纠纷案件适用法律若干问题的规定（现行有效，施行日期 2021-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-2df05ed068/3.html

因食品、药品质量问题发生纠纷，购买者向生产者、销售者主张权利，生产者、销售者以购买者明知食品、药品存在质量问题而仍然购买为由进行抗辩的，人民法院不予支持。
