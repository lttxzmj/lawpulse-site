# 大型群众性活动安全管理条例第二十五条

- 法规：大型群众性活动安全管理条例（现行有效）
- 章节：第五章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e4067d5a9e/25.html

县级以上各级人民政府、国务院部门直接举办的大型群众性活动的安全保卫工作，由举办活动的人民政府、国务院部门负责，不实行安全许可制度，但应当按照本条例的有关规定，责成或者会同有关公安机关制订更加严格的安全保卫工作方案，并组织实施。
