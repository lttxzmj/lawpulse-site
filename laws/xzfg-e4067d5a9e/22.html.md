# 大型群众性活动安全管理条例第二十二条

- 法规：大型群众性活动安全管理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e4067d5a9e/22.html

在大型群众性活动举办过程中发生公共安全事故，安全责任人不立即启动应急救援预案或者不立即向公安机关报告的，由公安机关对安全责任人和其他直接责任人员处5000元以上5万元以下罚款。
