# 大型群众性活动安全管理条例第二十三条

- 法规：大型群众性活动安全管理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e4067d5a9e/23.html

参加大型群众性活动的人员有违反本条例第九条规定行为的，由公安机关给予批评教育；有危害社会治安秩序、威胁公共安全行为的，公安机关可以将其强行带离现场，依法给予治安管理处罚；构成犯罪的，依法追究刑事责任。
