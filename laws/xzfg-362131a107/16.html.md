# 中华人民共和国军品出口管理条例第十六条

- 法规：中华人民共和国军品出口管理条例（现行有效）
- 章节：第三章军品出口管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-362131a107/16.html

重大的军品出口项目、合同，应当经国家军品出口主管部门会同国务院、中央军事委员会的有关部门审查，报国务院和中央军事委员会批准。
