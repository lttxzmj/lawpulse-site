# 中华人民共和国军品出口管理条例第二十八条

- 法规：中华人民共和国军品出口管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-362131a107/28.html

国家军品出口管理工作人员滥用职权、玩忽职守或者利用职务上的便利收受、索取他人财物，触犯刑律的，依照刑法关于滥用职权罪、玩忽职守罪、受贿罪或者其他罪的规定，依法追究刑事责任；尚不够刑事处罚的，依法给予行政处分。
