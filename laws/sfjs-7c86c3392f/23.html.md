# 最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释（二）第二十三条

- 法规：最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7c86c3392f/23.html

被诉侵权技术方案或者外观设计落入在先的涉案专利权的保护范围，被诉侵权人以其技术方案或者外观设计被授予专利权为由抗辩不侵犯涉案专利权的，人民法院不予支持。
