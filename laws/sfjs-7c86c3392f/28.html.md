# 最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释（二）第二十八条

- 法规：最高人民法院关于审理侵犯专利权纠纷案件应用法律若干问题的解释（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-7c86c3392f/28.html

权利人、侵权人依法约定专利侵权的赔偿数额或者赔偿计算方法，并在专利侵权诉讼中主张依据该约定确定赔偿数额的，人民法院应予支持。
