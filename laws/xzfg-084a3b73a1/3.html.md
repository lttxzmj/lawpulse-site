# 中华人民共和国海关行政处罚实施条例第三条

- 法规：中华人民共和国海关行政处罚实施条例（现行有效，施行日期 2022-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-084a3b73a1/3.html

海关行政处罚由发现违法行为的海关管辖，也可以由违法行为发生地海关管辖。
2个以上海关都有管辖权的案件，由最先发现违法行为的海关管辖。
管辖不明确的案件，由有关海关协商确定管辖，协商不成的，报请共同的上级海关指定管辖。
重大、复杂的案件，可以由海关总署指定管辖。
