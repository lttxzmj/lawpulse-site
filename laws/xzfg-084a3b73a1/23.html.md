# 中华人民共和国海关行政处罚实施条例第二十三条

- 法规：中华人民共和国海关行政处罚实施条例（现行有效，施行日期 2022-05-01）
- 章节：第三章违反海关监管规定的行为及其处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-084a3b73a1/23.html

有下列行为之一的，予以警告，可以处3万元以下罚款：
（一）擅自开启或者损毁海关封志的；
（二）遗失海关制发的监管单证、手册等凭证，妨碍海关监管的；
（三）有违反海关监管规定的其他行为，致使海关不能或者中断对进出境运输工具、物品实施监管的。
