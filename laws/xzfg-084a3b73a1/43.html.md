# 中华人民共和国海关行政处罚实施条例第四十三条

- 法规：中华人民共和国海关行政处罚实施条例（现行有效，施行日期 2022-05-01）
- 章节：第四章对违反海关法行为的调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-084a3b73a1/43.html

海关查问违法嫌疑人或者询问证人，应当个别进行，并告知其权利和作伪证应当承担的法律责任。违法嫌疑人、证人必须如实陈述、提供证据。
海关查问违法嫌疑人或者询问证人应当制作笔录，并当场交其辨认，没有异议的，立即签字确认；有异议的，予以更正后签字确认。
严禁刑讯逼供或者以威胁、引诱、欺骗等非法手段收集证据。
海关查问违法嫌疑人，可以到违法嫌疑人的所在单位或者住处进行，也可以要求其到海关或者海关指定的地点进行。
