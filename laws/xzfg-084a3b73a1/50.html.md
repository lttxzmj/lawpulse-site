# 中华人民共和国海关行政处罚实施条例第五十条

- 法规：中华人民共和国海关行政处罚实施条例（现行有效，施行日期 2022-05-01）
- 章节：第五章海关行政处罚的决定和执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-084a3b73a1/50.html

案件调查终结，海关关长应当对调查结果进行审查，根据不同情况，依法作出决定。
对情节复杂或者重大违法行为给予较重的行政处罚，应当由海关案件审理委员会集体讨论决定。
