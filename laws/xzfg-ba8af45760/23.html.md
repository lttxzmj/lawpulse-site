# 禁止传销条例第二十三条

- 法规：禁止传销条例（现行有效）
- 章节：第三章查处措施和程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba8af45760/23.html

对于经查证属于传销行为的，工商行政管理部门、公安机关可以向社会公开发布警示、提示。
向社会公开发布警示、提示应当经县级以上工商行政管理部门主要负责人或者公安机关主要负责人批准。
