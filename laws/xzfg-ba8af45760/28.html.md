# 禁止传销条例第二十八条

- 法规：禁止传销条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba8af45760/28.html

有本条例第十条规定的行为或者拒绝、阻碍工商行政管理部门的执法人员依法查处传销行为，构成违反治安管理行为的，由公安机关依照治安管理的法律、行政法规规定处罚；构成犯罪的，依法追究刑事责任。
