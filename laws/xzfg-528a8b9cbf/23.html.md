# 城镇排水与污水处理条例第二十三条

- 法规：城镇排水与污水处理条例（现行有效，施行日期 2026-08-15）
- 章节：第三章排水
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-528a8b9cbf/23.html

城镇排水主管部门应当加强对排放口设置以及预处理设施和水质、水量检测设施建设的指导和监督；对不符合规划要求或者国家有关规定的，应当要求排水户采取措施，限期整改。
