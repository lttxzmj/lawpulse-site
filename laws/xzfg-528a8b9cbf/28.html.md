# 城镇排水与污水处理条例第二十八条

- 法规：城镇排水与污水处理条例（现行有效，施行日期 2026-08-15）
- 章节：第四章污水处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-528a8b9cbf/28.html

城镇排水主管部门应当与城镇污水处理设施维护运营单位签订维护运营合同，明确双方权利义务。
城镇污水处理设施维护运营单位应当依照法律、法规和有关规定以及维护运营合同进行维护运营，定期向社会公开有关维护运营信息，并接受相关部门和社会公众的监督。
