# 城镇排水与污水处理条例第四十五条

- 法规：城镇排水与污水处理条例（现行有效，施行日期 2026-08-15）
- 章节：第五章设施维护与保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-528a8b9cbf/45.html

审计机关应当加强对城镇排水与污水处理设施建设、运营、维护和保护等资金筹集、管理和使用情况的监督，并公布审计结果。
