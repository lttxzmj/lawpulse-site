# 城镇排水与污水处理条例第四十一条

- 法规：城镇排水与污水处理条例（现行有效，施行日期 2026-08-15）
- 章节：第五章设施维护与保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-528a8b9cbf/41.html

城镇排水主管部门应当会同有关部门，按照国家有关规定划定城镇排水与污水处理设施保护范围，并向社会公布。
在保护范围内，有关单位从事爆破、钻探、打桩、顶进、挖掘、取土等可能影响城镇排水与污水处理设施安全的活动的，应当与设施维护运营单位等共同制定设施保护方案，并采取相应的安全防护措施。
