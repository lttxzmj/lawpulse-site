# 最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释第二十一条

- 法规：最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-maimai/21.html

买卖合同当事人一方以对方违约为由主张支付违约金，对方以合同不成立、合同未生效、合同无效或者不构成违约等为由进行免责抗辩而未主张调整过高的违约金的，人民法院应当就法院若不支持免责抗辩，当事人是否需要主张调整违约金进行释明。
一审法院认为免责抗辩成立且未予释明，二审法院认为应当判决支付违约金的，可以直接释明并改判。
