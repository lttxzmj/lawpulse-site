# 最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释第二十三条

- 法规：最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-maimai/23.html

买卖合同当事人一方因对方违约而获有利益，违约方主张从损失赔偿额中扣除该部分利益的，人民法院应予支持。
