# 最高人民法院关于审理破坏广播电视设施等刑事案件具体应用法律若干问题的解释第八条

- 法规：最高人民法院关于审理破坏广播电视设施等刑事案件具体应用法律若干问题的解释（现行有效，施行日期 2011-06-13）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e271eee777/8.html

本解释所称广播电视台中直接关系节目播出的设施、广播电视传输网内的设施，参照国家广播电视行政主管部门和其他相关部门的有关规定确定。
