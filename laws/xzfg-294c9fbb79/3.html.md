# 缔结条约管理办法第三条

- 法规：缔结条约管理办法（现行有效，施行日期 2023-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-294c9fbb79/3.html

外交部在国务院领导下管理缔结条约的具体事务，指导、督促国务院有关部门依照法定程序办理缔结条约工作。
国务院有关部门在各自职权范围内负责办理缔结条约的相关工作。
