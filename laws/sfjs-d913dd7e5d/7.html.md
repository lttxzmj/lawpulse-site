# 最高人民法院关于审理行政许可案件若干问题的规定第七条

- 法规：最高人民法院关于审理行政许可案件若干问题的规定（现行有效，施行日期 2010-01-04）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d913dd7e5d/7.html

作为被诉行政许可行为基础的其他行政决定或者文书存在以下情形之一的，人民法院不予认可：
（一）明显缺乏事实根据；
（二）明显缺乏法律依据；
（三）超越职权；
（四）其他重大明显违法情形。
