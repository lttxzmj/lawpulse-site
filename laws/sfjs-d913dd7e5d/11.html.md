# 最高人民法院关于审理行政许可案件若干问题的规定第十一条

- 法规：最高人民法院关于审理行政许可案件若干问题的规定（现行有效，施行日期 2010-01-04）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d913dd7e5d/11.html

人民法院审理不予行政许可决定案件，认为原告请求准予许可的理由成立，且被告没有裁量余地的，可以在判决理由写明，并判决撤销不予许可决定，责令被告重新作出决定。
