# 中华人民共和国人民币管理条例第十六条

- 法规：中华人民共和国人民币管理条例（现行有效）
- 章节：第三章发行和回收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ee5342b684/16.html

中国人民银行发行新版人民币，应当报国务院批准。
中国人民银行应当将新版人民币的发行时间、面额、图案、式样、规格、主色调、主要特征等予以公告。
中国人民银行不得在新版人民币发行公告发布前将新版人民币支付给金融机构。
