# 电力供应与使用条例第二十一条

- 法规：电力供应与使用条例（现行有效）
- 章节：第四章电力供应
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-483303739a/21.html

因抢险救灾需要紧急供电时，供电企业必须尽速安排供电。所需工程费用和应付电费由有关地方人民政府有关部门从抢险救灾经费中支出，但是抗旱用电应当由用户交付电费。
