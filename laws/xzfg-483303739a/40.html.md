# 电力供应与使用条例第四十条

- 法规：电力供应与使用条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-483303739a/40.html

违反本条例第三十条规定，违章用电的，供电企业可以根据违章事实和造成的后果追缴电费，并按照国务院电力管理部门的规定加收电费和国家规定的其他费用；情节严重的，可以按照国家规定的程序停止供电。
