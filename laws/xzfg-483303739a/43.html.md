# 电力供应与使用条例第四十三条

- 法规：电力供应与使用条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-483303739a/43.html

因电力运行事故给用户或者第三人造成损害的，供电企业应当依法承担赔偿责任。
因用户或者第三人的过错给供电企业或者其他用户造成损害的，该用户或者第三人应当依法承担赔偿责任。
