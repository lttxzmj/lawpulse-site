# 电力供应与使用条例第二十六条

- 法规：电力供应与使用条例（现行有效）
- 章节：第四章电力供应
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-483303739a/26.html

用户应当安装用电计量装置。用户使用的电力、电量，以计量检定机构依法认可的用电计量装置的记录为准。用电计量装置，应当安装在供电设施与受电设施的产权分界处。
安装在用户处的用电计量装置，由用户负责保护。
