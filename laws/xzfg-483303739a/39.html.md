# 电力供应与使用条例第三十九条

- 法规：电力供应与使用条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-483303739a/39.html

违反本条例第二十七条规定，逾期未交付电费的，供电企业可以从逾期之日起，每日按照电费总额的1‰至3‰加收违约金，具体比例由供用电双方在供用电合同中约定；自逾期之日起计算超过30日，经催交仍未交付电费的，供电企业可以按照国家规定的程序停止供电。
