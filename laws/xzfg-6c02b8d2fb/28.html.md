# 中华人民共和国价格管理条例第二十八条

- 法规：中华人民共和国价格管理条例（现行有效）
- 章节：第五章价格监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6c02b8d2fb/28.html

物价检查人员必须依法办事。对滥用职权、贪污受贿、徇私舞弊、玩忽职守的，依照国家有关规定给予处分；情节严重，构成犯罪的，由司法机关依法追究刑事责任。
