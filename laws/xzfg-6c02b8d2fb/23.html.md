# 中华人民共和国价格管理条例第二十三条

- 法规：中华人民共和国价格管理条例（现行有效）
- 章节：第五章价格监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6c02b8d2fb/23.html

群众价格监督组织监督检查的重点，应当是同人民生活关系密切的消费品价格和服务收费标准。
群众价格监督人员进行价格监督检查活动时，应当佩带标志，出示价格检查证。
