# 最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定第三条

- 法规：最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a18f980ac6/3.html

侵害植物新品种权纠纷案件涉及的专门性问题需要鉴定的，由双方当事人协商确定的有鉴定资格的鉴定机构、鉴定人鉴定；协商不成的，由人民法院指定的有鉴定资格的鉴定机构、鉴定人鉴定。
没有前款规定的鉴定机构、鉴定人的，由具有相应品种检测技术水平的专业机构、专业人员鉴定。
