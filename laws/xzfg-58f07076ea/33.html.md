# 中华人民共和国商标法实施条例第三十三条

- 法规：中华人民共和国商标法实施条例（现行有效）
- 章节：第四章注册商标的变更、转让、续展
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-58f07076ea/33.html

注册商标需要续展注册的，应当向商标局提交商标续展注册申请书。商标局核准商标注册续展申请的，发给相应证明并予以公告。
