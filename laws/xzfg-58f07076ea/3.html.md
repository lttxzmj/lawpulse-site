# 中华人民共和国商标法实施条例第三条

- 法规：中华人民共和国商标法实施条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-58f07076ea/3.html

商标持有人依照商标法第十三条规定请求驰名商标保护的，应当提交其商标构成驰名商标的证据材料。商标局、商标评审委员会应当依照商标法第十四条的规定，根据审查、处理案件的需要以及当事人提交的证据材料，对其商标驰名情况作出认定。
