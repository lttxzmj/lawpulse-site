# 中华人民共和国商标法实施条例第九十三条

- 法规：中华人民共和国商标法实施条例（现行有效）
- 章节：第十章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-58f07076ea/93.html

商标注册用商品和服务分类表，由商标局制定并公布。
申请商标注册或者办理其他商标事宜的文件格式，由商标局、商标评审委员会制定并公布。
商标评审委员会的评审规则由国务院工商行政管理部门制定并公布。
