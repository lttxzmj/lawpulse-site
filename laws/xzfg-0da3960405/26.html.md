# 全国社会保障基金条例第二十六条

- 法规：全国社会保障基金条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0da3960405/26.html

全国社会保障基金理事会违反本条例规定的，由国务院财政部门、国务院社会保险行政部门责令改正；对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。
