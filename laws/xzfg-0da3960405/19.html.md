# 全国社会保障基金条例第十九条

- 法规：全国社会保障基金条例（现行有效）
- 章节：第三章全国社会保障基金的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0da3960405/19.html

国务院财政部门、国务院社会保险行政部门按照各自职责对全国社会保障基金的收支、管理和投资运营情况实施监督；发现存在问题的，应当依法处理；不属于本部门职责范围的，应当依法移送国务院外汇管理部门、国务院证券监督管理机构、国务院银行业监督管理机构等有关部门处理。
