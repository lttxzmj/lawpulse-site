# 全国社会保障基金条例第二十一条

- 法规：全国社会保障基金条例（现行有效）
- 章节：第三章全国社会保障基金的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0da3960405/21.html

对全国社会保障基金境外投资管理人、托管人的监督，由国务院证券监督管理机构、国务院银行业监督管理机构按照与投资管理人、托管人所在国家或者地区有关监督管理机构签署的合作文件的规定执行。
