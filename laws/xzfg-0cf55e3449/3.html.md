# 全国年节及纪念日放假办法第三条

- 法规：全国年节及纪念日放假办法（现行有效，施行日期 2025-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cf55e3449/3.html

部分公民放假的节日及纪念日：
（一）妇女节（3月8日），妇女放假半天；
（二）青年节（5月4日），14周岁以上的青年放假半天；
（三）儿童节（6月1日），不满14周岁的少年儿童放假1天；
（四）中国人民解放军建军纪念日（8月1日），现役军人放假半天。
