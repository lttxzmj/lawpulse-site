# 戒毒条例第三十四条

- 法规：戒毒条例（现行有效）
- 章节：第四章强制隔离戒毒
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-381dd303f7/34.html

解除强制隔离戒毒的，强制隔离戒毒场所应当在解除强制隔离戒毒3日前通知强制隔离戒毒决定机关，出具解除强制隔离戒毒证明书送达戒毒人员本人，并通知其家属、所在单位、其户籍所在地或者现居住地公安派出所将其领回。
