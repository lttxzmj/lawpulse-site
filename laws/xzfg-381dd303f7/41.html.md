# 戒毒条例第四十一条

- 法规：戒毒条例（现行有效）
- 章节：第五章社区康复
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-381dd303f7/41.html

自愿戒毒人员、社区戒毒、社区康复的人员可以自愿与戒毒康复场所签订协议，到戒毒康复场所戒毒康复、生活和劳动。
戒毒康复场所应当配备必要的管理人员和医务人员，为戒毒人员提供戒毒康复、职业技能培训和生产劳动条件。
