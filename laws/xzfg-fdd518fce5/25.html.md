# 规章制定程序条例第二十五条

- 法规：规章制定程序条例（现行有效）
- 章节：第四章审查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-fdd518fce5/25.html

法制机构应当认真研究各方面的意见，与起草单位协商后，对规章送审稿进行修改，形成规章草案和对草案的说明。说明应当包括制定规章拟解决的主要问题、确立的主要措施以及与有关部门的协调情况等。
规章草案和说明由法制机构主要负责人签署，提出提请本部门或者本级人民政府有关会议审议的建议。
