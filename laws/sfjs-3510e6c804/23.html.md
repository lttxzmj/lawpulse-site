# 最高人民法院关于审理独立保函纠纷案件若干问题的规定第二十三条

- 法规：最高人民法院关于审理独立保函纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3510e6c804/23.html

当事人约定在国内交易中适用独立保函，一方当事人以独立保函不具有涉外因素为由，主张保函独立性的约定无效的，人民法院不予支持。
