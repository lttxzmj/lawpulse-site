# 中华人民共和国监察法实施条例第四十二条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第三章监察范围和管辖 · 第一节监察对象
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/42.html

监察法第十五条第二项所称法律、法规授权或者受国家机关依法委托管理公共事务的组织中从事公务的人员，是指在上述组织中，除参照公务员法管理的人员外，对公共事务履行组织、领导、管理、监督等职责的人员，包括具有公共事务管理职能的行业协会等组织中从事公务的人员，以及法定检验检测、检疫等机构中从事公务的人员。
