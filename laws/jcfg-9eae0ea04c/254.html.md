# 中华人民共和国监察法实施条例第二百五十四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第六节移送审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/254.html

监察机关对已经移送起诉的职务犯罪案件，发现遗漏被调查人罪行需要补充移送起诉的，应当经审批出具《补充起诉意见书》，连同相关案卷材料、证据等一并移送同级人民检察院。
对于经人民检察院指定管辖的案件需要补充移送起诉的，可以直接移送原受理移送起诉的人民检察院；需要追加犯罪嫌疑人、被告人的，应当再次商请人民检察院办理指定管辖手续。
