# 中华人民共和国监察法实施条例第一百八十三条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第十六节技术调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/183.html

监察机关根据调查涉嫌重大贪污贿赂等职务犯罪需要，依照规定的权限和程序报经批准，可以依法采取技术调查措施，按照规定交公安机关或者国家有关执法机关依法执行。
