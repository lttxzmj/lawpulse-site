# 中华人民共和国监察法实施条例第二百九十五条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/295.html

办理监察事项的监察人员有监察法第六十七条所列情形之一的，应当自行提出回避；没有自行提出回避的，监察机关应当依法决定其回避，监察对象、检举人及其他有关人员也有权要求其回避。
选用借调人员、看护人员、调查场所，应当严格执行回避制度。
