# 中华人民共和国监察法实施条例第二百七十六条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第六章反腐败国际合作 · 第三节对外合作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/276.html

监察机关对依法应当留置或者已经决定留置的外逃人员，需要申请发布国际刑警组织红色通报的，应当逐级报送国家监察委员会审核。国家监察委员会审核后，依法通过公安部向国际刑警组织提出申请。
需要延期、暂停、撤销红色通报的，申请发布红色通报的监察机关应当逐级报送国家监察委员会审核，由国家监察委员会依法通过公安部联系国际刑警组织办理。
