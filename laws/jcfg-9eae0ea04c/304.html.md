# 中华人民共和国监察法实施条例第三百零四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/304.html

监察机关根据已经掌握的事实及证据，发现涉嫌严重职务违法或者职务犯罪的监察人员可能实施下列行为之一的，经依法审批，可以在具备安全保障条件的场所对其采取禁闭措施：
（一）继续实施违法犯罪行为的；
（二）为被调查人或者涉案人员通风报信等泄露监察工作秘密的；
（三）威胁、恐吓、蓄意报复举报人、控告人、被害人、证人、鉴定人等相关人员的；
（四）其他可能造成更为严重的后果或者恶劣影响的行为。
