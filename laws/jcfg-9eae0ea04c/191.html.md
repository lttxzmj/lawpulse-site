# 中华人民共和国监察法实施条例第一百九十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第十七节通缉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/191.html

监察机关对于被通缉人员已经归案、死亡，或者依法撤销留置决定以及发现有其他不需要继续采取通缉措施情形的，应当经审批出具《撤销通缉通知书》，送交协助采取原措施的公安机关执行。需要撤销网上追逃措施的，监察机关应当出具《撤销网上追逃通知书》，送交协助采取原措施的公安机关执行。
