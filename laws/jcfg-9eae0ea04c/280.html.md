# 中华人民共和国监察法实施条例第二百八十条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第六章反腐败国际合作 · 第三节对外合作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/280.html

地方各级监察机关通过境外追诉方式办理相关涉外案件的，应当提供外逃人员相关违法线索和证据，逐级报送国家监察委员会审核。由国家监察委员会按照国际刑事司法协助法等规定直接或者协调有关单位向有关国家（地区）相关机构提交，请其依法对外逃人员调查、起诉、审判，移管被判刑人或者遣返外逃人员。
