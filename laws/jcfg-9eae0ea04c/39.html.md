# 中华人民共和国监察法实施条例第三十九条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第二章监察机关及其职责 · 第四节监察处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/39.html

监察机关根据监督、调查结果，发现监察对象所在单位具有下列情形之一，需要整改纠正的，依法提出监察建议，推动以案促改工作：
（一）廉政建设方面存在突出问题的；
（二）权力运行制约监督方面存在较大风险的；
（三）监察对象教育管理监督方面存在突出问题的；
（四）执行法律法规制度不到位的；
（五）不履行或者不正确履行法定职责的；
（六）其他需要提出监察建议的情形。
监察机关应当跟踪了解监察建议的采纳情况，指导、督促有关单位限期整改，对未达到整改要求的提出进一步整改意见，推动监察建议落实到位。
