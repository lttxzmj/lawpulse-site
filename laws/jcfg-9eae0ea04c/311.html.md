# 中华人民共和国监察法实施条例第三百一十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/311.html

申诉人对申诉处理决定不服的，可以自收到申诉处理决定书之日起一个月以内向上一级监察机关申请复查。上一级监察机关应当进行核实，并自收到复查申请之日起二个月以内作出处理决定。
