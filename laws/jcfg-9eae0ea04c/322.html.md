# 中华人民共和国监察法实施条例第三百二十二条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第九章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/322.html

本条例所称监察机关，包括各级监察委员会及其派驻或者派出监察机构、监察专员，以及再派出的监察机构、监察专员。
