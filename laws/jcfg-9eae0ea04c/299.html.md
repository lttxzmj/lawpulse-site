# 中华人民共和国监察法实施条例第二百九十九条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/299.html

监察机关应当严格执行保密制度，控制监察事项知悉范围和时间。监察人员不准私自留存、隐匿、查阅、摘抄、复制、携带问题线索和涉案资料，严禁泄露监察工作秘密。
监察机关应当建立健全检举控告保密制度，对检举控告人的姓名（单位名称）、工作单位、住址、电话和邮箱等有关情况以及检举控告内容必须严格保密。
