# 中华人民共和国监察法实施条例第六十九条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第二节证据
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/69.html

监察机关调查终结的职务违法案件，应当事实清楚、证据确凿。证据确凿，应当符合下列条件：
（一）定性处置的事实都有证据证实；
（二）定案证据真实、合法；
（三）据以定案的证据之间不存在无法排除的矛盾；
（四）综合全案证据，所认定事实清晰且令人信服。
