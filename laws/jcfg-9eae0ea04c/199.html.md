# 中华人民共和国监察法实施条例第一百九十九条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第一节线索处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/199.html

监察机关对于报案或者举报应当依法接受。属于本级监察机关管辖的，依法予以受理；属于其他监察机关管辖的，应当在五个工作日以内予以转送。
监察机关可以向下级监察机关发函交办检举控告，并进行督办，下级监察机关应当按期回复办理结果。
