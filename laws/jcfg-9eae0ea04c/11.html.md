# 中华人民共和国监察法实施条例第十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第二章监察机关及其职责 · 第一节领导体制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/11.html

上级监察委员会可以依法统一调用所辖各级监察机关的监察人员办理监察事项。调用决定应当以书面形式作出。
监察机关办理监察事项应当加强互相协作和配合，对于重要、复杂事项可以提请上级监察机关予以协调。
