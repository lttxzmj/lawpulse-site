# 中华人民共和国监察法实施条例第二百四十二条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第五节处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/242.html

复审、复核机关承办部门应当成立工作组，调阅原案卷宗，必要时可以进行调查取证。承办部门应当集体研究，提出办理意见，经审批作出复审、复核决定。决定应当送达申请人，抄送相关单位，并在一定范围内宣布。
复审、复核期间，不停止原处理决定的执行。复审、复核机关经审查认定处理决定有错误或者不当的，应当依法撤销、变更原处理决定，或者责令原处理机关及时予以纠正。复审、复核机关经审查认定处理决定事实清楚、适用法律正确的，应当予以维持。
坚持复审复核与调查审理分离，原案调查、审理人员不得参与复审复核。
