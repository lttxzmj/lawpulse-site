# 中华人民共和国监察法实施条例第二百九十二条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/292.html

监察机关应当加强对监察人员执行职务和遵纪守法情况的监督，按照管理权限依法对监察人员涉嫌违法犯罪问题进行调查处置。
