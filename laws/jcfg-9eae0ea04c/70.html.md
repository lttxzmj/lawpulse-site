# 中华人民共和国监察法实施条例第七十条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第二节证据
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/70.html

监察机关调查终结的职务犯罪案件，应当事实清楚，证据确实、充分。证据确实、充分，应当符合下列条件：
（一）定罪量刑的事实都有证据证明；
（二）据以定案的证据均经法定程序查证属实；
（三）综合全案证据，对所认定事实已排除合理怀疑。
证据不足的，不得移送人民检察院审查起诉。
