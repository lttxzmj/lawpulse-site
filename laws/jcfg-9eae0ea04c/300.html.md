# 中华人民共和国监察法实施条例第三百条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/300.html

监察机关涉密人员离岗离职后，应当遵守脱密期管理规定，严格履行保密义务，不得泄露相关秘密。
