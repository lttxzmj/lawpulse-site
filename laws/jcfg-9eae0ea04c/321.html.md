# 中华人民共和国监察法实施条例第三百二十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/321.html

监察机关及其工作人员违法行使职权侵犯公民、法人和其他组织的合法权益造成损害的，该机关为赔偿义务机关。申请赔偿应当向赔偿义务机关提出，由该机关负责复审复核工作的部门受理。
赔偿以支付赔偿金为主要方式。能够返还财产或者恢复原状的，予以返还财产或者恢复原状。
