# 中华人民共和国监察法实施条例第二百四十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第五节处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/241.html

监察对象对监察机关作出的涉及本人的处理决定不服的，可以在收到处理决定之日起一个月以内，向作出决定的监察机关申请复审。复审机关应当依法受理，并在受理后一个月以内作出复审决定。监察对象对复审决定仍不服的，可以在收到复审决定之日起一个月以内，向上一级监察机关申请复核。复核机关应当依法受理，并在受理后二个月以内作出复核决定。
上一级监察机关的复核决定和国家监察委员会的复审、复核决定为最终决定。
