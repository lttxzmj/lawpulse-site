# 中华人民共和国监察法实施条例第三百一十五条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/315.html

监察对象对控告人、申诉人、批评人、检举人、证人、监察人员进行打击、压制等报复陷害的，监察机关应当依法给予政务处分。构成犯罪的，依法追究刑事责任。
