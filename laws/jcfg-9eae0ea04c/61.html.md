# 中华人民共和国监察法实施条例第六十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第一节一般要求
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/61.html

需要商请其他监察机关协助收集证据材料的，应当依法出具《委托调查函》；商请其他监察机关对采取措施提供一般性协助的，应当依法出具《商请协助采取措施函》。商请协助事项涉及协助地监察机关管辖的监察对象的，应当由协助地监察机关按照所涉人员的管理权限报批。协助地监察机关对于协助请求，应当依法予以协助配合。
