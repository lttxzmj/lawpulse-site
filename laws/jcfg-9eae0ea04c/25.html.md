# 中华人民共和国监察法实施条例第二十五条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第二章监察机关及其职责 · 第三节监察调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/25.html

监察机关依法履行监察调查职责，依据监察法、《中华人民共和国公职人员政务处分法》（以下简称政务处分法）和《中华人民共和国刑法》（以下简称刑法）等规定对职务违法和职务犯罪进行调查。
