# 中华人民共和国监察法实施条例第三百零一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/301.html

监察人员离任三年以内，不得从事与监察和司法工作相关联且可能发生利益冲突的职业。
监察人员离任后，不得担任原任职监察机关办理案件的诉讼代理人或者辩护人，但是作为当事人的监护人或者近亲属代理诉讼或者进行辩护的除外。
