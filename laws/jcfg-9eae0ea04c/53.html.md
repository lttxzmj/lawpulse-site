# 中华人民共和国监察法实施条例第五十三条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第三章监察范围和管辖 · 第二节管辖
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/53.html

监察机关办理案件中涉及无隶属关系的其他监察机关的监察对象，认为需要立案调查的，应当商请有管理权限的监察机关依法立案调查。商请立案时，应当提供涉案人员基本情况、已经查明的涉嫌违法犯罪事实以及相关证据材料。
承办案件的监察机关认为由其一并调查更为适宜的，可以报请有权决定的上级监察机关指定管辖。
