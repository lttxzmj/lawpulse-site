# 中华人民共和国监察法实施条例第二百六十一条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第六节移送审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/261.html

监察机关认为人民检察院不起诉决定有错误的，应当在收到不起诉决定书后三十日以内，依法向其上一级人民检察院提请复议。监察机关应当将上述情况及时向上一级监察机关书面报告。
