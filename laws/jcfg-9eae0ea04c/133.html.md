# 中华人民共和国监察法实施条例第一百三十三条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第九节留置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/133.html

重新计算留置时间的，留置时间不得超过三个月。新发现的罪行具有本条例第一百二十九条、第一百三十条规定情形的，可以依法延长和再延长留置时间。但是，此前已经根据本条例第一百三十条规定再延长留置时间的，不得再次适用该规定再延长留置时间。
