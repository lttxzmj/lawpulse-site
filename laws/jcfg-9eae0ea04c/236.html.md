# 中华人民共和国监察法实施条例第二百三十六条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第五节处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/236.html

监察机关在研究提出监察建议过程中，应当坚持问题导向、系统观念，加强分析研判，保证监察建议质量。
监察机关可以采取专题调研、部门会商、征求特约监察员等有关人员意见，以及与被建议单位或者其他有关方面沟通等方式，提高监察建议的针对性、可行性。
