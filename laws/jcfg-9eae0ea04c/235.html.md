# 中华人民共和国监察法实施条例第二百三十五条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第五节处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/235.html

监察机关依法向监察对象所在单位提出监察建议的，应当经审批制作监察建议书。
监察建议书一般应当包括下列内容：
（一）监督调查情况；
（二）发现的主要问题及其产生的原因；
（三）整改建议内容和要求；
（四）整改期限和反馈整改情况的要求；
（五）提出异议的期限和方式。
