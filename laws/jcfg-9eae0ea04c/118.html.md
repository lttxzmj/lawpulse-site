# 中华人民共和国监察法实施条例第一百一十八条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第八节管护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/118.html

管护时间不得超过七日，自向被管护人员宣布之日起算。因案情复杂、疑难，在七日以内无法作出留置或者解除管护决定的，经审批可以延长一日至三日。
延长管护时间的，应当在管护期满前向被管护人员宣布延长管护时间的决定，要求其在《延长管护时间决定书》上签名、捺指印。被管护人员拒绝签名、捺指印的，调查人员应当在文书上记明。
延长管护时间的，应当及时通知被管护人员所在单位和家属。
