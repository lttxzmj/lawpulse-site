# 中华人民共和国监察法实施条例第二百八十八条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第七章对监察机关和监察人员的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/288.html

监察机关实行严格的人员准入制度，严把政治关、品行关、能力关、作风关、廉洁关。监察人员必须忠诚坚定、担当尽责、遵纪守法、清正廉洁。
