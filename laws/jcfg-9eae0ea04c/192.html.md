# 中华人民共和国监察法实施条例第一百九十二条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第十八节限制出境
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/192.html

监察机关为防止被调查人及相关人员逃匿境外，按规定报批后，可以依法决定采取限制出境措施，交由移民管理机构依法执行。
