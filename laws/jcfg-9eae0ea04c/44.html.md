# 中华人民共和国监察法实施条例第四十四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第三章监察范围和管辖 · 第一节监察对象
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/44.html

监察法第十五条第四项所称公办的教育、科研、文化、医疗卫生、体育等单位中从事管理的人员，是指国家为了社会公益目的，由国家机关举办或者其他组织利用国有资产举办的教育、科研、文化、医疗卫生、体育等事业单位中，从事组织、领导、管理、监督等工作的人员。
