# 中华人民共和国监察法实施条例第二百二十七条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第四节审理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/227.html

审理工作结束后应当形成审理报告，载明被调查人基本情况、调查简况、涉嫌违法或者犯罪事实、被调查人态度和认识、涉案财物处置、承办部门意见、审理意见等内容，提请监察机关集体审议。
对被调查人涉嫌职务犯罪需要追究刑事责任的，应当形成《起诉意见书》，作为审理报告附件。《起诉意见书》应当忠实于事实真象，载明被调查人基本情况，调查简况，采取监察强制措施的时间，依法查明的犯罪事实和证据，从重、从轻、减轻或者免除处罚等情节，涉案财物情况，涉嫌罪名和法律依据，采取刑事强制措施的建议，以及其他需要说明的情况。
案件审理部门经审理认为现有证据不足以证明被调查人存在违法犯罪行为，且通过退回补充调查仍无法达到证明标准的，应当提出撤销案件的建议。
