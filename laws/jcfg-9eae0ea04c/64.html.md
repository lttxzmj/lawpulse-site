# 中华人民共和国监察法实施条例第六十四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第一节一般要求
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/64.html

监察机关依法变更强制到案、责令候查、管护、留置以及禁闭等监察强制措施的，原监察强制措施自监察机关采取新的监察强制措施之时自动解除。
