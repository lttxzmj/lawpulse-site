# 中华人民共和国监察法实施条例第九十六条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第五节询问
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/96.html

凡是知道案件情况的人，都有如实作证的义务。对故意提供虚假证言的证人，应当依法追究法律责任。
证人或者其他任何人不得帮助被调查人伪造、隐匿、毁灭证据或者串供，不得实施其他干扰调查活动的行为。
