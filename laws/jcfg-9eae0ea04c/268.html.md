# 中华人民共和国监察法实施条例第二百六十八条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第六章反腐败国际合作 · 第一节工作职责和领导体制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/268.html

监察机关应当建立追逃追赃和防逃工作内部联络机制。承办部门在调查过程中，发现被调查人或者重要涉案人员外逃、违法所得及其他涉案财产被转移到境外的，可以请追逃追赃部门提供工作协助。监察机关将案件移送人民检察院审查起诉后，仍有重要涉案人员外逃或者未追缴的违法所得及其他涉案财产的，应当由追逃追赃部门继续办理，或者由追逃追赃部门指定协调有关单位办理。
