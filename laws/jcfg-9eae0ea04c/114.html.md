# 中华人民共和国监察法实施条例第一百一十四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第八节管护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/114.html

采取管护措施时，调查人员不得少于二人，应当向被管护人员宣布《管护决定书》，告知被管护人员权利义务，要求其在《管护决定书》上签名、捺指印。被管护人员拒绝签名、捺指印的，调查人员应当在文书上记明。
