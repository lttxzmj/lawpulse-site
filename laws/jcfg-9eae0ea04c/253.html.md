# 中华人民共和国监察法实施条例第二百五十三条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第五章监察程序 · 第六节移送审查起诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/253.html

上级监察机关指定下级监察机关进行调查，移送起诉时需要人民检察院依法指定管辖的，应当按规定办理有关程序事宜。
