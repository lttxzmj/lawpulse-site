# 中华人民共和国监察法实施条例第一百二十六条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第四章监察权限 · 第九节留置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/126.html

采取留置措施时，调查人员不得少于二人，应当向被留置人员宣布《留置决定书》，告知被留置人员权利义务，要求其在《留置决定书》上签名、捺指印。被留置人员拒绝签名、捺指印的，调查人员应当在文书上记明。
