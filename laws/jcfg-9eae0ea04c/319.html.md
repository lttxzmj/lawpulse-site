# 中华人民共和国监察法实施条例第三百一十九条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/319.html

对监察人员在履行职责中存在违法行为的，可以根据情节轻重，依法进行谈话提醒、批评教育、责令检查、诫勉，或者给予政务处分。构成犯罪的，依法追究刑事责任。
