# 中华人民共和国监察法实施条例第三百二十四条

- 法规：中华人民共和国监察法实施条例（现行有效，施行日期 2025-06-01）
- 章节：第九章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/jcfg-9eae0ea04c/324.html

本条例所称同种罪行和不同种罪行，应当以罪名区分，但属选择性罪名或者在法律、事实上密切关联的犯罪，应当认定为同种罪行。
