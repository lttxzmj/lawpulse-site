# 不动产登记暂行条例第四条

- 法规：不动产登记暂行条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-662078a4f6/4.html

国家实行不动产统一登记制度。
不动产登记遵循严格管理、稳定连续、方便群众的原则。
不动产权利人已经依法享有的不动产权利，不因登记机构和登记程序的改变而受到影响。
