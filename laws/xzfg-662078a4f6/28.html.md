# 不动产登记暂行条例第二十八条

- 法规：不动产登记暂行条例（现行有效，施行日期 2024-05-01）
- 章节：第四章登记信息共享与保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-662078a4f6/28.html

查询不动产登记资料的单位、个人应当向不动产登记机构说明查询目的，不得将查询获得的不动产登记资料用于其他目的；未经权利人同意，不得泄露查询获得的不动产登记资料。
