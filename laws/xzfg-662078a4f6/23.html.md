# 不动产登记暂行条例第二十三条

- 法规：不动产登记暂行条例（现行有效，施行日期 2024-05-01）
- 章节：第四章登记信息共享与保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-662078a4f6/23.html

国务院自然资源主管部门应当会同有关部门建立统一的不动产登记信息管理基础平台。
各级不动产登记机构登记的信息应当纳入统一的不动产登记信息管理基础平台，确保国家、省、市、县四级登记信息的实时共享。
