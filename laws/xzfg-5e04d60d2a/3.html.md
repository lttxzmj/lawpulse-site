# 教育督导条例第三条

- 法规：教育督导条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5e04d60d2a/3.html

实施教育督导应当坚持以下原则：
(一)以提高教育教学质量为中心；
(二)遵循教育规律；
(三)遵守教育法律、法规、规章和国家教育方针、政策的规定；
(四)对政府履行教育工作相关职责的督导与对学校教育教学工作的督导并重，监督与指导并重；
(五)实事求是、客观公正。
