# 外国律师事务所驻华代表机构管理条例第三条

- 法规：外国律师事务所驻华代表机构管理条例（现行有效，施行日期 2025-01-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-36830cb948/3.html

代表机构及其代表从事法律服务活动，应当遵守中国的法律、法规和规章，恪守中国律师职业道德和执业纪律，不得损害中国国家安全和社会公共利益。
