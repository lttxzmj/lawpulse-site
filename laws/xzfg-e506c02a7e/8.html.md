# 中华人民共和国测量标志保护条例第八条

- 法规：中华人民共和国测量标志保护条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e506c02a7e/8.html

建设永久性测量标志，应当符合下列要求：
(一)使用国家规定的测绘基准和测绘标准；
(二)选择有利于测量标志长期保护和管理的点位；
(三)符合法律、法规规定的其他要求。
