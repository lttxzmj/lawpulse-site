# 中华人民共和国监狱法第六十四条

- 法规：中华人民共和国监狱法（现行有效，施行日期 2013-01-01）
- 章节：第五章对罪犯的教育改造
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-589af18f36/64.html

监狱应当根据监狱生产和罪犯释放后就业的需要，对罪犯进行职业技术教育，经考核合格的，由劳动部门发给相应的技术等级证书。
