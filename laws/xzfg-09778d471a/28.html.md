# 无人驾驶航空器飞行管理暂行条例第二十八条

- 法规：无人驾驶航空器飞行管理暂行条例（现行有效，施行日期 2024-01-01）
- 章节：第三章空域和飞行活动管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-09778d471a/28.html

无人驾驶航空器飞行活动申请按照下列权限批准：
（一）在飞行管制分区内飞行的，由负责该飞行管制分区的空中交通管理机构批准；
（二）超出飞行管制分区在飞行管制区内飞行的，由负责该飞行管制区的空中交通管理机构批准；
（三）超出飞行管制区飞行的，由国家空中交通管理领导机构授权的空中交通管理机构批准。
