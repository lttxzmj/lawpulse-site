# 无人驾驶航空器飞行管理暂行条例第六十一条

- 法规：无人驾驶航空器飞行管理暂行条例（现行有效，施行日期 2024-01-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-09778d471a/61.html

本条例施行前生产的民用无人驾驶航空器不能按照国家有关规定自动向无人驾驶航空器一体化综合监管服务平台报送识别信息的，实施飞行活动应当依照本条例的规定向空中交通管理机构提出飞行活动申请，经批准后方可飞行。
