# 无人驾驶航空器飞行管理暂行条例第六十条

- 法规：无人驾驶航空器飞行管理暂行条例（现行有效，施行日期 2024-01-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-09778d471a/60.html

模型航空器的分类、生产、登记、操控人员、航空飞行营地等事项的管理办法，由国务院体育主管部门会同有关空中交通管理机构，国务院工业和信息化、公安、民用航空主管部门另行制定。
