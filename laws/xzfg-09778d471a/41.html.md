# 无人驾驶航空器飞行管理暂行条例第四十一条

- 法规：无人驾驶航空器飞行管理暂行条例（现行有效，施行日期 2024-01-01）
- 章节：第四章监督管理和应急处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-09778d471a/41.html

对空中不明情况和无人驾驶航空器违规飞行，公安机关在条件有利时可以对低空目标实施先期处置，并负责违规飞行无人驾驶航空器落地后的现场处置。有关军事机关、公安机关、国家安全机关等单位按职责分工组织查证处置，民用航空管理等其他有关部门应当予以配合。
