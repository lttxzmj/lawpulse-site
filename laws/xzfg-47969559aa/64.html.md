# 医疗器械监督管理条例第六十四条

- 法规：医疗器械监督管理条例（现行有效，施行日期 2025-01-20）
- 章节：第五章不良事件的处理与医疗器械的召回
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-47969559aa/64.html

负责药品监督管理的部门应当根据医疗器械不良事件评估结果及时采取发布警示信息以及责令暂停生产、进口、经营和使用等控制措施。
省级以上人民政府药品监督管理部门应当会同同级卫生主管部门和相关部门组织对引起突发、群发的严重伤害或者死亡的医疗器械不良事件及时进行调查和处理，并组织对同类医疗器械加强监测。
负责药品监督管理的部门应当及时向同级卫生主管部门通报医疗器械使用单位的不良事件监测有关情况。
