# 医疗器械监督管理条例第三十三条

- 法规：医疗器械监督管理条例（现行有效，施行日期 2025-01-20）
- 章节：第三章医疗器械生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-47969559aa/33.html

医疗器械生产质量管理规范应当对医疗器械的设计开发、生产设备条件、原材料采购、生产过程控制、产品放行、企业的机构设置和人员配备等影响医疗器械安全、有效的事项作出明确规定。
