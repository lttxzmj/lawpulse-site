# 中华人民共和国市场主体登记管理条例第三条

- 法规：中华人民共和国市场主体登记管理条例（现行有效，施行日期 2022-03-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a08abf240/3.html

市场主体应当依照本条例办理登记。未经登记，不得以市场主体名义从事经营活动。法律、行政法规规定无需办理登记的除外。
市场主体登记包括设立登记、变更登记和注销登记。
