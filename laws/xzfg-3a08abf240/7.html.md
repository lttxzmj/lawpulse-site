# 中华人民共和国市场主体登记管理条例第七条

- 法规：中华人民共和国市场主体登记管理条例（现行有效，施行日期 2022-03-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a08abf240/7.html

国务院市场监督管理部门和国务院有关部门应当推动市场主体登记信息与其他政府信息的共享和运用，提升政府服务效能。
