# 中华人民共和国市场主体登记管理条例第四十二条

- 法规：中华人民共和国市场主体登记管理条例（现行有效，施行日期 2022-03-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a08abf240/42.html

登记机关或者其上级机关认定撤销市场主体登记决定错误的，可以撤销该决定，恢复原登记状态，并通过国家企业信用信息公示系统公示。
