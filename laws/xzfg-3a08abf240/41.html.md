# 中华人民共和国市场主体登记管理条例第四十一条

- 法规：中华人民共和国市场主体登记管理条例（现行有效，施行日期 2022-03-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a08abf240/41.html

有下列情形之一的，登记机关可以不予撤销市场主体登记：
（一）撤销市场主体登记可能对社会公共利益造成重大损害；
（二）撤销市场主体登记后无法恢复到登记前的状态；
（三）法律、行政法规规定的其他情形。
