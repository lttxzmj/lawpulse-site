# 中华人民共和国乡村集体所有制企业条例第二十三条

- 法规：中华人民共和国乡村集体所有制企业条例（现行有效）
- 章节：第三章企业的所有者和经营者
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a1d8856e12/23.html

实行承包或者租赁制的企业，订立承包或者租赁合同时，应当坚持平等、自愿、协商的原则，兼顾国家、集体和个人的利益。
