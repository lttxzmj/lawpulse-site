# 森林病虫害防治条例第十六条

- 法规：森林病虫害防治条例（现行有效，施行日期 2026-03-20）
- 章节：第三章森林病虫害的除治
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ee3f445e94/16.html

县级以上地方人民政府或者其林业主管部门应当制定除治森林病虫害的实施计划，并组织好交界地区的联防联治，对除治情况定期检查。
