# 最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）第三条

- 法规：最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1e03941979/3.html

人民法院审理人身保险合同纠纷案件时，应主动审查投保人订立保险合同时是否具有保险利益，以及以死亡为给付保险金条件的合同是否经过被保险人同意并认可保险金额。
