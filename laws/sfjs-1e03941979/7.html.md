# 最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）第七条

- 法规：最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1e03941979/7.html

当事人以被保险人、受益人或者他人已经代为支付保险费为由，主张投保人对应的交费义务已经履行的，人民法院应予支持。
