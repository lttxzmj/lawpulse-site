# 最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）第二十一条

- 法规：最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1e03941979/21.html

保险人以被保险人自杀为由拒绝给付保险金的，由保险人承担举证责任。
受益人或者被保险人的继承人以被保险人自杀时无民事行为能力为由抗辩的，由其承担举证责任。
