# 最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）第二十三条

- 法规：最高人民法院关于适用《中华人民共和国保险法》若干问题的解释（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1e03941979/23.html

保险人主张根据保险法第四十五条的规定不承担给付保险金责任的，应当证明被保险人的死亡、伤残结果与其实施的故意犯罪或者抗拒依法采取的刑事强制措施的行为之间存在因果关系。
被保险人在羁押、服刑期间因意外或者疾病造成伤残或者死亡，保险人主张根据保险法第四十五条的规定不承担给付保险金责任的，人民法院不予支持。
