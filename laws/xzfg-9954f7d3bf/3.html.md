# 中华人民共和国水下文物保护管理条例第三条

- 法规：中华人民共和国水下文物保护管理条例（现行有效，施行日期 2022-04-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9954f7d3bf/3.html

本条例第二条第一款第一项、第二项所规定的水下文物属于国家所有，国家对其行使管辖权；本条例第二条第一款第三项所规定的水下文物，遗存于外国领海以外的其他管辖海域以及公海区域内的起源国不明的文物，国家享有辨认器物物主的权利。
