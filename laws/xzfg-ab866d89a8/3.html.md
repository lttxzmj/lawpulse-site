# 基金会管理条例第三条

- 法规：基金会管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ab866d89a8/3.html

基金会分为面向公众募捐的基金会(以下简称公募基金会)和不得面向公众募捐的基金会(以下简称非公募基金会)。公募基金会按照募捐的地域范围，分为全国性公募基金会和地方性公募基金会。
