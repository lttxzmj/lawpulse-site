# 基金会管理条例第十六条

- 法规：基金会管理条例（现行有效）
- 章节：第二章设立、变更和注销
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ab866d89a8/16.html

基金会、境外基金会代表机构有下列情形之一的，应当向登记管理机关申请注销登记：
(一)按照章程规定终止的；
(二)无法按照章程规定的宗旨继续从事公益活动的；
(三)由于其他原因终止的。
