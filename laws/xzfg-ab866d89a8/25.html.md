# 基金会管理条例第二十五条

- 法规：基金会管理条例（现行有效）
- 章节：第四章财产的管理和使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ab866d89a8/25.html

基金会组织募捐、接受捐赠，应当符合章程规定的宗旨和公益活动的业务范围。境外基金会代表机构不得在中国境内组织募捐、接受捐赠。
公募基金会组织募捐，应当向社会公布募得资金后拟开展的公益活动和资金的详细使用计划。
