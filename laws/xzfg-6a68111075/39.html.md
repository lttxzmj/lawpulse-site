# 公共机构节能条例第三十九条

- 法规：公共机构节能条例（现行有效）
- 章节：第五章监督和保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a68111075/39.html

负责审批固定资产投资项目的部门对未通过节能评估和审查的公共机构建设项目予以批准的，对直接负责的主管人员和其他直接责任人员依法给予处分。
公共机构开工建设未通过节能评估和审查的建设项目的，由有关机关依法责令限期整改；对直接负责的主管人员和其他直接责任人员依法给予处分。
