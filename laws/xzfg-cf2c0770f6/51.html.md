# 农业转基因生物安全管理条例第五十一条

- 法规：农业转基因生物安全管理条例（现行有效）
- 章节：第七章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf2c0770f6/51.html

假冒、伪造、转让或者买卖农业转基因生物有关证明文书的，由县级以上人民政府农业行政主管部门依据职权，收缴相应的证明文书，并处2万元以上10万元以下的罚款；构成犯罪的，依法追究刑事责任。
