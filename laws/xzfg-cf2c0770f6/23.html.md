# 农业转基因生物安全管理条例第二十三条

- 法规：农业转基因生物安全管理条例（现行有效）
- 章节：第三章生产与加工
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf2c0770f6/23.html

农业转基因生物在生产、加工过程中发生基因安全事故时，生产、加工单位和个人应当立即采取安全补救措施，并向所在地县级人民政府农业行政主管部门报告。
