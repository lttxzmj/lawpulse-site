# 最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释第八条

- 法规：最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5ccdaff9e2/8.html

当事人依法申请对医疗损害责任纠纷中的专门性问题进行鉴定的，人民法院应予准许。
当事人未申请鉴定，人民法院对前款规定的专门性问题认为需要鉴定的，应当依职权委托鉴定。
