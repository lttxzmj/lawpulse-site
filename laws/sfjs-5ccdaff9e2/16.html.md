# 最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释第十六条

- 法规：最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5ccdaff9e2/16.html

对医疗机构或者其医务人员的过错，应当依据法律、行政法规、规章以及其他有关诊疗规范进行认定，可以综合考虑患者病情的紧急程度、患者个体差异、当地的医疗水平、医疗机构与医务人员资质等因素。
