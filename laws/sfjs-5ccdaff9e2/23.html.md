# 最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释第二十三条

- 法规：最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5ccdaff9e2/23.html

医疗产品的生产者、销售者、药品上市许可持有人明知医疗产品存在缺陷仍然生产、销售，造成患者死亡或者健康严重损害，被侵权人请求生产者、销售者、药品上市许可持有人赔偿损失及二倍以下惩罚性赔偿的，人民法院应予支持。
