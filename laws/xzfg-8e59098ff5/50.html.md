# 中华人民共和国招标投标法实施条例第五十条

- 法规：中华人民共和国招标投标法实施条例（现行有效）
- 章节：第四章开标、评标和中标
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e59098ff5/50.html

招标项目设有标底的，招标人应当在开标时公布。标底只能作为评标的参考，不得以投标报价是否接近标底作为中标条件，也不得以投标报价超过标底上下浮动范围作为否决投标的条件。
