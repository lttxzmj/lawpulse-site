# 中华人民共和国招标投标法实施条例第七十八条

- 法规：中华人民共和国招标投标法实施条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e59098ff5/78.html

国家建立招标投标信用制度。有关行政监督部门应当依法公告对招标人、招标代理机构、投标人、评标委员会成员等当事人违法行为的行政处理决定。
