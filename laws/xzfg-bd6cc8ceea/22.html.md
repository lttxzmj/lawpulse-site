# 全民阅读促进条例第二十二条

- 法规：全民阅读促进条例（现行有效，施行日期 2026-02-01）
- 章节：第三章全民阅读服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bd6cc8ceea/22.html

任何单位和个人不得擅自拆除全民阅读设施，不得擅自改变全民阅读设施功能、用途或者妨碍其正常运行。因城乡建设确需拆除或者改变功能、用途的，应当依法重建、改建全民阅读设施。
