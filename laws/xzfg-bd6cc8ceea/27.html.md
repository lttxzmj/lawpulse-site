# 全民阅读促进条例第二十七条

- 法规：全民阅读促进条例（现行有效，施行日期 2026-02-01）
- 章节：第三章全民阅读服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bd6cc8ceea/27.html

国家鼓励和支持与全民阅读促进相关的文化产业高质量发展；鼓励和支持社会力量参与建设公共阅读空间，开展旧书交换流通，创新阅读服务模式，丰富全民阅读场景。
国家鼓励和支持社会力量依法通过兴办实体、资助项目、赞助活动、提供设施、捐赠出版物等多种方式，参与提供阅读服务。
