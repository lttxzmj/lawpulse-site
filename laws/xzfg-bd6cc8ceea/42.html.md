# 全民阅读促进条例第四十二条

- 法规：全民阅读促进条例（现行有效，施行日期 2026-02-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bd6cc8ceea/42.html

违反本条例规定，地方各级人民政府和县级以上有关部门及其工作人员未履行全民阅读促进工作职责，侵占、挪用全民阅读经费，或者有其他滥用职权、玩忽职守、徇私舞弊行为的，由其上级机关或者监察机关责令限期改正；情节严重的，对负有责任的领导人员和直接责任人员依法给予处分。
