# 全民阅读促进条例第三十七条

- 法规：全民阅读促进条例（现行有效，施行日期 2026-02-01）
- 章节：第四章全民阅读保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bd6cc8ceea/37.html

国家鼓励为阅读障碍者提供有声、大字、盲文、电子等无障碍格式版本的出版物，支持全民阅读无障碍设施建设。
残疾人服务机构应当为残疾人提供必要阅读辅助设施和相应服务。
