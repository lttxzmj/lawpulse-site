# 全民阅读促进条例第三条

- 法规：全民阅读促进条例（现行有效，施行日期 2026-02-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bd6cc8ceea/3.html

全民阅读促进工作由党委领导、政府主导、社会力量参与，按照公益性、基本性、均等性、便利性的要求，构建全民覆盖、普惠高效的全民阅读促进体系，涵育文明风尚，厚植家国情怀，增强实现中华民族伟大复兴的精神力量。
