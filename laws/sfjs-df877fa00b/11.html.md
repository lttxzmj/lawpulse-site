# 最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释第十一条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-df877fa00b/11.html

人民法院经审查再审申请书等材料，认为申请再审事由成立的，应当径行裁定再审。
当事人申请再审超过民事诉讼法第二百零五条规定的期限，或者超出民事诉讼法第二百条所列明的再审事由范围的，人民法院应当裁定驳回再审申请。
