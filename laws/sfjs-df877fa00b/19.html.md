# 最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释第十九条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-df877fa00b/19.html

上一级人民法院可以根据案件的影响程度以及案件参与人等情况，决定是否指定再审。需要指定再审的，应当考虑便利当事人行使诉讼权利以及便利人民法院审理等因素。
接受指定再审的人民法院，应当按照民事诉讼法第二百零七条第一款规定的程序审理。
