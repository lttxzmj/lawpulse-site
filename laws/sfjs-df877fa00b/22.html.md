# 最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释第二十二条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》审判监督程序若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-df877fa00b/22.html

人民法院应当依照民事诉讼法第二百零七条的规定，按照第一审程序或者第二审程序审理再审案件。
人民法院审理再审案件应当开庭审理。但按照第二审程序审理的，双方当事人已经其他方式充分表达意见，且书面同意不开庭审理的除外。
