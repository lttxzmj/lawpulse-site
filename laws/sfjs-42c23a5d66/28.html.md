# 最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释第二十八条

- 法规：最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2024-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-42c23a5d66/28.html

原告主张被诉垄断行为属于反垄断法第二十二条第一款规定的滥用市场支配地位的，应当对被告在相关市场内具有支配地位和被告滥用市场支配地位承担举证责任。被告以其行为具有正当性为由抗辩的，应当承担举证责任。
