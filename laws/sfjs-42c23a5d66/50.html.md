# 最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释第五十条

- 法规：最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2024-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-42c23a5d66/50.html

人民法院审理垄断民事纠纷案件，适用被诉垄断行为发生时施行的反垄断法。被诉垄断行为发生在修改后的反垄断法施行之前，行为持续至或者损害后果出现在修改后的反垄断法施行之后的，适用修改后的反垄断法。
