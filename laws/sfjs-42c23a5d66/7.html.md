# 最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释第七条

- 法规：最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2024-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-42c23a5d66/7.html

案件立案时的案由并非垄断民事纠纷，人民法院受理后经审查发现属于垄断民事纠纷，但受诉人民法院并无垄断民事纠纷案件管辖权的，应当将案件移送有管辖权的人民法院。
