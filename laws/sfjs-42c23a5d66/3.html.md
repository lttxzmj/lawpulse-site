# 最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理垄断民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2024-07-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-42c23a5d66/3.html

一方当事人向人民法院提起垄断民事诉讼，另一方当事人以双方之间存在合同关系且有仲裁协议为由，主张人民法院不应受理的，人民法院不予支持。
