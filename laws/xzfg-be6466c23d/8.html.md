# 中华人民共和国民用航空器权利登记条例第八条

- 法规：中华人民共和国民用航空器权利登记条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be6466c23d/8.html

就两架以上民用航空器设定一项抵押权或者就同一民用航空器设定两项以上抵押权时，民用航空器的抵押权人和抵押人应当就每一架民用航空器或者每一项抵押权分别办理抵押权登记。
