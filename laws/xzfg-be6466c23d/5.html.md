# 中华人民共和国民用航空器权利登记条例第五条

- 法规：中华人民共和国民用航空器权利登记条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be6466c23d/5.html

办理民用航空器所有权登记的，民用航空器的所有人应当提交下列文件或者经核对无误的复印件：
(一)民用航空器国籍登记证书；
(二)民用航空器所有权取得的证明文件；
(三)国务院民用航空主管部门要求提交的其他必要的有关文件。
