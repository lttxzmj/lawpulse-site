# 中华人民共和国民用航空器权利登记条例第三条

- 法规：中华人民共和国民用航空器权利登记条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be6466c23d/3.html

国务院民用航空主管部门主管民用航空器权利登记工作，设立民用航空器权利登记簿，统一记载民用航空器权利登记事项。
同一民用航空器的权利登记事项应当记载于同一权利登记簿中。
