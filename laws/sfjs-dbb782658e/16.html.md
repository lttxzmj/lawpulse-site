# 最高人民法院关于审理企业破产案件确定管理人报酬的规定第十六条

- 法规：最高人民法院关于审理企业破产案件确定管理人报酬的规定（现行有效，施行日期 2007-06-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-dbb782658e/16.html

管理人发生更换的，人民法院应当分别确定更换前后的管理人报酬。其报酬比例总和不得超出本规定第二条规定的限制范围。
