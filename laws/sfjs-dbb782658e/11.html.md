# 最高人民法院关于审理企业破产案件确定管理人报酬的规定第十一条

- 法规：最高人民法院关于审理企业破产案件确定管理人报酬的规定（现行有效，施行日期 2007-06-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-dbb782658e/11.html

管理人收取报酬，应当向人民法院提出书面申请。申请书应当包括以下内容：
（一）可供支付报酬的债务人财产情况；
（二）申请收取报酬的时间和数额；
（三）管理人履行职责的情况。
人民法院应当自收到上述申请书之日起十日内，确定支付管理人的报酬数额。
