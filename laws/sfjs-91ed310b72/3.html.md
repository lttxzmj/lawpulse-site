# 最高人民法院关于审理人民检察院按照审判监督程序提出的刑事抗诉案件若干问题的规定第三条

- 法规：最高人民法院关于审理人民检察院按照审判监督程序提出的刑事抗诉案件若干问题的规定（现行有效，施行日期 2012-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-91ed310b72/3.html

本规定所指的新证据，是指具有下列情形之一，指向原起诉事实并可能改变原判决、裁定据以定罪量刑的事实的证据：
（一）原判决、裁定生效后新发现的证据；
（二）原判决、裁定生效前已经发现，但由于客观原因未予收集的证据；
（三）原判决、裁定生效前已经收集，但庭审中未予质证、认证的证据；
（四）原生效判决、裁定所依据的鉴定结论，勘验、检查笔录或其他证据被改变或者否定的。
