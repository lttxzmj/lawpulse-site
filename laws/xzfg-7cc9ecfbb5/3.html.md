# 地方各级人民政府机构设置和编制管理条例第三条

- 法规：地方各级人民政府机构设置和编制管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7cc9ecfbb5/3.html

地方各级人民政府机构设置和编制管理工作，应当按照经济社会全面协调可持续发展的要求，适应全面履行职能的需要，遵循精简、统一、效能的原则。
