# 地方各级人民政府机构设置和编制管理条例第二十三条

- 法规：地方各级人民政府机构设置和编制管理条例（现行有效）
- 章节：第四章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7cc9ecfbb5/23.html

地方各级人民政府机构编制管理机关，应当如实向上级机构编制管理机关提交机构编制年度统计资料，不得虚报、瞒报、伪造。
