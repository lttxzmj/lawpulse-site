# 危险化学品安全管理条例第六十八条

- 法规：危险化学品安全管理条例（现行有效）
- 章节：第六章危险化学品登记与事故应急救援
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-930f51c87a/68.html

危险化学品登记机构应当定期向工业和信息化、环境保护、公安、卫生、交通运输、铁路、质量监督检验检疫等部门提供危险化学品登记的有关信息和资料。
