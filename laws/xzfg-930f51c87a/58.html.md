# 危险化学品安全管理条例第五十八条

- 法规：危险化学品安全管理条例（现行有效）
- 章节：第五章运输安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-930f51c87a/58.html

通过内河运输危险化学品，危险化学品包装物的材质、型式、强度以及包装方法应当符合水路运输危险化学品包装规范的要求。国务院交通运输主管部门对单船运输的危险化学品数量有限制性规定的，承运人应当按照规定安排运输数量。
