# 高等教育自学考试暂行条例第三十二条

- 法规：高等教育自学考试暂行条例（现行有效）
- 章节：第七章毕业人员的使用与待遇
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d987f71050/32.html

高等教育自学考试毕业证书获得者的工资待遇：非在职人员录用后，与普通高等学校同类毕业生相同；在职人员的工资待遇低于普通高等学校同类毕业生的，从获得毕业证书之日起，按普通高等学校同类毕业生工资标准执行。
