# 高等教育自学考试暂行条例第三十七条

- 法规：高等教育自学考试暂行条例（现行有效）
- 章节：第九章奖励和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d987f71050/37.html

高等教育自学考试应考者在考试中有夹带、传递、抄袭、换卷、代考等舞弊行为以及其他违反考试规则的行为，省考委视情节轻重，分别给予警告、取消考试成绩、停考1至3年的处罚。
