# 高等教育自学考试暂行条例第七条

- 法规：高等教育自学考试暂行条例（现行有效）
- 章节：第二章考试机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d987f71050/7.html

全国考委根据工作需要设立若干专业委员会，负责拟订专业考试计划和课程自学考试大纲，组织编写和推荐适合自学的高等教育教材，对本专业考试工作进行业务指导和质量评估。
