# 高等教育自学考试暂行条例第二十八条

- 法规：高等教育自学考试暂行条例（现行有效）
- 章节：第六章社会助学
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d987f71050/28.html

国家鼓励企业、事业单位和其他社会力量，根据高等教育自学考试的专业考试计划和课程自学考试大纲的要求，通过电视、广播、函授、面授等多种形式开展助学活动。
