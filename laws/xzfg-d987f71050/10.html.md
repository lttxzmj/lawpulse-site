# 高等教育自学考试暂行条例第十条

- 法规：高等教育自学考试暂行条例（现行有效）
- 章节：第二章考试机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d987f71050/10.html

主考学校由省考委遴选专业师资力量较强的全日制普通高等学校担任。主考学校在高等教育自学考试工作上接受省考委的领导，参与命题和评卷，负责有关实践性学习环节的考核，在毕业证书上副署，办理省考委交办的其他有关工作。
主考学校应设立高等教育自学考试办事机构，根据任务配备专职工作人员，所需编制列入学校总编制数内，由学校主管部门解决。
