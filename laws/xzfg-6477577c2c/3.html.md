# 历史文化名城名镇名村保护条例第三条

- 法规：历史文化名城名镇名村保护条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6477577c2c/3.html

历史文化名城、名镇、名村的保护应当遵循科学规划、严格保护的原则，保持和延续其传统格局和历史风貌，维护历史文化遗产的真实性和完整性，继承和弘扬中华民族优秀传统文化，正确处理经济社会发展和历史文化遗产保护的关系。
