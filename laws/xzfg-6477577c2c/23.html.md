# 历史文化名城名镇名村保护条例第二十三条

- 法规：历史文化名城名镇名村保护条例（现行有效）
- 章节：第四章保护措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6477577c2c/23.html

在历史文化名城、名镇、名村保护范围内从事建设活动，应当符合保护规划的要求，不得损害历史文化遗产的真实性和完整性，不得对其传统格局和历史风貌构成破坏性影响。
