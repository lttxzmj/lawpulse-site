# 历史文化名城名镇名村保护条例第十九条

- 法规：历史文化名城名镇名村保护条例（现行有效）
- 章节：第三章保护规划
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6477577c2c/19.html

经依法批准的保护规划，不得擅自修改；确需修改的，保护规划的组织编制机关应当向原审批机关提出专题报告，经同意后，方可编制修改方案。修改后的保护规划，应当按照原审批程序报送审批。
