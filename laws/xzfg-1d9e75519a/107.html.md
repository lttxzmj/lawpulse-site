# 中华人民共和国国境卫生检疫法实施细则第一百零七条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第十章卫生监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/107.html

对饮用水、食品及从业人员的卫生要求是：
(一)国境口岸和交通工具上的食品、饮用水必须符合有关的卫生标准；
(二)国境口岸内的涉外宾馆，以及向入境、出境的交通工具提供饮食服务的部门，必须取得卫生检疫机关发放的卫生许可证；
(三)国境口岸内涉外的宾馆和入境、出境交通工具上的食品、饮用水从业人员应当持有有效健康证明。
