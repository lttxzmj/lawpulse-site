# 中华人民共和国国境卫生检疫法实施细则第六十二条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/62.html

对船舶的鼠患检查或者除鼠，应当尽量在船舶空舱的时候进行。如果船舶因故不宜按期进行鼠患检查或者蒸熏除鼠，并且该船又开往便于实施鼠患检查或者蒸熏除鼠的港口，可以准许该船原有的除鼠证书或者免予除鼠证书的有效期延长1个月，并签发延长证明。
