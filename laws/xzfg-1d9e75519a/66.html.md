# 中华人民共和国国境卫生检疫法实施细则第六十六条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/66.html

国务院卫生行政部门认为必要时，可以要求来自国外或者国外某些地区的人员在入境时，向卫生检疫机关出示有效的某种预防接种证书或者健康证明。
