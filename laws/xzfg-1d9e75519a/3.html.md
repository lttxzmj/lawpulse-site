# 中华人民共和国国境卫生检疫法实施细则第三条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/3.html

卫生检疫机关在国境口岸工作的范围，是指为国境口岸服务的涉外宾馆、饭店、俱乐部，为入境、出境交通工具提供饮食、服务的单位和对入境、出境人员、交通工具、集装箱和货物实施检疫、监测、卫生监督的场所。
