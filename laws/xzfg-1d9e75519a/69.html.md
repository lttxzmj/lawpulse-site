# 中华人民共和国国境卫生检疫法实施细则第六十九条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第八章检疫传染病管理 · 第一节鼠疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/69.html

船舶、航空器在到达时，有下列情形之一的，为染有鼠疫：
(一)船舶、航空器上有鼠疫病例的；
(二)船舶、航空器上发现有感染鼠疫的啮齿动物的；
(三)船舶上曾经有人在上船6日以后患鼠疫的。
