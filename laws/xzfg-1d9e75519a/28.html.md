# 中华人民共和国国境卫生检疫法实施细则第二十八条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第四章海港检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/28.html

持有效卫生证书的船舶在入境前24小时，应当向卫生检疫机关报告下列事项：
(一)船名、国籍、预定到达检疫锚地的日期和时间；
(二)发航港、最后寄港；
(三)船员和旅客人数及健康状况；
(四)货物种类；
(五)船舶卫生证书的签发日期和编号、除鼠证书或者免予除鼠证书的签发日期和签发港，以及其他卫生证件。
经卫生检疫机关对上述报告答复同意后，即可进港。
