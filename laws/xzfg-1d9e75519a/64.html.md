# 中华人民共和国国境卫生检疫法实施细则第六十四条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/64.html

船舶在港口停靠期间，船长应当负责采取下列的措施：
(一)缆绳上必须使用有效的防鼠板，或者其他防鼠装置；
(二)夜间放置扶梯、桥板时，应当用强光照射；
(三)在船上发现死鼠或者捕获到鼠类时，应当向卫生检疫机关报告。
