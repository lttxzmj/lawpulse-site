# 中华人民共和国国境卫生检疫法实施细则第四十六条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第六章陆地边境检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/46.html

受入境检疫的列车和其他车辆到达车站、关口，在实施入境检疫而未取得入境检疫证以前，未经卫生检疫机关许可，任何人不准上下列车或者其他车辆，不准装卸行李、货物、邮包等物品。
