# 中华人民共和国国境卫生检疫法实施细则第一百零六条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第十章卫生监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/106.html

对交通工具的卫生要求是：
(一)交通工具上的宿舱、车厢必须保持清洁卫生，通风良好；
(二)交通工具上必须备有足够的消毒、除鼠、除虫药物及器械，并备有防鼠装置；
(三)交通工具上的货舱、行李舱、货车车厢在装货前或者卸货后应当进行彻底清扫，有毒物品和食品不得混装，防止污染；
(四)对不符合卫生要求的入境、出境交通工具，必须接受卫生检疫机关的督导立即进行改进。
