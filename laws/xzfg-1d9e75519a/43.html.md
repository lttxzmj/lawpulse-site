# 中华人民共和国国境卫生检疫法实施细则第四十三条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第五章航空检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/43.html

对出境航空器查验完毕以后，如果没有染疫，检疫医师应当签发出境检疫证或者在必要的卫生处理完毕以后，再发给出境检疫证；如果该航空器因卫生处理不能按原定时间起飞，应当及时通知航空站。
