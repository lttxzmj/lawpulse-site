# 中华人民共和国国境卫生检疫法实施细则第五十五条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/55.html

由国外起运经过中华人民共和国境内的货物，如果不在境内换装，除发生在流行病学上有重要意义的事件，需要实施卫生处理外，在一般情况下不实施卫生处理。
