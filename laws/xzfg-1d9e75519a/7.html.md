# 中华人民共和国国境卫生检疫法实施细则第七条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第一章一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/7.html

在国境口岸以及停留在该场所的入境、出境交通工具上，所有非因意外伤害而死亡并死因不明的尸体，必须经卫生检疫机关查验，并签发尸体移运许可证后，方准移运。
