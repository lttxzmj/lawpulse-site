# 中华人民共和国国境卫生检疫法实施细则第三十四条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第四章海港检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/34.html

对船舶实施出境检疫完毕以后，检疫医师应当按照检疫结果立即签发出境检疫证，如果因卫生处理不能按原定时间启航，应当及时通知港务监督机关。
