# 中华人民共和国国境卫生检疫法实施细则第五十二条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第六章陆地边境检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/52.html

受入境、出境检疫的列车以及其他车辆，载有来自疫区、有染疫或者染疫嫌疑或者夹带能传播传染病的病媒昆虫和啮齿动物的货物，应当接受卫生检查和必要的卫生处理。
