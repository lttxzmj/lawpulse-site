# 中华人民共和国国境卫生检疫法实施细则第二十六条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第四章海港检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/26.html

悬挂检疫信号的船舶，除引航员和经卫生检疫机关许可的人员外，其他人员不准上船，不准装卸行李、货物、邮包等物品，其他船舶不准靠近；船上的人员，除因船舶遇险外，未经卫生检疫机关许可，不准离船；引航员不得将船引离检疫锚地。
