# 中华人民共和国国境卫生检疫法实施细则第二十二条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第四章海港检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/22.html

船舶的入境检疫，必须在港口的检疫锚地或者经卫生检疫机关同意的指定地点实施。
检疫锚地由港务监督机关和卫生检疫机关会商确定，报国务院交通运输主管部门和海关总署备案。
