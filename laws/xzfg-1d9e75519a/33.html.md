# 中华人民共和国国境卫生检疫法实施细则第三十三条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第四章海港检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/33.html

受出境检疫的船舶，船长应当向卫生检疫机关出示除鼠证书或者免予除鼠证书和其他有关检疫证件。检疫医师可以向船长、船医提出有关船员、旅客健康情况和船上卫生情况的询问，船长、船医对上述询问应当如实回答。
