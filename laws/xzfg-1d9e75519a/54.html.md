# 中华人民共和国国境卫生检疫法实施细则第五十四条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/54.html

入境、出境的集装箱、行李、货物、邮包等物品需要卫生处理的，由卫生检疫机关实施。
入境、出境的交通工具有下列情形之一的，应当由卫生检疫机关实施消毒、除鼠、除虫或者其他卫生处理：
(一)来自检疫传染病疫区的；
(二)被检疫传染病污染的；
(三)发现有与人类健康有关的啮齿动物或者病媒昆虫，超过国家卫生标准的。
