# 中华人民共和国国境卫生检疫法实施细则第五十七条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第七章卫生处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/57.html

入境、出境的尸体、骸骨托运人或者代理人应当申请卫生检疫，并出示死亡证明或者其他有关证件，对不符合卫生要求的，必须接受卫生检疫机关实施的卫生处理。经卫生检疫合格后，方准运进或者运出。
对因患检疫传染病而死亡的病人尸体，必须就近火化，不准移运。
