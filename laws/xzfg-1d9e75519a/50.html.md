# 中华人民共和国国境卫生检疫法实施细则第五十条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第六章陆地边境检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/50.html

对列车或者其他车辆实施入境、出境检疫完毕后，检疫医师应当根据检疫结果分别签发入境、出境检疫证，或者在必要的卫生处理完毕后，再分别签发入境、出境检疫证。
