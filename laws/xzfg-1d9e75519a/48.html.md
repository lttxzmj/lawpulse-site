# 中华人民共和国国境卫生检疫法实施细则第四十八条

- 法规：中华人民共和国国境卫生检疫法实施细则（现行有效）
- 章节：第六章陆地边境检疫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d9e75519a/48.html

应当受入境、出境检疫的列车和其他车辆，如果在行程中发现检疫传染病、疑似检疫传染病，或者有人非因意外伤害而死亡并死因不明的，列车或者其他车辆到达车站、关口时，列车长或者其他车辆负责人应当向卫生检疫机关报告。
