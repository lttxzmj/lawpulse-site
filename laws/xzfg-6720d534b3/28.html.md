# 中华人民共和国著作权法实施条例第二十八条

- 法规：中华人民共和国著作权法实施条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6720d534b3/28.html

图书出版合同中约定图书出版者享有专有出版权但没有明确其具体内容的，视为图书出版者享有在合同有效期限内和在合同约定的地域范围内以同种文字的原版、修订版出版图书的专有权利。
