# 中华人民共和国专利法实施细则第六十六条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第四章专利申请的复审与专利权的无效宣告
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/66.html

请求人在提出复审请求或者在对国务院专利行政部门的复审通知书作出答复时，可以修改专利申请文件；但是，修改应当仅限于消除驳回决定或者复审通知书指出的缺陷。
