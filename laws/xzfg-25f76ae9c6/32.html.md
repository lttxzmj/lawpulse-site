# 中华人民共和国专利法实施细则第三十二条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第二章专利的申请
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/32.html

国务院专利行政部门认为必要时，可以要求外观设计专利申请人提交使用外观设计的产品样品或者模型。样品或者模型的体积不得超过30厘米×30厘米×30厘米，重量不得超过15公斤。易腐、易损或者危险品不得作为样品或者模型提交。
