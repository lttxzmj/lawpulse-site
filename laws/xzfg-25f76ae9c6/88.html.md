# 中华人民共和国专利法实施细则第八十八条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第六章专利实施的特别许可
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/88.html

专利权人不得通过提供虚假材料、隐瞒事实等手段，作出开放许可声明或者在开放许可实施期间获得专利年费减免。
