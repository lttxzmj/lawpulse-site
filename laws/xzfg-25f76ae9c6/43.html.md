# 中华人民共和国专利法实施细则第四十三条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第三章专利申请的审查和批准
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/43.html

国务院专利行政部门收到发明或者实用新型专利申请的请求书、说明书（实用新型必须包括附图）和权利要求书，或者外观设计专利申请的请求书、外观设计的图片或者照片和简要说明后，应当明确申请日、给予申请号，并通知申请人。
