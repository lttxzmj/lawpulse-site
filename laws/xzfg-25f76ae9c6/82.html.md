# 中华人民共和国专利法实施细则第八十二条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第五章专利权期限补偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/82.html

依照专利法第四十二条第三款的规定给予专利权期限补偿的，补偿期限按照该专利申请日至该新药在中国获得上市许可之日的间隔天数减去5年，在符合专利法第四十二条第三款规定的基础上确定。
