# 中华人民共和国专利法实施细则第一百三十五条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第十一章关于发明、实用新型国际申请的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/135.html

基于国际申请授予的专利权，由于译文错误，致使依照专利法第六十四条规定确定的保护范围超出国际申请的原文所表达的范围的，以依据原文限制后的保护范围为准；致使保护范围小于国际申请的原文所表达的范围的，以授权时的保护范围为准。
