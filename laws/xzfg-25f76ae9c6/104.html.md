# 中华人民共和国专利法实施细则第一百零四条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第八章专利权的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/104.html

人民法院在审理民事案件中裁定对专利申请权或者专利权采取保全措施的，国务院专利行政部门应当在收到写明申请号或者专利号的裁定书和协助执行通知书之日中止被保全的专利申请权或者专利权的有关程序。保全期限届满，人民法院没有裁定继续采取保全措施的，国务院专利行政部门自行恢复有关程序。
