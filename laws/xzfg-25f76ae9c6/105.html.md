# 中华人民共和国专利法实施细则第一百零五条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第八章专利权的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/105.html

国务院专利行政部门根据本细则第一百零三条和第一百零四条规定中止有关程序，是指暂停专利申请的初步审查、实质审查、复审程序，授予专利权程序和专利权无效宣告程序；暂停办理放弃、变更、转移专利权或者专利申请权手续，专利权质押手续以及专利权期限届满前的终止手续等。
