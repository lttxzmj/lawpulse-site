# 中华人民共和国专利法实施细则第一百二十八条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第十一章关于发明、实用新型国际申请的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/128.html

国际申请的申请日在优先权期限届满之后2个月内，在国际阶段受理局已经批准恢复优先权的，视为已经依照本细则第三十六条的规定提出了恢复优先权请求；在国际阶段申请人未请求恢复优先权，或者提出了恢复优先权请求但受理局未批准，申请人有正当理由的，可以自进入日起2个月内向国务院专利行政部门请求恢复优先权。
