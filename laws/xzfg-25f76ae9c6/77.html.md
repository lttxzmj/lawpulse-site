# 中华人民共和国专利法实施细则第七十七条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第五章专利权期限补偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/77.html

依照专利法第四十二条第二款的规定请求给予专利权期限补偿的，专利权人应当自公告授予专利权之日起3个月内向国务院专利行政部门提出。
