# 中华人民共和国专利法实施细则第一百一十八条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第十一章关于发明、实用新型国际申请的特别规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/118.html

国务院专利行政部门根据专利法第十九条规定，受理按照专利合作条约提出的专利国际申请。
按照专利合作条约提出并指定中国的专利国际申请（以下简称国际申请）进入国务院专利行政部门处理阶段（以下称进入中国国家阶段）的条件和程序适用本章的规定；本章没有规定的，适用专利法及本细则其他各章的有关规定。
