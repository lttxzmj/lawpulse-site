# 中华人民共和国专利法实施细则第八十四条

- 法规：中华人民共和国专利法实施细则（现行有效，施行日期 2024-01-20）
- 章节：第五章专利权期限补偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25f76ae9c6/84.html

国务院专利行政部门对依照专利法第四十二条第二款、第三款的规定提出的专利权期限补偿请求进行审查后，认为符合补偿条件的，作出给予期限补偿的决定，并予以登记和公告；不符合补偿条件的，作出不予期限补偿的决定，并通知提出请求的专利权人。
