# 核电厂核事故应急管理条例第十三条

- 法规：核电厂核事故应急管理条例（现行有效）
- 章节：第三章应急准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ef81113144/13.html

场内核事故应急计划、场外核事故应急计划应当包括下列内容：
(一)核事故应急工作的基本任务；
(二)核事故应急响应组织及其职责；
(三)烟羽应急计划区和食入应急计划区的范围；
(四)干预水平和导出干预水平；
(五)核事故应急准备和应急响应的详细方案；
(六)应急设施、设备、器材和其他物资；
(七)核电厂核事故应急机构同省级人民政府指定的部门之间以及同其他有关方面相互配合、支援的事项及措施。
