# 核电厂核事故应急管理条例第十六条

- 法规：核电厂核事故应急管理条例（现行有效）
- 章节：第三章应急准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ef81113144/16.html

核电厂应当对职工进行核安全、辐射防护和核事故应急知识的专门教育。
省级人民政府指定的部门应当在核电厂的协助下对附近的公众进行核安全、辐射防护和核事故应急知识的普及教育。
