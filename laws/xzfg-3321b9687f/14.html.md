# 国有企业管理人员处分条例第十四条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第二章处分的种类和适用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/14.html

国有企业管理人员在处分期内，不得晋升职务、岗位等级和职称；其中，被记过、记大过、降级、撤职的，不得晋升薪酬待遇等级。被撤职的，降低职务或者岗位等级，同时降低薪酬待遇。被开除的，用人单位依法解除劳动合同。
