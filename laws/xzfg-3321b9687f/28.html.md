# 国有企业管理人员处分条例第二十八条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第四章处分的程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/28.html

重大违法案件调查过程中，确有需要的，可以商请有管理权限的监察机关提供必要支持。
违法情形复杂、涉及面广或者造成重大影响，由任免机关、单位调查核实存在困难的，经任免机关、单位负责人同意，可以商请有管理权限的监察机关处理。
