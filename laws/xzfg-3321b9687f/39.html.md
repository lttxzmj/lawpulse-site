# 国有企业管理人员处分条例第三十九条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第五章复核、申诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/39.html

被处分人对复核决定仍不服的，可以自收到复核决定之日起1个月内按照管理权限向上一级机关、单位申诉。受理申诉的机关、单位（以下称申诉机关）应当自受理之日起2个月以内作出处理决定；案情复杂的，可以适当延长，但是延长期限最多不超过1个月。
被处分人因不可抗拒的事由或者其他正当理由耽误申诉申请期限的，在障碍消除后的10个工作日内，可以申请顺延期限；是否准许，由申诉机关决定。
