# 国有企业管理人员处分条例第四十二条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第五章复核、申诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/42.html

有下列情形之一的，原处分决定单位、申诉机关应当撤销原处分决定，重新作出决定或者由申诉机关责令原处分决定单位重新作出决定：
（一）处分所依据的违法事实不清或者证据不足；
（二）违反本条例规定的程序，影响案件公正处理；
（三）超越职权或者滥用职权作出处分决定。
