# 国有企业管理人员处分条例第四十三条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第五章复核、申诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/43.html

有下列情形之一的，原处分决定单位、申诉机关应当变更原处分决定，或者由申诉机关责令原处分决定单位予以变更：
（一）适用法律、法规确有错误；
（二）对违法行为的情节认定确有错误；
（三）处分不当。
