# 国有企业管理人员处分条例第三十四条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第四章处分的程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/34.html

国有企业管理人员涉嫌违法，已经被立案调查，不宜继续履行职责的，任免机关、单位可以决定暂停其履行职务。国有企业管理人员在被立案调查期间，未经决定立案的任免机关、单位同意，不得出境、辞去公职；其任免机关、单位以及上级机关、单位不得对其交流、晋升、奖励或者办理退休手续。
