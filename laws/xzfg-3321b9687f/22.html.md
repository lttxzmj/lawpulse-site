# 国有企业管理人员处分条例第二十二条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第三章违法行为及其适用的处分
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/22.html

国有企业管理人员在履行提供社会公共服务职责过程中，侵犯服务对象合法权益或者社会公共利益，被监管机构查实并提出处分建议的，依据公职人员政务处分法第三十八条的规定，情节较重的，予以警告、记过或者记大过；情节严重的，予以降级或者撤职；情节特别严重的，予以开除。
