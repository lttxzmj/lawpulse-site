# 国有企业管理人员处分条例第三十三条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第四章处分的程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/33.html

任免机关、单位对担任各级人民代表大会代表或者中国人民政治协商会议各级委员会委员的国有企业管理人员给予处分的，应当向有关的人民代表大会常务委员会，乡、民族乡、镇的人民代表大会主席团或者中国人民政治协商会议委员会常务委员会通报。
