# 国有企业管理人员处分条例第四十一条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第五章复核、申诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/41.html

任免机关、单位发现本机关、本单位或者下级机关、单位作出的处分决定确有错误的，应当及时予以纠正或者责令下级机关、单位及时予以纠正。
监察机关发现任免机关、单位应当给予处分而未给予，或者给予的处分违法、不当，依法提出监察建议的，任免机关、单位应当采纳并将执行情况函告监察机关，不采纳的应当说明理由。
