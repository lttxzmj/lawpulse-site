# 国有企业管理人员处分条例第四条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/4.html

任免机关、单位加强对国有企业管理人员的教育、管理、监督。给予国有企业管理人员处分，应当坚持公正公平，集体讨论决定；坚持宽严相济，惩戒与教育相结合；坚持法治原则，以事实为根据，以法律为准绳，依法保障国有企业管理人员以及相关人员的合法权益。
