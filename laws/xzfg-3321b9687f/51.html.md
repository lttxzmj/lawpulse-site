# 国有企业管理人员处分条例第五十一条

- 法规：国有企业管理人员处分条例（现行有效，施行日期 2024-09-01）
- 章节：第七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3321b9687f/51.html

本条例施行前，已经结案的案件如果需要复核、申诉，适用当时的规定。尚未结案的案件，如果行为发生时的规定不认为是违法的，适用当时的规定；如果行为发生时的规定认为是违法的，依照当时的规定处理，但是如果本条例不认为是违法或者根据本条例处理较轻的，适用本条例。
