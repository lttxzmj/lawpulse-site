# 最高人民法院、最高人民检察院关于适用犯罪嫌疑人、被告人逃匿、死亡案件违法所得没收程序若干问题的规定第三条

- 法规：最高人民法院、最高人民检察院关于适用犯罪嫌疑人、被告人逃匿、死亡案件违法所得没收程序若干问题的规定（现行有效，施行日期 2017-01-05）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-244b09f9d4/3.html

犯罪嫌疑人、被告人为逃避侦查和刑事追究潜逃、隐匿，或者在刑事诉讼过程中脱逃的，应当认定为刑事诉讼法第二百八十条第一款规定的“逃匿”。
犯罪嫌疑人、被告人因意外事故下落不明满二年，或者因意外事故下落不明，经有关机关证明其不可能生存的，依照前款规定处理。
