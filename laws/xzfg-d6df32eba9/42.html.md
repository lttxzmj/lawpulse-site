# 排污许可管理条例第四十二条

- 法规：排污许可管理条例（现行有效，施行日期 2021-03-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d6df32eba9/42.html

违反本条例规定，接受审批部门委托的排污许可技术机构弄虚作假的，由审批部门解除委托关系，将相关信息记入其信用记录，在全国排污许可证管理信息平台上公布，同时纳入国家有关信用信息系统向社会公布；情节严重的，禁止从事排污许可技术服务。
