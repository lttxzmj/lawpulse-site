# 营业性演出管理条例第五十五条

- 法规：营业性演出管理条例（现行有效，施行日期 2020-11-29）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e84e85a7d/55.html

文化主管部门、公安部门、工商行政管理部门的工作人员滥用职权、玩忽职守、徇私舞弊或者未依照本条例规定履行职责的，依法给予行政处分；构成犯罪的，依法追究刑事责任。
