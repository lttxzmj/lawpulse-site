# 营业性演出管理条例第二十八条

- 法规：营业性演出管理条例（现行有效，施行日期 2020-11-29）
- 章节：第三章营业性演出规范
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e84e85a7d/28.html

演员不得以假唱欺骗观众，演出举办单位不得组织演员假唱。任何单位或者个人不得为假唱提供条件。
演出举办单位应当派专人对演出进行监督，防止假唱行为的发生。
