# 营业性演出管理条例第三十三条

- 法规：营业性演出管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e84e85a7d/33.html

文化主管部门应当加强对营业性演出的监督管理。
演出所在地县级人民政府文化主管部门对外国的或者香港特别行政区、澳门特别行政区、台湾地区的文艺表演团体、个人参加的营业性演出和临时搭建舞台、看台的营业性演出，应当进行实地检查；对其他营业性演出，应当进行实地抽样检查。
