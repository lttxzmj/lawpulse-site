# 营业性演出管理条例第三十九条

- 法规：营业性演出管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e84e85a7d/39.html

文化主管部门依法对营业性演出进行监督检查时，应当将监督检查的情况和处理结果予以记录，由监督检查人员签字后归档。公众有权查阅监督检查记录。
