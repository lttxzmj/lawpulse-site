# 公共场所卫生管理条例第三条

- 法规：公共场所卫生管理条例（现行有效，施行日期 2025-01-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-69d39e6295/3.html

公共场所的下列项目应符合国家卫生标准和要求：
（一）空气、微小气候（湿度、温度、风速）；
（二）水质；
（三）采光、照明；
（四）噪音；
（五）顾客用具和卫生设施。
公共场所的卫生标准和要求，由国务院疾病预防控制部门负责制定。
