# 外国驻华外交领事机构中国籍雇员管理条例第三条

- 法规：外国驻华外交领事机构中国籍雇员管理条例（现行有效，施行日期 2026-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-df7012b70c/3.html

中国政府依法为外国驻华外交领事机构雇用中国籍雇员提供便利。
外国驻华外交领事机构应当尊重中国的法律、法规，保障中国籍雇员的合法权益。
