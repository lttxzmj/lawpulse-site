# 最高人民法院关于内地与澳门特别行政区关于相互认可和执行民商事判决的安排第二十三条

- 法规：最高人民法院关于内地与澳门特别行政区关于相互认可和执行民商事判决的安排（现行有效，施行日期 2006-04-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a280bf0da7/23.html

为执行本安排，最高人民法院和澳门特别行政区终审法院应当相互提供相关法律资料。
最高人民法院和澳门特别行政区终审法院每年相互通报执行本安排的情况。
