# 最高人民法院关于当事人对人民法院撤销仲裁裁决的裁定不服申请再审人民法院是否受理问题的批复全文

- 法规：最高人民法院关于当事人对人民法院撤销仲裁裁决的裁定不服申请再审人民法院是否受理问题的批复（现行有效，施行日期 1999-02-16）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-53615e65df/0.html

法释〔1999〕6号
（1999年1月29日最高人民法院审判委员会第1042次会议通过 1999年2月11日最高人民法院公告公布 自1999年2月16日起施行）
陕西省高级人民法院：
你院陕高法〔1998〕78号《关于当事人对人民法院撤销仲裁裁决的裁定不服申请再审是否应当受理的请示》收悉。经研究，答复如下：
根据《中华人民共和国仲裁法》第九条规定的精神，当事人对人民法院撤销仲裁裁决的裁定不服申请再审的，人民法院不予受理。
此复。
