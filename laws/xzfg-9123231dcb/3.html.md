# 旅行社条例第三条

- 法规：旅行社条例（现行有效，施行日期 2020-11-29）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9123231dcb/3.html

国务院旅游行政主管部门负责全国旅行社的监督管理工作。
县级以上地方人民政府管理旅游工作的部门按照职责负责本行政区域内旅行社的监督管理工作。
县级以上各级人民政府工商、价格、商务、外汇等有关部门，应当按照职责分工，依法对旅行社进行监督管理。
