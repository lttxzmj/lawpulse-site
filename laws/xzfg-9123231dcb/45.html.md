# 旅行社条例第四十五条

- 法规：旅行社条例（现行有效，施行日期 2020-11-29）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9123231dcb/45.html

旅游、工商、价格、商务、外汇等有关部门工作人员不得接受旅行社的任何馈赠，不得参加由旅行社支付费用的购物活动或者游览项目，不得通过旅行社为自己、亲友或者其他个人、组织牟取私利。
