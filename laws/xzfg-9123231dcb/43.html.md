# 旅行社条例第四十三条

- 法规：旅行社条例（现行有效，施行日期 2020-11-29）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9123231dcb/43.html

旅行社损害旅游者合法权益的，旅游者可以向旅游行政管理部门、工商行政管理部门、价格主管部门、商务主管部门或者外汇管理部门投诉，接到投诉的部门应当按照其职责权限及时调查处理，并将调查处理的有关情况告知旅游者。
