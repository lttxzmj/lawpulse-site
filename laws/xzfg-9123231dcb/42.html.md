# 旅行社条例第四十二条

- 法规：旅行社条例（现行有效，施行日期 2020-11-29）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9123231dcb/42.html

旅游、工商、价格等行政管理部门应当及时向社会公告监督检查的情况。公告的内容包括旅行社业务经营许可证的颁发、变更、吊销、注销情况，旅行社的违法经营行为以及旅行社的诚信记录、旅游者投诉信息等。
