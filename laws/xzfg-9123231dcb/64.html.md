# 旅行社条例第六十四条

- 法规：旅行社条例（现行有效，施行日期 2020-11-29）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9123231dcb/64.html

因妨害国(边)境管理受到刑事处罚的，在刑罚执行完毕之日起五年内不得从事旅行社业务经营活动；旅行社被吊销旅行社业务经营许可的，其主要负责人在旅行社业务经营许可被吊销之日起五年内不得担任任何旅行社的主要负责人。
