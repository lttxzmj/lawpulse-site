# 电力设施保护条例第二十二条

- 法规：电力设施保护条例（现行有效）
- 章节：第四章对电力设施与其他设施互相妨碍的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d680b2fbad/22.html

公用工程、城市绿化和其他工程在新建、改建或扩建中妨碍电力设施时，或电力设施在新建、改建或扩建中妨碍公用工程、城市绿化和其他工程时，双方有关单位必须按照本条例和国家有关规定协商，就迁移、采取必要的防护措施和补偿等问题达成协议后方可施工。
