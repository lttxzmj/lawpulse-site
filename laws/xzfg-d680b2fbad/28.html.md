# 电力设施保护条例第二十八条

- 法规：电力设施保护条例（现行有效）
- 章节：第五章奖励与惩罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d680b2fbad/28.html

违反本条例规定，在依法划定的电力设施保护区内进行烧窑、烧荒、抛锚、拖锚、炸鱼、挖沙作业，危及电力设施安全的，由电力管理部门责令停止作业、恢复原状并赔偿损失。
