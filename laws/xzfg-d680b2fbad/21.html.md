# 电力设施保护条例第二十一条

- 法规：电力设施保护条例（现行有效）
- 章节：第四章对电力设施与其他设施互相妨碍的处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d680b2fbad/21.html

新建架空电力线路不得跨越储存易燃、易爆物品仓库的区域；一般不得跨越房屋，特殊情况需要跨越房屋时，电力建设企业应采取安全措施，并与有关单位达成协议。
