# 最高人民法院关于审理行政赔偿案件若干问题的规定第三条

- 法规：最高人民法院关于审理行政赔偿案件若干问题的规定（现行有效，施行日期 2022-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-6758b9a6eb/3.html

赔偿请求人不服赔偿义务机关下列行为的，可以依法提起行政赔偿诉讼：
（一）确定赔偿方式、项目、数额的行政赔偿决定；
（二）不予赔偿决定；
（三）逾期不作出赔偿决定；
（四）其他有关行政赔偿的行为。
