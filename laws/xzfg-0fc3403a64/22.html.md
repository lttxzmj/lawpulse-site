# 国有土地上房屋征收与补偿条例第二十二条

- 法规：国有土地上房屋征收与补偿条例（现行有效）
- 章节：第三章补偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0fc3403a64/22.html

因征收房屋造成搬迁的，房屋征收部门应当向被征收人支付搬迁费；选择房屋产权调换的，产权调换房屋交付前，房屋征收部门应当向被征收人支付临时安置费或者提供周转用房。
