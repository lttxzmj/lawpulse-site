# 国有土地上房屋征收与补偿条例第三十三条

- 法规：国有土地上房屋征收与补偿条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0fc3403a64/33.html

贪污、挪用、私分、截留、拖欠征收补偿费用的，责令改正，追回有关款项，限期退还违法所得，对有关责任单位通报批评、给予警告；造成损失的，依法承担赔偿责任；对直接负责的主管人员和其他直接责任人员，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予处分。
