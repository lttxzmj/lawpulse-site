# 建设工程安全生产管理条例第四十二条

- 法规：建设工程安全生产管理条例（现行有效）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aa5048269a/42.html

建设行政主管部门在审核发放施工许可证时，应当对建设工程是否有安全施工措施进行审查，对没有安全施工措施的，不得颁发施工许可证。
建设行政主管部门或者其他有关部门对建设工程是否有安全施工措施进行审查时，不得收取费用。
