# 建设工程安全生产管理条例第五十三条

- 法规：建设工程安全生产管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aa5048269a/53.html

违反本条例的规定，县级以上人民政府建设行政主管部门或者其他有关行政管理部门的工作人员，有下列行为之一的，给予降级或者撤职的行政处分；构成犯罪的，依照刑法有关规定追究刑事责任：
(一)对不具备安全生产条件的施工单位颁发资质证书的；
(二)对没有安全施工措施的建设工程颁发施工许可证的；
(三)发现违法行为不予查处的；
(四)不依法履行监督管理职责的其他行为。
