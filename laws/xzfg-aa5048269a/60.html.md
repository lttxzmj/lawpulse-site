# 建设工程安全生产管理条例第六十条

- 法规：建设工程安全生产管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aa5048269a/60.html

违反本条例的规定，出租单位出租未经安全性能检测或者经检测不合格的机械设备和施工机具及配件的，责令停业整顿，并处5万元以上10万元以下的罚款；造成损失的，依法承担赔偿责任。
