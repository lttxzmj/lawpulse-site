# 地质资料管理条例第十一条

- 法规：地质资料管理条例（现行有效）
- 章节：第二章地质资料的汇交
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bb9fa75681/11.html

因不可抗力，地质资料汇交人不能按照本条例第十条规定的期限汇交地质资料的，应当将造成延期汇交地质资料的不可抗力事实书面告知负责接收地质资料的地质矿产主管部门。
