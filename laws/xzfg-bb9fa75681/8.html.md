# 地质资料管理条例第八条

- 法规：地质资料管理条例（现行有效）
- 章节：第二章地质资料的汇交
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bb9fa75681/8.html

国家对地质资料实行统一汇交制度。
地质资料汇交人应当按照本条例附件规定的范围汇交地质资料。
除成果地质资料、国家规定需要汇交的原始地质资料和实物地质资料外，其他的原始地质资料和实物地质资料只需汇交目录。国家规定需要汇交的原始地质资料和实物地质资料细目，由国务院地质矿产主管部门商国务院有关部门制定。
