# 最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释第十六条

- 法规：最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-318f122995/16.html

以森林生态效益补偿收益、林业碳汇等提供担保，债务人不履行到期债务或者发生当事人约定的实现担保物权的情形，担保物权人请求就担保财产优先受偿的，人民法院依法予以支持。
