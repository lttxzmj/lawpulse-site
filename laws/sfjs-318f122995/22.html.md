# 最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释第二十二条

- 法规：最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-318f122995/22.html

侵权人自愿交纳保证金作为履行森林生态环境修复义务担保的，在其不履行修复义务时，人民法院可以将保证金用于支付森林生态环境修复费用。
