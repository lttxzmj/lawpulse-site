# 最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理森林资源民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-318f122995/3.html

当事人以未办理批准、登记、备案、审查、审核等手续为由，主张林地承包、林地承包经营权互换或者转让、林地经营权流转、林木流转、森林资源担保等合同无效的，人民法院不予支持。
因前款原因，不能取得相关权利的当事人请求解除合同、由违约方承担违约责任的，人民法院依法予以支持。
