# 企业财务会计报告条例第二十三条

- 法规：企业财务会计报告条例（现行有效）
- 章节：第三章财务会计报告的编制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d8b018b11/23.html

企业应当按照国家统一的会计制度规定的会计报表格式和内容，根据登记完整、核对无误的会计账簿记录和其他有关资料编制会计报表，做到内容完整、数字真实、计算准确，不得漏报或者任意取舍。
