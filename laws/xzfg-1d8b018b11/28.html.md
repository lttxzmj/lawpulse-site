# 企业财务会计报告条例第二十八条

- 法规：企业财务会计报告条例（现行有效）
- 章节：第三章财务会计报告的编制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d8b018b11/28.html

按照国家统一的会计制度的规定，需要编制合并会计报表的企业集团，母公司除编制其个别会计报表外，还应当编制企业集团的合并会计报表。
企业集团合并会计报表，是指反映企业集团整体财务状况、经营成果和现金流量的会计报表。
