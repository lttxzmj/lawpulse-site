# 企业财务会计报告条例第三十三条

- 法规：企业财务会计报告条例（现行有效）
- 章节：第四章财务会计报告的对外提供
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d8b018b11/33.html

有关部门或者机构依照法律、行政法规或者国务院的规定，要求企业提供部分或者全部财务会计报告及其有关数据的，应当向企业出示依据，并不得要求企业改变财务会计报告有关数据的会计口径。
