# 企业财务会计报告条例第二十二条

- 法规：企业财务会计报告条例（现行有效）
- 章节：第三章财务会计报告的编制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1d8b018b11/22.html

企业编制年度和半年度财务会计报告时，对经查实后的资产、负债有变动的，应当按照资产、负债的确认和计量标准进行确认和计量，并按照国家统一的会计制度的规定进行相应的会计处理。
