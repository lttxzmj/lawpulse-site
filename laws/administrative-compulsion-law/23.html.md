# 中华人民共和国行政强制法第二十三条

- 法规：中华人民共和国行政强制法（现行有效，施行日期 2012-01-01）
- 章节：第三章行政强制措施实施程序 · 第二节查封、扣押
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/administrative-compulsion-law/23.html

查封、扣押限于涉案的场所、设施或者财物，不得查封、扣押与违法行为无关的场所、设施或者财物；不得查封、扣押公民个人及其所扶养家属的生活必需品。
当事人的场所、设施或者财物已被其他国家机关依法查封的，不得重复查封。
