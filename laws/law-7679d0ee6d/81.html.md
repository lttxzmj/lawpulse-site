# 中华人民共和国海商法第八十一条

- 法规：中华人民共和国海商法（现行有效，施行日期 2026-05-01）
- 章节：第四章海上货物运输合同 · 第四节运输单证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-7679d0ee6d/81.html

承运人签发提单以外的单证用以证明收到待运货物的，此项单证即为订立海上货物运输合同和承运人接收该单证中所列货物的初步证据。
承运人签发的此类单证不得转让。
