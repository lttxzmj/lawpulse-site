# 机关团体建设楼堂馆所管理条例第三条

- 法规：机关团体建设楼堂馆所管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9f85a0a4ae/3.html

建设办公用房应当严格履行审批程序，严格执行建设标准。未经批准，不得建设办公用房。
禁止以技术业务用房等名义建设办公用房或者违反规定在技术业务用房中设置办公用房。
