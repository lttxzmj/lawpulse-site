# 促进个体工商户发展条例第二十七条

- 法规：促进个体工商户发展条例（现行有效，施行日期 2022-11-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-71d963de9c/27.html

县级以上地方人民政府制定实施城乡建设规划及城市和交通管理、市容环境治理、产业升级等相关政策措施，应当充分考虑个体工商户经营需要和实际困难，实施引导帮扶。
