# 促进个体工商户发展条例第二十一条

- 法规：促进个体工商户发展条例（现行有效，施行日期 2022-11-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-71d963de9c/21.html

国家推动建立和完善个体工商户信用评价体系，鼓励金融机构开发和提供适合个体工商户发展特点的金融产品和服务，扩大个体工商户贷款规模和覆盖面，提高贷款精准性和便利度。
