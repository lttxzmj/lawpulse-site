# 促进个体工商户发展条例第三条

- 法规：促进个体工商户发展条例（现行有效，施行日期 2022-11-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-71d963de9c/3.html

促进个体工商户发展工作坚持中国共产党的领导，发挥党组织在个体工商户发展中的引领作用和党员先锋模范作用。
个体工商户中的党组织和党员按照中国共产党章程的规定开展党的活动。
