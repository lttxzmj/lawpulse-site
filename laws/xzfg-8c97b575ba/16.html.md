# 企业名称登记管理规定第十六条

- 法规：企业名称登记管理规定（现行有效，施行日期 2021-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8c97b575ba/16.html

企业名称由申请人自主申报。
申请人可以通过企业名称申报系统或者在企业登记机关服务窗口提交有关信息和材料，对拟定的企业名称进行查询、比对和筛选，选取符合本规定要求的企业名称。
申请人提交的信息和材料应当真实、准确、完整，并承诺因其企业名称与他人企业名称近似侵犯他人合法权益的，依法承担法律责任。
