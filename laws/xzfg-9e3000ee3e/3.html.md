# 中华人民共和国发票管理办法第三条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/3.html

本办法所称发票，是指在购销商品、提供或者接受服务以及从事其他经营活动中，开具、收取的收付款凭证。
发票包括纸质发票和电子发票。电子发票与纸质发票具有同等法律效力。国家积极推广使用电子发票。
