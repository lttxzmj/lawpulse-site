# 中华人民共和国发票管理办法第二十一条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第四章发票的开具和保管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/21.html

开具发票应当按照规定的时限、顺序、栏目，全部联次一次性如实开具，开具纸质发票应当加盖发票专用章。
任何单位和个人不得有下列虚开发票行为：
（一）为他人、为自己开具与实际经营业务情况不符的发票；
（二）让他人为自己开具与实际经营业务情况不符的发票；
（三）介绍他人开具与实际经营业务情况不符的发票。
