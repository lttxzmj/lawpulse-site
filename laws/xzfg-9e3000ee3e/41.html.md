# 中华人民共和国发票管理办法第四十一条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/41.html

税务人员利用职权之便，故意刁难印制、使用发票的单位和个人，或者有违反发票管理法规行为的，依照国家有关规定给予处分；构成犯罪的，依法追究刑事责任。
