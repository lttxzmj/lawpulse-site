# 中华人民共和国发票管理办法第三十二条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第五章发票的检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/32.html

单位和个人从中国境外取得的与纳税有关的发票或者凭证，税务机关在纳税审查时有疑义的，可以要求其提供境外公证机构或者注册会计师的确认证明，经税务机关审核认可后，方可作为记账核算的凭证。
