# 中华人民共和国发票管理办法第二十六条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第四章发票的开具和保管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/26.html

开具发票的单位和个人应当建立发票使用登记制度，配合税务机关进行身份验证，并定期向主管税务机关报告发票使用情况。
