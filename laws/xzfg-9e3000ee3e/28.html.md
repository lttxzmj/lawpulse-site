# 中华人民共和国发票管理办法第二十八条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第四章发票的开具和保管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/28.html

开具发票的单位和个人应当按照国家有关规定存放和保管发票，不得擅自损毁。已经开具的发票存根联，应当保存5年。
