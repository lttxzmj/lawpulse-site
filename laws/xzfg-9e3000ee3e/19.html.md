# 中华人民共和国发票管理办法第十九条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第四章发票的开具和保管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/19.html

所有单位和从事生产、经营活动的个人在购买商品、接受服务以及从事其他经营活动支付款项，应当向收款方取得发票。取得发票时，不得要求变更品名和金额。
