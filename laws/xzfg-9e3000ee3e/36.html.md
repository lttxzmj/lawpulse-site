# 中华人民共和国发票管理办法第三十六条

- 法规：中华人民共和国发票管理办法（现行有效，施行日期 2023-07-20）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e3000ee3e/36.html

私自印制、伪造、变造发票，非法制造发票防伪专用品，伪造发票监制章，窃取、截留、篡改、出售、泄露发票数据的，由税务机关没收违法所得，没收、销毁作案工具和非法物品，并处1万元以上5万元以下的罚款；情节严重的，并处5万元以上50万元以下的罚款；构成犯罪的，依法追究刑事责任。
前款规定的处罚，《中华人民共和国税收征收管理法》有规定的，依照其规定执行。
