# 防治海洋工程建设项目污染损害海洋环境管理条例第十六条

- 章节：第三章海洋工程的污染防治
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c9b775070/16.html
