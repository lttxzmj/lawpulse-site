# 防治海洋工程建设项目污染损害海洋环境管理条例第四十二条

- 法规：防治海洋工程建设项目污染损害海洋环境管理条例（现行有效）
- 章节：第六章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c9b775070/42.html

县级以上人民政府海洋主管部门的监督检查人员进行现场执法检查时，应当出示规定的执法证件。用于执法检查、巡航监视的公务飞机、船舶和车辆应当有明显的执法标志。
