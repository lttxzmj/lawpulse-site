# 防治海洋工程建设项目污染损害海洋环境管理条例第二十三条

- 法规：防治海洋工程建设项目污染损害海洋环境管理条例（现行有效）
- 章节：第三章海洋工程的污染防治
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c9b775070/23.html

从事海水养殖的养殖者，应当采取科学的养殖方式，减少养殖饵料对海洋环境的污染。因养殖污染海域或者严重破坏海洋景观的，养殖者应当予以恢复和整治。
