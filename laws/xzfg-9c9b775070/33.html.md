# 防治海洋工程建设项目污染损害海洋环境管理条例第三十三条

- 法规：防治海洋工程建设项目污染损害海洋环境管理条例（现行有效）
- 章节：第四章污染物排放管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9c9b775070/33.html

海洋油气矿产资源勘探开发作业中应当安装污染物流量自动监控仪器，对生产污水、机舱污水和生活污水的排放进行计量。
