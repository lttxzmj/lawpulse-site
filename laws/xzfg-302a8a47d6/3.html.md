# 中华人民共和国核出口管制条例第三条

- 法规：中华人民共和国核出口管制条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-302a8a47d6/3.html

国家对核出口实行严格管制，严格履行所承担的不扩散核武器的国际义务。
国家严格限制铀浓缩设施、设备，辐照燃料后处理设施、设备，重水生产设施、设备等物项及其相关技术等核扩散敏感物项，以及可以用于核武器或者其他核爆炸装置的材料的出口。
