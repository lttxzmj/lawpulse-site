# 武器装备研制设计师系统和行政指挥系统工作条例第三条

- 法规：武器装备研制设计师系统和行政指挥系统工作条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c6c4169ccc/3.html

武器装备研制行政指挥系统(以下简称行政指挥系统)是由各级行政指挥组成的在各自行政隶属关系范围内实施行政指挥的系统，负责本部门武器装备研制的组织指挥，计划调度，人员、经费、物资保障等工作，并组织跨部门的协调工作。
