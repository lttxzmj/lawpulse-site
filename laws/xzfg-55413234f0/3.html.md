# 中华人民共和国档案法实施条例第三条

- 法规：中华人民共和国档案法实施条例（现行有效，施行日期 2024-03-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55413234f0/3.html

档案工作应当坚持和加强党的领导，全面贯彻党的路线方针政策和决策部署，健全党领导档案工作的体制机制，把党的领导贯彻到档案工作各方面和各环节。
