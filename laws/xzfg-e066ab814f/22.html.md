# 国家科学技术奖励条例第二十二条

- 法规：国家科学技术奖励条例（现行有效，施行日期 2024-05-26）
- 章节：第三章国家科学技术奖的提名、评审和授予
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e066ab814f/22.html

国家最高科学技术奖报请国家主席签署并颁发奖章、证书和奖金。
国家自然科学奖、国家技术发明奖、国家科学技术进步奖颁发证书和奖金。
中华人民共和国国际科学技术合作奖颁发奖章和证书。
