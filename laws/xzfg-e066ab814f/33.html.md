# 国家科学技术奖励条例第三十三条

- 法规：国家科学技术奖励条例（现行有效，施行日期 2024-05-26）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e066ab814f/33.html

对违反本条例规定，有科研诚信严重失信行为的个人、组织，记入科研诚信严重失信行为数据库，并共享至全国信用信息共享平台，按照国家有关规定实施联合惩戒。
