# 国家科学技术奖励条例第二十三条

- 法规：国家科学技术奖励条例（现行有效，施行日期 2024-05-26）
- 章节：第三章国家科学技术奖的提名、评审和授予
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e066ab814f/23.html

国家科学技术奖提名和评审的办法、奖励总数、奖励结果等信息应当向社会公布，接受社会监督。
涉及国家安全的保密项目，应当严格遵守国家保密法律法规的有关规定，加强项目内容的保密管理，在适当范围内公布。
