# 外国民用航空器飞行管理规则第三十四条

- 法规：外国民用航空器飞行管理规则（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-277a917c4e/34.html

在特殊情况下，国务院民用航空主管部门公布临时关闭有关的航路或者机场时，与该航路或者机场飞行有关的外国民用航空器，必须根据国务院民用航空主管部门的航行通告或者有关的空中交通管制部门的通知，修订飞行计划。
