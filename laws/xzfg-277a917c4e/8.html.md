# 外国民用航空器飞行管理规则第八条

- 法规：外国民用航空器飞行管理规则（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-277a917c4e/8.html

外国民用航空器在中华人民共和国境内进行不定期飞行时，由国务院民用航空主管部门指派飞行人员（包括领航员和无线电通信员）随机引导，如果许可中有特别规定的，依照规定。
