# 外国民用航空器飞行管理规则第三条

- 法规：外国民用航空器飞行管理规则（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-277a917c4e/3.html

外国民用航空器及其空勤组成员和乘客，在中华人民共和国境内飞行或者停留时，必须遵守中华人民共和国的法律和有关入境、出境、过境的法令规章。
