# 外国民用航空器飞行管理规则第二十八条

- 法规：外国民用航空器飞行管理规则（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-277a917c4e/28.html

外国民用航空器在航空站区域内目视气象条件下飞行时，其空勤组应当进行严密的空中观察，防止与其他航空器碰撞；如果发生碰撞，航空器的机长应负直接责任。
