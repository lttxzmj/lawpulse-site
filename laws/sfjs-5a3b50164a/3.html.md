# 最高人民法院关于诉讼代理人查阅民事案件材料的规定第三条

- 法规：最高人民法院关于诉讼代理人查阅民事案件材料的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5a3b50164a/3.html

诉讼代理人在诉讼过程中需要查阅案件有关材料的，应当提前与该案件的书记员或者审判人员联系；查阅已经审理终结的案件有关材料的，应当与人民法院有关部门工作人员联系。
