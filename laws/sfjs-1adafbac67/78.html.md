# 人民检察院行政诉讼监督规则第七十八条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第四章审查 · 第四节简易案件办理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/78.html

审查简易案件，承办检察官通过审查监督申请书等材料即可以认定案件事实的，可以直接制作审查终结报告，提出处理建议。
审查过程中发现案情复杂或者需要调查核实，不宜适用简易程序的，转为普通案件办理程序。
