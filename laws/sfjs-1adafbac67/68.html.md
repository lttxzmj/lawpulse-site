# 人民检察院行政诉讼监督规则第六十八条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第四章审查 · 第三节听证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/68.html

人民检察院审查行政诉讼监督案件，在事实认定、法律适用、案件处理等方面存在较大争议，或者有重大社会影响，需要当面听取当事人和其他相关人员意见的，可以召开听证会。
