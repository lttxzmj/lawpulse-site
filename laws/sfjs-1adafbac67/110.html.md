# 人民检察院行政诉讼监督规则第一百一十条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第七章对行政案件执行活动的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/110.html

人民检察院发现人民法院在执行活动中违反规定采取调查、查封、扣押、冻结、评估、拍卖、变卖、保管、发还财产，以及信用惩戒等执行实施措施的，应当向同级人民法院提出检察建议。
