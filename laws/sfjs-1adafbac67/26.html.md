# 人民检察院行政诉讼监督规则第二十六条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第三章受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/26.html

当事人申请监督同时符合下列条件的，人民检察院应当受理：
（一）符合本规则第十九条的规定；
（二）符合本规则第二十条的规定；
（三）申请人提供的材料符合本规则第二十一条至第二十四条的规定；
（四）属于本院受理案件范围；
（五）不具有本规则规定的不予受理情形。
