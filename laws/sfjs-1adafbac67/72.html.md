# 人民检察院行政诉讼监督规则第七十二条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第四章审查 · 第三节听证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/72.html

听证会由检察官主持，书记员负责记录，司法警察负责维持秩序。
听证过程应当全程录音录像。经检察长批准，人民检察院可以通过中国检察听证网和其他公共媒体，对听证会进行图文、音频、视频直播或者录播。
