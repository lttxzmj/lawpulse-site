# 人民检察院行政诉讼监督规则第九十一条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第五章对生效行政判决、裁定、调解书的监督 · 第二节提出再审检察建议和提请抗诉、提出抗诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/91.html

地方各级人民检察院发现同级人民法院已经发生法律效力的行政调解书损害国家利益或者社会公共利益的，可以向同级人民法院提出再审检察建议，也可以提请上一级人民检察院抗诉。
