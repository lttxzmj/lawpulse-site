# 人民检察院行政诉讼监督规则第八十二条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第五章对生效行政判决、裁定、调解书的监督 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/82.html

申请人提供的新证据以及人民检察院调查取得的证据，能够证明原判决、裁定确有错误的，应当认定为《中华人民共和国行政诉讼法》第九十一条第二项规定的情形，但原审被诉行政机关无正当理由逾期提供证据的除外。
