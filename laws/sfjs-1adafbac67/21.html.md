# 人民检察院行政诉讼监督规则第二十一条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第三章受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/21.html

当事人向人民检察院申请监督，应当提交监督申请书、身份证明、相关法律文书及证据材料。提交证据材料的，应当附证据清单。
申请监督材料不齐备的，人民检察院应当要求申请人限期补齐，并一次性明确告知应当补齐的全部材料以及逾期未按要求补齐视为撤回监督申请的法律后果。申请人逾期未补齐主要材料的，视为撤回监督申请。
