# 人民检察院行政诉讼监督规则第一百三十三条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/133.html

人民检察院办理行政诉讼监督案件，不收取案件受理费。申请复印、鉴定、审计、勘验等产生的费用由申请人直接支付给有关机构或者单位，人民检察院不得代收代付。
