# 人民检察院行政诉讼监督规则第一百零二条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第五章对生效行政判决、裁定、调解书的监督 · 第三节出席法庭
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/102.html

人民法院开庭审理人民检察院提出再审检察建议的案件，人民检察院派员出席再审法庭的，参照适用本节规定。
人民检察院派员出席法庭的再审案件公开审理的，可以协调人民法院安排人民监督员旁听。
