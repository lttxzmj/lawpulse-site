# 人民检察院行政诉讼监督规则第九十三条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第五章对生效行政判决、裁定、调解书的监督 · 第二节提出再审检察建议和提请抗诉、提出抗诉
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/93.html

人民检察院提请抗诉，应当制作《提请抗诉报告书》，在决定之日起十五日内将《提请抗诉报告书》连同案件卷宗等材料报送上一级人民检察院，并制作通知文书，发送当事人。
