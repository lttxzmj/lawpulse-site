# 人民检察院行政诉讼监督规则第一百二十一条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/121.html

人民检察院办理行政诉讼监督案件，可以对行政诉讼监督情况进行年度或者专题分析，向人民法院、行政机关通报，向党委、人大报告。通报、报告包括以下内容：
（一）审判机关、行政机关存在的普遍性问题和突出问题；
（二）审判机关、行政机关存在的苗头性、倾向性问题或者某方面问题的特点和趋势；
（三）促进依法行政、公正司法的意见和建议；
（四）认为需要通报、报告的其他情形。
