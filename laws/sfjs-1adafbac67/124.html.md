# 人民检察院行政诉讼监督规则第一百二十四条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/124.html

人民法院对行政诉讼监督案件作出再审判决、裁定或者其他处理决定后，提出监督意见的人民检察院应当对处理结果进行审查，并填写《行政诉讼监督案件处理结果审查登记表》。
