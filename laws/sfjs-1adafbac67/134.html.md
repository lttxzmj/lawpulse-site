# 人民检察院行政诉讼监督规则第一百三十四条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第九章其他规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/134.html

人民检察院办理行政诉讼监督案件，对于申请人诉求具有一定合理性，但通过法律途径难以解决，且生活困难的，可以依法给予司法救助。
对于未纳入国家司法救助范围或者实施国家司法救助后仍然面临生活困难的申请人，可以引导其依照相关规定申请社会救助。
