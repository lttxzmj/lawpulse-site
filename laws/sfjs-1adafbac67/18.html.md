# 人民检察院行政诉讼监督规则第十八条

- 法规：人民检察院行政诉讼监督规则（现行有效，施行日期 2021-09-01）
- 章节：第三章受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1adafbac67/18.html

人民检察院受理行政诉讼监督案件的途径包括：
（一）当事人向人民检察院申请监督；
（二）当事人以外的公民、法人或者其他组织向人民检察院控告；
（三）人民检察院依职权发现。
