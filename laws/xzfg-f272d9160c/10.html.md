# 中华人民共和国船舶和海上设施检验条例第十条

- 法规：中华人民共和国船舶和海上设施检验条例（现行有效）
- 章节：第二章船舶检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f272d9160c/10.html

在中国沿海水域从事钻探、开发作业的外国籍钻井船、移动式平台的所有人或者经营人，必须向船检局设置或者指定的船舶检验机构申请下列检验：
(一)作业前检验；
(二)作业期间的定期检验。
