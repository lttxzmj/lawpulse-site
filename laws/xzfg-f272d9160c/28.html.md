# 中华人民共和国船舶和海上设施检验条例第二十八条

- 法规：中华人民共和国船舶和海上设施检验条例（现行有效）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f272d9160c/28.html

船舶检验机构的检验人员滥用职权、徇私舞弊、玩忽职守、严重失职的，由所在单位或者上级机关给予行政处分或者撤销其检验资格；情节严重，构成犯罪的，由司法机关依法追究刑事责任。
