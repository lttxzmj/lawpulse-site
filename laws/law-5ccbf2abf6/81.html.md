# 中华人民共和国商业银行法第八十一条

- 法规：中华人民共和国商业银行法（现行有效，施行日期 2015-10-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-5ccbf2abf6/81.html

未经国务院银行业监督管理机构批准，擅自设立商业银行，或者非法吸收公众存款、变相吸收公众存款，构成犯罪的，依法追究刑事责任；并由国务院银行业监督管理机构予以取缔。
伪造、变造、转让商业银行经营许可证，构成犯罪的，依法追究刑事责任。
