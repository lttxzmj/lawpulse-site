# 国务院关于在线政务服务的若干规定第五条

- 法规：国务院关于在线政务服务的若干规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9be2f2967d/5.html

国家政务服务平台基于自然人身份信息、法人单位信息等资源，建设全国统一身份认证系统，为各地区、各部门政务服务平台提供统一身份认证服务，实现一次认证、全网通办。
