# 国务院关于在线政务服务的若干规定第三条

- 法规：国务院关于在线政务服务的若干规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9be2f2967d/3.html

国务院办公厅负责牵头推进国家政务服务平台建设，推动建设一体化在线平台标准规范体系、安全保障体系和运营管理体系。
省、自治区、直辖市人民政府和国务院有关部门负责本地区、本部门政务服务平台建设、安全保障和运营管理，做好与国家政务服务平台对接工作。
