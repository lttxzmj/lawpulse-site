# 农民承担费用和劳务管理条例第三条

- 法规：农民承担费用和劳务管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-216c0516b3/3.html

国务院农业行政主管部门主管全国农民承担费用和劳务(以下简称农民负担)的监督管理工作。县级以上地方人民政府农业行政主管部门主管本行政区域内的农民负担监督管理工作。
乡人民政府主管本乡的农民负担监督管理工作，日常工作由乡农村经济经营管理部门负责。
