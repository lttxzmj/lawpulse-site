# 农民承担费用和劳务管理条例第二十三条

- 法规：农民承担费用和劳务管理条例（现行有效）
- 章节：第四章其他项目的监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-216c0516b3/23.html

向农民集资，必须在法律、法规和国务院有关政策允许的范围内进行，并遵循自愿、适度、出资者受益、资金定向使用的原则。集资项目的设置和范围的确定，须经省、自治区、直辖市以上人民政府计划主管部门会同财政主管部门、农民负担监督管理部门批准，重要项目须经国务院或者省、自治区、直辖市人民政府批准。
