# 最高人民法院关于审理船舶碰撞纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理船舶碰撞纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-55af1fd655/3.html

因船舶碰撞导致船舶触碰引起的侵权纠纷，依照海商法第八章的规定确定碰撞船舶的赔偿责任。
非因船舶碰撞导致船舶触碰引起的侵权纠纷，依照民法典的规定确定触碰船舶的赔偿责任，但不影响海商法第八章之外其他规定的适用。
