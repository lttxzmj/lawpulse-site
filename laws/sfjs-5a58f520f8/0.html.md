# 最高人民法院关于人民法院不予受理人民检察院单独就诉讼费负担裁定提出抗诉问题的批复全文

- 法规：最高人民法院关于人民法院不予受理人民检察院单独就诉讼费负担裁定提出抗诉问题的批复（现行有效，施行日期 1998-09-05）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5a58f520f8/0.html

法释〔1998〕22号
（1998年7月21日最高人民法院审判委员会第1005次会议通过 1998年8月31日最高人民法院公告公布 自1998年9月5日起施行）
河南省高级人民法院：
你院豫高法〔1998〕131号《关于人民检察院单独就诉讼费负担的裁定进行抗诉能否受理的请示》收悉。经研究，同意你院意见，即：人民检察院对人民法院就诉讼费负担的裁定提出抗诉，没有法律依据，人民法院不予受理。
此复。
