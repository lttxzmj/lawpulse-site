# 最高人民法院关于审理军队、武警部队、政法机关移交、撤销企业和与党政机关脱钩企业相关纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理军队、武警部队、政法机关移交、撤销企业和与党政机关脱钩企业相关纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d134231361/3.html

被开办企业虽然领取了企业法人营业执照，但投入的资金未达到《中华人民共和国企业法人登记管理条例施行细则》第十二条第七项规定数额的，或者不具备企业法人其他条件的，应当认定其不具备法人资格，其民事责任由开办单位承担。
