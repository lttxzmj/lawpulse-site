# 最高人民法院关于民事执行中变更、追加当事人若干问题的规定第三条

- 法规：最高人民法院关于民事执行中变更、追加当事人若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-095b1c053f/3.html

作为申请执行人的自然人离婚时，生效法律文书确定的权利全部或部分分割给其配偶，该配偶申请变更、追加其为申请执行人的，人民法院应予支持。
