# 最高人民法院关于民事执行中变更、追加当事人若干问题的规定第二十八条

- 法规：最高人民法院关于民事执行中变更、追加当事人若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-095b1c053f/28.html

申请人申请变更、追加执行当事人，应当向执行法院提交书面申请及相关证据材料。
除事实清楚、权利义务关系明确、争议不大的案件外，执行法院应当组成合议庭审查并公开听证。经审查，理由成立的，裁定变更、追加；理由不成立的，裁定驳回。
执行法院应当自收到书面申请之日起六十日内作出裁定。有特殊情况需要延长的，由本院院长批准。
