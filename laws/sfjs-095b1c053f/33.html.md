# 最高人民法院关于民事执行中变更、追加当事人若干问题的规定第三十三条

- 法规：最高人民法院关于民事执行中变更、追加当事人若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-095b1c053f/33.html

被申请人提起的执行异议之诉，人民法院经审理，按照下列情形分别处理：
（一）理由成立的，判决不得变更、追加被申请人为被执行人或者判决变更责任范围；
（二）理由不成立的，判决驳回诉讼请求。
诉讼期间，人民法院不得对被申请人争议范围内的财产进行处分。申请人请求人民法院继续执行并提供相应担保的，人民法院可以准许。
