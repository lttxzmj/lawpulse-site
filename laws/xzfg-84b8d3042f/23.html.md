# 中华人民共和国国境口岸卫生监督办法第二十三条

- 法规：中华人民共和国国境口岸卫生监督办法（现行有效）
- 章节：第六章卫生监督机关的职责
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-84b8d3042f/23.html

国境口岸卫生监督员持其证件，有权对国境口岸和交通工具的负责人，进行卫生监督、检查和技术指导；配合有关部门，对卫生工作情况不良或引起传染病传播的单位或个人，提出改进意见，协同有关部门采取必要措施，进行处理。
