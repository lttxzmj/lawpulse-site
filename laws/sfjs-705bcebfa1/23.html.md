# 最高人民法院关于扣押与拍卖船舶适用法律若干问题的规定第二十三条

- 法规：最高人民法院关于扣押与拍卖船舶适用法律若干问题的规定（现行有效，施行日期 2015-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-705bcebfa1/23.html

当事人依照民事诉讼法第十五章第七节的规定，申请拍卖船舶实现船舶担保物权的，由船舶所在地或船籍港所在地的海事法院管辖，按照海事诉讼特别程序法以及本规定关于船舶拍卖受偿程序的规定处理。
