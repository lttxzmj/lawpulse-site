# 商事调解条例第二十二条

- 法规：商事调解条例（现行有效，施行日期 2026-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e0b22a0b58/22.html

经商事调解达成协议的，除当事人另有约定外，应当制作商事调解协议，载明主要事实、争议事项和当事人达成协议的主要内容、履行方式与期限等。商事调解员应当在商事调解协议上签名并加盖商事调解组织的印章。
商事调解协议的内容不得损害国家利益、社会公共利益和他人合法权益，不得违反法律、行政法规的强制性规定，不得违背公序良俗。
商事调解协议具有法律约束力，当事人应当履行。
