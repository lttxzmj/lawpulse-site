# 商事调解条例第二十八条

- 法规：商事调解条例（现行有效，施行日期 2026-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e0b22a0b58/28.html

未经司法行政部门批准，擅自以商事调解组织名义开展本条例规定的商事调解活动的，由省、自治区、直辖市或者设区的市级人民政府司法行政部门责令改正，处10万元以上30万元以下的罚款；有违法所得的，没收违法所得。
