# 重要军工设施保护条例第二十六条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第四章重要军工设施管理单位的责任义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/26.html

重要军工设施管理单位应当建立重要军工设施档案，定期对重要军工设施进行检查、维护，根据需要升级完善安全防护措施。
