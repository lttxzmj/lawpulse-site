# 重要军工设施保护条例第三十八条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第五章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/38.html

国务院国防科技工业主管部门应当建立重要军工设施风险管控机制，制定监督检查计划，会同有关部门开展监督检查，及时处理发现的风险隐患。
