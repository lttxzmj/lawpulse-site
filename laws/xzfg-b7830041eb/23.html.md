# 重要军工设施保护条例第二十三条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第四章重要军工设施管理单位的责任义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/23.html

重要军工设施管理单位应当建立健全本单位重要军工设施保护制度和保护责任制，完善考核机制，确保重要军工设施安全保密和使用效能。
