# 重要军工设施保护条例第三十三条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第五章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/33.html

县级以上地方人民政府应当制定重要军工设施保护的具体方案，可以公告施行。
划定重要军工设施保护区的重要军工设施保护的具体方案，应当随重要军工设施保护区范围划定方案一并报批。
