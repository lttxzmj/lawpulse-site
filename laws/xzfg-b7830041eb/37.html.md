# 重要军工设施保护条例第三十七条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第五章保障和监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/37.html

各级人民政府应当加强国防和重要军工设施保护教育，使全体公民增强国防观念，保护重要军工设施，保守关于重要军工设施的国家秘密，制止破坏、危害重要军工设施的行为。
