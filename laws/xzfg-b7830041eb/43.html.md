# 重要军工设施保护条例第四十三条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/43.html

违反本条例规定，在作为重要军工设施的机场的净空保护区域内修建超出机场净空保护标准的建筑物、构筑物或者其他设施的，由自然资源、住房城乡建设主管部门按照各自职责责令停止兴建活动、限期拆除超高部分，依法处以罚款。
