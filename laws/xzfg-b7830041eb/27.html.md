# 重要军工设施保护条例第二十七条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第四章重要军工设施管理单位的责任义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/27.html

重要军工设施管理单位应当制定本单位重要军工设施保护应急预案，定期开展应急演练。
重要军工设施管理单位应当定期组织开展重要军工设施安全保护风险评估，及时发现和消除安全隐患。
