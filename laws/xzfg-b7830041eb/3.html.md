# 重要军工设施保护条例第三条

- 法规：重要军工设施保护条例（现行有效，施行日期 2025-09-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b7830041eb/3.html

重要军工设施保护工作坚持中国共产党的领导，坚持总体国家安全观，坚持与国防科技工业体系和布局相适应、与经济社会发展相协调，坚持积极防范、内外兼顾、综合协调，确保重要军工设施安全。
