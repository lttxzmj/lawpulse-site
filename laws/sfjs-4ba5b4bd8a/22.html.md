# 最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释第二十二条

- 法规：最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4ba5b4bd8a/22.html

人民法院审理道路交通事故损害赔偿案件，应当将承保交强险的保险公司列为共同被告。但该保险公司已经在交强险责任限额范围内予以赔偿且当事人无异议的除外。
人民法院审理道路交通事故损害赔偿案件，当事人请求将承保商业三者险的保险公司列为共同被告的，人民法院应予准许。
