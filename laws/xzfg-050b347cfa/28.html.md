# 彩票管理条例第二十八条

- 法规：彩票管理条例（现行有效）
- 章节：第四章彩票资金管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-050b347cfa/28.html

彩票资金包括彩票奖金、彩票发行费和彩票公益金。彩票资金构成比例由国务院决定。
彩票品种中彩票资金的具体构成比例，由国务院财政部门按照国务院的决定确定。
随着彩票发行规模的扩大和彩票品种的增加，可以降低彩票发行费比例。
