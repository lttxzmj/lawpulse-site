# 最高人民法院关于民事审判监督程序严格依法适用指令再审和发回重审若干问题的规定第三条

- 法规：最高人民法院关于民事审判监督程序严格依法适用指令再审和发回重审若干问题的规定（现行有效，施行日期 2015-03-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8e4b5fd882/3.html

虽然符合本规定第二条可以指令再审的条件，但有下列情形之一的，应当提审：
（一）原判决、裁定系经原审人民法院再审审理后作出的；
（二）原判决、裁定系经原审人民法院审判委员会讨论作出的；
（三）原审审判人员在审理该案件时有贪污受贿，徇私舞弊，枉法裁判行为的；
（四）原审人民法院对该案无再审管辖权的；
（五）需要统一法律适用或裁量权行使标准的；
（六）其他不宜指令原审人民法院再审的情形。
