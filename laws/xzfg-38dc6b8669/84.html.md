# 中华人民共和国食品安全法实施条例第八十四条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/84.html

县级以上人民政府食品安全监督管理部门及其工作人员违法向他人提供网络食品交易第三方平台提供者提供的信息的，依照食品安全法第一百四十五条的规定给予处分。
