# 中华人民共和国食品安全法实施条例第四十二条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第五章食品检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/42.html

依照食品安全法第八十八条的规定申请复检的，申请人应当向复检机构先行支付复检费用。复检结论表明食品不合格的，复检费用由复检申请人承担；复检结论表明食品合格的，复检费用由实施抽样检验的食品安全监督管理部门承担。
复检机构无正当理由不得拒绝承担复检任务。
