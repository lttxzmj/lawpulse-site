# 中华人民共和国食品安全法实施条例第七十七条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/77.html

县级以上地方人民政府食品安全监督管理等部门对有食品安全法第一百二十三条规定的违法情形且情节严重，可能需要行政拘留的，应当及时将案件及有关材料移送同级公安机关。公安机关认为需要补充材料的，食品安全监督管理等部门应当及时提供。公安机关经审查认为不符合行政拘留条件的，应当及时将案件及有关材料退回移送的食品安全监督管理等部门。
