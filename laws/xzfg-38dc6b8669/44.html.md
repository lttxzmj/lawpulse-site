# 中华人民共和国食品安全法实施条例第四十四条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第六章食品进出口
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/44.html

进口商进口食品、食品添加剂，应当按照规定向出入境检验检疫机构报检，如实申报产品相关信息，并随附法律、行政法规规定的合格证明材料。
