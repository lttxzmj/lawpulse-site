# 中华人民共和国食品安全法实施条例第七十二条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/72.html

从事对温度、湿度等有特殊要求的食品贮存业务的非食品生产经营者，食品集中交易市场的开办者、食品展销会的举办者，未按照规定备案或者报告的，由县级以上人民政府食品安全监督管理部门责令改正，给予警告；拒不改正的，处1万元以上5万元以下罚款；情节严重的，责令停产停业，并处5万元以上20万元以下罚款。
