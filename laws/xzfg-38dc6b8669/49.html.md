# 中华人民共和国食品安全法实施条例第四十九条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第六章食品进出口
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/49.html

进口商依照食品安全法第九十四条第三款的规定召回进口食品的，应当将食品召回和处理情况向所在地县级人民政府食品安全监督管理部门和所在地出入境检验检疫机构报告。
