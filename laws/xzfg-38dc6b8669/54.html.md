# 中华人民共和国食品安全法实施条例第五十四条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第七章食品安全事故处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/54.html

食品安全事故按照国家食品安全事故应急预案实行分级管理。县级以上人民政府食品安全监督管理部门会同同级有关部门负责食品安全事故调查处理。
县级以上人民政府应当根据实际情况及时修改、完善食品安全事故应急预案。
