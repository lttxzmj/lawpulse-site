# 中华人民共和国食品安全法实施条例第五十五条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第七章食品安全事故处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/55.html

县级以上人民政府应当完善食品安全事故应急管理机制，改善应急装备，做好应急物资储备和应急队伍建设，加强应急培训、演练。
