# 中华人民共和国食品安全法实施条例第四十三条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第五章食品检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/43.html

任何单位和个人不得发布未依法取得资质认定的食品检验机构出具的食品检验信息，不得利用上述检验信息对食品、食品生产经营者进行等级评定，欺骗、误导消费者。
