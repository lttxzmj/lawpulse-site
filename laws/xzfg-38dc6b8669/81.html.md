# 中华人民共和国食品安全法实施条例第八十一条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/81.html

食品安全监督管理部门依照食品安全法、本条例对违法单位或者个人处以30万元以上罚款的，由设区的市级以上人民政府食品安全监督管理部门决定。罚款具体处罚权限由国务院食品安全监督管理部门规定。
