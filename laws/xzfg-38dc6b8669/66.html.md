# 中华人民共和国食品安全法实施条例第六十六条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第八章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/66.html

国务院食品安全监督管理部门应当会同国务院有关部门建立守信联合激励和失信联合惩戒机制，结合食品生产经营者信用档案，建立严重违法生产经营者黑名单制度，将食品安全信用状况与准入、融资、信贷、征信等相衔接，及时向社会公布。
