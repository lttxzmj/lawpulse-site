# 中华人民共和国食品安全法实施条例第十八条

- 法规：中华人民共和国食品安全法实施条例（现行有效，施行日期 2019-12-01）
- 章节：第四章食品生产经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38dc6b8669/18.html

食品生产经营者应当建立食品安全追溯体系，依照食品安全法的规定如实记录并保存进货查验、出厂检验、食品销售等信息，保证食品可追溯。
