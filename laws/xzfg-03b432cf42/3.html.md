# 中华人民共和国保守国家秘密法实施条例第三条

- 法规：中华人民共和国保守国家秘密法实施条例（现行有效，施行日期 2024-09-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03b432cf42/3.html

国家保密行政管理部门主管全国的保密工作。县级以上地方各级保密行政管理部门在上级保密行政管理部门指导下，主管本行政区域的保密工作。
