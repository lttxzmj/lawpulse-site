# 中华人民共和国保守国家秘密法实施条例第六十四条

- 法规：中华人民共和国保守国家秘密法实施条例（现行有效，施行日期 2024-09-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03b432cf42/64.html

设区的市级以上保密行政管理部门应当建立监测预警制度，分析研判保密工作有关情况，配备监测预警设施和相应工作力量，发现、识别、处置安全保密风险隐患，及时发出预警通报。
