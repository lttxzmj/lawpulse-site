# 中华人民共和国保守国家秘密法实施条例第七十二条

- 法规：中华人民共和国保守国家秘密法实施条例（现行有效，施行日期 2024-09-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03b432cf42/72.html

保密行政管理部门未依法履行职责，或者滥用职权、玩忽职守、徇私舞弊的，对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。
