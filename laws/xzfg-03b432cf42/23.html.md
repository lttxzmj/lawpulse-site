# 中华人民共和国保守国家秘密法实施条例第二十三条

- 法规：中华人民共和国保守国家秘密法实施条例（现行有效，施行日期 2024-09-01）
- 章节：第二章国家秘密的范围和密级
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03b432cf42/23.html

机关、单位被撤销或者合并、分立的，该机关、单位所确定国家秘密的变更和解除，由承担其职能的机关、单位负责；没有相应机关、单位的，由其上级机关、单位或者同级保密行政管理部门指定的机关、单位负责。
