# 通用航空飞行管制条例第二十三条

- 法规：通用航空飞行管制条例（现行有效）
- 章节：第四章飞行保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-517196b5e3/23.html

从事通用航空飞行活动的单位、个人，应当与有关飞行管制部门建立可靠的通信联络。
在划设的临时飞行空域内从事通用航空飞行活动时，应当保持空地联络畅通。
