# 通用航空飞行管制条例第三条

- 法规：通用航空飞行管制条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-517196b5e3/3.html

本条例所称通用航空，是指除军事、警务、海关缉私飞行和公共航空运输飞行以外的航空活动，包括从事工业、农业、林业、渔业、矿业、建筑业的作业飞行和医疗卫生、抢险救灾、气象探测、海洋监测、科学实验、遥感测绘、教育训练、文化体育、旅游观光等方面的飞行活动。
