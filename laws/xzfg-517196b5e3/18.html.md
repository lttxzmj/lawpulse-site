# 通用航空飞行管制条例第十八条

- 法规：通用航空飞行管制条例（现行有效）
- 章节：第三章飞行活动的管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-517196b5e3/18.html

使用临时航线转场飞行的，其飞行计划申请应当在拟飞行2天前向当地飞行管制部门提出；飞行管制部门应当在拟飞行前1天18时前作出批准或者不予批准的决定，并通知申请人，同时按照规定通报有关单位。
