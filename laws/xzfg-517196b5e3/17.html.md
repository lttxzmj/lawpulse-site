# 通用航空飞行管制条例第十七条

- 法规：通用航空飞行管制条例（现行有效）
- 章节：第三章飞行活动的管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-517196b5e3/17.html

在划设的临时飞行空域内实施通用航空飞行活动的，可以在申请划设临时飞行空域时一并提出15天以内的短期飞行计划申请，不再逐日申请；但是每日飞行开始前和结束后，应当及时报告飞行管制部门。
