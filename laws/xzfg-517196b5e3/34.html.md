# 通用航空飞行管制条例第三十四条

- 法规：通用航空飞行管制条例（现行有效）
- 章节：第五章升放和系留气球的规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-517196b5e3/34.html

升放无人驾驶自由气球，应当在拟升放2天前持本条例第三十三条规定的批准文件向当地飞行管制部门提出升放申请；飞行管制部门应当在拟升放1天前作出批准或者不予批准的决定，并通知申请人。
