# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（四）第二十五条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（四）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3492980330/25.html

股东依据公司法第一百五十一条第二款、第三款规定直接提起诉讼的案件，胜诉利益归属于公司。股东请求被告直接向其承担民事责任的，人民法院不予支持。
