# 最高人民法院关于严格执行案件审理期限制度的若干规定第十一条

- 法规：最高人民法院关于严格执行案件审理期限制度的若干规定（现行有效，施行日期 2000-09-28）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d64ff07e46/11.html

刑事公诉案件、被告人被羁押的自诉案件，需要延长审理期限的，应当在审理期限届满七日以前，向高级人民法院提出申请；被告人未被羁押的刑事自诉案件，需要延长审理期限的，应当在审理期限届满十日前向本院院长提出申请。
