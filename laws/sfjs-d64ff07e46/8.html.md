# 最高人民法院关于严格执行案件审理期限制度的若干规定第八条

- 法规：最高人民法院关于严格执行案件审理期限制度的若干规定（现行有效，施行日期 2000-09-28）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d64ff07e46/8.html

案件的审理期限从立案次日起计算。
由简易程序转为普通程序审理的第一审刑事案件的期限，从决定转为普通程序次日起计算；由简易程序转为普通程序审理的第一审民事案件的期限，从立案次日起连续计算。
