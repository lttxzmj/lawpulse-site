# 最高人民法院关于严格执行案件审理期限制度的若干规定第二十三条

- 法规：最高人民法院关于严格执行案件审理期限制度的若干规定（现行有效，施行日期 2000-09-28）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d64ff07e46/23.html

审判人员故意拖延办案，或者因过失延误办案，造成严重后果的，依照《人民法院审判纪律处分办法（试行）》第五十九条的规定予以处分。
审判人员故意拖延移送案件材料，或者接受委托送达后，故意拖延不予送达的，参照《人民法院审判纪律处分办法（试行）》第五十九条的规定予以处分。
