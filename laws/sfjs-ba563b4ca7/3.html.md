# 最高人民法院关于审理注册商标、企业名称与在先权利冲突的民事纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理注册商标、企业名称与在先权利冲突的民事纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-ba563b4ca7/3.html

人民法院应当根据原告的诉讼请求和争议民事法律关系的性质，按照民事案件案由规定，确定注册商标或者企业名称与在先权利冲突的民事纠纷案件的案由，并适用相应的法律。
