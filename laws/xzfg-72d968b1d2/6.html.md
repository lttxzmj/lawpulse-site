# 中华人民共和国土地增值税暂行条例第六条

- 法规：中华人民共和国土地增值税暂行条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-72d968b1d2/6.html

计算增值额的扣除项目：
(一)取得土地使用权所支付的金额；
(二)开发土地的成本、费用；
(三)新建房及配套设施的成本、费用，或者旧房及建筑物的评估价格；
(四)与转让房地产有关的税金；
(五)财政部规定的其他扣除项目。
