# 出版管理条例第七十二条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第九章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/72.html

行政法规对音像制品和电子出版物的出版、复制、进口、发行另有规定的，适用其规定。
接受境外机构或者个人赠送出版物的管理办法、订户订购境外出版物的管理办法、网络出版审批和管理办法，由国务院出版行政主管部门根据本条例的原则另行制定。
