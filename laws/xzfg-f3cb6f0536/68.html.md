# 出版管理条例第六十八条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/68.html

未经批准，举办境外出版物展览的，由出版行政主管部门责令停止违法行为，没收出版物、违法所得；情节严重的，责令限期停业整顿或者由原发证机关吊销许可证。
