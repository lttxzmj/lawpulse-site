# 出版管理条例第七十条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/70.html

单位违反本条例被处以吊销许可证行政处罚的，其法定代表人或者主要负责人自许可证被吊销之日起10年内不得担任出版、印刷或者复制、进口、发行单位的法定代表人或者主要负责人。
出版从业人员违反本条例规定，情节严重的，由原发证机关吊销其资格证书。
