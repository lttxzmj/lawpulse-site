# 出版管理条例第六十九条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/69.html

印刷或者复制、批发、零售、出租、散发含有本条例第二十五条、第二十六条禁止内容的出版物或者其他非法出版物的，当事人对非法出版物的来源作出说明、指认，经查证属实的，没收出版物、违法所得，可以减轻或者免除其他行政处罚。
