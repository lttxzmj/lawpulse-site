# 出版管理条例第五十条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第六章监督与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/50.html

出版行政主管部门履行下列职责：
（一）对出版物的出版、印刷、复制、发行、进口单位进行行业监管，实施准入和退出管理；
（二）对出版活动进行监管，对违反本条例的行为进行查处；
（三）对出版物内容和质量进行监管；
（四）根据国家有关规定对出版从业人员进行管理。
