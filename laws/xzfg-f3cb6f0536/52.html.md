# 出版管理条例第五十二条

- 法规：出版管理条例（现行有效，施行日期 2025-01-20）
- 章节：第六章监督与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f3cb6f0536/52.html

国务院出版行政主管部门制定出版单位综合评估办法，对出版单位分类实施综合评估。
出版物的出版、印刷或者复制、发行和进口经营单位不再具备行政许可的法定条件的，由出版行政主管部门责令限期改正；逾期仍未改正的，由原发证机关撤销行政许可。
