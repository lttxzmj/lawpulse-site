# 中华人民共和国母婴保健法实施办法第三十二条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第五章技术鉴定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/32.html

当事人对婚前医学检查、遗传病诊断、产前诊断结果有异议，需要进一步确诊的，可以自接到检查或者诊断结果之日起15日内向所在地县级或者设区的市级母婴保健医学技术鉴定委员会提出书面鉴定申请。
母婴保健医学技术鉴定委员会应当自接到鉴定申请之日起30日内作出医学技术鉴定意见，并及时通知当事人。
当事人对鉴定意见有异议的，可以自接到鉴定意见通知书之日起15日内向上一级母婴保健医学技术鉴定委员会申请再鉴定。
