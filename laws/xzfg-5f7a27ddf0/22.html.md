# 中华人民共和国母婴保健法实施办法第二十二条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第三章孕产期保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/22.html

生育过严重遗传性疾病或者严重缺陷患儿的，再次妊娠前，夫妻双方应当按照国家有关规定到医疗、保健机构进行医学检查。医疗、保健机构应当向当事人介绍有关遗传性疾病的知识，给予咨询、指导。对诊断患有医学上认为不宜生育的严重遗传性疾病的，医师应当向当事人说明情况，并提出医学意见。
