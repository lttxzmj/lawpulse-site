# 中华人民共和国母婴保健法实施办法第二十七条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第四章婴儿保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/27.html

医疗、保健机构应当按照规定的程序和项目对婴儿进行预防接种。
婴儿的监护人应当保证婴儿及时接受预防接种。
