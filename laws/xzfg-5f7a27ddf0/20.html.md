# 中华人民共和国母婴保健法实施办法第二十条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第三章孕产期保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/20.html

孕妇有下列情形之一的，医师应当对其进行产前诊断：
（一）羊水过多或者过少的；
（二）胎儿发育异常或者胎儿有可疑畸形的；
（三）孕早期接触过可能导致胎儿先天缺陷的物质的；
（四）有遗传病家族史或者曾经分娩过先天性严重缺陷婴儿的；
（五）初产妇年龄超过35周岁的。
