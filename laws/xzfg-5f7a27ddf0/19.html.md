# 中华人民共和国母婴保健法实施办法第十九条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第三章孕产期保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/19.html

医疗、保健机构发现孕妇患有下列严重疾病或者接触物理、化学、生物等有毒、有害因素，可能危及孕妇生命安全或者可能严重影响孕妇健康和胎儿正常发育的，应当对孕妇进行医学指导和下列必要的医学检查：
（一）严重的妊娠合并症或者并发症；
（二）严重的精神性疾病；
（三）国务院卫生行政部门规定的严重影响生育的其他疾病。
