# 中华人民共和国母婴保健法实施办法第十六条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第二章婚前保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/16.html

在实行婚前医学检查的地区，婚姻登记机关在办理结婚登记时，应当查验婚前医学检查证明或者母婴保健法第十一条规定的医学鉴定证明。
