# 中华人民共和国母婴保健法实施办法第十一条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第二章婚前保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/11.html

从事婚前医学检查的医疗、保健机构，由其所在地县级人民政府卫生行政部门进行审查；符合条件的，在其《医疗机构执业许可证》上注明。
