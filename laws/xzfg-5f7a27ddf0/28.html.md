# 中华人民共和国母婴保健法实施办法第二十八条

- 法规：中华人民共和国母婴保健法实施办法（现行有效，施行日期 2023-07-20）
- 章节：第四章婴儿保健
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5f7a27ddf0/28.html

国家推行母乳喂养。医疗、保健机构应当为实施母乳喂养提供技术指导，为住院分娩的产妇提供必要的母乳喂养条件。
医疗、保健机构不得向孕产妇和婴儿家庭宣传、推荐母乳代用品。
