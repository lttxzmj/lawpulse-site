# 工商行政管理所条例第八条

- 法规：工商行政管理所条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d34e23ff9d/8.html

工商所的具体行政行为是区、县工商局的具体行政行为，但有下列情况之一的，工商所可以以自己的名义作出具体行政行为：
(一)对个体工商户违法行为的处罚；
(二)对集市贸易中违法行为的处罚；
(三)法律、法规和规章规定工商所以自己的名义作出的其他具体行政行为。
前款第(一)、(二)项处罚不包括吊销营业执照。
