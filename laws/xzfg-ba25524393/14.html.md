# 婚姻登记条例第十四条

- 法规：婚姻登记条例（现行有效，施行日期 2025-05-10）
- 章节：第三章离婚登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba25524393/14.html

申请离婚登记的当事人有下列情形之一的，婚姻登记机关不予受理：
（一）未达成离婚协议的；
（二）属于无民事行为能力人或者限制民事行为能力人的；
（三）其结婚登记不是在中国内地办理的。
