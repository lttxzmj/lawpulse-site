# 中华人民共和国民用航空安全保卫条例第三条

- 法规：中华人民共和国民用航空安全保卫条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1eea0c20b1/3.html

民用航空安全保卫工作实行统一管理、分工负责的原则。
民用航空公安机关(以下简称民航公安机关)负责对民用航空安全保卫工作实施统一管理、检查和监督。
