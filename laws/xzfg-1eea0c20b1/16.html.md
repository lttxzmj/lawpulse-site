# 中华人民共和国民用航空安全保卫条例第十六条

- 法规：中华人民共和国民用航空安全保卫条例（现行有效）
- 章节：第二章民用机场的安全保卫
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1eea0c20b1/16.html

机场内禁止下列行为：
(一)攀(钻)越、损毁机场防护围栏及其他安全防护设施；
(二)在机场控制区内狩猎、放牧、晾晒谷物、教练驾驶车辆；
(三)无机场控制区通行证进入机场控制区；
(四)随意穿越航空器跑道、滑行道；
(五)强行登、占航空器；
(六)谎报险情，制造混乱；
(七)扰乱机场秩序的其他行为。
