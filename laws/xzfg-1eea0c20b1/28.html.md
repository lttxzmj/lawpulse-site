# 中华人民共和国民用航空安全保卫条例第二十八条

- 法规：中华人民共和国民用航空安全保卫条例（现行有效）
- 章节：第四章安全检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1eea0c20b1/28.html

进入候机隔离区的工作人员(包括机组人员)及其携带的物品，应当接受安全检查。
接送旅客的人员和其他人员不得进入候机隔离区。
