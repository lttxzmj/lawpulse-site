# 最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释第二十一条

- 法规：最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释（现行有效，施行日期 2006-09-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e23320b273/21.html

当事人申请撤销国内仲裁裁决的案件属于下列情形之一的，人民法院可以依照仲裁法第六十一条的规定通知仲裁庭在一定期限内重新仲裁：
（一）仲裁裁决所根据的证据是伪造的；
（二）对方当事人隐瞒了足以影响公正裁决的证据的。
人民法院应当在通知中说明要求重新仲裁的具体理由。
