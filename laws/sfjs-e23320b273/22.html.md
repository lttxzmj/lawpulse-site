# 最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释第二十二条

- 法规：最高人民法院关于适用《中华人民共和国仲裁法》若干问题的解释（现行有效，施行日期 2006-09-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e23320b273/22.html

仲裁庭在人民法院指定的期限内开始重新仲裁的，人民法院应当裁定终结撤销程序；未开始重新仲裁的，人民法院应当裁定恢复撤销程序。
