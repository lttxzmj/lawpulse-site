# 金融资产管理公司条例第二十八条

- 法规：金融资产管理公司条例（现行有效）
- 章节：第五章公司的经营和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bf3f89fa4e/28.html

金融资产管理公司免交在收购国有银行不良贷款和承接、处置因收购国有银行不良贷款形成的资产的业务活动中的税收。具体办法由财政部会同国家税务总局制定。
金融资产管理公司免交工商登记注册费等行政性收费。
