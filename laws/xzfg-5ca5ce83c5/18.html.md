# 中国人民解放军实施《中华人民共和国执业医师法》办法第十八条

- 法规：中国人民解放军实施《中华人民共和国执业医师法》办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ca5ce83c5/18.html

军队人员非医师行医的，依照《中国人民解放军纪律条令》的有关规定，给予处分；给患者造成损害的，依法承担赔偿责任；构成犯罪的，依法追究刑事责任。
