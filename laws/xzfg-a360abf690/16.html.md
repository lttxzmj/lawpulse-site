# 国际航行船舶进出中华人民共和国口岸检查办法第十六条

- 法规：国际航行船舶进出中华人民共和国口岸检查办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a360abf690/16.html

本办法下列用语的含义：
(一)国际航行船舶，是指进出中华人民共和国口岸的外国籍船舶和航行国际航线的中华人民共和国国籍船舶。
(二)口岸，是指国家批准可以进出国际航行船舶的港口。
(三)船方，是指船舶所有人或者经营人。
