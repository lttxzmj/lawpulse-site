# 国际航行船舶进出中华人民共和国口岸检查办法第三条

- 法规：国际航行船舶进出中华人民共和国口岸检查办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a360abf690/3.html

中华人民共和国港务监督机构(以下简称港务监督机构)、中华人民共和国海关(以下简称海关)、中华人民共和国出入境边防检查机关是负责对船舶进出中华人民共和国口岸实施检查的机关(以下统称检查机关)。
