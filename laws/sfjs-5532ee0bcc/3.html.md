# 最高人民法院关于审理为境外窃取、刺探、收买、非法提供国家秘密、情报案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理为境外窃取、刺探、收买、非法提供国家秘密、情报案件具体应用法律若干问题的解释（现行有效，施行日期 2001-01-22）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5532ee0bcc/3.html

为境外窃取、刺探、收买、非法提供国家秘密或者情报，具有下列情形之一的，处5年以上10年以下有期徒刑，可以并处没收财产：
（一）为境外窃取、刺探、收买、非法提供机密级国家秘密的；
（二）为境外窃取、刺探、收买、非法提供三项以上秘密级国家秘密的；
（三）为境外窃取、刺探、收买、非法提供国家秘密或者情报，对国家安全和利益造成其他严重损害的。
