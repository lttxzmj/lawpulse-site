# 最高人民法院关于审理企业破产案件指定管理人的规定第二十八条

- 法规：最高人民法院关于审理企业破产案件指定管理人的规定（现行有效，施行日期 2007-06-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-27c1d8ee06/28.html

管理人无正当理由，不得拒绝人民法院的指定。
管理人一经指定，不得以任何形式将管理人应当履行的职责全部或者部分转给其他社会中介机构或者个人。
