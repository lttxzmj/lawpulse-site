# 最高人民法院关于审理企业破产案件指定管理人的规定第二十六条

- 法规：最高人民法院关于审理企业破产案件指定管理人的规定（现行有效，施行日期 2007-06-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-27c1d8ee06/26.html

社会中介机构或者个人有重大债务纠纷或者因涉嫌违法行为正被相关部门调查的，人民法院不应指定该社会中介机构或者个人为本案管理人。
