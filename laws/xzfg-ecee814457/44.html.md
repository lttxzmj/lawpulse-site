# 武器装备质量管理条例第四十四条

- 法规：武器装备质量管理条例（现行有效）
- 章节：第四章维修质量管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ecee814457/44.html

武器装备研制、生产和维修单位发现武器装备存在质量缺陷的，应当及时、主动通报军队有关装备部门及有关单位，采取纠正措施，解决武器装备质量问题，防止类似质量缺陷重复发生。
