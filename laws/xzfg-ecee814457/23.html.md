# 武器装备质量管理条例第二十三条

- 法规：武器装备质量管理条例（现行有效）
- 章节：第三章研制、生产与试验质量管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ecee814457/23.html

武器装备研制、生产单位应当对武器装备的研制、生产过程严格实施技术状态管理。更改技术状态应当按照规定履行审批手续；对可能影响武器装备性能和合同要求的技术状态的更改，应当充分论证和验证，并经原审批部门批准。
