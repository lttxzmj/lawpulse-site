# 武器装备质量管理条例第二十八条

- 法规：武器装备质量管理条例（现行有效）
- 章节：第三章研制、生产与试验质量管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ecee814457/28.html

武器装备研制、生产和试验单位应当建立故障的报告、分析和纠正措施系统。对武器装备研制、生产和试验过程中出现的故障，应当及时采取纠正和预防措施。
