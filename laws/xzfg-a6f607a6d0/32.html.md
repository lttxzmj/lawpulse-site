# 农业机械安全监督管理条例第三十二条

- 法规：农业机械安全监督管理条例（现行有效）
- 章节：第五章服务与监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a6f607a6d0/32.html

联合收割机跨行政区域作业前，当地县级人民政府农业机械化主管部门应当会同有关部门，对跨行政区域作业的联合收割机进行必要的安全检查，并对操作人员进行安全教育。
