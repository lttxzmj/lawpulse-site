# 中华人民共和国车船税法实施条例第三条

- 法规：中华人民共和国车船税法实施条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0408f5e309/3.html

省、自治区、直辖市人民政府根据车船税法所附《车船税税目税额表》确定车辆具体适用税额，应当遵循以下原则：
(一)乘用车依排气量从小到大递增税额；
(二)客车按照核定载客人数20人以下和20人(含)以上两档划分，递增税额。
省、自治区、直辖市人民政府确定的车辆具体适用税额，应当报国务院备案。
