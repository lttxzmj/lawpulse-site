# 最高人民法院关于人民法院司法拍卖房产竞买人资格若干问题的规定第三条

- 法规：最高人民法院关于人民法院司法拍卖房产竞买人资格若干问题的规定（现行有效，施行日期 2022-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-340b2995f3/3.html

人民法院在司法拍卖房产成交后、向买受人出具成交裁定书前，应当审核买受人提交的自其申请参与竞拍到成交裁定书出具时具备购房资格的证明材料；经审核买受人不符合持续具备购房资格条件，买受人请求出具拍卖成交裁定书的，人民法院不予准许。
