# 直销管理条例第三十七条

- 法规：直销管理条例（现行有效）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6ab68bea88/37.html

工商行政管理部门应当设立并公布举报电话，接受对违反本条例行为的举报和投诉，并及时进行调查处理。
工商行政管理部门应当为举报人保密；对举报有功人员，应当依照国家有关规定给予奖励。
