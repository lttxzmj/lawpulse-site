# 直销管理条例第二十八条

- 法规：直销管理条例（现行有效）
- 章节：第四章直销活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6ab68bea88/28.html

直销企业应当依照国务院商务主管部门和国务院工商行政管理部门的规定，建立并实行完备的信息报备和披露制度。
直销企业信息报备和披露的内容、方式及相关要求，由国务院商务主管部门和国务院工商行政管理部门另行规定。
