# 直销管理条例第三条

- 法规：直销管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6ab68bea88/3.html

本条例所称直销，是指直销企业招募直销员，由直销员在固定营业场所之外直接向最终消费者(以下简称消费者)推销产品的经销方式。
本条例所称直销企业，是指依照本条例规定经批准采取直销方式销售产品的企业。
本条例所称直销员，是指在固定营业场所之外将产品直接推销给消费者的人员。
