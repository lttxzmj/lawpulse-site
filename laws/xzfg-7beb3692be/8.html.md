# 中华人民共和国考古涉外工作管理办法第八条

- 法规：中华人民共和国考古涉外工作管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7beb3692be/8.html

申请合作考古调查、勘探、发掘的项目应当同时具备下列条件：
(一)有利于促进中国文物保护和考古学研究，有利于促进国际文化学术交流；
(二)中方已有一定的工作基础和研究成果，有从事该课题方向研究的专家；
(三)外方应当是专业考古研究机构，有从事该课题方向或者相近方向研究的专家，并具有一定的实际考古工作经历；
(四)有可靠的措施使发掘后的文物得到保护。
