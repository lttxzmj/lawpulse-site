# 查检邮件中夹带外币或外币票据暂行处理办法第十一条

- 法规：查检邮件中夹带外币或外币票据暂行处理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a08a67b2b4/11.html

凡无中国银行或人民银行机构设立之边远或乡村地区，其持有外币或外币票据拟寄递至附近地区中国银行或人民银行存兑者，经当地区级以上政府证明后，可不受本办法第四条及第五条条文之限制。
