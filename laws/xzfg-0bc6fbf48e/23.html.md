# 土地复垦条例第二十三条

- 法规：土地复垦条例（现行有效）
- 章节：第三章历史遗留损毁土地和自然灾害损毁土地的复垦
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0bc6fbf48e/23.html

对历史遗留损毁土地和自然灾害损毁土地，县级以上人民政府应当投入资金进行复垦，或者按照“谁投资，谁受益”的原则，吸引社会投资进行复垦。土地权利人明确的，可以采取扶持、优惠措施，鼓励土地权利人自行复垦。
