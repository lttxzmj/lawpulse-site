# 无障碍环境建设条例第三十三条

- 法规：无障碍环境建设条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6d48a2f5a1/33.html

无障碍设施的所有权人或者管理人对无障碍设施未进行保护或者及时维修，导致无法正常使用的，由有关主管部门责令限期维修；造成使用人人身、财产损害的，无障碍设施的所有权人或者管理人应当承担赔偿责任。
