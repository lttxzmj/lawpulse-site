# 国务院实施《中华人民共和国民族区域自治法》若干规定第二十八条

- 法规：国务院实施《中华人民共和国民族区域自治法》若干规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-37a8180c17/28.html

上级人民政府及其工作部门领导人员中应当合理配备少数民族干部；民族自治地方人民政府及其工作部门应当依法配备实行区域自治的民族和其他民族领导干部，在公开选拔、竞争上岗配备领导干部时，可以划出相应的名额和岗位，定向选拔少数民族干部。
民族自治地方录用、聘用国家工作人员时，对实行区域自治的民族和其他少数民族予以照顾，具体办法由录用、聘用主管部门规定。
