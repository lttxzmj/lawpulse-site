# 国务院实施《中华人民共和国民族区域自治法》若干规定第三条

- 法规：国务院实施《中华人民共和国民族区域自治法》若干规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-37a8180c17/3.html

维护祖国统一和民族团结是公民的职责和义务。
民族自治地方人民政府应当切实保障宪法和法律在本地方的遵守和执行，积极维护国家的整体利益。
