# 护士条例第二十七条

- 法规：护士条例（现行有效，施行日期 2020-03-27）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c29be2fbb5/27.html

卫生主管部门的工作人员未依照本条例规定履行职责，在护士监督管理工作中滥用职权、徇私舞弊，或者有其他失职、渎职行为的，依法给予处分；构成犯罪的，依法追究刑事责任。
