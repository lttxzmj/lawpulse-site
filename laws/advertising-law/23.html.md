# 中华人民共和国广告法第二十三条

- 法规：中华人民共和国广告法（现行有效，施行日期 2021-04-29）
- 章节：第二章广告内容准则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/advertising-law/23.html

酒类广告不得含有下列内容：
（一）诱导、怂恿饮酒或者宣传无节制饮酒；
（二）出现饮酒的动作；
（三）表现驾驶车、船、飞机等活动；
（四）明示或者暗示饮酒有消除紧张和焦虑、增加体力等功效。
