# 最高人民法院关于适用《中华人民共和国行政诉讼法》的解释第七十二条

- 法规：最高人民法院关于适用《中华人民共和国行政诉讼法》的解释（现行有效，施行日期 2018-02-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-48ccf9c396/72.html

有下列情形之一的，可以延期开庭审理：
（一）应当到庭的当事人和其他诉讼参与人有正当理由没有到庭的；
（二）当事人临时提出回避申请且无法及时作出决定的；
（三）需要通知新的证人到庭，调取新的证据，重新鉴定、勘验，或者需要补充调查的；
（四）其他应当延期的情形。
