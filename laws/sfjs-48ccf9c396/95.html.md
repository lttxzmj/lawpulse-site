# 最高人民法院关于适用《中华人民共和国行政诉讼法》的解释第九十五条

- 法规：最高人民法院关于适用《中华人民共和国行政诉讼法》的解释（现行有效，施行日期 2018-02-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-48ccf9c396/95.html

人民法院经审理认为被诉行政行为违法或者无效，可能给原告造成损失，经释明，原告请求一并解决行政赔偿争议的，人民法院可以就赔偿事项进行调解；调解不成的，应当一并判决。人民法院也可以告知其就赔偿事项另行提起诉讼。
