# 最高人民法院关于适用《中华人民共和国行政诉讼法》的解释第八十二条

- 法规：最高人民法院关于适用《中华人民共和国行政诉讼法》的解释（现行有效，施行日期 2018-02-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-48ccf9c396/82.html

当事人之间恶意串通，企图通过诉讼等方式侵害国家利益、社会公共利益或者他人合法权益的，人民法院应当裁定驳回起诉或者判决驳回其请求，并根据情节轻重予以罚款、拘留；构成犯罪的，依法追究刑事责任。
