# 最高人民法院关于适用《中华人民共和国行政诉讼法》的解释第二十八条

- 法规：最高人民法院关于适用《中华人民共和国行政诉讼法》的解释（现行有效，施行日期 2018-02-08）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-48ccf9c396/28.html

人民法院追加共同诉讼的当事人时，应当通知其他当事人。应当追加的原告，已明确表示放弃实体权利的，可不予追加；既不愿意参加诉讼，又不放弃实体权利的，应追加为第三人，其不参加诉讼，不能阻碍人民法院对案件的审理和裁判。
