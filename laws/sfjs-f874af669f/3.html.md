# 最高人民法院关于审理涉执行司法赔偿案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理涉执行司法赔偿案件适用法律若干问题的解释（现行有效，施行日期 2022-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f874af669f/3.html

原债权人转让债权的，其基于债权申请国家赔偿的权利随之转移，但根据债权性质、当事人约定或者法律规定不得转让的除外。
