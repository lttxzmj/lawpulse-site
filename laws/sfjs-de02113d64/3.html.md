# 最高人民法院、最高人民检察院关于办理渎职刑事案件适用法律若干问题的解释（一）第三条

- 法规：最高人民法院、最高人民检察院关于办理渎职刑事案件适用法律若干问题的解释（一）（现行有效，施行日期 2013-01-09）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-de02113d64/3.html

国家机关工作人员实施渎职犯罪并收受贿赂，同时构成受贿罪的，除刑法另有规定外，以渎职犯罪和受贿罪数罪并罚。
