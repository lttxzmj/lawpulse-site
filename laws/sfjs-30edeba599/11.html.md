# 最高人民法院、最高人民检察院关于办理拒不执行判决、裁定刑事案件适用法律若干问题的解释第十一条

- 法规：最高人民法院、最高人民检察院关于办理拒不执行判决、裁定刑事案件适用法律若干问题的解释（现行有效，施行日期 2024-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-30edeba599/11.html

实施刑法第三百一十三条规定的拒不执行判决、裁定行为，情节显著轻微危害不大的，不认为是犯罪；在提起公诉前，履行全部或者部分执行义务，犯罪情节轻微的，可以依法不起诉。在一审宣告判决前，履行全部或者部分执行义务，犯罪情节轻微的，可以依法从轻或者免除处罚。
