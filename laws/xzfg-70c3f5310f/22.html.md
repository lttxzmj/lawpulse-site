# 幼儿园管理条例第二十二条

- 法规：幼儿园管理条例（现行有效）
- 章节：第四章幼儿园的行政事务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70c3f5310f/22.html

各级教育行政部门应当负责监督、评估和指导幼儿园的保育、教育工作，组织培训幼儿园的师资，审定、考核幼儿园教师的资格，并协助卫生行政部门检查和指导幼儿园的卫生保健工作，会同建设行政部门制定幼儿园园舍、设施的标准。
