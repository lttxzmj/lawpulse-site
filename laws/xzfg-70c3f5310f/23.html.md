# 幼儿园管理条例第二十三条

- 法规：幼儿园管理条例（现行有效）
- 章节：第四章幼儿园的行政事务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70c3f5310f/23.html

幼儿园园长负责幼儿园的工作。
幼儿园园长由举办幼儿园的单位或个人聘任，并向幼儿园的登记注册机关备案。
幼儿园的教师、医师、保健员、保育员和其他工作人员，由幼儿园园长聘任，也可由举办幼儿园的单位或个人聘任。
