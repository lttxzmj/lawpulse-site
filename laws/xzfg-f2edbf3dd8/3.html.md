# 古生物化石保护条例第三条

- 法规：古生物化石保护条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2edbf3dd8/3.html

中华人民共和国领域和中华人民共和国管辖的其他海域遗存的古生物化石属于国家所有。
国有的博物馆、科学研究单位、高等院校和其他收藏单位收藏的古生物化石，以及单位和个人捐赠给国家的古生物化石属于国家所有，不因其收藏单位的终止或者变更而改变其所有权。
