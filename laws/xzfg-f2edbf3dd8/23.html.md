# 古生物化石保护条例第二十三条

- 法规：古生物化石保护条例（现行有效）
- 章节：第三章古生物化石收藏
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2edbf3dd8/23.html

国有收藏单位不得将其收藏的重点保护古生物化石转让、交换、赠与给非国有收藏单位或者个人。
任何单位和个人不得将其收藏的重点保护古生物化石转让、交换、赠与、质押给外国人或者外国组织。
