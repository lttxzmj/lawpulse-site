# 防治船舶污染海洋环境管理条例第六十二条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/62.html

违反本条例的规定，有下列情形之一的，由海事管理机构处2000元以上1万元以下的罚款：
(一)船舶未按照规定保存污染物接收单证的；
(二)船舶燃油供给单位未如实填写燃油供受单证的；
(三)船舶燃油供给单位未按照规定向船舶提供燃油供受单证和燃油样品的；
(四)船舶和船舶燃油供给单位未按照规定保存燃油供受单证和燃油样品的。
