# 防治船舶污染海洋环境管理条例第六十六条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/66.html

违反本条例的规定，有下列情形之一的，由海事管理机构处1万元以上5万元以下的罚款：
(一)载运散装液体污染危害性货物的船舶和1万总吨以上的其他船舶，其经营人未按照规定签订污染清除作业协议的；
(二)污染清除作业单位不符合国家有关技术规范从事污染清除作业的。
