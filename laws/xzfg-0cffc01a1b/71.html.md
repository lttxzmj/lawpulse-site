# 防治船舶污染海洋环境管理条例第七十一条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/71.html

违反本条例的规定，船舶所有人有下列情形之一的，由海事管理机构责令改正，可以处5万元以下的罚款；拒不改正的，处5万元以上25万元以下的罚款：
(一)在中华人民共和国管辖海域内航行的船舶，其所有人未按照规定投保船舶油污损害民事责任保险或者取得相应的财务担保的；
(二)船舶所有人投保船舶油污损害民事责任保险或者取得的财务担保的额度低于《中华人民共和国海商法》、中华人民共和国缔结或者参加的有关国际条约规定的油污赔偿限额的。
