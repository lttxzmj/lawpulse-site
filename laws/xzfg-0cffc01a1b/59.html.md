# 防治船舶污染海洋环境管理条例第五十九条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/59.html

违反本条例的规定，船舶未按照规定在船舶上留存船舶污染物处置记录，或者船舶污染物处置记录与船舶运行过程中产生的污染物数量不符合的，由海事管理机构处2万元以上10万元以下的罚款。
