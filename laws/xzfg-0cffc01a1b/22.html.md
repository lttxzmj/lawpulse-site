# 防治船舶污染海洋环境管理条例第二十二条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第四章船舶有关作业活动的污染防治
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/22.html

载运污染危害性货物进出港口的船舶，其承运人、货物所有人或者代理人，应当向海事管理机构提出申请，经批准方可进出港口或者过境停留。
