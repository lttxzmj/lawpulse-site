# 防治船舶污染海洋环境管理条例第五十七条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/57.html

违反本条例的规定，船舶的结构不符合国家有关防治船舶污染海洋环境的技术规范或者有关国际条约要求的，由海事管理机构处10万元以上30万元以下的罚款。
