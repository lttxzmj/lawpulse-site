# 防治船舶污染海洋环境管理条例第五十八条

- 法规：防治船舶污染海洋环境管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0cffc01a1b/58.html

违反本条例的规定，有下列情形之一的，由海事管理机构依照《中华人民共和国海洋环境保护法》有关规定予以处罚：
(一)船舶未取得并随船携带防治船舶污染海洋环境的证书、文书的；
(二)船舶、港口、码头、装卸站未配备防治污染设备、器材的；
(三)船舶向海域排放本条例禁止排放的污染物的；
(四)船舶未如实记录污染物处置情况的；
(五)船舶超过标准向海域排放污染物的；
(六)从事船舶水上拆解作业，造成海洋环境污染损害的。
