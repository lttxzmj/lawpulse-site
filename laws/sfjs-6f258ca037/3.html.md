# 最高人民法院关于审理涉及公证活动相关民事案件的若干规定第三条

- 法规：最高人民法院关于审理涉及公证活动相关民事案件的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-6f258ca037/3.html

当事人、公证事项的利害关系人对公证书所公证的民事权利义务有争议的，可以依照公证法第四十条规定就该争议向人民法院提起民事诉讼。
当事人、公证事项的利害关系人对具有强制执行效力的公证债权文书的民事权利义务有争议直接向人民法院提起民事诉讼的，人民法院依法不予受理。但是，公证债权文书被人民法院裁定不予执行的除外。
