# 外国企业常驻代表机构登记管理条例第三十四条

- 法规：外国企业常驻代表机构登记管理条例（现行有效，施行日期 2024-05-01）
- 章节：第五章注销登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e8b325272f/34.html

登记机关应当自受理申请之日起10日内作出是否准予注销登记的决定。作出准予注销决定的，应当自作出决定之日起5日内出具准予注销通知书，收缴登记证和代表证；作出不予注销登记决定的，应当自作出决定之日起5日内向申请人出具注销登记驳回通知书，说明不予注销登记的理由。
