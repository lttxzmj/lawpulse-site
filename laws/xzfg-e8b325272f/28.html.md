# 外国企业常驻代表机构登记管理条例第二十八条

- 法规：外国企业常驻代表机构登记管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章变更登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e8b325272f/28.html

代表机构驻在期限届满后继续从事业务活动的，外国企业应当在驻在期限届满前60日内向登记机关申请变更登记。
