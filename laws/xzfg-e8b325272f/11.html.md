# 外国企业常驻代表机构登记管理条例第十一条

- 法规：外国企业常驻代表机构登记管理条例（现行有效，施行日期 2024-05-01）
- 章节：第二章登记事项
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e8b325272f/11.html

外国企业应当委派一名首席代表。首席代表在外国企业书面授权范围内，可以代表外国企业签署代表机构登记申请文件。
外国企业可以根据业务需要，委派1至3名代表。
