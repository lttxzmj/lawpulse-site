# 外国企业常驻代表机构登记管理条例第七条

- 法规：外国企业常驻代表机构登记管理条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e8b325272f/7.html

代表机构应当依法设置会计账簿，真实记载外国企业经费拨付和代表机构费用收支情况，并置于代表机构驻在场所。
代表机构不得使用其他企业、组织或者个人的账户。
