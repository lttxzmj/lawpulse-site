# 外国企业常驻代表机构登记管理条例第二十一条

- 法规：外国企业常驻代表机构登记管理条例（现行有效，施行日期 2024-05-01）
- 章节：第二章登记事项
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e8b325272f/21.html

登记机关对代表机构涉嫌违反本条例的行为进行查处，可以依法行使下列职权：
（一）向有关的单位和个人调查、了解情况；
（二）查阅、复制、查封、扣押与违法行为有关的合同、票据、账簿以及其他资料；
（三）查封、扣押专门用于从事违法行为的工具、设备、原材料、产品（商品）等财物；
（四）查询从事违法行为的代表机构的账户以及与存款有关的会计凭证、账簿、对账单等。
