# 人民法院在线调解规则第二十八条

- 法规：人民法院在线调解规则（现行有效，施行日期 2022-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-bd836aa652/28.html

人民法院可以建立婚姻家庭、劳动争议、道路交通、金融消费、证券期货、知识产权、海事海商、国际商事和涉港澳台侨纠纷等专业行业特邀调解名册，按照不同专业邀请具备相关专业能力的组织和人员加入。
最高人民法院建立全国性特邀调解名册，邀请全国人大代表、全国政协委员、知名专家学者、具有较高知名度的调解组织以及较强调解能力的人员加入，参与调解全国法院有重大影响、疑难复杂、适宜调解的案件。
高级人民法院、中级人民法院可以建立区域性特邀调解名册，参与本辖区法院案件的调解。
