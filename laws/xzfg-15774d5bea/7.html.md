# 关于工资总额组成的规定第七条

- 法规：关于工资总额组成的规定（现行有效）
- 章节：第二章工资总额的组成
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-15774d5bea/7.html

奖金是指支付给职工的超额劳动报酬和增收节支的劳动报酬。包括：
(一)生产奖；
(二)节约奖；
(三)劳动竞赛奖；
(四)机关、事业单位的奖励工资；
(五)其他奖金。
