# 中国公民因私事往来香港地区或者澳门地区的暂行管理办法第三条

- 法规：中国公民因私事往来香港地区或者澳门地区的暂行管理办法（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c31c0ddbc/3.html

内地公民因私事前往香港、澳门，凭我国公安机关签发的前往港澳通行证或者往来港澳通行证从指定的口岸通行；返回内地也可以从其他对外开放的口岸通行。
指定的口岸：往香港是深圳，往澳门是拱北。
