# 中国公民因私事往来香港地区或者澳门地区的暂行管理办法第二十三条

- 法规：中国公民因私事往来香港地区或者澳门地区的暂行管理办法（现行有效）
- 章节：第五章证件管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c31c0ddbc/23.html

港澳同胞来内地后遗失港澳同胞回乡证，应向遗失地的市、县或者交通运输部门的公安机关报失，经公安机关调查属实，出具证明，由公安机关出入境管理部门签发一次有效的入出境通行证，凭证返回香港、澳门。港澳同胞无论在香港、澳门或者内地遗失港澳同胞回乡证，均可以按照本办法第十四条规定重新申请领取港澳同胞回乡证。
