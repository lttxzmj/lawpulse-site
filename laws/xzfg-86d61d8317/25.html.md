# 中华人民共和国人类遗传资源管理条例第二十五条

- 法规：中华人民共和国人类遗传资源管理条例（现行有效，施行日期 2024-05-01）
- 章节：第三章利用和对外提供
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-86d61d8317/25.html

利用我国人类遗传资源开展国际合作科学研究，合作双方应当按照平等互利、诚实信用、共同参与、共享成果的原则，依法签订合作协议，并依照本条例第二十四条的规定对相关事项作出明确、具体的约定。
