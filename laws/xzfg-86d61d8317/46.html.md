# 中华人民共和国人类遗传资源管理条例第四十六条

- 法规：中华人民共和国人类遗传资源管理条例（现行有效，施行日期 2024-05-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-86d61d8317/46.html

人类遗传资源相关信息属于国家秘密的，应当依照《中华人民共和国保守国家秘密法》和国家其他有关保密规定实施保密管理。
