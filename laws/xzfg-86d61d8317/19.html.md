# 中华人民共和国人类遗传资源管理条例第十九条

- 法规：中华人民共和国人类遗传资源管理条例（现行有效，施行日期 2024-05-01）
- 章节：第三章利用和对外提供
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-86d61d8317/19.html

国家鼓励科研机构、高等学校、医疗机构、企业根据自身条件和相关研究开发活动需要，利用我国人类遗传资源开展国际合作科学研究，提升相关研究开发能力和水平。
