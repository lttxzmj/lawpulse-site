# 中华人民共和国人类遗传资源管理条例第三条

- 法规：中华人民共和国人类遗传资源管理条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-86d61d8317/3.html

采集、保藏、利用、对外提供我国人类遗传资源，应当遵守本条例。
为临床诊疗、采供血服务、查处违法犯罪、兴奋剂检测和殡葬等活动需要，采集、保藏器官、组织、细胞等人体物质及开展相关活动，依照相关法律、行政法规规定执行。
