# 人体器官捐献和移植条例第八条

- 法规：人体器官捐献和移植条例（现行有效，施行日期 2024-05-01）
- 章节：第二章人体器官的捐献
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-df8cc33003/8.html

人体器官捐献应当遵循自愿、无偿的原则。
公民享有捐献或者不捐献其人体器官的权利；任何组织或者个人不得强迫、欺骗或者利诱他人捐献人体器官。
