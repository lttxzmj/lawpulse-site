# 人体器官捐献和移植条例第四十五条

- 法规：人体器官捐献和移植条例（现行有效，施行日期 2024-05-01）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-df8cc33003/45.html

人体器官捐献协调员、医疗机构及其工作人员违反本条例规定，泄露人体器官捐献人、接受人或者申请人体器官移植手术患者个人信息的，依照法律、行政法规关于个人信息保护的规定予以处罚；构成犯罪的，依法追究刑事责任。
