# 人体器官捐献和移植条例第三条

- 法规：人体器官捐献和移植条例（现行有效，施行日期 2024-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-df8cc33003/3.html

人体器官捐献和移植工作坚持人民至上、生命至上。国家建立人体器官捐献和移植工作体系，推动人体器官捐献，规范人体器官获取和分配，提升人体器官移植服务能力，加强监督管理。
