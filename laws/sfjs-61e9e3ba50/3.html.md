# 最高人民法院关于刑事裁判涉财产部分执行的若干规定第三条

- 法规：最高人民法院关于刑事裁判涉财产部分执行的若干规定（现行有效，施行日期 2014-11-06）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-61e9e3ba50/3.html

人民法院办理刑事裁判涉财产部分执行案件的期限为六个月。有特殊情况需要延长的，经本院院长批准，可以延长。
