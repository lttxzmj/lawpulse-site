# 中华人民共和国民营经济促进法第五十条

- 法规：中华人民共和国民营经济促进法（现行有效，施行日期 2025-05-20）
- 章节：第六章服务保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-2a1ac04584/50.html

行政机关坚持依法行政。行政机关开展执法活动应当避免或者尽量减少对民营经济组织正常生产经营活动的影响，并对其合理、合法诉求及时响应、处置。
