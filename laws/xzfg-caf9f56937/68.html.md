# 使用有毒物品作业场所劳动保护条例第六十八条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第七章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/68.html

用人单位违反本条例的规定，有下列行为之一的，由疾病预防控制部门给予警告，责令限期改正，处5000元以上2万元以下的罚款；逾期不改正的，责令停止使用有毒物品作业，或者提请有关人民政府按照国务院规定的权限予以关闭：
（一）未按照规定配备或者聘请职业卫生医师和护士的；
（二）未为从事使用高毒物品作业的劳动者设置淋浴间、更衣室或者未设置清洗、存放和处理工作服、工作鞋帽等物品的专用间，或者不能正常使用的；
（三）未安排从事使用高毒物品作业一定年限的劳动者进行岗位轮换的。
