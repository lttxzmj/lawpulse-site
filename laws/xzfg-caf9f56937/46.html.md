# 使用有毒物品作业场所劳动保护条例第四十六条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第五章劳动者的权利与义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/46.html

劳动者应当学习和掌握相关职业卫生知识，遵守有关劳动保护的法律、法规和操作规程，正确使用和维护职业中毒危害防护设施及其用品；发现职业中毒事故隐患时，应当及时报告。
作业场所出现使用有毒物品产生的危险时，劳动者应当采取必要措施，按照规定正确使用防护设施，将危险加以消除或者减少到最低限度。
