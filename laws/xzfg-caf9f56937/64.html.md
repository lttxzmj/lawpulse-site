# 使用有毒物品作业场所劳动保护条例第六十四条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第七章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/64.html

从事使用有毒物品作业的用人单位违反本条例的规定，在转产、停产、停业或者解散、破产时未采取有效措施，妥善处理留存或者残留高毒物品的设备、包装物和容器的，由疾病预防控制部门责令改正，处2万元以上10万元以下的罚款；触犯刑律的，对负有责任的主管人员和其他直接责任人员依照刑法关于污染环境罪、危险物品肇事罪或者其他罪的规定，依法追究刑事责任。
