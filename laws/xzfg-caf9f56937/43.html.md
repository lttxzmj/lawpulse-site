# 使用有毒物品作业场所劳动保护条例第四十三条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第五章劳动者的权利与义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/43.html

用人单位无营业执照以及被依法吊销营业执照，其劳动者从事使用有毒物品作业患职业病的，应当按照国家有关工伤保险规定的项目和标准，给予劳动者一次性赔偿。
