# 使用有毒物品作业场所劳动保护条例第五十一条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/51.html

职业卫生监督执法人员依法执行职务时，应当出示执法证件。
职业卫生监督执法人员应当忠于职守，秉公执法；涉及用人单位秘密的，应当为其保密。
