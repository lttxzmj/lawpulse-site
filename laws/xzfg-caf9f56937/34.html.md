# 使用有毒物品作业场所劳动保护条例第三十四条

- 法规：使用有毒物品作业场所劳动保护条例（现行有效，施行日期 2025-01-20）
- 章节：第四章职业健康监护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caf9f56937/34.html
