# 生态环境监测条例第二十三条

- 法规：生态环境监测条例（现行有效，施行日期 2026-08-15）
- 章节：第三章自行监测
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-05573644b5/23.html

依照法律、法规规定应当安装、使用自动监测设备的企事业单位，其自动监测设备应当与生态环境主管部门联网。
企事业单位发现自动监测设备传输数据异常的，应当及时报告生态环境主管部门，并对自动监测设备进行检查、修复。
