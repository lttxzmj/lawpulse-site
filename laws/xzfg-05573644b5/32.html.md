# 生态环境监测条例第三十二条

- 法规：生态环境监测条例（现行有效，施行日期 2026-08-15）
- 章节：第四章技术服务机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-05573644b5/32.html

接受委托开展监测服务的技术服务机构应当建立监测数据质量管理制度，不得以任何方式对监测数据弄虚作假。
本条例第二十五条的规定，适用于接受委托开展监测服务的技术服务机构。
技术服务机构及其负责人对技术服务机构出具的监测数据的真实性、准确性负责。
