# 生态环境监测条例第二十六条

- 法规：生态环境监测条例（现行有效，施行日期 2026-08-15）
- 章节：第三章自行监测
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-05573644b5/26.html

企事业单位应当依照法律、法规规定的期限保存自行监测的原始监测记录；法律、法规没有规定保存期限的，原始监测记录至少保存5年。
企事业单位应当依法公开自行监测相关信息，接受社会监督。
