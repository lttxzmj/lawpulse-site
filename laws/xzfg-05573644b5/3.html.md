# 生态环境监测条例第三条

- 法规：生态环境监测条例（现行有效，施行日期 2026-08-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-05573644b5/3.html

生态环境监测工作应当贯彻党和国家路线方针政策、决策部署，坚持依法监测、科学监测、诚信监测，构建政府主导、部门协同、企事业单位履责、社会参与、公众监督的机制。
