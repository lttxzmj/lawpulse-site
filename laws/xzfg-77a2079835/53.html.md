# 广播电视管理条例第五十三条

- 法规：广播电视管理条例（现行有效，施行日期 2025-01-20）
- 章节：第五章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-77a2079835/53.html

广播电视行政部门及其工作人员在广播电视管理工作中滥用职权、玩忽职守、徇私舞弊，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予行政处分。
