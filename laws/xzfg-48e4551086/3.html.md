# 行政区划管理条例第三条

- 法规：行政区划管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-48e4551086/3.html

行政区划的设立、撤销以及变更隶属关系或者行政区域界线时，应当考虑经济发展、资源环境、人文历史、地形地貌、治理能力等情况；变更人民政府驻地时，应当优化资源配置、便于提供公共服务；变更行政区划名称时，应当体现当地历史、文化和地理特征。
