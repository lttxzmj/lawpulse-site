# 最高人民法院关于审理执行异议之诉案件适用法律问题的解释第三条

- 法规：最高人民法院关于审理执行异议之诉案件适用法律问题的解释（现行有效，施行日期 2025-07-24）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-67298c63dd/3.html

案外人就执行标的享有足以排除强制执行的民事权益，人民法院判决不得执行该执行标的的，应同时判决解除执行措施并写明相关查封、扣押、冻结裁定书案号。案外人可以持生效判决请求相关执行法院解除执行措施。
