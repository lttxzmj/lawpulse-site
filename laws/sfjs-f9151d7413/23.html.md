# 最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释第二十三条

- 法规：最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f9151d7413/23.html

2025年7月1日《中华人民共和国矿产资源法》施行前的法律事实引起的矿产资源纠纷案件，适用当时的法律、司法解释的规定，但是法律另有规定的除外。
本解释自2026年2月1日起施行。《最高人民法院关于审理矿业权纠纷案件适用法律若干问题的解释》（法释〔2017〕12号）同时废止。
