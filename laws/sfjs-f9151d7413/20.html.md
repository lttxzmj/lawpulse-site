# 最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释第二十条

- 法规：最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f9151d7413/20.html

矿业权在期限届满前因公共利益的需要被依法收回，矿业权人请求作出收回决定的行政机关给予补偿的，人民法院应予支持。
矿业权在期限届满前因不符合管控要求依法退出自然保护地，矿业权人请求作出退出决定的行政机关给予补偿的，人民法院应予支持。
