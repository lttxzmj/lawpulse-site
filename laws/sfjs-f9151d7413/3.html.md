# 最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理矿产资源纠纷案件适用法律若干问题的解释（现行有效，施行日期 2026-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f9151d7413/3.html

当事人订立合同对未设置矿业权的矿产资源实施勘查、开采，违反矿产资源法第四条第二款规定的，人民法院应当认定合同无效。
以将来取得的矿业权进行合作勘查、开采或者转让的合同，当事人仅以合作人或者转让人在订立合同时未取得矿业权为由主张合同无效的，人民法院不予支持。
