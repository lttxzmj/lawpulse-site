# 最高人民法院关于人民法院办理海峡两岸送达文书和调查取证司法互助案件的规定第二十八条

- 法规：最高人民法院关于人民法院办理海峡两岸送达文书和调查取证司法互助案件的规定（现行有效，施行日期 2011-06-25）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-6a8b713c14/28.html

最高人民法院审理的案件需要请求台湾地区协助送达司法文书和调查取证的，参照本规定由本院自行办理。
专门人民法院办理海峡两岸送达文书和调查取证司法互助业务，参照本规定执行。
