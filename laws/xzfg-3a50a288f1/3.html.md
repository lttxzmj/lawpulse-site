# 互联网信息服务管理办法第三条

- 法规：互联网信息服务管理办法（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a50a288f1/3.html

互联网信息服务分为经营性和非经营性两类。
经营性互联网信息服务，是指通过互联网向上网用户有偿提供信息或者网页制作等服务活动。
非经营性互联网信息服务，是指通过互联网向上网用户无偿提供具有公开性、共享性信息的服务活动。
