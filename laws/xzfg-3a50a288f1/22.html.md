# 互联网信息服务管理办法第二十二条

- 法规：互联网信息服务管理办法（现行有效，施行日期 2025-01-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3a50a288f1/22.html

违反本办法的规定，未在其网站主页上标明其经营许可证编号或者备案编号的，由省、自治区、直辖市电信管理机构责令改正，处5000元以上5万元以下的罚款。
