# 中央储备粮管理条例第四十四条

- 法规：中央储备粮管理条例（现行有效）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-65f1fa8229/44.html

国家粮食行政管理部门、国务院财政部门的监督检查人员应当将监督检查情况作出书面记录，并由监督检查人员和被检查单位的负责人签字。被检查单位的负责人拒绝签字的，监督检查人员应当将有关情况记录在案。
