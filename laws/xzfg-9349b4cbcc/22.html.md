# 中华人民共和国对外合作开采海洋石油资源条例第二十二条

- 法规：中华人民共和国对外合作开采海洋石油资源条例（现行有效）
- 章节：第三章石油作业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9349b4cbcc/22.html

作业者和承包者在实施石油作业中，应当遵守中华人民共和国有关环境保护和安全方面的法律规定，并参照国际惯例进行作业，保护渔业资源和其他自然资源，防止对大气、海洋、河流、湖泊和陆地等环境的污染和损害。
