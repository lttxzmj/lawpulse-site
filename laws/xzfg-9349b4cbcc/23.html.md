# 中华人民共和国对外合作开采海洋石油资源条例第二十三条

- 法规：中华人民共和国对外合作开采海洋石油资源条例（现行有效）
- 章节：第三章石油作业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9349b4cbcc/23.html

石油合同区产出的石油，应当在中华人民共和国登陆，也可以在海上油(气)外输计量点运出。如需在中华人民共和国以外的地点登陆，必须经国务院指定的部门批准。
