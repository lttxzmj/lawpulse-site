# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）第二十条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-gongsifa-3/20.html
