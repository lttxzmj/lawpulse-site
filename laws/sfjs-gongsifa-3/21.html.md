# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）第二十一条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-gongsifa-3/21.html

当事人向人民法院起诉请求确认其股东资格的，应当以公司为被告，与案件争议股权有利害关系的人作为第三人参加诉讼。
