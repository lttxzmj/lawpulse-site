# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）第十六条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-gongsifa-3/16.html

股东未履行或者未全面履行出资义务或者抽逃出资，公司根据公司章程或者股东会决议对其利润分配请求权、新股优先认购权、剩余财产分配请求权等股东权利作出相应的合理限制，该股东请求认定该限制无效的，人民法院不予支持。
