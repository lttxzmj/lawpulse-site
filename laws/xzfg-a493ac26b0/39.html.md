# 中华人民共和国政府信息公开条例第三十九条

- 法规：中华人民共和国政府信息公开条例（现行有效，施行日期 2019-05-15）
- 章节：第四章依申请公开
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a493ac26b0/39.html

申请人以政府信息公开申请的形式进行信访、投诉、举报等活动，行政机关应当告知申请人不作为政府信息公开申请处理并可以告知通过相应渠道提出。
申请人提出的申请内容为要求行政机关提供政府公报、报刊、书籍等公开出版物的，行政机关可以告知获取的途径。
