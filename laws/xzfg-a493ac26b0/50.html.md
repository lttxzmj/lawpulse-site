# 中华人民共和国政府信息公开条例第五十条

- 法规：中华人民共和国政府信息公开条例（现行有效，施行日期 2019-05-15）
- 章节：第五章监督和保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a493ac26b0/50.html

政府信息公开工作年度报告应当包括下列内容：
(一)行政机关主动公开政府信息的情况；
(二)行政机关收到和处理政府信息公开申请的情况；
(三)因政府信息公开工作被申请行政复议、提起行政诉讼的情况；
(四)政府信息公开工作存在的主要问题及改进情况，各级人民政府的政府信息公开工作年度报告还应当包括工作考核、社会评议和责任追究结果情况；
(五)其他需要报告的事项。
全国政府信息公开工作主管部门应当公布政府信息公开工作年度报告统一格式，并适时更新。
