# 中华人民共和国政府信息公开条例第五十一条

- 法规：中华人民共和国政府信息公开条例（现行有效，施行日期 2019-05-15）
- 章节：第五章监督和保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a493ac26b0/51.html

公民、法人或者其他组织认为行政机关在政府信息公开工作中侵犯其合法权益的，可以向上一级行政机关或者政府信息公开工作主管部门投诉、举报，也可以依法申请行政复议或者提起行政诉讼。
