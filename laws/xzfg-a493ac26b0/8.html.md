# 中华人民共和国政府信息公开条例第八条

- 法规：中华人民共和国政府信息公开条例（现行有效，施行日期 2019-05-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a493ac26b0/8.html

各级人民政府应当加强政府信息资源的规范化、标准化、信息化管理，加强互联网政府信息公开平台建设，推进政府信息公开平台与政务服务平台融合，提高政府信息公开在线办理水平。
