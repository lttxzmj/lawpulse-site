# 中华人民共和国政府信息公开条例第二十三条

- 法规：中华人民共和国政府信息公开条例（现行有效，施行日期 2019-05-15）
- 章节：第三章主动公开
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a493ac26b0/23.html

行政机关应当建立健全政府信息发布机制，将主动公开的政府信息通过政府公报、政府网站或者其他互联网政务媒体、新闻发布会以及报刊、广播、电视等途径予以公开。
