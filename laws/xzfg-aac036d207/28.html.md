# 科学技术档案工作条例第二十八条

- 法规：科学技术档案工作条例（现行有效）
- 章节：第四章科技档案工作管理体制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-aac036d207/28.html

国务院所属的各专业主管机关，根据需要建立专业档案馆，收集和保管本专业需要长期和永久保存的科技档案。
大中城市应当建立城市基本建设档案馆，收集和保管本城市应当长期和永久保存的基本建设档案。
专业档案馆和城市基本建设档案馆是科学技术事业单位。
