# 地名管理条例第三十四条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/34.html

县级以上地方人民政府地名批准机关违反本条例规定进行地名命名、更名的，由其上一级行政机关责令改正，对该批准机关负有责任的领导人员和其他直接责任人员依法给予处分。
