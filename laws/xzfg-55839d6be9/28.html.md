# 地名管理条例第二十八条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/28.html

上级人民政府地名行政主管部门应当加强对下级人民政府地名行政主管部门地名管理工作的指导、监督。上级人民政府其他有关部门应当加强对下级人民政府相应部门地名管理工作的指导、监督。
