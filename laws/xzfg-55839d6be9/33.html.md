# 地名管理条例第三十三条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/33.html

任何单位和个人发现违反本条例规定行为的，可以向县级以上地方人民政府地名行政主管部门或者其他有关部门举报。接到举报的部门应当依法处理。有关部门应当对举报人的相关信息予以保密。
