# 地名管理条例第三十六条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/36.html

违反本条例第四条、第九条、第十条、第十二条规定，擅自进行地名命名、更名的，由有审批权的行政机关责令限期改正；逾期不改正的，予以取缔，并对违法单位通报批评。
