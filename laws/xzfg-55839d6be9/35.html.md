# 地名管理条例第三十五条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/35.html

县级以上地方人民政府地名批准机关不报送备案或者未按时报送备案的，由国务院地名行政主管部门或者上一级人民政府地名行政主管部门通知该批准机关，限期报送；逾期仍未报送的，对直接责任人员依法给予处分。
