# 地名管理条例第三十八条

- 法规：地名管理条例（现行有效，施行日期 2022-05-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-55839d6be9/38.html

擅自设置、拆除、移动、涂改、遮挡、损毁地名标志的，由地名标志设置、维护和管理部门责令改正并对责任人员处1000元以上5000元以下罚款。
