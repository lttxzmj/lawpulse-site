# 最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定第二十八条

- 法规：最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定（现行有效，施行日期 2020-09-12）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-407a72d0d7/28.html

人民法院审理侵犯商业秘密民事案件，适用被诉侵权行为发生时的法律。被诉侵权行为在法律修改之前已经发生且持续到法律修改之后的，适用修改后的法律。
