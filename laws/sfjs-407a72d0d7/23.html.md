# 最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定第二十三条

- 法规：最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定（现行有效，施行日期 2020-09-12）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-407a72d0d7/23.html

当事人主张依据生效刑事裁判认定的实际损失或者违法所得确定涉及同一侵犯商业秘密行为的民事案件赔偿数额的，人民法院应予支持。
