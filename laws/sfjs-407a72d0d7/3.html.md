# 最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定第三条

- 法规：最高人民法院关于审理侵犯商业秘密民事案件适用法律若干问题的规定（现行有效，施行日期 2020-09-12）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-407a72d0d7/3.html

权利人请求保护的信息在被诉侵权行为发生时不为所属领域的相关人员普遍知悉和容易获得的，人民法院应当认定为反不正当竞争法第九条第四款所称的不为公众所知悉。
