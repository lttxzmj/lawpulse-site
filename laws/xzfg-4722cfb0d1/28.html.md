# 废弃电器电子产品回收处理管理条例第二十八条

- 法规：废弃电器电子产品回收处理管理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4722cfb0d1/28.html

违反本条例规定，未取得废弃电器电子产品处理资格擅自从事废弃电器电子产品处理活动的，由县级以上人民政府生态环境主管部门责令停业、关闭，没收违法所得，并处5万元以上50万元以下的罚款。
