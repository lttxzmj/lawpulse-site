# 废弃电器电子产品回收处理管理条例第三十三条

- 法规：废弃电器电子产品回收处理管理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4722cfb0d1/33.html

违反本条例规定，有关行政主管部门的工作人员滥用职权、玩忽职守、徇私舞弊，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予处分。
