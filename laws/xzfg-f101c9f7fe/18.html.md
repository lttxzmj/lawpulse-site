# 地图管理条例第十八条

- 法规：地图管理条例（现行有效）
- 章节：第三章地图审核
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f101c9f7fe/18.html

省、自治区、直辖市人民政府测绘地理信息行政主管部门负责审核主要表现地在本行政区域范围内的地图。其中，主要表现地在设区的市行政区域范围内不涉及国界线的地图，由设区的市级人民政府测绘地理信息行政主管部门负责审核。
