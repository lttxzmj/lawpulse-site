# 消耗臭氧层物质管理条例第七条

- 法规：消耗臭氧层物质管理条例（现行有效，施行日期 2026-08-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3f39744fce/7.html

国家对消耗臭氧层物质的生产、使用、进出口实行总量控制和配额管理。国务院生态环境主管部门根据国家方案和消耗臭氧层物质淘汰进展情况，商国务院有关部门确定国家消耗臭氧层物质的年度生产、使用和进出口配额总量，并予以公告。
