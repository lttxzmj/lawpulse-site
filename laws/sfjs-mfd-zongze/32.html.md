# 最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释第三十二条

- 法规：最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释（现行有效，施行日期 2022-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-zongze/32.html

为了使国家利益、社会公共利益、本人或者他人的人身权利、财产权利以及其他合法权益免受正在发生的急迫危险，不得已而采取紧急措施的，应当认定为民法典第一百八十二条规定的紧急避险。
