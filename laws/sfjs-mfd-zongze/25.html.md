# 最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释第二十五条

- 法规：最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释（现行有效，施行日期 2022-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-zongze/25.html

数个委托代理人共同行使代理权，其中一人或者数人未与其他委托代理人协商，擅自行使代理权的，依据民法典第一百七十一条、第一百七十二条等规定处理。
