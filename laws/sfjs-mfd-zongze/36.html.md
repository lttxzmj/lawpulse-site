# 最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释第三十六条

- 法规：最高人民法院关于适用《中华人民共和国民法典》总则编若干问题的解释（现行有效，施行日期 2022-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-zongze/36.html

无民事行为能力人或者限制民事行为能力人的权利受到损害的，诉讼时效期间自其法定代理人知道或者应当知道权利受到损害以及义务人之日起计算，但是法律另有规定的除外。
