# 中华人民共和国国际海运条例第四十九条

- 法规：中华人民共和国国际海运条例（现行有效，施行日期 2025-09-28）
- 章节：第七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9b05263064/49.html

本条例施行前已从事国际海上运输经营活动以及与国际海上运输相关的辅助性经营活动的，应当在本条例施行之日起60日内按照本条例的规定补办有关手续。
