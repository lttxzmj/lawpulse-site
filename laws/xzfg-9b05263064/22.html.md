# 中华人民共和国国际海运条例第二十二条

- 法规：中华人民共和国国际海运条例（现行有效，施行日期 2025-09-28）
- 章节：第三章国际海上运输及其辅助性业务经营活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9b05263064/22.html

国际航运交易平台经营者应当向国务院交通运输主管部门报送经营者名称、注册地、联系方式、平台服务协议、航运交易规则等信息，具体办法由国务院交通运输主管部门制定。
