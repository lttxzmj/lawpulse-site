# 宗教事务条例第六十七条

- 法规：宗教事务条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/67.html

宗教团体、宗教院校、宗教活动场所违反国家有关财务、会计、资产、税收管理规定的，由财政、税务等部门依据相关规定进行处罚；情节严重的，经财政、税务部门提出，由登记管理机关或者批准设立机关吊销其登记证书或者设立许可。
