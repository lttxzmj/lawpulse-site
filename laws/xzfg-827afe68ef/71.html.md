# 宗教事务条例第七十一条

- 法规：宗教事务条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/71.html

为违法宗教活动提供条件的，由宗教事务部门给予警告，有违法所得、非法财物的，没收违法所得和非法财物，情节严重的，并处2万元以上20万元以下的罚款；有违法房屋、构筑物的，由规划、建设等部门依法处理；有违反治安管理行为的，依法给予治安管理处罚。
