# 宗教事务条例第五十三条

- 法规：宗教事务条例（现行有效）
- 章节：第七章宗教财产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/53.html

任何组织或者个人捐资修建宗教活动场所，不享有该宗教活动场所的所有权、使用权，不得从该宗教活动场所获得经济收益。
禁止投资、承包经营宗教活动场所或者大型露天宗教造像，禁止以宗教名义进行商业宣传。
