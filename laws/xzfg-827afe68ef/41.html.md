# 宗教事务条例第四十一条

- 法规：宗教事务条例（现行有效）
- 章节：第六章宗教活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/41.html

非宗教团体、非宗教院校、非宗教活动场所、非指定的临时活动地点不得组织、举行宗教活动，不得接受宗教性的捐赠。
非宗教团体、非宗教院校、非宗教活动场所不得开展宗教教育培训，不得组织公民出境参加宗教方面的培训、会议、活动等。
