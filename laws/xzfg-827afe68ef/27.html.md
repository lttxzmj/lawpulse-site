# 宗教事务条例第二十七条

- 法规：宗教事务条例（现行有效）
- 章节：第四章宗教活动场所
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/27.html

宗教事务部门应当对宗教活动场所遵守法律、法规、规章情况，建立和执行场所管理制度情况，登记项目变更情况，以及宗教活动和涉外活动情况进行监督检查。宗教活动场所应当接受宗教事务部门的监督检查。
