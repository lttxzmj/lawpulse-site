# 宗教事务条例第三十三条

- 法规：宗教事务条例（现行有效）
- 章节：第四章宗教活动场所
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/33.html

在宗教活动场所内改建或者新建建筑物，应当经所在地县级以上地方人民政府宗教事务部门批准后，依法办理规划、建设等手续。
宗教活动场所扩建、异地重建的，应当按照本条例第二十一条规定的程序办理。
