# 宗教事务条例第五十五条

- 法规：宗教事务条例（现行有效）
- 章节：第七章宗教财产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-827afe68ef/55.html

为了公共利益需要，征收宗教团体、宗教院校或者宗教活动场所房屋的，应当按照国家房屋征收的有关规定执行。宗教团体、宗教院校或者宗教活动场所可以选择货币补偿，也可以选择房屋产权调换或者重建。
