# 最高人民法院关于审理反倾销行政案件应用法律若干问题的规定第八条

- 法规：最高人民法院关于审理反倾销行政案件应用法律若干问题的规定（现行有效，施行日期 2003-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3e3b4d572e/8.html

原告对其主张的事实有责任提供证据。
经人民法院依照法定程序审查，原告提供的证据具有关联性、合法性和真实性的，可以作为定案的根据。
被告在反倾销行政调查程序中依照法定程序要求原告提供证据，原告无正当理由拒不提供、不如实提供或者以其他方式严重妨碍调查，而在诉讼程序中提供的证据，人民法院不予采纳。
