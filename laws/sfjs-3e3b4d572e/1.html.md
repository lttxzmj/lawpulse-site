# 最高人民法院关于审理反倾销行政案件应用法律若干问题的规定第一条

- 法规：最高人民法院关于审理反倾销行政案件应用法律若干问题的规定（现行有效，施行日期 2003-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3e3b4d572e/1.html

人民法院依法受理对下列反倾销行政行为提起的行政诉讼：
（一）有关倾销及倾销幅度、损害及损害程度的终裁决定；
（二）有关是否征收反倾销税的决定以及追溯征收、退税、对新出口经营者征税的决定；
（三）有关保留、修改或者取消反倾销税以及价格承诺的复审决定；
（四）依照法律、行政法规规定可以起诉的其他反倾销行政行为。
