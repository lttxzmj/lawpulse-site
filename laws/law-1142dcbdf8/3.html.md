# 中华人民共和国香港特别行政区驻军法第三条

- 法规：中华人民共和国香港特别行政区驻军法（现行有效，施行日期 1997-07-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-1142dcbdf8/3.html

香港驻军由中华人民共和国中央军事委员会领导，其员额根据香港特别行政区防务的需要确定。
香港驻军实行人员轮换制度。
