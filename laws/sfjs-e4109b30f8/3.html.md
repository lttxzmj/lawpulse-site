# 最高人民法院关于以法院专递方式邮寄送达民事诉讼文书的若干规定第三条

- 法规：最高人民法院关于以法院专递方式邮寄送达民事诉讼文书的若干规定（现行有效，施行日期 2005-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e4109b30f8/3.html

当事人起诉或者答辩时应当向人民法院提供或者确认自己准确的送达地址，并填写送达地址确认书。当事人拒绝提供的，人民法院应当告知其拒不提供送达地址的不利后果，并记入笔录。
