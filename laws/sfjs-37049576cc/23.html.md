# 最高人民法院关于认可和执行台湾地区法院民事判决的规定第二十三条

- 法规：最高人民法院关于认可和执行台湾地区法院民事判决的规定（现行有效，施行日期 2025-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-37049576cc/23.html

台湾地区法院民事判决被人民法院裁定全部或者部分认可后，申请人对认可部分申请执行的，依据民事诉讼法关于执行程序的规定予以执行。
