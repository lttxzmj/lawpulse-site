# 中华人民共和国中外合作办学条例第三十三条

- 法规：中华人民共和国中外合作办学条例（现行有效）
- 章节：第四章教育教学
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f6a43a916c/33.html

中外合作办学机构的招生简章和广告应当报审批机关备案。
中外合作办学机构应当将办学类型和层次、专业设置、课程内容和招生规模等有关情况，定期向社会公布。
