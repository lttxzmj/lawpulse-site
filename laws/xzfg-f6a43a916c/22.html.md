# 中华人民共和国中外合作办学条例第二十二条

- 法规：中华人民共和国中外合作办学条例（现行有效）
- 章节：第三章组织与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f6a43a916c/22.html

中外合作办学机构的理事会、董事会或者联合管理委员会由中外合作办学者的代表、校长或者主要行政负责人、教职工代表等组成，其中1/3以上组成人员应当具有5年以上教育、教学经验。
中外合作办学机构的理事会、董事会或者联合管理委员会组成人员名单应当报审批机关备案。
