# 中华人民共和国中外合作办学条例第三条

- 法规：中华人民共和国中外合作办学条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f6a43a916c/3.html

中外合作办学属于公益性事业，是中国教育事业的组成部分。
国家对中外合作办学实行扩大开放、规范办学、依法管理、促进发展的方针。
国家鼓励引进外国优质教育资源的中外合作办学。
国家鼓励在高等教育、职业教育领域开展中外合作办学，鼓励中国高等教育机构与外国知名的高等教育机构合作办学。
