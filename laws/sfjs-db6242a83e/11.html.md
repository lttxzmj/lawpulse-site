# 最高人民法院关于审理海上货运代理纠纷案件若干问题的规定第十一条

- 法规：最高人民法院关于审理海上货运代理纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-db6242a83e/11.html

货运代理企业未尽谨慎义务，与未在我国交通主管部门办理提单登记的无船承运业务经营者订立海上货物运输合同，造成委托人损失的，应承担相应的赔偿责任。
