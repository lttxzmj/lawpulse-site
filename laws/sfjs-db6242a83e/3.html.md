# 最高人民法院关于审理海上货运代理纠纷案件若干问题的规定第三条

- 法规：最高人民法院关于审理海上货运代理纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-db6242a83e/3.html

人民法院应根据书面合同约定的权利义务的性质，并综合考虑货运代理企业取得报酬的名义和方式、开具发票的种类和收费项目、当事人之间的交易习惯以及合同实际履行的其他情况，认定海上货运代理合同关系是否成立。
