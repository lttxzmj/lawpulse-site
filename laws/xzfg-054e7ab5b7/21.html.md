# 著作权集体管理条例第二十一条

- 法规：著作权集体管理条例（现行有效）
- 章节：第四章著作权集体管理活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/21.html

权利人可以依照章程规定的程序，退出著作权集体管理组织，终止著作权集体管理合同。但是，著作权集体管理组织已经与他人订立许可使用合同的，该合同在期限届满前继续有效；该合同有效期内，权利人有权获得相应的使用费并可以查阅有关业务材料。
