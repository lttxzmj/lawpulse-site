# 著作权集体管理条例第三条

- 法规：著作权集体管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/3.html

本条例所称著作权集体管理组织，是指为权利人的利益依法设立，根据权利人授权、对权利人的著作权或者与著作权有关的权利进行集体管理的社会团体。
著作权集体管理组织应当依照有关社会团体登记管理的行政法规和本条例的规定进行登记并开展活动。
