# 著作权集体管理条例第二十五条

- 法规：著作权集体管理条例（现行有效）
- 章节：第四章著作权集体管理活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/25.html

除著作权法第二十三条、第三十三条第二款、第四十条第三款、第四十三条第二款和第四十四条规定应当支付的使用费外，著作权集体管理组织应当根据国务院著作权管理部门公告的使用费收取标准，与使用者约定收取使用费的具体数额。
