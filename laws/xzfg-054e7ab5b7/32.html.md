# 著作权集体管理条例第三十二条

- 法规：著作权集体管理条例（现行有效）
- 章节：第五章对著作权集体管理组织的监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/32.html

著作权集体管理组织应当对下列事项进行记录，供权利人和使用者查阅：
(一)作品许可使用情况；
(二)使用费收取和转付情况；
(三)管理费提取和使用情况。
权利人有权查阅、复制著作权集体管理组织的财务报告、工作报告和其他业务材料；著作权集体管理组织应当提供便利。
