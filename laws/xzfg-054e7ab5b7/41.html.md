# 著作权集体管理条例第四十一条

- 法规：著作权集体管理条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/41.html

著作权集体管理组织自国务院民政部门发给登记证书之日起超过6个月无正当理由未开展著作权集体管理活动，或者连续中止著作权集体管理活动6个月以上的，由国务院著作权管理部门吊销其著作权集体管理许可证，并由国务院民政部门撤销登记。
