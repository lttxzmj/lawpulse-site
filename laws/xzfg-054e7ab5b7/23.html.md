# 著作权集体管理条例第二十三条

- 法规：著作权集体管理条例（现行有效）
- 章节：第四章著作权集体管理活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/23.html

著作权集体管理组织许可他人使用其管理的作品、录音录像制品等，应当与使用者以书面形式订立许可使用合同。
著作权集体管理组织不得与使用者订立专有许可使用合同。
使用者以合理的条件要求与著作权集体管理组织订立许可使用合同，著作权集体管理组织不得拒绝。
许可使用合同的期限不得超过2年；合同期限届满可以续订。
