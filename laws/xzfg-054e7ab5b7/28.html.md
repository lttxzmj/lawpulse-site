# 著作权集体管理条例第二十八条

- 法规：著作权集体管理条例（现行有效）
- 章节：第四章著作权集体管理活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-054e7ab5b7/28.html

著作权集体管理组织可以从收取的使用费中提取一定比例作为管理费，用于维持其正常的业务活动。
著作权集体管理组织提取管理费的比例应当随着使用费收入的增加而逐步降低。
