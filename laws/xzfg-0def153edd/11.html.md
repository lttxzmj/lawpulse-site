# 蓄滞洪区运用补偿办法第十一条

- 法规：蓄滞洪区运用补偿办法（现行有效，施行日期 2025-06-23）
- 章节：第二章补偿对象、范围和标准
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0def153edd/11.html

蓄滞洪区运用后，对区内居民遭受的下列损失给予补偿：
（一）农作物、专业养殖和经济林水毁损失；
（二）住房水毁损失；
（三）无法转移的农业生产机械、家庭主要耐用消费品和饲养的畜禽水毁损失。
