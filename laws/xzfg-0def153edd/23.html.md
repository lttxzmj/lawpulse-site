# 蓄滞洪区运用补偿办法第二十三条

- 法规：蓄滞洪区运用补偿办法（现行有效，施行日期 2025-06-23）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0def153edd/23.html

地方各级人民政府和县级以上人民政府有关部门及其工作人员，以及其他依法履行公职的人员，在蓄滞洪区运用补偿工作中滥用职权、玩忽职守、徇私舞弊，或者骗取、侵吞、挪用补偿资金的，对负有责任的领导人员和直接责任人员依法给予处分。
