# 蓄滞洪区运用补偿办法第二十二条

- 法规：蓄滞洪区运用补偿办法（现行有效，施行日期 2025-06-23）
- 章节：第三章补偿程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0def153edd/22.html

补偿资金发放完毕后，蓄滞洪区所在地省级人民政府或者其授权的主管部门应当及时将补偿工作情况报国务院财政主管部门、水行政主管部门和应急管理部门。
