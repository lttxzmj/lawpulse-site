# 水库大坝安全管理条例第二十三条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章大坝管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/23.html

大坝主管部门对其所管辖的大坝应当按期注册登记，建立技术档案。大坝注册登记办法由国务院水行政主管部门会同有关主管部门制定。
