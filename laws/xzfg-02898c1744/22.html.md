# 水库大坝安全管理条例第二十二条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章大坝管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/22.html

大坝主管部门应当建立大坝定期安全检查、鉴定制度。
汛前、汛后，以及暴风、暴雨、特大洪水或者强烈地震发生后，大坝主管部门应当组织对其所管辖的大坝的安全进行检查。
