# 水库大坝安全管理条例第十四条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章大坝管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/14.html

非大坝管理人员不得操作大坝的泄洪闸门、输水闸门以及其他设施，大坝管理人员操作时应当遵守有关的规章制度。禁止任何单位和个人干扰大坝的正常管理工作。
