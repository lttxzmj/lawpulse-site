# 水库大坝安全管理条例第十一条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第二章大坝建设
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/11.html

大坝开工后，大坝主管部门应当组建大坝管理单位，由其按照工程基本建设验收规程参与质量检查以及大坝分部、分项验收和蓄水验收工作。
大坝竣工后，建设单位应当申请大坝主管部门组织验收。
