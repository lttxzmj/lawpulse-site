# 水库大坝安全管理条例第二条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/2.html

本条例适用于中华人民共和国境内坝高15米以上或者库容100万立方米以上的水库大坝（以下简称大坝）。大坝包括永久性挡水建筑物以及与其配合运用的泄洪、输水和过船建筑物等。
坝高15米以下、10米以上或者库容100万立方米以下、10万立方米以上，对重要城镇、交通干线、重要军事设施、工矿区安全有潜在危险的大坝，其安全管理参照本条例执行。
