# 水库大坝安全管理条例第十七条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第三章大坝管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/17.html

禁止在坝体修建码头、渠道、堆放杂物、晾晒粮草。在大坝管理和保护范围内修建码头、鱼塘的，须经大坝主管部门批准，并与坝脚和泄水、输水建筑物保持一定距离，不得影响大坝安全、工程管理和抢险工作。
