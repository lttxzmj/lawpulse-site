# 水库大坝安全管理条例第二十七条

- 法规：水库大坝安全管理条例（现行有效，施行日期 2026-03-20）
- 章节：第四章险坝处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-02898c1744/27.html

大坝主管部门应当对其所管辖的需要加固的险坝制定加固计划，限期消除危险；有关人民政府应当优先安排所需资金和物料。
险坝加固必须由具有相应设计资格证书的单位作出加固设计，经审批后组织实施。险坝加固竣工后，由大坝主管部门组织验收。
