# 殡葬管理条例第十七条

- 法规：殡葬管理条例（现行有效，施行日期 2026-03-30）
- 章节：第二章殡葬设施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f258bae3f6/17.html

县级以上地方人民政府建设骨灰堂、公墓，应当结合本行政区域实行火葬、改革土葬以及现有土地资源等状况，按照供需适配、节地生态原则，合理确定建设类型、数量和规模。
