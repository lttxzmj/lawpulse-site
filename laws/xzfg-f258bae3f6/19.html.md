# 殡葬管理条例第十九条

- 法规：殡葬管理条例（现行有效，施行日期 2026-03-30）
- 章节：第二章殡葬设施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f258bae3f6/19.html

殡葬设施所需的遗体接运车、遗体冷藏柜、火化机、火化污染物净化设备等殡葬设备，应当符合相关强制性标准。禁止制造、销售、使用不符合强制性标准的殡葬设备。
