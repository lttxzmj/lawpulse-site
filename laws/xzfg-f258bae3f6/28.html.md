# 殡葬管理条例第二十八条

- 法规：殡葬管理条例（现行有效，施行日期 2026-03-30）
- 章节：第三章殡仪服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f258bae3f6/28.html

殡仪馆应当凭死亡证明和火化确认书火化遗体，并出具火化证明。
殡仪馆应当在遗体存放、火化等重点区域安装图像采集设备，并将收集的视频图像信息保存不少于90日备查。
