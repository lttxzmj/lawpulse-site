# 殡葬管理条例第四十九条

- 法规：殡葬管理条例（现行有效，施行日期 2026-03-30）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f258bae3f6/49.html

县级以上地方人民政府民政部门应当建立健全对殡葬设施建设运营、公墓安葬标准、丧事活动管理等事项的随机抽查机制。抽查情况以及查处结果应当书面告知被抽查对象，并依法向社会公开。
