# 证券公司监督管理条例第六十一条

- 法规：证券公司监督管理条例（现行有效）
- 章节：第五章客户资产的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16298e2784/61.html

证券公司不得以证券经纪客户或者证券资产管理客户的资产向他人提供融资或者担保。任何单位或者个人不得强令、指使、协助、接受证券公司以其证券经纪客户或者证券资产管理客户的资产提供融资或者担保。
