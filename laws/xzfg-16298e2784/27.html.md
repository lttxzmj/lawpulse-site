# 证券公司监督管理条例第二十七条

- 法规：证券公司监督管理条例（现行有效）
- 章节：第三章组织机构 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16298e2784/27.html

证券公司应当按照审慎经营的原则，建立健全风险管理与内部控制制度，防范和控制风险。
证券公司应当对分支机构实行集中统一管理，不得与他人合资、合作经营管理分支机构，也不得将分支机构承包、租赁或者委托给他人经营管理。
