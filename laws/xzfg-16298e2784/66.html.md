# 证券公司监督管理条例第六十六条

- 法规：证券公司监督管理条例（现行有效）
- 章节：第六章监督管理措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16298e2784/66.html

证券公司应当依法向社会公开披露其基本情况、参股及控股情况、负债及或有负债情况、经营管理状况、财务收支状况、高级管理人员薪酬和其他有关信息。具体办法由国务院证券监督管理机构制定。
