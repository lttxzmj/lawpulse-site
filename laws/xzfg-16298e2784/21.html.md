# 证券公司监督管理条例第二十一条

- 法规：证券公司监督管理条例（现行有效）
- 章节：第三章组织机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16298e2784/21.html

证券公司设董事会秘书，负责股东会和董事会会议的筹备、文件的保管以及股东资料的管理，按照规定或者根据国务院证券监督管理机构、股东等有关单位或者个人的要求，依法提供有关资料，办理信息报送或者信息披露事项。董事会秘书为证券公司高级管理人员。
