# 中国人民解放军实施《中华人民共和国药品管理法》办法第三条

- 数据核对至：2026-10-22

军队药品管理工作坚持中国共产党的领导，贯彻习近平强军思想，坚持风险管理、全程管控、军地协同的原则，科学严格监管，保障药品的安全、有效、可及。
