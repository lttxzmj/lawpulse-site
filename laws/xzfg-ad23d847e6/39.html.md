# 中国人民解放军实施《中华人民共和国药品管理法》办法第三十九条

- 法规：中国人民解放军实施《中华人民共和国药品管理法》办法（现行有效，施行日期 2025-06-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ad23d847e6/39.html

军队医疗机构使用假药、劣药的，没收其使用的假药、劣药和违法所得，责令改正；情节严重的，有关责任人员有医疗卫生人员执业证书的，还应当吊销其执业证书。
