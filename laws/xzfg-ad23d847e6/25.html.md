# 中国人民解放军实施《中华人民共和国药品管理法》办法第二十五条

- 法规：中国人民解放军实施《中华人民共和国药品管理法》办法（现行有效，施行日期 2025-06-01）
- 章节：第四章军队特需药品管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ad23d847e6/25.html

军队特需药品应当在军队内部使用；地方单位因特殊情况需要购进军队特需药品的，应当经国务院药品监督管理部门或者省、自治区、直辖市人民政府药品监督管理部门审核，并经中央军事委员会后勤保障部负责卫生工作的业务部门同意。
军队特需药品需要转化为民用药品的，应当经中央军事委员会后勤保障部负责卫生工作的业务部门审核，由国务院药品监督管理部门按照药品上市注册有关规定办理。
