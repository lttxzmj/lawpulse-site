# 中国人民解放军实施《中华人民共和国药品管理法》办法第二十八条

- 法规：中国人民解放军实施《中华人民共和国药品管理法》办法（现行有效，施行日期 2025-06-01）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ad23d847e6/28.html

中央军事委员会后勤保障部负责卫生工作的业务部门制定军队药品质量抽查检验计划，组织对军队单位生产、储备、供应、使用的药品以及委托生产的军队特需药品进行抽查检验。药品质量抽查检验结果按照规定向军队有关单位和地方有关药品监督管理部门通报。
军队医疗机构、科研机构、药材供应保障机构发现药品有疑似质量问题的，应当按照规定送交军队药品专业技术机构进行质量检验。
