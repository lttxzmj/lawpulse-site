# 中华人民共和国海洋倾废管理条例第二十一条

- 法规：中华人民共和国海洋倾废管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-35f557c4f2/21.html

对违反本条例，造成或可能造成海洋环境污染损害的直接责任人，主管部门可处以警告或者罚款，也可以并处。
对于违反本条例，污染损害海洋环境造成重大财产损失或致人伤亡的直接责任人，由司法机关依法追究刑事责任。
