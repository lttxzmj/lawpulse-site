# 最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（一）第三条

- 法规：最高人民法院关于适用《中华人民共和国公司法》若干问题的规定（一）（现行有效，施行日期 2014-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-2e5e35cc7c/3.html
