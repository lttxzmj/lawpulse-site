# 中华人民共和国保障措施条例第三条

- 法规：中华人民共和国保障措施条例（现行有效）
- 章节：第二章调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-558c210f2b/3.html

与国内产业有关的自然人、法人或者其他组织(以下统称申请人)，可以依照本条例的规定，向商务部提出采取保障措施的书面申请。
商务部应当及时对申请人的申请进行审查，决定立案调查或者不立案调查。
