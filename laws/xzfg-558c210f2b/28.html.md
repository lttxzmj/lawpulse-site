# 中华人民共和国保障措施条例第二十八条

- 法规：中华人民共和国保障措施条例（现行有效）
- 章节：第四章保障措施的期限与复审
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-558c210f2b/28.html

保障措施实施期限超过3年的，商务部应当在实施期间内对该项措施进行中期复审。
复审的内容包括保障措施对国内产业的影响、国内产业的调整情况等。
