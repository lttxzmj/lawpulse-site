# 最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定第二十三条

- 法规：最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-508fb6bac6/23.html

拍卖时无人竞买或者竞买人的最高应价低于保留价，到场的申请执行人或者其他执行债权人不申请以该次拍卖所定的保留价抵债的，应当在六十日内再行拍卖。
