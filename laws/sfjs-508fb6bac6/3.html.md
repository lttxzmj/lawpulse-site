# 最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定第三条

- 法规：最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-508fb6bac6/3.html

人民法院拍卖被执行人财产，应当委托具有相应资质的拍卖机构进行，并对拍卖机构的拍卖进行监督，但法律、司法解释另有规定的除外。
