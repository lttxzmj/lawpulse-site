# 企业债券管理条例第二条

- 法规：企业债券管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-fa4e684f05/2.html

本条例适用于中华人民共和国境内具有法人资格的企业(以下简称企业)在境内发行的债券。但是，金融债券和外币债券除外。
除前款规定的企业外，任何单位和个人不得发行企业债券。
