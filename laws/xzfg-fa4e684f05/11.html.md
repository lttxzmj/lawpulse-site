# 企业债券管理条例第十一条

- 法规：企业债券管理条例（现行有效）
- 章节：第三章企业债券的管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-fa4e684f05/11.html

企业发行企业债券必须按照本条例的规定进行审批；未经批准的，不得擅自发行和变相发行企业债券。
中央企业发行企业债券，由中国人民银行会同国家计划委员会审批；地方企业发行企业债券，由中国人民银行省、自治区、直辖市、计划单列市分行会同同级计划主管部门审批。
