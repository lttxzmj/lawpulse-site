# 公平竞争审查条例第十六条

- 法规：公平竞争审查条例（现行有效，施行日期 2024-08-01）
- 章节：第三章审查机制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-414619875c/16.html

开展公平竞争审查，应当听取有关经营者、行业协会商会等利害关系人关于公平竞争影响的意见。涉及社会公众利益的，应当听取社会公众意见。
