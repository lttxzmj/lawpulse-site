# 公平竞争审查条例第二十二条

- 法规：公平竞争审查条例（现行有效，施行日期 2024-08-01）
- 章节：第四章监督保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-414619875c/22.html

对违反本条例规定的政策措施，任何单位和个人可以向市场监督管理部门举报。市场监督管理部门接到举报后，应当及时处理或者转送有关部门处理。
市场监督管理部门应当向社会公开受理举报的电话、信箱或者电子邮件地址。
