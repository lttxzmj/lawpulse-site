# 公平竞争审查条例第二十三条

- 法规：公平竞争审查条例（现行有效，施行日期 2024-08-01）
- 章节：第四章监督保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-414619875c/23.html

国务院定期对县级以上地方人民政府公平竞争审查工作机制建设情况、公平竞争审查工作开展情况、举报处理情况等开展督查。国务院市场监督管理部门负责具体实施。
