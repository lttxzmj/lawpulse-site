# 公平竞争审查条例第十七条

- 法规：公平竞争审查条例（现行有效，施行日期 2024-08-01）
- 章节：第三章审查机制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-414619875c/17.html

开展公平竞争审查，应当按照本条例规定的审查标准，在评估对公平竞争影响后，作出审查结论。
适用本条例第十二条规定的，应当在审查结论中详细说明。
