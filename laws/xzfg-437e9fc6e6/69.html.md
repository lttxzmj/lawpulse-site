# 铁路安全管理条例第六十九条

- 法规：铁路安全管理条例（现行有效）
- 章节：第五章铁路运营安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-437e9fc6e6/69.html

运输危险货物应当依照法律法规和国家其他有关规定使用专用的设施设备，托运人应当配备必要的押运人员和应急处理器材、设备以及防护用品，并使危险货物始终处于押运人员的监管之下；危险货物发生被盗、丢失、泄漏等情况，应当按照国家有关规定及时报告。
