# 铁路安全管理条例第四十二条

- 法规：铁路安全管理条例（现行有效）
- 章节：第四章铁路线路安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-437e9fc6e6/42.html

船舶通过铁路桥梁应当符合桥梁的通航净空高度并遵守航行规则。
桥区航标中的桥梁航标、桥柱标、桥梁水尺标由铁路运输企业负责设置、维护，水面航标由铁路运输企业负责设置，航道管理部门负责维护。
