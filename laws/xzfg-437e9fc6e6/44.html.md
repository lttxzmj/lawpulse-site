# 铁路安全管理条例第四十四条

- 法规：铁路安全管理条例（现行有效）
- 章节：第四章铁路线路安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-437e9fc6e6/44.html

铁路线路安全保护区内的道路和铁路线路路堑上的道路、跨越铁路线路的道路桥梁，应当按照国家有关规定设置防止车辆以及其他物体进入、坠入铁路线路的安全防护设施和警示标志，并由道路管理部门或者道路经营企业维护、管理。
