# 铁路安全管理条例第八十一条

- 法规：铁路安全管理条例（现行有效）
- 章节：第六章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-437e9fc6e6/81.html

铁路监管部门发现安全隐患，应当责令有关单位立即排除。重大安全隐患排除前或者排除过程中无法保证安全的，应当责令从危险区域内撤出人员、设备，停止作业；重大安全隐患排除后方可恢复作业。
