# 铁路安全管理条例第一百零一条

- 法规：铁路安全管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-437e9fc6e6/101.html

铁路监管部门及其工作人员应当严格按照本条例规定的处罚种类和幅度，根据违法行为的性质和具体情节行使行政处罚权，具体办法由国务院铁路行业监督管理部门制定。
