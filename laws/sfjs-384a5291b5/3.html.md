# 最高人民法院关于人民法院庭审录音录像的若干规定第三条

- 法规：最高人民法院关于人民法院庭审录音录像的若干规定（现行有效，施行日期 2017-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-384a5291b5/3.html

庭审录音录像应当自宣布开庭时开始，至闭庭时结束。除下列情形外，庭审录音录像不得人为中断：
（一）休庭；
（二）公开庭审中的不公开举证、质证活动；
（三）不宜录制的调解活动。
负责录音录像的人员应当对录音录像的起止时间、有无中断等情况进行记录并附卷。
