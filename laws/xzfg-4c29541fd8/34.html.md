# 海洋观测预报管理条例第三十四条

- 法规：海洋观测预报管理条例（现行有效，施行日期 2023-07-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c29541fd8/34.html

从事海洋观测活动的单位未按照规定汇交海洋观测资料的，由负责接收海洋观测资料的海洋主管部门责令限期汇交；逾期不汇交的，责令停止海洋观测活动，处2万元以上10万元以下的罚款。
