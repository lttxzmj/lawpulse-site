# 海洋观测预报管理条例第三条

- 法规：海洋观测预报管理条例（现行有效，施行日期 2023-07-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c29541fd8/3.html

海洋观测预报事业是基础性公益事业。国务院和沿海县级以上地方人民政府应当将海洋观测预报事业纳入本级国民经济和社会发展规划，所需经费纳入本级财政预算。
