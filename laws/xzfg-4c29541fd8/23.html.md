# 海洋观测预报管理条例第二十三条

- 法规：海洋观测预报管理条例（现行有效，施行日期 2023-07-20）
- 章节：第四章海洋预报
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c29541fd8/23.html

国务院有关部门、沿海地方各级人民政府和沿海县级以上地方人民政府有关部门应当根据海洋预报机构提供的海洋灾害警报信息采取必要措施，并根据防御海洋灾害的需要，启动相应的海洋灾害应急预案，避免或者减轻海洋灾害。
