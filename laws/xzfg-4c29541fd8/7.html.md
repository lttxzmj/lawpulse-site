# 海洋观测预报管理条例第七条

- 法规：海洋观测预报管理条例（现行有效，施行日期 2023-07-20）
- 章节：第二章海洋观测网的规划、建设与保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4c29541fd8/7.html

编制海洋观测网规划，应当坚持统筹兼顾、突出重点、合理布局的原则，避免重复建设，保障国防安全。
编制海洋观测网规划，应当将沿海城市和人口密集区、产业园区、滨海重大工程所在区、海洋灾害易发区和海上其他重要区域作为规划的重点。
