# 最高人民法院关于审理无正本提单交付货物案件适用法律若干问题的规定第八条

- 法规：最高人民法院关于审理无正本提单交付货物案件适用法律若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-542a2a13c9/8.html

承运到港的货物超过法律规定期限无人向海关申报，被海关提取并依法变卖处理，或者法院依法裁定拍卖承运人留置的货物，承运人主张免除交付货物责任的，人民法院应予支持。
