# 植物检疫条例第十一条

- 法规：植物检疫条例（现行有效，施行日期 2026-03-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2fbcf23605/11.html

种子、苗木和其他繁殖材料的繁育单位，必须有计划地建立无植物检疫对象的种苗繁育基地、母树林基地。试验、推广的种子、苗木和其他繁殖材料，不得带有植物检疫对象。植物检疫机构应实施产地检疫。
