# 中华人民共和国宪法（2018年修正文本）第八十一条

- 法规：中华人民共和国宪法（2018年修正文本）（现行有效，施行日期 2018-03-11）
- 章节：第三章国家机构 · 第二节中华人民共和国主席
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/constitution/81.html

中华人民共和国主席代表中华人民共和国，进行国事活动，接受外国使节；根据全国人民代表大会常务委员会的决定，派遣和召回驻外全权代表，批准和废除同外国缔结的条约和重要协定。
