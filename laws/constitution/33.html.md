# 中华人民共和国宪法（2018年修正文本）第三十三条

- 法规：中华人民共和国宪法（2018年修正文本）（现行有效，施行日期 2018-03-11）
- 章节：第二章公民的基本权利和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/constitution/33.html

凡具有中华人民共和国国籍的人都是中华人民共和国公民。
中华人民共和国公民在法律面前一律平等。
国家尊重和保障人权。
任何公民享有宪法和法律规定的权利，同时必须履行宪法和法律规定的义务。
