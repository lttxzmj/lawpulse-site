# 中华人民共和国宪法（2018年修正文本）第六十三条

- 法规：中华人民共和国宪法（2018年修正文本）（现行有效，施行日期 2018-03-11）
- 章节：第三章国家机构 · 第一节全国人民代表大会
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/constitution/63.html

全国人民代表大会有权罢免下列人员：
（一）中华人民共和国主席、副主席；
（二）国务院总理、副总理、国务委员、各部部长、各委员会主任、审计长、秘书长；
（三）中央军事委员会主席和中央军事委员会其他组成人员；
（四）国家监察委员会主任；
（五）最高人民法院院长；
（六）最高人民检察院检察长。
