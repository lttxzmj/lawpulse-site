# 中华人民共和国民用航空器国籍登记条例第八条

- 法规：中华人民共和国民用航空器国籍登记条例（现行有效，施行日期 2020-11-29）
- 章节：第二章国籍登记
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-af5a1051f0/8.html

国务院民用航空主管部门应当自收到民用航空器国籍登记申请之日起7个工作日内，对申请书及有关证明文件进行审查；经审查，符合本条例规定的，应当向申请人颁发中华人民共和国民用航空器国籍登记证书。
