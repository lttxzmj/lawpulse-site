# 中华人民共和国海警法第六十条

- 法规：中华人民共和国海警法（现行有效，施行日期 2021-02-01）
- 章节：第七章保障和协作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-0e5c9fc702/60.html

海警机构对依法决定行政拘留的违法行为人和拘留审查的外国人，以及决定刑事拘留、执行逮捕的犯罪嫌疑人，分别送海警机构所在地拘留所或者看守所执行。
