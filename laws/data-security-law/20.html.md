# 中华人民共和国数据安全法第二十条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第二章数据安全与发展
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/20.html

国家支持教育、科研机构和企业等开展数据开发利用技术和数据安全相关教育和培训，采取多种方式培养数据开发利用技术和数据安全专业人才，促进人才交流。
