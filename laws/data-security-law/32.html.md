# 中华人民共和国数据安全法第三十二条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第四章数据安全保护义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/32.html

任何组织、个人收集数据，应当采取合法、正当的方式，不得窃取或者以其他非法方式获取数据。
法律、行政法规对收集、使用数据的目的、范围有规定的，应当在法律、行政法规规定的目的和范围内收集、使用数据。
