# 中华人民共和国数据安全法第十六条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第二章数据安全与发展
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/16.html

国家支持数据开发利用和数据安全技术研究，鼓励数据开发利用和数据安全等领域的技术推广和商业创新，培育、发展数据开发利用和数据安全产品、产业体系。
