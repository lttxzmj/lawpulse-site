# 中华人民共和国数据安全法第二十四条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第三章数据安全制度
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/24.html

国家建立数据安全审查制度，对影响或者可能影响国家安全的数据处理活动进行国家安全审查。
依法作出的安全审查决定为最终决定。
