# 中华人民共和国数据安全法第五十三条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/53.html

开展涉及国家秘密的数据处理活动，适用《中华人民共和国保守国家秘密法》等法律、行政法规的规定。
在统计、档案工作中开展数据处理活动，开展涉及个人信息的数据处理活动，还应当遵守有关法律、行政法规的规定。
