# 中华人民共和国数据安全法第二十二条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第三章数据安全制度
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/22.html

国家建立集中统一、高效权威的数据安全风险评估、报告、信息共享、监测预警机制。国家数据安全工作协调机制统筹协调有关部门加强数据安全风险信息的获取、分析、研判、预警工作。
