# 中华人民共和国数据安全法第三十三条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第四章数据安全保护义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/33.html

从事数据交易中介服务的机构提供服务，应当要求数据提供方说明数据来源，审核交易双方的身份，并留存审核、交易记录。
