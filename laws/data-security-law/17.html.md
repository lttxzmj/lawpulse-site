# 中华人民共和国数据安全法第十七条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第二章数据安全与发展
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/17.html

国家推进数据开发利用技术和数据安全标准体系建设。国务院标准化行政主管部门和国务院有关部门根据各自的职责，组织制定并适时修订有关数据开发利用技术、产品和数据安全相关标准。国家支持企业、社会团体和教育、科研机构等参与标准制定。
