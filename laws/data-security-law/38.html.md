# 中华人民共和国数据安全法第三十八条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第五章政务数据安全与开放
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/38.html

国家机关为履行法定职责的需要收集、使用数据，应当在其履行法定职责的范围内依照法律、行政法规规定的条件和程序进行；对在履行职责中知悉的个人隐私、个人信息、商业秘密、保密商务信息等数据应当依法予以保密，不得泄露或者非法向他人提供。
