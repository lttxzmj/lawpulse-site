# 中华人民共和国数据安全法第二十三条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第三章数据安全制度
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/23.html

国家建立数据安全应急处置机制。发生数据安全事件，有关主管部门应当依法启动应急预案，采取相应的应急处置措施，防止危害扩大，消除安全隐患，并及时向社会发布与公众有关的警示信息。
