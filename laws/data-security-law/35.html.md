# 中华人民共和国数据安全法第三十五条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第四章数据安全保护义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/35.html

公安机关、国家安全机关因依法维护国家安全或者侦查犯罪的需要调取数据，应当按照国家有关规定，经过严格的批准手续，依法进行，有关组织、个人应当予以配合。
