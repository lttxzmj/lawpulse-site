# 中华人民共和国数据安全法第四十一条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第五章政务数据安全与开放
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/41.html

国家机关应当遵循公正、公平、便民的原则，按照规定及时、准确地公开政务数据。依法不予公开的除外。
