# 中华人民共和国数据安全法第三十九条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第五章政务数据安全与开放
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/39.html

国家机关应当依照法律、行政法规的规定，建立健全数据安全管理制度，落实数据安全保护责任，保障政务数据安全。
