# 中华人民共和国数据安全法第十三条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第二章数据安全与发展
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/13.html

国家统筹发展和安全，坚持以数据开发利用和产业发展促进数据安全，以数据安全保障数据开发利用和产业发展。
