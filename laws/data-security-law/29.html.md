# 中华人民共和国数据安全法第二十九条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第四章数据安全保护义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/29.html

开展数据处理活动应当加强风险监测，发现数据安全缺陷、漏洞等风险时，应当立即采取补救措施；发生数据安全事件时，应当立即采取处置措施，按照规定及时告知用户并向有关主管部门报告。
