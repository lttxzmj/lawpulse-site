# 中华人民共和国数据安全法第四十条

- 法规：中华人民共和国数据安全法（现行有效，施行日期 2021-09-01）
- 章节：第五章政务数据安全与开放
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/data-security-law/40.html

国家机关委托他人建设、维护电子政务系统，存储、加工政务数据，应当经过严格的批准程序，并应当监督受托方履行相应的数据安全保护义务。受托方应当依照法律、法规的规定和合同约定履行数据安全保护义务，不得擅自留存、使用、泄露或者向他人提供政务数据。
