# 中华人民共和国烟草专卖法实施条例第十一条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第二章烟草专卖许可证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/11.html

申请领取烟草专卖生产企业许可证的，应当向省、自治区、直辖市（以下简称省级）烟草专卖行政主管部门提出申请，由省级烟草专卖行政主管部门审查签署意见，报国务院烟草专卖行政主管部门审批发证。
