# 中华人民共和国烟草专卖法实施条例第六十四条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/64.html

违反本条例第四十八条的规定，拍卖企业未对竞买人进行资格验证，或者不接受烟草专卖行政主管部门的监督，擅自拍卖烟草专卖品的，由烟草专卖行政主管部门处以拍卖的烟草专卖品价值20%以上50%以下的罚款，并依法取消其拍卖烟草专卖品的资格。
