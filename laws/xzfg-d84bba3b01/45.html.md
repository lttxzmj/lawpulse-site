# 中华人民共和国烟草专卖法实施条例第四十五条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/45.html

国务院烟草专卖行政主管部门在必要时，可以根据烟草专卖工作的实际情况，在重点地区设立派出机构；省级烟草专卖行政主管部门在必要时，可以向烟草专卖品生产、经营企业派驻人员。派出机构和派驻人员在派出部门的授权范围内监督、检查烟草专卖品的生产、经营活动。
