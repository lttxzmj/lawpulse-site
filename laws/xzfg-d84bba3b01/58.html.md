# 中华人民共和国烟草专卖法实施条例第五十八条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/58.html

违反本条例第二十五条、第三十八条第一款规定销售非法生产的烟草专卖品的，由烟草专卖行政主管部门责令停止销售，没收违法所得，处以违法销售总额20%以上50%以下的罚款，并将非法销售的烟草专卖品公开销毁。
