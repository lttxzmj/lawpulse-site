# 中华人民共和国烟草专卖法实施条例第六十三条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/63.html

违反本条例第四十二条规定，在海关监管区内经营免税的卷烟、雪茄烟没有在小包、条包上标注国务院烟草专卖行政主管部门规定的专门标志的，可以处非法经营总额50%以下的罚款。
