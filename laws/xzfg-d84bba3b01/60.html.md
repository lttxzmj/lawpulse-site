# 中华人民共和国烟草专卖法实施条例第六十条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/60.html

违反本条例第二十六条、第三十六条第二款规定，为无烟草专卖许可证的单位或者个人提供烟草专卖品的，由烟草专卖行政主管部门没收违法所得，并处以销售总额20%以上50%以下的罚款。
