# 中华人民共和国烟草专卖法实施条例第六十二条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/62.html

违反本条例第四十一条规定，免税进口的烟草制品不按规定存放在烟草制品保税仓库内的，可以处烟草制品价值50%以下的罚款。
