# 中华人民共和国烟草专卖法实施条例第五十九条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/59.html

违反本条例规定，未取得国务院烟草专卖行政主管部门颁发的烟草专卖批发企业许可证，擅自跨省、自治区、直辖市从事烟草制品批发业务的，由烟草专卖行政主管部门处以批发总额10%以上20%以下的罚款。
