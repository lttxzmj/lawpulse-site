# 中华人民共和国烟草专卖法实施条例第二十六条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第五章烟草制品的销售
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/26.html

烟草专卖生产企业和烟草专卖批发企业，不得向无烟草专卖零售许可证的单位或者个人提供烟草制品。
