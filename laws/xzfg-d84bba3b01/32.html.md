# 中华人民共和国烟草专卖法实施条例第三十二条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第六章烟草专卖品的运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/32.html

烟草专卖品准运证由省级以上烟草专卖行政主管部门或其授权的机构审批、发放。烟草专卖品准运证的管理办法由国务院烟草专卖行政主管部门制定。
