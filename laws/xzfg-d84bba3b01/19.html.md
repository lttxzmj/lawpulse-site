# 中华人民共和国烟草专卖法实施条例第十九条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第四章烟草制品的生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/19.html

设立烟草制品生产企业，应当由省级烟草专卖行政主管部门报经国务院烟草专卖行政主管部门批准，取得烟草专卖生产企业许可证，并经工商行政管理部门核准登记。
