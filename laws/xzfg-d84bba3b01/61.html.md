# 中华人民共和国烟草专卖法实施条例第六十一条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第十章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/61.html

违反本条例第三十六条第一款规定，烟草专卖批发企业和烟草制品生产企业从无烟草专卖生产企业许可证的企业购买卷烟纸、滤嘴棒、烟用丝束、烟草专用机械的，由烟草专卖行政主管部门处以所购烟草专卖品价值50%以上1倍以下的罚款。
