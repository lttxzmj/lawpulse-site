# 中华人民共和国烟草专卖法实施条例第二十七条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第五章烟草制品的销售
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/27.html

在中国境内销售的卷烟、雪茄烟，应当在小包、条包上标注焦油含量级和“吸烟有害健康”的中文字样。
