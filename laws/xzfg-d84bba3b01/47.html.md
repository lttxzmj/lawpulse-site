# 中华人民共和国烟草专卖法实施条例第四十七条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/47.html

烟草专卖行政主管部门或者烟草专卖行政主管部门会同有关部门，可以依法对非法运输烟草专卖品的活动进行检查、处理。
