# 中华人民共和国烟草专卖法实施条例第四十六条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/46.html

烟草专卖行政主管部门查处违反《烟草专卖法》和本条例的案件时，可以行使下列职权：
（一）询问违法案件的当事人、嫌疑人和证人；
（二）检查违法案件当事人的经营场所，依法对违法生产或者经营的烟草专卖品进行处理；
（三）查阅、复制与违法活动有关的合同、发票、账册、单据、记录、文件、业务函电和其他资料。
