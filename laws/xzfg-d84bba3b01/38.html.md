# 中华人民共和国烟草专卖法实施条例第三十八条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第七章卷烟纸、滤嘴棒、烟用丝束、烟草专用机械的
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/38.html

任何单位或者个人不得销售非法生产的烟草专用机械、卷烟纸、滤嘴棒及烟用丝束。
淘汰报废、非法拼装的烟草专用机械，残次的卷烟纸、滤嘴棒、烟用丝束及下脚料，由当地烟草专卖行政主管部门监督处理，不得以任何方式销售。
