# 中华人民共和国烟草专卖法实施条例第四十四条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/44.html

烟草专卖行政主管部门依法对执行《烟草专卖法》及本条例的情况进行监督、检查，查处违反《烟草专卖法》及本条例的案件，并会同国家有关部门查处烟草专卖品的走私贩私、假冒伪劣行为。
