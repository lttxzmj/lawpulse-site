# 中华人民共和国烟草专卖法实施条例第三十七条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第七章卷烟纸、滤嘴棒、烟用丝束、烟草专用机械的
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/37.html

烟草专用机械的购进、出售、转让，必须经国务院烟草专卖行政主管部门批准。
烟草专用机械的名录由国务院烟草专卖行政主管部门规定。
