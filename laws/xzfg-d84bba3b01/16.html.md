# 中华人民共和国烟草专卖法实施条例第十六条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第三章烟叶的种植、收购和调拨
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/16.html

烟叶由烟草公司或其委托单位依法统一收购。烟草公司或其委托单位根据需要，可以在国家下达烟叶收购计划的地区设立烟叶收购站（点）收购烟叶。设立烟叶收购站（点），应当经设区的市级烟草专卖行政主管部门批准。未经批准，任何单位和个人不得收购烟叶。
