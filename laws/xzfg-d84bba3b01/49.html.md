# 中华人民共和国烟草专卖法实施条例第四十九条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第九章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/49.html

烟草专卖行政主管部门的专卖管理检查人员执行公务时，应当佩戴国务院烟草专卖行政主管部门制发的徽章，出示省级以上烟草专卖行政主管部门签发的检查证件。
