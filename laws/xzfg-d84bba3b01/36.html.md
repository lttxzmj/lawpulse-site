# 中华人民共和国烟草专卖法实施条例第三十六条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第七章卷烟纸、滤嘴棒、烟用丝束、烟草专用机械的
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/36.html

烟草专卖批发企业和烟草制品生产企业只能从取得烟草专卖生产企业许可证的企业购买卷烟纸、滤嘴棒、烟用丝束和烟草专用机械。
卷烟纸、滤嘴棒、烟用丝束、烟草专用机械的生产企业不得将其产品销售给无烟草专卖生产企业许可证的单位或者个人。
