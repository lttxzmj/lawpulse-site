# 中华人民共和国烟草专卖法实施条例第四十二条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第八章进出口贸易和对外经济技术合作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/42.html

在海关监管区内经营免税的卷烟、雪茄烟的，只能零售，并应当在卷烟、雪茄烟的小包、条包上标注国务院烟草专卖行政主管部门规定的专门标志。
