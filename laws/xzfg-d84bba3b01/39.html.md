# 中华人民共和国烟草专卖法实施条例第三十九条

- 法规：中华人民共和国烟草专卖法实施条例（现行有效，施行日期 2023-07-20）
- 章节：第八章进出口贸易和对外经济技术合作
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d84bba3b01/39.html

设立外商投资的烟草专卖生产企业，应当报经国务院烟草专卖行政主管部门审查同意后，方可按照国家有关规定批准立项。
