# 最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定第二十三条

- 法规：最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-shijian/23.html

被继承人在民法典施行前立有公证遗嘱，民法典施行后又立有新遗嘱，其死亡后，因该数份遗嘱内容相抵触发生争议的，适用民法典第一千一百四十二条第三款的规定。
