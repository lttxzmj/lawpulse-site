# 最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定第二十五条

- 法规：最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-shijian/25.html

民法典施行前成立的合同，当时的法律、司法解释没有规定且当事人没有约定解除权行使期限，对方当事人也未催告的，解除权人在民法典施行前知道或者应当知道解除事由，自民法典施行之日起一年内不行使的，人民法院应当依法认定该解除权消灭；解除权人在民法典施行后知道或者应当知道解除事由的，适用民法典第五百六十四条第二款关于解除权行使期限的规定。
