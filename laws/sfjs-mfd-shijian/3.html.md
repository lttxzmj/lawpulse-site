# 最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定第三条

- 法规：最高人民法院关于适用《中华人民共和国民法典》时间效力的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-shijian/3.html

民法典施行前的法律事实引起的民事纠纷案件，当时的法律、司法解释没有规定而民法典有规定的，可以适用民法典的规定，但是明显减损当事人合法权益、增加当事人法定义务或者背离当事人合理预期的除外。
