# 兽药管理条例第五十条

- 法规：兽药管理条例（现行有效，施行日期 2020-03-27）
- 章节：第七章兽药监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ffc3781ba/50.html

国家实行兽药不良反应报告制度。
兽药生产企业、经营企业、兽药使用单位和开具处方的兽医人员发现可能与兽药使用有关的严重不良反应，应当立即向所在地人民政府兽医行政管理部门报告。
