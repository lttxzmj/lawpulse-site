# 兽药管理条例第六十四条

- 法规：兽药管理条例（现行有效，施行日期 2020-03-27）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ffc3781ba/64.html

违反本条例规定，擅自转移、使用、销毁、销售被查封或者扣押的兽药及有关材料的，责令其停止违法行为，给予警告，并处5万元以上10万元以下罚款。
