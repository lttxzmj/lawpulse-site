# 森林草原防灭火条例第二十三条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第二章森林草原火灾的预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/23.html

国务院有关部门和县级以上地方人民政府应当按照国家有关规定，加强防火道、隔离带、通信基站、应急广播、瞭望塔、应急水源（储水）等基础设施建设，推动防灭火装备转型升级，建立健全森林草原防灭火物资储备保障体系，及时补充更新防灭火物资。
