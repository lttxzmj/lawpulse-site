# 森林草原防灭火条例第五十条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第四章灾后处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/50.html

森林草原火灾发生后，森林、林木、林地、草原经营单位和个人应当及时采取更新造林等措施，恢复火烧迹地森林植被和林业、牧业生产条件，当地人民政府应当为森林草原资源的灾后恢复提供必要支持。
