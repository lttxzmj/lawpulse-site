# 森林草原防灭火条例第二十二条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第二章森林草原火灾的预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/22.html

专职或者兼职护林员、草管员负责巡护森林草原，发现火情应当及时处理并按照有关规定报告，做好防火宣传，并协助有关部门调查森林草原火灾案件。
