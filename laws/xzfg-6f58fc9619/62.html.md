# 森林草原防灭火条例第六十二条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/62.html

对设在林牧区的军事设施、军工设施的森林草原防灭火工作，以及军事区域森林草原防灭火基础设施建设、设施设备配备工作，军事法规、规章另有规定的，从其规定。
中国人民解放军、中国人民武装警察部队和民兵组织执行森林草原火灾扑救任务的，依照有关法律法规的规定执行。
