# 森林草原防灭火条例第二十八条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第二章森林草原火灾的预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/28.html

防火期内，森林、林木、林地、草原经营单位和个人应当在防火区内设置防火警示宣传标志或者设备，并向进入其经营区域的人员告知防火注意事项。
防火期内，进入防火区的各种机动车辆和机械设备应当按照规定安装防火装置、配备灭火器材。在防火区内野外作业的机械设备，应当采取防火措施；作业人员应当遵守防火安全操作规程，防止失火。
