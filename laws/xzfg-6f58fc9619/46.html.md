# 森林草原防灭火条例第四十六条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第四章灾后处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/46.html

县级以上人民政府应当组织有关部门及时对森林草原火灾发生原因、受害面积和蓄积、人员伤亡、其他经济损失、生态环境影响以及应急救援处置等情况进行调查评估，并形成调查评估报告。森林草原火灾有责任单位、责任人的，当地人民政府应当根据调查评估报告确定火灾责任单位、责任人，并依法处理。
森林草原火灾调查评估工作按照国家有关规定执行。森林草原火灾损失评估标准，由国务院林业草原主管部门会同有关部门制定。
