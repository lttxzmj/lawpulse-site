# 森林草原防灭火条例第三条

- 法规：森林草原防灭火条例（现行有效，施行日期 2026-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6f58fc9619/3.html

森林草原防灭火工作应当贯彻党和国家路线方针政策、决策部署。
森林草原防灭火工作应当坚持预防为主、积极消灭、生命至上、安全第一的工作方针，坚持协调联动、分级负责、属地为主、科学扑救、快速反应、安全高效的原则。
