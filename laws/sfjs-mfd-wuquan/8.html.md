# 最高人民法院关于适用《中华人民共和国民法典》物权编的解释（一）第八条

- 法规：最高人民法院关于适用《中华人民共和国民法典》物权编的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-wuquan/8.html

依据民法典第二百二十九条至第二百三十一条规定享有物权，但尚未完成动产交付或者不动产登记的权利人，依据民法典第二百三十五条至第二百三十八条的规定，请求保护其物权的，应予支持。
