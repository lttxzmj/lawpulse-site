# 最高人民法院关于适用《中华人民共和国民法典》物权编的解释（一）第三条

- 法规：最高人民法院关于适用《中华人民共和国民法典》物权编的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-wuquan/3.html

异议登记因民法典第二百二十条第二款规定的事由失效后，当事人提起民事诉讼，请求确认物权归属的，应当依法受理。异议登记失效不影响人民法院对案件的实体审理。
