# 中华人民共和国水文条例第一条

- 法规：中华人民共和国水文条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd196f0a17/1.html

为了加强水文管理，规范水文工作，为开发、利用、节约、保护水资源和防灾减灾服务，促进经济社会的可持续发展，根据《中华人民共和国水法》和《中华人民共和国防洪法》，制定本条例。
