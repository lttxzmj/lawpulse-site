# 中华人民共和国水文条例第三十三条

- 法规：中华人民共和国水文条例（现行有效）
- 章节：第五章设施与监测环境保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd196f0a17/33.html

在国家基本水文测站上下游建设影响水文监测的工程，建设单位应当采取相应措施，在征得对该站有管理权限的水行政主管部门同意后方可建设。因工程建设致使水文测站改建的，所需费用由建设单位承担。
