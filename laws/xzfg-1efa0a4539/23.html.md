# 棉花质量监督管理条例第二十三条

- 法规：棉花质量监督管理条例（现行有效）
- 章节：第三章棉花质量监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1efa0a4539/23.html

经国务院质量监督检验检疫部门认可的其他纤维检验机构，可以受委托从事棉花质量检验业务。具体办法由国务院质量监督检验检疫部门会同国务院有关部门规定。
