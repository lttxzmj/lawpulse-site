# 棉花质量监督管理条例第二十九条

- 法规：棉花质量监督管理条例（现行有效）
- 章节：第四章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1efa0a4539/29.html

棉花经营者违反本条例第十一条的规定，伪造、变造、冒用棉花质量凭证、标识、公证检验证书、公证检验标志的，由棉花质量监督机构处5万元以上10万元以下的罚款；情节严重的，移送工商行政管理机关吊销营业执照；构成犯罪的，依法追究刑事责任。
