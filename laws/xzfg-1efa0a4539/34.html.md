# 棉花质量监督管理条例第三十四条

- 法规：棉花质量监督管理条例（现行有效）
- 章节：第四章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1efa0a4539/34.html

政府机关及其工作人员违反本条例第十条第四款的规定，强令将未经公证检验的棉花作为国家储备棉入库、出库的，对负责的主管人员和其他直接责任人员依法给予降级或者撤职的行政处分。
