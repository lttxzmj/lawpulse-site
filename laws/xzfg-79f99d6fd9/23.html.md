# 村庄和集镇规划建设管理条例第二十三条

- 法规：村庄和集镇规划建设管理条例（现行有效）
- 章节：第四章村庄和集镇建设的设计、施工管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-79f99d6fd9/23.html

承担村庄、集镇规划区内建筑工程施工任务的单位，必须具有相应的施工资质等级证书或者资质审查证书，并按照规定的经营范围承担施工任务。
在村庄、集镇规划区内从事建筑施工的个体工匠，除承担房屋修缮外，须按有关规定办理施工资质审批手续。
