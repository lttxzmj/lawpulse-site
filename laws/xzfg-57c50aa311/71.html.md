# 中华人民共和国电信条例第七十一条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/71.html

违反本条例第四十一条的规定，在电信业务经营活动中进行不正当竞争的，由国务院信息产业主管部门或者省、自治区、直辖市电信管理机构依据职权责令改正，处10万元以上100万元以下罚款；情节严重的，责令停业整顿。
