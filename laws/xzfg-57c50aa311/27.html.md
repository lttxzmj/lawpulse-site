# 中华人民共和国电信条例第二十七条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第二章电信市场 · 第四节电信资源
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/27.html

电信业务经营者占有、使用电信资源，应当缴纳电信资源费。具体收费办法由国务院信息产业主管部门会同国务院财政部门、价格主管部门制定，报国务院批准后公布施行。
