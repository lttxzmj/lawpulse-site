# 中华人民共和国电信条例第五十一条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第四章电信建设 · 第一节电信设施建设
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/51.html

任何组织或者个人不得阻止或者妨碍基础电信业务经营者依法从事电信设施建设和向电信用户提供公共电信服务；但是，国家规定禁止或者限制进入的区域除外。
