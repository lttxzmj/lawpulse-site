# 中华人民共和国电信条例第四十二条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第三章电信服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/42.html

国务院信息产业主管部门或者省、自治区、直辖市电信管理机构应当依据职权对电信业务经营者的电信服务质量和经营活动进行监督检查，并向社会公布监督抽查结果。
