# 中华人民共和国电信条例第六十四条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第五章电信安全
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/64.html

在中华人民共和国境内从事国际通信业务，必须通过国务院信息产业主管部门批准设立的国际通信出入口局进行。
我国内地与香港特别行政区、澳门特别行政区和台湾地区之间的通信，参照前款规定办理。
