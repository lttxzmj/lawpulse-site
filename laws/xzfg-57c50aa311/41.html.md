# 中华人民共和国电信条例第四十一条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第三章电信服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/41.html

电信业务经营者在电信业务经营活动中，不得有下列行为：
(一)以任何方式限制电信用户选择其他电信业务经营者依法开办的电信服务；
(二)对其经营的不同业务进行不合理的交叉补贴；
(三)以排挤竞争对手为目的，低于成本提供电信业务或者服务，进行不正当竞争。
