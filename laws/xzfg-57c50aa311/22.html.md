# 中华人民共和国电信条例第二十二条

- 法规：中华人民共和国电信条例（现行有效）
- 章节：第二章电信市场 · 第二节电信网间互联
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-57c50aa311/22.html

网间互联的费用结算与分摊应当执行国家有关规定，不得在规定标准之外加收费用。
网间互联的技术标准、费用结算办法和具体管理规定，由国务院信息产业主管部门制定。
