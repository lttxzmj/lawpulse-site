# 国内水路运输管理条例第三十八条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/38.html

水路运输经营者有下列情形之一的，由海事管理机构依法予以处罚：
（一）未按照规定配备船员或者未使船舶处于适航状态；
（二）超越船舶核定载客定额或者核定载重量载运旅客或者货物；
（三）使用货船载运旅客；
（四）使用未取得危险货物适装证书的船舶运输危险货物。
