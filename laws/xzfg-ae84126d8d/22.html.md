# 国内水路运输管理条例第二十二条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第三章水路运输经营活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/22.html

货物班轮运输业务经营者应当在班轮航线开航的7日前，公布所使用的船舶以及班期、班次和运价。
货物班轮运输应当按照公布的班期、班次运行；变更班期、班次、运价或者停止经营部分或者全部班轮航线的，应当在7日前向社会公布。
