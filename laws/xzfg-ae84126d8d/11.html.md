# 国内水路运输管理条例第十一条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第二章水路运输经营者
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/11.html

外国的企业、其他经济组织和个人不得经营水路运输业务，也不得以租用中国籍船舶或者舱位等方式变相经营水路运输业务。
香港特别行政区、澳门特别行政区和台湾地区的企业、其他经济组织以及个人参照适用前款规定，国务院另有规定的除外。
