# 国内水路运输管理条例第二十条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第三章水路运输经营活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/20.html

水路运输经营者运输危险货物，应当遵守法律、行政法规以及国务院交通运输主管部门关于危险货物运输的规定，使用依法取得危险货物适装证书的船舶，按照规定的安全技术规范进行配载和运输，保证运输安全。
