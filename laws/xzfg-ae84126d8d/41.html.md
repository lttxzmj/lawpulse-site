# 国内水路运输管理条例第四十一条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/41.html

旅客班轮运输业务经营者自取得班轮航线经营许可之日起60日内未开航的，由负责水路运输管理的部门责令改正；拒不改正的，由原许可机关撤销该项经营许可。
