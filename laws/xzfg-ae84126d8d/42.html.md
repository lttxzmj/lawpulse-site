# 国内水路运输管理条例第四十二条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/42.html

水路运输、船舶管理业务经营者取得许可后，不再具备本条例规定的许可条件的，由负责水路运输管理的部门责令限期整改；在规定期限内整改仍不合格的，由原许可机关撤销其经营许可。
