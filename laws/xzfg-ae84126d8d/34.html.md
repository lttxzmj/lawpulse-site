# 国内水路运输管理条例第三十四条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/34.html

水路运输经营者使用未取得船舶营运证件的船舶从事水路运输的，由负责水路运输管理的部门责令该船停止经营，没收违法所得，并处违法所得1倍以上5倍以下的罚款；没有违法所得或者违法所得不足2万元的，处2万元以上10万元以下的罚款。
