# 国内水路运输管理条例第二十一条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第三章水路运输经营活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/21.html

旅客班轮运输业务经营者应当自取得班轮航线经营许可之日起60日内开航，并在开航15日前公布所使用的船舶、班期、班次、运价等信息。
旅客班轮运输应当按照公布的班期、班次运行；变更班期、班次、运价的，应当在15日前向社会公布；停止经营部分或者全部班轮航线的，应当在30日前向社会公布并报原许可机关备案。
