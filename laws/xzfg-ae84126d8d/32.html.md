# 国内水路运输管理条例第三十二条

- 法规：国内水路运输管理条例（现行有效，施行日期 2023-07-20）
- 章节：第四章水路运输辅助业务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ae84126d8d/32.html

本条例第十二条、第十七条的规定适用于船舶管理业务经营者。本条例第十一条、第二十四条的规定适用于船舶管理、船舶代理、水路旅客运输代理和水路货物运输代理业务经营活动。
国务院交通运输主管部门应当依照本条例的规定制定水路运输辅助业务的具体管理办法。
