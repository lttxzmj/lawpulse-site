# 放射性同位素与射线装置安全和防护条例第二十五条

- 法规：放射性同位素与射线装置安全和防护条例（现行有效）
- 章节：第二章许可和备案
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-34457dbf56/25.html

使用放射性同位素的单位需要将放射性同位素转移到外省、自治区、直辖市使用的，应当持许可证复印件向使用地省、自治区、直辖市人民政府生态环境主管部门备案，并接受当地生态环境主管部门的监督管理。
