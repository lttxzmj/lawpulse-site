# 放射性同位素与射线装置安全和防护条例第二十八条

- 法规：放射性同位素与射线装置安全和防护条例（现行有效）
- 章节：第三章安全和防护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-34457dbf56/28.html

生产、销售、使用放射性同位素和射线装置的单位，应当对直接从事生产、销售、使用活动的工作人员进行安全和防护知识教育培训，并进行考核；考核不合格的，不得上岗。
辐射安全关键岗位应当由注册核安全工程师担任。辐射安全关键岗位名录由国务院生态环境主管部门商国务院有关部门制定并公布。
