# 放射性同位素与射线装置安全和防护条例第二十三条

- 法规：放射性同位素与射线装置安全和防护条例（现行有效）
- 章节：第二章许可和备案
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-34457dbf56/23.html

持有放射源的单位将废旧放射源交回生产单位、返回原出口方或者送交放射性废物集中贮存单位贮存的，应当在该活动完成之日起20日内向其所在地省、自治区、直辖市人民政府生态环境主管部门备案。
