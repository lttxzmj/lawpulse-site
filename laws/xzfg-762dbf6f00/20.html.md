# 中华人民共和国知识产权海关保护条例第二十条

- 法规：中华人民共和国知识产权海关保护条例（现行有效）
- 章节：第三章扣留侵权嫌疑货物的申请及其处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-762dbf6f00/20.html

海关发现进出口货物有侵犯备案知识产权嫌疑并通知知识产权权利人后，知识产权权利人请求海关扣留侵权嫌疑货物的，海关应当自扣留之日起30个工作日内对被扣留的侵权嫌疑货物是否侵犯知识产权进行调查、认定；不能认定的，应当立即书面通知知识产权权利人。
