# 上海航运交易所管理规定第七条

- 法规：上海航运交易所管理规定（现行有效）
- 章节：第二章组织机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-91e52eb2b0/7.html

理事会行使下列职权：
(一)制定航运交易所章程、交易规则及其他有关规定；
(二)审议航运交易所的工作计划和工作报告；
(三)决定、处理航运交易所运作中的重大问题；
(四)聘任、解聘航运交易所总裁、副总裁；
(五)决定取消会员资格。
