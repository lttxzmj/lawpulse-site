# 企业信息公示暂行条例第三条

- 法规：企业信息公示暂行条例（现行有效，施行日期 2024-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f31147af3b/3.html

企业信息公示应当真实、及时。公示的企业信息涉及国家秘密、国家安全或者社会公共利益的，应当报请主管的保密行政管理部门或者国家安全机关批准。县级以上地方人民政府有关部门公示的企业信息涉及企业商业秘密或者个人隐私的，应当报请上级主管部门批准。
