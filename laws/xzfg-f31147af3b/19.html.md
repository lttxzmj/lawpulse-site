# 企业信息公示暂行条例第十九条

- 法规：企业信息公示暂行条例（现行有效，施行日期 2024-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f31147af3b/19.html

县级以上地方人民政府及其有关部门应当建立健全信用约束机制，在政府采购、工程招投标、国有土地出让、授予荣誉称号等工作中，将企业信息作为重要考量因素，对被列入经营异常名录或者市场监督管理严重违法失信名单的企业依法予以限制或者禁入。
