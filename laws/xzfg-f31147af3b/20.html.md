# 企业信息公示暂行条例第二十条

- 法规：企业信息公示暂行条例（现行有效，施行日期 2024-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f31147af3b/20.html

鼓励企业主动纠正违法失信行为、消除不良影响，依法申请修复失信记录。政府部门依法解除相关管理措施并修复失信记录的，应当及时将上述信息与有关部门共享。
