# 野生药材资源保护管理条例第七条

- 法规：野生药材资源保护管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3649e33896/7.html

采猎、收购二、三级保护野生药材物种的，必须按照批准的计划执行。该计划由县以上(含县，下同)医药管理部门(含当地人民政府授权管理该项工作的有关部门，下同)会同同级野生动物、植物管理部门制定，报上一级医药管理部门批准。
