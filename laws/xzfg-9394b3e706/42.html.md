# 中华人民共和国审计法实施条例第四十二条

- 法规：中华人民共和国审计法实施条例（现行有效）
- 章节：第五章审计程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9394b3e706/42.html

被审计单位应当按照审计机关规定的期限和要求执行审计决定。对应当上缴的款项，被审计单位应当按照财政管理体制和国家有关规定缴入国库或者财政专户。审计决定需要有关主管机关、单位协助执行的，审计机关应当书面提请协助执行。
