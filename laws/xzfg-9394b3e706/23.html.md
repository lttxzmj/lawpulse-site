# 中华人民共和国审计法实施条例第二十三条

- 法规：中华人民共和国审计法实施条例（现行有效）
- 章节：第三章审计机关职责
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9394b3e706/23.html

审计机关可以依照审计法和本条例规定的审计程序、方法以及国家其他有关规定，对预算管理或者国有资产管理使用等与国家财政收支有关的特定事项，向有关地方、部门、单位进行专项审计调查。
