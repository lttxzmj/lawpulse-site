# 中华人民共和国审计法实施条例第二十八条

- 法规：中华人民共和国审计法实施条例（现行有效）
- 章节：第四章审计机关权限
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9394b3e706/28.html

审计机关依法进行审计监督时，被审计单位应当依照审计法第三十一条规定，向审计机关提供与财政收支、财务收支有关的资料。被审计单位负责人应当对本单位提供资料的真实性和完整性作出书面承诺。
