# 保税区海关监管办法第二十二条

- 法规：保税区海关监管办法（现行有效）
- 章节：第五章对保税区加工贸易货物的管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-419af9b6a8/22.html

区内加工企业全部用境外运入料、件加工的制成品销往非保税区时，海关按照进口制成品征税。
用含有境外运入料、件加工的制成品销往非保税区时，海关对其制成品按照所含境外运入料、件征税；对所含境外运入料、件的品名、数量、价值申报不实的，海关按照进口制成品征税。
