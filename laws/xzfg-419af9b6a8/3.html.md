# 保税区海关监管办法第三条

- 法规：保税区海关监管办法（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-419af9b6a8/3.html

保税区是海关监管的特定区域。海关依照本办法对进出保税区的货物、运输工具、个人携带物品实施监管。
保税区与中华人民共和国境内的其他地区(以下简称非保税区)之间，应当设置符合海关监管要求的隔离设施。
