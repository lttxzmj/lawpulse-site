# 保税区海关监管办法第二十七条

- 法规：保税区海关监管办法（现行有效）
- 章节：第六章对进出保税区运输工具和个人携带物品的监管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-419af9b6a8/27.html

未经海关批准，从保税区到非保税区的运输工具和人员不得运输、携带保税区内的免税货物、物品，保税货物，以及用保税料、件生产的产品。
