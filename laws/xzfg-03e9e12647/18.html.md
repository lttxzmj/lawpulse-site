# 中华人民共和国矿山安全法实施条例第十八条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第三章矿山开采的安全保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/18.html

煤矿和其他有瓦斯爆炸可能性的矿井，应当严格执行瓦斯检查制度，任何人不得携带烟草和点火用具下井。
