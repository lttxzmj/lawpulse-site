# 中华人民共和国矿山安全法实施条例第三条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/3.html

国家采取政策和措施，支持发展矿山安全教育，鼓励矿山安全开采技术、安全管理方法、安全设备与仪器的研究和推广，促进矿山安全科学技术进步。
