# 中华人民共和国矿山安全法实施条例第五十一条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第六章矿山事故处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/51.html

矿山事故调查处理工作应当自事故发生之日起90日内结束；遇有特殊情况，可以适当延长，但是不得超过180日。矿山事故处理结案后，应当公布处理结果。
