# 中华人民共和国矿山安全法实施条例第二十八条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第四章矿山企业的安全管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/28.html

矿山企业应当建立、健全下列安全生产责任制：
(一)行政领导岗位安全生产责任制；
(二)职能机构安全生产责任制；
(三)岗位人员的安全生产责任制。
