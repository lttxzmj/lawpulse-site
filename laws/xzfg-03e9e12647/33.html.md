# 中华人民共和国矿山安全法实施条例第三十三条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第四章矿山企业的安全管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/33.html

矿山企业职工应当履行下列义务：
(一)遵守有关矿山安全的法律、法规和企业规章制度；
(二)维护矿山企业的生产设备、设施；
(三)接受安全教育和培训；
(四)及时报告危险情况，参加抢险救护。
