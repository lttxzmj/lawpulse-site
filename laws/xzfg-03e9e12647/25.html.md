# 中华人民共和国矿山安全法实施条例第二十五条

- 法规：中华人民共和国矿山安全法实施条例（现行有效，施行日期 1996-10-30）
- 章节：第三章矿山开采的安全保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03e9e12647/25.html

矿山企业对地面、井下产生粉尘的作业，应当采取综合防尘措施，控制粉尘危害。
井下风动凿岩，禁止干打眼。
