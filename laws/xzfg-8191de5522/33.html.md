# 黄河水量调度条例第三十三条

- 法规：黄河水量调度条例（现行有效，施行日期 2026-08-15）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8191de5522/33.html

黄河水利委员会及其所属管理机构、县级以上地方人民政府水行政主管部门实施监督检查时，有权采取下列措施：
（一）要求被检查单位提供有关文件和资料，进行查阅或者复制；
（二）要求被检查单位就执行本条例的有关问题进行说明；
（三）进入被检查单位生产场所进行现场检查；
（四）对取（退）水量进行现场监测；
（五）责令被检查单位纠正违反本条例的行为。
