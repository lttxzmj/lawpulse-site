# 黄河水量调度条例第二十三条

- 法规：黄河水量调度条例（现行有效，施行日期 2026-08-15）
- 章节：第四章应急调度
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8191de5522/23.html

十一省区市人民政府水行政主管部门和河南、山东黄河河务局以及水库管理单位，应当根据经批准的旱情紧急情况下的水量调度预案，制订实施方案，并抄送黄河水利委员会。
