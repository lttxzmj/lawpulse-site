# 煤矿安全生产条例第五十九条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/59.html

发生煤矿生产安全事故后，煤矿企业及其负责人应当迅速采取有效措施组织抢救，并依照《生产安全事故报告和调查处理条例》的规定立即如实向当地应急管理部门、负有煤矿安全生产监督管理职责的部门和所在地矿山安全监察机构报告。
国家矿山安全监察机构及其设在地方的矿山安全监察机构应当根据事故等级和工作需要，派出工作组赶赴事故现场，指导配合事故发生地地方人民政府开展应急救援工作。
