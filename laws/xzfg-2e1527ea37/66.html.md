# 煤矿安全生产条例第六十六条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/66.html

煤矿企业有下列行为之一的，责令改正；拒不改正的，处10万元以上20万元以下的罚款；对其直接负责的主管人员和其他直接责任人员处1万元以上2万元以下的罚款：
（一）违反本条例第三十七条第一款规定，隐瞒存在的事故隐患以及其他安全问题的；
（二）违反本条例第四十四条第一款规定，擅自启封或者使用被查封、扣押的设施、设备、器材的；
（三）有其他拒绝、阻碍监督检查行为的。
