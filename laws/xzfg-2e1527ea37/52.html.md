# 煤矿安全生产条例第五十二条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/52.html

国家矿山安全监察机构及其设在地方的矿山安全监察机构对县级以上地方人民政府煤矿安全生产监督管理工作进行监督检查，可以采取以下方式：
（一）听取有关地方人民政府及其负有煤矿安全生产监督管理职责的部门工作汇报；
（二）调阅、复制与煤矿安全生产有关的文件、档案、工作记录等资料；
（三）要求有关地方人民政府及其负有煤矿安全生产监督管理职责的部门和有关人员就煤矿安全生产工作有关问题作出说明；
（四）有必要采取的其他方式。
