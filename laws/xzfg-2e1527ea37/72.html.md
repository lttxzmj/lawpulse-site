# 煤矿安全生产条例第七十二条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/72.html

承担安全评价、认证、检测、检验等职责的煤矿安全生产技术服务机构有出具失实报告、租借资质、挂靠、出具虚假报告等情形的，对该机构及直接负责的主管人员和其他直接责任人员，应当依照《中华人民共和国安全生产法》有关规定予以处罚并追究相应责任。其主要负责人对重大、特别重大煤矿生产安全事故负有责任的，终身不得从事煤矿安全生产相关技术服务工作。
