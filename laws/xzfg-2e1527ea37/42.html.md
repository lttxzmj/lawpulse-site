# 煤矿安全生产条例第四十二条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第三章煤矿安全生产监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/42.html

省、自治区、直辖市人民政府负有煤矿安全生产监督管理职责的部门负责煤矿企业安全生产许可证的颁发和管理，并接受国家矿山安全监察机构及其设在地方的矿山安全监察机构的监督。
