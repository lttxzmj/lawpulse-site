# 煤矿安全生产条例第六十一条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/61.html

未依法取得安全生产许可证等擅自进行煤矿生产的，应当责令立即停止生产，没收违法所得和开采出的煤炭以及采掘设备；违法所得在10万元以上的，并处违法所得2倍以上5倍以下的罚款；没有违法所得或者违法所得不足10万元的，并处10万元以上20万元以下的罚款。
关闭的煤矿企业擅自恢复生产的，依照前款规定予以处罚。
