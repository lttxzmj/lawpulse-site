# 煤矿安全生产条例第四十条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第三章煤矿安全生产监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/40.html

省、自治区、直辖市人民政府应当按照分级分类监管的原则，明确煤矿企业的安全生产监管主体。
县级以上人民政府相关主管部门对未依法取得安全生产许可证等擅自进行煤矿生产的，应当依法查处。
乡镇人民政府在所辖区域内发现未依法取得安全生产许可证等擅自进行煤矿生产的，应当采取有效措施制止，并向县级人民政府相关主管部门报告。
