# 煤矿安全生产条例第五十八条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/58.html

国家矿山安全监察机构及其设在地方的矿山安全监察机构依法对煤矿企业贯彻执行安全生产法律法规、煤矿安全规程以及保障安全生产的国家标准或者行业标准的情况进行监督检查，行使本条例第四十四条规定的职权。
