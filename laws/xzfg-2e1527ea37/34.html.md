# 煤矿安全生产条例第三十四条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第二章煤矿企业的安全生产责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/34.html

在煤矿进行石门揭煤、探放水、巷道贯通、清理煤仓、强制放顶、火区密闭和启封、动火以及国家矿山安全监察机构规定的其他危险作业，应当采取专门安全技术措施，并安排专门人员进行现场安全管理。
