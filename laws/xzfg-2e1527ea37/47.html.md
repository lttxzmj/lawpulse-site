# 煤矿安全生产条例第四十七条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第三章煤矿安全生产监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/47.html

县级以上人民政府及其有关部门对存在安全生产失信行为的煤矿企业、煤矿安全生产技术服务机构及有关从业人员，依法依规实施失信惩戒。
