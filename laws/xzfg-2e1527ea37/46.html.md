# 煤矿安全生产条例第四十六条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第三章煤矿安全生产监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/46.html

县级以上地方人民政府负有煤矿安全生产监督管理职责的部门应当加强对煤矿安全生产技术服务机构的监管。
承担安全评价、认证、检测、检验等职责的煤矿安全生产技术服务机构应当依照有关法律法规和国家标准或者行业标准的规定开展安全生产技术服务活动，并对出具的报告负责，不得租借资质、挂靠、出具虚假报告。
