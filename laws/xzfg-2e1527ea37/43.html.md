# 煤矿安全生产条例第四十三条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第三章煤矿安全生产监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/43.html

县级以上地方人民政府负有煤矿安全生产监督管理职责的部门应当编制煤矿安全生产年度监督检查计划，并按照计划进行监督检查。
煤矿安全生产年度监督检查计划应当抄送所在地矿山安全监察机构。
