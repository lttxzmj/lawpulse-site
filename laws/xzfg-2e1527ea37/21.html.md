# 煤矿安全生产条例第二十一条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第二章煤矿企业的安全生产责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/21.html

煤矿企业主要负责人和安全生产管理人员应当通过安全生产知识和管理能力考核，并持续保持相应水平和能力。
煤矿企业从业人员经安全生产教育和培训合格，方可上岗作业。煤矿企业特种作业人员应当按照国家有关规定经专门的安全技术培训和考核合格，并取得相应资格。
