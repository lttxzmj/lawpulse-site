# 煤矿安全生产条例第六十七条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/67.html

发生煤矿生产安全事故，对负有责任的煤矿企业除要求其依法承担相应的赔偿等责任外，依照下列规定处以罚款：
（一）发生一般事故的，处50万元以上100万元以下的罚款；
（二）发生较大事故的，处150万元以上200万元以下的罚款；
（三）发生重大事故的，处500万元以上1000万元以下的罚款；
（四）发生特别重大事故的，处1000万元以上2000万元以下的罚款。
发生煤矿生产安全事故，情节特别严重、影响特别恶劣的，可以按照前款罚款数额的2倍以上5倍以下对负有责任的煤矿企业处以罚款。
