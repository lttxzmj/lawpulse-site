# 煤矿安全生产条例第五十一条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/51.html

设在地方的矿山安全监察机构应当对所辖区域内煤矿安全生产实施监察；对事故多发地区，应当实施重点监察。国家矿山安全监察机构根据实际情况，组织对全国煤矿安全生产的全面监察或者重点监察。
