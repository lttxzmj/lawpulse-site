# 煤矿安全生产条例第二十八条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第二章煤矿企业的安全生产责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/28.html

露天煤矿的采场及排土场边坡与重要建筑物、构筑物之间应当留有足够的安全距离。
煤矿企业应当定期对露天煤矿进行边坡稳定性评价，评价范围应当涵盖露天煤矿所有边坡。达不到边坡稳定要求时，应当修改采矿设计或者采取安全措施，同时加强边坡监测工作。
