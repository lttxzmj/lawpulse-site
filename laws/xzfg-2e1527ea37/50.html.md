# 煤矿安全生产条例第五十条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/50.html

国家矿山安全监察机构及其设在地方的矿山安全监察机构应当依法履行煤矿安全监察职责，对县级以上地方人民政府煤矿安全生产监督管理工作加强监督检查，并及时向有关地方人民政府通报监督检查的情况，提出改善和加强煤矿安全生产工作的监察意见和建议，督促开展重大事故隐患整改和复查。
县级以上地方人民政府应当配合和接受国家矿山安全监察机构及其设在地方的矿山安全监察机构的监督检查，及时落实监察意见和建议。
