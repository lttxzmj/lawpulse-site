# 煤矿安全生产条例第六十四条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/64.html

对存在重大事故隐患仍然进行生产的煤矿企业，责令停产整顿，明确整顿的内容、时间等具体要求，并处50万元以上200万元以下的罚款；对煤矿企业主要负责人处3万元以上15万元以下的罚款。
