# 煤矿安全生产条例第五十四条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/54.html

国家矿山安全监察机构及其设在地方的矿山安全监察机构发现煤矿企业存在重大事故隐患责令停产整顿的，应当及时移送县级以上地方人民政府负有煤矿安全生产监督管理职责的部门处理并进行督办。
