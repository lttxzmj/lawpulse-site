# 煤矿安全生产条例第六十条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第四章煤矿安全监察
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/60.html

煤矿生产安全事故按照事故等级实行分级调查处理。
特别重大事故由国务院或者国务院授权有关部门依照《生产安全事故报告和调查处理条例》的规定组织调查处理。重大事故、较大事故、一般事故由国家矿山安全监察机构及其设在地方的矿山安全监察机构依照《生产安全事故报告和调查处理条例》的规定组织调查处理。
