# 煤矿安全生产条例第三十三条

- 法规：煤矿安全生产条例（现行有效，施行日期 2024-05-01）
- 章节：第二章煤矿企业的安全生产责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2e1527ea37/33.html

煤矿开采有下列情形之一的，应当编制专项设计：
（一）有煤（岩）与瓦斯（二氧化碳）突出的；
（二）有冲击地压危险的；
（三）开采需要保护的建筑物、水体、铁路下压煤或者主要井巷留设煤柱的；
（四）水文地质类型复杂、极复杂或者周边有老窑采空区的；
（五）开采容易自燃和自燃煤层的；
（六）其他需要编制专项设计的。
