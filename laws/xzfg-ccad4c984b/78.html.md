# 中华人民共和国政府采购法实施条例第七十八条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第九章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/78.html

财政管理实行省直接管理的县级人民政府可以根据需要并报经省级人民政府批准，行使政府采购法和本条例规定的设区的市级人民政府批准变更采购方式的职权。
