# 中华人民共和国政府采购法实施条例第二十八条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第三章政府采购方式
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/28.html

在一个财政年度内，采购人将一个预算项目下的同一品目或者类别的货物、服务采用公开招标以外的方式多次采购，累计资金数额超过公开招标数额标准的，属于以化整为零方式规避公开招标，但项目预算调整或者经批准采用公开招标以外方式采购除外。
