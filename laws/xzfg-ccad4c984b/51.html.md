# 中华人民共和国政府采购法实施条例第五十一条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第五章政府采购合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/51.html

采购人应当按照政府采购合同规定，及时向中标或者成交供应商支付采购资金。
政府采购项目资金支付程序，按照国家有关财政资金支付管理的规定执行。
