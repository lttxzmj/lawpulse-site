# 中华人民共和国政府采购法实施条例第二十七条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第三章政府采购方式
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/27.html

政府采购法第三十一条第一项规定的情形，是指因货物或者服务使用不可替代的专利、专有技术，或者公共服务项目具有特殊要求，导致只能从某一特定供应商处采购。
