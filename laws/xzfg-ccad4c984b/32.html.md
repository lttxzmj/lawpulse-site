# 中华人民共和国政府采购法实施条例第三十二条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第四章政府采购程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/32.html

采购人或者采购代理机构应当按照国务院财政部门制定的招标文件标准文本编制招标文件。
招标文件应当包括采购项目的商务条件、采购需求、投标人的资格条件、投标报价要求、评标方法、评标标准以及拟签订的合同文本等。
