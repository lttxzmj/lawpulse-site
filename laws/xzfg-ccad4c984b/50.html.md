# 中华人民共和国政府采购法实施条例第五十条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第五章政府采购合同
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/50.html

采购人应当自政府采购合同签订之日起2个工作日内，将政府采购合同在省级以上人民政府财政部门指定的媒体上公告，但政府采购合同中涉及国家秘密、商业秘密的内容除外。
