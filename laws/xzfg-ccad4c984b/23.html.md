# 中华人民共和国政府采购法实施条例第二十三条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第三章政府采购方式
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/23.html

采购人采购公开招标数额标准以上的货物或者服务，符合政府采购法第二十九条、第三十条、第三十一条、第三十二条规定情形或者有需要执行政府采购政策等特殊情况的，经设区的市级以上人民政府财政部门批准，可以依法采用公开招标以外的采购方式。
