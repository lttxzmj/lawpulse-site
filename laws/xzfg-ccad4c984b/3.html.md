# 中华人民共和国政府采购法实施条例第三条

- 法规：中华人民共和国政府采购法实施条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ccad4c984b/3.html

集中采购目录包括集中采购机构采购项目和部门集中采购项目。
技术、服务等标准统一，采购人普遍使用的项目，列为集中采购机构采购项目；采购人本部门、本系统基于业务需要有特殊要求，可以统一采购的项目，列为部门集中采购项目。
