# 商用密码管理条例第二十三条

- 法规：商用密码管理条例（现行有效，施行日期 2023-07-01）
- 章节：第四章电子认证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9570439875/23.html

电子认证服务机构应当按照法律、行政法规和电子认证服务密码使用技术规范、规则，使用密码提供电子认证服务，保证其电子认证服务密码使用持续符合要求。
电子认证服务密码使用技术规范、规则由国家密码管理部门制定并公布。
