# 最高人民法院关于适用《中华人民共和国民法典》继承编的解释（一）第二十二条

- 法规：最高人民法院关于适用《中华人民共和国民法典》继承编的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-jicheng/22.html

继承人有扶养能力和扶养条件，愿意尽扶养义务，但被继承人因有固定收入和劳动能力，明确表示不要求其扶养的，分配遗产时，一般不应因此而影响其继承份额。
