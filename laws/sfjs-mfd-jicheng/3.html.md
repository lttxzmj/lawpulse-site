# 最高人民法院关于适用《中华人民共和国民法典》继承编的解释（一）第三条

- 法规：最高人民法院关于适用《中华人民共和国民法典》继承编的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-jicheng/3.html

被继承人生前与他人订有遗赠扶养协议，同时又立有遗嘱的，继承开始后，如果遗赠扶养协议与遗嘱没有抵触，遗产分别按协议和遗嘱处理；如果有抵触，按协议处理，与协议抵触的遗嘱全部或者部分无效。
