# 中华人民共和国学前教育法第八十一条

- 法规：中华人民共和国学前教育法（现行有效，施行日期 2025-06-01）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-a6471adb19/81.html

在学前教育活动中违反本法规定的行为，本法未规定法律责任，《中华人民共和国教育法》、《中华人民共和国未成年人保护法》、《中华人民共和国劳动法》等法律、行政法规有规定的，依照其规定。
