# 最高人民法院关于审理涉及农村土地承包纠纷案件适用法律问题的解释第十三条

- 法规：最高人民法院关于审理涉及农村土地承包纠纷案件适用法律问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-10d585a2f7/13.html

承包方未经发包方同意，转让其土地承包经营权的，转让合同无效。但发包方无法定理由不同意或者拖延表态的除外。
