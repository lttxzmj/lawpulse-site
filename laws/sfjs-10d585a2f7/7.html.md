# 最高人民法院关于审理涉及农村土地承包纠纷案件适用法律问题的解释第七条

- 法规：最高人民法院关于审理涉及农村土地承包纠纷案件适用法律问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-10d585a2f7/7.html

承包合同约定或者土地承包经营权证等证书记载的承包期限短于农村土地承包法规定的期限，承包方请求延长的，应予支持。
