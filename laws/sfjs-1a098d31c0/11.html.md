# 最高人民法院关于审判人员在诉讼活动中执行回避制度若干问题的规定第十一条

- 法规：最高人民法院关于审判人员在诉讼活动中执行回避制度若干问题的规定（现行有效，施行日期 2011-06-13）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1a098d31c0/11.html

当事人及其法定代理人、诉讼代理人、辩护人认为审判人员有违反本规定行为的，可以向法院纪检、监察部门或者其他有关部门举报。受理举报的人民法院应当及时处理，并将相关意见反馈给举报人。
