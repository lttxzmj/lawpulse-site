# 粮食流通管理条例第三条

- 法规：粮食流通管理条例（现行有效，施行日期 2021-04-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-053420357c/3.html

国家鼓励多种所有制市场主体从事粮食经营活动，促进公平竞争。依法从事的粮食经营活动受国家法律保护。严禁以非法手段阻碍粮食自由流通。
国有粮食企业应当转变经营机制，提高市场竞争能力，在粮食流通中发挥主渠道作用，带头执行国家粮食政策。
