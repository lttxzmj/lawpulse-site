# 粮食流通管理条例第四十三条

- 法规：粮食流通管理条例（现行有效，施行日期 2021-04-15）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-053420357c/43.html

粮食收购企业未按照规定备案或者提供虚假备案信息的，由粮食和储备行政管理部门责令改正，给予警告；拒不改正的，处2万元以上5万元以下罚款。
