# 粮食流通管理条例第二十八条

- 法规：粮食流通管理条例（现行有效，施行日期 2021-04-15）
- 章节：第三章宏观调控
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-053420357c/28.html

国务院和地方人民政府建立健全粮食风险基金制度。粮食风险基金主要用于支持粮食储备、稳定粮食市场等。
国务院和地方人民政府财政部门负责粮食风险基金的监督管理，确保专款专用。
