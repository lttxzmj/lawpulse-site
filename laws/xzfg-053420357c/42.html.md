# 粮食流通管理条例第四十二条

- 法规：粮食流通管理条例（现行有效，施行日期 2021-04-15）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-053420357c/42.html

违反本条例规定，粮食和储备行政管理部门和其他有关部门不依法履行粮食流通管理和监督职责的，对负有责任的领导人员和直接责任人员依法给予处分。
