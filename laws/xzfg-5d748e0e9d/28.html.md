# 中华人民共和国注册建筑师条例第二十八条

- 法规：中华人民共和国注册建筑师条例（现行有效，施行日期 2026-03-20）
- 章节：第四章权利和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d748e0e9d/28.html

注册建筑师应当履行下列义务：
（一）遵守法律、法规和职业道德，维护社会公共利益；
（二）保证建筑设计的质量，并在其负责的设计图纸上签字；
（三）保守在执业中知悉的单位和个人的秘密；
（四）不得同时受聘于二个以上建筑设计单位执行业务；
（五）不得准许他人以本人名义执行业务。
