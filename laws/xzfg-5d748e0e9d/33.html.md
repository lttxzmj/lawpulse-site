# 中华人民共和国注册建筑师条例第三十三条

- 法规：中华人民共和国注册建筑师条例（现行有效，施行日期 2026-03-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d748e0e9d/33.html

违反本条例规定，未经注册建筑师同意擅自修改其设计图纸的，由县级以上人民政府建设行政主管部门责令纠正；造成损失的，应当承担赔偿责任。
