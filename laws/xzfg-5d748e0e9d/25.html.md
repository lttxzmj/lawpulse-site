# 中华人民共和国注册建筑师条例第二十五条

- 法规：中华人民共和国注册建筑师条例（现行有效，施行日期 2026-03-20）
- 章节：第四章权利和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5d748e0e9d/25.html

注册建筑师有权以注册建筑师的名义执行注册建筑师业务。
非注册建筑师不得以注册建筑师的名义执行注册建筑师业务。二级注册建筑师不得以一级注册建筑师的名义执行业务，也不得超越国家规定的二级注册建筑师的执业范围执行业务。
