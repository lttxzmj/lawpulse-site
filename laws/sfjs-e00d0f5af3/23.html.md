# 最高人民法院关于生态环境侵权民事诉讼证据的若干规定第二十三条

- 法规：最高人民法院关于生态环境侵权民事诉讼证据的若干规定（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e00d0f5af3/23.html

当事人就环境污染、生态破坏的专门性问题自行委托有关机构、人员出具的意见，人民法院应当结合本案的其他证据，审查确定能否作为认定案件事实的根据。
对方当事人对该意见有异议的，人民法院应当告知提供意见的当事人可以申请出具意见的机构或者人员出庭陈述意见；未出庭的，该意见不得作为认定案件事实的根据。
