# 最高人民法院、最高人民检察院关于修改《关于办理妨害信用卡管理刑事案件具体应用法律若干问题的解释》的决定第七条

- 法规：最高人民法院、最高人民检察院关于修改《关于办理妨害信用卡管理刑事案件具体应用法律若干问题的解释》的决定（现行有效，施行日期 2018-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8616d26d91/7.html

催收同时符合下列条件的，应当认定为本解释第六条规定的“有效催收”：
（一）在透支超过规定限额或者规定期限后进行；
（二）催收应当采用能够确认持卡人收悉的方式，但持卡人故意逃避催收的除外；
（三）两次催收至少间隔三十日；
（四）符合催收的有关规定或者约定。
对于是否属于有效催收，应当根据发卡银行提供的电话录音、信息送达记录、信函送达回执、电子邮件送达记录、持卡人或者其家属签字以及其他催收原始证据材料作出判断。
发卡银行提供的相关证据材料，应当有银行工作人员签名和银行公章。
