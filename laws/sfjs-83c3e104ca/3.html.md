# 最高人民法院关于审理生态环境侵权纠纷案件适用惩罚性赔偿的解释第三条

- 法规：最高人民法院关于审理生态环境侵权纠纷案件适用惩罚性赔偿的解释（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-83c3e104ca/3.html

被侵权人在生态环境侵权纠纷案件中请求惩罚性赔偿的，应当在起诉时明确赔偿数额以及所依据的事实和理由。
被侵权人在生态环境侵权纠纷案件中没有提出惩罚性赔偿的诉讼请求，诉讼终结后又基于同一污染环境、破坏生态事实另行起诉请求惩罚性赔偿的，人民法院不予受理。
