# 城市公共交通条例第二十八条

- 法规：城市公共交通条例（现行有效，施行日期 2024-12-01）
- 章节：第四章安全管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6991f258bb/28.html

城市公共交通企业应当遵守有关安全生产的法律、法规和标准，落实全员安全生产责任，建立健全安全生产管理制度和安全生产责任制，保障安全经费投入，构建安全风险分级管控和隐患排查治理双重预防机制，增强突发事件防范和应急能力。
