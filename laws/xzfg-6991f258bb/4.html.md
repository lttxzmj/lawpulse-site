# 城市公共交通条例第四条

- 法规：城市公共交通条例（现行有效，施行日期 2024-12-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6991f258bb/4.html

城市公共交通工作应当坚持中国共产党的领导，坚持以人民为中心，坚持城市公共交通公益属性，落实城市公共交通优先发展战略，构建安全、便捷、高效、绿色、经济的城市公共交通体系。
