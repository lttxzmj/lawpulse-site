# 城市公共交通条例第五十一条

- 法规：城市公共交通条例（现行有效，施行日期 2024-12-01）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6991f258bb/51.html

城市人民政府及其城市公共交通主管部门、其他有关部门的工作人员在城市公共交通工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分。
