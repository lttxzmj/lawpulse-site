# 城市公共交通条例第二十三条

- 法规：城市公共交通条例（现行有效，施行日期 2024-12-01）
- 章节：第三章运营服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6991f258bb/23.html

因大型群众性活动等情形出现公共交通客流集中、正常运营服务安排难以满足需求的，城市公共交通企业应当按照城市人民政府城市公共交通主管部门的要求，及时采取增开临时班次、缩短发车间隔、延长运营时间等措施，保障运营服务。
