# 行政事业性国有资产管理条例第二十六条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第三章预算管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/26.html

各部门及其所属单位应当及时收取各类资产收入，不得违反国家规定，多收、少收、不收、侵占、私分、截留、占用、挪用、隐匿、坐支。
