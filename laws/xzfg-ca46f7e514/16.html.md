# 行政事业性国有资产管理条例第十六条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第二章资产配置、使用和处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/16.html

各部门及其所属单位接受捐赠的资产，应当按照捐赠约定的用途使用。捐赠人意愿不明确或者没有约定用途的，应当统筹安排使用。
