# 行政事业性国有资产管理条例第四十三条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第五章资产报告
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/43.html

国家建立行政事业性国有资产管理情况报告制度。
国务院向全国人民代表大会常务委员会报告全国行政事业性国有资产管理情况。
县级以上地方人民政府按照规定向本级人民代表大会常务委员会报告行政事业性国有资产管理情况。
