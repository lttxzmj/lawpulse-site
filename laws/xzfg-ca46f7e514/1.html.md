# 行政事业性国有资产管理条例第一条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/1.html

为了加强行政事业性国有资产管理与监督，健全国有资产管理体制，推进国家治理体系和治理能力现代化，根据全国人民代表大会常务委员会关于加强国有资产管理情况监督的决定，制定本条例。
