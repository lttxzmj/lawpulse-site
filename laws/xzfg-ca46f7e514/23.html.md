# 行政事业性国有资产管理条例第二十三条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第二章资产配置、使用和处置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/23.html
