# 行政事业性国有资产管理条例第二十八条

- 法规：行政事业性国有资产管理条例（现行有效，施行日期 2021-04-01）
- 章节：第三章预算管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca46f7e514/28.html

各部门及其所属单位应当按照国家规定建立国有资产绩效管理制度，建立健全绩效指标和标准，有序开展国有资产绩效管理工作。
