# 城市道路管理条例第二十二条

- 法规：城市道路管理条例（现行有效）
- 章节：第三章养护和维修
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3042981313/22.html

市政工程行政主管部门组织建设和管理的道路，由其委托的城市道路养护、维修单位负责养护、维修。单位投资建设和管理的道路，由投资建设的单位或者其委托的单位负责养护、维修。城市住宅小区、开发区内的道路，由建设单位或者其委托的单位负责养护、维修。
