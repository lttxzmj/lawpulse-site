# 最高人民法院关于依据国际公约和双边司法协助条约办理民商事案件司法文书送达和调查取证司法协助请求的规定第三条

- 法规：最高人民法院关于依据国际公约和双边司法协助条约办理民商事案件司法文书送达和调查取证司法协助请求的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e32e6f39f7/3.html

人民法院协助外国办理民商事案件司法文书送达和调查取证请求，应当进行审查。外国提出的司法协助请求，具有海牙送达公约、海牙取证公约或双边民事司法协助条约规定的拒绝提供协助的情形的，人民法院应当拒绝提供协助。
