# 工伤保险条例第五十一条

- 法规：工伤保险条例（现行有效，施行日期 2011-01-01）
- 章节：第六章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e4ae5638e/51.html

社会保险行政部门依法对工伤保险费的征缴和工伤保险基金的支付情况进行监督检查。
财政部门和审计机关依法对工伤保险基金的收支、管理情况进行监督。
