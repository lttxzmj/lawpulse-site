# 工伤保险条例第二十三条

- 法规：工伤保险条例（现行有效，施行日期 2011-01-01）
- 章节：第四章劳动能力鉴定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e4ae5638e/23.html

劳动能力鉴定由用人单位、工伤职工或者其近亲属向设区的市级劳动能力鉴定委员会提出申请，并提供工伤认定决定和职工工伤医疗的有关资料。
