# 最高人民法院、最高人民检察院关于办理洗钱刑事案件适用法律若干问题的解释第八条

- 法规：最高人民法院、最高人民检察院关于办理洗钱刑事案件适用法律若干问题的解释（现行有效，施行日期 2024-08-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-86ff030d78/8.html

刑法第一百九十一条规定的“黑社会性质的组织犯罪的所得及其产生的收益”，是指黑社会性质组织及其成员实施相关犯罪的所得及其产生的收益，包括黑社会性质组织的形成、发展过程中，该组织及组织成员通过违法犯罪活动聚敛的全部财物、财产性权益及其孳息、收益。
