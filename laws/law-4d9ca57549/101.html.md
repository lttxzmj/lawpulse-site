# 中华人民共和国证券投资基金法第一百零一条

- 法规：中华人民共和国证券投资基金法（现行有效，施行日期 2015-04-24）
- 章节：第十一章基金服务机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-4d9ca57549/101.html

基金管理人可以委托基金服务机构代为办理基金的份额登记、核算、估值、投资顾问等事项，基金托管人可以委托基金服务机构代为办理基金的核算、估值、复核等事项，但基金管理人、基金托管人依法应当承担的责任不因委托而免除。
