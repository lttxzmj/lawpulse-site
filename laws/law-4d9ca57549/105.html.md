# 中华人民共和国证券投资基金法第一百零五条

- 法规：中华人民共和国证券投资基金法（现行有效，施行日期 2015-04-24）
- 章节：第十一章基金服务机构
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-4d9ca57549/105.html

基金管理人、基金托管人、基金服务机构的信息技术系统，应当符合规定的要求。国务院证券监督管理机构可以要求信息技术系统服务机构提供该信息技术系统的相关资料。
