# 反兴奋剂条例第四十二条

- 法规：反兴奋剂条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c1b6cb06b/42.html

体育社会团体、运动员管理单位违反本条例规定，负有责任的主管人员和其他直接责任人员属于国家工作人员的，还应当依法给予撤职、开除的行政处分。
运动员辅助人员违反本条例规定，属于国家工作人员的，还应当依法给予撤职、开除的行政处分。
