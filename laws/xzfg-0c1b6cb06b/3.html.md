# 反兴奋剂条例第三条

- 法规：反兴奋剂条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c1b6cb06b/3.html

国家提倡健康、文明的体育运动，加强反兴奋剂的宣传、教育和监督管理，坚持严格禁止、严格检查、严肃处理的反兴奋剂工作方针，禁止使用兴奋剂。
任何单位和个人不得向体育运动参加者提供或者变相提供兴奋剂。
