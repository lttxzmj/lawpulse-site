# 反兴奋剂条例第十八条

- 法规：反兴奋剂条例（现行有效）
- 章节：第三章反兴奋剂义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c1b6cb06b/18.html

实施运动员注册管理的体育社会团体(以下简称体育社会团体)应当加强对在本体育社会团体注册的运动员和教练、领队、队医等运动员辅助人员的监督管理和反兴奋剂的教育、培训。
运动员管理单位应当加强对其所属的运动员和运动员辅助人员的监督管理和反兴奋剂的教育、培训。
