# 反兴奋剂条例第二十三条

- 法规：反兴奋剂条例（现行有效）
- 章节：第三章反兴奋剂义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c1b6cb06b/23.html

运动员辅助人员应当教育、提示运动员不得使用兴奋剂，并向运动员提供有关反兴奋剂规则的咨询。
运动员辅助人员不得向运动员提供兴奋剂，不得组织、强迫、欺骗、教唆、协助运动员在体育运动中使用兴奋剂，不得阻挠兴奋剂检查，不得实施影响采样结果的行为。
运动员发现运动员辅助人员违反前款规定的，有权检举、控告。
