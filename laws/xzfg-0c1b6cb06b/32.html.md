# 反兴奋剂条例第三十二条

- 法规：反兴奋剂条例（现行有效）
- 章节：第四章兴奋剂检查与检测
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c1b6cb06b/32.html

国务院体育主管部门应当根据兴奋剂检查计划，决定对全国性体育竞赛的参赛运动员实施赛内兴奋剂检查；并可以决定对省级体育竞赛的参赛运动员实施赛内兴奋剂检查。
其他体育竞赛需要进行赛内兴奋剂检查的，由竞赛组织者决定。
