# 中国人民解放军文职人员条例第七十一条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）
- 章节：第十二章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-24e5cbd207/71.html

文职人员辞职或者被辞退、解除聘用合同，且存在严重违约失信行为的，或者被军队开除的，不得再次进入军队工作。
