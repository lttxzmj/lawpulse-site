# 中国人民解放军文职人员条例第四十四条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）
- 章节：第九章教育管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-24e5cbd207/44.html

文职人员可以按照军队有关规定，参加军地本专业领域学术组织，以及社会团体的组织及其活动。军队鼓励支持从事专业技术工作的文职人员参加国家和地方的人才工程计划、军民科技协同创新等活动。
从事专业技术工作的文职人员，在履行好岗位职责、完成本职工作的前提下，经批准可以到军队以外单位兼职。
