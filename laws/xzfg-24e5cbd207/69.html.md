# 中国人民解放军文职人员条例第六十九条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）
- 章节：第十二章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-24e5cbd207/69.html

中央和国家有关机关、地方有关机关及其工作人员，在文职人员管理工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。
