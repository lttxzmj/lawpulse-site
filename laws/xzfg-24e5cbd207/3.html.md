# 中国人民解放军文职人员条例第三条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-24e5cbd207/3.html

文职人员管理坚持中国共产党的绝对领导，深入贯彻习近平强军思想，贯彻军委主席负责制，落实新时代党的组织路线，坚持党管干部、党管人才，坚持人才是第一资源，坚持公开、平等、竞争、择优，依照法定的权限、条件、标准和程序进行。
