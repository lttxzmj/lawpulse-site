# 中国人民解放军文职人员条例第四十二条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）
- 章节：第九章教育管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-24e5cbd207/42.html

用人单位应当加强文职人员队伍的思想政治建设，引导文职人员投身强军兴军实践，培养政治合格、业务熟练、敢于担当、积极作为、恪尽职守、遵规守纪的职业操守，培育热爱军队、服务国防的职业认同。
