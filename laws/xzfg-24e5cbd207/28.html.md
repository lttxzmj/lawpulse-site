# 中国人民解放军文职人员条例第二十八条

- 法规：中国人民解放军文职人员条例（现行有效，施行日期 2023-01-01）

- 数据核对至：2026-10-22

文职人员实行分类分级考核。
文职人员的考核，应当全面考核文职人员的政治品质、专业能力、担当精神、工作实绩、廉洁自律等情况。
