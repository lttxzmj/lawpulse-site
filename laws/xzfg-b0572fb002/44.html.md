# 民兵工作条例第四十四条

- 法规：民兵工作条例（现行有效）
- 章节：第八章奖励和惩处
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b0572fb002/44.html

对违反本条例规定，拒绝建立或者擅自取消民兵组织，拒绝完成民兵工作任务的单位，由本地区军事领导指挥机关报同级人民政府批准，对该单位给予批评或者行政处罚，对该单位负责人给予行政处分，并责令限期改正。
