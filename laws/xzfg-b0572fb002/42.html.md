# 民兵工作条例第四十二条

- 法规：民兵工作条例（现行有效）
- 章节：第八章奖励和惩处
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b0572fb002/42.html

民兵、民兵组织和人民武装干部在参战、支前中做出显著成绩的，参照《中国人民解放军纪律条令》规定的奖励项目和批准权限，由军队给予奖励；在完成民兵工作或者执行维护社会治安等其他任务中做出显著成绩的，由地方人民政府、本地区的军事领导指挥机关给予奖励。
