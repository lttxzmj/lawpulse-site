# 民兵工作条例第二十三条

- 法规：民兵工作条例（现行有效）
- 章节：第四章军事训练
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b0572fb002/23.html

民兵军事训练的教材、器材，分级负责解决。总参谋部负责组织编印教材和配发部分制式训练器材，其余所需的训练器材，由省军区、军分区、县人民武装部分别购置或者调整解决。
民兵训练教材、器材应当严格管理，不得挪作它用。
