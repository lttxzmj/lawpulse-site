# 民兵工作条例第三十三条

- 法规：民兵工作条例（现行有效）
- 章节：第六章战备执勤
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b0572fb002/33.html

陆海边防地区和其他战备重点地区的民兵组织，应当根据上级军事机关的要求，与驻地的人民解放军和人民武装警察部队实行联防。
发现敌人袭扰、空降和潜入等紧急情况，民兵应当在当地军事机关组织指挥下迅速进行围歼或者搜捕。
战时，民兵应当配合部队作战，担负各项战斗勤务，支援前线，保护群众，保卫生产。
民兵应当配合公安机关维护社会治安。
