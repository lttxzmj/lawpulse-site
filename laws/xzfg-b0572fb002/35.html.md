# 民兵工作条例第三十五条

- 法规：民兵工作条例（现行有效）
- 章节：第六章战备执勤
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b0572fb002/35.html

民兵担负勤务的报酬或者补助，由使用单位支付。
民兵守护重要目标执勤点所需营房、营具、厨具和通信、照明、饮水、警戒等设施，以及执勤民兵的生活补贴、执勤用品、必要的文化用品、医疗、伤亡抚恤等经费，由目标归属单位解决。
