# 最高人民法院关于审理侵害知识产权民事纠纷案件适用惩罚性赔偿的解释第三条

- 法规：最高人民法院关于审理侵害知识产权民事纠纷案件适用惩罚性赔偿的解释（现行有效，施行日期 2026-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b0f609354c/3.html

原告在一审法庭辩论终结前增加惩罚性赔偿请求的，人民法院应当准许。在二审中增加惩罚性赔偿请求的，人民法院可以根据当事人自愿原则进行调解，调解不成的，不予支持。
