# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二百六十八条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/268.html

对没有委托律师、基层法律服务工作者代理诉讼的当事人，人民法院在庭审过程中可以对回避、自认、举证证明责任等相关内容向其作必要的解释或者说明，并在庭审过程中适当提示当事人正确行使诉讼权利、履行诉讼义务。
