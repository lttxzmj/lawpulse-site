# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第一百二十二条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/122.html

当事人可以依照民事诉讼法第八十二条的规定，在举证期限届满前申请一至二名具有专门知识的人出庭，代表当事人对鉴定意见进行质证，或者对案件事实所涉及的专业问题提出意见。
具有专门知识的人在法庭上就专业问题提出的意见，视为当事人的陈述。
人民法院准许当事人申请的，相关费用由提出申请的当事人负担。
