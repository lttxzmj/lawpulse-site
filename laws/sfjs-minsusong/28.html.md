# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二十八条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/28.html

民事诉讼法第三十四条第一项规定的不动产纠纷是指因不动产的权利确认、分割、相邻关系等引起的物权纠纷。
农村土地承包经营合同纠纷、房屋租赁合同纠纷、建设工程施工合同纠纷、政策性房屋买卖合同纠纷，按照不动产纠纷确定管辖。
不动产已登记的，以不动产登记簿记载的所在地为不动产所在地；不动产未登记的，以不动产实际所在地为不动产所在地。
