# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第五百四十五条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/545.html

当事人申请承认和执行外国法院作出的发生法律效力的判决、裁定或者外国仲裁裁决的期间，适用民事诉讼法第二百四十六条的规定。
当事人仅申请承认而未同时申请执行的，申请执行的期间自人民法院对承认申请作出的裁定生效之日起重新计算。
