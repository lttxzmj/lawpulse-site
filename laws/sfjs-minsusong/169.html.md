# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第一百六十九条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/169.html

民事诉讼法规定的先予执行，人民法院应当在受理案件后终审判决作出前采取。先予执行应当限于当事人诉讼请求的范围，并以当事人的生活、生产经营的急需为限。
