# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第四百三十一条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/431.html

债务人在收到支付令后，未在法定期间提出书面异议，而向其他人民法院起诉的，不影响支付令的效力。
债务人超过法定期间提出异议的，视为未提出异议。
