# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第一百一十一条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/111.html

民事诉讼法第七十三条规定的提交书证原件确有困难，包括下列情形：
（一）书证原件遗失、灭失或者毁损的；
（二）原件在对方当事人控制之下，经合法通知提交而拒不提交的；
（三）原件在他人控制之下，而其有权不提交的；
（四）原件因篇幅或者体积过大而不便提交的；
（五）承担举证证明责任的当事人通过申请人民法院调查收集或者其他方式无法获得书证原件的。
前款规定情形，人民法院应当结合其他证据和案件具体情况，审查判断书证复制品等能否作为认定案件事实的根据。
