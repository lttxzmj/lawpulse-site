# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第一百九十条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/190.html

民事诉讼法第一百一十五条规定的他人合法权益，包括案外人的合法权益、国家利益、社会公共利益。
第三人根据民事诉讼法第五十九条第三款规定提起撤销之诉，经审查，原案当事人之间恶意串通进行虚假诉讼的，适用民事诉讼法第一百一十五条规定处理。
