# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二百三十七条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/237.html

有独立请求权的第三人参加诉讼后，原告申请撤诉，人民法院在准许原告撤诉后，有独立请求权的第三人作为另案原告，原案原告、被告作为另案被告，诉讼继续进行。
