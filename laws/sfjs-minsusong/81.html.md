# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第八十一条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/81.html

根据民事诉讼法第五十九条的规定，有独立请求权的第三人有权向人民法院提出诉讼请求和事实、理由，成为当事人；无独立请求权的第三人，可以申请或者由人民法院通知参加诉讼。
第一审程序中未参加诉讼的第三人，申请参加第二审程序的，人民法院可以准许。
