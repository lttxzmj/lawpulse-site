# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二百九十九条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/299.html

第三人撤销之诉案件审理期间，人民法院对生效判决、裁定、调解书裁定再审的，受理第三人撤销之诉的人民法院应当裁定将第三人的诉讼请求并入再审程序。但有证据证明原审当事人之间恶意串通损害第三人合法权益的，人民法院应当先行审理第三人撤销之诉案件，裁定中止再审诉讼。
