# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第三百八十八条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/388.html

有下列情形之一，导致判决、裁定结果错误的，应当认定为民事诉讼法第二百零七条第六项规定的原判决、裁定适用法律确有错误：
(一)适用的法律与案件性质明显不符的；
(二)确定民事责任明显违背当事人约定或者法律规定的；
(三)适用已经失效或者尚未施行的法律的；
(四)违反法律溯及力规定的；
(五)违反法律适用规则的；
(六)明显违背立法原意的。
