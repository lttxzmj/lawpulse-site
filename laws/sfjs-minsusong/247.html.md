# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二百四十七条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/247.html

当事人就已经提起诉讼的事项在诉讼过程中或者裁判生效后再次起诉，同时符合下列条件的，构成重复起诉：
(一)后诉与前诉的当事人相同；
(二)后诉与前诉的诉讼标的相同；
(三)后诉与前诉的诉讼请求相同，或者后诉的诉讼请求实质上否定前诉裁判结果。
当事人重复起诉的，裁定不予受理；已经受理的，裁定驳回起诉，但法律、司法解释另有规定的除外。
