# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第二百四十一条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/241.html

被告经传票传唤无正当理由拒不到庭，或者未经法庭许可中途退庭的，人民法院应当按期开庭或者继续开庭审理，对到庭的当事人诉讼请求、双方的诉辩理由以及已经提交的证据及其他诉讼材料进行审理后，可以依法缺席判决。
