# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第一百六十条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/160.html

当事人向采取诉前保全措施以外的其他有管辖权的人民法院起诉的，采取诉前保全措施的人民法院应当将保全手续移送受理案件的人民法院。诉前保全的裁定视为受移送人民法院作出的裁定。
