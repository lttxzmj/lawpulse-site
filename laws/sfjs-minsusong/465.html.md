# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第四百六十五条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/465.html

一方当事人不履行或者不完全履行在执行中双方自愿达成的和解协议，对方当事人申请执行原生效法律文书的，人民法院应当恢复执行，但和解协议已履行的部分应当扣除。和解协议已经履行完毕的，人民法院不予恢复执行。
