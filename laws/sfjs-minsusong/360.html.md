# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第三百六十条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/360.html

实现票据、仓单、提单等有权利凭证的权利质权案件，可以由权利凭证持有人住所地人民法院管辖；无权利凭证的权利质权，由出质登记地人民法院管辖。
