# 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第四百六十三条

- 法规：最高人民法院关于适用《中华人民共和国民事诉讼法》的解释（现行有效，施行日期 2022-04-10）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-minsusong/463.html

案外人对执行标的提出的异议，经审查，按照下列情形分别处理：
(一)案外人对执行标的不享有足以排除强制执行的权益的，裁定驳回其异议；
(二)案外人对执行标的享有足以排除强制执行的权益的，裁定中止执行。
驳回案外人执行异议裁定送达案外人之日起十五日内，人民法院不得对执行标的进行处分。
