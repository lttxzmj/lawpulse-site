# 破坏性地震应急条例第二十二条

- 法规：破坏性地震应急条例（现行有效）
- 章节：第五章震后应急
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4d8cdb56d9/22.html

破坏性地震发生后，有关的省、自治区、直辖市人民政府应当宣布灾区进入震后应急期，并指明震后应急期的起止时间。
震后应急期一般为10日；必要时，可以延长20日。
