# 最高人民法院关于成渝金融法院案件管辖的规定第三条

- 法规：最高人民法院关于成渝金融法院案件管辖的规定（现行有效，施行日期 2023-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-2b05fefaa7/3.html

以住所地在重庆市以及四川省属于成渝地区双城经济圈范围内依法设立的金融基础设施机构为被告或者第三人，与其履行职责相关的第一审金融民商事案件和涉金融行政案件，由成渝金融法院管辖。
