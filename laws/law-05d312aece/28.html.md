# 中华人民共和国招标投标法第二十八条

- 法规：中华人民共和国招标投标法（现行有效，施行日期 2017-12-28）
- 章节：第三章投标
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-05d312aece/28.html

投标人应当在招标文件要求提交投标文件的截止时间前，将投标文件送达投标地点。招标人收到投标文件后，应当签收保存，不得开启。投标人少于三个的，招标人应当依照本法重新招标。
在招标文件要求提交投标文件的截止时间后送达的投标文件，招标人应当拒收。
