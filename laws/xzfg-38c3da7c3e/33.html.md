# 中华人民共和国森林法实施条例第三十三条

- 法规：中华人民共和国森林法实施条例（现行有效）
- 章节：第五章森林采伐
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38c3da7c3e/33.html

利用外资营造的用材林达到一定规模需要采伐的，应当在国务院批准的年森林采伐限额内，由省、自治区、直辖市人民政府林业主管部门批准，实行采伐限额单列。
