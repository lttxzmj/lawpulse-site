# 中华人民共和国森林法实施条例第三条

- 法规：中华人民共和国森林法实施条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-38c3da7c3e/3.html

国家依法实行森林、林木和林地登记发证制度。依法登记的森林、林木和林地的所有权、使用权受法律保护，任何单位和个人不得侵犯。
森林、林木和林地的权属证书式样由国务院林业主管部门规定。
