# 中华人民共和国尘肺病防治条例第二十条

- 法规：中华人民共和国尘肺病防治条例（现行有效）
- 章节：第四章健康管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ac265f5311/20.html

各企业、事业单位必须贯彻执行职业病报告制度，按期向当地卫生行政部门、劳动部门、工会组织和本单位的主管部门报告职工尘肺病发生和死亡情况。
