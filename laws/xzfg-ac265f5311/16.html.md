# 中华人民共和国尘肺病防治条例第十六条

- 法规：中华人民共和国尘肺病防治条例（现行有效）
- 章节：第三章监督和监测
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ac265f5311/16.html

卫生行政部门负责卫生标准的监测；劳动部门负责劳动卫生工程技术标准的监测。
工会组织负责组织职工群众对本单位的尘肺病防治工作进行监督，并教育职工遵守操作规程与防尘制度。
