# 中华人民共和国尘肺病防治条例第十一条

- 法规：中华人民共和国尘肺病防治条例（现行有效）
- 章节：第二章防尘
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ac265f5311/11.html

严禁任何企业、事业单位将粉尘作业转嫁、外包或以联营的形式给没有防尘设施的乡镇、街道企业或个体工商户。
中、小学校各类校办的实习工厂或车间，禁止从事有粉尘的作业。
