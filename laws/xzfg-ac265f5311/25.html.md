# 中华人民共和国尘肺病防治条例第二十五条

- 法规：中华人民共和国尘肺病防治条例（现行有效）
- 章节：第五章奖励和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ac265f5311/25.html

企业、事业单位负责人和监督、监测人员玩忽职守，致使公共财产、国家和人民利益遭受损失，情节轻微的，由其主管部门给予行政处分；造成重大损失，构成犯罪的，由司法机关依法追究直接责任人员的刑事责任。
