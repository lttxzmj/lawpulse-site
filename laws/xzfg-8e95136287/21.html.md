# 中华人民共和国企业所得税法实施条例第二十一条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第二章应纳税所得额 · 第二节收入
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/21.html

企业所得税法第六条第（八）项所称接受捐赠收入，是指企业接受的来自其他企业、组织或者个人无偿给予的货币性资产、非货币性资产。
接受捐赠收入，按照实际收到捐赠资产的日期确认收入的实现。
