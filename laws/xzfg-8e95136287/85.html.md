# 中华人民共和国企业所得税法实施条例第八十五条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第四章税收优惠
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/85.html

企业所得税法第二十六条第（四）项所称符合条件的非营利组织的收入，不包括非营利组织从事营利性活动取得的收入，但国务院财政、税务主管部门另有规定的除外。
