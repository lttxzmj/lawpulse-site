# 中华人民共和国企业所得税法实施条例第一百一十六条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第六章特别纳税调整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/116.html

企业所得税法第四十五条所称中国居民，是指根据《中华人民共和国个人所得税法》的规定，就其从中国境内、境外取得的所得在中国缴纳个人所得税的个人。
