# 中华人民共和国企业所得税法实施条例第一百二十三条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第六章特别纳税调整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/123.html

企业与其关联方之间的业务往来，不符合独立交易原则，或者企业实施其他不具有合理商业目的安排的，税务机关有权在该业务发生的纳税年度起10年内，进行纳税调整。
