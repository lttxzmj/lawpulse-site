# 中华人民共和国企业所得税法实施条例第六十八条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第二章应纳税所得额 · 第四节资产的税务处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/68.html

企业所得税法第十三条第（一）项和第（二）项所称固定资产的改建支出，是指改变房屋或者建筑物结构、延长使用年限等发生的支出。
企业所得税法第十三条第（一）项规定的支出，按照固定资产预计尚可使用年限分期摊销；第（二）项规定的支出，按照合同约定的剩余租赁期限分期摊销。
改建的固定资产延长使用年限的，除企业所得税法第十三条第（一）项和第（二）项规定外，应当适当延长折旧年限。
