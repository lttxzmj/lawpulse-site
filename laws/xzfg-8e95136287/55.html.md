# 中华人民共和国企业所得税法实施条例第五十五条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第二章应纳税所得额 · 第三节扣除
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/55.html

企业所得税法第十条第（七）项所称未经核定的准备金支出，是指不符合国务院财政、税务主管部门规定的各项资产减值准备、风险准备等准备金支出。
