# 中华人民共和国企业所得税法实施条例第一百一十八条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第六章特别纳税调整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/118.html

企业所得税法第四十五条所称实际税负明显低于企业所得税法第四条第一款规定税率水平，是指低于企业所得税法第四条第一款规定税率的50%。
