# 中华人民共和国企业所得税法实施条例第一百一十五条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第六章特别纳税调整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/115.html

税务机关依照企业所得税法第四十四条的规定核定企业的应纳税所得额时，可以采用下列方法：
（一）参照同类或者类似企业的利润率水平核定；
（二）按照企业成本加合理的费用和利润的方法核定；
（三）按照关联企业集团整体利润的合理比例核定；
（四）按照其他合理方法核定。
企业对税务机关按照前款规定的方法核定的应纳税所得额有异议的，应当提供相关证据，经税务机关认定后，调整核定的应纳税所得额。
