# 中华人民共和国企业所得税法实施条例第九十条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第四章税收优惠
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/90.html

企业所得税法第二十七条第（四）项所称符合条件的技术转让所得免征、减征企业所得税，是指一个纳税年度内，居民企业技术转让所得不超过500万元的部分，免征企业所得税；超过500万元的部分，减半征收企业所得税。
