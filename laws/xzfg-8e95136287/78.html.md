# 中华人民共和国企业所得税法实施条例第七十八条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第三章应纳税额
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/78.html

企业所得税法第二十三条所称抵免限额，是指企业来源于中国境外的所得，依照企业所得税法和本条例的规定计算的应纳税额。除国务院财政、税务主管部门另有规定外，该抵免限额应当分国（地区）不分项计算，计算公式如下：
抵免限额＝中国境内、境外所得依照企业所得税法和本条例的规定计算的应纳税总额×来源于某国（地区）的应纳税所得额÷中国境内、境外应纳税所得总额
