# 中华人民共和国企业所得税法实施条例第一百零五条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第五章源泉扣缴
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/105.html

企业所得税法第三十七条所称支付，包括现金支付、汇拨支付、转账支付和权益兑价支付等货币支付和非货币支付。
企业所得税法第三十七条所称到期应支付的款项，是指支付人按照权责发生制原则应当计入相关成本、费用的应付款项。
