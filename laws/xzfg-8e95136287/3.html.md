# 中华人民共和国企业所得税法实施条例第三条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/3.html

企业所得税法第二条所称依法在中国境内成立的企业，包括依照中国法律、行政法规在中国境内成立的企业、事业单位、社会团体以及其他取得收入的组织。
企业所得税法第二条所称依照外国（地区）法律成立的企业，包括依照外国（地区）法律成立的企业和其他取得收入的组织。
