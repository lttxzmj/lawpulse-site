# 中华人民共和国企业所得税法实施条例第一百零八条

- 法规：中华人民共和国企业所得税法实施条例（现行有效，施行日期 2025-01-20）
- 章节：第五章源泉扣缴
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8e95136287/108.html

企业所得税法第三十九条所称该纳税人在中国境内其他收入，是指该纳税人在中国境内取得的其他各种来源的收入。
税务机关在追缴该纳税人应纳税款时，应当将追缴理由、追缴数额、缴纳期限和缴纳方式等告知该纳税人。
