# 中华人民共和国高等教育法第六十二条

- 法规：中华人民共和国高等教育法（现行有效，施行日期 2018-12-29）
- 章节：第七章高等教育投入和条件保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-c86388bc91/62.html

国务院教育行政部门会同国务院其他有关部门根据在校学生年人均教育成本，规定高等学校年经费开支标准和筹措的基本原则；省、自治区、直辖市人民政府教育行政部门会同有关部门制订本行政区域内高等学校年经费开支标准和筹措办法，作为举办者和高等学校筹措办学经费的基本依据。
