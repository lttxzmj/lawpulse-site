# 股票发行与交易管理暂行条例第二十二条

- 法规：股票发行与交易管理暂行条例（现行有效）
- 章节：第二章股票的发行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a688723eab/22.html

拟公开发行股票的面值总额超过人民币三千万元或者预期销售总金额超过人民币五千万元的，应当由承销团承销。
承销团由二个以上承销机构组成。主承销商由发行人按照公平竞争的原则，通过竞标或者协商的方式确定。主承销商应当与其他承销商签署承销团协议。
