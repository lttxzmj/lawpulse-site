# 股票发行与交易管理暂行条例第三十九条

- 法规：股票发行与交易管理暂行条例（现行有效）
- 章节：第三章股票的交易
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a688723eab/39.html

证券业从业人员、证券业管理人员和国家规定禁止买卖股票的其他人员，不得直接或者间接持有、买卖股票，但是买卖经批准发行的投资基金证券除外。
