# 森林和野生动物类型自然保护区管理办法第三条

- 法规：森林和野生动物类型自然保护区管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1ce21544a2/3.html

自然保护区管理机构的主要任务：贯彻执行国家有关自然保护区的方针、政策和规定，加强管理，开展宣传教育，保护和发展珍贵稀有野生动植物资源，进行科学研究，探索自然演变规律和合理利用森林和动植物资源的途径，为社会主义建设服务。
