# 森林和野生动物类型自然保护区管理办法第七条

- 法规：森林和野生动物类型自然保护区管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1ce21544a2/7.html

建立自然保护区要注意保护对象的完整性和最适宜的范围，考虑当地经济建设和群众生产生活的需要，尽可能避开群众的土地、山林；确实不能避开的，应当严格控制范围，并根据国家有关规定，合理解决群众的生产生活问题。
