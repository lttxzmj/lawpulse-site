# 最高人民法院关于公证债权文书执行若干问题的规定第二十三条

- 法规：最高人民法院关于公证债权文书执行若干问题的规定（现行有效，施行日期 2018-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3652baa6a1/23.html

对债务人依照本规定第二十二条第一款规定提起的诉讼，人民法院经审理认为理由成立的，判决不予执行或者部分不予执行；理由不成立的，判决驳回诉讼请求。
当事人同时就公证债权文书涉及的民事权利义务争议提出诉讼请求的，人民法院可以在判决中一并作出裁判。
