# 最高人民法院关于公证债权文书执行若干问题的规定第三条

- 法规：最高人民法院关于公证债权文书执行若干问题的规定（现行有效，施行日期 2018-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3652baa6a1/3.html

债权人申请执行公证债权文书，除应当提交作为执行依据的公证债权文书等申请执行所需的材料外，还应当提交证明履行情况等内容的执行证书。
