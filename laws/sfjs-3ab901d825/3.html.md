# 最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）第三条

- 法规：最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）（现行有效，施行日期 2021-07-07）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3ab901d825/3.html

受品种权保护的繁殖材料应当具有繁殖能力，且繁殖出的新个体与该授权品种的特征、特性相同。
前款所称的繁殖材料不限于以品种权申请文件所描述的繁殖方式获得的繁殖材料。
