# 最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）第七条

- 法规：最高人民法院关于审理侵害植物新品种权纠纷案件具体应用法律问题的若干规定（二）（现行有效，施行日期 2021-07-07）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-3ab901d825/7.html

受托人、被许可人超出与品种权人约定的规模或者区域生产、繁殖授权品种的繁殖材料，或者超出与品种权人约定的规模销售授权品种的繁殖材料，品种权人请求判令受托人、被许可人承担侵权责任的，人民法院依法予以支持。
