# 中华人民共和国反补贴条例第四十七条

- 法规：中华人民共和国反补贴条例（现行有效，施行日期 2004-06-01）
- 章节：第五章反补贴税和承诺的期限与复审
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd0bbeeda4/47.html

反补贴税的征收期限和承诺的履行期限不超过5年；但是，经复审确定终止征收反补贴税有可能导致补贴和损害的继续或者再度发生的，反补贴税的征收期限可以适当延长。
