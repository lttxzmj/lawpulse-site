# 中华人民共和国反补贴条例第三十三条

- 法规：中华人民共和国反补贴条例（现行有效，施行日期 2004-06-01）
- 章节：第四章反补贴措施 · 第二节承诺
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd0bbeeda4/33.html

出口经营者、出口国（地区）政府不作出承诺或者不接受有关价格承诺的建议的，不妨碍对反补贴案件的调查和确定。出口经营者继续补贴进口产品的，商务部有权确定损害威胁更有可能出现。
