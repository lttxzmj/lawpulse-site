# 中华人民共和国反补贴条例第十六条

- 法规：中华人民共和国反补贴条例（现行有效，施行日期 2004-06-01）
- 章节：第三章反补贴调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd0bbeeda4/16.html

商务部应当自收到申请人提交的申请书及有关证据之日起60天内，对申请是否由国内产业或者代表国内产业提出、申请书内容及所附具的证据等进行审查，并决定立案调查或者不立案调查。在特殊情形下，可以适当延长审查期限。
在决定立案调查前，应当就有关补贴事项向产品可能被调查的国家（地区）政府发出进行磋商的邀请。
