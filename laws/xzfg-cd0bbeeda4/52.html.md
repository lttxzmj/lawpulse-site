# 中华人民共和国反补贴条例第五十二条

- 法规：中华人民共和国反补贴条例（现行有效，施行日期 2004-06-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd0bbeeda4/52.html

对依照本条例第二十六条作出的终裁决定不服的，对依照本条例第四章作出的是否征收反补贴税的决定以及追溯征收的决定不服的，或者对依照本条例第五章作出的复审决定不服的，可以依法申请行政复议，也可以依法向人民法院提起诉讼。
