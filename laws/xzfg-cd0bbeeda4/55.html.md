# 中华人民共和国反补贴条例第五十五条

- 法规：中华人民共和国反补贴条例（现行有效，施行日期 2004-06-01）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cd0bbeeda4/55.html

任何国家（地区）对中华人民共和国的出口产品采取歧视性反补贴措施的，中华人民共和国可以根据实际情况对该国家（地区）采取相应的措施。
