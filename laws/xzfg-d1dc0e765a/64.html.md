# 中华人民共和国道路运输条例第六十四条

- 法规：中华人民共和国道路运输条例（现行有效，施行日期 2026-03-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d1dc0e765a/64.html

不符合本条例第九条、第二十二条规定条件的人员驾驶道路运输经营车辆的，由县级以上地方人民政府交通运输主管部门责令改正，处200元以上2000元以下的罚款；构成犯罪的，依法追究刑事责任。
