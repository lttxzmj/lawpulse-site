# 中华人民共和国道路运输条例第二十三条

- 法规：中华人民共和国道路运输条例（现行有效，施行日期 2026-03-20）
- 章节：第二章道路运输经营 · 第二节货运
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d1dc0e765a/23.html

申请从事危险货物运输经营的，还应当具备下列条件：
（一）有5辆以上经检测合格的危险货物运输专用车辆、设备；
（二）有经所在地设区的市级人民政府交通运输主管部门考试合格，取得上岗资格证的驾驶人员、装卸管理人员、押运人员；
（三）危险货物运输专用车辆配有必要的通讯工具；
（四）有健全的安全生产管理制度。
