# 中华人民共和国道路运输条例第四十一条

- 法规：中华人民共和国道路运输条例（现行有效，施行日期 2026-03-20）
- 章节：第三章道路运输相关业务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d1dc0e765a/41.html

道路旅客运输站（场）经营者应当为客运经营者合理安排班次，公布其运输线路、起止经停站点、运输班次、始发时间、票价，调度车辆进站、发车，疏导旅客，维持上下车秩序。
道路旅客运输站（场）经营者应当设置旅客购票、候车、行李寄存和托运等服务设施，按照车辆核定载客限额售票，并采取措施防止携带危险品的人员进站乘车。
