# 中华人民共和国道路运输条例第五十条

- 法规：中华人民共和国道路运输条例（现行有效，施行日期 2026-03-20）
- 章节：第四章国际道路运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d1dc0e765a/50.html

中国国际道路运输经营者应当在其投入运输车辆的显著位置，标明中国国籍识别标志。
外国国际道路运输经营者的车辆在中国境内运输，应当标明本国国籍识别标志，并按照规定的运输线路行驶；不得擅自改变运输线路，不得从事起止地都在中国境内的道路运输经营。
