# 古树名木保护条例第二十二条

- 法规：古树名木保护条例（现行有效，施行日期 2025-03-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2caf8e50b8/22.html

国务院古树名木主管部门应当建立古树名木保护管理信息平台。
县级以上地方人民政府古树名木主管部门应当及时将本行政区域内的古树名木数据信息归集至古树名木保护管理信息平台。
