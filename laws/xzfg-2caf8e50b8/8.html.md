# 古树名木保护条例第八条

- 法规：古树名木保护条例（现行有效，施行日期 2025-03-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2caf8e50b8/8.html

对古树按照下列标准实行分级保护：
（一）树龄500年以上的，实行一级保护；
（二）树龄300年以上不满500年的，实行二级保护；
（三）树龄100年以上不满300年的，实行三级保护。
省、自治区、直辖市人民政府根据实际情况，可以决定对城市内树龄300年以上不满500年的古树实行一级保护、树龄100年以上不满300年的古树实行二级保护。
对名木均实行一级保护，不受树龄限制。
