# 最高人民检察院关于涉嫌犯罪单位被撤销、注销、吊销营业执照或者宣告破产的应如何进行追诉问题的批复全文

- 法规：最高人民检察院关于涉嫌犯罪单位被撤销、注销、吊销营业执照或者宣告破产的应如何进行追诉问题的批复（现行有效，施行日期 2002-07-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-dcc8a5b8ec/0.html

（2002年7月4日最高人民检察院第九届检察委员会
第一百一十一次会议通过）
高检发释字〔2002〕4号
四川省人民检察院：
你院《关于对已注销的单位原犯罪行为是否应当追诉的请示》（川检发研〔2001〕25号）收悉。经研究，批复如下：
涉嫌犯罪的单位被撤销、注销、吊销营业执照或者宣告破产的，应当根据刑法关于单位犯罪的相关规定，对实施犯罪行为的该单位直接负责的主管人员和其他直接责任人员追究刑事责任，对该单位不再追诉。
此复。
最高人民检察院
2002年7月9日
