# 生产安全事故报告和调查处理条例第四十四条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/44.html

没有造成人员伤亡，但是社会影响恶劣的事故，国务院或者有关地方人民政府认为需要调查处理的，依照本条例的有关规定执行。
国家机关、事业单位、人民团体发生的事故的报告和调查处理，参照本条例的规定执行。
