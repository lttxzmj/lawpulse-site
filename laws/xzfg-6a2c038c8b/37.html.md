# 生产安全事故报告和调查处理条例第三十七条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/37.html

事故发生单位对事故发生负有责任的，依照下列规定处以罚款：
(一)发生一般事故的，处10万元以上20万元以下的罚款；
(二)发生较大事故的，处20万元以上50万元以下的罚款；
(三)发生重大事故的，处50万元以上200万元以下的罚款；
(四)发生特别重大事故的，处200万元以上500万元以下的罚款。
