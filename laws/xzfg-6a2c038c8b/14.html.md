# 生产安全事故报告和调查处理条例第十四条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第二章事故报告
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/14.html

事故发生单位负责人接到事故报告后，应当立即启动事故相应应急预案，或者采取有效措施，组织抢救，防止事故扩大，减少人员伤亡和财产损失。
