# 生产安全事故报告和调查处理条例第三十九条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/39.html

有关地方人民政府、安全生产监督管理部门和负有安全生产监督管理职责的有关部门有下列行为之一的，对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任：
(一)不立即组织事故抢救的；
(二)迟报、漏报、谎报或者瞒报事故的；
(三)阻碍、干涉事故调查工作的；
(四)在事故调查中作伪证或者指使他人作伪证的。
