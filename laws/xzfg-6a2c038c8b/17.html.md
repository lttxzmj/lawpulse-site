# 生产安全事故报告和调查处理条例第十七条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第二章事故报告
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/17.html

事故发生地公安机关根据事故的情况，对涉嫌犯罪的，应当依法立案侦查，采取强制措施和侦查措施。犯罪嫌疑人逃匿的，公安机关应当迅速追捕归案。
