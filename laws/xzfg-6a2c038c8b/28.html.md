# 生产安全事故报告和调查处理条例第二十八条

- 法规：生产安全事故报告和调查处理条例（现行有效）
- 章节：第三章事故调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6a2c038c8b/28.html

事故调查组成员在事故调查工作中应当诚信公正、恪尽职守，遵守事故调查组的纪律，保守事故调查的秘密。
未经事故调查组组长允许，事故调查组成员不得擅自发布有关事故的信息。
