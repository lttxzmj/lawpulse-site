# 城市房地产开发经营管理条例第二十三条

- 法规：城市房地产开发经营管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章房地产经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-90caa8ca29/23.html

房地产开发企业申请办理商品房预售登记，应当提交下列文件：
(一)本条例第二十二条第(一)项至第(三)项规定的证明材料；
(二)营业执照和资质等级证书；
(三)工程施工合同；
(四)预售商品房分层平面图；
(五)商品房预售方案。
