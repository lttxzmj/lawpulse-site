# 城市房地产开发经营管理条例第二十七条

- 法规：城市房地产开发经营管理条例（现行有效，施行日期 2020-11-29）
- 章节：第四章房地产经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-90caa8ca29/27.html

商品房销售，当事人双方应当签订书面合同。合同应当载明商品房的建筑面积和使用面积、价格、交付日期、质量要求、物业管理方式以及双方的违约责任。
