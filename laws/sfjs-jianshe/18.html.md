# 最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）第十八条

- 法规：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-jianshe/18.html

因保修人未及时履行保修义务，导致建筑物毁损或者造成人身损害、财产损失的，保修人应当承担赔偿责任。
保修人与建筑物所有人或者发包人对建筑物毁损均有过错的，各自承担相应的责任。
