# 最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）第三条

- 法规：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-jianshe/3.html

当事人以发包人未取得建设工程规划许可证等规划审批手续为由，请求确认建设工程施工合同无效的，人民法院应予支持，但发包人在起诉前取得建设工程规划许可证等规划审批手续的除外。
发包人能够办理审批手续而未办理，并以未办理审批手续为由请求确认建设工程施工合同无效的，人民法院不予支持。
