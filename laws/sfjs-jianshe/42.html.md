# 最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）第四十二条

- 法规：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-jianshe/42.html

发包人与承包人约定放弃或者限制建设工程价款优先受偿权，损害建筑工人利益，发包人根据该约定主张承包人不享有建设工程价款优先受偿权的，人民法院不予支持。
