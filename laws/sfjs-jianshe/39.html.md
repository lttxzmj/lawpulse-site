# 最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）第三十九条

- 法规：最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-jianshe/39.html

未竣工的建设工程质量合格，承包人请求其承建工程的价款就其承建工程部分折价或者拍卖的价款优先受偿的，人民法院应予支持。
