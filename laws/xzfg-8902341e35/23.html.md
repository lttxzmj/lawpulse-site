# 商业特许经营管理条例第二十三条

- 法规：商业特许经营管理条例（现行有效）
- 章节：第三章信息披露
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8902341e35/23.html

特许人向被特许人提供的信息应当真实、准确、完整，不得隐瞒有关信息，或者提供虚假信息。
特许人向被特许人提供的信息发生重大变更的，应当及时通知被特许人。
特许人隐瞒有关信息或者提供虚假信息的，被特许人可以解除特许经营合同。
