# 商业特许经营管理条例第三十三条

- 法规：商业特许经营管理条例（现行有效）
- 章节：第五章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8902341e35/33.html

本条例施行前已经从事特许经营活动的特许人，应当自本条例施行之日起1年内，依照本条例的规定向商务主管部门备案；逾期不备案的，依照本条例第二十五条的规定处罚。
前款规定的特许人，不适用本条例第七条第二款的规定。
