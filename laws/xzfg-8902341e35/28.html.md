# 商业特许经营管理条例第二十八条

- 法规：商业特许经营管理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8902341e35/28.html

特许人违反本条例第二十一条、第二十三条规定，被特许人向商务主管部门举报并经查实的，由商务主管部门责令改正，处1万元以上5万元以下的罚款；情节严重的，处5万元以上10万元以下的罚款，并予以公告。
