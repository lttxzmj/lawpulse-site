# 气象灾害防御条例第二十二条

- 法规：气象灾害防御条例（现行有效）
- 章节：第二章预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dc1ba58404/22.html

大雾、霾多发区域的地方各级人民政府、有关部门和单位应当加强对机场、港口、高速公路、航道、渔场等重要场所和交通要道的大雾、霾的监测设施建设，做好交通疏导、调度和防护等准备工作。
