# 最高人民法院、最高人民检察院关于办理组织、利用邪教组织破坏法律实施等刑事案件适用法律若干问题的解释第三条

- 法规：最高人民法院、最高人民检察院关于办理组织、利用邪教组织破坏法律实施等刑事案件适用法律若干问题的解释（现行有效，施行日期 2017-02-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-292893a66d/3.html

组织、利用邪教组织，破坏国家法律、行政法规实施，具有下列情形之一的，应当认定为刑法第三百条第一款规定的“情节特别严重”，处七年以上有期徒刑或者无期徒刑，并处罚金或者没收财产：
（一）实施本解释第二条第一项至第七项规定的行为，社会危害特别严重的；
（二）实施本解释第二条第八项至第十二项规定的行为，数量或者数额达到第二条规定相应标准五倍以上的；
（三）其他情节特别严重的情形。
