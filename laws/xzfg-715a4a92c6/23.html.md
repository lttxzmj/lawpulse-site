# 工人考核条例第二十三条

- 法规：工人考核条例（现行有效）
- 章节：第五章考核组织和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-715a4a92c6/23.html

《技师合格证书》，地方所属单位由省、自治区、直辖市及计划单列市劳动行政部门核发；国务院各部门所属单位由其主管部门的劳动工资机构核发。
《技术等级证书》的核发办法，地方所属单位由省、自治区、直辖市及计划单列市劳动行政部门规定；国务院各部门所属单位由其主管部门的劳动工资机构规定。
企业内部的《岗位合格证书》的核发办法，由企业自行规定，但企业主管部门有统一规定的，应当按照统一规定办理。
