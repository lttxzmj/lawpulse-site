# 工人考核条例第二十二条

- 法规：工人考核条例（现行有效）
- 章节：第五章考核组织和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-715a4a92c6/22.html

企业、事业单位或者企业主管部门应当根据实际情况组成不同专业(工种)的考核组织，负责具体考核工作。各专业工种的考核组织成员中，应当有三分之二以上的专业技术人员、技师、高级技术工人。
