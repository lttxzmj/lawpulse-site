# 最高人民法院关于在审理经济纠纷案件中涉及经济犯罪嫌疑若干问题的规定第三条

- 法规：最高人民法院关于在审理经济纠纷案件中涉及经济犯罪嫌疑若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-56a02a0bbd/3.html

单位直接负责的主管人员和其他直接责任人员，以该单位的名义对外签订经济合同，将取得的财物部分或全部占为己有构成犯罪的，除依法追究行为人的刑事责任外，该单位对行为人因签订、履行该经济合同造成的后果，依法应当承担民事责任。
