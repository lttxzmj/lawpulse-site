# 最高人民法院、最高人民检察院关于办理非法采矿、破坏性采矿刑事案件适用法律若干问题的解释第七条

- 法规：最高人民法院、最高人民检察院关于办理非法采矿、破坏性采矿刑事案件适用法律若干问题的解释（现行有效，施行日期 2016-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e26622d386/7.html

明知是犯罪所得的矿产品及其产生的收益，而予以窝藏、转移、收购、代为销售或者以其他方法掩饰、隐瞒的，依照刑法第三百一十二条的规定，以掩饰、隐瞒犯罪所得、犯罪所得收益罪定罪处罚。
实施前款规定的犯罪行为，事前通谋的，以共同犯罪论处。
