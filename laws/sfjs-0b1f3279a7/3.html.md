# 最高人民法院关于审理国际贸易行政案件若干问题的规定第三条

- 法规：最高人民法院关于审理国际贸易行政案件若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0b1f3279a7/3.html

自然人、法人或者其他组织认为中华人民共和国具有国家行政职权的机关和组织及其工作人员（以下统称行政机关）有关国际贸易的具体行政行为侵犯其合法权益的，可以依照行政诉讼法以及其他有关法律、法规的规定，向人民法院提起行政诉讼。
