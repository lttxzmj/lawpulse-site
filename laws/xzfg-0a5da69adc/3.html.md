# 进口影片管理办法第三条

- 法规：进口影片管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0a5da69adc/3.html

中国电影资料馆进口的资料影片(包括中国电影资料馆与外国电影资料馆互相选购、交换、赠送或通过其他途径购作资料的影片)，属于非商业性影片，海关凭该馆填报的进口货物报关单核查免税放行。
进口的资料影片，如经批准，需向全国发行的，由中影公司按章向北京海关办理补税手续。
