# 最高人民法院关于审理期货纠纷案件若干问题的规定（二）第三条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-76bdaf5b47/3.html

期货交易所为债务人，债权人请求冻结、划拨以下账户中资金或者有价证券的，人民法院不予支持：
（一）期货交易所会员在期货交易所保证金账户中的资金；
（二）期货交易所会员向期货交易所提交的用于充抵保证金的有价证券。
