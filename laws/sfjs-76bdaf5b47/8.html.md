# 最高人民法院关于审理期货纠纷案件若干问题的规定（二）第八条

- 法规：最高人民法院关于审理期货纠纷案件若干问题的规定（二）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-76bdaf5b47/8.html

人民法院在办理案件过程中，依法需要通过期货交易所、期货公司查询、冻结、划拨资金或者有价证券的，期货交易所、期货公司应当予以协助。应当协助而拒不协助的，按照《中华人民共和国民事诉讼法》第一百一十四条之规定办理。
