# 中华人民共和国消费税暂行条例第三条

- 法规：中华人民共和国消费税暂行条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3aa75a1669/3.html

纳税人兼营不同税率的应当缴纳消费税的消费品(以下简称应税消费品)，应当分别核算不同税率应税消费品的销售额、销售数量；未分别核算销售额、销售数量，或者将不同税率的应税消费品组成成套消费品销售的，从高适用税率。
