# 中华人民共和国货物进出口管理条例第六十七条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/67.html

进出口经营者以欺骗或者其他不正当手段获取货物进出口配额、批准文件、许可证或者自动进口许可证明的，依法收缴其货物进出口配额、批准文件、许可证或者自动进口许可证明。
