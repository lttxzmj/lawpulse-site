# 中华人民共和国货物进出口管理条例第五十二条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章国营贸易和指定经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/52.html

国营贸易企业和指定经营企业应当根据正常的商业条件从事经营活动，不得以非商业因素选择供应商，不得以非商业因素拒绝其他企业或者组织的委托。
