# 中华人民共和国货物进出口管理条例第六十八条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/68.html

违反本条例第五十一条规定，擅自从事实行国营贸易管理或者指定经营管理的货物进出口贸易，扰乱市场秩序，情节严重的，依照刑法关于非法经营罪的规定，依法追究刑事责任；尚不够刑事处罚的，由市场监督管理部门依法给予行政处罚。
