# 中华人民共和国货物进出口管理条例第六十九条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/69.html

国营贸易企业或者指定经营企业违反本条例第四十八条、第五十二条规定的，由国务院外经贸主管部门予以警告；情节严重的，可以暂停直至取消其国营贸易企业或者指定经营企业资格。
