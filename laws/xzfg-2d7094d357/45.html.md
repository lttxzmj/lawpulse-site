# 中华人民共和国货物进出口管理条例第四十五条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章国营贸易和指定经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/45.html

国家可以对部分货物的进出口实行国营贸易管理。
实行国营贸易管理的进出口货物目录由国务院外经贸主管部门会同国务院有关经济管理部门制定、调整并公布。
