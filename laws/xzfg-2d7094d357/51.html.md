# 中华人民共和国货物进出口管理条例第五十一条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章国营贸易和指定经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/51.html

除本条例第四十七条规定的情形外，未列入国营贸易企业名录和指定经营企业名录的企业或者其他组织，不得从事实行国营贸易管理、指定经营管理的货物的进出口贸易。
