# 中华人民共和国货物进出口管理条例第四十九条

- 法规：中华人民共和国货物进出口管理条例（现行有效，施行日期 2024-05-01）
- 章节：第四章国营贸易和指定经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d7094d357/49.html

国务院外经贸主管部门基于维护进出口经营秩序的需要，可以在一定期限内对部分货物实行指定经营管理。
实行指定经营管理的进出口货物目录由国务院外经贸主管部门制定、调整并公布。
