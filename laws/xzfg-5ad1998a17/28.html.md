# 民办非企业单位登记管理暂行条例第二十八条

- 法规：民办非企业单位登记管理暂行条例（现行有效）
- 章节：第五章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ad1998a17/28.html

民办非企业单位被限期停止活动的，由登记管理机关封存其登记证书、印章和财务凭证。
民办非企业单位被撤销登记的，由登记管理机关收缴登记证书和印章。
