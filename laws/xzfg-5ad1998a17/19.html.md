# 民办非企业单位登记管理暂行条例第十九条

- 法规：民办非企业单位登记管理暂行条例（现行有效）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5ad1998a17/19.html

登记管理机关履行下列监督管理职责：
(一)负责民办非企业单位的成立、变更、注销登记；
(二)对民办非企业单位实施年度检查；
(三)对民办非企业单位违反本条例的问题进行监督检查，对民办非企业单位违反本条例的行为给予行政处罚。
