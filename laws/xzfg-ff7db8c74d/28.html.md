# 中华人民共和国反倾销条例第二十八条

- 法规：中华人民共和国反倾销条例（现行有效）
- 章节：第四章反倾销措施 · 第一节临时反倾销措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ff7db8c74d/28.html

初裁决定确定倾销成立，并由此对国内产业造成损害的，可以采取下列临时反倾销措施：
(一)征收临时反倾销税；
(二)要求提供保证金、保函或者其他形式的担保。
临时反倾销税税额或者提供的保证金、保函或者其他形式担保的金额，应当不超过初裁决定确定的倾销幅度。
