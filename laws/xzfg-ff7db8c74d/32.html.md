# 中华人民共和国反倾销条例第三十二条

- 法规：中华人民共和国反倾销条例（现行有效）
- 章节：第四章反倾销措施 · 第二节价格承诺
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ff7db8c74d/32.html

出口经营者不作出价格承诺或者不接受价格承诺的建议的，不妨碍对反倾销案件的调查和确定。出口经营者继续倾销进口产品的，商务部有权确定损害威胁更有可能出现。
