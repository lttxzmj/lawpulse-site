# 中华人民共和国反倾销条例第四十六条

- 法规：中华人民共和国反倾销条例（现行有效）
- 章节：第四章反倾销措施 · 第三节反倾销税
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ff7db8c74d/46.html

倾销进口产品的进口经营者有证据证明已经缴纳的反倾销税税额超过倾销幅度的，可以向商务部提出退税申请；商务部经审查、核实并提出建议，国务院关税税则委员会根据商务部的建议可以作出退税决定，由海关执行。
