# 中华人民共和国反倾销条例第三十八条

- 法规：中华人民共和国反倾销条例（现行有效）
- 章节：第四章反倾销措施 · 第三节反倾销税
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ff7db8c74d/38.html

征收反倾销税，由商务部提出建议，国务院关税税则委员会根据商务部的建议作出决定，由商务部予以公告。海关自公告规定实施之日起执行。
