# 中华人民共和国反倾销条例第四十五条

- 法规：中华人民共和国反倾销条例（现行有效）
- 章节：第四章反倾销措施 · 第三节反倾销税
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ff7db8c74d/45.html

终裁决定确定不征收反倾销税的，或者终裁决定未确定追溯征收反倾销税的，已征收的临时反倾销税、已收取的保证金应当予以退还，保函或者其他形式的担保应当予以解除。
