# 保障中小企业款项支付条例第七条

- 法规：保障中小企业款项支付条例（现行有效，施行日期 2025-06-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e279f9df9d/7.html

机关、事业单位和大型企业不得要求中小企业接受不合理的付款期限、方式、条件和违约责任等交易条件，不得拖欠中小企业的货物、工程、服务款项。
中小企业应当依法经营，诚实守信，按照合同约定提供合格的货物、工程和服务。
