# 保障中小企业款项支付条例第三十四条

- 法规：保障中小企业款项支付条例（现行有效，施行日期 2025-06-01）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e279f9df9d/34.html

大型企业违反本条例，未按照规定在企业年度报告中公示逾期尚未支付中小企业款项信息或者隐瞒真实情况、弄虚作假的，由市场监督管理部门依法处理。
