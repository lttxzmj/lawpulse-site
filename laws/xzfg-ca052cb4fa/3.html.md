# 国务院关于规范中介机构为公司公开发行股票提供服务的规定第三条

- 法规：国务院关于规范中介机构为公司公开发行股票提供服务的规定（现行有效，施行日期 2025-02-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ca052cb4fa/3.html

中介机构为公司公开发行股票提供服务，应当遵循诚实守信、勤勉尽责、独立客观的原则，同时配备具有相应专业能力和资质的从业人员，建立有效的利益冲突审查等风险控制制度。
