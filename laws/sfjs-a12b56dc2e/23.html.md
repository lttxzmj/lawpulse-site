# 最高人民法院关于审理行政协议案件若干问题的规定第二十三条

- 法规：最高人民法院关于审理行政协议案件若干问题的规定（现行有效，施行日期 2020-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a12b56dc2e/23.html

人民法院审理行政协议案件，可以依法进行调解。
人民法院进行调解时，应当遵循自愿、合法原则，不得损害国家利益、社会公共利益和他人合法权益。
