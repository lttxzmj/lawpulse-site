# 最高人民法院关于审理行政协议案件若干问题的规定第七条

- 法规：最高人民法院关于审理行政协议案件若干问题的规定（现行有效，施行日期 2020-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a12b56dc2e/7.html

当事人书面协议约定选择被告所在地、原告所在地、协议履行地、协议订立地、标的物所在地等与争议有实际联系地点的人民法院管辖的，人民法院从其约定，但违反级别管辖和专属管辖的除外。
