# 最高人民法院关于涉外民商事案件管辖若干问题的规定第三条

- 法规：最高人民法院关于涉外民商事案件管辖若干问题的规定（现行有效，施行日期 2023-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e5ec127498/3.html

高级人民法院管辖诉讼标的额人民币50亿元以上（包含本数）或者其他在本辖区有重大影响的第一审涉外民商事案件。
