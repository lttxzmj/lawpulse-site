# 中华人民共和国对外合作开采陆上石油资源条例第八条

- 法规：中华人民共和国对外合作开采陆上石油资源条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d886ed0854/8.html

中方石油公司在国务院批准的对外合作开采陆上石油资源的区域内，按划分的合作区块，通过招标或者谈判，确定合作开采陆上石油资源的外国企业，签订合作开采石油合同或者其他合作合同，并向中华人民共和国商务部报送合同有关情况。
