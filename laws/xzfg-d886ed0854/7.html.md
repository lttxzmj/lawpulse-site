# 中华人民共和国对外合作开采陆上石油资源条例第七条

- 法规：中华人民共和国对外合作开采陆上石油资源条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d886ed0854/7.html

中国石油天然气集团公司、中国石油化工集团公司(以下简称中方石油公司)负责对外合作开采陆上石油资源的经营业务；负责与外国企业谈判、签订、执行合作开采陆上石油资源的合同；在国务院批准的对外合作开采陆上石油资源的区域内享有与外国企业合作进行石油勘探、开发、生产的专营权。
