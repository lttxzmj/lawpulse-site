# 中华人民共和国行政复议法实施条例第五十七条

- 法规：中华人民共和国行政复议法实施条例（现行有效，施行日期 2026-07-01）
- 章节：第五章行政复议决定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96efaed515/57.html

行政复议法第六十四条第一款第三项规定的适用的依据不合法包括下列情形：
（一）适用的依据尚未生效；
（二）适用的依据超越制定主体权限；
（三）适用的依据违反上位法的规定；
（四）其他适用的依据不合法的情形。
行政行为适用的依据不合法，但有合法依据可以适用且符合行政复议法第六十三条规定的情形的，行政复议机关可以作出变更决定。
