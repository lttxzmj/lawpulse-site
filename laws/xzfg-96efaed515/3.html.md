# 中华人民共和国行政复议法实施条例第三条

- 法规：中华人民共和国行政复议法实施条例（现行有效，施行日期 2026-07-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96efaed515/3.html

各级行政复议机关应当认真履行行政复议职责，领导并支持本机关行政复议机构依法办理行政复议事项，依照有关规定配备、充实、调剂专职行政复议人员，保证行政复议机构的办案能力与工作任务相适应。
