# 中华人民共和国行政复议法实施条例第二十八条

- 法规：中华人民共和国行政复议法实施条例（现行有效，施行日期 2026-07-01）
- 章节：第二章行政复议申请 · 第三节申请的提出
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96efaed515/28.html

申请人通过行政复议机关指定的互联网渠道申请行政复议的，行政复议申请材料到达特定系统之日，为行政复议机关收到行政复议申请之日。
申请人通过互联网渠道提交的申请材料符合法定要求的，行政复议机关不得要求另行提供纸质材料。
