# 石油地震勘探损害补偿规定第七条

- 法规：石油地震勘探损害补偿规定（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d6dfdfee76/7.html

当事人双方对石油地震勘探损害补偿问题发生纠纷时，首先应当协商解决，协商不成的，提请当地县级人民政府及其指定的部门调解处理；对调解处理决定不服的，任何一方可在接到处理决定之日起十五日内向所在地人民法院起诉，但在调解和诉讼期间，应当保证地震作业队正常作业。
