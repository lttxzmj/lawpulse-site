# 石油地震勘探损害补偿规定第二十二条

- 法规：石油地震勘探损害补偿规定（现行有效）
- 章节：第五章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d6dfdfee76/22.html

地震作业队违反第六条规定，擅自在安全距离内放炮的，应当根据国家有关法律、法规由有关部门对地震作业队责任人员追究行政责任或民事责任；对情节严重构成犯罪的，依法追究其刑事责任。
