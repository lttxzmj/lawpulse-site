# 中华人民共和国军事设施保护法实施办法第二十三条

- 法规：中华人民共和国军事设施保护法实施办法（现行有效）
- 章节：第四章军用机场净空的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-83e44907b1/23.html

在军用机场净空保护区域内建设高大建筑物、构筑物或者其他设施的，建设单位必须在申请立项前书面征求军用机场管理单位的军级以上主管军事机关的意见；未征求军事机关意见或者建设项目设计高度超过军用机场净空保护标准的，国务院有关部门、地方人民政府有关部门不予办理建设许可手续。
