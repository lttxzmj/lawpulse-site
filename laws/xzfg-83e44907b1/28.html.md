# 中华人民共和国军事设施保护法实施办法第二十八条

- 法规：中华人民共和国军事设施保护法实施办法（现行有效）
- 章节：第五章军用通信、输电线路和军用输油、输水管道的保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-83e44907b1/28.html

军事设施保护法所称军用输油、输水管道，是指专供军队使用的地面或者地下、水下输油、输水管道和管道沿线的加压站、计量站、处理场、油库、阀室、标志物以及其他附属设施。
