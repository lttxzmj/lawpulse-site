# 中华人民共和国军事设施保护法实施办法第四十六条

- 法规：中华人民共和国军事设施保护法实施办法（现行有效）
- 章节：第八章强制措施和法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-83e44907b1/46.html

违反本办法第十六条的规定，擅自在作战工程安全保护范围内修筑建筑物、构筑物、道路或者进行农田水利基本建设的，由城市规划、交通、农业行政主管部门依据各自的职权给予警告，责令限期改正；造成损失的，依法赔偿损失。
