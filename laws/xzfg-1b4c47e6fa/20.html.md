# 证券公司风险处置条例第二十条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第三章撤销
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/20.html

证券公司经停业整顿、托管、接管或者行政重组在规定期限内仍达不到正常经营条件，并且有本条例第十九条第（二）项或者第（三）项规定情形的，国务院证券监督管理机构应当撤销该证券公司。
