# 证券公司风险处置条例第三十八条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第四章破产清算和重整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/38.html

证券公司有《企业破产法》第二条规定情形的，国务院证券监督管理机构可以直接向人民法院申请对该证券公司进行重整。
证券公司或者其债权人依照《企业破产法》的有关规定，可以向人民法院提出对证券公司进行破产清算或者重整的申请，但应当依照《证券法》第一百二十二条的规定报经国务院证券监督管理机构批准。
