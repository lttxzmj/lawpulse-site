# 证券公司风险处置条例第三条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/3.html

国务院证券监督管理机构应当会同中国人民银行、国务院财政部门、国务院公安部门、国务院其他金融监督管理机构以及省级人民政府建立处置证券公司风险的协调配合与快速反应机制。
