# 证券公司风险处置条例第十六条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第二章停业整顿、托管、接管、行政重组
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/16.html

证券公司经停业整顿、托管、接管或者行政重组在规定期限内达到正常经营条件的，经国务院证券监督管理机构批准，可以恢复正常经营。
