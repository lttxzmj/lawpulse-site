# 证券公司风险处置条例第五十条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第五章监督协调
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/50.html

国务院证券监督管理机构依照本条例第二章、第三章对证券公司进行处置的，可以向人民法院提出申请中止以该证券公司以及其分支机构为被告、第三人或者被执行人的民事诉讼程序或者执行程序。
证券公司设立或者实际控制的关联公司，其资产、人员、财务或者业务与被处置证券公司混合的，国务院证券监督管理机构可以向人民法院提出申请中止以该关联公司为被告、第三人或者被执行人的民事诉讼程序或者执行程序。
采取前两款规定措施期间，除本条例第三十一条规定的情形外，不得对被处置证券公司债务进行个别清偿。
