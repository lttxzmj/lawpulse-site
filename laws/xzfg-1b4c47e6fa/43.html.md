# 证券公司风险处置条例第四十三条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第四章破产清算和重整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/43.html

自债权人会议各表决组通过重整计划草案之日起10日内，证券公司或者管理人应当向人民法院提出批准重整计划的申请。重整计划涉及《证券法》第一百二十二条规定相关事项的，证券公司或者管理人应当同时向国务院证券监督管理机构提出批准相关事项的申请，国务院证券监督管理机构应当自收到申请之日起15日内做出批准或者不予批准的决定。
