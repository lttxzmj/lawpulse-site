# 证券公司风险处置条例第四十二条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第四章破产清算和重整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/42.html

人民法院裁定证券公司重整的，证券公司或者管理人应当同时向债权人会议、国务院证券监督管理机构和人民法院提交重整计划草案。
