# 证券公司风险处置条例第二十八条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第三章撤销
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/28.html

行政清理组应当自成立之日起10日内，将债权人需要登记的相关事项予以公告。
符合国家有关规定的债权人应当自公告之日起90日内，持相关证明材料向行政清理组申报债权，行政清理组按照规定登记。无正当理由逾期申报的，不予登记。
已登记债权经甄别确认符合国家收购规定的，行政清理组应当及时按照国家有关规定申请收购资金并协助收购；经甄别确认不符合国家收购规定的，行政清理组应当告知申报的债权人。
