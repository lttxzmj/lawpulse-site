# 证券公司风险处置条例第四十五条

- 法规：证券公司风险处置条例（现行有效，施行日期 2023-07-20）
- 章节：第四章破产清算和重整
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1b4c47e6fa/45.html

经批准的重整计划由证券公司执行，管理人负责监督。监督期届满，管理人应当向人民法院和国务院证券监督管理机构提交监督报告。
