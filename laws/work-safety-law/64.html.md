# 中华人民共和国安全生产法第六十四条

- 法规：中华人民共和国安全生产法（现行有效，施行日期 2021-09-01）
- 章节：第四章安全生产的监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/work-safety-law/64.html

负有安全生产监督管理职责的部门对涉及安全生产的事项进行审查、验收，不得收取费用；不得要求接受审查、验收的单位购买其指定品牌或者指定生产、销售单位的安全设备、器材或者其他产品。
