# 中华人民共和国安全生产法第四十二条

- 法规：中华人民共和国安全生产法（现行有效，施行日期 2021-09-01）
- 章节：第二章生产经营单位的安全生产保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/work-safety-law/42.html

生产、经营、储存、使用危险物品的车间、商店、仓库不得与员工宿舍在同一座建筑物内，并应当与员工宿舍保持安全距离。
生产经营场所和员工宿舍应当设有符合紧急疏散要求、标志明显、保持畅通的出口、疏散通道。禁止占用、锁闭、封堵生产经营场所或者员工宿舍的出口、疏散通道。
