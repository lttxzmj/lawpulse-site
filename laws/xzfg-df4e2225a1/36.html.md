# 艾滋病防治条例第三十六条

- 法规：艾滋病防治条例（现行有效）
- 章节：第三章预防与控制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-df4e2225a1/36.html

采集或者使用人体组织、器官、细胞、骨髓等的，应当进行艾滋病检测；未经艾滋病检测或者艾滋病检测阳性的，不得采集或者使用。但是，用于艾滋病防治科研、教学的除外。
