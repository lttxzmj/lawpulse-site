# 最高人民法院关于审理破坏森林资源刑事案件适用法律若干问题的解释第十七条

- 法规：最高人民法院关于审理破坏森林资源刑事案件适用法律若干问题的解释（现行有效，施行日期 2023-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-68a5bd01e9/17.html

涉案国家重点保护植物或者其他林木的价值，可以根据销赃数额认定；无销赃数额，销赃数额难以查证，或者根据销赃数额认定明显不合理的，根据市场价格认定。
