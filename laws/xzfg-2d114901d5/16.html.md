# 劳动保障监察条例第十六条

- 法规：劳动保障监察条例（现行有效）
- 章节：第三章劳动保障监察的实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2d114901d5/16.html

劳动保障监察员进行调查、检查，不得少于2人，并应当佩戴劳动保障监察标志、出示劳动保障监察证件。
劳动保障监察员办理的劳动保障监察事项与本人或者其近亲属有直接利害关系的，应当回避。
