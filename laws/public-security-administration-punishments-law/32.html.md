# 中华人民共和国治安管理处罚法第三十二条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第一节扰乱公共秩序的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/32.html

违反国家规定，有下列行为之一的，处五日以上十日以下拘留；情节严重的，处十日以上十五日以下拘留：
（一）故意干扰无线电业务正常进行的；
（二）对正常运行的无线电台（站）产生有害干扰，经有关主管部门指出后，拒不采取有效措施消除的；
（三）未经批准设置无线电广播电台、通信基站等无线电台（站）的，或者非法使用、占用无线电频率，从事违法活动的。
