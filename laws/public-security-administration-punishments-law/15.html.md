# 中华人民共和国治安管理处罚法第十五条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第二章处罚的种类和适用
- 数据核对至：2026-10-22

醉酒的人违反治安管理的，应当给予处罚。
醉酒的人在醉酒状态中，对本人有危险或者对他人的人身、财产或者公共安全有威胁的，应当对其采取保护性措施约束至酒醒。
