# 中华人民共和国治安管理处罚法第一百二十四条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第三节执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/124.html

人民警察当场收缴的罚款，应当自收缴罚款之日起二日以内，交至所属的公安机关；在水上、旅客列车上当场收缴的罚款，应当自抵岸或者到站之日起二日以内，交至所属的公安机关；公安机关应当自收到罚款之日起二日以内将罚款缴付指定的银行。
