# 中华人民共和国治安管理处罚法第一百三十三条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第五章执法监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/133.html

公安机关及其人民警察办理治安案件，应当自觉接受社会和公民的监督。
公安机关及其人民警察办理治安案件，不严格执法或者有违法违纪行为的，任何单位和个人都有权向公安机关或者人民检察院、监察机关检举、控告；收到检举、控告的机关，应当依据职责及时处理。
