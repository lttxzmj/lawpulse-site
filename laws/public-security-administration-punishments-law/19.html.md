# 中华人民共和国治安管理处罚法第十九条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第二章处罚的种类和适用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/19.html

为了免受正在进行的不法侵害而采取的制止行为，造成损害的，不属于违反治安管理行为，不受处罚；制止行为明显超过必要限度，造成较大损害的，依法给予处罚，但是应当减轻处罚；情节较轻的，不予处罚。
