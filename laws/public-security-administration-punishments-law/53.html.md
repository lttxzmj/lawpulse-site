# 中华人民共和国治安管理处罚法第五十三条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第三节侵犯人身权利、财产权利的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/53.html

有下列行为之一的，处五日以下拘留或者警告；情节较重的，处五日以上十日以下拘留，可以并处一千元以下罚款：
（一）虐待家庭成员，被虐待人或者其监护人要求处理的；
（二）对未成年人、老年人、患病的人、残疾人等负有监护、看护职责的人虐待被监护、看护的人的；
（三）遗弃没有独立生活能力的被扶养人的。
