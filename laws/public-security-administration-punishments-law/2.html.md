# 中华人民共和国治安管理处罚法第二条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/2.html

治安管理工作坚持中国共产党的领导，坚持综合治理。
各级人民政府应当加强社会治安综合治理，采取有效措施，预防和化解社会矛盾纠纷，增进社会和谐，维护社会稳定。
