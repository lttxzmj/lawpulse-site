# 中华人民共和国治安管理处罚法第一百二十三条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第三节执行
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/123.html

受到罚款处罚的人应当自收到处罚决定书之日起十五日以内，到指定的银行或者通过电子支付系统缴纳罚款。但是，有下列情形之一的，人民警察可以当场收缴罚款：
（一）被处二百元以下罚款，被处罚人对罚款无异议的；
（二）在边远、水上、交通不便地区，旅客列车上或者口岸，公安机关及其人民警察依照本法的规定作出罚款决定后，被处罚人到指定的银行或者通过电子支付系统缴纳罚款确有困难，经被处罚人提出的；
（三）被处罚人在当地没有固定住所，不当场收缴事后难以执行的。
