# 中华人民共和国治安管理处罚法第七十二条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第四节妨害社会管理的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/72.html

有下列行为之一的，处五日以上十日以下拘留，可以并处一千元以下罚款；情节较轻的，处警告或者一千元以下罚款：
（一）隐藏、转移、变卖、擅自使用或者损毁行政执法机关依法扣押、查封、冻结、扣留、先行登记保存的财物的；
（二）伪造、隐匿、毁灭证据或者提供虚假证言、谎报案情，影响行政执法机关依法办案的；
（三）明知是赃物而窝藏、转移或者代为销售的；
（四）被依法执行管制、剥夺政治权利或者在缓刑、暂予监外执行中的罪犯或者被依法采取刑事强制措施的人，有违反法律、行政法规或者国务院有关部门的监督管理规定的行为的。
