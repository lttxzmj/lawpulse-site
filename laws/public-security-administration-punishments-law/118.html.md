# 中华人民共和国治安管理处罚法第一百一十八条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第二节决定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/118.html

公安机关办理治安案件的期限，自立案之日起不得超过三十日；案情重大、复杂的，经上一级公安机关批准，可以延长三十日。期限延长以二次为限。公安派出所办理的案件需要延长期限的，由所属公安机关批准。
为了查明案情进行鉴定的期间、听证的期间，不计入办理治安案件的期限。
