# 中华人民共和国治安管理处罚法第六十四条

船舶擅自进入、停靠国家禁止、限制进入的水域或者岛屿的，对船舶负责人及有关责任人员处一千元以上二千元以下罚款；情节严重的，处五日以下拘留，可以并处二千元以下罚款。
