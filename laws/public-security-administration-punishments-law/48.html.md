# 中华人民共和国治安管理处罚法第四十八条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第三节侵犯人身权利、财产权利的行为和处罚
- 数据核对至：2026-10-22

组织、胁迫未成年人在不适宜未成年人活动的经营场所从事陪酒、陪唱等有偿陪侍活动的，处十日以上十五日以下拘留，并处五千元以下罚款；情节较轻的，处五日以下拘留或者五千元以下罚款。
