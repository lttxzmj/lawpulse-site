# 中华人民共和国治安管理处罚法第八条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/8.html

违反治安管理行为对他人造成损害的，除依照本法给予治安管理处罚外，行为人或者其监护人还应当依法承担民事责任。
违反治安管理行为构成犯罪，应当依法追究刑事责任的，不得以治安管理处罚代替刑事处罚。
