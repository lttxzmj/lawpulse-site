# 中华人民共和国治安管理处罚法第八十一条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第四节妨害社会管理的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/81.html

有下列行为之一的，处十日以上十五日以下拘留，并处一千元以上二千元以下罚款：
（一）组织播放淫秽音像的；
（二）组织或者进行淫秽表演的；
（三）参与聚众淫乱活动的。
明知他人从事前款活动，为其提供条件的，依照前款的规定处罚。
组织未成年人从事第一款活动的，从重处罚。
