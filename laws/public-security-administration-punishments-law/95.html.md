# 中华人民共和国治安管理处罚法第九十五条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第一节调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/95.html

人民警察在办理治安案件过程中，遇有下列情形之一的，应当回避；违反治安管理行为人、被侵害人或者其法定代理人也有权要求他们回避：
（一）是本案当事人或者当事人的近亲属的；
（二）本人或者其近亲属与本案有利害关系的；
（三）与本案当事人有其他关系，可能影响案件公正处理的。
人民警察的回避，由其所属的公安机关决定；公安机关负责人的回避，由上一级公安机关决定。
