# 中华人民共和国治安管理处罚法第二十条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第二章处罚的种类和适用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/20.html

违反治安管理有下列情形之一的，从轻、减轻或者不予处罚：
（一）情节轻微的；
（二）主动消除或者减轻违法后果的；
（三）取得被侵害人谅解的；
（四）出于他人胁迫或者诱骗的；
（五）主动投案，向公安机关如实陈述自己的违法行为的；
（六）有立功表现的。
