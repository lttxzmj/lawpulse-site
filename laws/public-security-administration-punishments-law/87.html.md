# 中华人民共和国治安管理处罚法第八十七条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第四节妨害社会管理的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/87.html

旅馆业、饮食服务业、文化娱乐业、出租汽车业等单位的人员，在公安机关查处吸毒、赌博、卖淫、嫖娼活动时，为违法犯罪行为人通风报信的，或者以其他方式为上述活动提供条件的，处十日以上十五日以下拘留；情节较轻的，处五日以下拘留或者一千元以上二千元以下罚款。
