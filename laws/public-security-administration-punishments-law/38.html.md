# 中华人民共和国治安管理处罚法第三十八条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第二节妨害公共安全的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/38.html

非法携带枪支、弹药或者弩、匕首等国家规定的管制器具的，处五日以下拘留，可以并处一千元以下罚款；情节较轻的，处警告或者五百元以下罚款。
非法携带枪支、弹药或者弩、匕首等国家规定的管制器具进入公共场所或者公共交通工具的，处五日以上十日以下拘留，可以并处一千元以下罚款。
