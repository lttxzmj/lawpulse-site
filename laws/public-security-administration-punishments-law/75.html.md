# 中华人民共和国治安管理处罚法第七十五条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第三章违反治安管理的行为和处罚 · 第四节妨害社会管理的行为和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/75.html

有下列行为之一的，处警告或者五百元以下罚款；情节较重的，处五日以上十日以下拘留，并处五百元以上一千元以下罚款：
（一）刻划、涂污或者以其他方式故意损坏国家保护的文物、名胜古迹的；
（二）违反国家规定，在文物保护单位附近进行爆破、钻探、挖掘等活动，危及文物安全的。
