# 中华人民共和国治安管理处罚法第九十四条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第一节调查
- 数据核对至：2026-10-22

公安机关及其人民警察在办理治安案件时，对涉及的国家秘密、商业秘密、个人隐私或者个人信息，应当予以保密。
