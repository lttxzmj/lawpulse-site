# 中华人民共和国治安管理处罚法第九十九条

- 法规：中华人民共和国治安管理处罚法（现行有效，施行日期 2026-01-01）
- 章节：第四章处罚程序 · 第一节调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/public-security-administration-punishments-law/99.html

人民警察询问被侵害人或者其他证人，可以在现场进行，也可以到其所在单位、住处或者其提出的地点进行；必要时，也可以通知其到公安机关提供证言。
人民警察在公安机关以外询问被侵害人或者其他证人，应当出示人民警察证。
询问被侵害人或者其他证人，同时适用本法第九十八条的规定。
