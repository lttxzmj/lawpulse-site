# 中华人民共和国海关稽查条例第十八条

- 法规：中华人民共和国海关稽查条例（现行有效，施行日期 2022-05-01）
- 章节：第三章海关稽查的实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6190872c29/18.html

被稽查人应当接受海关稽查，如实反映情况，提供账簿、单证等有关资料，不得拒绝、拖延、隐瞒。
被稽查人使用计算机记账的，应当向海关提供记账软件、使用说明书及有关资料。
