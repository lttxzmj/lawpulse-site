# 中华人民共和国海关稽查条例第二十三条

- 法规：中华人民共和国海关稽查条例（现行有效，施行日期 2022-05-01）
- 章节：第三章海关稽查的实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6190872c29/23.html

海关应当自收到稽查报告之日起30日内，作出海关稽查结论并送达被稽查人。
海关应当在稽查结论中说明作出结论的理由，并告知被稽查人的权利。
