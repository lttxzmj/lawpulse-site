# 关于骗购外汇、非法套汇、逃汇、非法买卖外汇等违反外汇管理规定行为的行政处分或者纪律处分暂行规定第三条

- 法规：关于骗购外汇、非法套汇、逃汇、非法买卖外汇等违反外汇管理规定行为的行政处分或者纪律处分暂行规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-46eb22a1af/3.html

有本规定所列违反外汇管理规定的行为的，除依法给予行政处罚外，对有关责任人员依照本规定给予行政处分或者纪律处分；构成犯罪的，依法追究刑事责任。
