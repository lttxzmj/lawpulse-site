# 供水条例第三条

- 法规：供水条例（现行有效，施行日期 2026-06-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-266d98607a/3.html

供水事业发展应当贯彻党和国家路线方针政策、决策部署，坚持以人为本、城乡统筹，坚持公益属性，实行开发水源和节约用水相结合，持续增强供水安全保障能力，促进供水服务均等化。
