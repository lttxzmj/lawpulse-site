# 供水条例第三十二条

- 法规：供水条例（现行有效，施行日期 2026-06-01）
- 章节：第五章供水设施管理和保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-266d98607a/32.html

建设工程开工前，建设单位或者施工单位应当查明工程建设范围内地下供水设施的相关情况。供水单位和有关档案机构等单位应当及时提供相关资料。
建设工程施工可能影响供水设施安全的，建设单位或者施工单位应当事先与供水单位商定相应的保护措施，由施工单位负责实施。
