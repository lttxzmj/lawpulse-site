# 最高人民法院关于修改《中华人民共和国人民法院法庭规则》的决定第三条

- 法规：最高人民法院关于修改《中华人民共和国人民法院法庭规则》的决定（现行有效，施行日期 2016-05-01）
- 数据核对至：2026-10-22

法庭分设审判活动区和旁听区，两区以栏杆等进行隔离。
审理未成年人案件的法庭应当根据未成年人身心发展特点设置区域和席位。
有新闻媒体旁听或报道庭审活动时，旁听区可以设置专门的媒体记者席。
