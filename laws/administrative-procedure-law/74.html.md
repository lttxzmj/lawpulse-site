# 中华人民共和国行政诉讼法第七十四条

- 法规：中华人民共和国行政诉讼法（现行有效，施行日期 2017-07-01）
- 章节：第七章审理和判决 · 第二节第一审普通程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/administrative-procedure-law/74.html

行政行为有下列情形之一的，人民法院判决确认违法，但不撤销行政行为：
（一）行政行为依法应当撤销，但撤销会给国家利益、社会公共利益造成重大损害的；
（二）行政行为程序轻微违法，但对原告权利不产生实际影响的。
行政行为有下列情形之一，不需要撤销或者判决履行的，人民法院判决确认违法：
（一）行政行为违法，但不具有可撤销内容的；
（二）被告改变原违法行政行为，原告仍要求确认原行政行为违法的；
（三）被告不履行或者拖延履行法定职责，判决履行没有意义的。
