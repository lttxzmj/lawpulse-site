# 最高人民法院关于审理拐卖妇女案件适用法律有关问题的解释第三条

- 法规：最高人民法院关于审理拐卖妇女案件适用法律有关问题的解释（现行有效，施行日期 2000-01-25）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0a3eb3ed9a/3.html

对于外国籍被告人身份无法查明或者其国籍国拒绝提供有关身份证明，人民检察院根据刑事诉讼法第一百二十八条第二款的规定起诉的案件，人民法院应当依法受理。
