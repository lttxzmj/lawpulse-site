# 汶川地震灾后恢复重建条例第六十四条

- 法规：汶川地震灾后恢复重建条例（现行有效）
- 章节：第六章资金筹集与政策扶持
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-84e95f7436/64.html

对地震灾后恢复重建中需要办理行政审批手续的事项，有审批权的人民政府及有关部门应当按照方便群众、简化手续、提高效率的原则，依法及时予以办理。
