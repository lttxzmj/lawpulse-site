# 汶川地震灾后恢复重建条例第三条

- 法规：汶川地震灾后恢复重建条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-84e95f7436/3.html

地震灾后恢复重建应当遵循以下原则：
(一)受灾地区自力更生、生产自救与国家支持、对口支援相结合；
(二)政府主导与社会参与相结合；
(三)就地恢复重建与异地新建相结合；
(四)确保质量与注重效率相结合；
(五)立足当前与兼顾长远相结合；
(六)经济社会发展与生态环境资源保护相结合。
