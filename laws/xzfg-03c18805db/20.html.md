# 安全生产许可证条例第二十条

- 法规：安全生产许可证条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-03c18805db/20.html

违反本条例规定，安全生产许可证有效期满未办理延期手续，继续进行生产的，责令停止生产，限期补办延期手续，没收违法所得，并处5万元以上10万元以下的罚款；逾期仍不办理延期手续，继续进行生产的，依照本条例第十九条的规定处罚。
