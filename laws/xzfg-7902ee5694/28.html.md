# 放射性废物安全管理条例第二十八条

- 法规：放射性废物安全管理条例（现行有效）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7902ee5694/28.html

县级以上人民政府环境保护主管部门和其他有关部门，依照《中华人民共和国放射性污染防治法》和本条例的规定，对放射性废物处理、贮存和处置等活动的安全性进行监督检查。
