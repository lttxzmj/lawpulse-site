# 放射性废物安全管理条例第三十四条

- 法规：放射性废物安全管理条例（现行有效）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7902ee5694/34.html

禁止将放射性废物和被放射性污染的物品输入中华人民共和国境内或者经中华人民共和国境内转移。具体办法由国务院环境保护主管部门会同国务院商务主管部门、海关总署、国家出入境检验检疫主管部门制定。
