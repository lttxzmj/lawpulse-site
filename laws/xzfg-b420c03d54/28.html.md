# 中华人民共和国集会游行示威法实施条例第二十八条

- 法规：中华人民共和国集会游行示威法实施条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b420c03d54/28.html

对于依照《集会游行示威法》第二十七条的规定被强行带离现场或者立即予以拘留的，公安机关应当在24小时以内进行讯问。不需要追究法律责任的，可以令其具结悔过后释放；需要追究法律责任的，依照有关法律规定办理。
