# 中华人民共和国集会游行示威法实施条例第八条

- 法规：中华人民共和国集会游行示威法实施条例（现行有效）
- 章节：第二章集会游行示威的申请和许可
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b420c03d54/8.html

举行集会、游行、示威，必须有负责人。
下列人员不得担任集会、游行、示威的负责人：
(一)无行为能力人或者限制行为能力人；
(二)被判处刑罚尚未执行完毕的；
(三)正在被劳动教养的；
(四)正在被依法采取刑事强制措施或者法律规定的其他限制人身自由措施的。
