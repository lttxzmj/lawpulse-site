# 全国人口普查条例第三十三条

- 法规：全国人口普查条例（现行有效）
- 章节：第四章人口普查资料的管理和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b1cacd55ad/33.html

人口普查中获得的能够识别或者推断单个普查对象身份的资料，任何单位和个人不得对外提供、泄露，不得作为对人口普查对象作出具体行政行为的依据，不得用于人口普查以外的目的。
人口普查数据不得作为对地方人民政府进行政绩考核和责任追究的依据。
