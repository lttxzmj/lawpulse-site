# 全国人口普查条例第二十一条

- 法规：全国人口普查条例（现行有效）
- 章节：第三章人口普查的组织实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b1cacd55ad/21.html

普查机构应当对普查指导员和普查员进行业务培训，并对考核合格的人员颁发全国统一的普查指导员证或者普查员证。
普查指导员和普查员执行人口普查任务时，应当出示普查指导员证或者普查员证。
