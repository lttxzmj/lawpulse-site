# 最高人民法院关于人民法院对经劳动争议仲裁裁决的纠纷准予撤诉或驳回起诉后劳动争议仲裁裁决从何时起生效的解释第三条

- 法规：最高人民法院关于人民法院对经劳动争议仲裁裁决的纠纷准予撤诉或驳回起诉后劳动争议仲裁裁决从何时起生效的解释（现行有效，施行日期 2000-07-19）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c22364fd06/3.html

因仲裁裁决确定的主体资格错误或仲裁裁决事项不属于劳动争议，被人民法院驳回起诉的，原仲裁裁决不发生法律效力。
