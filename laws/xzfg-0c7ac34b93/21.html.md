# 中华人民共和国监控化学品管理条例第二十一条

- 法规：中华人民共和国监控化学品管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c7ac34b93/21.html

违反本条例规定，生产监控化学品的，由省、自治区、直辖市人民政府化学工业主管部门责令限期改正；逾期不改正的，可以处20万元以下的罚款；情节严重的，可以提请省、自治区、直辖市人民政府责令停产整顿。
