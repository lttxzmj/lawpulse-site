# 中华人民共和国监控化学品管理条例第七条

- 法规：中华人民共和国监控化学品管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c7ac34b93/7.html

国家对第二类、第三类监控化学品和第四类监控化学品中含磷、硫、氟的特定有机化学品的生产，实行特别许可制度；未经特别许可的，任何单位和个人均不得生产。特别许可办法，由国务院化学工业主管部门制定。
