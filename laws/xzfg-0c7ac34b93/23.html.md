# 中华人民共和国监控化学品管理条例第二十三条

- 法规：中华人民共和国监控化学品管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c7ac34b93/23.html

违反本条例规定，经营监控化学品的，由省、自治区、直辖市人民政府化学工业主管部门没收其违法经营的监控化学品和违法所得，可以并处违法经营额1倍以上2倍以下的罚款。
