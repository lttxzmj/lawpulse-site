# 中华人民共和国个人独资企业法第二十八条

- 法规：中华人民共和国个人独资企业法（现行有效，施行日期 2000-01-01）
- 章节：第四章个人独资企业的解散和清算
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sole-proprietorship-enterprise-law/28.html

个人独资企业解散后，原投资人对个人独资企业存续期间的债务仍应承担偿还责任，但债权人在五年内未向债务人提出偿债请求的，该责任消灭。
