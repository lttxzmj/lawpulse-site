# 最高人民法院关于审理交通肇事刑事案件具体应用法律若干问题的解释第三条

- 法规：最高人民法院关于审理交通肇事刑事案件具体应用法律若干问题的解释（现行有效，施行日期 2000-11-21）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-e630602fbf/3.html

“交通运输肇事后逃逸”，是指行为人具有本解释第二条第一款规定和第二款第（一）至（五）项规定的情形之一，在发生交通事故后，为逃避法律追究而逃跑的行为。
