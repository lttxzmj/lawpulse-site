# 城市市容和环境卫生管理条例第二十三条

- 法规：城市市容和环境卫生管理条例（现行有效）
- 章节：第三章城市环境卫生管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-63958e7404/23.html

按国家行政建制设立的市的主要街道、广场和公共水域的环境卫生，由环境卫生专业单位负责。
居住区、街巷等地方，由街道办事处负责组织专人清扫保洁。
