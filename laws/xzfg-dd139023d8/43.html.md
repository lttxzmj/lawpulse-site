# 化妆品监督管理条例第四十三条

- 法规：化妆品监督管理条例（现行有效，施行日期 2021-01-01）
- 章节：第三章生产经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dd139023d8/43.html

化妆品广告的内容应当真实、合法。
化妆品广告不得明示或者暗示产品具有医疗作用，不得含有虚假或者引人误解的内容，不得欺骗、误导消费者。
