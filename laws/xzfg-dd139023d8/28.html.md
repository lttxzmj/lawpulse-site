# 化妆品监督管理条例第二十八条

- 法规：化妆品监督管理条例（现行有效，施行日期 2021-01-01）
- 章节：第三章生产经营
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dd139023d8/28.html

化妆品注册人、备案人可以自行生产化妆品，也可以委托其他企业生产化妆品。
委托生产化妆品的，化妆品注册人、备案人应当委托取得相应化妆品生产许可的企业，并对受委托企业（以下称受托生产企业）的生产活动进行监督，保证其按照法定要求进行生产。受托生产企业应当依照法律、法规、强制性国家标准、技术规范以及合同约定进行生产，对生产活动负责，并接受化妆品注册人、备案人的监督。
