# 化妆品监督管理条例第四十九条

- 法规：化妆品监督管理条例（现行有效，施行日期 2021-01-01）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dd139023d8/49.html

化妆品检验机构按照国家有关认证认可的规定取得资质认定后，方可从事化妆品检验活动。化妆品检验机构的资质认定条件由国务院药品监督管理部门、国务院市场监督管理部门制定。
化妆品检验规范以及化妆品检验相关标准品管理规定，由国务院药品监督管理部门制定。
