# 化妆品监督管理条例第三条

- 法规：化妆品监督管理条例（现行有效，施行日期 2021-01-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dd139023d8/3.html

本条例所称化妆品，是指以涂擦、喷洒或者其他类似方法，施用于皮肤、毛发、指甲、口唇等人体表面，以清洁、保护、美化、修饰为目的的日用化学工业产品。
