# 人民检察院公益诉讼办案规则第六十七条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第三章行政公益诉讼 · 第一节立案与调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/67.html

人民检察院经过对行政公益诉讼案件线索进行评估，认为同时存在以下情形的，应当立案：
国家利益或者社会公共利益受到侵害；
（二）生态环境和资源保护、食品药品安全、国有财产保护、国有土地使用权出让、未成年人保护等领域对保护国家利益或者社会公共利益负有监督管理职责的行政机关可能违法行使职权或者不作为。
