# 人民检察院公益诉讼办案规则第四十一条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第二章一般规定 · 第四节调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/41.html

人民检察院对专门性问题认为确有必要鉴定、评估、审计、检验、检测、翻译的，可以委托具备资格的机构进行鉴定、评估、审计、检验、检测、翻译，委托时应当制作《委托鉴定（评估、审计、检验、检测、翻译）函》。
