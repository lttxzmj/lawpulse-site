# 人民检察院公益诉讼办案规则第八十一条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第三章行政公益诉讼 · 第三节提起诉讼
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/81.html

行政机关经检察建议督促仍然没有依法履行职责，国家利益或者社会公共利益处于受侵害状态的，人民检察院应当依法提起行政公益诉讼。
