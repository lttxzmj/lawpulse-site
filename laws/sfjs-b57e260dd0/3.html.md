# 人民检察院公益诉讼办案规则第三条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/3.html

人民检察院办理公益诉讼案件，应当遵守宪法、法律和相关法规，秉持客观公正立场，遵循相关诉讼制度的基本原则和程序规定，坚持司法公开。
