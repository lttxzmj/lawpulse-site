# 人民检察院公益诉讼办案规则第七十四条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第三章行政公益诉讼 · 第一节立案与调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/74.html

经调查，人民检察院认为存在下列情形之一的，应当作出终结案件决定：
（一）行政机关未违法行使职权或者不作为的；
（二）国家利益或者社会公共利益已经得到有效保护的；
（三）行政机关已经全面采取整改措施依法履行职责的；
（四）其他应当终结案件的情形。
终结案件的，应当报检察长决定，并制作《终结案件决定书》送达行政机关。
