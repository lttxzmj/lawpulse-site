# 人民检察院公益诉讼办案规则第七十一条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第三章行政公益诉讼 · 第一节立案与调查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/71.html

人民检察院办理行政公益诉讼案件，围绕以下事项进行调查：
（一）国家利益或者社会公共利益受到侵害的事实；
（二）行政机关的监督管理职责；
（三）行政机关不依法履行职责的行为；
（四）行政机关不依法履行职责的行为与国家利益或者社会公共利益受到侵害的关联性；
（五）其他需要查明的事项。
