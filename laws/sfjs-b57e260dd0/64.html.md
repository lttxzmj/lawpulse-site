# 人民检察院公益诉讼办案规则第六十四条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第二章一般规定 · 第八节诉讼监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/64.html

最高人民检察院发现各级人民法院、上级人民检察院发现下级人民法院已经发生法律效力的公益诉讼判决、裁定确有错误，损害国家利益或者社会公共利益的，应当依法提出抗诉。
