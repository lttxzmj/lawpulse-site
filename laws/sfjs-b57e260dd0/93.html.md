# 人民检察院公益诉讼办案规则第九十三条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第四章民事公益诉讼 · 第二节公告
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/93.html

发布公告后，人民检察院应当对赔偿权利人启动生态环境损害赔偿程序情况、适格主体起诉情况、英雄烈士等的近亲属提起民事诉讼情况，以及社会公共利益受到损害的情况跟进调查，收集相关证据材料。
