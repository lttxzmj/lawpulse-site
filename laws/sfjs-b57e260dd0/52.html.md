# 人民检察院公益诉讼办案规则第五十二条

- 法规：人民检察院公益诉讼办案规则（现行有效，施行日期 2021-07-01）
- 章节：第二章一般规定 · 第六节出席第一审法庭
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b57e260dd0/52.html

出庭检察人员应当客观、全面地向法庭出示证据。根据庭审情况合理安排举证顺序，分组列举证据，可以使用多媒体等示证方式。质证应当围绕证据的真实性、合法性、关联性展开。
