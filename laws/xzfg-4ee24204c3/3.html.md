# 碳排放权交易管理暂行条例第三条

- 法规：碳排放权交易管理暂行条例（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4ee24204c3/3.html

碳排放权交易及相关活动的管理，应当坚持中国共产党的领导，贯彻党和国家路线方针政策和决策部署，坚持温室气体排放控制与经济社会发展相适应，坚持政府引导与市场调节相结合，遵循公开、公平、公正的原则。
国家加强碳排放权交易领域的国际合作与交流。
