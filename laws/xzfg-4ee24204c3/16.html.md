# 碳排放权交易管理暂行条例第十六条

- 法规：碳排放权交易管理暂行条例（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4ee24204c3/16.html

国务院生态环境主管部门建立全国碳排放权交易市场管理平台，加强对碳排放配额分配、清缴以及重点排放单位温室气体排放情况等的全过程监督管理，并与国务院有关部门实现信息共享。
