# 最高人民法院关于人民法院民事调解工作若干问题的规定第三条

- 法规：最高人民法院关于人民法院民事调解工作若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-8d302b1f9f/3.html

人民法院应当在调解前告知当事人主持调解人员和书记员姓名以及是否申请回避等有关诉讼权利和诉讼义务。
