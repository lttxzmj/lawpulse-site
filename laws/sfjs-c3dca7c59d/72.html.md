# 最高人民法院关于行政诉讼证据若干问题的规定第七十二条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/72.html

庭审中经过质证的证据，能够当庭认定的，应当当庭认定；不能当庭认定的，应当在合议庭合议时认定。
人民法院应当在裁判文书中阐明证据是否采纳的理由。
