# 最高人民法院关于行政诉讼证据若干问题的规定第四十九条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/49.html

法庭在质证过程中，对与案件没有关联的证据材料，应予排除并说明理由。
法庭在质证过程中，准许当事人补充证据的，对补充的证据仍应进行质证。
法庭对经过庭审质证的证据，除确有必要外，一般不再进行质证。
