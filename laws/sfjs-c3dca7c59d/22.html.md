# 最高人民法院关于行政诉讼证据若干问题的规定第二十二条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/22.html

根据行政诉讼法第三十四条第二款的规定，有下列情形之一的，人民法院有权向有关行政机关以及其他组织、公民调取证据：
（一）涉及国家利益、公共利益或者他人合法权益的事实认定的；
（二）涉及依职权追加当事人、中止诉讼、终结诉讼、回避等程序性事项的。
