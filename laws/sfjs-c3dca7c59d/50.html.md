# 最高人民法院关于行政诉讼证据若干问题的规定第五十条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/50.html

在第二审程序中，对当事人依法提供的新的证据，法庭应当进行质证；当事人对第一审认定的证据仍有争议的，法庭也应当进行质证。
