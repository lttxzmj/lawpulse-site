# 最高人民法院关于行政诉讼证据若干问题的规定第二十八条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/28.html

人民法院依照行政诉讼法第三十六条规定保全证据的，可以根据具体情况，采取查封、扣押、拍照、录音、录像、复制、鉴定、勘验、制作询问笔录等保全措施。
人民法院保全证据时，可以要求当事人或者其诉讼代理人到场。
