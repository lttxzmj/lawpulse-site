# 最高人民法院关于行政诉讼证据若干问题的规定第八十条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/80.html

本规定自2002年10月1日起施行。2002年10月1日尚未审结的一审、二审和再审行政案件不适用本规定。
本规定施行前已经审结的行政案件，当事人以违反本规定为由申请再审的，人民法院不予支持。
本规定施行后按照审判监督程序决定再审的行政案件，适用本规定。
