# 最高人民法院关于行政诉讼证据若干问题的规定第二十三条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/23.html

原告或者第三人不能自行收集，但能够提供确切线索的，可以申请人民法院调取下列证据材料：
（一）由国家有关部门保存而须由人民法院调取的证据材料；
（二）涉及国家秘密、商业秘密、个人隐私的证据材料；
（三）确因客观原因不能自行收集的其他证据材料。
人民法院不得为证明被诉具体行政行为的合法性，调取被告在作出具体行政行为时未收集的证据。
