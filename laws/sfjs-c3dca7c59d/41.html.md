# 最高人民法院关于行政诉讼证据若干问题的规定第四十一条

- 法规：最高人民法院关于行政诉讼证据若干问题的规定（现行有效，施行日期 2002-10-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-c3dca7c59d/41.html

凡是知道案件事实的人，都有出庭作证的义务。有下列情形之一的，经人民法院准许，当事人可以提交书面证言：
（一）当事人在行政程序或者庭前证据交换中对证人证言无异议的；
（二）证人因年迈体弱或者行动不便无法出庭的；
（三）证人因路途遥远、交通不便无法出庭的；
（四）证人因自然灾害等不可抗力或者其他意外事件无法出庭的；
（五）证人因其他特殊原因确实无法出庭的。
