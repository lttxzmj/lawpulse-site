# 最高人民法院关于审理劳动争议案件适用法律问题的解释（一）第三条

- 法规：最高人民法院关于审理劳动争议案件适用法律问题的解释（一）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-laodong-1/3.html

劳动争议案件由用人单位所在地或者劳动合同履行地的基层人民法院管辖。
劳动合同履行地不明确的，由用人单位所在地的基层人民法院管辖。
法律另有规定的，依照其规定。
