# 最高人民法院关于审理海事赔偿责任限制相关纠纷案件的若干规定第十六条

- 法规：最高人民法院关于审理海事赔偿责任限制相关纠纷案件的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4347fa3d57/16.html

责任人对海商法第二百零七条规定的海事赔偿请求未提出海事赔偿责任限制抗辩，债权人依据有关生效裁判文书或者仲裁裁决书，申请执行责任人海事赔偿责任限制基金以外的财产的，人民法院应予支持，但债权人以上述文书作为债权证据申请登记债权并经海事法院裁定准予的除外。
