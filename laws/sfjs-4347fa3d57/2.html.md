# 最高人民法院关于审理海事赔偿责任限制相关纠纷案件的若干规定第二条

- 法规：最高人民法院关于审理海事赔偿责任限制相关纠纷案件的若干规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-4347fa3d57/2.html

同一海事事故中，不同的责任人在起诉前依据海事诉讼特别程序法第一百零二条的规定向不同的海事法院申请设立海事赔偿责任限制基金的，后立案的海事法院应当依照民事诉讼法的规定，将案件移送先立案的海事法院管辖。
