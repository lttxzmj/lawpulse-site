# 财政违法行为处罚处分条例第二十八条

- 法规：财政违法行为处罚处分条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-05ca39f964/28.html

财政部门、审计机关、监察机关的工作人员滥用职权、玩忽职守、徇私舞弊的，给予警告、记过或者记大过处分；情节较重的，给予降级或者撤职处分；情节严重的，给予开除处分。构成犯罪的，依法追究刑事责任。
