# 中华人民共和国无障碍环境建设法第三条

- 法规：中华人民共和国无障碍环境建设法（现行有效，施行日期 2023-09-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/accessibility-law/3.html

无障碍环境建设应当坚持中国共产党的领导，发挥政府主导作用，调动市场主体积极性，引导社会组织和公众广泛参与，推动全社会共建共治共享。
