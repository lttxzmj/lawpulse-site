# 中华人民共和国渔业法实施细则第十八条

- 法规：中华人民共和国渔业法实施细则（现行有效，施行日期 2020-11-29）
- 章节：第四章捕捞业
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-322f2742fd/18.html

娱乐性游钓和在尚未养殖、管理的滩涂手工采集零星水产品的，不必申请捕捞许可证，但应当加强管理，防止破坏渔业资源。具体管理办法由县级以上人民政府制定。
