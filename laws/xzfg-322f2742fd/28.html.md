# 中华人民共和国渔业法实施细则第二十八条

- 法规：中华人民共和国渔业法实施细则（现行有效，施行日期 2020-11-29）
- 章节：第五章渔业资源的增殖和保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-322f2742fd/28.html

在重点渔业水域不得从事拆船业。在其他渔业水域从事拆船业，造成渔业资源损害的，由拆船单位依照有关规定负责赔偿。
