# 中华人民共和国渔业法实施细则第二十三条

- 法规：中华人民共和国渔业法实施细则（现行有效，施行日期 2020-11-29）
- 章节：第五章渔业资源的增殖和保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-322f2742fd/23.html

定置渔业一般不得跨县作业。县级以上人民政府渔业行政主管部门应当限制其网桩数量、作业场所，并规定禁渔期。海洋定置渔业，不得越出“机动渔船底拖网禁渔区线”。
