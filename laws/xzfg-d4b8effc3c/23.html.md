# 拘留所条例第二十三条

- 法规：拘留所条例（现行有效）
- 章节：第四章管理教育
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d4b8effc3c/23.html

被拘留人有下列违法行为之一的，拘留所可以予以训诫、责令具结悔过或者使用警械：
(一)哄闹、打架斗殴的；
(二)殴打、欺侮他人的；
(三)故意损毁拘留所财物或者他人财物的；
(四)预谋或者实施逃跑的；
(五)严重违反管理的其他行为。
拘留所人民警察对被拘留人使用警械应当经拘留所所长批准，并遵守有关法律、行政法规的规定。
