# 拘留所条例第三条

- 法规：拘留所条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d4b8effc3c/3.html

拘留所应当依法保障被拘留人的人身安全和合法权益，不得侮辱、体罚、虐待被拘留人或者指使、纵容他人侮辱、体罚、虐待被拘留人。
被拘留人应当遵守法律、行政法规和拘留所的管理规定，服从管理，接受教育。
