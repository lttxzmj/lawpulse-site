# 最高人民法院关于死刑缓期执行限制减刑案件审理程序若干问题的规定第三条

- 法规：最高人民法院关于死刑缓期执行限制减刑案件审理程序若干问题的规定（现行有效，施行日期 2011-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-24861481f6/3.html

高级人民法院审理或者复核判处死刑缓期执行并限制减刑的案件，认为原判对被告人判处死刑缓期执行适当，但判决限制减刑不当的，应当改判，撤销限制减刑。
