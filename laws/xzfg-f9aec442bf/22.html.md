# 中华人民共和国海上航行警告和航行通告管理规定第二十二条

- 法规：中华人民共和国海上航行警告和航行通告管理规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9aec442bf/22.html

在渔港水域内新建、改建、扩建各种设施或者进行其他施工作业，由渔政渔港监督管理机关根据本规定和国家其他有关规定发布海上航行通告。
