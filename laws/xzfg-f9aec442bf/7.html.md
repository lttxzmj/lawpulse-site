# 中华人民共和国海上航行警告和航行通告管理规定第七条

- 法规：中华人民共和国海上航行警告和航行通告管理规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9aec442bf/7.html

船舶从事本规定第五条第(九)项所列活动的，应当在启拖开始之日的三天前向启拖地所在海区的区域主管机关递交发布海上航行警告、航行通告的书面申请。
书面申请应当包括下列内容：
(一)拖船、被拖船或者被拖物的名称；
(二)启拖时间；
(三)启始位置、终到位置及主要转向点位置；
(四)拖带总长度；
(五)航速。
