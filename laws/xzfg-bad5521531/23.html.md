# 中华人民共和国测绘成果管理条例第二十三条

- 法规：中华人民共和国测绘成果管理条例（现行有效）
- 章节：第四章重要地理信息数据的审核与公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bad5521531/23.html

重要地理信息数据包括：
(一)国界、国家海岸线长度；
(二)领土、领海、毗连区、专属经济区面积；
(三)国家海岸滩涂面积、岛礁数量和面积；
(四)国家版图的重要特征点，地势、地貌分区位置；
(五)国务院测绘行政主管部门商国务院其他有关部门确定的其他重要自然和人文地理实体的位置、高程、深度、面积、长度等地理信息数据。
