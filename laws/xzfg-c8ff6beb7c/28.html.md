# 中华人民共和国传染病防治法实施办法第二十八条

- 法规：中华人民共和国传染病防治法实施办法（现行有效）
- 章节：第二章预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c8ff6beb7c/28.html

发现人畜共患传染病已在人、畜间流行时，卫生行政部门与畜牧兽医部门应当深入疫区，按照职责分别对人、畜开展防治工作。
传染病流行区的家畜家禽，未经畜牧兽医部门检疫不得外运。
进入鼠疫自然疫源地捕猎旱獭应按照国家有关规定执行。
