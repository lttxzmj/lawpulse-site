# 中华人民共和国传染病防治法实施办法第六十条

- 法规：中华人民共和国传染病防治法实施办法（现行有效）
- 章节：第五章监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c8ff6beb7c/60.html

传染病管理监督员执行下列任务：
(一)监督检查《传染病防治法》及本办法的执行情况；
(二)进行现场调查，包括采集必需的标本及查阅、索取、翻印复制必要的文字、图片、声像资料等，并根据调查情况写出书面报告；
(三)对违法单位或者个人提出处罚建议；
(四)执行卫生行政部门或者其他有关部门卫生主管机构交付的任务；
(五)及时提出预防和控制传染病措施的建议。
