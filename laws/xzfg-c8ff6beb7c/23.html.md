# 中华人民共和国传染病防治法实施办法第二十三条

- 法规：中华人民共和国传染病防治法实施办法（现行有效）
- 章节：第二章预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c8ff6beb7c/23.html

出售、运输被传染病病原体污染或者来自疫区可能被传染病病原体污染的皮毛、旧衣物及生活用品等，必须按照卫生防疫机构的要求进行必要的卫生处理。
