# 中华人民共和国传染病防治法实施办法第六十九条

- 法规：中华人民共和国传染病防治法实施办法（现行有效）
- 章节：第六章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c8ff6beb7c/69.html

单位和个人非法经营、出售用于预防传染病菌苗、疫苗等生物制品的，县级以上政府卫生行政部门可以处相当出售金额三倍以下的罚款，危害严重，出售金额不满五千元的，以五千元计算；对主管人员和直接责任人员由所在单位或者上级机关根据情节，可以给予行政处分。
