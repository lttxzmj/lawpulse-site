# 中华人民共和国传染病防治法实施办法第五十三条

- 法规：中华人民共和国传染病防治法实施办法（现行有效）
- 章节：第四章控制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c8ff6beb7c/53.html

县级以上政府接到下一级政府关于采取《传染病防治法》第二十五条规定的紧急措施报告时，应当在二十四小时内做出决定。下一级政府在上一级政府作出决定前，必要时，可以临时采取《传染病防治法》第二十五条第一款第(一)、(四)项紧急措施，但不得超过二十四小时。
