# 基本农田保护条例第二十八条

- 法规：基本农田保护条例（现行有效）
- 章节：第四章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8129797195/28.html

县级以上地方人民政府应当建立基本农田保护监督检查制度，定期组织土地行政主管部门、农业行政主管部门以及其他有关部门对基本农田保护情况进行检查，将检查情况书面报告上一级人民政府。被检查的单位和个人应当如实提供有关情况和资料，不得拒绝。
