# 民用运力国防动员条例第四十二条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第五章经费保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/42.html

民用运力国防动员所需费用，由中央财政和县级以上地方各级财政共同负担。
中央财政负担的费用，列入中央预算；县级以上地方各级财政负担的费用，列入本级政府预算。
