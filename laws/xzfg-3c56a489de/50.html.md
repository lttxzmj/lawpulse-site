# 民用运力国防动员条例第五十条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/50.html

违反本条例的规定，县级以上人民政府交通运输管理部门、公安交通管理部门和其他有关部门拒绝向国防交通主管机构报送或者迟延报送上一年度民用运力登记的有关资料和情况的，由本级人民政府责令限期报送；逾期未报送的，对负有直接责任的主管人员和其他直接责任人员，由有关主管机关依法给予记过、记大过、降级的行政处分。
