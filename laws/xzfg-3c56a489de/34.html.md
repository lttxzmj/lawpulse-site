# 民用运力国防动员条例第三十四条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第三章民用运力国防动员的实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/34.html

民用运力国防动员实施过程中，需要使用港口、码头、机场、车站和其他设施的，由国防交通主管机构事先向有关部门或者单位提出使用要求，有关部门和单位应当予以配合、支持。
