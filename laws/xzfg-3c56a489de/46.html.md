# 民用运力国防动员条例第四十六条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/46.html

违反本条例的规定，预征民用运力的单位或者个人逃避或者拒不履行民用运力国防动员义务的，由设区的市级人民政府国防交通主管机构责令改正；拒不改正的，强制其履行义务，可以对单位处2万元以上10万元以下的罚款，对个人处2000元以上1万元以下的罚款；构成犯罪的，依法追究刑事责任。
