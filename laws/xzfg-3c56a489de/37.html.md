# 民用运力国防动员条例第三十七条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第四章补偿与抚恤
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/37.html

民用运力国防动员任务完成后，使用民用运力的单位应当收拢民用运力，清查动员民用运力数量，统计民用运载工具及相关设备、设施的损失、损坏情况以及操作、保障人员的伤亡情况，按照有关规定办理移交手续，并出具民用运力使用、损毁情况证明。
