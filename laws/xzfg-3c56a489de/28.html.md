# 民用运力国防动员条例第二十八条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第三章民用运力国防动员的实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/28.html

战时的民用运力国防动员，依据国家主席发布的动员令实施。
平时特殊情况下的民用运力国防动员，依据国务院、中央军事委员会发布的民用运力国防动员决定实施。
