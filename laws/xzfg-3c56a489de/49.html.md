# 民用运力国防动员条例第四十九条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/49.html

破坏预征民用运载工具及相关设备或者以其他方式阻碍、干扰民用运力国防动员活动，造成损失或者不良影响的，由公安机关依照《中华人民共和国治安管理处罚法》给予处罚；构成犯罪的，依法追究刑事责任。
