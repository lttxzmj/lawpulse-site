# 民用运力国防动员条例第七条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/7.html

县级以上各级人民政府应当采取有效措施，加强民用运力国防动员准备工作，将民用运力国防动员准备工作纳入国民经济和社会发展计划，增强动员潜力，支持和督促其有关部门依法履行职责，落实民用运力国防动员的各项工作。
