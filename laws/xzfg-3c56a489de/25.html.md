# 民用运力国防动员条例第二十五条

- 法规：民用运力国防动员条例（现行有效）
- 章节：第二章民用运力国防动员的准备
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3c56a489de/25.html

人民武装动员机构应当会同国防交通主管机构和军队负责军事交通运输工作的部门，根据民用运力国防动员准备要求，结合预征民用运力担负的运输生产任务，组织预征民用运力进行必要的军事训练和专业技术训练。
参加预征民用运力训练的人员，训练期间的误工补贴或者在原单位的工资、奖金、福利待遇以及伙食补助、往返差旅费等，训练人员纳入民兵组织的，依照国家有关民兵参加军事训练的规定执行；训练人员未纳入民兵组织的，参照国家有关民兵参加军事训练的规定执行。
