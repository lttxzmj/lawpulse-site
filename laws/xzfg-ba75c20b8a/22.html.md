# 中华人民共和国外国人入境出境管理条例第二十二条

- 法规：中华人民共和国外国人入境出境管理条例（现行有效，施行日期 2025-10-01）
- 章节：第三章停留居留管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba75c20b8a/22.html

持学习类居留证件的外国人需要在校外勤工助学或者实习的，应当经所在学校同意后，向公安机关出入境管理机构申请居留证件加注勤工助学或者实习地点、期限等信息。
持学习类居留证件的外国人所持居留证件未加注前款规定信息的，不得在校外勤工助学或者实习。
