# 中华人民共和国外国人入境出境管理条例第十一条

- 法规：中华人民共和国外国人入境出境管理条例（现行有效，施行日期 2025-10-01）
- 章节：第三章停留居留管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba75c20b8a/11.html

在中国境内的外国人所持签证遗失、损毁、被盗抢的，应当及时向停留地县级以上地方人民政府公安机关出入境管理机构申请补发签证。
