# 中华人民共和国外国人入境出境管理条例第二十三条

- 法规：中华人民共和国外国人入境出境管理条例（现行有效，施行日期 2025-10-01）
- 章节：第三章停留居留管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ba75c20b8a/23.html

在中国境内的外国人因证件遗失、损毁、被盗抢等原因未持有效护照或者国际旅行证件，无法在本国驻中国有关机构补办的，可以向停留居留地县级以上地方人民政府公安机关出入境管理机构申请办理出境手续。
