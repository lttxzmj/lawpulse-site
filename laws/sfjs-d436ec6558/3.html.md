# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（一）第三条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（一）（现行有效，施行日期 2011-09-26）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d436ec6558/3.html

债务人的资产负债表，或者审计报告、资产评估报告等显示其全部资产不足以偿付全部负债的，人民法院应当认定债务人资产不足以清偿全部债务，但有相反证据足以证明债务人资产能够偿付全部负债的除外。
