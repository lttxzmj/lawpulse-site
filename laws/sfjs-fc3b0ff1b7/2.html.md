# 最高人民法院关于审理破坏土地资源刑事案件具体应用法律若干问题的解释第二条

- 法规：最高人民法院关于审理破坏土地资源刑事案件具体应用法律若干问题的解释（现行有效，施行日期 2000-06-22）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-fc3b0ff1b7/2.html

实施第一条规定的行为，具有下列情形之一的，属于非法转让、倒卖土地使用权“情节特别严重”：
（一）非法转让、倒卖基本农田10亩以上的；
（二）非法转让、倒卖基本农田以外的耕地20亩以上的；
（三）非法转让、倒卖其他土地40亩以上的；
（四）非法获利100万元以上的；
（五）非法转让、倒卖土地接近上述数量标准并具有其他恶劣情节，如造成严重后果等。
