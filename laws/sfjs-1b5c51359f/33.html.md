# 人民检察院检察委员会工作规则第三十三条

- 法规：人民检察院检察委员会工作规则（现行有效，施行日期 2020-07-31）
- 章节：第六章决定的执行和督办
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-1b5c51359f/33.html

检察委员会办事机构应当及时了解办案检察官或者事项承办人和有关内设机构、下级人民检察院执行检察委员会决定的情况，必要时进行督办，重要情况及时报告检察长。
