# 最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定第十一条

- 法规：最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-11ed603120/11.html

居住在我国境内的外国法院离婚判决的被告为申请人，提交第八条、第十条所要求的证明文件和公证、认证有困难的，如能提交外国法院的应诉通知或出庭传票的，可推定外国法院离婚判决书为真实和已经生效。
