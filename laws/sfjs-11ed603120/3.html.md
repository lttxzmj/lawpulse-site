# 最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定第三条

- 法规：最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-11ed603120/3.html

向人民法院申请承认外国法院的离婚判决，申请人应提出书面申请书，并须附有外国法院离婚判决书正本及经证明无误的中文译本。否则，不予受理。
