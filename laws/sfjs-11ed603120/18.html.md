# 最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定第十八条

- 法规：最高人民法院关于中国公民申请承认外国法院离婚判决程序问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-11ed603120/18.html

人民法院受理离婚诉讼后，原告一方变更请求申请承认外国法院离婚判决，或者被告一方另提出承认外国法院离婚判决申请的，其申请均不受理。
