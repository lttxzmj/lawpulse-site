# 中华人民共和国工业产品生产许可证管理条例第六十三条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/63.html

工业产品生产许可证主管部门违法实施许可，给当事人的合法权益造成损害的，应当依照《中华人民共和国国家赔偿法》的规定给予赔偿。
