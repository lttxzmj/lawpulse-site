# 中华人民共和国工业产品生产许可证管理条例第五十九条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/59.html

县级以上地方工业产品生产许可证主管部门违反本条例规定，对列入目录产品以外的工业产品设定生产许可的，由国务院工业产品生产许可证主管部门责令改正，或者依法予以撤销。
