# 中华人民共和国工业产品生产许可证管理条例第五十三条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/53.html

取得生产许可证的企业未依照本条例规定定期向省、自治区、直辖市工业产品生产许可证主管部门提交报告的，由省、自治区、直辖市工业产品生产许可证主管部门责令限期改正。
