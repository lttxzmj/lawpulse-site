# 中华人民共和国工业产品生产许可证管理条例第五十一条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/51.html

伪造、变造许可证证书、生产许可证标志和编号的，责令改正，没收违法生产、销售的产品，并处违法生产、销售产品货值金额等值以上3倍以下的罚款；有违法所得的，没收违法所得；构成犯罪的，依法追究刑事责任。
