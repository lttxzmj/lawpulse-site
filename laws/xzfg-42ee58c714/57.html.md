# 中华人民共和国工业产品生产许可证管理条例第五十七条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/57.html

检验机构和检验人员从事与其检验的列入目录产品相关的生产、销售活动，或者以其名义推荐或者监制、监销其检验的列入目录产品的，由工业产品生产许可证主管部门处2万元以上10万元以下的罚款；有违法所得的，没收违法所得；情节严重的，撤销其检验资格。
