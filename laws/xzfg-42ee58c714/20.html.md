# 中华人民共和国工业产品生产许可证管理条例第二十条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第三章审查与决定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/20.html

检验机构应当依照国家有关标准、要求进行产品检验，在规定时间内完成检验工作。
检验机构和检验人员应当客观、公正、及时地出具检验报告。检验报告经检验人员签字后，由检验机构负责人签署。检验机构和检验人员对检验报告负责。
