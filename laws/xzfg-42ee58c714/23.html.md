# 中华人民共和国工业产品生产许可证管理条例第二十三条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第三章审查与决定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/23.html

由省、自治区、直辖市工业产品生产许可证主管部门组织对企业进行审查的，省、自治区、直辖市工业产品生产许可证主管部门应当在完成审查后将审查意见和全部申请材料报送国务院工业产品生产许可证主管部门。
