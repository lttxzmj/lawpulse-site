# 中华人民共和国工业产品生产许可证管理条例第三十五条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第四章证书和标志
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/35.html

任何单位和个人不得伪造、变造许可证证书、生产许可证标志和编号。取得生产许可证的企业不得出租、出借或者以其他形式转让许可证证书和生产许可证标志。
