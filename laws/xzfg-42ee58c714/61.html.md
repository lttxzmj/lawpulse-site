# 中华人民共和国工业产品生产许可证管理条例第六十一条

- 法规：中华人民共和国工业产品生产许可证管理条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-42ee58c714/61.html

工业产品生产许可证主管部门的工作人员办理工业产品生产许可证、实施监督检查，索取或者收受他人财物或者谋取其他利益，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予行政处分。
