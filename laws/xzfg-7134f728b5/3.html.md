# 地震安全性评价管理条例第三条

- 法规：地震安全性评价管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7134f728b5/3.html

新建、扩建、改建建设工程，依照《中华人民共和国防震减灾法》和本条例的规定，需要进行地震安全性评价的，必须严格执行国家地震安全性评价的技术规范，确保地震安全性评价的质量。
