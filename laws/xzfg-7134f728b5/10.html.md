# 地震安全性评价管理条例第十条

- 法规：地震安全性评价管理条例（现行有效）
- 章节：第四章地震安全性评价报告的审定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7134f728b5/10.html

国务院地震工作主管部门负责下列地震安全性评价报告的审定：
(一)国家重大建设工程；
(二)跨省、自治区、直辖市行政区域的建设工程；
(三)核电站和核设施建设工程。
省、自治区、直辖市人民政府负责管理地震工作的部门或者机构负责除前款规定以外的建设工程地震安全性评价报告的审定。
