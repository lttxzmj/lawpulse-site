# 最高人民法院关于互联网法院案件管辖的规定第三条

- 法规：最高人民法院关于互联网法院案件管辖的规定（现行有效，施行日期 2025-11-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a551a9931b/3.html

当事人对互联网法院作出的判决、裁定提起上诉的案件，由互联网法院所在地的中级人民法院审理。所在地设有多个中级人民法院的，由高级人民法院指定的中级人民法院审理。
上诉案件属于专门人民法院管辖范围的，由相应的专门人民法院审理。
