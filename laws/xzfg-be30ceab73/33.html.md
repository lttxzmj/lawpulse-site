# 中华人民共和国文物保护法实施条例第三十三条

- 法规：中华人民共和国文物保护法实施条例（现行有效）
- 章节：第四章馆藏文物
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be30ceab73/33.html

从事馆藏文物修复、复制、拓印的单位，应当具备下列条件：
(一)有取得中级以上文物博物专业技术职务的人员；
(二)有从事馆藏文物修复、复制、拓印所需的场所和技术设备；
(三)法律、行政法规规定的其他条件。
