# 中华人民共和国文物保护法实施条例第六十三条

- 法规：中华人民共和国文物保护法实施条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-be30ceab73/63.html

违反本条例规定，改变国有的博物馆、纪念馆、文物保护单位等的事业性收入的用途的，对负有责任的主管人员和其他直接责任人员依法给予行政处分；构成犯罪的，依法追究刑事责任。
