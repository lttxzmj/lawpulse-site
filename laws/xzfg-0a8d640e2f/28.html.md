# 中国公民出国旅游管理办法第二十八条

- 法规：中国公民出国旅游管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0a8d640e2f/28.html

组团社违反本办法第十二条的规定，向旅游者提供虚假服务信息或者低于成本报价的，由工商行政管理部门依照《中华人民共和国消费者权益保护法》、《中华人民共和国反不正当竞争法》的有关规定给予处罚。
