# 中华人民共和国自然保护区条例第四十七条

- 法规：中华人民共和国自然保护区条例（现行有效，施行日期 2026-03-15）
- 章节：第五章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf1be4d767/47.html

涉及国家海洋权益的自然保护区，由国务院林业草原主管部门会同有关部门根据本条例制定具体管理办法。
省、自治区、直辖市人民政府可以根据本条例，制定实施办法。
