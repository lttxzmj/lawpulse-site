# 中华人民共和国自然保护区条例第十九条

- 法规：中华人民共和国自然保护区条例（现行有效，施行日期 2026-03-15）
- 章节：第二章自然保护区的设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf1be4d767/19.html

因自然保护区主要保护对象生存环境发生重大改变，确需调整自然保护区区域范围的，应当按照自然保护区设立的程序，经原批准设立该自然保护区的人民政府批准。自然保护区变更名称，按照前述程序办理。
国家级自然保护区、省级自然保护区调整管控分区，应当分别经国务院林业草原主管部门和所在地省、自治区、直辖市人民政府林业草原主管部门会同同级有关部门组织评审后批准。
自然保护区设立后，原则上不得撤销；因特殊情形失去保护价值的，经原批准设立该自然保护区的人民政府批准，可以撤销。
