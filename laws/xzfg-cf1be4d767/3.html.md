# 中华人民共和国自然保护区条例第三条

- 法规：中华人民共和国自然保护区条例（现行有效，施行日期 2026-03-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf1be4d767/3.html

自然保护区建设应当贯彻党和国家路线方针政策、决策部署，践行绿水青山就是金山银山理念，坚持以人民为中心的发展思想，坚持生态保护第一、统筹保护和发展，坚持因地制宜、突出特色，构建政府主导、多方参与、社会共享的机制，实现生态保护、绿色发展、民生改善相统一。
