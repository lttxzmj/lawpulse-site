# 最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定第三条

- 法规：最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-57921b3c0a/3.html

执行法院收到执行异议后三日内既不立案又不作出不予受理裁定，或者受理后无正当理由超过法定期限不作出异议裁定的，异议人可以向上一级人民法院提出异议。上一级人民法院审查后认为理由成立的，应当指令执行法院在三日内立案或者在十五日内作出异议裁定。
