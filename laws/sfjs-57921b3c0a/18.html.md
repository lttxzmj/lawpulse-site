# 最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定第十八条

- 法规：最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-57921b3c0a/18.html
