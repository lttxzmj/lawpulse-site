# 最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定第十九条

- 法规：最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-57921b3c0a/19.html

当事人互负到期债务，被执行人请求抵销，请求抵销的债务符合下列情形的，除依照法律规定或者按照债务性质不得抵销的以外，人民法院应予支持：
（一）已经生效法律文书确定或者经申请执行人认可；
（二）与被执行人所负债务的标的物种类、品质相同。
