# 土地调查条例第三十三条

- 法规：土地调查条例（现行有效，施行日期 2018-03-19）
- 章节：第六章表彰和处罚
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2ab0160cd/33.html

县级以上地方人民政府有下列行为之一的，由上级人民政府予以通报批评；情节严重的，对直接负责的主管人员和其他直接责任人员依法给予处分：
（一）未按期完成土地调查工作，被责令限期完成，逾期仍未完成的；
（二）提供的土地调查数据失真，被责令限期改正，逾期仍未改正的。
