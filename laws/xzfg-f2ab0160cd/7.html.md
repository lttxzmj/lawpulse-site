# 土地调查条例第七条

- 法规：土地调查条例（现行有效，施行日期 2018-03-19）
- 章节：第二章土地调查的内容和方法
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2ab0160cd/7.html

土地调查包括下列内容：
（一）土地利用现状及变化情况，包括地类、位置、面积、分布等状况；
（二）土地权属及变化情况，包括土地的所有权和使用权状况；
（三）土地条件，包括土地的自然条件、社会经济条件等状况。
进行土地利用现状及变化情况调查时，应当重点调查基本农田现状及变化情况，包括基本农田的数量、分布和保护状况。
