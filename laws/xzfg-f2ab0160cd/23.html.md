# 土地调查条例第二十三条

- 法规：土地调查条例（现行有效，施行日期 2018-03-19）
- 章节：第四章调查成果处理和质量控制
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2ab0160cd/23.html

土地调查成果实行分阶段、分级检查验收制度。前一阶段土地调查成果经检查验收合格后，方可开展下一阶段的调查工作。
土地调查成果检查验收办法，由国务院国土资源主管部门会同国务院有关部门制定。
