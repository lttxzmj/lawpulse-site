# 土地调查条例第二十八条

- 法规：土地调查条例（现行有效，施行日期 2018-03-19）
- 章节：第五章调查成果公布和应用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f2ab0160cd/28.html

土地调查成果应当严格管理和规范使用，不作为依照其他法律、行政法规对调查对象实施行政处罚的依据，不作为划分部门职责分工和管理范围的依据。
