# 事业单位人事管理条例第四十一条

- 法规：事业单位人事管理条例（现行有效）
- 章节：第九章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-21fa00a1c4/41.html

事业单位违反本条例规定的，由县级以上事业单位人事综合管理部门或者主管部门责令限期改正；逾期不改正的，对直接负责的主管人员和其他直接责任人员依法给予处分。
