# 事业单位人事管理条例第三条

- 法规：事业单位人事管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-21fa00a1c4/3.html

中央事业单位人事综合管理部门负责全国事业单位人事综合管理工作。
县级以上地方各级事业单位人事综合管理部门负责本辖区事业单位人事综合管理工作。
事业单位主管部门具体负责所属事业单位人事管理工作。
