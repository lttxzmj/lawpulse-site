# 事业单位人事管理条例第二十三条

- 法规：事业单位人事管理条例（现行有效）
- 章节：第五章考核和培训
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-21fa00a1c4/23.html

事业单位应当根据不同岗位的要求，编制工作人员培训计划，对工作人员进行分级分类培训。
工作人员应当按照所在单位的要求，参加岗前培训、在岗培训、转岗培训和为完成特定任务的专项培训。
