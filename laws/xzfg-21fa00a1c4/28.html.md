# 事业单位人事管理条例第二十八条

- 法规：事业单位人事管理条例（现行有效）
- 章节：第六章奖励和处分
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-21fa00a1c4/28.html

事业单位工作人员有下列行为之一的，给予处分：
(一)损害国家声誉和利益的；
(二)失职渎职的；
(三)利用工作之便谋取不正当利益的；
(四)挥霍、浪费国家资财的；
(五)严重违反职业道德、社会公德的；
(六)其他严重违反纪律的。
