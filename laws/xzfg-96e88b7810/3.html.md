# 中华人民共和国金银管理条例第三条

- 法规：中华人民共和国金银管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-96e88b7810/3.html

国家对金银实行统一管理、统购统配的政策。
中华人民共和国境内的机关、部队、团体、学校、国营企业、事业单位，城乡集体经济组织(以下统称境内机构)的一切金银的收入和支出，都纳入国家金银收支计划。
