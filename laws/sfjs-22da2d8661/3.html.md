# 最高人民法院关于审理涉及计算机网络域名民事纠纷案件适用法律若干问题的解释第三条

- 法规：最高人民法院关于审理涉及计算机网络域名民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-22da2d8661/3.html

域名纠纷案件的案由，根据双方当事人争议的法律关系的性质确定，并在其前冠以计算机网络域名；争议的法律关系的性质难以确定的，可以通称为计算机网络域名纠纷案件。
