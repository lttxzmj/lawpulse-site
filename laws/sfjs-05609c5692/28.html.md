# 最高人民法院关于知识产权民事诉讼证据的若干规定第二十八条

- 法规：最高人民法院关于知识产权民事诉讼证据的若干规定（现行有效，施行日期 2020-11-18）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-05609c5692/28.html

当事人可以申请有专门知识的人出庭，就专业问题提出意见。经法庭准许，当事人可以对有专门知识的人进行询问。
