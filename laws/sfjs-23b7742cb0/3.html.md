# 最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（三）第三条

- 法规：最高人民法院关于适用《中华人民共和国企业破产法》若干问题的规定（三）（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-23b7742cb0/3.html

破产申请受理后，债务人欠缴款项产生的滞纳金，包括债务人未履行生效法律文书应当加倍支付的迟延利息和劳动保险金的滞纳金，债权人作为破产债权申报的，人民法院不予确认。
