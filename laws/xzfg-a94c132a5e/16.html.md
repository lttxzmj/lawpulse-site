# 广播电台电视台播放录音制品支付报酬暂行办法第十六条

- 法规：广播电台电视台播放录音制品支付报酬暂行办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a94c132a5e/16.html

广播电台、电视台与著作权人或者著作权集体管理组织因依照本办法规定支付报酬产生纠纷的，可以依法向人民法院提起民事诉讼，或者根据双方达成的书面仲裁协议向仲裁机构申请仲裁。
