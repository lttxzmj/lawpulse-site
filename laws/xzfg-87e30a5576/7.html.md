# 行政执法监督条例第七条

- 法规：行政执法监督条例（现行有效，施行日期 2026-02-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87e30a5576/7.html

行政执法监督机构承担下列职责：
（一）指导监督行政执法工作，组织落实行政执法责任制和责任追究制度；
（二）协调行政执法体制改革有关法治事项，协调行政执法争议；
（三）组织推动行政执法规范化、正规化、专业化、数字化建设；
（四）统筹实施行政执法主体、行政执法人员、行政执法行为、行政执法保障等方面的管理制度；
（五）法律、法规规定的其他职责。
