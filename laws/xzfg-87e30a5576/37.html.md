# 行政执法监督条例第三十七条

- 法规：行政执法监督条例（现行有效，施行日期 2026-02-01）
- 章节：第五章保障措施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87e30a5576/37.html

国务院行政执法监督机构应当提升全国行政执法监督信息一体化水平，对相关行政执法行为信息进行归集，运用大数据、云计算、人工智能等对行政执法过程中存在的问题进行快速预警，实现精准、高效、实时监督。
省、自治区、直辖市人民政府行政执法监督机构应当组织建设本行政区域的行政执法监督信息系统，加强数据共享，提高行政执法监督效能。
