# 行政执法监督条例第二十八条

- 法规：行政执法监督条例（现行有效，施行日期 2026-02-01）
- 章节：第四章监督处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87e30a5576/28.html

对行政执法监督工作中查明的违法或者明显不当的行政执法问题，行政执法监督机构可以制发行政执法监督意见书，监督有关行政执法机关予以纠正。
行政执法机关应当按照行政执法监督意见书的要求及时纠正，并在规定时限内向行政执法监督机构报送纠正情况。
