# 行政执法监督条例第二十一条

- 法规：行政执法监督条例（现行有效，施行日期 2026-02-01）
- 章节：第三章监督方式
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87e30a5576/21.html

省级以上人民政府行政执法监督机构根据党中央、国务院决策部署，可以结合人大代表建议、政协提案、监察建议、司法建议、检察建议、行政复议建议等反映的行政执法问题，对关系经济社会发展大局、人民群众切身利益的特定领域、特定问题开展专项监督。
开展专项监督应当制定工作方案，明确专项监督的责任部门、监督重点、进度安排和工作要求等，报本级人民政府批准。
