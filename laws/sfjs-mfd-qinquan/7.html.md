# 最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）第七条

- 法规：最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）（现行有效，施行日期 2024-09-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-qinquan/7.html

未成年子女造成他人损害，被侵权人请求父母共同承担侵权责任的，人民法院依照民法典第二十七条第一款、第一千零六十八条以及第一千一百八十八条的规定予以支持。
