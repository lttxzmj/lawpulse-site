# 最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）第十七条

- 法规：最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）（现行有效，施行日期 2024-09-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-qinquan/17.html

工作人员在执行工作任务中实施的违法行为造成他人损害，构成自然人犯罪的，工作人员承担刑事责任不影响用人单位依法承担民事责任。依照民法典第一千一百九十一条规定用人单位应当承担侵权责任的，在刑事案件中已完成的追缴、退赔可以在民事判决书中明确并扣减，也可以在执行程序中予以扣减。
