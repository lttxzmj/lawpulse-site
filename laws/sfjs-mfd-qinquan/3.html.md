# 最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）第三条

- 法规：最高人民法院关于适用《中华人民共和国民法典》侵权责任编的解释（一）（现行有效，施行日期 2024-09-27）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-mfd-qinquan/3.html

非法使被监护人脱离监护，被监护人在脱离监护期间死亡，作为近亲属的监护人既请求赔偿人身损害，又请求赔偿监护关系受侵害产生的损失的，人民法院依法予以支持。
