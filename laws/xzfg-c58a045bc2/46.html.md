# 中华人民共和国认证认可条例第四十六条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第四章认可
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/46.html

取得认可的机构应当在取得认可的范围内使用认可证书和认可标志。取得认可的机构不当使用认可证书和认可标志的，认可机构应当暂停其使用直至撤销认可证书，并予公布。
