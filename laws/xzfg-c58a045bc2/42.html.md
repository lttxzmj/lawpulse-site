# 中华人民共和国认证认可条例第四十二条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第四章认可
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/42.html

认可机构应当公开认可条件、认可程序、收费标准等信息。
认可机构受理认可申请，不得向申请人提出与认可活动无关的要求或者限制条件。
