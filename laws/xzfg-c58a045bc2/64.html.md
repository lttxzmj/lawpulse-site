# 中华人民共和国认证认可条例第六十四条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/64.html

指定的认证机构、实验室超出指定的业务范围从事列入目录产品的认证以及与认证有关的检查、检测活动的，责令改正，处10万元以上50万元以下的罚款，有违法所得的，没收违法所得；情节严重的，撤销指定直至撤销批准文件，并予公布。
指定的认证机构转让指定的认证业务的，依照前款规定处罚。
