# 中华人民共和国认证认可条例第四十四条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第四章认可
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/44.html

认可机构应当按照国家标准和国务院认证认可监督管理部门的规定，对从事评审、审核等认证活动的人员进行考核，考核合格的，予以注册。
