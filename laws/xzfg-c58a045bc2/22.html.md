# 中华人民共和国认证认可条例第二十二条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第三章认证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/22.html

认证机构及其认证人员应当及时作出认证结论，并保证认证结论的客观、真实。认证结论经认证人员签字后，由认证机构负责人签署。
认证机构及其认证人员对认证结果负责。
