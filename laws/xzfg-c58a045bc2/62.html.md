# 中华人民共和国认证认可条例第六十二条

- 法规：中华人民共和国认证认可条例（现行有效，施行日期 2023-07-20）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-c58a045bc2/62.html

认证人员从事认证活动，不在认证机构执业或者同时在两个以上认证机构执业的，责令改正，给予停止执业6个月以上2年以下的处罚，仍不改正的，撤销其执业资格。
