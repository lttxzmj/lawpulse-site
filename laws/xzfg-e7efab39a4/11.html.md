# 中国公民收养子女登记办法第十一条

- 法规：中国公民收养子女登记办法（现行有效，施行日期 2023-07-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e7efab39a4/11.html

收养登记机关收到解除收养关系登记申请书及有关材料后，应当自次日起30日内进行审查；对符合民法典规定的，为当事人办理解除收养关系的登记，收回收养登记证，发给解除收养关系证明。
