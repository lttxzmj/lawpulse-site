# 城市绿化条例第二十八条

- 法规：城市绿化条例（现行有效，施行日期 2026-03-20）
- 章节：第四章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-dbb27c386c/28.html

对不服从公共绿地管理单位管理的商业、服务摊点，由城市人民政府城市绿化行政主管部门或者其授权的单位给予警告，可以并处罚款；情节严重的，可以提请市场监督管理部门吊销营业执照。
