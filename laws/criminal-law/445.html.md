# 中华人民共和国刑法第四百四十五条

- 法规：中华人民共和国刑法（现行有效，施行日期 2021-03-01）
- 章节：第二编分则 · 第十章军人违反职责罪
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/criminal-law/445.html

战时在救护治疗职位上，有条件救治而拒不救治危重伤病军人的，处五年以下有期徒刑或者拘役；造成伤病军人重残、死亡或者有其他严重情节的，处五年以上十年以下有期徒刑。
