# 中华人民共和国刑法第四百二十六条

- 法规：中华人民共和国刑法（现行有效，施行日期 2021-03-01）
- 章节：第二编分则 · 第十章军人违反职责罪
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/criminal-law/426.html

以暴力、威胁方法，阻碍指挥人员或者值班、值勤人员执行职务的，处五年以下有期徒刑或者拘役；情节严重的，处五年以上十年以下有期徒刑；情节特别严重的，处十年以上有期徒刑或者无期徒刑。战时从重处罚。
