# 铁路交通事故应急救援和调查处理条例第三十三条

- 法规：铁路交通事故应急救援和调查处理条例（现行有效）
- 章节：第六章事故赔偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9db6e1e465/33.html

事故造成铁路旅客人身伤亡和自带行李损失的，铁路运输企业对每名铁路旅客人身伤亡的赔偿责任限额为人民币15万元，对每名铁路旅客自带行李损失的赔偿责任限额为人民币2000元。
铁路运输企业与铁路旅客可以书面约定高于前款规定的赔偿责任限额。(2012年11月9日删除)
