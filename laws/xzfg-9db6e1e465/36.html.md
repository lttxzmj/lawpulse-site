# 铁路交通事故应急救援和调查处理条例第三十六条

- 法规：铁路交通事故应急救援和调查处理条例（现行有效）
- 章节：第六章事故赔偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9db6e1e465/36.html

事故当事人对事故损害赔偿有争议的，可以通过协商解决，或者请求组织事故调查组的机关或者铁路管理机构组织调解，也可以直接向人民法院提起民事诉讼。
