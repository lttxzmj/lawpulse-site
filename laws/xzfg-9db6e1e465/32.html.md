# 铁路交通事故应急救援和调查处理条例第三十二条

- 法规：铁路交通事故应急救援和调查处理条例（现行有效）
- 章节：第六章事故赔偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9db6e1e465/32.html

事故造成人身伤亡的，铁路运输企业应当承担赔偿责任；但是人身伤亡是不可抗力或者受害人自身原因造成的，铁路运输企业不承担赔偿责任。
违章通过平交道口或者人行过道，或者在铁路线路上行走、坐卧造成的人身伤亡，属于受害人自身的原因造成的人身伤亡。
