# 铁路交通事故应急救援和调查处理条例第二十八条

- 法规：铁路交通事故应急救援和调查处理条例（现行有效）
- 章节：第五章事故调查处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9db6e1e465/28.html

事故调查处理，需要委托有关机构进行技术鉴定或者对铁路设备、设施及其他财产损失状况以及中断铁路行车造成的直接经济损失进行评估的，事故调查组应当委托具有国家规定资质的机构进行技术鉴定或者评估。技术鉴定或者评估所需时间不计入事故调查期限。
