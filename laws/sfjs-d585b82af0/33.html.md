# 最高人民法院关于审理与企业改制相关的民事纠纷案件若干问题的规定第三十三条

- 法规：最高人民法院关于审理与企业改制相关的民事纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d585b82af0/33.html

企业吸收合并或新设合并后，被兼并企业应当办理而未办理工商注销登记，债权人起诉被兼并企业的，人民法院应当根据企业兼并后的具体情况，告知债权人追加责任主体，并判令责任主体承担民事责任。
