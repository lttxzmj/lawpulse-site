# 缺陷汽车产品召回管理条例第二十二条

- 法规：缺陷汽车产品召回管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d3685ade11/22.html

生产者违反本条例规定，有下列情形之一的，由产品质量监督部门责令改正；拒不改正的，处5万元以上20万元以下的罚款：
(一)未按照规定保存有关汽车产品、车主的信息记录；
(二)未按照规定备案有关信息、召回计划；
(三)未按照规定提交有关召回报告。
