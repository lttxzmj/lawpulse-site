# 公共安全视频图像信息系统管理条例第三条

- 法规：公共安全视频图像信息系统管理条例（现行有效，施行日期 2025-04-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-496c7b627a/3.html

公共安全视频系统管理工作坚持中国共产党的领导，贯彻党和国家路线方针政策和决策部署。
建设、使用公共安全视频系统，应当遵守法律法规，坚持统筹规划、合理适度、标准引领、安全可控，不得危害国家安全、公共利益，不得损害个人、组织的合法权益。
