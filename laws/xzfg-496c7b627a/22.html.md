# 公共安全视频图像信息系统管理条例第二十二条

- 法规：公共安全视频图像信息系统管理条例（现行有效，施行日期 2025-04-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-496c7b627a/22.html

公共安全视频系统收集的视频图像信息被依法用于公开传播，可能损害个人、组织合法权益的，应当对涉及的人脸、机动车号牌等敏感个人信息，以及法人、非法人组织的名称、营业执照等信息采取严格保护措施。
