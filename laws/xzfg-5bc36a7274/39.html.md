# 中华人民共和国税收征收管理法实施细则第三十九条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第五章税款征收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/39.html

税务机关应当将各种税收的税款、滞纳金、罚款，按照国家规定的预算科目和预算级次及时缴入国库，税务机关不得占压、挪用、截留，不得缴入国库以外或者国家规定的税款账户以外的任何账户。
已缴入国库的税款、滞纳金、罚款，任何单位和个人不得擅自变更预算科目和预算级次。
