# 中华人民共和国税收征收管理法实施细则第九十一条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/91.html

非法印制、转借、倒卖、变造或者伪造完税凭证的，由税务机关责令改正，处2000元以上1万元以下的罚款；情节严重的，处1万元以上5万元以下的罚款；构成犯罪的，依法追究刑事责任。
