# 中华人民共和国税收征收管理法实施细则第五十七条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第五章税款征收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/57.html

税收征管法第三十七条所称未按照规定办理税务登记从事生产、经营的纳税人，包括到外县(市)从事生产、经营而未向营业地税务机关报验登记的纳税人。
