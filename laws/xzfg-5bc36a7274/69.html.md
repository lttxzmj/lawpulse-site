# 中华人民共和国税收征收管理法实施细则第六十九条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第五章税款征收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/69.html

税务机关将扣押、查封的商品、货物或者其他财产变价抵缴税款时，应当交由依法成立的拍卖机构拍卖；无法委托拍卖或者不适于拍卖的，可以交由当地商业企业代为销售，也可以责令纳税人限期处理；无法委托商业企业销售，纳税人也无法处理的，可以由税务机关变价处理，具体办法由国家税务总局规定。国家禁止自由买卖的商品，应当交由有关单位按照国家规定的价格收购。
拍卖或者变卖所得抵缴税款、滞纳金、罚款以及拍卖、变卖等费用后，剩余部分应当在3日内退还被执行人。
