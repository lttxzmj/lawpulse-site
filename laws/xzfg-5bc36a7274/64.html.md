# 中华人民共和国税收征收管理法实施细则第六十四条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第五章税款征收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/64.html

税务机关执行税收征管法第三十七条、第三十八条、第四十条的规定，扣押、查封价值相当于应纳税款的商品、货物或者其他财产时，参照同类商品的市场价、出厂价或者评估价估算。
税务机关按照前款方法确定应扣押、查封的商品、货物或者其他财产的价值时，还应当包括滞纳金和拍卖、变卖所发生的费用。
