# 中华人民共和国税收征收管理法实施细则第二十五条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第三章账簿、凭证管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/25.html

扣缴义务人应当自税收法律、行政法规规定的扣缴义务发生之日起10日内，按照所代扣、代收的税种，分别设置代扣代缴、代收代缴税款账簿。
