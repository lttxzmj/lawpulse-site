# 中华人民共和国税收征收管理法实施细则第六十八条

- 法规：中华人民共和国税收征收管理法实施细则（现行有效）
- 章节：第五章税款征收
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bc36a7274/68.html

纳税人在税务机关采取税收保全措施后，按照税务机关规定的期限缴纳税款的，税务机关应当自收到税款或者银行转回的完税凭证之日起1日内解除税收保全。
