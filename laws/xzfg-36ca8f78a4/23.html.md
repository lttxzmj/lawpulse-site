# 地震预报管理条例第二十三条

- 法规：地震预报管理条例（现行有效）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-36ca8f78a4/23.html

北京市的地震短期预报和临震预报，由国务院地震工作主管部门和北京市人民政府负责管理地震工作的机构，组织召开地震震情会商会，提出地震预报意见，经国务院地震工作主管部门组织评审后，报国务院批准，由北京市人民政府发布。
