# 地震预报管理条例第十七条

- 法规：地震预报管理条例（现行有效）
- 章节：第四章地震预报的发布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-36ca8f78a4/17.html

发生地震谣言，扰乱社会正常秩序时，国务院地震工作主管部门和县级以上地方人民政府负责管理地震工作的机构应当采取措施，迅速予以澄清，其他有关部门应当给予配合、协助。
