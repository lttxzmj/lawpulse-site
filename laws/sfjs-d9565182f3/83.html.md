# 最高人民法院关于审理企业破产案件若干问题的规定第八十三条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/83.html

处理破产财产前，可以确定有相应评估资质的评估机构对破产财产进行评估，债权人会议、清算组对破产财产的评估结论、评估费用有异议的，参照最高人民法院《关于民事诉讼证据的若干规定》第二十七条的规定处理。
