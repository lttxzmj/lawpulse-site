# 最高人民法院关于审理企业破产案件若干问题的规定第九十六条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/96.html

破产财产分配完毕，由清算组向人民法院报告分配情况，并申请人民法院终结破产程序。
人民法院在收到清算组的报告和终结破产程序申请后，认为符合破产程序终结规定的，应当在7日内裁定终结破产程序。
