# 最高人民法院关于审理企业破产案件若干问题的规定第三十二条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/32.html

人民法院受理债务人破产案件后，有下列情形之一的，应当裁定宣告债务人破产：
（一）债务人不能清偿债务且与债权人不能达成和解协议的；
（二）债务人不履行或者不能履行和解协议的；
（三）债务人在整顿期间有企业破产法第二十一条规定情形的；
（四）债务人在整顿期满后有企业破产法第二十二条第二款规定情形的。
宣告债务人破产应当公开进行。由债权人提出破产申请的，破产宣告时应当通知债务人到庭。
