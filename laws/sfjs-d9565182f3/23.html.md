# 最高人民法院关于审理企业破产案件若干问题的规定第二十三条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/23.html

连带债务人之一或者数人破产的，债权人可就全部债权向该债务人或者各债务人行使权利，申报债权。债权人未申报债权的，其他连带债务人可就将来可能承担的债务申报债权。
