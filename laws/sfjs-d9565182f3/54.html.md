# 最高人民法院关于审理企业破产案件若干问题的规定第五十四条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/54.html

清算组应当采取有效措施保护破产企业的财产。债务人的财产权利如不依法登记或者及时行使将丧失权利的，应当及时予以登记或者行使；对易损、易腐、跌价或者保管费用较高的财产应当及时变卖。
