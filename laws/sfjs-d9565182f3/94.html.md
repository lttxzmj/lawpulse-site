# 最高人民法院关于审理企业破产案件若干问题的规定第九十四条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/94.html

列入破产财产的债权，可以进行债权分配。债权分配以便于债权人实现债权为原则。
将人民法院已经确认的债权分配给债权人的，由清算组向债权人出具债权分配书，债权人可以凭债权分配书向债务人要求履行。债务人拒不履行的，债权人可以申请人民法院强制执行。
