# 最高人民法院关于审理企业破产案件若干问题的规定第八十九条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/89.html

人民法院受理企业破产案件可以按照《人民法院诉讼收费办法补充规定》预收案件受理费。
破产宣告前发生的经人民法院认可的必要支出，从债务人财产中拨付。债务人财产不足以支付的，如系债权人申请破产的，由债权人支付。
