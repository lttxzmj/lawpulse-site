# 最高人民法院关于审理企业破产案件若干问题的规定第八条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/8.html

债权人申请债务人破产，人民法院可以通知债务人核对以下情况：
（一）债权的真实性；
（二）债权在债务人不能偿还的到期债务中所占的比例；
（三）债务人是否存在不能清偿到期债务的情况。
