# 最高人民法院关于审理企业破产案件若干问题的规定第七条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/7.html

债权人申请债务人破产，应当向人民法院提交下列材料：
（一）债权发生的事实与证据；
（二）债权性质、数额、有无担保，并附证据；
（三）债务人不能清偿到期债务的证据。
