# 最高人民法院关于审理企业破产案件若干问题的规定第三条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/3.html

上级人民法院审理下级人民法院管辖的企业破产案件，或者将本院管辖的企业破产案件移交下级人民法院审理，以及下级人民法院需要将自己管辖的企业破产案件交由上级人民法院审理的，依照民事诉讼法第三十九条的规定办理；省、自治区、直辖市范围内因特殊情况需对个别企业破产案件的地域管辖作调整的，须经共同上级人民法院批准。
