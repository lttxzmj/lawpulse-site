# 最高人民法院关于审理企业破产案件若干问题的规定第一百零四条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/104.html

最高人民法院发现各级人民法院，或者上级人民法院发现下级人民法院在破产程序中作出的裁定确有错误的，应当通知其纠正；不予纠正的，可以裁定指令下级人民法院重新作出裁定。
