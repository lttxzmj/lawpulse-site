# 最高人民法院关于审理企业破产案件若干问题的规定第四十九条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/49.html

清算组经人民法院同意可以聘请破产清算机构、律师事务所、会计事务所等中介机构承担一定的破产清算工作。中介机构就清算工作向清算组负责。
