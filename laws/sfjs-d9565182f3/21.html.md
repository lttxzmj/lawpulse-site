# 最高人民法院关于审理企业破产案件若干问题的规定第二十一条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/21.html

债权人申报债权应当提交债权证明和合法有效的身份证明；代理申报人应当提交委托人的有效身份证明、授权委托书和债权证明。
申报的债权有财产担保的，应当提交证明财产担保的证据。
