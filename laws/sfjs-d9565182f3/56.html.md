# 最高人民法院关于审理企业破产案件若干问题的规定第五十六条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/56.html

因企业破产解除劳动合同，劳动者依法或者依据劳动合同对企业享有的补偿金请求权，参照企业破产法第三十七条第二款第（一）项规定的顺序清偿。
