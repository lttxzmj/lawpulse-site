# 最高人民法院关于审理企业破产案件若干问题的规定第二十八条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/28.html

企业由债权人申请破产的，如被申请破产的企业系国有企业，依照企业破产法第四章的规定，其上级主管部门可以申请对该企业进行整顿。整顿申请应当在债务人被宣告破产前提出。
企业无上级主管部门的，企业股东会议可以通过决议并以股东会议名义申请对企业进行整顿。整顿工作由股东会议指定人员负责。
