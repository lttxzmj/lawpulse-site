# 最高人民法院关于审理企业破产案件若干问题的规定第十八条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/18.html

人民法院受理企业破产案件后，除可以随即进行破产宣告成立清算组的外，在企业原管理组织不能正常履行管理职责的情况下，可以成立企业监管组。企业监管组成员从企业上级主管部门或者股东会议代表、企业原管理人员、主要债权人中产生，也可以聘请会计师、律师等中介机构参加。企业监管组主要负责处理以下事务：
（一）清点、保管企业财产；
（二）核查企业债权；
（三）为企业利益而进行的必要的经营活动；
（四）支付人民法院许可的必要支出；
（五）人民法院许可的其他工作。
企业监管组向人民法院负责，接受人民法院的指导、监督。
