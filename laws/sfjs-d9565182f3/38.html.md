# 最高人民法院关于审理企业破产案件若干问题的规定第三十八条

- 法规：最高人民法院关于审理企业破产案件若干问题的规定（现行有效，施行日期 2002-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-d9565182f3/38.html

破产宣告后，债权人或者债务人对破产宣告有异议的，可以在人民法院宣告企业破产之日起10日内，向上一级人民法院申诉。上一级人民法院应当组成合议庭进行审理，并在30日内作出裁定。
