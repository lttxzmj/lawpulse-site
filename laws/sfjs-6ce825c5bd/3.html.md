# 最高人民法院关于民事执行中财产调查若干问题的规定第三条

- 法规：最高人民法院关于民事执行中财产调查若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-6ce825c5bd/3.html

人民法院依申请执行人的申请或依职权责令被执行人报告财产情况的，应当向其发出报告财产令。金钱债权执行中，报告财产令应当与执行通知同时发出。
人民法院根据案件需要再次责令被执行人报告财产情况的，应当重新向其发出报告财产令。
