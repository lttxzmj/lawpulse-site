# 最高人民法院关于民事执行中财产调查若干问题的规定第二十三条

- 法规：最高人民法院关于民事执行中财产调查若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-6ce825c5bd/23.html

悬赏公告发布后，有关人员向人民法院提供财产线索的，人民法院应当对有关人员的身份信息和财产线索进行登记；两人以上提供相同财产线索的，应当按照提供线索的先后顺序登记。
人民法院对有关人员的身份信息和财产线索应当保密，但为发放悬赏金需要告知申请执行人的除外。
