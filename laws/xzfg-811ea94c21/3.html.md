# 中华人民共和国强制检定的工作计量器具检定管理办法第三条

- 法规：中华人民共和国强制检定的工作计量器具检定管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-811ea94c21/3.html

县级以上人民政府计量行政部门对本行政区域内的强制检定工作统一实施监督管理，并按照经济合理、就地就近的原则，指定所属或者授权的计量检定机构执行强制检定任务。
