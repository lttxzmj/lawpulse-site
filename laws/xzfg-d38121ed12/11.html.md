# 中华人民共和国无线电管理条例第十一条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第二章管理机构及其职责
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/11.html

军地建立无线电管理协调机制，共同划分无线电频率，协商处理涉及军事系统与非军事系统间的无线电管理事宜。无线电管理重大问题报国务院、中央军事委员会决定。
