# 中华人民共和国无线电管理条例第三十二条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第四章无线电台(站)管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/32.html

无线电台执照应当载明无线电台(站)的台址、使用频率、发射功率、有效期、使用要求等事项。
无线电台执照的样式由国家无线电管理机构统一规定。
