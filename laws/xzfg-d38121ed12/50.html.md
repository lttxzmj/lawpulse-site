# 中华人民共和国无线电管理条例第五十条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第五章无线电发射设备管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/50.html

研制、生产、销售和维修大功率无线电发射设备，应当采取措施有效抑制电波发射，不得对依法设置、使用的无线电台(站)产生有害干扰。进行实效发射试验的，应当依照本条例第三十条的规定向省、自治区、直辖市无线电管理机构申请办理临时设置、使用无线电台(站)手续。
