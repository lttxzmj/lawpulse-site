# 中华人民共和国无线电管理条例第五十一条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第六章涉外无线电管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/51.html

无线电频率协调的涉外事宜，以及我国境内电台与境外电台的相互有害干扰，由国家无线电管理机构会同有关单位与有关的国际组织或者国家、地区协调处理。
需要向国际电信联盟或者其他国家、地区提供无线电管理相关资料的，由国家无线电管理机构统一办理。
