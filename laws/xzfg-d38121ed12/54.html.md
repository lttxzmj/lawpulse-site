# 中华人民共和国无线电管理条例第五十四条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第六章涉外无线电管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/54.html

外国船舶(含海上平台)、航空器、铁路机车、车辆等设置的无线电台在我国境内使用，应当遵守我国的法律、法规和我国缔结或者参加的国际条约。
