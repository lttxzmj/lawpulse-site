# 中华人民共和国无线电管理条例第六十一条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第七章无线电监测和电波秩序维护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/61.html

经无线电管理机构确定的产生无线电波辐射的工程设施，可能对已依法设置、使用的无线电台(站)造成有害干扰的，其选址定点由地方人民政府城乡规划主管部门和省、自治区、直辖市无线电管理机构协商确定。
