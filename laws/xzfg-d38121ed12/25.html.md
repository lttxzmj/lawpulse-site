# 中华人民共和国无线电管理条例第二十五条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第三章频率管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/25.html

建设卫星工程，应当在项目规划阶段对拟使用的卫星无线电频率进行可行性论证；建设须经国务院、中央军事委员会批准的卫星工程，应当在项目规划阶段与国家无线电管理机构协商确定拟使用的卫星无线电频率。
