# 中华人民共和国无线电管理条例第四十五条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第五章无线电发射设备管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/45.html

取得无线电发射设备型号核准，应当符合下列条件：
(一)申请人有相应的生产能力、技术力量、质量保证体系；
(二)无线电发射设备的工作频率、功率等技术指标符合国家标准和国家无线电管理的有关规定。
