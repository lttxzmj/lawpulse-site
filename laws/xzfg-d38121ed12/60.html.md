# 中华人民共和国无线电管理条例第六十条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第七章无线电监测和电波秩序维护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/60.html

辐射无线电波的非无线电设备对已依法设置、使用的无线电台(站)产生有害干扰的，设备所有者或者使用者应当采取措施予以消除。
