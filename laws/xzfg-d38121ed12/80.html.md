# 中华人民共和国无线电管理条例第八十条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/80.html

生产、销售无线电发射设备违反产品质量管理法律法规的，由产品质量监督部门依法处罚。
进口无线电发射设备，携带、寄递或者以其他方式运输无线电发射设备入境，违反海关监管法律法规的，由海关依法处罚。
