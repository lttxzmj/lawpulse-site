# 中华人民共和国无线电管理条例第八条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第二章管理机构及其职责
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/8.html

国家无线电管理机构负责全国无线电管理工作，依据职责拟订无线电管理的方针、政策，统一管理无线电频率和无线电台(站)，负责无线电监测、干扰查处和涉外无线电管理等工作，协调处理无线电管理相关事宜。
