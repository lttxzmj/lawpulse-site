# 中华人民共和国无线电管理条例第四十一条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第四章无线电台(站)管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/41.html

使用无线电台(站)的单位或者个人不得故意收发无线电台执照许可事项之外的无线电信号，不得传播、公布或者利用无意接收的信息。
业余无线电台只能用于相互通信、技术研究和自我训练，并在业余业务或者卫星业余业务专用频率范围内收发信号，但是参与重大自然灾害等突发事件应急处置的除外。
