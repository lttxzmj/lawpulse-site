# 中华人民共和国无线电管理条例第七十九条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第八章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/79.html

维修无线电发射设备改变无线电发射设备型号核准证核定的技术指标的，由无线电管理机构责令改正；拒不改正的，处1万元以上3万元以下的罚款。
