# 中华人民共和国无线电管理条例第三十七条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第四章无线电台(站)管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/37.html

遇有危及国家安全、公共安全、生命财产安全的紧急情况或者为了保障重大社会活动的特殊需要，可以不经批准临时设置、使用无线电台(站)，但是应当及时向无线电台(站)所在地无线电管理机构报告，并在紧急情况消除或者重大社会活动结束后及时关闭。
