# 中华人民共和国无线电管理条例第五十五条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第六章涉外无线电管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/55.html

境外组织或者个人不得在我国境内进行电波参数测试或者电波监测。
任何单位或者个人不得向境外组织或者个人提供涉及国家安全的境内电波参数资料。
