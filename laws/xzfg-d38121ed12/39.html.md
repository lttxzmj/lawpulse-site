# 中华人民共和国无线电管理条例第三十九条

- 法规：中华人民共和国无线电管理条例（现行有效）
- 章节：第四章无线电台(站)管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d38121ed12/39.html

使用无线电台(站)的单位或者个人应当对无线电台(站)进行定期维护，保证其性能指标符合国家标准和国家无线电管理的有关规定，避免对其他依法设置、使用的无线电台(站)产生有害干扰。
