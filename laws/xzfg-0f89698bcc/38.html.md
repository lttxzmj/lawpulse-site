# 地震监测管理条例第三十八条

- 法规：地震监测管理条例（现行有效，施行日期 2025-01-20）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0f89698bcc/38.html

违反本条例的规定，外国的组织或者个人未经批准，擅自在中华人民共和国领域和中华人民共和国管辖的其他海域进行地震监测活动的，由国务院地震工作主管部门责令停止违法行为，没收监测成果和监测设施，并处1万元以上10万元以下的罚款；情节严重的，处10万元以上50万元以下的罚款。
