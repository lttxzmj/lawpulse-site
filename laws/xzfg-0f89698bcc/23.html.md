# 地震监测管理条例第二十三条

- 法规：地震监测管理条例（现行有效，施行日期 2025-01-20）
- 章节：第三章地震监测台网的管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0f89698bcc/23.html

专用地震监测台网和强震动监测设施的管理单位，应当将地震监测信息及时报送所在地省、自治区、直辖市人民政府负责管理地震工作的部门或者机构。
