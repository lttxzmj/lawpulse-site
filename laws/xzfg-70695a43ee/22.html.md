# 政务数据共享条例第二十二条

- 法规：政务数据共享条例（现行有效，施行日期 2025-08-01）
- 章节：第四章共享使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70695a43ee/22.html

政务数据提供部门应当自作出同意共享的答复之日起20个工作日内共享政务数据。
政务数据提供部门可以通过服务接口、批量交换、文件下载等方式向政务数据需求部门共享政务数据。
