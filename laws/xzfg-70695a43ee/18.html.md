# 政务数据共享条例第十八条

- 法规：政务数据共享条例（现行有效，施行日期 2025-08-01）
- 章节：第四章共享使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-70695a43ee/18.html

政府部门应当建立健全政务数据全过程质量管理体系，提高政务数据质量管理能力，加强政务数据收集、存储、加工、传输、共享、使用、销毁等标准化管理。
