# 全国农业普查条例第七条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/7.html

农业普查所需经费，由中央和地方各级人民政府共同负担，并列入相应年度预算，按时拨付，确保足额到位。
农业普查经费应当统一管理、专款专用、从严控制支出。
各级财政部门、审计部门依据职责，加强对农业普查经费的预算监督和审计监督。
