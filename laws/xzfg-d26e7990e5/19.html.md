# 全国农业普查条例第十九条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第三章农业普查的组织实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/19.html

农村的农业普查现场登记按普查区进行。普查区以村民委员会管理地域为基础划分，每个普查区可以划分为若干个普查小区。
城镇的农业普查现场登记，按照农业普查方案的规定进行。
