# 全国农业普查条例第十八条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第三章农业普查的组织实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/18.html

县级以上各级人民政府有关部门应当积极参与并密切配合普查办公室开展农业普查工作。
军队所属单位的农业普查工作，由军队统一组织实施。
新疆生产建设兵团的农业普查工作，由新疆生产建设兵团农业普查领导小组及其办公室负责组织实施。
