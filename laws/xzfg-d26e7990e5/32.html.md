# 全国农业普查条例第三十二条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第五章数据公布、资料管理和开发应用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/32.html

普查办公室、普查人员对在农业普查工作中知悉的国家秘密、工作秘密、商业秘密、个人隐私和个人信息，应当予以保密，不得泄露或者向他人非法提供；对在农业普查工作中搜集的能够识别或者推断单个农业普查对象身份的资料，不得对外提供、泄露，不得用于统计以外的目的。
