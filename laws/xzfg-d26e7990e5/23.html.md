# 全国农业普查条例第二十三条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第三章农业普查的组织实施
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/23.html

普查人员进行农业普查时，有权就与农业普查有关的问题询问有关单位和个人，要求有关单位和个人如实提供有关情况和资料并改正不真实、不准确的资料。
