# 全国农业普查条例第八条

- 法规：全国农业普查条例（现行有效，施行日期 2026-05-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26e7990e5/8.html

农业普查每10年进行一次，尾数逢6的年份为农业普查年度，标准时点为农业普查年度的12月31日24时。特殊地区的农业普查登记时间经国务院农业普查领导小组办公室批准，可以适当调整。
