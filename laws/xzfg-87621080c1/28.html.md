# 军用土地管理条例第二十八条

- 法规：军用土地管理条例（现行有效，施行日期 2025-11-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87621080c1/28.html

本条例适用于中国人民武装警察部队。
军队划入有关单位运营的土地的管理，依照有关法律、行政法规、军事法规的规定以及国务院、中央军事委员会的有关规定执行。
