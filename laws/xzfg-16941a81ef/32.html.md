# 结汇、售汇及付汇管理规定第三十二条

- 法规：结汇、售汇及付汇管理规定（现行有效）
- 章节：第四章结汇、售汇及付汇的监管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16941a81ef/32.html

外商投资企业可以在外汇指定银行办理结汇和售汇，也可以在外汇调剂中心买卖外汇，其他境内机构、居民个人、驻华机构及来华人员只能在外汇指定银行办理结汇和售汇。
