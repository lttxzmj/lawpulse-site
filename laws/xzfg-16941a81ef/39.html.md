# 结汇、售汇及付汇管理规定第三十九条

- 法规：结汇、售汇及付汇管理规定（现行有效）
- 章节：第四章结汇、售汇及付汇的监管
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-16941a81ef/39.html

经营外汇业务的银行应当按照规定向外汇局报送结汇、售汇及付汇情况报表。
外汇指定银行应当建立结售汇内部监管制度，遇有结售汇异常情况，应当及时向国家外汇管理局当地分支局报告。
