# 乳品质量安全监督管理条例第二十八条

- 法规：乳品质量安全监督管理条例（现行有效）
- 章节：第四章乳制品生产
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a5c4f8f021/28.html

从事乳制品生产活动，应当具备下列条件，取得所在地质量监督部门颁发的食品生产许可证：
(一)符合国家奶业产业政策；
(二)厂房的选址和设计符合国家有关规定；
(三)有与所生产的乳制品品种和数量相适应的生产、包装和检测设备；
(四)有相应的专业技术人员和质量检验人员；
(五)有符合环保要求的废水、废气、垃圾等污染物的处理设施；
(六)有经培训合格并持有有效健康证明的从业人员；
(七)法律、行政法规规定的其他条件。
质量监督部门对乳制品生产企业颁发食品生产许可证，应当征求所在地工业行业管理部门的意见。
未取得食品生产许可证的任何单位和个人，不得从事乳制品生产。
