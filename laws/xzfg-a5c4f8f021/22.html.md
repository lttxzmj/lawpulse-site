# 乳品质量安全监督管理条例第二十二条

- 法规：乳品质量安全监督管理条例（现行有效）
- 章节：第三章生鲜乳收购
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a5c4f8f021/22.html

生鲜乳收购站应当建立生鲜乳收购、销售和检测记录。生鲜乳收购、销售和检测记录应当包括畜主姓名、单次收购量、生鲜乳检测结果、销售去向等内容，并保存2年。
