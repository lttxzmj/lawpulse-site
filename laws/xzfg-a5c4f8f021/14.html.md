# 乳品质量安全监督管理条例第十四条

- 法规：乳品质量安全监督管理条例（现行有效）
- 章节：第二章奶畜养殖
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a5c4f8f021/14.html

从事奶畜养殖，不得使用国家禁用的饲料、饲料添加剂、兽药以及其他对动物和人体具有直接或者潜在危害的物质。
禁止销售在规定用药期和休药期内的奶畜产的生鲜乳。
