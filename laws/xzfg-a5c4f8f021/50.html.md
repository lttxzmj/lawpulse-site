# 乳品质量安全监督管理条例第五十条

- 法规：乳品质量安全监督管理条例（现行有效）
- 章节：第六章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a5c4f8f021/50.html

畜牧兽医主管部门、质量监督部门、工商行政管理部门应当建立乳品生产经营者违法行为记录，及时提供给中国人民银行，由中国人民银行纳入企业信用信息基础数据库。
