# 乳品质量安全监督管理条例第十七条

- 法规：乳品质量安全监督管理条例（现行有效）
- 章节：第二章奶畜养殖
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a5c4f8f021/17.html

奶畜养殖者应当遵守国务院畜牧兽医主管部门制定的生鲜乳生产技术规程。直接从事挤奶工作的人员应当持有有效的健康证明。
奶畜养殖者对挤奶设施、生鲜乳贮存设施等应当及时清洗、消毒，避免对生鲜乳造成污染。
