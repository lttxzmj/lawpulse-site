# 农作物病虫害防治条例第四十三条

- 法规：农作物病虫害防治条例（现行有效，施行日期 2020-05-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-971546b132/43.html

境外组织和个人违反本条例规定，在我国境内开展农作物病虫害监测活动的，由县级以上人民政府农业农村主管部门责令其停止监测活动，没收监测数据和工具，并处10万元以上50万元以下罚款；情节严重的，并处50万元以上100万元以下罚款；构成犯罪的，依法追究刑事责任。
