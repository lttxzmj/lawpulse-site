# 最高人民法院关于审理信用证纠纷案件若干问题的规定第一条

- 法规：最高人民法院关于审理信用证纠纷案件若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-18f4e19e43/1.html

本规定所指的信用证纠纷案件，是指在信用证开立、通知、修改、撤销、保兑、议付、偿付等环节产生的纠纷。
