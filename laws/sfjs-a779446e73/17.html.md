# 最高人民法院、最高人民检察院关于办理危害生产安全刑事案件适用法律若干问题的解释第十七条

- 法规：最高人民法院、最高人民检察院关于办理危害生产安全刑事案件适用法律若干问题的解释（现行有效，施行日期 2015-12-16）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-a779446e73/17.html

本解释自2015年12月16日起施行。本解释施行后，最高人民法院、最高人民检察院《关于办理危害矿山生产安全刑事案件具体应用法律若干问题的解释》（法释〔2007〕5号）同时废止。最高人民法院、最高人民检察院此前发布的司法解释和规范性文件与本解释不一致的，以本解释为准。
