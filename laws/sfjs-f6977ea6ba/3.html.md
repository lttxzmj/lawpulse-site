# 最高人民法院关于办理减刑、假释案件审查财产性判项执行问题的规定第三条

- 法规：最高人民法院关于办理减刑、假释案件审查财产性判项执行问题的规定（现行有效，施行日期 2024-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-f6977ea6ba/3.html

财产性判项未执行完毕的，人民法院应当着重审查罪犯的履行能力。
罪犯的履行能力应根据财产性判项的实际执行情况，并结合罪犯的财产申报、实际拥有财产情况，以及监狱或者看守所内消费、账户余额等予以判断。
