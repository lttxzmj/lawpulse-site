# 民用机场管理条例第六十九条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/69.html

机场管理机构未依照本条例的规定履行管理职责，造成运输机场地面事故、民用航空器飞行事故或者严重事故征候的，民用航空管理部门应当责令改正，处20万元以上100万元以下的罚款。
