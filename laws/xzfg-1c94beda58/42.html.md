# 民用机场管理条例第四十二条

- 法规：民用机场管理条例（现行有效）
- 章节：第三章民用机场安全和运营管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/42.html

申请在民用机场内从事航空燃油供应业务的企业，应当向民用机场所在地地区民用航空管理机构提出申请，并附送符合本条例第四十一条规定条件的相关材料。
地区民用航空管理机构应当自受理申请之日起30个工作日内，作出准予许可或者不予许可的决定。准予许可的，颁发民用机场航空燃油供应安全运营许可证；不予许可的，应当书面通知申请人并说明理由。
