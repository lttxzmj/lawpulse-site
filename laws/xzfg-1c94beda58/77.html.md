# 民用机场管理条例第七十七条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/77.html

违反本条例的规定，机场管理机构未向民用航空管理部门报送运输机场规划、建设和生产运营的有关资料的，由民用航空管理部门责令改正；拒不改正的，处1万元以上5万元以下的罚款。
