# 民用机场管理条例第八十一条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/81.html

违反本条例的规定，在民用航空无线电台(站)电磁环境保护区域内从事下列活动的，由民用机场所在地县级以上地方人民政府责令改正；情节严重的，处2万元以上10万元以下的罚款：
(一)修建架空高压输电线、架空金属线、铁路、公路、电力排灌站；
(二)存放金属堆积物；
(三)从事掘土、采砂、采石等改变地形地貌的活动；
(四)国务院民用航空主管部门规定的其他影响民用机场电磁环境保护的行为。
