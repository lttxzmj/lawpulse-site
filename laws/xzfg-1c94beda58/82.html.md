# 民用机场管理条例第八十二条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/82.html

违反本条例的规定，在民用机场起降的民用航空器不符合国家有关航空器噪声和涡轮发动机排出物的适航标准的，由民用航空管理部门责令相关航空运输企业改正，可以处10万元以下的罚款；拒不改正的，处10万元以上50万元以下的罚款。
