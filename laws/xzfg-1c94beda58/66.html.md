# 民用机场管理条例第六十六条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/66.html

违反本条例的规定，机场管理机构因故不能保障民用航空器飞行安全，临时关闭运输机场，未及时通知有关空中交通管理部门并及时向社会公告，或者经批准关闭运输机场后未及时向社会公告的，由运输机场所在地地区民用航空管理机构责令改正，处2万元以上10万元以下的罚款。
