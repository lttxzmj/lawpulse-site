# 民用机场管理条例第七十四条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/74.html

违反本条例的规定，运输机场航空燃油供应企业停止运输机场航空燃油供应业务，未提前90日告知地区民用航空管理机构、机场管理机构和相关航空运输企业的，由运输机场所在地地区民用航空管理机构处5万元以上25万元以下的罚款。
