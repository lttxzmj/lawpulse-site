# 民用机场管理条例第五十六条

- 法规：民用机场管理条例（现行有效）
- 章节：第四章民用机场安全环境保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/56.html

禁止在民用航空无线电台(站)电磁环境保护区域内，从事下列影响民用机场电磁环境的活动：
(一)修建架空高压输电线、架空金属线、铁路、公路、电力排灌站；
(二)存放金属堆积物；
(三)种植高大植物；
(四)从事掘土、采砂、采石等改变地形地貌的活动；
(五)国务院民用航空主管部门规定的其他影响民用机场电磁环境的行为。
