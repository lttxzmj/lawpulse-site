# 民用机场管理条例第七十八条

- 法规：民用机场管理条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1c94beda58/78.html

违反本条例的规定，在民用机场净空保护区域内设置22万伏以上(含22万伏)的高压输电塔，未依照国务院民用航空主管部门的有关规定设置障碍灯或者标志的，由民用机场所在地地区民用航空管理机构责令改正，处10万元以上50万元以下的罚款。
