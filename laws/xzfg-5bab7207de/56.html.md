# 中华人民共和国邮政法实施细则第五十六条

- 法规：中华人民共和国邮政法实施细则（现行有效）
- 章节：第七章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bab7207de/56.html

伪造或者冒用邮政专用标志、邮政标志服或者邮政日戳、邮政夹钳、邮袋等邮政专用品的，由邮电管理局或其授权单位处以一千五百元以下罚款，并没收有关物品。
