# 中华人民共和国邮政法实施细则第二十八条

- 法规：中华人民共和国邮政法实施细则（现行有效）
- 章节：第四章邮政业务资费和邮资凭证
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bab7207de/28.html

因工作需要，仿印邮票图案的，必须按照仿印邮票图案的有关规定，报经邮电部邮票主管部门或者有关邮电管理局审核、批准。
印刷单位不得承印未经批准的仿印邮票图案和与邮票相似的印件。
