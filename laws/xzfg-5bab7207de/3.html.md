# 中华人民共和国邮政法实施细则第三条

- 法规：中华人民共和国邮政法实施细则（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5bab7207de/3.html

市、县邮电局(含邮政局，下同)是全民所有制的经营邮政业务的公用企业(以下简称邮政企业)，经邮电管理局授权，管理该地区的邮政工作。
邮电支局、邮电所、邮政支局、邮政所是办理邮政业务的分支机构(以下简称分支机构)；邮亭、邮政报刊亭等是邮政企业的服务点。
邮电代办所视同邮政企业所属的分支机构。
