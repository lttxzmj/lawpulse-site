# 中华人民共和国搜寻援救民用航空器规定第八条

- 法规：中华人民共和国搜寻援救民用航空器规定（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ea00a51b40/8.html

为执行搜寻援救民用航空器的紧急任务，有关地方、部门、单位和人员必须积极行动，互相配合，努力完成任务；对执行搜寻援救任务成绩突出的单位和个人，由其上级机关给予奖励。
