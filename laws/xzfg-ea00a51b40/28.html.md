# 中华人民共和国搜寻援救民用航空器规定第二十八条

- 法规：中华人民共和国搜寻援救民用航空器规定（现行有效）
- 章节：第四章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-ea00a51b40/28.html

对违反本规定，有下列行为之一的人员，由其所在单位或者上级机关给予行政处分；构成犯罪的，依法追究刑事责任：
(一)不积极行动配合完成搜寻援救任务，造成重大损失的；
(二)不积极履行职责或者不服从指挥，致使损失加重的；
(三)玩忽职守，对民用航空器紧急情况判断、处置不当，贻误时机，造成损失的。
