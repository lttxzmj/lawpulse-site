# 收费公路管理条例第四十三条

- 法规：收费公路管理条例（现行有效）
- 章节：第四章收费公路的经营管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/43.html

国务院交通主管部门和省、自治区、直辖市人民政府交通主管部门应当对收费公路实施监督检查，督促收费公路经营管理者依法履行公路养护、绿化和公路用地范围内的水土保持义务。
