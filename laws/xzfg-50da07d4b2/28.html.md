# 收费公路管理条例第二十八条

- 法规：收费公路管理条例（现行有效）
- 章节：第四章收费公路的经营管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/28.html

收费公路经营管理者应当按照国家规定的标准，结合公路交通状况、沿线设施等情况，设置交通标志、标线。
交通标志、标线必须清晰、准确、易于识别。重要的通行信息应当重复提示。
