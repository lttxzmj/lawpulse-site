# 收费公路管理条例第三十七条

- 法规：收费公路管理条例（现行有效）
- 章节：第四章收费公路的经营管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/37.html

收费公路的收费期限届满，必须终止收费。
政府还贷公路在批准的收费期限届满前已经还清贷款、还清有偿集资款的，必须终止收费。
依照本条前两款的规定，收费公路终止收费的，有关省、自治区、直辖市人民政府应当向社会公告，明确规定终止收费的日期，接受社会监督。
