# 收费公路管理条例第二十七条

- 法规：收费公路管理条例（现行有效）
- 章节：第四章收费公路的经营管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/27.html

收费公路经营管理者应当在收费站的显著位置，设置载有收费站名称、审批机关、收费单位、收费标准、收费起止年限和监督电话等内容的公告牌，接受社会监督。
