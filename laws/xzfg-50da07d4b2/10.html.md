# 收费公路管理条例第十条

- 法规：收费公路管理条例（现行有效）
- 章节：第二章收费公路建设和收费站的设置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/10.html

县级以上地方人民政府交通主管部门利用贷款或者向企业、个人有偿集资建设的公路(以下简称政府还贷公路)，国内外经济组织投资建设或者依照公路法的规定受让政府还贷公路收费权的公路(以下简称经营性公路)，经依法批准后，方可收取车辆通行费。
