# 收费公路管理条例第十三条

- 法规：收费公路管理条例（现行有效）
- 章节：第二章收费公路建设和收费站的设置
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-50da07d4b2/13.html

高速公路以及其他封闭式的收费公路，应当实行计算机联网收费，减少收费站点，提高通行效率。联网收费的具体办法由国务院交通主管部门会同国务院有关部门制定。
