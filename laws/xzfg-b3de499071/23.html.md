# 国有资产评估管理办法第二十三条

- 法规：国有资产评估管理办法（现行有效，施行日期 2020-11-29）
- 章节：第四章评估方法
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b3de499071/23.html

国有资产评估方法包括：
(一)收益现值法；
(二)重置成本法；
(三)现行市价法；
(四)清算价格法；
(五)国务院国有资产管理行政主管部门规定的其他评估方法。
