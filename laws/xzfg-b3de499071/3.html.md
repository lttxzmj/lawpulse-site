# 国有资产评估管理办法第三条

- 法规：国有资产评估管理办法（现行有效，施行日期 2020-11-29）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b3de499071/3.html

国有资产占有单位(以下简称占有单位)有下列情形之一的，应当进行资产评估：
(一)资产拍卖、转让；
(二)企业兼并、出售、联营、股份经营；
(三)与外国公司、企业和其他经济组织或者个人开办外商投资企业；
(四)企业清算；
(五)依照国家有关规定需要进行资产评估的其他情形。
