# 最高人民法院关于审理司法赔偿案件适用请求时效制度若干问题的解释第三条

- 法规：最高人民法院关于审理司法赔偿案件适用请求时效制度若干问题的解释（现行有效，施行日期 2023-06-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-bdbbf26eee/3.html

赔偿请求人以人身权受到侵犯为由，依照国家赔偿法第十七条第四项、第五项规定申请赔偿的，请求时效期间自其知道或者应当知道损害结果之日起计算；损害结果当时不能确定的，自损害结果确定之日起计算。
