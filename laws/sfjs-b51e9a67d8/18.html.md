# 最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定第十八条

- 法规：最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b51e9a67d8/18.html

船舶取得有效的油污损害民事责任保险或者具有相应财务保证的，油污受损害人主张船舶优先权的，人民法院不予支持。
