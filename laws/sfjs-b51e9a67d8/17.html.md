# 最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定第十七条

- 法规：最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b51e9a67d8/17.html

船舶油污事故造成环境损害的，对环境损害的赔偿应限于已实际采取或者将要采取的合理恢复措施的费用。恢复措施的费用包括合理的监测、评估、研究费用。
