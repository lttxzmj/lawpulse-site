# 最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定第二十八条

- 法规：最高人民法院关于审理船舶油污损害赔偿纠纷案件若干问题的规定（现行有效，施行日期 2026-08-15）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-b51e9a67d8/28.html

对油轮装载持久性油类造成的油污损害，船舶所有人、船舶油污损害责任保险人或者财务保证人申请设立油污损害赔偿责任限制基金、受损害人申请债权登记与受偿，本规定没有规定的，适用海事诉讼特别程序法及相关司法解释的规定。
