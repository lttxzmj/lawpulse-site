# 医疗纠纷预防和处理条例第二十三条

- 法规：医疗纠纷预防和处理条例（现行有效）
- 章节：第三章医疗纠纷处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5c68a817b0/23.html

发生医疗纠纷，医疗机构应当告知患者或者其近亲属下列事项：
(一)解决医疗纠纷的合法途径；
(二)有关病历资料、现场实物封存和启封的规定；
(三)有关病历资料查阅、复制的规定。
患者死亡的，还应当告知其近亲属有关尸检的规定。
