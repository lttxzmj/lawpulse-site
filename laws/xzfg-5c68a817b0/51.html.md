# 医疗纠纷预防和处理条例第五十一条

- 法规：医疗纠纷预防和处理条例（现行有效）
- 章节：第四章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5c68a817b0/51.html

新闻媒体编造、散布虚假医疗纠纷信息的，由有关主管部门依法给予处罚；给公民、法人或者其他组织的合法权益造成损害的，依法承担消除影响、恢复名誉、赔偿损失、赔礼道歉等民事责任。
