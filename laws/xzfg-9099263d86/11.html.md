# 控制对企业进行经济检查的规定第十一条

- 法规：控制对企业进行经济检查的规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9099263d86/11.html

行政机关的工作人员对企业进行经济检查时，不得接受被检查企业的任何馈赠、报酬、福利待遇，不得在被检查企业报销任何费用，不得参加被检查企业提供的宴请、娱乐、旅游等活动，不得通过检查工作为本人、亲友或者他人谋取利益。
