# 建设工程质量管理条例第六十七条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/67.html

工程监理单位有下列行为之一的，责令改正，处50万元以上100万元以下的罚款，降低资质等级或者吊销资质证书；有违法所得的，予以没收；造成损失的，承担连带赔偿责任：
(一)与建设单位或者施工单位串通，弄虚作假、降低工程质量的；
(二)将不合格的建设工程、建筑材料、建筑构配件和设备按照合格签字的。
