# 建设工程质量管理条例第七十四条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/74.html

建设单位、设计单位、施工单位、工程监理单位违反国家规定，降低工程质量标准，造成重大安全事故，构成犯罪的，对直接责任人员依法追究刑事责任。
