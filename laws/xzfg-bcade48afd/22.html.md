# 建设工程质量管理条例第二十二条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第三章勘察、设计单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/22.html

设计单位在设计文件中选用的建筑材料、建筑构配件和设备，应当注明规格、型号、性能等技术指标，其质量要求必须符合国家规定的标准。
除有特殊要求的建筑材料、专用设备、工艺生产线等外，设计单位不得指定生产厂、供应商。
