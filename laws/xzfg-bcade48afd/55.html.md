# 建设工程质量管理条例第五十五条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/55.html

违反本条例规定，建设单位将建设工程肢解发包的，责令改正，处工程合同价款0.5%以上1%以下的罚款；对全部或者部分使用国有资金的项目，并可以暂停项目执行或者暂停资金拨付。
