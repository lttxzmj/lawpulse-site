# 建设工程质量管理条例第三十三条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第四章施工单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/33.html

施工单位应当建立、健全教育培训制度，加强对职工的教育培训；未经教育培训或者考核不合格的人员，不得上岗作业。
