# 建设工程质量管理条例第二十八条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第四章施工单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/28.html

施工单位必须按照工程设计图纸和施工技术标准施工，不得擅自修改工程设计，不得偷工减料。
施工单位在施工过程中发现设计文件和图纸有差错的，应当及时提出意见和建议。
