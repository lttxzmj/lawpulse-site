# 建设工程质量管理条例第五十八条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/58.html

违反本条例规定，建设单位有下列行为之一的，责令改正，处工程合同价款2%以上4%以下的罚款；造成损失的，依法承担赔偿责任：
(一)未组织竣工验收，擅自交付使用的；
(二)验收不合格，擅自交付使用的；
(三)对不合格的建设工程按照合格工程验收的。
