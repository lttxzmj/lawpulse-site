# 建设工程质量管理条例第四十二条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第六章建设工程质量保修
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/42.html

建设工程在超过合理使用年限后需要继续使用的，产权所有人应当委托具有相应资质等级的勘察、设计单位鉴定，并根据鉴定结果采取加固、维修等措施，重新界定使用期。
