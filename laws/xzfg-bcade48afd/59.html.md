# 建设工程质量管理条例第五十九条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/59.html

违反本条例规定，建设工程竣工验收后，建设单位未向建设行政主管部门或者其他有关部门移交建设项目档案的，责令改正，处1万元以上10万元以下的罚款。
