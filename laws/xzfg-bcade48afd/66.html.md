# 建设工程质量管理条例第六十六条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第八章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/66.html

违反本条例规定，施工单位不履行保修义务或者拖延履行保修义务的，责令改正，处10万元以上20万元以下的罚款，并对在保修期内因质量缺陷造成的损失承担赔偿责任。
