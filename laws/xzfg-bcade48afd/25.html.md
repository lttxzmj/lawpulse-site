# 建设工程质量管理条例第二十五条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第四章施工单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/25.html

施工单位应当依法取得相应等级的资质证书，并在其资质等级许可的范围内承揽工程。
禁止施工单位超越本单位资质等级许可的业务范围或者以其他施工单位的名义承揽工程。禁止施工单位允许其他单位或者个人以本单位的名义承揽工程。
施工单位不得转包或者违法分包工程。
