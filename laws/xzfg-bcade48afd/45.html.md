# 建设工程质量管理条例第四十五条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第七章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/45.html

国务院发展计划部门按照国务院规定的职责，组织稽察特派员，对国家出资的重大建设项目实施监督检查。
国务院经济贸易主管部门按照国务院规定的职责，对国家重大技术改造项目实施监督检查。
