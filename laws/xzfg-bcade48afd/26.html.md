# 建设工程质量管理条例第二十六条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第四章施工单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/26.html

施工单位对建设工程的施工质量负责。
施工单位应当建立质量责任制，确定工程项目的项目经理、技术负责人和施工管理负责人。
建设工程实行总承包的，总承包单位应当对全部建设工程质量负责；建设工程勘察、设计、施工、设备采购的一项或者多项实行总承包的，总承包单位应当对其承包的建设工程或者采购的设备的质量负责。
