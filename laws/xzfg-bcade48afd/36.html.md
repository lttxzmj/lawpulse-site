# 建设工程质量管理条例第三十六条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第五章工程监理单位的质量责任和义务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/36.html

工程监理单位应当依照法律、法规以及有关技术标准、设计文件和建设工程承包合同，代表建设单位对施工质量实施监理，并对施工质量承担监理责任。
