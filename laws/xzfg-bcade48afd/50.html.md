# 建设工程质量管理条例第五十条

- 法规：建设工程质量管理条例（现行有效，施行日期 2019-04-23）
- 章节：第七章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcade48afd/50.html

有关单位和个人对县级以上人民政府建设行政主管部门和其他有关部门进行的监督检查应当支持与配合，不得拒绝或者阻碍建设工程质量监督检查人员依法执行职务。
