# 证券、期货投资咨询管理暂行办法第二十九条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/29.html

地方证管办(证监会)根据投资人或者社会公众的投诉或者举报，有权要求证券、期货投资咨询机构及其投资咨询人员说明情况并提供相关资料。
