# 证券、期货投资咨询管理暂行办法第十六条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第三章证券、期货投资咨询人员
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/16.html

取得证券、期货投资咨询从业资格的人员申请执业的，由所参加的证券、期货投资咨询机构向所在地地方证管办(证监会)提出申请，地方证管办(证监会)审核同意后，报中国证监会审批；准予执业的，由中国证监会颁发执业证书。
