# 证券、期货投资咨询管理暂行办法第二十七条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/27.html

中国证监会和地方证管办(证监会)有权对证券、期货投资咨询机构和投资咨询人员的业务活动进行检查，被检查的证券、期货投资咨询机构及其投资咨询人员应当予以配合，不得干扰和阻碍。
中国证监会和地方证管办(证监会)及其工作人员在业务检查过程中，对所涉及的商业秘密应当注意保护。
