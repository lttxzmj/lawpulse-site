# 证券、期货投资咨询管理暂行办法第三十七条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第五章罚则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/37.html

中国证监会和地方证管办(证监会)的工作人员玩忽职守、滥用职权、徇私舞弊，构成犯罪的，依法追究刑事责任；尚不构成犯罪的，依法给予行政处分。
