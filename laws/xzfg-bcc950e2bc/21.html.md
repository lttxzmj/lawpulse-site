# 证券、期货投资咨询管理暂行办法第二十一条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/21.html

证券、期货投资咨询机构及其投资咨询人员，不得以虚假信息、市场传言或者内幕信息为依据向投资人或者客户提供投资分析、预测或建议。
