# 证券、期货投资咨询管理暂行办法第十九条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/19.html

证券、期货投资咨询机构及其投资咨询人员，应当以行业公认的谨慎、诚实和勤勉尽责的态度，为投资人或者客户提供证券、期货投资咨询服务。
