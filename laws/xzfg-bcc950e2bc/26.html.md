# 证券、期货投资咨询管理暂行办法第二十六条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/26.html

证券经营机构、期货经纪机构编发的供本机构内部使用的证券、期货信息简报、快讯、动态以及信息系统等，只能限于本机构范围内使用，不得通过任何途径向社会公众提供。
经中国证监会批准的公开发行股票的公司的承销商或者上市推荐人及其所属证券投资咨询机构，不得在公众传播媒体上刊登其为客户撰写的投资价值分析报告。
