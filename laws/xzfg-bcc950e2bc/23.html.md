# 证券、期货投资咨询管理暂行办法第二十三条

- 法规：证券、期货投资咨询管理暂行办法（现行有效）
- 章节：第四章证券、期货投资咨询业务管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-bcc950e2bc/23.html

证券、期货投资咨询机构与报刊、电台、电视台合办或者协办证券、期货投资咨询版面、节目或者与电信服务部门进行业务合作时，应当向地方证管办(证监会)备案，备案材料包括：合作内容、起止时间、版面安排或者节目时间段、项目负责人等，并加盖双方单位的印鉴。
