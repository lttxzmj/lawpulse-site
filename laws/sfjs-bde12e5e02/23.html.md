# 最高人民法院、最高人民检察院关于检察公益诉讼案件适用法律若干问题的解释第二十三条

- 法规：最高人民法院、最高人民检察院关于检察公益诉讼案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-bde12e5e02/23.html

人民检察院依据行政诉讼法第二十五条第四款的规定提起行政公益诉讼，符合行政诉讼法第四十九条第二项、第三项、第四项及本解释规定的起诉条件的，人民法院应当登记立案。
