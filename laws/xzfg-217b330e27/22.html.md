# 中华人民共和国植物新品种保护条例第二十二条

- 法规：中华人民共和国植物新品种保护条例（现行有效，施行日期 2025-06-01）
- 章节：第四章品种权的申请和受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-217b330e27/22.html

申请品种权的，应当向国务院农业农村、林业草原主管部门提交符合规定格式要求的申请文件。
申请文件应当使用中文书写。
