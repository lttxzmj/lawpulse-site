# 中华人民共和国植物新品种保护条例第二十七条

- 法规：中华人民共和国植物新品种保护条例（现行有效，施行日期 2025-06-01）
- 章节：第四章品种权的申请和受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-217b330e27/27.html

任何单位或者个人将在中国境内培育的植物新品种向境外申请品种权的，应当向国务院农业农村、林业草原主管部门登记；向境外提供繁殖材料的，应当遵守《中华人民共和国种子法》关于向境外提供种质资源的规定。
