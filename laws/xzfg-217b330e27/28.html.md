# 中华人民共和国植物新品种保护条例第二十八条

- 法规：中华人民共和国植物新品种保护条例（现行有效，施行日期 2025-06-01）
- 章节：第五章品种权的审查与批准
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-217b330e27/28.html

申请人缴纳申请费后，国务院农业农村、林业草原主管部门对品种权申请的下列内容进行初步审查：
（一）是否属于植物品种保护名录列举的植物属或者种的范围；
（二）是否符合本条例第二十一条的规定；
（三）是否符合新颖性的规定；
（四）植物新品种的命名是否适当。
