# 中华人民共和国植物新品种保护条例第二十条

- 法规：中华人民共和国植物新品种保护条例（现行有效，施行日期 2025-06-01）
- 章节：第四章品种权的申请和受理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-217b330e27/20.html

中国的单位或者个人申请品种权的，可以直接或者委托代理机构向国务院农业农村、林业草原主管部门提出申请。
中国的单位或者个人申请品种权的植物新品种涉及国家安全或者重大利益需要保密的，应当按照国家有关规定办理。
