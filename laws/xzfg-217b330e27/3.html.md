# 中华人民共和国植物新品种保护条例第三条

- 法规：中华人民共和国植物新品种保护条例（现行有效，施行日期 2025-06-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-217b330e27/3.html

植物新品种保护工作应当坚持中国共产党的领导，贯彻党和国家知识产权战略部署，促进育种创新，推动种业高质量发展。
