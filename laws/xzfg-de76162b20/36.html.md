# 放射性物品运输安全管理条例第三十六条

- 法规：放射性物品运输安全管理条例（现行有效）
- 章节：第四章放射性物品的运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-de76162b20/36.html

放射性物品运输的核与辐射安全分析报告批准书应当载明下列主要内容：
(一)托运人的名称、地址、法定代表人；
(二)运输放射性物品的品名、数量；
(三)运输放射性物品的运输容器型号和运输方式；
(四)批准日期和有效期限。
