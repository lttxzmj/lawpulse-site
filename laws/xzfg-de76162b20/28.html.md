# 放射性物品运输安全管理条例第二十八条

- 法规：放射性物品运输安全管理条例（现行有效）
- 章节：第三章放射性物品运输容器的制造与使用
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-de76162b20/28.html

国务院核安全监管部门办理使用境外单位制造的一类、二类放射性物品运输容器审查批准和备案手续，应当同时为运输容器确定编码。
