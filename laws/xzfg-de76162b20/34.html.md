# 放射性物品运输安全管理条例第三十四条

- 法规：放射性物品运输安全管理条例（现行有效）
- 章节：第四章放射性物品的运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-de76162b20/34.html

托运人应当向承运人提交运输说明书、辐射监测报告、核与辐射事故应急响应指南、装卸作业方法、安全防护指南，承运人应当查验、收存。托运人提交文件不齐全的，承运人不得承运。
