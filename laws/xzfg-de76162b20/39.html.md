# 放射性物品运输安全管理条例第三十九条

- 法规：放射性物品运输安全管理条例（现行有效）
- 章节：第四章放射性物品的运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-de76162b20/39.html

通过水路运输放射性物品的，按照水路危险货物运输的法律、行政法规和规章的有关规定执行。
通过铁路、航空运输放射性物品的，按照国务院铁路、民航主管部门的有关规定执行。
禁止邮寄一类、二类放射性物品。邮寄三类放射性物品的，按照国务院邮政管理部门的有关规定执行。
