# 放射性物品运输安全管理条例第三十三条

- 法规：放射性物品运输安全管理条例（现行有效）
- 章节：第四章放射性物品的运输
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-de76162b20/33.html

托运人和承运人应当按照国家职业病防治的有关规定，对直接从事放射性物品运输的工作人员进行个人剂量监测，建立个人剂量档案和职业健康监护档案。
