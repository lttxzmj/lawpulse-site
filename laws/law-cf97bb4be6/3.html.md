# 中华人民共和国预防未成年人犯罪法第三条

- 法规：中华人民共和国预防未成年人犯罪法（现行有效，施行日期 2021-06-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/law-cf97bb4be6/3.html

开展预防未成年人犯罪工作，应当尊重未成年人人格尊严，保护未成年人的名誉权、隐私权和个人信息等合法权益。
