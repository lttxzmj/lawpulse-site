# 最高人民法院、最高人民检察院关于适用刑事缺席审判程序若干问题的规定第十九条

- 法规：最高人民法院、最高人民检察院关于适用刑事缺席审判程序若干问题的规定（现行有效，施行日期 2026-05-22）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-cac693b883/19.html

患有严重疾病被告人在缺席审理期间死亡或者逃匿，符合违法所得没收程序适用条件的，人民检察院应当及时向人民法院提出没收违法所得申请。
