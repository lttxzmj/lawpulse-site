# 最高人民法院、最高人民检察院关于适用刑事缺席审判程序若干问题的规定第二十二条

- 法规：最高人民法院、最高人民检察院关于适用刑事缺席审判程序若干问题的规定（现行有效，施行日期 2026-05-22）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-cac693b883/22.html

人民法院按照审判监督程序重新审判的案件，被告人死亡的，可以缺席审理。经缺席审理确认无罪的，应当判决宣告被告人无罪；虽然构成犯罪，但原判量刑畸重的，应当依法作出判决。
