# 最高人民法院关于涉港澳民商事案件司法文书送达问题若干规定第一条

- 法规：最高人民法院关于涉港澳民商事案件司法文书送达问题若干规定（现行有效，施行日期 2009-03-16）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-2e5c7d7404/1.html

人民法院审理涉及香港特别行政区、澳门特别行政区的民商事案件时，向住所地在香港特别行政区、澳门特别行政区的受送达人送达司法文书，适用本规定。
