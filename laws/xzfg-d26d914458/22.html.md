# 中华人民共和国船员条例第二十二条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第四章船员职业保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/22.html

船舶上船员生活和工作的场所，应当符合国家船舶检验规范中有关船员生活环境、作业安全和防护的要求。
船员用人单位应当为船员提供必要的生活用品、防护用品、医疗用品，建立船员健康档案，并为船员定期进行健康检查，防治职业疾病。
船员在船工作期间患病或者受伤的，船员用人单位应当及时给予救治；船员失踪或者死亡的，船员用人单位应当及时做好相应的善后工作。
