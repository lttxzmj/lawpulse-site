# 中华人民共和国船员条例第五十条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/50.html

违反本条例的规定，船员服务簿记载的事项发生变更，船员未办理变更手续的，由海事管理机构责令改正，可以处1000元以下罚款。
