# 中华人民共和国船员条例第二十三条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第四章船员职业保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/23.html

船员用人单位应当依照有关劳动合同的法律、法规和中华人民共和国缔结或者加入的有关船员劳动与社会保障国际条约的规定，与船员订立劳动合同。
船员用人单位不得招用未取得本条例规定证件的人员上船工作。
