# 中华人民共和国船员条例第二十八条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第四章船员职业保障
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/28.html

船员可以从下列地点中选择遣返地点：
（一）船员接受招用的地点或者上船任职的地点；
（二）船员的居住地、户籍所在地或者船籍登记国；
（三）船员与船员用人单位或者船舶所有人约定的地点。
