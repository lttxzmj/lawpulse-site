# 中华人民共和国船员条例第三十四条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第五章船员培训和船员服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/34.html

从事船员培训业务的机构，应当按照国务院交通主管部门规定的船员培训大纲和水上交通安全、防治船舶污染、船舶保安等要求，在核定的范围内开展船员培训，确保船员培训质量。
