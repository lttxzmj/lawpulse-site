# 中华人民共和国船员条例第四十四条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第六章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/44.html

船舶违反本条例和有关法律、行政法规规定的，海事管理机构应当责令限期改正；在规定期限内未能改正的，海事管理机构可以禁止船舶离港或者限制船舶航行、停泊、作业。
