# 中华人民共和国船员条例第四十九条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/49.html

违反本条例的规定，伪造、变造或者买卖船员服务簿、船员培训合格证书、中华人民共和国海员证的，由海事管理机构收缴有关证件，处2万元以上10万元以下罚款，有违法所得的，还应当没收违法所得。
