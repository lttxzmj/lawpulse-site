# 中华人民共和国船员条例第四十一条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第六章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/41.html

海事管理机构对船员实施监督检查时，应当查验船员必须携带的证件的有效性，检查船员履行职责的情况，必要时可以进行现场考核。
