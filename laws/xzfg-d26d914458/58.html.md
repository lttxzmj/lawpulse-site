# 中华人民共和国船员条例第五十八条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/58.html

违反本条例的规定，船员服务机构在提供船员服务时，提供虚假信息，欺诈船员的，由海事管理机构或者劳动保障行政部门依据职责责令改正，处3万元以上15万元以下罚款；情节严重的，并给予暂停船员服务6个月以上2年以下直至吊销相关业务经营许可的处罚。
