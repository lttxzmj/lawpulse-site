# 中华人民共和国船员条例第三十九条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第五章船员培训和船员服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/39.html

船员服务机构为船员用人单位提供船舶配员服务，应当按照相关法律、行政法规的规定订立合同。
船员服务机构为船员用人单位提供的船员受伤、失踪或者死亡的，船员服务机构应当配合船员用人单位做好善后工作。
