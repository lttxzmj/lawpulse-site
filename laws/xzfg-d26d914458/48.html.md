# 中华人民共和国船员条例第四十八条

- 法规：中华人民共和国船员条例（现行有效，施行日期 2023-07-20）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d26d914458/48.html

违反本条例的规定，以欺骗、贿赂等不正当手段取得船员适任证书、船员培训合格证书、中华人民共和国海员证的，由海事管理机构吊销有关证件，并处2000元以上2万元以下罚款。
