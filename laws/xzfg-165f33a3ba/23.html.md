# 残疾人就业条例第二十三条

- 法规：残疾人就业条例（现行有效）
- 章节：第四章就业服务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-165f33a3ba/23.html

受劳动保障部门的委托，残疾人就业服务机构可以进行残疾人失业登记、残疾人就业与失业统计；经所在地劳动保障部门批准，残疾人就业服务机构还可以进行残疾人职业技能鉴定。
