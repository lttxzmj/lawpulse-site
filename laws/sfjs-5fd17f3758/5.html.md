# 最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定第五条

- 法规：最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5fd17f3758/5.html

下列第一审行政案件由北京知识产权法院管辖：
（一）不服国务院部门作出的有关专利、商标、植物新品种、集成电路布图设计等知识产权的授权确权裁定或者决定的；
（二）不服国务院部门作出的有关专利、植物新品种、集成电路布图设计的强制许可决定以及强制许可使用费或者报酬的裁决的；
（三）不服国务院部门作出的涉及知识产权授权确权的其他行政行为的。
