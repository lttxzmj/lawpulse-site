# 最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定第八条

- 法规：最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5fd17f3758/8.html

知识产权法院所在省（直辖市）的基层人民法院在知识产权法院成立前已经受理但尚未审结的本规定第一条第（一）项和第（三）项规定的案件，由该基层人民法院继续审理。
除广州市中级人民法院以外，广东省其他中级人民法院在广州知识产权法院成立前已经受理但尚未审结的本规定第一条第（一）项和第（三）项规定的案件，由该中级人民法院继续审理。
