# 最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定第七条

- 法规：最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5fd17f3758/7.html

当事人对知识产权法院作出的第一审判决、裁定提起的上诉案件和依法申请上一级法院复议的案件，由知识产权法院所在地的高级人民法院知识产权审判庭审理，但依法应由最高人民法院审理的除外。
