# 最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定第三条

- 法规：最高人民法院关于北京、上海、广州知识产权法院案件管辖的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-5fd17f3758/3.html

北京市、上海市各中级人民法院和广州市中级人民法院不再受理知识产权民事和行政案件。
广东省其他中级人民法院不再受理本规定第一条第（一）项和第（三）项规定的案件。
北京市、上海市、广东省各基层人民法院不再受理本规定第一条第（一）项和第（三）项规定的案件。
