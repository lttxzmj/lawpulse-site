# 最高人民法院关于人民法院赔偿委员会适用质证程序审理国家赔偿案件的规定第十七条

- 法规：最高人民法院关于人民法院赔偿委员会适用质证程序审理国家赔偿案件的规定（现行有效，施行日期 2014-03-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-86989395ef/17.html

质证一般按照下列顺序进行：
（一）赔偿请求人、赔偿义务机关分别陈述，复议机关进行说明；
（二）审判员归纳争议焦点；
（三）赔偿请求人、赔偿义务机关分别出示证据，发表意见；
（四）询问参加质证的证人、鉴定人、勘验人；
（五）赔偿请求人、赔偿义务机关就争议的事项进行质询和辩论；
（六）审判员宣布赔偿请求人、赔偿义务机关认识一致的事实和证据；
（七）赔偿请求人、赔偿义务机关最后陈述意见。
