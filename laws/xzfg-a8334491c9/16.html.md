# 密云水库水源保护条例第十六条

- 法规：密云水库水源保护条例（现行有效，施行日期 2025-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a8334491c9/16.html

在密云水库管理范围以及潮河、白河干流河道管理范围外1000米范围内，禁止新建、扩建尾矿库、化工园区和化工项目。
根据密云水库水源保护需要，北京市人民政府、河北省人民政府可以确定在前款规定区域内禁止或者限制新建、扩建的其他建设项目。
