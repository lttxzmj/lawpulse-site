# 密云水库水源保护条例第三条

- 法规：密云水库水源保护条例（现行有效，施行日期 2025-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a8334491c9/3.html

密云水库水源保护应当贯彻党和国家路线方针政策、决策部署，立足密云水库流域主体功能定位，坚持保护优先、统筹保护与发展，坚持源头控制、系统治理，强化区域协同联动，实现水源保护、绿色发展、民生改善相统一。
密云水库水源保护应当与全面提升密云水库流域防洪等防灾减灾救灾能力相结合。
