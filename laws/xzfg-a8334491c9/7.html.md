# 密云水库水源保护条例第七条

- 法规：密云水库水源保护条例（现行有效，施行日期 2025-12-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-a8334491c9/7.html

密云水库流域产业结构和布局应当与流域生态系统、资源环境承载能力以及密云水库水源保护要求相适应。
密云水库流域县级以上地方人民政府应当加快密云水库流域产业结构调整和布局优化，按照密云水库流域主体功能定位，依法加强对各类开发建设活动的管理，严禁不符合主体功能定位的各类开发建设活动。
