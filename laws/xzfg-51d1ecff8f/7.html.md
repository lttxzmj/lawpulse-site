# 中华人民共和国海关统计条例第七条

- 法规：中华人民共和国海关统计条例（现行有效，施行日期 2022-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-51d1ecff8f/7.html

进出口货物的品名及编码，按照《中华人民共和国海关统计商品目录》归类统计。
进出口货物的数量，按照《中华人民共和国海关统计商品目录》规定的计量单位统计。
《中华人民共和国海关统计商品目录》由海关总署公布。
