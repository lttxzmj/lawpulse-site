# 中华人民共和国海上交通事故调查处理条例第十八条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第四章处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/18.html

对海上交通事故的发生负有责任的人员及船舶、设施的所有人或经营人，需要追究其行政责任的，由港务监督提交其主管机关或行政监察机关处理；构成犯罪的，由司法机关依法追究刑事责任。
