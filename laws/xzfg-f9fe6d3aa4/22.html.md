# 中华人民共和国海上交通事故调查处理条例第二十二条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第五章调解
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/22.html

调解由当事人各方在事故发生之日起三十日内向负责该事故调查的港务监督提交书面申请。港务监督要求提供担保的，当事人应附经济赔偿担保证明文件。
