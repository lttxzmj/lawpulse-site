# 中华人民共和国海上交通事故调查处理条例第二十八条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第五章调解
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/28.html

凡申请港务监督调解的，应向港务监督缴纳调解费。调解的收费标准，由交通部会同国家物价局、财政部制定。
经调解达成协议的，调解费用按当事人过失比例或约定的数额分摊；调解不成的，由当事人各方平均分摊。
