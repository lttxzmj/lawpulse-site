# 中华人民共和国海上交通事故调查处理条例第二十条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第五章调解
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/20.html

对船舶、设施发生海上交通事故引起的民事侵权赔偿纠纷，当事人可以申请港务监督调解。
调解必须遵循自愿、公平的原则，不得强迫。
