# 中华人民共和国海上交通事故调查处理条例第十六条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第四章处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/16.html

《海上交通事故调查报告书》应包括以下内容：
(一)船舶、设施的概况和主要数据；
(二)船舶、设施所有人或经营人的名称和地址；
(三)事故发生的时间、地点、过程、气象海况、损害情况等；
(四)事故发生的原因及依据；
(五)当事人各方的责任及依据；
(六)其他有关情况。
