# 中华人民共和国海上交通事故调查处理条例第四条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/4.html

本条例所称海上交通事故是指船舶、设施发生的下列事故：
(一)碰撞、触碰或浪损；
(二)触礁或搁浅；
(三)火灾或爆炸；
(四)沉没；
(五)在航行中发生影响适航性能的机件或重要属具的损坏或灭失；
(六)其他引起财产损失和人身伤亡的海上交通事故。
