# 中华人民共和国海上交通事故调查处理条例第十九条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第四章处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/19.html

根据海上交通事故发生的原因，港务监督可责令有关船舶、设施的所有人、经营人限期加强对所属船舶、设施的安全管理。对拒不加强安全管理或在限期内达不到安全要求的，港务监督有权责令其停航、改航、停止作业，并可采取其他必要的强制性处置措施。
