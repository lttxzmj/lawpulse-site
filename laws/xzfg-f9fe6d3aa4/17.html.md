# 中华人民共和国海上交通事故调查处理条例第十七条

- 法规：中华人民共和国海上交通事故调查处理条例（现行有效）
- 章节：第四章处理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f9fe6d3aa4/17.html

对海上交通事故的发生负有责任的人员，港务监督可以根据其责任的性质和程度依法给予下列处罚：
(一)对中国籍船员、引航员或设施上的工作人员，可以给予警告、罚款或扣留、吊销职务证书；
(二)对外国籍船员或设施上的工作人员，可以给予警告、罚款或将其过失通报其所属国家的主管机关。
