# 特种设备安全监察条例第九十六条

- 法规：特种设备安全监察条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-8d99256fea/96.html

检验检测人员，从事检验检测工作，不在特种设备检验检测机构执业或者同时在两个以上检验检测机构中执业的，由特种设备安全监督管理部门责令改正，情节严重的，给予停止执业6个月以上2年以下的处罚；有违法所得的，没收违法所得。
