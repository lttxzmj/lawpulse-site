# 中华人民共和国土地管理法实施条例第四十七条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/47.html

土地管理监督检查人员应当经过培训，经考核合格，取得行政执法证件后，方可从事土地管理监督检查工作。
