# 中华人民共和国土地管理法实施条例第五十三条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/53.html

违反《土地管理法》第六十五条的规定，对建筑物、构筑物进行重建、扩建的，由县级以上人民政府自然资源主管部门责令限期拆除；逾期不拆除的，由作出行政决定的机关依法申请人民法院强制执行。
