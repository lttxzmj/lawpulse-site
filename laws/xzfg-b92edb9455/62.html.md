# 中华人民共和国土地管理法实施条例第六十二条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/62.html

违反土地管理法律、法规规定，阻挠国家建设征收土地的，由县级以上地方人民政府责令交出土地；拒不交出土地的，依法申请人民法院强制执行。
