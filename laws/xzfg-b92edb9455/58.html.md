# 中华人民共和国土地管理法实施条例第五十八条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/58.html

依照《土地管理法》第七十四条、第七十七条的规定，县级以上人民政府自然资源主管部门没收在非法转让或者非法占用的土地上新建的建筑物和其他设施的，应当于九十日内交由本级人民政府或者其指定的部门依法管理和处置。
