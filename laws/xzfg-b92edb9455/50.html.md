# 中华人民共和国土地管理法实施条例第五十条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/50.html

县级以上人民政府自然资源主管部门应当会同有关部门建立信用监管、动态巡查等机制，加强对建设用地供应交易和供后开发利用的监管，对建设用地市场重大失信行为依法实施惩戒，并依法公开相关信息。
