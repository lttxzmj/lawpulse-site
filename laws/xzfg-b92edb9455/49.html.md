# 中华人民共和国土地管理法实施条例第四十九条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第五章监督检查
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/49.html

依照《土地管理法》第七十三条的规定给予处分的，应当按照管理权限由责令作出行政处罚决定或者直接给予行政处罚的上级人民政府自然资源主管部门或者其他任免机关、单位作出。
