# 中华人民共和国土地管理法实施条例第十三条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第三章耕地保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/13.html

省、自治区、直辖市人民政府对本行政区域耕地保护负总责，其主要负责人是本行政区域耕地保护的第一责任人。
省、自治区、直辖市人民政府应当将国务院确定的耕地保有量和永久基本农田保护任务分解下达，落实到具体地块。
国务院对省、自治区、直辖市人民政府耕地保护责任目标落实情况进行考核。
