# 中华人民共和国土地管理法实施条例第五十一条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/51.html

违反《土地管理法》第三十七条的规定，非法占用永久基本农田发展林果业或者挖塘养鱼的，由县级以上人民政府自然资源主管部门责令限期改正；逾期不改正的，按占用面积处耕地开垦费2倍以上5倍以下的罚款；破坏种植条件的，依照《土地管理法》第七十五条的规定处罚。
