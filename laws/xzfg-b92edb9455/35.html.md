# 中华人民共和国土地管理法实施条例第三十五条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第四章建设用地 · 第四节宅基地管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/35.html

国家允许进城落户的农村村民依法自愿有偿退出宅基地。乡（镇）人民政府和农村集体经济组织、村民委员会等应当将退出的宅基地优先用于保障该农村集体经济组织成员的宅基地需求。
