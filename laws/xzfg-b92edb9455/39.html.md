# 中华人民共和国土地管理法实施条例第三十九条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第四章建设用地 · 第五节集体经营性建设用地管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/39.html

土地所有权人拟出让、出租集体经营性建设用地的，市、县人民政府自然资源主管部门应当依据国土空间规划提出拟出让、出租的集体经营性建设用地的规划条件，明确土地界址、面积、用途和开发建设强度等。
市、县人民政府自然资源主管部门应当会同有关部门提出产业准入和生态环境保护要求。
