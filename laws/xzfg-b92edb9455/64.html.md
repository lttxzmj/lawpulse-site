# 中华人民共和国土地管理法实施条例第六十四条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/64.html

贪污、侵占、挪用、私分、截留、拖欠征地补偿安置费用和其他有关费用的，责令改正，追回有关款项，限期退还违法所得，对有关责任单位通报批评、给予警告；造成损失的，依法承担赔偿责任；对直接负责的主管人员和其他直接责任人员，依法给予处分。
