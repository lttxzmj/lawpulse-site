# 中华人民共和国土地管理法实施条例第二十二条

- 法规：中华人民共和国土地管理法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第四章建设用地 · 第一节一般规定
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-b92edb9455/22.html

具有重要生态功能的未利用地应当依法划入生态保护红线，实施严格保护。
建设项目占用国土空间规划确定的未利用地的，按照省、自治区、直辖市的规定办理。
