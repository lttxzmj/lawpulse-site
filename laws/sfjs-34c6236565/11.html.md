# 最高人民法院关于审理著作权民事纠纷案件适用法律若干问题的解释第十一条

- 法规：最高人民法院关于审理著作权民事纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-34c6236565/11.html

因作品署名顺序发生的纠纷，人民法院按照下列原则处理：
有约定的按约定确定署名顺序；
没有约定的，可以按照创作作品付出的劳动、作品排列、作者姓氏笔划等确定署名顺序。
