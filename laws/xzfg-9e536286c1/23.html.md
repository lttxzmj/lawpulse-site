# 民用爆炸物品安全管理条例第二十三条

- 法规：民用爆炸物品安全管理条例（现行有效）
- 章节：第三章销售和购买
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e536286c1/23.html

销售、购买民用爆炸物品，应当通过银行账户进行交易，不得使用现金或者实物进行交易。
销售民用爆炸物品的企业，应当将购买单位的许可证、银行账户转账凭证、经办人的身份证明复印件保存2年备查。
