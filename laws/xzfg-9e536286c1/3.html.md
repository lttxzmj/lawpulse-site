# 民用爆炸物品安全管理条例第三条

- 法规：民用爆炸物品安全管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e536286c1/3.html

国家对民用爆炸物品的生产、销售、购买、运输和爆破作业实行许可证制度。
未经许可，任何单位或者个人不得生产、销售、购买、运输民用爆炸物品，不得从事爆破作业。
严禁转让、出借、转借、抵押、赠送、私藏或者非法持有民用爆炸物品。
