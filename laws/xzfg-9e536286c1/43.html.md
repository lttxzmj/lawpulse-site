# 民用爆炸物品安全管理条例第四十三条

- 法规：民用爆炸物品安全管理条例（现行有效）
- 章节：第六章储存
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e536286c1/43.html

民用爆炸物品变质和过期失效的，应当及时清理出库，并予以销毁。销毁前应当登记造册，提出销毁实施方案，报省、自治区、直辖市人民政府民用爆炸物品行业主管部门、所在地县级人民政府公安机关组织监督销毁。
