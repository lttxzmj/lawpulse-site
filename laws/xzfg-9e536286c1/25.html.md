# 民用爆炸物品安全管理条例第二十五条

- 法规：民用爆炸物品安全管理条例（现行有效）
- 章节：第三章销售和购买
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9e536286c1/25.html

进出口民用爆炸物品，应当经国务院民用爆炸物品行业主管部门审批。进出口民用爆炸物品审批办法，由国务院民用爆炸物品行业主管部门会同国务院公安部门、海关总署规定。
进出口单位应当将进出口的民用爆炸物品的品种、数量向收货地或者出境口岸所在地县级人民政府公安机关备案。
