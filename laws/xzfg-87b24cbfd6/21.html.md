# 军工关键设备设施管理条例第二十一条

- 法规：军工关键设备设施管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87b24cbfd6/21.html

企业、事业单位违反本条例规定，未经批准处置使用国家财政资金购建的用于武器装备总体、关键分系统、核心配套产品科研生产的军工关键设备设施的，责令限期改正，处以50万元以上100万元以下罚款，对直接负责的主管人员和其他直接责任人员处以5000元以上2万元以下罚款；有违法所得的，没收违法所得。
