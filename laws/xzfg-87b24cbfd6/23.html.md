# 军工关键设备设施管理条例第二十三条

- 法规：军工关键设备设施管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87b24cbfd6/23.html

本条例规定的行政处罚，由国务院国防科技工业主管部门决定。但是，对本条例第七条第二款规定的企业、事业单位有本条例第十九条规定的违法行为的行政处罚，由省、自治区、直辖市人民政府负责国防科技工业管理的部门决定。
