# 军工关键设备设施管理条例第七条

- 法规：军工关键设备设施管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87b24cbfd6/7.html

中央管理的企业负责办理所属单位军工关键设备设施的登记。国务院教育主管部门负责办理所属高等学校军工关键设备设施的登记。中国科学院负责办理所属科研机构军工关键设备设施的登记。
省、自治区、直辖市人民政府负责国防科技工业管理的部门负责办理本行政区域内前款规定以外的企业、事业单位军工关键设备设施的登记。
