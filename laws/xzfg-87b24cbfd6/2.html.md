# 军工关键设备设施管理条例第二条

- 法规：军工关键设备设施管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-87b24cbfd6/2.html

本条例所称军工关键设备设施，是指直接用于武器装备科研生产的重要的实验设施、工艺设备、试验及测试设备等专用的军工设备设施。
军工关键设备设施的目录，由国务院国防科技工业主管部门会同军队武器装备主管部门、国务院国有资产监督管理机构和国务院有关部门制定。
