# 中华人民共和国进出口商品检验法实施条例第二十三条

- 法规：中华人民共和国进出口商品检验法实施条例（现行有效，施行日期 2026-08-15）
- 章节：第二章进口商品的检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5815708f5e/23.html

进口机动车辆到货后，收货人凭出入境检验检疫机构签发的进口机动车辆检验证单以及有关部门签发的其他单证向车辆管理机关申领行车牌证。在使用过程中发现有涉及人身财产安全的质量缺陷的，出入境检验检疫机构应当及时作出相应处理。
