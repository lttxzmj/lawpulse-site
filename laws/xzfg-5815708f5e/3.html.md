# 中华人民共和国进出口商品检验法实施条例第三条

- 法规：中华人民共和国进出口商品检验法实施条例（现行有效，施行日期 2026-08-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5815708f5e/3.html

海关总署应当依照商检法第四条规定，制定、调整必须实施检验的进出口商品目录（以下简称目录）并公布实施。
目录应当至少在实施之日30日前公布；在紧急情况下，应当不迟于实施之日公布。
海关总署制定、调整目录时，应当征求国务院对外贸易主管部门等有关方面的意见。
