# 中华人民共和国进出口商品检验法实施条例第十一条

- 法规：中华人民共和国进出口商品检验法实施条例（现行有效，施行日期 2026-08-15）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5815708f5e/11.html

进出口商品的收货人或者发货人可以自行办理报检手续，也可以委托代理报检企业办理报检手续；采用快件方式进出口商品的，收货人或者发货人应当委托出入境快件运营企业办理报检手续。
