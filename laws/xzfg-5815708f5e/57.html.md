# 中华人民共和国进出口商品检验法实施条例第五十七条

- 法规：中华人民共和国进出口商品检验法实施条例（现行有效，施行日期 2026-08-15）
- 章节：第六章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5815708f5e/57.html

当事人对出入境检验检疫机构、海关总署作出的复验结论、处罚决定不服的，可以依法申请行政复议，也可以依法向人民法院提起诉讼。
当事人逾期不履行处罚决定，又不申请行政复议或者向人民法院提起诉讼的，作出处罚决定的机构可以申请人民法院强制执行。
