# 中华人民共和国进出口商品检验法实施条例第五十条

- 法规：中华人民共和国进出口商品检验法实施条例（现行有效，施行日期 2026-08-15）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5815708f5e/50.html

提供或者使用未经出入境检验检疫机构鉴定的出口危险货物包装容器的，由出入境检验检疫机构处10万元以下罚款。
提供或者使用经出入境检验检疫机构鉴定不合格的包装容器装运出口危险货物的，由出入境检验检疫机构处20万元以下罚款。
