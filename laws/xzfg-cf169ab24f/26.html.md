# 中华人民共和国领事保护与协助条例第二十六条

- 法规：中华人民共和国领事保护与协助条例（现行有效，施行日期 2023-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf169ab24f/26.html

中国公民、法人、非法人组织在领事保护与协助过程中，得到第三方提供的食宿、交通、医疗等物资和服务的，应当支付应由其自身承担的费用。
