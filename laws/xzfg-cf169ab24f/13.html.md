# 中华人民共和国领事保护与协助条例第十三条

- 法规：中华人民共和国领事保护与协助条例（现行有效，施行日期 2023-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf169ab24f/13.html

在国外的中国公民下落不明，其亲属向驻外外交机构求助的，驻外外交机构应当提供当地报警方式及其他获取救助的信息。
驻在国警方立案的，驻外外交机构应当敦促驻在国警方及时妥善处理。
