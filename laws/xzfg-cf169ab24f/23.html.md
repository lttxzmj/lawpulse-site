# 中华人民共和国领事保护与协助条例第二十三条

- 法规：中华人民共和国领事保护与协助条例（现行有效，施行日期 2023-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf169ab24f/23.html

驻外外交机构根据领事保护与协助工作实际需要，经外交部批准，可以聘用人员从事辅助性工作。
外交部和驻外外交机构根据工作职责要求，对从事领事保护与协助工作的驻外外交人员及其他人员进行培训。
