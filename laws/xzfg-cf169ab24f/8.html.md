# 中华人民共和国领事保护与协助条例第八条

- 法规：中华人民共和国领事保护与协助条例（现行有效，施行日期 2023-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf169ab24f/8.html

在国外的中国公民、法人、非法人组织因正当权益被侵犯向驻外外交机构求助的，驻外外交机构应当根据相关情形向其提供维护自身正当权益的渠道和建议，向驻在国有关部门核实情况，敦促依法公正妥善处理，并提供协助。
