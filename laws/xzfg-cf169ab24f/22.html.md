# 中华人民共和国领事保护与协助条例第二十二条

- 法规：中华人民共和国领事保护与协助条例（现行有效，施行日期 2023-09-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-cf169ab24f/22.html

国家为领事保护与协助工作提供人员、资金等保障。
地方人民政府参与领事保护与协助相关工作的经费纳入预算管理。
有外派人员的国内企业用于国外安全保障的投入纳入企业成本费用。
