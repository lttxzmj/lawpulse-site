# 国家赔偿费用管理条例第三条

- 法规：国家赔偿费用管理条例（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-4cf4586d44/3.html

国家赔偿费用由各级人民政府按照财政管理体制分级负担。
各级人民政府应当根据实际情况，安排一定数额的国家赔偿费用，列入本级年度财政预算。当年需要支付的国家赔偿费用超过本级年度财政预算安排的，应当按照规定及时安排资金。
