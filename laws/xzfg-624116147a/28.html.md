# 公共文化体育设施条例第二十八条

- 法规：公共文化体育设施条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-624116147a/28.html

文化、体育、城乡规划、建设、土地等有关行政主管部门及其工作人员，不依法履行职责或者发现违法行为不予依法查处的，对负有责任的主管人员和其他直接责任人员，依法给予行政处分；构成犯罪的，依法追究刑事责任。
