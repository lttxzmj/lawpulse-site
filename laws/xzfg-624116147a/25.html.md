# 公共文化体育设施条例第二十五条

- 法规：公共文化体育设施条例（现行有效）
- 章节：第四章管理和保护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-624116147a/25.html

公共文化体育设施管理单位应当建立、健全安全管理制度，依法配备安全保护设施、人员，保证公共文化体育设施的完好，确保公众安全。
公共体育设施内设置的专业性强、技术要求高的体育项目，应当符合国家规定的安全服务技术要求。
