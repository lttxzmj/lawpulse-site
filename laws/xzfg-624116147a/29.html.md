# 公共文化体育设施条例第二十九条

- 法规：公共文化体育设施条例（现行有效）
- 章节：第五章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-624116147a/29.html

侵占公共文化体育设施建设预留地或者改变其用途的，由土地行政主管部门、城乡规划行政主管部门依据各自职责责令限期改正；逾期不改正的，由作出决定的机关依法申请人民法院强制执行。
