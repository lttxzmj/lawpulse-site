# 中华人民共和国抗旱条例第二十八条

- 法规：中华人民共和国抗旱条例（现行有效）
- 章节：第二章旱灾预防
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9293188b53/28.html

抗旱预案应当包括预案的执行机构以及有关部门的职责、干旱灾害预警、干旱等级划分和按不同等级采取的应急措施、旱情紧急情况下水量调度预案和保障措施等内容。
干旱灾害按照区域耕地和作物受旱的面积与程度以及因干旱导致饮水困难人口的数量，分为轻度干旱、中度干旱、严重干旱、特大干旱四级。
