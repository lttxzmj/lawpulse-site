# 中华人民共和国抗旱条例第五十六条

- 法规：中华人民共和国抗旱条例（现行有效）
- 章节：第四章灾后恢复
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9293188b53/56.html

抗旱经费和抗旱物资必须专项使用，任何单位和个人不得截留、挤占、挪用和私分。
各级财政和审计部门应当加强对抗旱经费和物资管理的监督、检查和审计。
