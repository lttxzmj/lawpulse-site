# 中华人民共和国统计法实施条例第二十八条

- 法规：中华人民共和国统计法实施条例（现行有效）
- 章节：第四章统计资料的管理和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-62ab8a0584/28.html

公布统计资料应当按照国家有关规定进行。公布前，任何单位和个人不得违反国家有关规定对外提供，不得利用尚未公布的统计资料谋取不正当利益。
