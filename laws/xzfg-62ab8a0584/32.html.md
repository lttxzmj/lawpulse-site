# 中华人民共和国统计法实施条例第三十二条

- 法规：中华人民共和国统计法实施条例（现行有效）
- 章节：第五章统计机构和统计人员
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-62ab8a0584/32.html

县级以上地方人民政府统计机构受本级人民政府和上级人民政府统计机构的双重领导，在统计业务上以上级人民政府统计机构的领导为主。
乡、镇人民政府应当设置统计工作岗位，配备专职或者兼职统计人员，履行统计职责，在统计业务上受上级人民政府统计机构领导。乡、镇统计人员的调动，应当征得县级人民政府统计机构的同意。
县级以上人民政府有关部门在统计业务上受本级人民政府统计机构指导。
