# 中华人民共和国统计法实施条例第二十五条

- 法规：中华人民共和国统计法实施条例（现行有效）
- 章节：第四章统计资料的管理和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-62ab8a0584/25.html

国务院有关部门统计调查取得的统计数据，由国务院有关部门按照国家有关规定和已批准或者备案的统计调查制度公布。
县级以上地方人民政府有关部门公布其统计调查取得的统计数据，比照前款规定执行。
