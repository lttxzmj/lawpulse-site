# 中华人民共和国统计法实施条例第二十七条

- 法规：中华人民共和国统计法实施条例（现行有效）
- 章节：第四章统计资料的管理和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-62ab8a0584/27.html

县级以上人民政府统计机构和有关部门应当及时公布主要统计指标涵义、调查范围、调查方法、计算方法、抽样调查样本量等信息，对统计数据进行解释说明。
