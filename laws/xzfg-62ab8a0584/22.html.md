# 中华人民共和国统计法实施条例第二十二条

- 法规：中华人民共和国统计法实施条例（现行有效）
- 章节：第四章统计资料的管理和公布
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-62ab8a0584/22.html

统计调查中取得的统计调查对象的原始资料，应当至少保存2年。
汇总性统计资料应当至少保存10年，重要的汇总性统计资料应当永久保存。法律法规另有规定的，从其规定。
