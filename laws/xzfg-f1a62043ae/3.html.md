# 生猪屠宰管理条例第三条

- 法规：生猪屠宰管理条例（现行有效，施行日期 2021-08-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f1a62043ae/3.html

国务院农业农村主管部门负责全国生猪屠宰的行业管理工作。县级以上地方人民政府农业农村主管部门负责本行政区域内生猪屠宰活动的监督管理。
县级以上人民政府有关部门在各自职责范围内负责生猪屠宰活动的相关管理工作。
