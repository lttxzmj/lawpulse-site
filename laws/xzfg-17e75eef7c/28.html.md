# 残疾人教育条例第二十八条

- 法规：残疾人教育条例（现行有效）
- 章节：第三章职业教育
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-17e75eef7c/28.html

残疾人职业教育由普通职业教育机构和特殊职业教育机构实施，以普通职业教育机构为主。
县级以上地方人民政府应当根据需要，合理设置特殊职业教育机构，改善办学条件，扩大残疾人中等职业学校招生规模。
