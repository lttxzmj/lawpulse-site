# 残疾人教育条例第二十五条

- 法规：残疾人教育条例（现行有效）
- 章节：第二章义务教育
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-17e75eef7c/25.html

残疾儿童、少年特殊教育学校(班)的课程设置方案、课程标准和教材，应当适合残疾儿童、少年的身心特性和需要。
残疾儿童、少年特殊教育学校(班)的课程设置方案、课程标准由国务院教育行政部门制订；教材由省级以上人民政府教育行政部门按照国家有关规定审定。
