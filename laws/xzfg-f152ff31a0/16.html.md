# 中华人民共和国台湾同胞投资保护法实施细则第十六条

- 法规：中华人民共和国台湾同胞投资保护法实施细则（现行有效，施行日期 2020-11-29）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f152ff31a0/16.html

台湾同胞投资企业依法享有经营管理的自主权。
台湾同胞投资企业经营管理的自主权受国家法律保护，不受任何机关、单位或者个人的非法干预和侵犯。
