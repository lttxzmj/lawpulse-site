# 中华人民共和国台湾同胞投资保护法实施细则第三条

- 法规：中华人民共和国台湾同胞投资保护法实施细则（现行有效，施行日期 2020-11-29）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-f152ff31a0/3.html

国家依法保护台湾同胞投资。
台湾同胞投资者的投资、投资收益和其他合法权益受国家法律保护，任何机关、单位或者个人不得侵占、损害。
