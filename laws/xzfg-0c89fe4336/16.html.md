# 旅馆业治安管理办法第十六条

- 法规：旅馆业治安管理办法（现行有效，施行日期 2022-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-0c89fe4336/16.html

旅馆工作人员违反本办法第九条规定的，公安机关可以酌情给予警告或者处以200元以下罚款；情节严重构成犯罪的，依法追究刑事责任。
旅馆负责人参与违法犯罪活动，其所经营的旅馆已成为犯罪活动场所的，公安机关除依法追究其责任外，对该旅馆还应当会同工商行政管理部门依法处理。
