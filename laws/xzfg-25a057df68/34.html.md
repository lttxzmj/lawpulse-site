# 国家自然科学基金条例第三十四条

- 法规：国家自然科学基金条例（现行有效，施行日期 2025-01-01）
- 章节：第五章监督与管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-25a057df68/34.html

基金管理机构依照本条例规定对外公开有关信息，应当遵守国家有关保密规定。
基金管理机构应当健全科技安全制度和风险防范机制，加强科学技术研究、开发与应用活动的安全管理，支持国家安全领域科技创新，增强科技创新支撑国家安全的能力和水平。
