# 校车安全管理条例第五十四条

- 法规：校车安全管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1339fb2933/54.html

取得校车使用许可的学校、校车服务提供者违反本条例规定，情节严重的，原作出许可决定的地方人民政府可以吊销其校车使用许可，由公安机关交通管理部门收回校车标牌。
