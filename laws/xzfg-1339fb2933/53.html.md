# 校车安全管理条例第五十三条

- 法规：校车安全管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1339fb2933/53.html

未依照本条例规定指派照管人员随校车全程照管乘车学生的，由公安机关责令改正，可以处500元罚款。
随车照管人员未履行本条例规定的职责的，由学校或者校车服务提供者责令改正；拒不改正的，给予处分或者予以解聘。
