# 校车安全管理条例第五十七条

- 法规：校车安全管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1339fb2933/57.html

教育、公安、交通运输、工业和信息化、质量监督检验检疫、安全生产监督管理等有关部门及其工作人员不依法履行校车安全管理职责的，对负有责任的领导人员和直接责任人员依法给予处分。
