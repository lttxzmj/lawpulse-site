# 校车安全管理条例第十一条

- 法规：校车安全管理条例（现行有效）
- 章节：第二章学校和校车服务提供者
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-1339fb2933/11.html

由校车服务提供者提供校车服务的，学校应当与校车服务提供者签订校车安全管理责任书，明确各自的安全管理责任，落实校车运行安全管理措施。
学校应当将校车安全管理责任书报县级或者设区的市级人民政府教育行政部门备案。
