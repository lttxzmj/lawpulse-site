# 卫星地面接收设施接收外国卫星传送电视节目管理办法第三条

- 法规：卫星地面接收设施接收外国卫星传送电视节目管理办法（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-6aae81703b/3.html

国务院广播电视行政管理部门负责全国卫星地面接收设施接收外国卫星传送的电视节目的管理工作。
省、自治区、直辖市人民政府广播电视行政管理部门负责本行政区内卫星地面接收设施接收外国卫星传送的电视节目的管理工作。
