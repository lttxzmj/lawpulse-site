# 民用核安全设备监督管理条例第五十七条

- 法规：民用核安全设备监督管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3511ac6413/57.html

民用核安全设备设计、制造、安装和无损检验单位被责令限期整改，逾期不整改或者经整改仍不符合发证条件的，由国务院核安全监管部门暂扣或者吊销许可证。
