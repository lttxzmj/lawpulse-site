# 民用核安全设备监督管理条例第二十三条

- 法规：民用核安全设备监督管理条例（现行有效）
- 章节：第四章设计、制造、安装和无损检验
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3511ac6413/23.html

民用核安全设备制造、安装单位，应当在制造、安装活动开始30日前，将下列文件报国务院核安全监管部门备案：
(一)项目制造、安装质量保证分大纲和程序清单；
(二)制造、安装技术规格书；
(三)分包项目清单；
(四)制造、安装质量计划。
