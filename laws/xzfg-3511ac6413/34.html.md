# 民用核安全设备监督管理条例第三十四条

- 法规：民用核安全设备监督管理条例（现行有效）
- 章节：第五章进出口
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3511ac6413/34.html

国务院核安全监管部门根据需要，可以对境外单位为中华人民共和国境内民用核设施进行的民用核安全设备设计、制造、安装和无损检验活动实施核安全监督检查。
