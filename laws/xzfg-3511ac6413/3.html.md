# 民用核安全设备监督管理条例第三条

- 法规：民用核安全设备监督管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3511ac6413/3.html

民用核安全设备设计、制造、安装和无损检验活动适用本条例。
民用核安全设备运离民用核设施现场进行的维修活动，适用民用核安全设备制造活动的有关规定。
