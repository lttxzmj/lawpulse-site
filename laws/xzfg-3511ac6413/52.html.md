# 民用核安全设备监督管理条例第五十二条

- 法规：民用核安全设备监督管理条例（现行有效）
- 章节：第七章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-3511ac6413/52.html

民用核安全设备无损检验单位出具虚假无损检验结果报告的，由国务院核安全监管部门处10万元以上50万元以下的罚款，吊销许可证；有违法所得的，没收违法所得；对直接负责的主管人员和其他直接责任人员，处2万元以上10万元以下的罚款；构成犯罪的，依法追究刑事责任。
