# 最高人民法院关于审理技术合同纠纷案件适用法律若干问题的解释第三十六条

- 法规：最高人民法院关于审理技术合同纠纷案件适用法律若干问题的解释（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-0c90d86229/36.html

民法典第八百八十七条规定的“技术培训合同”，是指当事人一方委托另一方对指定的学员进行特定项目的专业技术训练和技术指导所订立的合同，不包括职业培训、文化学习和按照行业、法人或者非法人组织的计划进行的职工业余教育。
