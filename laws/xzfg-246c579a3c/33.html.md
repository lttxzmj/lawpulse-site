# 机动车交通事故责任强制保险条例第三十三条

- 法规：机动车交通事故责任强制保险条例（现行有效）
- 章节：第三章赔偿
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-246c579a3c/33.html

保险公司赔偿保险金或者垫付抢救费用，救助基金管理机构垫付抢救费用，需要向有关部门、医疗机构核实有关情况的，有关部门、医疗机构应当予以配合。
