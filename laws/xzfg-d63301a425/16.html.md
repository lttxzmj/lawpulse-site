# 中华人民共和国民用核设施安全监督管理条例第十六条

- 法规：中华人民共和国民用核设施安全监督管理条例（现行有效）
- 章节：第四章核安全监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d63301a425/16.html

国家核安全局及其派出机构可向核设施制造、建造和运行现场派驻监督组(员)执行下列核安全监督任务：
(一)审查所提交的安全资料是否符合实际；
(二)监督是否按照已批准的设计进行建造；
(三)监督是否按照已批准的质量保证大纲进行管理；
(四)监督核设施的建造和运行是否符合有关核安全法规和《核设施建造许可证》、《核设施运行许可证》所规定的条件；
(五)考察营运人员是否具备安全运行及执行应急计划的能力；
(六)其他需要监督的任务。
核安全监督员由国家核安全局任命并发给《核安全监督员证》。
