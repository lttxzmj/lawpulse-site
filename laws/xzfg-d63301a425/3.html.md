# 中华人民共和国民用核设施安全监督管理条例第三条

- 法规：中华人民共和国民用核设施安全监督管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d63301a425/3.html

民用核设施的选址、设计、建造、运行和退役必须贯彻安全第一的方针；必须有足够的措施保证质量，保证安全运行，预防核事故，限制可能产生的有害影响；必须保障工作人员、群众和环境不致遭到超过国家规定限值的辐射照射和污染，并将辐射照射和污染减至可以合理达到的尽量低的水平。
