# 物业管理条例第六十四条

- 法规：物业管理条例（现行有效，施行日期 2018-03-19）
- 章节：第六章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7b977506f7/64.html

违反物业服务合同约定，业主逾期不交纳物业服务费用的，业主委员会应当督促其限期交纳；逾期仍不交纳的，物业服务企业可以向人民法院起诉。
