# 物业管理条例第四十九条

- 法规：物业管理条例（现行有效，施行日期 2018-03-19）
- 章节：第五章物业的使用与维护
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7b977506f7/49.html

物业管理区域内按照规划建设的公共建筑和共用设施，不得改变用途。
业主依法确需改变公共建筑和共用设施用途的，应当在依法办理有关手续后告知物业服务企业；物业服务企业确需改变公共建筑和共用设施用途的，应当提请业主大会讨论决定同意后，由业主依法办理有关手续。
