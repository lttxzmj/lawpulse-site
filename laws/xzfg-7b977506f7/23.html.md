# 物业管理条例第二十三条

- 法规：物业管理条例（现行有效，施行日期 2018-03-19）
- 章节：第三章前期物业管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-7b977506f7/23.html

建设单位应当在物业销售前将临时管理规约向物业买受人明示，并予以说明。
物业买受人在与建设单位签订物业买卖合同时，应当对遵守临时管理规约予以书面承诺。
