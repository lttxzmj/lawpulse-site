# 最高人民法院关于审理民间借贷案件适用法律若干问题的规定第二十三条

- 法规：最高人民法院关于审理民间借贷案件适用法律若干问题的规定（现行有效，施行日期 2021-01-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-jiedai/23.html

当事人以订立买卖合同作为民间借贷合同的担保，借款到期后借款人不能还款，出借人请求履行买卖合同的，人民法院应当按照民间借贷法律关系审理。当事人根据法庭审理情况变更诉讼请求的，人民法院应当准许。
按照民间借贷法律关系审理作出的判决生效后，借款人不履行生效判决确定的金钱债务，出借人可以申请拍卖买卖合同标的物，以偿还债务。就拍卖所得的价款与应偿还借款本息之间的差额，借款人或者出借人有权主张返还或者补偿。
