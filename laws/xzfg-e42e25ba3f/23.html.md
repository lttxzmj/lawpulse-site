# 国务院关于禁止在市场经济活动中实行地区封锁的规定第二十三条

- 法规：国务院关于禁止在市场经济活动中实行地区封锁的规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e42e25ba3f/23.html

接到检举地区封锁行为的政府或者有关部门，不在规定期限内进行调查、处理或者泄露检举人情况的，对直接负责的主管人员和其他直接责任人员，按照法定程序，根据情节轻重，给予降级、撤职直至开除公职的行政处分。
