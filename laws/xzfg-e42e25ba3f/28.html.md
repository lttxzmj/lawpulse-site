# 国务院关于禁止在市场经济活动中实行地区封锁的规定第二十八条

- 法规：国务院关于禁止在市场经济活动中实行地区封锁的规定（现行有效）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-e42e25ba3f/28.html

本规定自公布之日起施行。
自本规定施行之日起，地方各级人民政府及其所属部门的规定与本规定相抵触或者部分相抵触的，全部或者相抵触的部分自行失效。
依据宪法和有关法律关于地方性法规不得同宪法、法律和行政法规相抵触的规定，自本规定施行之日起，地方性法规同本规定相抵触的，应当执行本规定。
