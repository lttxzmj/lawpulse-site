# 中华人民共和国民办教育促进法实施条例第三十二条

- 法规：中华人民共和国民办教育促进法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第三章民办学校的组织与活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9705f30809/32.html

实施高等学历教育的民办学校符合学位授予条件的，依照有关法律、行政法规的规定经审批同意后，可以获得相应的学位授予资格。
