# 中华人民共和国民办教育促进法实施条例第二十八条

- 法规：中华人民共和国民办教育促进法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第三章民办学校的组织与活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9705f30809/28.html

民办学校校长依法独立行使教育教学和行政管理职权。
民办学校内部组织机构的设置方案由校长提出，报理事会、董事会或者其他形式决策机构批准。
