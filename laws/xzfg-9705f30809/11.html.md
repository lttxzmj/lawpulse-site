# 中华人民共和国民办教育促进法实施条例第十一条

- 法规：中华人民共和国民办教育促进法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第二章民办学校的设立
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9705f30809/11.html

举办者依法制定学校章程，负责推选民办学校首届理事会、董事会或者其他形式决策机构的组成人员。
举办者可以依据法律、法规和学校章程规定的程序和要求参加或者委派代表参加理事会、董事会或者其他形式决策机构，并依据学校章程规定的权限行使相应的决策权、管理权。
