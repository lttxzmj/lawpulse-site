# 中华人民共和国民办教育促进法实施条例第三条

- 法规：中华人民共和国民办教育促进法实施条例（现行有效，施行日期 2021-09-01）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-9705f30809/3.html

各级人民政府应当依法支持和规范社会力量举办民办教育，保障民办学校依法办学、自主管理，鼓励、引导民办学校提高质量、办出特色，满足多样化教育需求。
对于举办民办学校表现突出或者为发展民办教育事业做出突出贡献的社会组织或者个人，按照国家有关规定给予奖励和表彰。
