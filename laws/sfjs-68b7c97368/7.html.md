# 最高人民法院关于适用《中华人民共和国反不正当竞争法》若干问题的解释第七条

- 法规：最高人民法院关于适用《中华人民共和国反不正当竞争法》若干问题的解释（现行有效，施行日期 2022-03-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-68b7c97368/7.html

反不正当竞争法第六条规定的标识或者其显著识别部分属于商标法第十条第一款规定的不得作为商标使用的标志，当事人请求依据反不正当竞争法第六条规定予以保护的，人民法院不予支持。
