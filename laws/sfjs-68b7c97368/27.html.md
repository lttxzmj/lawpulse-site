# 最高人民法院关于适用《中华人民共和国反不正当竞争法》若干问题的解释第二十七条

- 法规：最高人民法院关于适用《中华人民共和国反不正当竞争法》若干问题的解释（现行有效，施行日期 2022-03-20）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-68b7c97368/27.html

被诉不正当竞争行为发生在中华人民共和国领域外，但侵权结果发生在中华人民共和国领域内，当事人主张由该侵权结果发生地人民法院管辖的，人民法院应予支持。
