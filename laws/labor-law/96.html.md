# 中华人民共和国劳动法第九十六条

- 法规：中华人民共和国劳动法（现行有效，施行日期 2018-12-29）
- 章节：第十二章法律责任
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/labor-law/96.html

用人单位有下列行为之一，由公安机关对责任人员处以十五日以下拘留、罚款或者警告；构成犯罪的，对责任人员依法追究刑事责任：
（一）以暴力、威胁或者非法限制人身自由的手段强迫劳动的；
（二）侮辱、体罚、殴打、非法搜查和拘禁劳动者的。
