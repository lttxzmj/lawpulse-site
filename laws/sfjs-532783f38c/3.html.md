# 最高人民法院关于人民法院登记立案若干问题的规定第三条

- 法规：最高人民法院关于人民法院登记立案若干问题的规定（现行有效，施行日期 2015-05-01）
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/sfjs-532783f38c/3.html

人民法院应当提供诉状样本，为当事人书写诉状提供示范和指引。
当事人书写诉状确有困难的，可以口头提出，由人民法院记入笔录。符合法律规定的，予以登记立案。
