# 中华人民共和国国家安全法第二十一条

- 法规：中华人民共和国国家安全法（现行有效，施行日期 2015-07-01）
- 章节：第二章维护国家安全的任务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/national-security-law/21.html

国家合理利用和保护资源能源，有效管控战略资源能源的开发，加强战略资源能源储备，完善资源能源运输战略通道建设和安全保护措施，加强国际资源能源合作，全面提升应急保障能力，保障经济社会发展所需的资源能源持续、可靠和有效供给。
