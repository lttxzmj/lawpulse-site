# 中华人民共和国国家安全法第二十八条

- 法规：中华人民共和国国家安全法（现行有效，施行日期 2015-07-01）
- 章节：第二章维护国家安全的任务
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/national-security-law/28.html

国家反对一切形式的恐怖主义和极端主义，加强防范和处置恐怖主义的能力建设，依法开展情报、调查、防范、处置以及资金监管等工作，依法取缔恐怖活动组织和严厉惩治暴力恐怖活动。
