# 中华人民共和国国家安全法第八十一条

- 法规：中华人民共和国国家安全法（现行有效，施行日期 2015-07-01）
- 章节：第六章公民、组织的义务和权利
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/national-security-law/81.html

公民和组织因支持、协助国家安全工作导致财产损失的，按照国家有关规定给予补偿；造成人身伤害或者死亡的，按照国家有关规定给予抚恤优待。
