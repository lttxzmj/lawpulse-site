# 取水许可和水资源费征收管理条例第四十一条

- 法规：取水许可和水资源费征收管理条例（现行有效）
- 章节：第五章监督管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-d20f944249/41.html

有下列情形之一的，审批机关可以对取水单位或者个人的年度取水量予以限制：
(一)因自然原因，水资源不能满足本地区正常供水的；
(二)取水、退水对水功能区水域使用功能、生态与环境造成严重影响的；
(三)地下水严重超采或者因地下水开采引起地面沉降等地质灾害的；
(四)出现需要限制取水量的其他特殊情况的。
发生重大旱情时，审批机关可以对取水单位或者个人的取水量予以紧急限制。
