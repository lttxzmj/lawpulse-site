# 饲料和饲料添加剂管理条例第三条

- 法规：饲料和饲料添加剂管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-2dbab1e7f0/3.html

国务院农业行政主管部门负责全国饲料、饲料添加剂的监督管理工作。
县级以上地方人民政府负责饲料、饲料添加剂管理的部门(以下简称饲料管理部门)，负责本行政区域饲料、饲料添加剂的监督管理工作。
