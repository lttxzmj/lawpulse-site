# 中国人民银行货币政策委员会条例第二十三条

- 法规：中国人民银行货币政策委员会条例（现行有效，施行日期 2024-01-13）
- 章节：第四章工作程序
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-204d5f1411/23.html

货币政策委员会会议应当以会议纪要的形式记录各种意见。
货币政策委员会委员提出的货币政策议案，经出席会议的2/3以上委员表决通过，形成货币政策委员会建议书。
