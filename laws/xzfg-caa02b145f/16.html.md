# 社会保险经办条例第十六条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第二章社会保险登记和关系转移
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/16.html

用人单位和个人办理社会保险关系转移接续手续的，社会保险经办机构应当在规定时限内办理完毕，并将结果告知用人单位和个人，或者提供办理情况查询服务。
