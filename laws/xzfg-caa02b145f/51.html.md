# 社会保险经办条例第五十一条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第五章社会保险经办监督
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/51.html

任何组织和个人有权对违反社会保险法律、法规、规章的行为进行举报、投诉。
人力资源社会保障行政部门、医疗保障行政部门对收到的有关社会保险的举报、投诉，应当依法进行处理。
