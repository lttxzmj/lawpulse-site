# 社会保险经办条例第二十三条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第三章社会保险待遇核定和支付
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/23.html

人力资源社会保障行政部门、医疗保障行政部门应当按照各自职责建立健全异地就医医疗费用结算制度。社会保险经办机构应当做好异地就医医疗费用结算工作。
