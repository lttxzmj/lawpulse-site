# 社会保险经办条例第六十二条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第七章附则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/62.html

社会保障卡加载金融功能，有条件的地方可以扩大社会保障卡的应用范围，提升民生服务效能。医保电子凭证可以根据需要，加载相关服务功能。
