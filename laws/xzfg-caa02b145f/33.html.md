# 社会保险经办条例第三十三条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第四章社会保险经办服务和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/33.html

社会保险经办机构应当根据经办工作需要，与符合条件的机构协商签订服务协议，规范社会保险服务行为。人力资源社会保障行政部门、医疗保障行政部门应当加强对服务协议订立、履行等情况的监督。
