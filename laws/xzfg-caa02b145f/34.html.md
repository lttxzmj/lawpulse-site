# 社会保险经办条例第三十四条

- 法规：社会保险经办条例（现行有效，施行日期 2023-12-01）
- 章节：第四章社会保险经办服务和管理
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-caa02b145f/34.html

医疗保障行政部门所属的社会保险经办机构应当改进基金支付和结算服务，加强服务协议管理，建立健全集体协商谈判机制。
