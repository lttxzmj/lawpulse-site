# 对外承包工程管理条例第三条

- 法规：对外承包工程管理条例（现行有效）
- 章节：第一章总则
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5a7cb0d490/3.html

国家鼓励和支持开展对外承包工程，提高对外承包工程的质量和水平。
国务院有关部门制定和完善促进对外承包工程的政策措施，建立、健全对外承包工程服务体系和风险保障机制。
