# 对外承包工程管理条例第十九条

- 法规：对外承包工程管理条例（现行有效）
- 章节：第二章对外承包工程活动
- 数据核对至：2026-10-22
- 本页：https://lttxzmj.github.io/lawpulse-site/laws/xzfg-5a7cb0d490/19.html

国务院商务主管部门应当会同国务院有关部门建立对外承包工程信息收集、通报制度，向对外承包工程的单位无偿提供信息服务。
有关部门应当在货物通关、人员出入境等方面，依法为对外承包工程的单位提供快捷、便利的服务。
